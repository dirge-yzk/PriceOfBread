## 1. 方針

### 1-1. 値段に関わる量の 3 つの源

この doc の後の形では、値段に関わる量は次の 3 つのどれかから導く。参照価格（ゲームの外で一度だけ計算した固定の値段）を、値段を決める側・比べる側・見積もる側のどこにも置かない。

| 源 | 中身 | 既にある物【確】 |
|---|---|---|
| **①市場の値段** | その国の平滑化した実質の値段 `World.DiscoveryPrice`（国×財＋1・四半期の指数平滑・時定数 約3年・セーブに載る）・その時の値段 `Markets[g].Price`・着値 `WorldMarket.Landed`・世界の中央値（各国の `DiscoveryPrice` の中央値＝導ける量） | `World.cs:194`・`Discovery.cs:657-685`（`AdvancePrice`）・`:423`（`PriceSmoothingQ`） |
| **②作り方の費用（自然価格）** | その国で門の開いたレシピのうち一番安い作り方の費用＝自己費用×自己費用の物価水準÷物価水準＋Σ投入の量×投入の値段。市場の死んだ投入は〈着値と作る費用の安い方〉を同じ規則で繰り返す（＝**潜在の自然価格**）。投入の輪・作れない投入は値段なし | `Discovery.PriceBook`（`Discovery.cs:784-830`）・`NaturalPrior`（`:691-713`） |
| **③物の単位** | 物の量の換算（栄養・労働の時間・金属の量目・艦の強さ）。データの欄に出典つきで持つ | 一部（`Nutrition` の欄はあるが主食は −1＝未記入【確】 goods.json） |

### 1-2. 参照価格が最後に残る所＝〈1783 年の値段〉（量の物差しだけ）

- 実質の量の物差し（実質 GDP・艦の強さの換算・計器の額）だけに〈1783 年の値段〉として残す。値段を動かさない・比べる基準にしない・見積もりに使わない。
- **初期値の焼き込みの後は、初期値からも外す。** 開幕の値段・世界価格の初期値・地代の種は焼き込んだ盤面から読む（§3-9）。その後〈1783 年の値段〉の定義も、焼き込んだ開幕の盤面の世界の中央値（①）へ付け替える。1783 年に市場の無い財（新製品）は焼き込んだ開幕の潜在の自然価格（②）。`Catalog.ComputeRefPrices`・`ServiceRefPrice`・`Good.RefPrice` の欄は消える（§5 段11）。
- 残る弱さ（記録）：新製品の量の重みは開幕の潜在の自然価格＝作れる投入が揃っていない時の費用＝高めに出る。連鎖の指数にすれば消えるが、前の期の値段を貯める新しい状態が要る（思想⑩）＝入れない。

### 1-3. 同じ種類の固定の値段で、この回では残す物（正直に書く）

参照価格を消しても、名目の水準を錨で止めているのは次の定数×`CostPriceLevel` になる。どれも〈1783 年の金の額〉＝参照価格と同じ種類【確】。

## 3. 用途ごとの新しい形（AI の推奨）

### 3-1. 原則

- 新しい状態は作らない（思想⑩）。例外は必要性の最高値 1 本だけ（作者の裁定・§4-3）。
- 自然価格は既にある `PriceBook` を一般化して 1 本にする（第 2 の費用の関数を書かない）。
- 値段を決める側（価格の法則）は中央値も自分の平滑値も読まない＝自然価格（費用）を読む。費用は投入の値段から来る＝自分の値段を追わない＝引き戻す力が残る。
- 実質と名目を二重に掛けない。`DiscoveryPrice` は実質＝名目にするのは読み手が 1 回だけ物価水準を掛ける。
- 分子と分母は同じ段で同じ源へ移す（記憶〈分子と分母の非対称〉）。
- 量子化キャッシュの不変条件：四半期ごとの控えは四半期首の入力（セーブに載る `DiscoveryPrice` と門）だけから作る＝ロードの直後にも同じ値。

### 3-2. 自然価格の 1 本（②）

- 定義：`N[国, 財]` ＝その国で門の開いたレシピの一番安い作り方の費用＝`PriceBook.Of`。投入の値段＝国内の市場が生きていれば自国の `DiscoveryPrice`・死んでいれば〈着値と作る費用の安い方〉（同じ読み方を投入へ繰り返す＝潜在の自然価格）。役務の投入（労働）は賃金の `DiscoveryPrice`。
- 作れない財（門の開いたレシピが無い）＝着値・それも無ければ最後に観測した平滑値・それも無ければ値段なし（番兵 −1。否定形 `!(x >= 0)` で書く）。
- 頻度＝**四半期**（`DiscoveryPrice` が動く時）。控えは作業領域（セーブに載せず、ロードと四半期首に作り直す）。2026-10-02 の文面の〈毎年〉からの変更は §1-7（年の途中のロードで再現できない＝新しい状態になるため）。
- 置き場：州の `Good` に作業領域の欄を 1 本（`NaturalPrice`・州の物価水準を掛ける前の実質）。`MarketFlow:196` と `BilateralMarket:811/913/921` は**同じ口**を読む。
- 閉路：投入の値段→自然価格→値段→投入の値段。自己費用と労働が正なら利得は 1 未満【推】（`ComputeRefPrices` の反復が収束していることが 1783 のレシピでの証拠）。漂いは線で見る（§7-2）。

### 3-3. 価格の法則の中心（段3）

- 今の `GoodsYAmp`【確】`MarketFlow.cs:310-318`（速さ `AmpOf` は `:301`）：実効需要 `D×(rp/P)^ε`・実効供給 `S×(P/rp)^ε` ＝不動点 `P* = rp×(D/S)^(1/2ε)`。旬の中で D と S は定数＝この支点が旬の中の唯一の復元力。
- 新：支点を `rp`＝参照×物価水準 から **`N×物価水準`** へ。供給の側は〈値段が費用を越えれば多く出す〉＝支点が費用なのは経済の形どおり。需要の側の支点も同じ値に置く（不動点を費用に置くため・旬の中の復元力だけの働き）。
- 動きの速さ `AmpOf`（対数の乖離）と帯 `SoftBandLn` の中心も同じ `N×物価水準`。⚠ 閉じた式の速い道（`BandT`・`SoftT`・`SubStep`・`PinnedClosed`）は**渡す値を変えるだけ**でコードは触らない（高速化のフォーク spd が同じ行を触る＝衝突を避ける）。

## 4. 発見の必要性＝古いやり方の側の圧力

### 4-1. 式（メインのセッションの推奨を式にした・作者の承認は未確認）

行 d（製法・新製品）ごとに、古いやり方 O と新しいレシピ R を置く。

- **製法の行**：O＝**行ごとに固定の前のレシピ**（データ）＝同じ財の、発見の表に行の無いレシピ（地理差＝1783 年から開いている物）。同じ財に地理差のレシピが 2 本以上ある行（紙のぼろ布と木・肥料の厩肥とグアノの類）は、段5 の計器で行ごとに取り出して表にし、1 本を選ぶ（選べない行は前のレシピの名前をデータの欄 `Predecessor` に書く＝新しい係数ではなくデータ）。R＝行のレシピ。産出 1 単位あたりの投入の量の差 `Δq_g = q_R(g) − q_O(g)`（労働・技師も財として数える）。**O が国で変わらない＝Δq はどの国でも同じ**＝下の約分の条件。
  - 置き換える要素 S＝`Δq_g < 0` の財（新しいやり方で減る物）・使う要素 U＝`Δq_g > 0` の財（増える物）。
- **新製品の行**：S＝代替する財（`Replaces`）1 単位・U＝R の投入（新しい財そのものは R の投入ではない）。
- **既にある財だけ**：U と S の財は世界のどこかに市場がある物（世界の平滑化した値段がある）。U のどれかが世界のどこにも無い行は必要性 0（前提の財が無い＝作者の「電力はともかく」の行はここで待つ。電力が世界のどこかで作られた四半期から立つ）。
- **まだ需要の無い投入の割高さは約分で消える**：作者 2026-10-20「例えば蒸気機関が発明されるまでは、機械部品もあまり生産されておらず（需要がないため）、蒸気期間は非常に割高だ。」＝発明の前の機械部品・蒸気機関の財の割高さは**どの国でも同じ向き**（どこにも需要が無い）＝`X_n ÷ 中央値` で打ち消される。投入を手で選んで外す規則は要らない（行ごとの手の選び方は置かない）。残るのは国の差（英は機関を安く作る・清は高い）だけ。
- 国 n の値段 `p_n(g)`：国内の市場が生きていれば自国の `DiscoveryPrice`・死んでいれば着値・取引できない財（電力）は潜在の自然価格・それも無ければ世界の中央値。⇒**全ての国で同じ財の組を同じ量で数える**（比が約分できる条件）。
- 国の比：`X_n = Σ_{g∈S} |Δq_g| p_n(g) ÷ Σ_{g∈U} Δq_g p_n(g)`（U が空なら分母 1）。
- **圧力**：`P_n = ln( X_n ÷ 中央値_m X_m )`。m＝今の規則と同じ〈使っている国〉＝製法は行の財の需要 `dem[g] > 0` の国・新製品は代替する財の需要 `dem[Replaces] > 0` の国（`Discovery.cs` の `ReplacedStrength` の〈使っていない物の代わりは要らない〉と同じ門）。`P_n ≦ 0` は 0。
- 必要性の項：`70 × P ÷ (P ＋ 半分点)`（今の `Saturate`）。**半分点は今の 1 本（製法 0.2・新製品 0.4）を引き継げない**（§4-3）。

性質（なぜこの形か）：

1. **換算の比が消える**。新製品の S と U は別の財＝物の単位がそろわないが、どの国でも同じ定数が掛かるので `X_n ÷ 中央値` で約分される＝`ReplacedUnits`（参照価格の比）は削除。作者への確認②（Q-NW1）はこの形では答えが要らない。
2. **世界に共通の跳ねが消える**。開幕の 2〜7 倍の跳ね（(454) の根 1・〈窓は全ての国に開く〉）は全ての国の X を同じ向きに動かす＝中央値で打ち消される。残るのは国ごとの偏りだけ。
3. **〈高いか〉の相手が世界**。作者 2026-10-02 の一般則〈代替するものが高いか〉の相手を〈新しいレシピの費用〉（「2でよい」）から〈世界の同じ比〉へ移す＝**「2でよい」からの変更**。理由＝新しいレシピの費用は作られていない投入の値段を読む＝作者 2026-10-20 の蒸気機関の文の形で発明の前に割高に出る（(454) 型C の主な部分＝根 3）。§1-7 で推奨で進め、報告の先頭に書く。
4. **限界**：中央値と比べるので、どの時点でもおよそ半分の国は圧力が正。必要性は〈いつ〉を決めず〈どこで先に〉を決める。〈いつ〉は時計（技術力の項＝技師の量・Q-W1′ は〈あたらない・細い傾斜〉）が決める。世界の全体が上がる必要（例：世界の硫黄の高騰）は中央値で消える＝**世界で最初の発見は、中央値より上の国の偏りと最高値の記録からしか起きない**。
