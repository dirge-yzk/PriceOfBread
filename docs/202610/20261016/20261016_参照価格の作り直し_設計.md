## 3. 用途ごとの新しい形（AI の推奨）

### 3-1. 原則

- 新しい状態を作らない（思想⑩）。**平滑化した値段は既にある**＝`World.DiscoveryPrice`（国×財＋1・四半期の指数平滑・実質＝値段÷物価水準・セーブに載る・思想⑩の例外として理由つきで置かれた1本）【確】`World.cs:198`・`Discovery.cs:563-578`。新しい読み手はこれを読む。
- 世界の値は導く。`Discovery.WorldPrices` の平均は重みが四半期首の瞬間の産出（セーブに載らない）＝ロードの直後に再現できない。**世界の中央値**（各国の `DiscoveryPrice` の中央値）はセーブに載る値だけで再現できる＝導ける量。1-2 の③〈中央値〉はこの点でも合う。
- 値段を決める側（①②）は中央値も自分の平滑値も読まない（1-2 の注意どおり）。
- 実質と名目を二重に掛けない。`DiscoveryPrice` は実質。名目にするのは読み手が1回だけ `×PriceLevel`（または `CostPriceLevel`）を掛ける。
- 分子と分母は同じ段で同じ物差しへ移す（`PolicyPreferences`・`World.cs:346`・GDP の比）。

### 3-2. ②帯の中心＝自然価格

- 定義：自然価格[国, 財]＝その国で門の開いたレシピのうち一番安い作り方の費用。費用＝自己費用（`FactoryVa`・`RgoVa`）＋Σ投入の量×投入の `DiscoveryPrice`（市場が死んだ投入は同じ規則の自然価格）＋労働×賃金の `DiscoveryPrice`。帯の中心＝自然価格×州の物価水準（今の `RefPrice×pl` と同じ形）。
- 役務（労働3財ほか）は据え置き（生産者に投入が無い・(219) と同じ）＝§5 Q2。
- 作り直しの頻度：**四半期**（`DiscoveryPrice` が動く時）⚑。1-2 の文面は〈毎年〉。毎年にすると年初の入力を別に貯める必要が出る（年の途中のロードで再現できない＝新しい状態）。四半期なら `DiscoveryPrice` と門（どちらもセーブに載る）から**いつでも導ける**＝控えは作業領域（セーブに載せず、ロードと四半期首に作り直す）。量子化キャッシュの不変条件（鍵が四半期なら値も四半期首の入力から）を守る。〈毎年〉からの変更は §1-7（推奨で進め、報告の先頭に書く）。
- 門は技術（発見）で決める。建った工場の有無では決めない＝旬の中で動かない。
- 置き場：州の `Good` に作業領域の欄を1本（`NaturalPrice`）。`MarketFlow:196` と `BilateralMarket:738/834/842` は**同じ口**を読む（`gd` の使い回しを州ごとの引きへ直すのは段1 で恒等に）。
- 閉路：投入の値段→自然価格→値段→投入の値段。レシピの行列が生産的（自己費用と労働が正）なら利得は1未満【推】＝`ComputeRefPrices` の反復が収束していることが 1783 のレシピでの証拠。新しいレシピもこの条件を守る。漂いは線で見る（§4-3）。

### 3-3. ③評価＝GDP ほか

- 1-2 の形：平滑化した市場の値段の中央値（その時の値段）。
- ⚠ 型の問題：`GdpPerMonth` は `RealGdpPerMonth`、名目は `NominalGdpPerMonth => NominalOf(GdpPerMonth)`（`World.cs:1633`）【確】。1-2 の組み合わせは単位の値型（2026-10-10）より前の案。③をそのまま実質へ入れると、名目の読み手 31 行は〈今の相対価格×物価水準〉を読む＝式は閉じるが、**時代をまたぐ量の伸び**（成長）は相対価格の変化と混ざる。
- 史実の計り方（§4-4）：量の伸びは基準年の値段で測る（固定か連鎖）。比（債務÷GDP・軍事費÷GDP・貿易÷GDP）は名目÷名目＝その時の値段。
- 推奨（§5 Q1 の案 B）：**実質＝基準年の固定のまま**（量の物差し・`Catalog.RefPrices` を〈1783 年の値段〉と名前を変えて残す）。**名目＝その時の値段**（Σ産出×その国の `DiscoveryPrice`×物価水準。`NominalOf(実質)` をやめる）。国力・脅威・割譲・首都の比べは同じ時点の国どうし＝実質（固定）で足りる。
- 案 B の利点：メモ化の鍵は実質の側で今のまま。名目は同じ走査に足し算を1本足し、鍵に値段の世代（四半期）を足すだけ。
- 案 B で要る仕分け：実質の読み手（`.GdpPerMonth` の 27 行）を〈量の物差し〉と〈金の額〉に分ける表を段1 で作る。金の額は名目へ移す。例【確】：金の額＝`Diplomacy.cs:786`（拿捕の賞金・注に〈実質 GDP を貨幣の額に使う〉と自分で書いてある）・`:1340`（貢納）・`:2967`（賠償金）／量の物差し＝`:1045`・`:1110`（脅威の質量）・`SelfPlay.cs:46`（経済規模）・`TechEducation.cs:41`（1人あたり）。残りは段1 の表で決める。

### 3-4. ④計画の見積もり
