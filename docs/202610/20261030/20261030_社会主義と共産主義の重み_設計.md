## 1. 今の式の形と、なぜ共産主義にほぼ回らないか

### 1-1 式（`Ideology.cs`）

POP ごとの思想の重み `r` は、毎四半期に `UpdateShares`（:16〜110）で作り直す。

- 基底（`BaseWeights`・:156〜195）。閉鎖階級でも兵士でもない POP（:184〜194）：
  - 社会主義 `r[5] = 2·poor·(1−rentier) + (都市なら 1.0)`（:188）
  - 共産主義 `r[6] = 1.5·poor·(都市なら 1)`（:189）
  - poor＝平均未満の窮乏∈[0,1]・rentier＝所得のうち地代の割合∈[0,1]。
- 意識と闘争度の加点（:80〜85）。`prog = 1 − conserv`（富裕ほど小さい）・`mil = max(闘争度, 不満度)`（:58）：
  - 自由 `r[2] += 2.5·cons·prog`・共和 `r[3] += (1.5·cons + 1.0·mil)·prog`
  - 社会主義 `r[5] += (1.0·cons + 1.5·mil)·prog`（:83）
  - 共産主義 `r[6] += 2.0·mil·prog`（:84）
  - 無政府 `r[7] += 1.0·mil·prog`（:85）
- 出来事の加点：公約の思想 `r[ManifestoIdeology] += ManifestoCredit`（:91〜92）・飢えの記憶 `r[5] += famSoc`（:95）。どちらも社会主義の側にしか乗らない（公約が共産主義になった行は (681) で 0）。
- 思想の門（:97）：`r[5] *= eraSoc; r[6] *= eraComm;`（発見の表の 2 値＝見つけていない国では 0）。
- `Normalize`（:197〜203）で和を 1 にする。比例なので POP の主軸（最大の思想）は変わらない。

### 1-2 代数で閉じる＝都市の賃金で暮らす POP では、主軸が共産主義になることは無い

(671) の〈意識が闘争度の半分未満の POP だけが共産主義に回る〉は必要条件で、十分条件ではない。基底の差も入れて閉じる。

- 都市の POP（閉鎖でも兵士でもない）で `r[6] − r[5]` を作る：
  - 基底の差 ＝ `1.5·poor − 2·poor·(1−rentier) − 1.0` ≦ `1.5·poor − 2·poor − 1.0 + 2·poor·rentier` 。rentier＝0（賃金で暮らす POP）なら `−0.5·poor − 1.0` ≦ **−1.0**。
  - 加点の差 ＝ `(2.0·mil − 1.0·cons − 1.5·mil)·prog` ＝ `(0.5·mil − cons)·prog` ≦ **0.5**（mil∈[0,1]・`Politics.cs:322` で目標を [0,1] に切る）。
  - 出来事の加点（公約・飢え）は社会主義の側だけ。
  - 合計 ≦ −0.5 ＜ 0。**闘争度と意識がどんな値でも、都市の賃金で暮らす POP の主軸は共産主義にならない。**
- 主軸が共産主義になれるのは、都市でなく地代の割合が大きい POP だけ（基底の社会主義 `2·poor·(1−rentier)` が小さくなる）。rev3 の格子で共産主義が立った 25 点〈地代依存 0.75 以上〉と同じ。**設計の向き（都市の労働者の思想）と逆**の所にだけ共産主義の主軸が立つ。
- 兵士（:179〜183）は国民主義の基底 4 に `2.0·mil·prog ≦ 2` が届かない。閉鎖階級は伝統の基底 `2·rentier + 0.5 + 特権` に届きにくい。

### 1-5 史実との食い違い（〈推〉）

- 今の式は〈意識の高い労働者は社会主義・意識が低く闘争的な労働者が共産主義〉の形。史実の革命的な社会主義（ボリシェヴィキ）の担い手は、識字があり組織された都市の熟練工（ペトログラードの金属工）だった〈推・一般の知識〉。今の式は意識の項（:83 の `1.0·cons`）を社会主義の側にだけ置くので、組織された層ほど共産主義から遠ざかる。
- 改良主義と革命主義の分かれ目は、労働者の組織と政治参加が合法の道を持つかどうか（排除の仮説）とされる〈推・Lipset 1983『Radicalism or Reformism』・Marks ほか 2009 の第一次大戦前の社会主義政党の比較〉。出典は手元で確かめていない。

## 2. 式の案（rev3 [R5] の ①②③ を満たす 1 本）

### 2-1 形＝左の束の中の移し替え（和を変えない）

思想の門（:97）の**後**・ファシズムの加点（:99）と `Normalize` の前に、社会主義の重みの一部を共産主義へ移す。

```
// 旗 RadicalSplitByRepression（仮の名・既定 0）> 0 のときだけ
double t = eraComm * repress * mil * r[5];   // r[5] は門の後（eraSoc＝0 の国では既に 0）
if (t > 0) { r[5] -= t; r[6] += t; }          // 否定形＝t が 0・NaN なら何もしない
```

- `repress`＝労働者の組織の合法の道が閉じている度合い∈[0,1]＝`1 − 組合の合法度`。組合の合法度は `Politics.MeasureMobilization`（`Politics.cs:531`）の表（容認 1.0・統制 0.5・非合法 0）を**関数に出して両方が呼ぶ**（新しい表を書かない。報道法に 2 つの表がある罠〔`Coefficients.cs:3444`〕を作らない）。国の量なので POP のループの外で 1 回だけ求める（`unionMob` と同じ作法）。
- `mil`＝同じループの局所変数（max(闘争度, 不満度)・:58〜59）。新しく読む量は無い。
- 移すのは社会主義からだけ。共和・無政府・自由・伝統・反動・国民主義・帝国・王党派の重みは 1 ビットも変わらない。和 `r[5]+r[6]` は**代数では**変わらないので、`Normalize` の分母も代数では同じ＝他の思想のシェアは代数では動かない（社会主義と共産主義の割り振りだけが動く）。**浮動小数では `(r[5]−t)+(r[6]+t)` が `r[5]+r[6]` と最下位の桁で違いうる**＝分母が最下位でずれ、他の 9 思想のシェアも最下位の桁が動きうる。ビット一致を主張できるのは t＝0 の経路（eraComm＝0・eraSoc＝0・組合容認・`mil`＝NaN）だけで、そこは `r` に触れない形なので無傷。
- ファシズムの加点（:99）は `r[1]`・`r[4]` だけを読む＝移し替えの影響を受けない。

### 2-2 rev3 [R5] の 3 条件

1. **v→0 で発散しない**：発言権を読まない。割り算が無い。`repress`・`mil`∈[0,1]・`r[5]`≧0 の積＝有限。床も天井も置かない（設計思想⑧）。
2. **eraComm＝0 の国で旗 0 と一致**：`eraComm` は 0.0 か 1.0。0.0 なら `t = 0`（全ての因子が有限で非負）＝`if (t > 0)` が偽＝`r` に触れない＝旗 0 とビット一致。eraSoc＝0 の国は `r[5]` が既に 0 で同じく一致。**組合が容認の国（repress＝0）も一致**。旗を上げて世界が変わるのは〈社会主義と共産主義の両方を見つけ、組合が非合法か統制の国〉の POP だけ。`mil` が NaN のときは `t` が NaN で `if (t > 0)` が偽＝旗 0 と同じ（旗 0 でも NaN の `mil` は `r[1..7]` を NaN にして `Normalize` が 0 へ倒す）。
3. **絶対王政の国で急進の全量が共産主義へ行かない**：`t ≦ mil·r[5] ≦ r[5]`。移るのは社会主義の重みのうち闘争度の割合だけで、共和（`r[3]` は `1.0·mil·prog` を持つ）と無政府（`r[7]`）の重みは残る＝急進（共和・社会・共産・無政府）の全量が共産主義になるのは作りの上で無い。数の見込み（1-4 の生から・国の平均の闘争度を全ての POP に当てた近似）：絶対王政の 1,151 行で、左の束（社会＋共産）のうち共産主義の割合が 旗 0 の中央 0.266・最大 0.323 → 案の中央 0.468・99% 0.645・最大 0.672。

### 2-3 反転の条件（P2 が開く所）

- 移した後に主軸が共産主義へ変わる条件は `r[6] + t > r[5] − t` ＝ θ（＝`repress·mil`）＞ `(1 − r[6]/r[5]) / 2`。
- 都市の窮乏した賃金の POP（poor＝0.5・cons＝0.3・mil＝0.3・prog＝1）：`r[5]＝2.75`・`r[6]＝1.35` → θ ＞ 0.25。共和 1.75・自由 1.75 も上回る（移した後の共産主義 2.175）。農村の窮乏した POP（同じ値・都市でない）：`r[5]＝1.75`・`r[6]＝0.6`＝社会主義を上回るのは θ ＞ 0.33 だが、共和（1.75）を上回るには `0.6 + θ·1.75 ＞ 1.75`＝θ ＞ 0.66 が要る（共和の重みは移し替えで変わらない）。
- **組合が非合法なら、都市の窮乏した POP は闘争度が 0.25 前後を超えた所で主軸が共産主義へ変わる。農村は 0.66 前後まで共和が上に残る**＝式の上でも共産主義は都市の側に立つ。閾値は式の中に置いていない（比例の形・README §1-8）。閾値は式の中に置いていない（比例の形・README §1-8）。

### 2-6 設計思想の点検

- ⑧ 天井なし：新しい床・上限・閾値を置かない。`repress`・`mil` はもとから [0,1]。
- ⑨ 二重計上：`mil` は共産主義の加点 `2.0·mil` にも入っている（闘争度の主効果）。移し替えは `repress×mil` の交互作用で、repress＝0 なら消える＝別の原因（法）の項〈AI の読み＝⑨に当たらない〉。ただし闘争度の向きを二度読む形ではあるので、代案 B′（3-3 の Q3）を残す。発言権は読まない（不満度に `(1−発言権)` が既に入る〔`Politics.cs:203〜204` の `LawDistance`〕）。報道法も読まない（報道の自由は意識の目標に既に入る〔`Politics.cs:256`〕＝意識の項 `1.0·cons` を通って社会主義の側へ既に効いている）。
- ⑩ 新しい状態：無い（毎四半期に作り直す重みの中の移し替え・保存する値は無い）。
- 新しい倍率：無い（係数のリテラルを足さない・旗は 0 か 1 の門で、掛け算の強さにしない）。
- 文化に属性を付けない・国名を書かない：読むのは法の段と POP の量だけ。
