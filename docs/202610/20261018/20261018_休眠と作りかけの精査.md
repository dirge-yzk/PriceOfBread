## §1 判定の基準

作者の方針（原文）：

- 「全てのバフ・デバフ(特に倍率を変更するもの）は全て削除したいです。」
- 「技術水準・工業化度・制度疲労ですが、これらは「盤面から導く形に置換」ではなく、これらは既に経済側に機能しているので、それを集計してバフ/デバフを与えるのは全て二重計上という判断です。」
- 「闘争度・正当性・威信→保持(過去の記憶も含むため)」
- 「文化に属性は付けたくない。」
- 「史実度の低下は差し戻し理由にはなりません。」「バランスより正しい挙動を優先してください」

AI の整理：

| 判定 | 基準 |
|---|---|
| **不要** | 〈読み手が無い〉〈回らない枝の中にしか無い〉〈集計値や抽象の状態を入力にして、本物の流れへ掛ける倍率と閾値〉〈導ける量を貯めている（思想⑩）〉〈既定 1 で点火済みの旗の、0 の側の旧い枝〉〈根拠のないクールダウン〉〈廃止が決まった量（汚職・技術水準・工業化度・厭戦・行政効率・条約港）の読み手〉 |
| **修正** | 働きは本物だが形が方針に反する。天井と床（思想⑧）・二重計上（⑨）・新しい状態（⑩）・閾値の崖・片方向の錠・国や財の特例・文化の札・分子と分母の非対称 |
| **必要** | 本物の流れ・値段・量・所得への応答で、まだ点いていない物。レシピ・発見の生産性・減価・輸送の物理の換算 |
| **残す** | 今の形で方針に合う物（値段への応答・初期値のデータ・土地のデータ） |

時期の決め方：

- 闘争度・正統性・威信は保持します。これらに掛かる事件の項は、二重計上かどうかだけを問います。
- 技術水準と工業化度は、置き換えでなく削除です。ただし (386)(391) の読みに従い、学習曲線（工程の発見の行）と工場の設備を先に入れます。
- 州をまたぐ資本と海外投資は、全ての残りのタスクの後です（作者 2026-10-13）。
- 〈恒等で消せる〉は、既定が 0 か、枝に入らないか、消しても計算される値が 1 つも変わらない物だけです。成績表 3 枚の全行一致で確かめます。
