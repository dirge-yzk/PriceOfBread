# 2. 何を作るのか（一文）

> **★★★貨幣需要を財の市場に立てる。** 銀本位の国は通貨の裏付けとして銀を買い、金本位の国は金を買う。⚠ **各国が金へ移るほど銀の需要が消え、銀が暴落する。**

⚠ **新しいスカラーを1つも作らない。** ★ 銀価格＝**銀(120) の市場価格そのもの**である。

# 3. 設計

## 3-1. ★★★ 貨幣需要を市場に立てる（⚠ 本設計の心臓）

★ 鋳造（`GoldMintFraction`）は既に「金鉱の産出を造幣局が買う」形を持つ。⚠ **これを「本位金属の準備需要」へ一般化する。**

```
★金本位の国  → 金(4)   を通貨の裏付けとして買う
★銀本位の国  → 銀(120) を通貨の裏付けとして買う
⚠不換の国    → どちらも買わない
```

★★ **買う量は「基礎貨幣 × 目標カバー率 − 現在の準備」**——⚠ **既にある `Convertibility` のカバー率の式が分子分母を持っている。**

### ★★★ これで暴落が内生する

```
1783年   ⚠多くの国が銀本位（★金は持っていない）→ ★★銀の需要が大きい
  ↓
1871年   ★ドイツが金本位へ
  ↓      ⚠ドイツの銀需要が【消える】＋ ★ドイツが準備の銀を売る
1873年   ★★他国が追随 → ⚠銀の需要が次々に消える
  ↓
1890年代 ★★★銀が暴落
```

⚠⚠ **価格弾力性（安くなると需要が増える）と戦えるのは、これが「需要曲線上の移動」でなく【需要曲線そのものの下方シフト】だからである。**

```csharp
MarketFlow.cs  eD = ★totalDemand × (参照価格/価格)^PriceElasticity
```

★★★ **`totalDemand` そのものが半減すれば、弾力性では戻せない。**

### ★ そして金は逆に上がる

⚠ **同じ機構が、金の需要を増やす。** ★★ **金は上がり、銀は下がる**——★★★ **これが1870年代に実際に起きたこと**である。

## 3-2. ★ 金銀の産出を `world.json` へ足す（⚠ データのみ）

⚠ **現状ゼロなので、機構を作っても供給が無い。**

| 金属 | 主な産地（1783年時点） |
|---|---|
| ★**銀** | **ヌエバ・エスパーニャ（メキシコ）**★★世界最大／**ペルー**（ポトシ）／⚠**日本**（★石見。**既に衰退期**）／ボヘミア |
| ★**金** | **ブラジル**（★ミナスジェライス）／⚠ **カリフォルニア・豪州・南アは1848年以降**＝★★初期はゼロでよい |

★★ **1783年に金の産地が薄いのは正しい。** ⚠ **金本位が19世紀後半まで広がらなかったのは、金が足りなかったからである。**

★ 思想②に照らして問題ない——⚠ **`world.json` の `resources` は一次データであって、国ごとの倍率ではない。**

## 3-3. ★★ 鉱脈の発見（⚠ 枯渇の鏡像）

★ 既存の枯渇イベントと**同じ形**で、逆向きを足す。

```
★枯渇  年次確率で産出が 0.2 倍へ → ⚠緩やかに回復
★★発見  年次確率で産出が n 倍へ → ★緩やかに減衰（⚠ 鉱脈は尽きる）
```

★★★ **これで「カリフォルニア1848」「コムストック1859（銀）」「南アフリカ1886」が、暦年でなく確率から出る。**

⚠ **暦年を書かない**（思想①）。★ ただし**技術ゲート**は置いてよい——⚠ 深い鉱脈は掘削技術が要る。

## 3-4. ★ 法を3値へ開く

```
不換紙幣（0） ／ ★銀本位（1） ／ 金本位（2）
```

⚠ **`GoldStandardLaw` は `bool` なので、3値の enum へ変える。** ★ 呼び手は6箇所前後で、`StepBool` → `StepEnum` への差し替えになる（★ `StepEnum` は他の法で使用済み）。

★★ **階段の順序が意味を持つ**：不換 → 銀 → 金。⚠ **1期1段しか動けない**ので、★★★ **不換から一気に金へは飛べない**——⚠ 史実でもまず正貨兌換を回復し、次に本位を選んだ。

## 3-5. ★★★ 為替は既存の式がそのまま出す（⚠ 新しい係数ゼロ）

```csharp
World.cs  rateTarget = floatTarget + (1 − floatTarget) × ★Convertibility
```

⚠ **`Convertibility` を「金への兌換」から「★★本位への兌換」に読み替えるだけ。**

★★ **すると自動的にこうなる：**

```
金本位国 ⇄ 金本位国   ★固定（⚠双方 Convertibility=1 で平価1.0）
銀本位国 ⇄ 銀本位国   ★固定（同上）
★★★金本位国 ⇄ 銀本位国   ⚠変動 ← 【銀価格がここに入る】
```

★★★ **「銀安で輸出有利／輸入不利」は、局所価格に係数を掛けるのでなく——⚠ `ExchangeRate` が本位ごとの平価を持てば、既存の交易の式が出す。**

## 3-6. ★★★ 金建て債務の実質負担（⚠ 移行を強いる力）

★★ **史実で銀本位国を金へ追い込んだ最大の力。**

| | |
|---|---|
| ★**インドの Home Charges** | ⚠ ロンドンへの支払いが金建て。★★ 銀安で**実質負担が倍増** |
| ★**清の庚子賠款**（1901） | ⚠ 金建て4億5千万両。★ 銀安で膨らみ続けた |

★ 現物には**対外国債**があり、⚠ **引き受け手が実在する**。★★ **銀本位国の対外債務を金建てで評価すれば、`ExchangeRate` がそのまま効く。**

⚠⚠ **保存則に注意**：★★★ **膨らんだ分は【債権者が受け取る】。** ⚠ 移転であって、湧いてはならない。

## 3-7. ★ 移行の政治は既存のゲートに載せる

⚠ **「銀安だから移行が安くなる」は採らない。史実は逆である。**

⚠ **銀が下がるほど、銀本位国の輸出業者は移行に反対する**（★ 銀安が有利だから）。★★ **移行を望むのは債権者・輸入業者・金建て債務を負う国庫。**

```
★輸出業者・農民・債務者 → ⚠銀に留まりたい
⚠債権者・輸入業者・国庫 → ★金へ移りたい
```

★★★ **これは既に実装されている**（`PolicyPreferences` の債務者 vs 債権者）。⚠ **銀価格の変動を、その選好の入力に足すだけ。**

## 3-8. ★★ 日本の形（⚠ 「大量産出」ではない）

⚠ **1783年の日本は「衰退した銀山」を持つ。** ★ 石見のピークは17世紀で、幕府は銀の流出に苦しんでいた。

★★★ **面白いのは産出でなく、この経路である：**

```
★日本は銀本位（⚠1783年から）
  → ★★1870年代に世界の銀が暴落
  → ⚠日本にとっては【自国通貨の下落】
  → ★★★輸出が有利になる（史実：生糸と綿糸が伸びた）
  → ★1895年 日清戦争の賠償金（⚠金建て）で金を得る
  → ★★★1897年 金本位へ移行
```

⚠⚠ **「賠償金が本位の転換を可能にした」**——★ これは既存の賠償金機構がそのまま出す。★★ **日本専用のコードは1行も要らない。**

# 7. 再開（作者裁定 2026-09-06「一時的に壊れるのは問題ない。その後に復旧する仕組みが必要」）

## 7-1. 現状の実測（silverprobe seed1・2026-09-06 02:42）
- 銀/金比＝1.00±0.06 で151年平坦。銀の世界価格は 0.42→1.25（1833）→1.0 と金と**同じ軌道**（一般物価に乗っているだけ）。銀産出は 7.9k→39.6k（5倍）。
- 通貨法＝1783 銀61 → 1873 銀63/金12 → 1883 銀67/金7（史実は1873〜80で欧州の大半が金）。工業化が金閾 3.5 を超える国は4〜5。
- **造幣の準備需要が動いていない**＝造幣局は「市場価格 ≤ 平価（RefPrice 0.54）」の時だけ買うが、銀の市場価格は宝飾/時計の産業需要で常に平価の上（0.5→1.25）＝造幣局は1ビットも買わない。兌換率（準備/基礎貨幣）は0.37〜0.60のまま。

## 7-2. なぜ暴落しないか（1文）
**貨幣需要が市場で買っていない**ので、法の切替（銀→金）で消えるべき需要が最初から存在しない。demonetization の売りも「準備が0」なので出ない。

## 7-3. 設計（器・既定0）
1. **`MintBuysAtMarket`**：カバー率（準備/基礎貨幣）が目標未満のとき、造幣局は平価以下に限らず**市場価格で**本位金属を買う（数量＝shortfall×産出比例の既存式）。支払い＝新鋳貨（価値＝数量×市場価格＝BaseMoney/CumulativeGoldMinted に同額計上＝保存）。史実＝造幣局は持ち込まれた地金を平価で鋳造したが、国庫・銀行は準備を市場で買い増した（1840〜60年代の仏・米）。これで**貨幣需要が産出の主要な買い手**になる（61カ国×カバー率不足）。
2. 法の切替で（既存）需要が消える＋準備の売却（SellDemonetizedReserves・既存）＝**銀の需要曲線が下へずれる**。金は逆に上がる。
3. **復旧**（作者裁定の「その後に復旧する仕組み」）：(a) 銀圏の国は自国通貨の対金下落＝輸入物価↑・信認↓ → 既存の MonetaryPeerPull（交易網の引力）で金へ移る（雪崩）。(b) 金圏はデフレ（金不足）→ 既存の鉱脈発見（bonanza）と GoldCoverCreditRestraint の緩み、兌換停止（GoldStandardSuspendDebt）＝不換への逃げ道。(c) 新しい機構は足さない＝復旧は既存3経路の帰結。**壊れる（信認・兌換停止の連鎖）ことは許容**し、151年で復帰するかを chronicle で見る。
4. **銀の産地の是正**（財の3分類の再開・データ）：メキシコ/ポトシ/ネバダ/ペルーへ賦存を置き、仏の銀鉱を外す（world.json）。硫黄と同じ「総量保存ゲート」の型。
