# 1. ★★★ なぜこれが §11-7 より強いか

★ §11-7 は「**機構を数えろ、データは数えるな**」だった。⚠ **しかし「機構か」は判断である**——★ 私が読んで決めていた（§12-6 / §13-8 で限界として明記した通り）。

★★★ **本則は【深さ】を言う。深さは判断ではなく、データの流れを辿れば数えられる。**

```
★深さ0  コア           需要と供給が価格を決める
★深さ1  サブシステム     供給者が少ないと価格が上がる
⚠深さ2  サブのサブ       ⚠【無視する】
```

⚠ **複雑さの正体は機構の【個数】ではなく【相互作用の数】であり、★ 相互作用は深さで爆発する。**
★ コア＋20個の平らなサブシステムは、⚠ コアとの相互作用が20本。
⚠⚠ **サブのサブは、親とコアと【兄弟の親への影響】の全てに対して正しくなければならない。**★★ **ここで手に負えなくなる。**

# 3. ★★★ ダイヤモンドは、既に実装されている

# 8-2. ★★★ コアは【関係】である — 名詞はコアになれない（★ 検討 2026-08-14）

> ★★★ **「XがYを決める」の形に書けなければコアではない。**

```
★価格コア    ⚠需給が価格を決める          ← ★動詞がある

⚠「利益」    ★——                        ← ⚠⚠動詞がない＝コアになれない
```

⚠⚠ **名詞をコアに置くと、★ 必ず「それを使う何か」が別に要る**——⚠ **そして2コアに割れる。**

★ **実例**（`20260814_緊張度をコアにする.PARTIAL.md` §8-2）：⚠ 「利益」をコアに置くと「外交」が別コアになり、
★★ **動詞（「各国は自国の利益を守れる相手と組み、脅かす相手と対立する」）に直すと1本になった。**

## ★★ 系 — **国内と外交は同じ空間に乗らない**

⚠ **異なるコアの量を1つのベクトルに混ぜると、★ 意味を持たない次元（死んだ次元）ができ、⚠ そこに `if` が生える。**

★★★ **正しい繋ぎ方は【重み】である**——⚠ **他コアの状態は、このコアの成分に掛かるスカラーとして入る。**
★ **重みは正規化する**（⚠ Σ＝1）＝★★ **「どれだけ欲しいか」でなく「何を優先するか」＝自己有界（条件②）。**
