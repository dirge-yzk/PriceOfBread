## ★ 0. 結論

⚠⚠⚠ **`Colony` が POP を持たないことが、★ すべての例外の根である。**

```
⚠class Colony { ★PopSize / Savings / Militancy / Literacy / SettlerSize / SettlerLiteracy … }
                 ↑⚠⚠POP の属性を【平板化して抱えている】
★class Region { ⚠List<Pop> Pops }
                 ↑★同じ概念を【POP として持つ】
```

★★ **＝ 同じ概念が2つの型で実装されている。⚠ そのため POP を読む機構が一つも使えず、⚠⚠ 6つの独自実装が生まれた。**

⚠ **統一すれば、★ 独自実装が全部消え、⚠⚠ 搾取率も条約港も「その場の対処」でなくなる。**

## ⚠ 1. 現状の差異 — ★ 属国と植民地は **7箇所すべて違う式**

### ⚠ 属国の離反

```
★hold ＝ 宗主の【陸軍力】 × 投射（距離減衰） × VassalHoldScale(0.5)
⚠圧力 ＝ 属国の【軍】
★意志 ＝ 属国民の平均闘争度 > VassalDefectionMilitancy(0.6)
⚠猶予 ＝ 従属成立から VassalDefectionGraceYears(8年) は離反不能
```

### ★ 植民地の独立

```
⚠hold ＝ 本国の【総合ゲージ】 × 即応度 × ColonialHoldScale(1500) × 距離減衰 / 按分
★圧力 ＝ 植民地の【人口 × 不満】
⚠意志 ＝ 不満 > ColonialIndependenceMilitancy(0.85)
★猶予 ＝ 無し
```

### ⚠⚠ 差異の一覧

| ★ 項目 | ⚠ 属国 | ★ 植民地 |
|---|---|---|
| ⚠ **圧力の中身** | ★★ **軍** | ⚠⚠ **人口 × 不満** |
| ★ **抑えの中身** | ⚠ **陸軍力 × 投射** | ★ **総合ゲージ × 即応度** |
| ⚠ **スケール** | ★ **0.5** | ⚠⚠ **1500**（★ 3桁違う） |
| ★ **意志の閾値** | ⚠ **0.6** | ★ **0.85** |
| ⚠ **不満の持ち主** | ★★ **POP の平均闘争度** | ⚠⚠ **Colony 独自の `Militancy`** |
| ★ **猶予期間** | ⚠ **8年** | ⚠⚠ **無し** |
| ⚠ **同時多発の按分** | ★ **無し** | ⚠ **有り（0.5）** |

⚠ **現物自身が「同型」と認識している**（★ `ColonialHoldDistanceDecay` のコメント：「⚠⚠ **属国離反と同型**」）。
★★ **同型と分かっていながら別実装。⚠ これが「例外が多い」の実体である。**

## ★★ 5. 分離の式が **1本になる**

> ⚠ 作者裁定 (2)「★ 属国は統一したルールで支配される。⚠⚠ **植民地も属国も、同一の条件で分離する**」

```
⚠離脱圧力 ＝ 現地POPの闘争度 × 規模 × (1 − ★政治的地位の算入率)
★引き留め ＝ 宗主の力 × 投射（⚠距離減衰）/ ★同時多発の按分
⚠猶予     ＝ 従属成立からの年数
```

★★ **＝ 属国も植民地も同じ式。⚠ 違うのは【属性の値】だけ。**

### ⚠ これで史実が出る

```
★英の自治領（カナダ・豪）→ ⚠政治的地位が【高い】 → ⚠⚠離脱しない（★1867 自治領・平和裏）
⚠英領インド             → ★政治的地位が【低い】 → ★★離脱する
★仏のアルジェリア        → ⚠欧州系だけ算入      → ⚠⚠内戦になる（★1954-62）
⚠露の中央アジア          → ★陸続き＝投射が強い  → ⚠離脱しない
```

★★★ **＝ 「⚠ なぜカナダは独立戦争をせず、★ インドはしたか」が属性から出る。⚠⚠ 台本ゼロ。**

### ★ そして 2026-08-27 の内戦一元化に乗る

⚠ **現在の植民地独立は「⚠⚠ 判定が通ったら瞬間的に離れる」だけで、★ 独立戦争が無い。**
★★ **統一すれば `CheckSecession` → ⚠ `SpawnNation` → ⚠⚠ 既存の戦争システムで戦われる。**

```
⚠アルジェリア戦争型・★ベトナム戦争型・⚠アイルランド独立戦争型が出る
★宗主国の厭戦が独立を早める（⚠仏1962・★英1921）
⚠第三国の介入が効く（★8/27 の和平提案機構）
```

## ⚠⚠ 6. 搾取率の廃止 — ★ **何も置き換えなくてよい**

> ⚠ 作者裁定 (3)「★ 搾取率は廃止する。⚠ **外科的すぎるし、管理が面倒**」

### ★ 現在 `exploitation` が効いている先

```
⚠不満成長 × 搾取
★人口減   × 搾取（ColonialExploitMortality）
⚠産出
```

### ⚠⚠ 統一後 — ★ すべて既存の機構が持つ

```
⚠不満   ← ★既存の闘争度
          ⚠⚠「搾取されている」＝★生活水準が低い＝⚠【既に入っている】
★人口減 ← ⚠既存の人口動態（★生活水準・飢餓）
⚠産出   ← ★既存の生産（⚠POP が働く）
```

★★★ **＝ 搾取率という係数は【要らない】。⚠ 搾取は【結果として現れる】。**

### ★ 搾取の実体は【所有の構造】である

```
⚠所有者が本国のPOPなら → ★地代・利潤が本国へ流れる
                        → ⚠現地POPの生活水準が下がる
                        → ★★闘争度が上がる
                        → ⚠⚠独立圧力
```

⚠ **史実：★ インドの鉄道は英国資本が所有し、⚠⚠ 利潤は英国へ送金された**（★ Home Charges）。
★ **搾取率という係数ではなく、⚠ 所有の構造である。**

⚠⚠ **そして器が既にある：**

```
★RentShare / OwnerPopIndex         ⚠誰が地代を取るか（★2026-08-27『奴隷制』でも使った）
⚠PlantationRentShare               ★賦存州の残余が地主へ（⚠2026-07-30 点火済み）
★GoldDebtBurdenGate（休眠）        ⚠⚠コメントに「インドの Home Charges・清の賠償」と明記
```

★★ **＝ 2026-08-27『奴隷制』と同じ判断である**——⚠ **「⚠⚠ 経済的帰結は所有の構造で表す。★ 専用の係数を作らない」。**
