# 世界市場の廃止と二国間交易への置換（作者裁定 2026-08-11）

## 0. 何を変えるか

> 「港・海盆・陸路が揃っているので、それをそのまま使う。世界の重心という概念は廃止する。
>   世界市場も廃止し、平均価格を使用する。」

| | 現行 | 置換後 |
|---|---|---|
| 取引の相手 | **無い**（各州が1つの池に対して売買） | **州と州**（買い手が最も安く着く売り手を選ぶ） |
| 距離 | 州 → **世界の交易重心**（全国の交易量で重み付けした球面上の1点） | 州 → 相手州（陸→港→海盆→港→陸の実経路） |
| 価格 | 世界価格（需給で動く1本＝オークションの清算値） | **平均価格**（統計。市場ではない） |
| 決済 | 世界価格 × 数量（両建てで保存） | 引き渡し価格 × 数量（売り手の受取＋運賃＋関税に分解して保存） |

★これで「輸入元」が**本物の相手**になる。封鎖・運河・戦争が相手ごとに効き、
「近いから安い」が平均距離の縮小ではなく**個々の取引の選択**として出る。

## 1. 現行の実装（読み取り結果・置換の対象）

`InternationalMarket.Step`（601行）。

- 重心：`clat/clon` ＝ 全国の座標を `TradeWeight` で加重した**球面ベクトル平均**（:60-70）。
- 国の距離係数：`distF[i] = 1 + DistanceMarginScale × km / 10,000`（:106）。
  `km` は重心までの海路距離。`RegionalDistanceWeight>0` なら「近い大口相手ほど重い」重力カーネルで
  平均距離を縮める（:91-103）＝**近さは効くが相手は決まらない**。
- 州単位の3脚（:167-217）：州→最寄り港（陸×`LandSeaCostRatio`）→海→**重心**。
  ⚠ 3脚は既にあるが、終点が重心になっている。**ここを相手州の港へ差し替えるのが本体**。
- 清算（:311-374）：財ごとに全州の輸入希望と輸出可能を積み、`traded = min(総輸入, 総輸出)` で
  短い側に律速して按分。売り買いとも**同じ世界価格**で決済＝地球規模で金が保存。

## 2. 置換後の清算（設計）

財 g について：

1. **平均価格** `avg[g]` ＝ 取引に参加する州の局所価格の（取扱高で重み付けしない）平均。
   用途は①表示②数量の正規化（現行が `(lp - thresh)/w × scale` で使っている分母）だけ。
   ★清算には使わない＝「市場」ではなくなる。
2. **売り手候補**：`lp_s < avg[g]` の州（安い側）。価格の昇順に並べる。
3. **買い手**：`lp_t > avg[g]` の州。
4. 買い手ごとに、売り手を安い順に見て**引き渡し価格**を計算し、最小のものを選ぶ：
   ```
   引き渡し = lp_s × (1 + 運賃(s→t) + 買い手側の関税 + 穀物法 + 封鎖狙撃 − 高く買う)
   運賃(s→t) = TransportMargin × (1 + DistanceMarginScale × 実距離(s,t)/10,000)
              + 従量成分(重量/価値比) × 実距離(s,t)/10,000
              + リスク料(経路の敵支配度の線積分)
   実距離(s,t) = 海路(港_s, 港_t) + (陸_s + 陸_t) × LandSeaCostRatio
   ```
   `lp_t > 引き渡し` なら取引成立。**枝刈り**＝売り手を価格の昇順に見て、
   `lp_s × (1 + 最小運賃)` が既知の最良を超えたら打ち切る（実測で候補は数件に収まる想定）。
5. **数量**：現行と同じ形で `(lp_t − 引き渡し)/avg × scale × access` を上限に、
   売り手の在庫・両側の輸送容量で律速。
6. **決済（保存）**：買い手が `引き渡し × q` を払い、
   - 売り手が `lp_s × q` を受け取る
   - 運賃ぶんは現行と同じ海運プールへ（`FreightRatePer10Mm` の按分経路）
   - 関税ぶんは買い手の国庫へ（現行 `CollectTariff` と同じ）
   ＝ 出た金と入った金が一致する（leakhunt が検証）。

## 3. 計算量

- ペアの海路距離は**キャッシュ**する（港どうし＝約90×90、スエズ/パナマの開閉4通り）。
  州の座標は不変なので構築時に1度で足りる（所有国が変わっても距離は変わらない）。
- 清算：買い手（〜180）× 候補売り手（枝刈り後 数件）× 財（136）≒ 現行の3倍。
  バッチ11分 → 30分程度を見込む。

## 4. 段取り（この順で測る）

1. `BilateralTrade=0`（既定）で**厳密恒等**を確認（旧経路がそのまま動く）。
2. 点火して A/B。★帯は大きく動く前提＝**現行の較正は全て「重心つき池」に対して合わせてある**。
3. 硬性ゲート（破綻・異常・フラグ）が緑なら採用し、6次元の劣化は再較正ラウンドへ送る。

⚠ この置換は「正しい挙動＞バランス」の適用対象。ただし**破綻しない＞正しい挙動**なので、
破綻や保存則の破れが出たら差し戻す。

## 5-2. ★実装バグ（自分で作って自分で潰した）

**輸送容量が交易量を絞っていなかった。** 旧経路は事前パスで潜在輸送量を積んで `acc *= LastTradeThrottle` していたが、
置換版はこの掛け算を落としており、容量は診断表示だけになっていた＝**鉄道ゼロの1783年でも荷が無制限に動く**。
最初の測定（+24.2）はこのバグ込みで、信用できない数字だった。
二国間では相手ごとに量が決まるため事前パスで潜在量を出せないので、**前月の積載から決まった律速率を今月に掛ける**
（月次フィードバック）形で入れ直した。⚠律速率の再計算は「絞る前の潜在量」へ戻して測る（絞った後で割ると必ず1.0へ戻り自己解除する）。

## 5-5. 申し送り

- ⚠**スウェーデンの3港が全て凍る**（ストックホルム・ウメオ・ヘルシングフォシュ）＝Q4とQ1は完全に閉じる。
  史実の逃げ道ヨーテボリ（西岸・不凍）が world.json に無いためで、**データの欠落**。州として足すのが正しい。
- `MonopolyMarkupMax`（HHIによる価格上乗せ）は**役割が重複**した＝二国間では売り手が1人なら買い手の言い値まで取れる
  （独占レントが構造から出る）。撤去候補。
- トランジットの候補港は構築時固定の2港＝「毎期いちばん安い港を選び直す」形にはなっていない。拡張余地。
- 通行料は取扱高の定率5%＝港所有国が料率を決める政治的な手は無い。拡張余地。
