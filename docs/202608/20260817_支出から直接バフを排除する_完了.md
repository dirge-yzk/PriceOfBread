# 1. ★★ 判定基準

> ⚠ **金が【財・役務を買う】か、★ 数値を直接動かすか。**

```
⚠悪い形：教育費を払う → 「識字率 +5%」
★良い形：教育費を払う → ⚠教育（役務94）を買う → ★POPが消費 → ⚠識字が上がる
```

★★ **良い形だと、⚠ 間に必ず【市場】が挟まる：**
- ⚠ 供給者（教師）がいなければ買えない
- ★ 投入（紙）がなければ生産できない
- ⚠ 価格が上がれば同じ金で買える量が減る

★★★ **これは思想②（外科的倍率の禁止）の経済版である。**

## ★★ 福祉は何を買うか — **現金給付**

| ★ 案 | ⚠ 中身 | ★ 評価 |
|---|---|---|
| ★★★ **A：現金給付** | ⚠ **貧しいPOPの `Savings` へ振り込む** | ★★ **19世紀の救貧法・年金はまさに現金給付**。⚠ POPが自分でパンを買う＝**市場が挟まる** |
| ⚠ B：現物給付 | ★ 医療（役務95）・主食を国庫が買ってPOPへ | ⚠ **20世紀型**。★ 19世紀には合わない |

★★★ **A を推す。⚠ そして A なら効果が自動的に出る：**

```
★給付を受ける → ⚠POPがパンを買える → ★飢えない → ⚠満足度が上がる
                          ↑
                ★★★パンが高ければ同じ金でも足りない
```

★★ **「インフレが福祉を空洞化する」が特例なしで出る**——⚠ **19世紀の年金・救貧の現実そのもの。**
