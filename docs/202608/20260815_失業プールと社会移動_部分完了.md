# 失業プールと社会移動（2026-08-15・作者指示）

## 作者指示（プレイ中フィードバックの発展）

1. UI：財政タブの「技術効率」→「効率」に改名（済）。
2. 失業POPは無条件で工場労働者に流すのではなく、**上流・中流・下流に分かれた失業プール**に流し、
   **識字率・高等教育の有無で判断**した後、可能なら**同じ階級のもっともマシな職業**に転職するが、
   **不可能なら降格**する。全POPに適用。

## 既存の社会移動（実装済みだったもの）

| 経路 | 駆動 | 実装 |
|---|---|---|
| ① 労働者→専門職（技師/教師/官僚/医者） | 給与差×識字×高等教育ゲート×M | Meritocracy（live） |
| ② 労働者→聖職者 | 宗教社会の聖職の豊かさ | live |
| ③ 中流→資本家 | 貯蓄閾値（経済規模比） | live |
| ④ 上流→中流 | 貯蓄枯渇・債務破産（資本家→職人／貴族・聖職→最富の専門職） | live |
| ⑤ 専門職→労働者 | 貯蓄枯渇（失業教師の転落） | live |
| ⑥ 職人→労働者 | 貯蓄枯渇・破産 | live |
| 農民↔労働者 | 所得差softmax＋工業化天井（都市化） | PopDecision（live） |
| ①' 職人→労働者 | 所得差（工場に市場を奪われる） | ArtisanDeclineRate=0（休眠・2026-08-15） |

**欠けていたもの**：(a) **失業（UnemploymentRate）が社会移動を一切駆動しない**（政治の怒りにしか使われない）
(b) 転落の行き先が**無条件に固定**（専門職→労働者・資本家→職人）＝「もっともマシな職」の選択がない
(c) 降格途中の**資格判定**（識字・高等教育で踏み留まれるか）がない。

## 実装（Meritocracy.cs ①''・休眠 JobSearchRate=0）

- **階級判定 ClassOf**：上流(2)=閉鎖階級（貴族・聖職）＋資本家／中流(1)=技師・教師・官僚・医者・商人・職人／
  下流(0)=残り（農民・労働者・使用人等）。兵士=対象外（軍事力学の管轄）。
- **プール流入**：毎四半期、労働を売る全popから `JobSearchRate × UnemploymentRate × Size`。
  「プール」は四半期内の判定＝滞留の動力学は UnemploymentRate 自体が持つ（売れ残りが続く限り毎期入り続ける）。
- **経路 RouteViaPool**：
  1. 同階級で**今より稼げる**職を1人あたり所得の高い順に試す（ウォーターフォール）。
     資格ゲート＝①と同じ物差し（識字×高等教育×世俗の水路・官僚は世俗免除・職人=小営業で資格なし・下流職=資格なし）。
     行き先候補から閉鎖階級・資本家（参入は資本=③）・商人（参入は元手=①の判断踏襲）・兵士・自分を除く。
  2. 残りは**1段下の最良職へ降格**（所得比較なし＝職の無さより増し）。下流はこれ以上落ちない＝残留。
     1段ずつ＝落ち切らなければ翌四半期に再判定。
- **>0 で転落の行き先も同経路に切替**：④⑤⑥・①' の無条件「→労働者」「→職人」を廃止し、
  貧した教師は給与の立つ技師・官僚に踏み留まれる（資格があれば）。0＝厳密恒等（全変更が `JobSearchRate > 0` ゲート内）。

### 点火直後の回帰＝聖職者爆発（182→8362・教訓つき）

- フルスイート303中1赤＝「聖職者は世俗化で没落するが消えない」。プローブ連鎖（月次差分→フェーズ別→属性）で根因2層を特定：
  1. **既存の潜在バグ（凍結分母）**：FertileWomenBirths の出生配分重み `Size×fertile/InitialFertileShare` は、
     初期構成が偏ったpop（聖職者F=0.10）でも t=0 で重み=Size を保証し、新生児（F≈0.5）の蓄積で構成が正常化すると
     分母が凍結されたまま分子が育ち**恒久的な出生倍率（実測2.1倍）**になる。「比のガードは絶対値で書かない」と同族。
  2. **プールの残余滞留が④の排水を細らせた**：softmax着地の「吸収されない残余はsrcに残す」は失業（自発）には正しいが、
     **強制転落（④⑤⑥・①'）に適用すると破産者が元の階級に滞留**＝聖職者の排水が出生ループに負けて爆発。職人の絶滅（size=0）も併発＝rank6の警告どおり。
- **修正**：RouteViaPool に forced フラグ＝強制転落は資格・空き・天井で吸収しきれない残余を**1段下の最良職へ全量**
 （旧経路と同じ「必ず落ち切る」）。滞留は失業①''の専有。MobilityTests 8/8緑・聖職者テスト回復。
- **裁定候補（新規）**：凍結分母そのものの是正（出生重みを現在構成ベースへブレンドする休眠1本）。聖職者以外に偏構成popが増えるほど（性別ゲートrank12採用時など）効く＝rank7（転落物差し）と同席で。
