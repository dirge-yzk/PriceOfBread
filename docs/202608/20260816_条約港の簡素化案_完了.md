# 条約港の簡素化案（2026-08-16・作者指摘「戦争で解除という例外を作りたくない。もっとシンプルな構成に」）

## 問題の整理

- 現状＝TreatyPortsGranted（int・敗戦の自動要求で++・1港あたり実効関税−25%）。**減る手段が存在しない片道ラチェット**。
- 撤回済みの案（動詞3点セット＝交渉/一方的破棄/モラトリアム）＝例外のつぎ足し。要求が自動＝狙った戦争が難しい世界と噛み合わない。作者指摘どおり不採用・実装エージェントは停止済み（部分編集なし）。

## 案A（推奨）＝維持条件つきの状態——「不平等条約は力の差が続く間だけ有効」

条約港の本質は「砲艦が背後にある譲歩」。ならば**状態そのものに持続条件を持たせる**だけでよい：

```
毎年1回の検査（全国一律・動詞なし）：
  自国の国力（軍事+工業スコア）÷ 最強列強の国力 ≧ 閾値
  → 条約港を1港失効（ペース＝クールダウン数年で1港ずつ）
```

- **動詞なし・ボタンなし・戦争例外なし・交渉なし**。プレイヤーの仕事は「強くなること」だけ＝日本の条約改正（1899/1911＝近代化を背景に消えた）がそのまま創発。
- AI対称は自動（同じ検査が全国に走る）。
- 追加は係数2本（閾値・ペース＝ともに休眠→A/B）と減算1箇所のみ。状態の追加ゼロ。
- 自己有界＝力が並べば効果は消える（極限でコアへ還る＝§4条件②）。固有名詞なし。
- 失効時に受益側との緊張を少し上げるかは任意（無しでも成立＝最小はゼロ）。

## 案B＝時限失効（純タイマー）

- N年で自動的に1港失効（安政条約の改定期日1872のような「条約には期限がある」）。
- 最も単純だが力と無関係＝崩壊寸前の国でも条約が消える（史実と逆）。案Aの下位互換。

## 案C＝カウンタ廃止・関係量への一本化（より大胆な再構成）

- TreatyPortsGranted という**専用カウンタ自体を廃止**し、「実効関税＝素の関税 ×（対列強の相対国力の関数）」に置換
  ＝弱い国は条約の有無に関わらず関税自主権が実質的に細る（砲艦外交の連続量化）。
- 状態が消える＝最シンプル。ただし「開港の瞬間」という歴史イベント性が失われる（南京条約の画期が連続量に溶ける）＋敗戦の要求リストから条約港が消える＝外交の動詞体系に影響。

## 裁定（2026-08-16作者）＝**案Aで確定**

実装形（確定）：
- `TreatyPortLapseRatio = 0.0`（休眠ゲート兼閾値。>0で機構が生きる。設計目安0.5＝最強列強の半分の国力で条約が風化し始める）
- `TreatyPortLapseYears = 4`（ペース＝この年数ごとの検査で1港失効。**無状態**＝year % N == 0 の全国一斉検査＝クールダウン用の新フィールドを作らない）
- 国力の物差し＝NationalScore の軍事+生産（既存スコア成分の再利用・新量なし）÷ 最強列強の同値
- 失効時＝通知のみ（緊張は上げない＝最小構成）。AI対称は自動（同じ検査が全国に走る）。
- 点火はA/B 1本（清・日本の忠実度が主対象）。

## 私の推奨

**案A**。理由＝(1)例外ゼロ・状態ゼロで袋小路が解ける (2)脱出路が「強くなる」という本編の主目的と一致する（プレイヤーに新しい操作を覚えさせない） (3)史実の条約改正の物理（力の均衡が条約を風化させる）そのもの。
