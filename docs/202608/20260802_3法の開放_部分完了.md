# 1. 判定の根拠（なぜ開放するのか）

## 1-1. 史実が逆になっている

| 法 | 史実 |
|---|---|
| **農奴解放** | ★1861年アレクサンドル2世の**勅令**。議会は存在しない。貴族の反対を押し切った専制君主の決断 |
| **土地改革** | 明治の地租改正1873（藩閥政府）／ストルイピン1906（**議会を迂回した緊急勅令87条**） |
| **穀物法撤廃** | ★1846年ピール首相が押し切り、**自党を分裂させて政治的に死んだ** |

★★★ 3つとも「**指導者が決めて政治的代価を払った**」型である。

## 1-2. ★★ その代価は、既に実装されている

```csharp
Government.cs:213-219  MandateGate     ＝ NetSupport > −θ の一本判定（毎期1段）
Government.cs:217,319  MandateSpent   += |net| × MandateSpendRate(0.5)      ← 押し切りの消費
Government.cs:225-237  PushGrievance   ＝ ★**反対したブロックのpopの闘争度だけ**を
                                          PushedLawGrievance(0.05) × min(1,|net|) × 反対の強さ だけ上げる
```

★★★ **ピールが自党を割った代価が、闘争度 → 急進派 → 正統性侵食 → 次の余白減 という創発ループとして既に動いている。** 開放に新しい機構は1つも要らない。

## 1-3. 機構は他の22軸と完全に同じ

★ 3軸は `Government.cs:47/50/51` で**同じ `StepEnum`・同じゲート**を通る。追加条件は `LandReform` の `LandTaxUnlocked`（検地台帳）だけで、それも**既に `LawPrereq` に登録済み**（`Government.cs:255-257`）。

## 1-4. 賛否は保有から出ており、プレイヤーとAIで同一

```
穀物法      = 1.5 × 地代シェア[b] −（旧支配層以外は 1.0）        PolicyPreferences.cs:139-140
農奴解放    = 旧支配層 −2.0×(0.5 + 旧支配層の富シェア) ／ 他 +1.0   同 :159-160
土地改革    = 同式。大衆 +2.0 ／ 近代 +1.0                          同 :165-166
```
★ **プレイヤーが押すときも AI が押すときも `NetSupport` は同一関数**＝賛否は完全に対等。

| **6** | ★**AIが3軸をどれだけ積極的に使うか。** ⚠ 保守的にすると開放の意味が薄れ、積極的にすると46カ国が同時に動く。**段2の較正点** |

# 8. この設計の限界

| # | |
|---|---|
| 1 | ⚠ **測定していない。** §4 の帯リスクは経路を特定しただけで、大きさは実走でしか分からない |
