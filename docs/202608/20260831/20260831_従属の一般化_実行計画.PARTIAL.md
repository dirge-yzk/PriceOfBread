- `ColoniesAreRegions=1.0` が**既に既定**＝開始時の植民地は全て RegionTier.Colonial の州。
  Colony オブジェクトが生まれ続けるのは3経路だけ＝①Subjugate接収（Diplomacy:1883）②講和奪取（:2476）③内戦再統合（MultiNationSim:886）。
- 変換の雛形＝`Simulation.PromoteColonyToRegion`（:1144-1232・保存記帳込み）。呼び出しは2箇所のみ。
- **難所トップ5**：
  1. `Colony.Population`（人口ウェイト）＝第二の物差し（脅威35%成分・海軍シェア・維持費・産出の4系統が同じ比を読む）

  3. 抽象標的40+（Nation==null の Power）が ColonyList を**代理領土**として使う（CanInvade/NearestColonyKm/TargetPoint等）
  4. 保存検査の3出口（TotalColonies+IndependentColonies+PromotedColonies==Initial）＝独立植民地は Power でも Region でもない**第4の在り方**（自由供給者）
  5. UI の参照同一性（_interestColony=ReferenceEquals・_colHoverCache=Dictionary<Colony,…>・Invade(Power,Colony?) が公開API）

## 1b. V1 第1腕の実測と修正（2026-08-31）

- 帯＝◎8→10・植民地+2.5・逸脱11→9（改善方向）だが**ハーネス「植民地の保存」8/10赤**。
- 根因＝**二重計上**：`Power.Colonies = ColonyList.Count + ColonialRegions` なので Colonial tier への変換は
  リスト−1・州+1＝**総数不変**。そこへ `PromotedColonies++` を足すと保存検査
  （Total+独立+昇格==初期）の左辺だけ膨らむ。構築時の一括昇格（PromoteAllColonies）が
  Colonial tier で**数えない**のと同じ規約に合わせてカウンタ増を撤去。
- ⚠規約として明文化：**PromotedColonies は「Colonies の集計から抜ける昇格（Integrated化）」だけを数える**。
- 第2腕の実測（同一base＝roundV_base300・gate0はビット同一なので再走せず）：
  - **V1b＝保存検査の赤解消**（8/10→1/10・残1はseed3の下流財3件＝境界）。帯＝◎+2・植民地+2.5・逸脱−2／政体−1.8・人口−2.8＝ほぼ中立。
