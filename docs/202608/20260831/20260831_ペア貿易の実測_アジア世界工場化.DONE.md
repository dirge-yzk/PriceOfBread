```

```

## 穴②の対（実装済み・休眠）＝輸出利害の反関税

`TariffExportOppositionWeight`：関税選好の近代エリート項へ **−これ×(輸出/GDP)** を加算＝
マンチェスター学派（輸出で食う資本は自由貿易を推す＝穀物法撤廃1846の物質的基盤）。
既存の保護利害（TariffInterestPref＝後発の資本家は保護を求める・独1879型）と**同じブロック内で正面から割れる**＝
英1846 vs 独1879 が保有から出る形。⚠穴①とセットでのみ意味を持つ（輸出が関税に痛む物理が先）。
複合腕（①=1・②=3）を測定中（roundI2）。
