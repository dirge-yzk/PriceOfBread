> ⚠ **清（及び後進国）の遅れは軍だけではない。**
> ★★ **政治・経済・軍・外交のすべてに、法または施設の壁があるべきである。**

## 11-1. ★★★ 教育 — 2軸に分ける

### ⚠ 現在は1軸

```csharp
enum EducationLaw { None, Religious, Public, Compulsory }
```

★ これは「**どこまで広げたか**」だけで、⚠ **「何を教えるか」が無い。**

### ★★ 提案：広さ × 中身

```
EducationLaw      ⚠なし / 初等 / 公教育 / 義務教育     ★裾野の広さ
EducationContent  ⚠宗教 / 官学 / 世俗                  ★誰が教壇に立つか
```

★★★ **「宗教」と「官学」と「世俗」は横並びである**（⚠ どれかが上位ではない）。

| 中身 | ★ 出口 | ⚠ `Elite`（技術者） | ★ `AdminEfficiency`（行政） | ⚠ 実体 |
|---|---|---|---|---|
| ⚠**宗教** | 聖職者 | ★ 低 | ⚠ 低 | ★ 教会学校・神学校 |
| ★**官学** | ⚠ **官僚** | ★ 低 | ★★★ **高** | ⚠ **科挙・マドラサ**（★ ウラマーは法官兼行政官） |
| ⚠**世俗** | ★ **技術者・商人** | ★★★ **高** | ⚠ 低 | ⚠ **寺子屋**（★ 往来物＝職業別の実用教材）・**プロイセンの実科学校1747**・**英の Dissenting Academies**（⚠ ワットもプリーストリーもここ出身） |

★★★ **三すくみになり、⚠ どれも上位互換ではない。**

| ⚠ 帰結 | ★ 史実 |
|---|---|
| ★ **官学の国** | ⚠⚠ **行政は世界最高だが技術者が育たない**（★ 清の軍機処・奏摺制度） |
| ⚠ **世俗の国** | ★★ **技術は入るが国家が弱い**（⚠ **幕末日本＝幕府は財政破綻していた**） |
| ★ **宗教の国** | ⚠ どちらも低いが、★ **教会が福祉・教育を無償で担う**（⚠ 国庫が浮く） |

### ⚠⚠ 現在の world.json に誤りがある

```
日本   education = "Religious"      ⚠⚠【誤り】
```

★ **幕末日本は「初等 × 世俗」**である（⚠ 寺子屋は仏典を教えていない）。
★★ そして `peasLit = 0.30` は**既に高く置かれている**（⚠ 世界最高水準の一つ）＝**識字データとは整合している。**

## 11-2. ★★★ 高等教育は「財」、大学は「施設」

> ⚠ **法ではなく、財と施設にする。★ そのほうが自然である。**

### ⚠ 現在は「初等教育財の余り」で代用している

```csharp
Meritocracy.cs
// ★「⚠【高等教育ゲート】：中流が買えた教育（＝下層が買った後の【余剰】教育）が専門職への転職資格。
//    ⚠【教育の供給が下層の基礎教育で尽きる社会では専門職が育たない】」

double secular = w.EducationLaw switch {
    Public or Compulsory => 1.0,
    Religious => c.ReligiousProfessionShare,   // ⚠0.05
    _ => 0.0,
};
// ★「⚠【官僚は例外】＝宗教社会も官僚制は築ける（科挙・寺社官僚）。★代わりに官僚はエリートに数えない」
```

⚠⚠ **「高等教育ゲート」という概念は既にあるが、★ 実体が初等教育財の余りである。**
★★★ **そして「官僚は例外」という逃げが、⚠ 科挙を扱いきれていない証拠。**

### ★★ 設計

```
★施設「大学」（⚠州に建てる・建設が要る）
   古典大学  → ⚠高等教育(古典) を生産
   工科大学  → ★高等教育(技術) を生産

★財の流れ
   高等教育(古典) → ⚠Meritocracy → 官僚pop   → ★AdminEfficiency
   高等教育(技術) → ★Meritocracy → 専門職pop → ⚠⚠Elite → ★技術成長
```

⚠ **財を2つに分けるので、★ 「官僚は例外」という逃げが要らなくなる**——★★ **古典大学が官僚を作るのは、例外でなく機構である。**

### ★★★ 無償化されない — 2段階の購買

> ⚠ **大学は無償化されない。**
> ★★ **教育を買ったPOPが【さらに】買うことでのみ、技師あるいは上位POPになる。**

```
①初等教育を買う  → ★識字     （⚠義務教育法で【無償化されうる】）
②高等教育を買う  → ⚠技師・上位POP（★★★常に自費）
```

⚠ **史実**：★ 19世紀の大学は授業料が高く、⚠ **義務教育の無償化（仏1881）の後も高等教育は有償のまま**だった。
★ エコール・ポリテクニークは国費だが、⚠ **極めて少数の選抜**。

### ★★★ 三すくみ — 3つ揃って初めて技師が育つ

```
①★識字   ⚠初等教育の裾野
②★所得   ⚠高等教育を買える余剰      ← ★無償化されない
③★大学   ⚠高等教育財の供給
```

| ⚠ 欠けるもの | ★ 帰結 | ⚠ 史実 |
|---|---|---|
| ⚠ **所得が無い** | ★ **識字は高いが技師が育たない** | ★★ **ロシアの農民**（識字0.05）・⚠ **スウェーデン**（識字0.50だが貧しい） |
| ★ **裾野が無い** | ⚠ **少数の天才は出るが層が薄い** | ★★★ **ロシア**（⚠ **ペテルブルク科学アカデミー1724・モスクワ大学1755を持ちながら農民は文盲**） |
| ⚠ **大学が無い** | ★ **読み書きはできるが技師が居ない** | ⚠ **幕末日本**（★ だから**1873年に工部大学校を作った**）・⚠ **清**（★ **1866年福州船政学堂・1898年京師大学堂まで技術系高等教育がゼロ**） |

### ★ 既存の機構がそのまま使える

```csharp
Simulation.cs:838
producers.Add(new Producer { GoodId = Catalog.EducationId, Productivity = 5.0, ...,
                             LaborPopIndex = teacherIdx, OwnerPopIndex = teacherIdx });
// ★大学も同じ形——⚠ただし【全州に自動で置かない】＝建設が要る
```

★★ **`TryBuildFacility`（★ ボトルネック駆動＝実質相対価格の超過）が既にある**——
⚠ **技術者が不足すれば高等教育財の価格が上がり、★ 大学が建つ。**
★★★ **AIも自動で建てる。⚠ 新しいAI判断が要らない。**

### ⚠ これで消えるもの

| ⚠ 消える | ★ 理由 |
|---|---|
| ⚠ `Meritocracy` の `secular` switch | ★★ **どの大学が建っているかで決まる** |
| ⚠ `ReligiousProfessionShare = 0.05` | ★ 同上 |
| ⚠⚠ **「官僚は例外」という逃げ** | ★★★ **古典大学が官僚を作る**＝例外でなく機構 |
| ⚠ `EliteMultiplier(EducationLaw)` | ★ **`EmergentElite` が高等教育財を見る** |

### ★ 1783年の初期配置

| | ⚠ 状況 |
|---|---|
| ★**古典大学** | ⚠ **欧州に多数**（★ オックスフォード・パリ・ボローニャ・ライプツィヒ…）／⚠ 清の書院・オスマンのマドラサも**古典大学**として置ける |
| ⚠⚠**工科大学** | ★★★ **世界にほぼゼロ**（⚠ **1794年エコール・ポリテクニークが最初期**） |

★★ **つまり「誰が最初に工科大学を建てるか」の競争になる**——⚠ **開幕に差が無い。**

## 11-3. ★★ 経済 — 会社法（★ 特許を畳む）

### ⚠⚠ 現在は「閾値で自動解禁」されている

```csharp
Coefficients.cs
// ★「制度・改革（研究C＝カードに代わる離散選択。⚠【社会の閾値で解禁】し施行＝恒久ブースト）」
PatentInnovationBonus  = 1.5;   // ★特許制度：技術成長 ×これ
JointStockInvestBonus  = 1.6;   // ★株式会社：工業化投資 ×これ
PatentEliteThreshold   = 0.4;   // ⚠特許の解禁【エリート水準】
JointStockIndThreshold = 0.3;   // ⚠株式会社の解禁【工業化度】
```

★★★ **法ではなく、「発展したら自動でついてくるボーナス」である。**

⚠⚠ **そして循環している：**

```
⚠工業化度 0.3 に達しないと株式会社が解禁されない
   ↑                                    ↓
   ⚠株式会社が無いと資本を集められない ←┘
```

★★ **清が近代化できないのは「疲労0.8」だからではなく、⚠ この循環に閉じ込められているから**——★ **しかも誰も決めていない。**

### ★ 提案：1軸3段の法へ畳む

```csharp
enum CommercialLaw { Chartered, Patent, JointStock }
   0 ⚠勅許独占     ★東インド会社型（発明も会社も王の恩恵）
   1 ★特許法       ⚠発明者の権利（★英1624）
   2 ★★一般会社法   ⚠有限責任（★1855-62に欧州で一般化・⚠清・オスマンには最後まで無かった）
```

★★★ **「近代エリートがいないと通らない」は、⚠ 既存の `MandateGate` がそのままやる**——
★ `PolicyPreferences` が近代エリートのブロック力から賛否を出すので、⚠ **資本家が居ない国では `NetSupport` が負のまま。**
★★ **新しいゲートを1つも書かない。**

⚠ **鉄道（`RailwayIndThreshold`）は技術なので自動でよい**（★ 判断が要る・§11-6a）。

## 11-6b. ★★★ 書籍に研究者を要求する（★ 作者提案 2026-08-14）

> ★ **「書物の生産に研究者を要求するようにするのはどうか。**
> ⚠ **また医者は研究者に統合してもよいかもしれない。」**

### ★★★ 実測 — **「知識人」というPOPは存在しない**

```csharp
Simulation.cs:660  engineer   = professional × (1 − IntelligentsiaFrac)   ★技師   → 高度労働力(100)
Simulation.cs:663  teacher    = intel × 0.40                              ★教師   → 教育(94)
Simulation.cs:664  bureaucrat = intel × 0.35                              ★官僚   → 行政(96)
Simulation.cs:665  doctor     = intel × 0.25                              ★医者   → 医療(95)
```

⚠⚠ **知識人は既に【教師0.40 / 官僚0.35 / 医者0.25】に3分割されており、★ 「研究者」だけが欠けている。**
★ **そして医者は `IsModernElite=true` / `Literacy=IntelLit` で、⚠ 教師・官僚と完全に同型**——
★★★ **作者の「医者は研究者に統合してもよい」は、コードの構造上とても筋が良い。**

### ★★★ 「本は買えるが、知識は買えない」

```
★研究者がいない国 → 書籍が作れない → ⚠輸入するしかない
                                        ↓
⚠高等教育(Service)は NonTradeable → ★輸入できない
                                        ↓
★★★「本は買えるが、知識は買えない」
```

⚠ **史実そのもの**——★ **清は洋書を大量に訳したが、大学は自前で建てるしかなかった。**

### ★ 研究者をどこから出すか — 3案

| ★ 案 | ⚠ 中身 | ★ 評価 |
|---|---|---|
| ★★ **A（推奨）** | ⚠ **知識人を4分割**：教師0.30 / 官僚0.25 / 医者0.20 / **研究者0.25** | ★★★ **奪い合いが最も明確**。⚠ POPが1つ増える |
| ★ **B**（★ 作者案） | ★ **医者が医療＋研究を両方産出** | ★ **POPゼロ増**。⚠ **人口ペナルティ（下記）** |
| ⚠ **C** | ★ 書籍の入力に既存の**高度労働力(100)** | ⚠ 最小だが★ **意味がずれる**（⚠ 技師≠著述家） |

### ★★★ A を推す理由 — **奪い合いが出る**

⚠ **知識人の総量は変わらず、内訳が変わるだけ**＝★ **保存則を満たす**（思想⑥）。

> ★★★ **大学を建てる ＝ 教育か行政か医療を犠牲にする。**

⚠ **後発国が実際に直面した選択である**——★ **限られた知識層を、学校・役所・病院・大学のどこに置くか。**
★★ **「近代化の壁」が【人】のレベルでも出る**——⚠ **法でも財でもなく、人が足りない。**

### ⚠ B（医者統合）の問題 — **人口ペナルティ**

⚠⚠ **医療需要は人口比例で全国に薄く出るが、★ 研究は都市の大学に濃く要る。**

```
⚠人口が多い国 → 医療需要が大きい → 研究者が医療に吸われる → ★大学が動かない
```

★★★ **「人口が多いこと」自体がペナルティになる。**⚠ **清とインドが不利になりすぎる。**

★ **ただし作者の直感の核は正しい**——⚠ **19世紀の研究者は実際に医学部にいた**（★ パスツール・コッホ・北里）。
★★ **A でも研究者は `intel` から出すので、「医学部から研究者が出る」関係は保たれる。**

### ★★ B の最も良い効果は、A でも自動的に出る

⚠ **A でも医者と研究者は同じ `intel` プールを分けるので：**

```
★疫病が流行る → 医療需要が跳ねる → ⚠医者の賃金が上がる
                                    ↓
                        ★知識人が医者へ流れる → ⚠研究が止まる
```

★★★ **奪い合いは残り、⚠ 人口ペナルティだけを避けられる。**

### ★★★ 作者裁定（2026-08-14 夜）

> ★ **「上流階級（貴族・聖職者）と別カテゴリで、インテリ（医者/技師/研究者）を置くのがよい。」**

★★ **研究者は独立POPとして新設**（⚠ B＝医者統合は不採用）。
★ **「インテリ」＝医者・技師・研究者の職能グループで、⚠ 既存のブロック構造（`Closed`＝上流階級 vs `IsModernElite`）と一致する**——
★★★ **機構の変更はゼロ。POPを1つ足すだけ。**⚠ **配分比は較正ノブ**（★ 上の 0.30/0.25/0.20/0.25 は例示であって裁定ではない）。

### ★ 思想⑧での判定

```
⚠増える機構  0   （★知識人の内訳は既存の【データ】。⚠ 書籍のレシピに1入力足すだけ）
★減る機構    0
```

⚠ **POPが1つ増えるが、★ 機構は増えない**——⚠ **`intel × 係数` の行が1本増えるだけ。**
