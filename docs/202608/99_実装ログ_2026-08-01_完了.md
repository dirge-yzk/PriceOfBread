## 3. 国民意識のPOP化（実装済み・測定待ち）

作者指示「国民意識を国家ラベルでなく**POPにつけたい**。**植民地あるいは本国と離れた州、非コアのPOPは上がりづらい**仕組みが欲しい」。

`CrownParliament.AccumulatePopConsciousness` を追加。国のスカラーはそのまま残し、POP側にも同じ形で積み、国の値を **size加重平均** で置き換える。旧式との違いは3つだけ：

1. 民族の抵抗を国平均(`EthnicUnity`)でなく **そのPOPの中核民族シェア** で見る
2. **首都からの距離**で配信が減衰する（`1/(1+km/800)`）
3. 天井がPOPごとに残る

**⚠国名も「植民地かどうかのフラグ」も見ない。** 距離と民族構成という現物だけで植民地の性質が出る（遠くて中核民族が少ない州＝定義上の植民地）。だから州の身分ラベル `RegionTier` が空のままでも正しく効く。

### 較正の根拠
`NationConsciousnessReachDecay = 800 km`（到達が半分になる距離）
- ブルターニュ約400km＝×0.67（遅れて追いつく）
- アルジェ1350km＝×0.37
- デリー6700km＝×0.11（ほぼ届かない）

ウェーバー『農民をフランス人に』の周縁像に合う。**⚠既知の粗さ＝大圏距離であって鉄道距離ではない**（山脈も海峡も無視）。

`NationConsciousnessCoreWeight = 0.8`（中核民族シェア0のPOPは伸びが×0.2）。**0にしない理由**＝少数民族も「その国の」意識を多少は持つ（チェコ人は墺の兵士として戦った）。

**⚠予想される帯の動き**＝首都と同じ場所で単一民族の国（日本・デンマーク）は**動かない**が、広大な多民族帝国（露・墺・英印）の国民意識は下がる。これは意図した是正である。

### 既知の限界（記録）
移民は「到着国の平均的な国民意識」を持って現れる。本来は出身国の意識を引きずるべきで、**国民意識が移民で薄まらない**ことを意味する。別ラウンドの対象。

## 4. 通貨制度の政治化（実装済み・測定待ち）

金本位は「政府が決めるスイッチ」ではなく**議会が通す法**である。

- `World.GoldStandardLaw` を新設。`Policy.GoldStandardTarget`＝プレイヤー/AIの願望、`GoldStandardLaw`＝政治を通った現実。**Fiscal は後者だけを読む**。
- 選好は**実際に起きている物価の動き**（`ExpectedInflation`）と**その勢力の資産保有**だけから出す。金本位そのものが良い/悪いという値は1つも書かない。

```
持てる側（e.Wealth[b] 大）：インフレ →「金の規律を」
持たざる側（1−Wealth）  ：デフレ   →「兌換の停止を」
```

**⚠物価が安定していれば両側とも0**＝通貨は争点にならない（平時の国で無意味な要求が出ない）。

史実＝1873-96年の大デフレは債務者と債権者の政治戦争だった。抵当を抱えた農民には、物価が下がるとは「同じ借金を返すのに去年より多くの小麦を売る」ことを意味した（ブライアン「黄金の十字架」1896）。

## 5. 徴兵法の3値化（実装済み・測定待ち）

作者裁定「2値は少し物足りない。徴兵制の中に2段階。小規模/大規模」。

```
Volunteer = 0  志願兵制（英の職業軍・米の平時）
Selective = 1  選抜徴兵（籤で一部を引く。仏1798ジュルダン法・米1863徴兵法の代人制）  ← 旧 Conscription と同じ添字
Universal = 2  国民皆兵（適齢男子は全員が現役、以後は予備役。普1814の兵役義務）
```

**⚠添字を動かさない**＝旧セーブと旧挙動を壊さない。`ConscriptionLaw.Conscription` → `Selective` は名前だけの変更で、値も比較も同一。

新しい内容は `UniversalConscriptionFactor = 2.5`＝**引ける人数が法で変わる**。較正＝1870年の普（2400万人から120万人＝5.0%）と仏の選抜徴兵（3600万人から50万人＝1.4%）の比＝約3.5。動員の上限は別途 manpower が抑えるので 2.5 から入る。

⚠これは「強い軍が持てる」だけの話ではない——**引いた人数ぶん労働力が畑と工場から消える**＝供給側の穴が開く。作者が求めた「理想の軍隊を目指す構造がモノ・ヒト・カネの過不足を生む」の一部。

UI＝法律タブの徴兵法を3ボタンへ（志願兵／選抜徴兵／国民皆兵）。

## 6. 再点火発注に代金を付ける（実装済み・測定待ち）

作者指摘：「実装の形としては正ですが、**実装方法としてはスマートではありません**。同等の、またはよりリアリティのある挙動を確保できるのであれば、より良い実装に差し替えてほしい」

### 何が「スマートでなかった」のか（実装を読んで確定した事実）

止まった工場が出す再点火トリクルは、`ReignitionTrickleConserves=0`（恒久的な既定）では **`coreDemand` に入っている**＝実際に在庫を食っている。ところが決済は `s.Output` ベースなので、**誰も代金を払わず、売った側も1銭も受け取らない**。

つまり**幽霊だったのは物量ではなく代金の方**だった。旧コメントの「物量を持たない幽霊需要」という記述は誤りで、これも訂正した。

### 差し替えた形

**止まった工場の持ち主が、自分の貯蓄から払う。売った側がその金を受け取る。**

これが現実の姿である——止まっている工場も、いつでも再開できるように少量を買い続け、それは持ち主の持ち出しである（ボイラーを温め、原料庫を空にしない費用）。

- **発注量・配給・物量の消費は1つも変えない** ＝ 作者が意図した「上位工場を先に建ててから下流を整備する」プレイの余地はそのまま残る。
- 変えるのは**金の流れだけ**。
- 新しい制約が1つ増える＝**持ち主が無一文なら再開の準備もできない**。

**⚠残った不完全さ**＝払い切れなかった分は現物だけが動いた状態が残る（旧＝全額がその状態だった）。診断 `Region.ReignitionUnpaid` に積んで**見えるように**した。0に近いほど「物と金が揃って動いている」。

## 8. 内戦による国家分裂（実装済み・測定待ち）

内戦の決着が「反乱が勝つ／中央が勝つ」の二値しかないのは史実の姿ではない。**どちらも押し切れないと国が割れる**（アメリカ南北戦争1861・グラン・コロンビアの解体1831・墨の連邦派対中央派）。

```
①拮抗の判定  どちらの戦力も相手の CivilWarLandslideRatio 倍に届かない
              ★新しい帯を作らない——発火側にしか使われていなかった同じ定数を決着側にも使う（物差しが1本）
②州の陣営     その州のPOPの思想分布が、反乱の目標政体を現政体より支持するか（Ideologies.Regional）
③首都は残る   Id0 は必ず中央に残る＝親が消滅しない・首都不変条件を壊さない
```

**⚠国名も文化名も出てこない。** アメリカ南部が離れるのは南部のpopの思想分布がそうさせるからで、「南部だから」ではない。だから同じ条件が揃えば清でも墺でも起きる。

`SpawnNation` を**多州対応**に拡張した（要素1なら旧経路と完全に同じ）。分離独立と同じ建国路を通るので、保存則も命名も継承も1本で済む。離脱側は自分たちの目標政体を持って出る。

## 10. 海軍の構造バグ（実測で発見・修正）

段Aの計器が出した1914年断面：

```
海軍力の順位（現行＝兵数駆動）: 1位 西安王国 10.4 ／ 2位 成都共和国 8.5 ／ 3位 清 7.8 ／ 4位 西山朝 7.2
艦隊ストックの順位            : 1位 清 1463007 ／ 2位 広州王国 ／ 3位 西山朝 ／ 4位 マラータ同盟
```

**内陸の西安王国が世界最強の海軍を持っていた。** 作者指摘「海軍の強さが海兵の数から決まるのはナンセンス」の実測上の証拠である。

### 修正① 軍艦は港でしか造れない（点火）
`NavalProcurementNeedsPort = 1`。**倍率で直す話ではない**——軍艦は港でしか造れず係留もできない、という地理が抜けていただけ。★総額は保存する＝海に回すはずだった予算は陸へ回る（内陸国は大砲を多く買う）。

### 修正② 海軍力＝船と乗員の弱い方（器・未点火）
```
NavalPower = min(艦隊ゲージ, 兵数×海軍シェア)
```
船が上限、乗員が充足率。船を持たない国の海軍は0になる。

**⚠点火していない理由**＝`FleetStockPerNavalGauge`（1ゲージぶんの艦隊ストック額）が**未較正**だから。上の分布は港ゲート導入前のものなので、ゲート後の分布を測ってから較正する。**推測で数字を置かない。**

### 是正＝応諾の天秤（`InterventionSubmitBar`）

ベルリン会議1878でロシアが呑んだのは、イギリスがロシアを圧倒できたからではない。天秤に乗ったのは3つである。

```
lean    調停者が敵側に回ったときの重み（0..1・対等なら0.5）
weary   自分の厭戦（WarPeaceExhaustion で正規化・0..1）

応諾 ⟺ lean + weary > winning + InterventionSubmitBar(0.5)
```

# ハーネスゲートを「0件」から「率」へ（96シード化の前提）

⚠**10シードで0件は96シードで全緑を1ミリも保証しない。**

| 1試合あたりの失敗率 p | 96シードで全緑になる確率 |
|---|---|
| 0.02 | 14 % |
| 0.05 | 0.7 % |

さらに rule of three により「10シードで 0/10」から95%信頼で言えるのは **p ≤ 0.30** までである。
⚠しかも落ちる検査「満足度・最小国」は **54カ国の最小値**（`Validation.WorstSat` ＝ `Nations.Min`）＝
順序統計量の裾なので、**シードを増やすほど構造的に裾を引きやすくなる**。

★このまま96シードへ上げると「何も変えていないのに見出しのゲートが赤になり」、その後の判断が全部その赤に引きずられる。

**「不合格0件」→「不合格率 ≤ 5%」へ。** 10シードでは 0/10 だけが合格（1件で 0.1 > 0.05 ＝赤）＝**現行と同じ厳しさ**。
96シードでは4試合まで許容。⚠これは緩和ではなく**標本数への正規化**である。
