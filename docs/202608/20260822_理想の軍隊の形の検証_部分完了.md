## 1. 陸と海の非対称（静的・`ArmyShape.cs`）

- **陸** ＝ `NeedLand`（注意配分＝相手の陸軍のうち自分に向く分）**＋ `NeedInternal = InternalGarrisonPerPop × 人口 × 不穏度`**
  ＝ 外生アンカー（他国の力を参照しない項）が**ある**。設計書の言う「不動点が0にならないための土台」。
- **海** ＝ `NeedSea`（注意配分）**＋ `SeaEscortPerTradeValue × seaValue`**
  ＝ 外生アンカーの係数が **0.0＝休眠**（`Coefficients.cs:1711`）。

`ArmyShape.cs:47-48` の設計者コメント（原文の要旨）：
> `BasinPresence` は L1 正規化済み＝**この内積を「海軍需要の水準」の根拠にしてはならない**（分散する国ほど内積が小さく符号が逆転する）。
> ここでは「j の艦隊のうち i に向く分」を決める**相対重み**としてのみ使い、**水準は下の通商保護項（絶対量）が担う**。

⇒ **水準を担うはずの項が0なので、水準は禁じられた側だけで決まっている。**

### 2-2. 絶対水準が小さすぎる＝比が暴れる

`NeedSea ≈ 0.001〜0.004`・`NeedLand ≈ 0.003〜0.027`＝**どちらも実質ゼロ近傍**。
理想海比 `ShapeNavalShare = NeedSea /(NeedLand+NeedInternal+NeedSea)` は**ゼロ近傍どうしの比**になる。

⇒ これが軍需調達の `navalMul = ShapeNavalShare ÷ flatShare` に入り、**最大 10.83倍**の再配分になっていた
（docs/202608/20260822_初期軍需の整合_部分完了.md §1＝作者報告「軍艦1083%」の正体）。
**小さな絶対差が桁違いの倍率を生む**＝水準を担う項が無いことの直接の帰結。

## 3. 注意配分の健全性（縮小写像の前提）＝**境界に張り付く**

設計書は「**列和が1未満であること**が縮小写像の実証（段1で必ず確認する）」と明記。実測（seed1）：

| 断面 | 列和最大 | 判定 |
|---|---|---|
| Q1（1783） | ≈1.0000 | ⚠ 境界 |
| Q268（1850） | ≈1.0000 | ⚠ 境界 |
| Q524（1914） | ≈1.0000 | ⚠ 境界 |

`colL = Σ_i hr[j,i] / (u_j + Σ_k hr[j,k])` なので、**1未満の余裕は `u = 不穏度 = 大衆闘争度 ×(1−正統性)` だけが作る**。
少なくとも1カ国は常に u≈0（正統性≈1.0）なので、**最大列和は全断面で 1.0 に張り付く**。

⇒ **発散はしない**（1を有意に超えない＝`>1+1e-6` の国は0）。しかし**「構造的に縮小写像」という設計の保証は空**であり、
実際は**非拡大（non-expansive）**にとどまる。余裕がゼロの列が常に存在する。
⚠計器の注意：`AttentionColSumMax` は**全列の最大を全国に複製した値**なので、「62/62が1超」は62カ国分の独立した証拠ではなく
**1つの最大値**の再掲である（初版の「★★不合格」表示は浮動小数の 1+1e-16 を拾った誤報＝許容幅 1e-6 を入れて3値判定へ是正済み）。

## 3-2. ★理想は実際の軍隊を形作っていない（**機構が名ばかり**）

作者の問いの核心。理想海比（`ShapeNavalShare`）と**実際の戦力海比**（`NavalPower/(NavalPower+LandPower)`）の乖離：

| 断面 | 平均 \|理想−実際\| | 中央値 |
|---|---|---|
| Q1（1783） | 0.049 | 0.053 |
| Q268（1850） | 0.100 | 0.052 |
| Q524（1914） | **0.124** | 0.077 |

**乖離は縮まるどころか約2.5倍に拡大する。**

主要国の推移（理想海比 / 支出海比 / **戦力海比**）：

| プロイセン | 0.000 / 0.071 / 0.022 | 0.068 / 0.214 / — | **0.361** / 0.214 / **0.185** |
| フランス | 0.082 / 0.600 / — | 0.213 / 0.571 / 0.580 | 0.253 / 0.214 / 0.186 |

★**1914年の戦力海比が全国 0.18〜0.21 にほぼ一様**（理想は 0.07〜0.63 とばらついているのに）。
＝**実際の陸海比は理想を1ビットも反映していない**。再配分（`MilMul`）は調達に掛かっているのに、
出来上がる軍の形は理想と無関係な一様値へ収束する。

⇒ **機構は「掛かっている」が「効いていない」**＝名ばかり。

### 因果の断絶点（特定）

```
理想(ShapeNavalShare) → 調達の再配分 MilMul → 艦の購入 → FleetStock → FleetGauge ─┐
                                                                                  ├→ NavalPower = min(艦, 乗員)
維持費の比(NavalSpendShare) → NavalShare ───────────→ 乗員 = Military × NavalShare ─┘
```

- `Diplomacy.cs:704-707`＝`shareTarget = Clamp(nw.NavalSpendShare, …)`／`p.NavalShare = shareTarget`（`NavalBuildRate=1.0`＝即時）。
- `Diplomacy.cs:29-30`＝`NavalPower = min(FleetGauge × 燃料, Military × NavalShare) × 練度`。
- **理想が触れるのは左の枝（艦）だけで、右の枝（乗員）は維持費の比だけで決まる。**
  `min` が**乗員側で律速すると、理想は NavalPower に1ビットも届かない。**

★実測がこれと一致する＝1914年の **戦力海比（0.18〜0.21）≒ 支出海比（0.214）** が全国で成立している
（理想は 0.07〜0.63 とばらついているのに、出来上がりは支出比に貼り付く）。
⇒ **乗員側が律速している**（＝`min` が右を選んでいる）と考えて矛盾がない。
★**`navalgauge` で全4断面を測った**（61カ国・プローブ自身の合格条件＝「両側が 30〜70% で張り合う」）：

| 断面 | 艦隊が律速 | 乗員が律速 | 判定 |
|---|---|---|---|
| Q4（1784） | 18% | **82%** | ★両端に張り付き |
| Q200（1833） | 28% | **72%** | ★両端に張り付き |
| Q350（1870） | 34% | 66% | 合格 |
| Q524（1914） | 30% | 70% | 合格 |

⚠**初版でQ4だけを見て「82%＝乗員律速」と断じかけた＝§10の一般則（単一断面から読むな）を自分で踏みかけた**。是正して全断面を載せる。

- **乗員側が常に多数派（66〜82%）**＝`min` は**大半の国で維持費の比を選ぶ**＝理想が動かす艦隊側は捨てられる。
- ただし**晩期は艦隊側も3割**まで上がり、プローブの合格帯には入る＝**「完全に無効」ではない**。
- しかし**理想と実際の乖離が拡大するのはまさにその晩期**（0.049→0.100→**0.124**）＝
  **艦隊側が効き始めても理想へは収束していない**。⇒ `min` の律速だけでは説明が閉じない＝
  艦隊側の中でも「理想の海比」が実際の購入構成を支配していない可能性が残る（次ラウンドの調査点）。
⚠`NavalPowerFromFleet=1.0` は**点火済み**（2026-08-02）なので、これは休眠機構の話ではなく**現行の挙動**。

⚠なお `NeedSea` の絶対水準は Q1 の 0.001 級から Q524 の 1〜2 級へ育つ（注意項だけで）。
　水準が育っても**土台（護衛項）が0である事実は変わらない**＝育っているのは「禁じられた側」である。

## 4. 覇権封じ込めとの自己矛盾（疑い・要確認）

`Diplomacy.cs:598` ＝ `if (fr == _hegemon) lost += _hegemonContainLost;`（`HegemonContainmentMax=0.55`）。
`TradeAccess` は `BilateralMarket.cs:81` の `natAccess` として交易量に掛かり、その交易額が `LastPortThroughput` に積まれる。

⇒ **覇権国は覇権であるがゆえに港取扱高を最大55%失う**。
⇒ その結果「守るべき海上価値」が縮み、（土台を点火した場合）**理想の海軍が小さくなる**。
⇒ 史実の因果（覇権国こそ最大の海軍を要する）と**符号が逆**。
★土台（`SeaEscortPerTradeValue`）を点火する前に、この経路を断つか別の基数にする必要がある。

## 5. 申し送り

- **点火してはならない**（現状のまま `SeaEscortPerTradeValue>0` にすると）：土台が港取扱高＝死んだ貿易＝普>英の歪みを輸入する。
  2026-08-08 の保留判断（「経済規模の是正が先」）は**今も有効**であり、本ラウンドの実測はそれを追認した。
- **順序**：①貿易の復活（土台を実在させる）→ ②覇権封じ込めの経路整理（§4）→ ③土台の点火 → ④理想と実際の収束の再測定。
- ⚠**国名を主語にした主張は避けた**（§10一般則）。上の「普>英」は**1シード1断面の観察**であり、
  「プロイセンが海軍大国になる」という主張ではなく「**土台の分布が史実の順序を再現しない**」という土台側の指摘である。
