# 3. ★★★ 確定形（作者裁定 2026-08-26）— **路線を1本も定義しない**

> ★ 作者：「経済的な道は既に計算されており、そこに民間鉄道が走っている。これはモデルとして正しい。
> ⚠ ただし、**非経済だが国防に必要な路線を先に定義するのは台本的だ**。いい感じに一般化したい」

## 3-1. ★ 形

⚠ 既存の輸送投資は「**目標容量を決めて、そこへ向けて財を買う**」形（`Transport.cs`）：

```csharp
target = 人口項 × (1−w) + 交易潜在量 × w      // ★民間の目的関数
target *= 1 + 混雑シグナル
BuyToward(w, c, [RailGoodId, LocoGoodId], target × railGate, rail: true);
```

★★★ **目標を決める式に、第2の目的関数を足すだけ。**

```
★民間鉄道（既存）：目標 ← 交易潜在量 ＋ 混雑        ⚠1文字も触らない
⚠国防鉄道（新規）：目標 ← ＋ 脅威の総量             ★同じ「輸送容量への投資」
```

⚠ **「非経済だが国防に必要な路線」はどこにも書かない。**★ 脅威が高ければ目標容量が上がり、国庫が鉄道財を買う。それだけ。
★★★ **＝ 「シベリア鉄道」という名前が消える。**⚠ ロシアが極東を持ち、日本の脅威が高ければ、★ **その状況から輸送投資が出る**＝台本ではなく帰結。

## 3-2. ★★ これで仕様書の ★4／★5 が不要になる

⚠ **脅威も抽象で測れる**からである：

```
★投射力(A → B) ＝ A の輸送容量 × f(A と B の距離)
```

★ 輸送容量が大きいほど遠くまで届く。⚠ **州単位の経路は要らない。**
★★ **鉄道が抽象のスカラーであることと、脅威が抽象のスカラーであることが一貫する。**

⚠ **＝ 「鉄道を輸送グラフへ降ろす」（大改修）も「戦略鉄道の個別建設」も要らない。**
★ **そして31件の鉄道建造物は「輸送容量への投資」という1つの量に畳める。**

## 3-3. ⚠ 代償（★ 承知のうえで受ける）

**方向性が消える。**⚠ ロシアが鉄道を積むと、★ 極東にもヨーロッパにも同じだけ届く。史実では極東への集中投資だった。

★ ただし**新しい歪みではない**——`RailCapacity` は元々国のスカラー1つで、⚠ **既存のモデルが既にそうなっている。**
★★★ **思想⑧の「粗いコア」として許容範囲**（⚠ 「サブシステムのサブシステム、例外の例外は無視する」）。
