|---|---|

## ⚠ 2. 現物の診断

### ★ 2-1. 戦死の式（⚠ `Diplomacy.cs:2254`）

```
⚠戦死 = WarCasualtyRate × ( Military + CasualtiesFromContact × (contactStrength − Military) )
★上限 = WarCasualtyMonthlyCap × 兵士数
```

⚠ `CasualtiesFromContact = 1.0` ★ なので実効は：

```
★★戦死 = WarCasualtyRate × contactStrength      ⚠contactStrength = min(aPush, bPush)
```

### ★★★ 2-2. ⚠ 塹壕は【戦死を減らさない】— 既に正しく作られている

⚠ `Diplomacy.cs:2130` の注記：

> ★ 上の contactStrength（:1918）には**掛けない**＝「⚠ **戦線は動かないが人は死ぬ**」が WWI の実相。
> ⚠ 接触側にも壁を掛けると塹壕戦が穏やかな戦争になり、★ 狙い（厭戦→革命）が消える。**意図的な非対称**。

★★ **`contactStrength` は塹壕ブロックの【前】（:1918）で確定している。**
⚠ 塹壕（:2132）が削るのは `aPush`/`bPush` ＝ ★ **`war.Score` の動き＝戦線の移動だけ**。

★★★ **＝ WW1 の核心である「膠着しても死に続ける」は【既に実装済み】である。**

```
⚠塹壕が深い → ★戦線が動かない → ⚠決着がつかない → ★戦争が終わらない
                                                        ↓
                                      ⚠★★毎月の戦死は減らないまま積み上がる
```

### ⚠ 2-3. なのに死者が増えない理由（★ 3つ）

```
⚠①ConscriptConsciousnessWeight = 0.0   ★休眠 ＝ 兵が増えない
★②TrenchDefenseWeight          = 0.5   ⚠押しを半分しか削らない ＝ 膠着が浅い
⚠③WartimeBudgetFollowsNeed     = 0.35  ★★開戦すると機関銃が買えない ＝ ①②が戦争中に消える
```

⚠ そして戦死率そのものは **2026-06-28 に【下げられている】**：

```csharp
⚠WarCasualtyRate       8.0    // ★24 → 8（⚠「WWI動員の10〜20%/年の【一桁過大】」）
⚠WarCasualtyMonthlyCap 0.04   // ★0.15 → 0.04（⚠総力戦で年〜40%）
```

★★★ **この判断は正しい。⚠ 率は史実水準にある。⚠⚠ だから率を触ってはいけない。**

## ★★★ 3. 設計

### ⚠ 3-1. ①動員規模は【国民意識】で決まる — ★ `ConscriptConsciousnessWeight` を点火

> ⚠ 作者指摘：「★ **動員規模は国民意識で高まります**」

★★ **現物のコメントが既に同じことを言っている**（⚠ `Military.cs:80`）：

> ⚠ 徴兵忌避と脱走で実効の動員力にならなかった。★★ **国民国家（仏・普）が同じ人口からはるかに多くの兵を出せたのはこれである。**
> ⚠ **国名も民族名も書かない**——★ 読むのは州の POP の国民意識だけ。⚠ 既定 0 ＝ ×1.0 ＝ **厳密恒等**。

★ 実装も既にある（⚠ `Military.cs:85–91`）：

```
⚠avgNc = 非兵士POPの国民意識の人口加重平均（★州ごと）
★share = max(0, 1 − ConscriptConsciousnessWeight × (1 − avgNc))
⚠natManpower += (pa + pb + sld.Size) × share
```

```

⚠ **1.0 にしない理由**＝★ 「国民意識 0 の州は兵ゼロ」は強すぎる。⚠ **絶対王政も傭兵と徴募で軍は持てた**（★ 質は落ちるが数は出た）。⚠ 0.7 なら「国民意識 0 の州は 30% しか出せない」＝★ 史実の比に近い。

### ★ 3-2. ②機関銃は事実上【防御陣地】— ⚠ 膠着を深くする

> ⚠ 作者指摘：「★ **機関銃は事実上、防御陣地です。⚠ ですので、より防御有利で膠着するよう調整する**」

★★ **現物の式が既にその形になっている**（⚠ `Diplomacy.cs:2140`）：

```
⚠aPush *= 1 − TrenchDefenseWeight × qB × (1 − t3A)
★         ↑Aの押しを削るのは【Bの機関銃】、取り戻すのは【Aの戦車】
```

⚠ `qB` ＝ ★ **B の陸分・上位軍需の充足率**（⚠ 機関銃 104）

★★★ **＝「機関銃＝防御陣地／戦車＝それを破る道具」が既にこの1行に入っている。**

#### ⚠ 処方

```
★TrenchDefenseWeight   0.5 → 【0.8 を測定。⚠1.0 は完全膠着なので上限として測る】
```

⚠ **0.5 では、相手が機関銃を満たしこちらが戦車ゼロでも【押しが半分残る】。**
★ **0.8 なら押しは 20% まで落ちる**＝⚠ **戦線が実質止まる**。

#### ★ 非対称は維持する

⚠⚠ **`contactStrength` には絶対に掛けない**（★ 現物の注記どおり）。
★★★ **これを破ると「塹壕戦が穏やかな戦争」になり、⚠ 設計の狙い（★ 厭戦 → 革命）が消える。**

### ★★★ 3-3. ③本丸 — ⚠ 戦時に機関銃が戦場から消える

⚠ **`Coefficients.cs:952` の自己申告：**

> ★ 開戦で消費 9 倍・予算 3.8 倍なので ⚠⚠ **戦争中は上位段も tier3 も 0**（★ **塹壕と戦車が戦場で消える**）。

★★★ **①も②も、⚠ 戦争が始まった瞬間に無効になる。**

#### ⚠ 既に打たれている手

```
★ArmsStockEnabled = 1.0   ⚠点火済み（2026-08-13）＝上位段と tier3 を【ストック】にする
⚠ArmsWearRate     = 0.02  ★平時の月次摩耗
★ArmsWarWearScale = 1.0   ⚠戦時は摩耗 9 倍（★「9倍壊れない、9倍激しく使えば早く壊れる」）
```

⚠ **これは正しい方向**——★ 発注は不足分 `(目標 − 在庫)⁺` だけなので、⚠ **予算を 9 倍にしなくても装備が戦場に残る。**

#### ⚠ しかし穴が残っている（★ 現物が明言）

> ⚠ **残る本当の穴 ＝ 開戦で消費 9 倍・予算 3.8 倍のため戦時に上位段が消える。**
> ★ 優先順位を保ったまま直すには **`WartimeBudgetFollowsNeed`（予算が需要に追随する度合い）の側を扱う。⚠ 別項目。**

```
★WartimeBudgetFollowsNeed = 0.35   ⚠【1.0 は硬性赤（戦費が経済を焼き尽くす国）→ 0.35 を測定中 2026-08-08】
```

⚠ **予算は需要の 35% しか追随しない。★ 需要は 9 倍。⚠ ＝ 実効で 3.8 倍。**
★★ **カスケード（まず小銃、余ったら機関銃）は正しいので、⚠ 3.8 倍では基本段（★ 全コストの 63%）で使い切る。**

#### ★★★ 処方（⚠ 3案・要測定）

| ★ | ⚠ 案 | ★ 内容 | ⚠ 危険 |
|---|---|---|---|
| ★★★ **A** | ⚠ **ストックの目標を上げる** | ★ 平時に機関銃を**貯めておく**（⚠ 戦時に買えなくてよい） | ★ 平時の軍事費が上がる |
| ★★ **B** | ⚠ **戦時の摩耗を下げる**（`ArmsWarWearScale` 1.0 → 0.5） | ★ 耐久装備は 9 倍使っても 9 倍は壊れない | ⚠ 装備が減らない＝**戦争が一方的になる**（★ 2026-08-13 の実測で確認済み） |
| ★ **C** | ⚠ **`WartimeBudgetFollowsNeed` を上げる** | ★ 予算が需要に追随する | ⚠⚠ **1.0 は硬性赤**（★ 経済が焼ける）。⚠ 0.5 前後で刻む |

⚠ **A が本命。**★ **平時に貯めることは史実そのもの**（⚠ 各国は戦前に大量の弾薬と機関銃を備蓄した）。
★★ そして「⚠ 戦争が始まってから軍拡はできない」は**総力戦の本質**である。

⚠ **A は B の危険を持たない**——★ 摩耗率は変えないので、⚠ **長期戦では装備が減り、質乗数が下がる**。★★ **これも史実**（⚠ 1917 年の独は機関銃を維持できなくなった）。

## ★★ 4. なぜこれで【時代性】が出るか — ⚠ 暦年を一つも書かない

★★★ **3つとも「時代」を参照しない。⚠ それでも 19 世紀末以降に集中する。**

```
⚠①国民意識 ← 教育・都市化・新聞（★どれも工業化とともに育つ）
★②機関銃   ← 鋼 + 精密工作機械（⚠深い連鎖＝AdvancedTechScale で晩期に自動解禁。マキシム 1884）
⚠③備蓄     ← 財政規模（★工業化した国だけが平時に貯められる）
```

★★ **3つが同時に揃うのは、⚠ 工業化が一定以上進んだ国だけである。**

| ★ 時代 | ⚠ 国民意識 | ★ 機関銃 | ⚠ 備蓄 | ★ 帰結 |
|---|---|---|---|---|
| ⚠ **1783** | ★ 低 | ⚠ **無い** | ★ 無 | ⚠ **小さい軍・短い戦争・少ない死者** |
| ★ **1800s** | ⚠ **革命で跳ねる** | ★ 無い | ⚠ 無 | ★★ **兵は増えるが戦線は動く**（⚠ ナポレオン式の会戦決着） |

| ★★★ **1910s** | ⚠⚠ **飽和** | ★★ **飽和** | ⚠ **有** | ⚠⚠⚠ **大量動員 × 膠着 ＝ 死者が桁で増える** |

⚠ **1914 という数字はどこにも書かれない。**★★ **それでも 1914 年ごろに集中する。**

### ★ 「急激」はどこから来るか

⚠ **積である。**

```
★戦死者 ≈ 月あたり戦死 × 期間
        ≈ (WarCasualtyRate × contactStrength) × 期間
```

⚠ `contactStrength` は **兵数に比例して大きくなる**（★ 押し合いの実接触）。

```
⚠動員が ×2.5（国民意識ゲート点火）
★期間が ×2.0（塹壕を 0.5 → 0.8）
                  ↓
⚠★★死者は ×5.0
```

★★★ **どちらも連続に増える量だが、⚠ 積は【急激に】増える。**
⚠ **これが思想⑩（★ 全ては連続的であるべき）を破らずに「急激」を出す唯一の形である。**

# ⚠ 15. 【調整項目】戦争特需が弱い（★ 作者メモ 2026-08-28）

## ★ 15-1. 作者の推測は **正しい**

```

## ⚠⚠ 15-2. しかし **原因は2つ**ある

### ★ 原因① 需要が価格に効かない（⚠ 2026-08-26 の宿題）

⚠⚠ **＝ 「⚠ 買いたいが買えない」。★ 市場から見れば需要が無いのと同じ。**

★★★ **＝ 二重に効いている。⚠ 価格も上がらず、⚠⚠ 取引量も増えない。**
