# プチブル利益束（小営業の第4束）設計 — 作者承認 2026-08-15「それでよい」

> 構想（作者）：「プチブルという層を作り、経済法でアッパーと対立する」
> 裁定形：**層オブジェクトではなく政治コアの深さ1の配線**＝法選好の第4束。着手は rank1/6（商人職人→資本家・小営業の入口）のA/B採否の後（体→声の順序）。

## 1. 何が欠けているか（現状）

法選好（PolicyPreferences.cs）は trad（旧支配層）/ modern（近代=資本・エリート）/ mass（大衆）の3束。
- 職人 → mass に薄まる／商人（IsModernElite）→ modern に折り畳まれる。
- Antitrust の現行：「独占レントを得る資本が抵抗・大衆が賛成」の2極＝**「大資本には反対だが私有と営業の自由は死守」という第3の立場が構造的に存在しない**
  （ミッテルシュタント政治・反百貨店運動・1848急進主義の母体）。

## 2. 実装形（休眠 PettyInterestGate=0）

- **束の判定**：職人pop＋商人pop（構造マーカー＝ArtisanPopIndex/MerchantPopIndex。自営=OwnerPopIndex==LaborPopIndexの所得を持つ階級）。
  Gate=0 で従来の束分類（職人=mass・商人=modern）と**ビット恒等**＝分類切替そのものを係数でゲート。
- **立場は保有から導出**（MilitaryExportPref と同型＝国名・年号なし）：
  | 法軸 | 小営業の立場 | 強さの導出元（既存量） |
  |---|---|---|
  | Antitrust | **賛成**（大資本の解体） | 企業集中＝EffFirms の逆数系（寡占マークアップの入力を再利用）×自営所得シェア |
  | Tariff（保護） | 賛成 | 自財の輸入競合シェア（LastImport÷(LastProduced+LastImport)） |
  | 消費税（per-good） | 反対 | 小営業の売上に乗る税＝消費税実効率そのもの |
  | 累進課税/所得税 | 中立〜弱賛成 | 対アッパーの相対所得（自分に累進はほぼ届かない） |
  対象はまずこの4本（過剰に広げない）。他の法軸では petty は従来束の値へフォールバック（恒等側）。
- **アッパーとの対立の発現**：法可決機構は既存（政治力×立場の集計）。プチブルの声が票として立てば、
  独禁・関税・税で modern（大資本）と正面衝突する＝**対立は集計から創発・専用機構なし**。
- **政治化（1848→ファシズムの母体）**：新規機構なし＝rank1/6 の締め付け（入口と出口）→没落が闘争度を運ぶ→
  反動/ナショ→ FascismGate の r[9]=eraFasc×dev×mil×(r[1]+r[4]) が拾う（既存経路）。

## 3. やらないこと（作者承認済みの境界）

- ClassOf（失業プールの3層）の4層化＝道案内が変わるだけで対立は生まれない。
- 王権・議会・軍・大衆（4主体・3つのパイ）への第5アクター追加＝コア手術（§8違反側）。
- 「プチブル」という語をコードの条件に書く＝③固有名詞違反。判定は常に構造マーカー。

## 4. 実装時の罠（前例）

- **「ゲート緑≠機構が働いた」**：PolicyAxis追加は7箇所の前例＝**束の追加も全読者を数える**こと。
  trad/modern/mass を分類している箇所を grep で全数把握（立場関数だけでなく、要求リスト生成・政治力加重・AI法選択の各所）。
- 恒等の検算＝Gate=0 で before/after ビット一致（分類切替が唯一の分岐点になるよう書く）。
- A/B の物差し＝法一致・総政変の恒等物差し・ファシズム到達数。合成後アブレーション（rank1/6と独立に切れること）。
