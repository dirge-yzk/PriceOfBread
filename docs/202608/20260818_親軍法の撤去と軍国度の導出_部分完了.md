# 親軍法の撤去と「軍国主義」の4実体への分解（2026-08-18）

作者裁定：**「親軍法は廃止したい。これは厳密には法ではなく政治機構だ。そしてこれは既存の数値から算出できるように思える」**

本ラウンドは**導出式が2度棄却され、3度目で確定した**。棄却の過程そのものが成果なので、順に記録する。

---

## 1. 生き残った判断：撤去は正しい

**「軍国主義法」という単一の立法は1783〜1934に存在しない。**（唯一の例は1946年の非ナチ化法＝軍国主義を**解体する**法。）
プロイセンの軍国性を作ったのは一般兵役義務（1814）・軍事予算・将校団の社会的地位であって、「軍国主義法」ではない。

加えて旧実装には**書類上の軍国主義**という穴があった：軍事費ゼロ・志願兵制のまま法だけ立てれば、戦力×1.3・将校貴族の政治力・戦争熱の加点が手に入る。

⇒ **親軍法（`Policy.Militarism` / `World.Militarism` / `PolicyAxis.Militarism`）の撤去は確定。**

## 2. 棄却された第1案：軍国度 ＝ 軍事費 × 徴兵法の深さ

### 2-1. 史学側の反証（反復する型であって例外ではない）

| 事例 | 反証の内容 |
|---|---|
| 英1913 | 徴兵深度**0**なのに国防費は中央政府支出の**43%**、軍事費/GDPは1870-1913平均**2.6%＝独と同率**。積は英を軍国度0と評価する |
| ワイマール独1920-34 | ヴェルサイユで徴兵禁止・陸軍10万の志願制＝**両因子とも最低**。なのに国防軍は「国家の中の国家」、カップ一揆で政府防衛を拒否、シュライヒャーは1932年に**首相** |
| 独50% 対 仏85% | 法はどちらも皆兵だが実際に徴集したのは独が適齢の約50%・仏は約85%（墺洪は約20%）＝**軍国の典型とされる独の方が「深度」が低い** |
| 日本1922-31 | 山梨・宇垣軍縮で平時兵力の約1/3（約10万名）を削減、軍事費の歳出比は1913年33.5%→**1930年28.5%が谷**。**なのにこの10年に軍の政治的自律は逆に高まった**（1936年に47.6%へ） |
| 決定実験 | 独帝国と仏第三共和政の1913年は**同じ高支出・同じ皆兵法**なのに結果が正反対。ツァーベル事件で帝国議会が宰相不信任を293対54で可決しても**何も起こらない**（宰相は皇帝にのみ責任を負う）／フィッシュ事件では**内閣が崩壊**した |

⇒ **欠けている次元は「誰が軍の人事・司法・予算を握るか」**。

## 3. 棄却された第2案の一部：「軍事費の不足が将校を怒らせる」

第1案の棄却時、下側の罰として「給与不払い（1−pay）を軍の政治的圧力に加算する」形を実装した（チリ1924「サーベルの音」＝俸給据え置きが引き金）。これも**イベリア＋ラテンアメリカ92件の検証で棄却された。**

- **スペイン アサーニャ軍制改革（1931）**＝本データセット最大のクーデタ（1932サンフルハダ→1936）を招いたが、**給与は一切削っていない**。士官団の約40%・約9,000名が**満額俸給付きで**退役（21,000→12,373名・将官190→90名）、16師団→8師団、軍事司法の最高会議を廃止し最高裁の一法廷（軍人判事4＋**文民判事2**）へ移管、独裁期の戦功昇進約300件を遡及無効化、サラゴサ士官学校の閉鎖。効いたのは**人数・地位・自律・名誉**。
- 同型：ブラジル1883-87（年金拠出義務化＋新聞発言の禁止＋文民大臣への従属）／スペイン1923（訴追の脅威）／ボリビア1934（司令部更迭）／ペルー1914（クーデタ2日前に参謀総長を罷免）。

**⇒ 階級による引き金の分岐**：兵卒・下士官はほぼ例外なく物質的苦情で動く（チリ1931コキンボ30%減俸／ブラジル1910／キューバ1933／スペイン1836）が、**将校は賃金では動かない**。

### 3-1. さらに：給与は「帰属」ではなく「規律・能力」を動かす（欧州・ロシア15事例）

旧実装は `ArmyAllegiance = pay ×（lean + milAff）` で、**払えない軍は忠誠の向きを失う**としていた。これも棄却された。

- **同一の給与で3週間後に符号が反転した**：ライヒスヴェーアは1920年3月にカップ一揆への発砲を拒み、4月にルールの労働者を1000人以上殺した。**給与変数は符号を変えられない。**
- **カップ派はベルリンを5日間、無給のまま保持して離反しなかった**（次官レヴァルトが一揆側への給与支払を拒否。一方、国庫を握る合法政府の側に撃つ気のある兵がいなかった）。
- **ヒトラー一揆を撃ったのは1ドル＝6285億マルクの日**（レンテンマルク導入の6日前）＝給与モデルなら離反リスク最大の一点で離反ゼロ。
- **勝った反乱者が自由な手で要求を書いたとき、金の要求はゼロ**：ペトログラード・ソヴィエト命令第1号（7項目）＋キール14項目＝**計21項目のうち金に関するものは一つも無い**（委員会・武器の管理・敬礼と敬称の廃止・勤務時間外の市民権・出撃の中止、そして「パンと平和」）。
- **兵は離反するために金を払っている**：カラーの将校57名はキャリア保全の申し出を蹴って**恩給を捨てた**。
- 逆の例：1830年7月の王室親衛隊は**2日間パンなしで**離反しなかった。ハプスブルクの国境守備兵は現金でなく**土地と免税**で報われ、対革命の最精鋭だった。

**⇒ 給与の出力は脱走・不服従・行軍拒否・動員の遅れ・練度低下であって、忠誠の向きの変更ではない。**
1848年3月以前のハプスブルク大蔵省がラデツキーを飢えさせた例がまさにこれ＝**軍は弱くなったが裏切らなかった**。

### 3-2. 給与が本当に発火した場合の出力は、クーデタではなくストライキ

インヴァーゴードン1931（譲歩を勝ち取って復帰。**将校は同じ減俸を受け入れて残ったので指揮系統がなく、政治的天井が存在しなかった**）／スピットヘッド1797（恩赦と昇給）／スペイン防衛フンタ1917（**自分の雇用主を恐喝した**＝新しい雇用主を探したのではない）／オランダ ハルスカンプ暴動1918（兵舎を焼いたのに数週間後の革命への参加は断った）／ファシスト民兵の一個軍団（日給17リラの約束に対し7リラで反乱＝雇い主を変えず拒否した）。
そして**政治的要求に手を伸ばした瞬間に殲滅される**：ノアの反乱1797はスピットヘッドと同じ兵が議会解散と対仏講和を要求し、パーカー以下29名が絞首された。

**⇒ 兵卒の物質的不満は単独では政治的天井を持たない。既存の反体制勢力へ流れ込む形にする。**

## 4. 確定した形：軍国主義は単一スカラーではなく**4つの別々の実体**

置き場所は **`PriceOfBread.SimCore/PoliticalQuantities.cs`**（採った理由は §4-5）。

| # | 実体 | 導出（すべて既存量のみ） | 効かせ先 |
|---|---|---|---|
| ① | **軍の練度** ∈[0,1] | 識字 × 組織（専門官僚制 × 鉄道）× 勤務年数 | `MilitarismStrengthBonus`（`ArmyShape.Quality`・`Diplomacy` の戦力合成） |
| ② | **軍の政治的優位** ∈[0,1] | 軍の圧力 ×（1 − 文民制度の弁） | `MilitarismClout`（`InterestGroups`）＋ **忠実度ハーネスの物差し** ＋ AIの軍国教義 |
| ③ | **好戦世論の公共圏** ∈[0,1] | 報道自由度 × 識字 × 都市化 × 対外屈辱 | `WarFeverMilitarism`・`WarFeverMilitancyGate`（`World.WarFever`） |
| ④ | **将校の任免権の所在** ∈[−1,1] | （君主がいて議会が弱い分）−（議会統制力） | `ArmyMilitarismAffinity`（`World.ArmyAllegiance` の向き） |

### 4-1. ①軍の練度

```
練度 ＝ 識字 × ( 0.5×官僚制の専門化 + 0.5×鉄道 ) × 勤務年数
        勤務年数：志願1.0 ／ 選抜0.6 ／ 皆兵0.4
効果：戦力乗数 ＝ 1 + (MilitarismStrengthBonus − 1) × 練度
```
根拠：質の駆動因は参謀組織・鉄道・識字・下士官層。露は皆兵＋巨額（1913年の陸軍費は独に次ぐ）でも低質＝識字と下士官層の不在。英は志願長期勤務で個人技量が最高。普は短期兵だが参謀本部・鉄道・義務教育で質を作った。

⚠**装備充足・即応度・軍事費÷兵数を入れない**。`ArmyShape.Quality` は `NeedMen` の分母に入るので、入れると「質が落ちる→必要兵数が増える→1人あたり予算が薄まる→さらに質が落ちる」の正帰還が閉じる（旧 `SoldierSustainDriven` 凍結と同型の墓標）。1人あたりの装備・給与の厚みは `Diplomacy` の戦力合成が既に `MilitaryReadiness`・装備充足として掛けている＝二重計上しない。

### 4-2. ②軍の政治的優位（＝忠実度の物差し）

```
圧力 push ＝ clamp( 組織の大きさ + 解隊の脅威 + 0.5×粛清の記憶 + 対外屈辱 , 0, 1 )
    組織の大きさ ＝ 兵士人口シェア ÷ MaxSoldierFraction
    解隊の脅威   ＝ max(0, 現在の維持費 − 目標の維持費) ÷ 現在の維持費     ← **最も重い**
    粛清の記憶   ＝ clamp(MandateSpent)（＝文民が反対を押し切った履歴・数年で減衰）
    対外屈辱     ＝ clamp(DefeatShock + LostLandNationalism × 失地ストック)
弁 civil ＝ ¼( 参政権開放度 + 官僚制の専門化 + 議会統制力 + 正統性 )
軍政比 ＝ push × (1 − civil)
```

- **給与を1度も読まない**（将校は賃金では動かない）。⚠「軍事費を全く読まない」ではない——軍事費が効く経路は2つだけで、
  どちらも**水準そのものではない**：(i) 兵数＝組織の大きさ／(ii) 現在値と目標の差＝解隊の脅威。
  **目標が現在値に追随している均衡では、水準をどこへ動かしても値は動かない**（テストで固定）。
- **解隊が最大のショック**：ノスケが1920-02-29にヴェルサイユの10万人上限を満たすためエアハルト海兵旅団とレーヴェンフェルト旅団の解散を命じたことがカップ一揆の直接原因（旅団は「解散に抵抗することを決意した」）。だから解隊は満額・粛清は半分。
- **粛清が次の反乱を生む連鎖**は `MandateSpent` が減衰しながら次期に残ることで出る（西1841→1843／1868→ラ・グロリオサ／1932→サンフルハダ、伯1892→1893／1904／1922-24→1930）。
- **⑤同じ軸の両符号**（Huntington 対 Nordlinger/Finer）：専門職性を高め自律を与える＝分母（civil）が厚くなり軍は政治的に不活性化／その自律が脅かされる＝分子（粛清・解隊）が育ち介入。**片方だけ実装していない。**
- Nordlinger「群を抜いて最も一般的な介入動機は軍の団体的利害の防衛＝**軍事予算・組織の自律・競合勢力に対する存続**」。ここでの予算は**軍の予算であって将校の給与ではない**（ギリシャ1909のクーデタ団も「増額された軍事予算と再編」を要求し、給与や未払への言及は史料に無い）。
- **⚠比のガード**：「軍の力 ÷ 文民の力」を素直に割ると分母が痩せた瞬間に万%へ跳ねる（memory「比のガードは絶対値で書かない」）。積の形 `push ×(1−civil)` で書く＝単調性は同じで有界。既存の `PolicyPreferences.ArmyPower` も同じ `×(1−議会統制)` の形。

### 4-3. ③好戦世論の公共圏

```
公共圏 ＝ 報道自由度 × 識字 × 都市化 × 対外屈辱（敗戦＋失地＋条約港）
```
1914年8月の熱狂は**都市の教育ある中産層と学生**に限られ、労働者と農村は静かだった。徴兵の無い英で1900年の南阿主戦熱、常備軍10万未満の米で1898年の戦争熱（黄色新聞）。1930年の統帥権干犯を焚きつけたのも軍ではなく野党（政友会）と新聞。
⚠屈辱が無ければこの項は0で、平時の対外的な食欲は既存の `WarFeverThreat`（緊張）・`WarFeverNoble`（将校貴族）・`WarFeverSoldier`（兵士規模）が担う＝二重計上しない。

### 4-4. ④将校の任免権の所在（**旧実装は符号が逆だった**）

```
任免権 ＝ (君主がいる ? 1 − 議会統制力 : 0) − 議会統制力      ∈[−1,1]
軍帰属 ＝ clamp( 兵士の思想の傾き + ArmyMilitarismAffinity × 任免権 , −1, 1 )
```
常備軍こそ王の圧政の道具であり、民兵・皆兵は共和派の対案だった（1697-99英の常備軍論争→ジョレス『新しい軍隊』1911→スイス憲法第13条の常備軍禁止）。しかも**軍が王政を倒す例が反復する**（ブラジル1889・ポルトガル1910・スペイン1931）。独将校団が王党派だったのは軍国度ではなく**憲法第64条の軍旗宣誓が「憲法」でなく「皇帝個人」に向いていた**から。

**★給与の乗算を撤去**（§3-1）：旧 `pay ×(lean + milAff)` → `lean + milAff`。給与は帰属を1ビットも動かさず、**規律・能力**＝`MilitaryReadiness`（士気×装備充足）の側だけに効く（この経路は既存＝兵士popの満足度から既に立っている）。
⚠旧指示「掛け算の構造（金 × 思想）を崩すな」は満たしている——**金を積んでも帰属は買えない**（1917露・1936西の型は `lean`＝兵士の思想が担う）。

### 4-5. 置き場所と理由：`PoliticalQuantities`

候補は `PolicyPreferences` / `ArmyShape` / 新規クラスだったが **`PoliticalQuantities` を採った**。

- このクラスは既に「**同じ量が複数実装で散在していたのを一元化する場所**」として設計されている（実効保持力・challenge/coerce比・族写像・天命母数・政体座標）。4実体の読み手は `ArmyShape` / `Diplomacy` / `InterestGroups` / `World.WarFever` / `CrownParliament` / `SelfPlay` / `PowerShares` / `HistoricalReference` に跨る**共有の導出量**で、性格が一致する。
- `PolicyPreferences` は「賛否の選好」の場所であって導出量の場所ではない。`ArmyShape` は軍の形の場所で、政治側（InterestGroups／CrownParliament）がそこを読むのは依存の向きが逆。
- 新規クラスは「政治の導出量が2つに分かれる」ので一元化の意図が薄まる。

## 5. 非歴史的最適解の2つの穴が塞がっていること（アブレーション実測）

`dotnet run -- milablate`（本ラウンドで恒久化。英・240四半期・単一国）：

```
  条件                         軍の練度      軍政比      公共圏      任免権      即応度      軍忠誠
  基準                        0.147    0.084    0.000   -0.256    0.630    0.027
  軍事費 0.05（振り切り下）           0.150    0.369    0.000   -0.269    0.660    0.035
  軍事費 0.95（振り切り上）           0.144    0.275    0.000   -0.162    0.501    0.046
  議会統制力 0（人事=宮廷）            0.205    0.073    0.000    0.145    0.619    0.191
  議会統制力 1（人事=内閣）            0.218    0.047    0.000   -1.000    0.629   -0.161
```

**別々の壊れ方をしている＝作者裁定の確認項目を満たす。**

| プレイヤーの狙い | 結果 | 機構 |
|---|---|---|
| 「軍事費を削れば軍は安全」 | **塞がる**：軍政比 0.084 → **0.369**（最悪値） | 解隊の脅威（ノスケ1920／アサーニャ1931） |
| 「金を積めば将校は黙る」 | **塞がる**：軍政比 0.084 → **0.275**（上がる）／即応度 0.630 → 0.501（下がる） | 組織が大きくなるほど政治主体として重い（中南米の歳出68%国家）。**給与**は1度も読まない |
| 人事権を文民へ寄せる | 軍政比 0.073 → 0.047・任免権 +0.145 → **−1.000**・軍忠誠 +0.191 → **−0.161** | 人事と軍法だけが忠誠の向きを決める |

★「軍事費」の2行が**軍政比を同じ向きに、即応度を逆向きに**動かしているのが本設計の核心＝**軍事費に最適点があり、両側に別々の罰がある**。

## 6. 忠実度ハーネスの扱い（作者裁定＝(b)＋物差しの差し替え）

```csharp
// 旧
if (e.MilitarismOk is { } m) { axes++; if (s.Militarism == m) ok++; }
// 新
if (e.MilitarismOk is { } m) { axes++; if ((s.Militarism >= MilitarismDegreeOk) == m) ok++; }
```
`NationStanding.Militarism` は **bool →「②軍の政治的優位」の double** になった。
この物差しなら **英1913（国防費が中央歳出の43%）でも文民制度が厚いので偽**になる＝金額では測らない、という要件を満たす。

### 6-1. 分母は不変

`MilitarismOk` を定義しているのは **アメリカ（false）** と **プロイセン（true）** の2件のみ。
「法」次元は**法軸を持つ22カ国の LawMatch（一致軸数／定義軸数）の平均**で、**分母22（国数）も各国の軸数も不変**（アメリカ5軸・プロイセン6軸・全22カ国で総72軸＝実測）。

### 6-2. ⚠物差しそのものが変わった（差の読み方）

差の内訳は「エンジンの変更由来」と「物差しの変更由来」の2つで、**原理的に分離できない**（旧の法 bool は新エンジンに存在しないので、新エンジン上で旧ルールを評価できない）。
ただし**物差しの変更が触りうる範囲は厳密に有界**：

- アメリカ：1/5軸＝自国 LawMatch で 20.0pt → 22カ国平均への寄与 **0.91pt**
- プロイセン：1/6軸＝16.7pt → **0.76pt**
- **合計で最大 1.67pt**。これを超える差分は物差しでなく**エンジンの変更由来**。

残り20カ国・70軸（参政権・教育・農奴解放・年金・穀物法・土地改革）は1行も変えていない。

| 変更後 | 親セッションの `selfplay-batch` / `fidelity` で測定（本セッションでは未取得＝§9） |

### 6-3. 閾値は2本ある（意図的）

- `HistoricalReference.MilitarismDegreeOk`＝**物差し**（参照表はシミュレーションから読まれない＝挙動を1ビットも動かさない、という既存の性質を守る）。
- `SelfPlay.MilitaristDoctrineDegree`＝**挙動**（AIの軍国教義の判定線＝SelfPlay私有定数）。

`HistoricalReference.MilitarismDegreeOk` は **実測で 0.13 に確定**（`milgrade 6seed`・1914断面・2026-08-18）：

```
  アメリカ(非軍国)  n=6  平均0.118  最小0.021  中央0.099  最大0.287
  プロイセン(軍国)  n=6  平均0.204  最小0.118  中央0.153  最大0.468
── 全国（平均の降順・上位）──
  ロシア 0.549 / 日本 0.490 / コーカンド 0.485 / スウェーデン 0.473 / デンマーク 0.473
  ラオス 0.443 / ネパール 0.432 / エチオピア 0.418 / 教皇領 0.399 / ビルマ 0.389 …
```

両者を**中央値で分ける**位置は (0.099, 0.153] の帯で、その中央の **0.13** を採った（普が過半のシードで真・米が過半で偽）。
`SelfPlay.MilitaristDoctrineDegree` は挙動側の判定線なので **0.25 のまま**（§6-3の分離の理由）。

### 6-4. ⚠この物差しの既知の弱点（次ラウンドの較正対象）

1. **分離が弱い**。プロイセン中央0.153 対 アメリカ中央0.099＝分布が大きく重なる。閾値は「どちらかと言えば分ける」位置でしかない。
2. **順位が部分的に史実と逆**。ロシア0.549・日本0.490が上位に来るのは**正しい**が、
   プロイセンが0.204で、デンマーク0.473・スウェーデン0.473・教皇領0.399・ビルマ0.389より**下**に沈む。
3. **原因の見立て**：`BureaucracyDepth`（官僚制の専門化）を**①の練度と②の文民の弁の両方**に置いたため、
   プロイセン（専門官僚制＋高い正統性）は分母が厚くなり比が下がる。しかし史実のプロイセンは
   **専門化と軍の政治的優位が両立していた**——軍が文民官僚機構の**外**にあったから（憲法64条・軍事内閣・帷幄上奏）。
   ⇒ 修正の方向は「文民の弁から官僚制を外して**政治的統制の3項（参政権・議会統制力・正統性）**にする」か、
   「専門化を**文民の専門化**と**軍の専門化**に割る」。どちらも本ラウンドの検証予算を超えるので次ラウンドへ送る。
4. 小国・後進国が上位に来るのは分母（文民制度）が薄いため＝Finer/Huntington の含意としては正しい向きだが、
   **組織の大きさの項が人口比で正規化されている**ので絶対的な軍事力の差が消えている点は要検討。
