> ★ **「技術者の流出を法で禁じる → これは法律で対応。★ B（他国から呼ぶ）で実装。⚠ まず高等教育から順に」**


# 3. ★★ 段B — 技師の招聘（★ 作者裁定「Bで実装」）

## ⚠⚠ 大衆移民に相乗りさせてはならない

```csharp
MultiNationSim.cs:1180  foreach (int cls in MigrantClasses)   // ⚠農民・労働者（大衆）が移る
```

★ **越境移民は既に「引力」を持つ**（⚠ `Territory.Opportunity` ＝ 生産性×空き×雇用×賃金プレミアム）。

⚠⚠ **しかし `MigrantClasses` に技師を足すのは危険**——★ **前例がある：**

```csharp
MultiNationSim.cs:1138
// ⚠全組判定だと1国が同時に多数へ毎四半期上限まで流出する多重排水
//   （★プロイセン技術0.38へ空洞化を実測）
```

★★★ **技師は数が桁違いに少ないので、⚠ 同じ流量式では先進国が一瞬で空になる。**

## ★★ 主語が違う＝式も別

> ⚠ **大衆は【自発的に】動く。★ 技師は【呼ばれて】動く。**

```
★招聘(a←b) ＝ 招聘予算(a) × 賃金差(a,b) × 距離減衰 × (1 − 流出禁止(b))
                  ↑⚠国庫が払う          ↑★既存の Opportunity 差
                                          ↑⚠既存の MigrationDistanceScale
```

★ **史実の規模**：⚠ **お雇い外国人は明治日本の最盛期でも数千人**（★ 大衆移民は数百万人）。
★★ **だから「予算で買える人数」という上限が自然に効く。**

## ★★★ 保存の帰結（★ 作者裁定 2026-08-16「保存です。POPは無からわかない」）

```
★先進国 → ⚠高等教育が豊富＝育てる速度が速い → ★流出しても補充できる
⚠後進国 → ★育てられない → ⚠呼ぶしかない → ★高くつく
                                    ↓
                        ⚠流出禁止法（段C）を敷かれると呼べない
                                    ↓
                        ★★★自力で育てるしかない＝近代化の壁
```

⚠ **世界全体の技師の総数は、★ 高等教育で育つ分だけ増える**——⚠ **奪い合いでは増えない**（★ 史実：英が育て・大陸が奪い・大陸で育った技師がさらに東へ）。

### ★★ 自己制限的である

```
⚠A国がB国から呼ぶ → ★B国の技師が減る → ⚠B国の賃金が上がる → ★呼びにくくなる
```

★ **既存の `Opportunity` 差が自動的にブレーキになる**——⚠ **新しい上限は要らない。**

### ★ 既存の国際移民との非対称は正しい

| ★ 対象 | ⚠ 供給 | ★ 根拠 |
|---|---|---|
| ⚠ **大衆** | ★ **モデル外から流入**（非ゼロサム・⚠ `PopulationDelta` に記帳＝台帳は閉じている） | ⚠ 19世紀の移民は**数千万人** |
| ★ **技師** | ⚠ **保存**（ゼロサム） | ★ 技術者の国際移動は**数万人規模**＝希少資源 |

## ★★★ 空振りした予算は国庫に戻す（★ 作者裁定 2026-08-16）

> ⚠ **作者「呼びたい技師を現在のコストで呼べない場合、★ 空振りしたコストは国庫に戻してください。⚠ 他の支出でも同じです」**

### ★★ 既存の作法（⚠ 実測・そのまま使う）

```csharp
EconomyStep.cs:1342  region.StateSpent -= qty × m.Price × cTax;
//   ⚠StateSpent に【実際の取引】を積み、★最後に Treasury -= StateSpent で精算＝保存

EconomyStep.cs:1626  region.StateBuildQueue = 0;
//   ⚠試行は消費（買えた分だけ建設・★残予算は国庫に残る）
```

★★★ **予算は【上限】であって支出ではない。⚠ 実際に買えた分だけ国庫から引く。**
★ **招聘も同じ器（`StateSpent`）に乗せるだけ＝新しい機構は要らない。**

### ⚠ 呼べない理由は5つ（★ どれも「金は出さない」で正しい）

| ⚠ 理由 | ★ 扱い |
|---|---|
| ★ 送出国が**流出禁止法**を敷いている（段C） | ⚠ 予算は残る |
| ⚠ 送出国に**技師が居ない** | ★ 同上 |
| ★ **賃金差が足りない**（⚠ 相手のほうが高い） | ⚠ 同上 |
| ⚠ **距離が遠すぎる** | ★ 同上 |
| ⚠⚠ **受入側に器が無い**（★ 7h） | ⚠⚠ **金は残るが黙って何も起きない**——★ **7h の対処が別途要る** |

### ⚠ 既存で唯一の例外＝**福祉・年金**

★ `WelfarePensionClampToTreasury = 1.0` で「国庫が空なら払わない」は点火済み。
⚠⚠ **しかし福祉は「買う」形でないので、★ そもそも【買えなかった】という状態が存在しない**——
★★ **前回指摘の「支出→直接バフ」と同根。⚠ 現金給付に変えればこの問題も一緒に消える**（★ 給付は必ず誰かに渡る）。

# 4. ★★★ 段C — 技術者流出禁止法（★ 作者裁定「法律で対応」）

## ★ 史実

> ⚠ **英国は 1719年〜1825年、職工の海外移住を法で禁じた**（★ Artificer Emigration Act）。
> ★ **1786年〜1843年には機械の輸出も禁じた。**
> ⚠ **それでも流出は起きた**（★ サミュエル・スレイターが図面を暗記して渡米＝アメリカ紡績業の父）。

★★★ **「禁じても完全には止まらない」＝ゲームとして良い形。**

## ★ 実装の形

```
★技術者流出禁止法（3段）
   ⚠なし        流出は自由
   ★制限        招聘の成功率が下がる（⚠ 完全には止まらない）
   ⚠全面禁止    さらに下がる ＋ ★正統性/自由度の代価
```

⚠ **既存の `PolicyAxis` に乗る＝機構ゼロ**（★ §11-7 の基準）。

## ★★ そして自然な対立が出る

| ⚠ 誰が | ★ どちらを望むか |
|---|---|
| ★ **先進国の資本家** | ⚠ **禁止したい**（★ 技術優位の保持） |
| ⚠ **後進国** | ★ **開けさせたい**（⚠ **§外交の「阻害」＝要求になる**） |
| ★ **技師本人** | ⚠ **移動の自由を望む**（★ 自由主義との緊張） |

★★★ **「機械や人の輸出禁止」は、⚠ §戦争を政治の延長にする の【阻害】そのもの**——
★ **補完的（先進国に技師が余り・後進国に足りない）なのに法で閉じている＝★★ 最も危険な状態。**

⚠ **つまり「不平等条約で技術者の受入を認めさせる」まで繋がる。**
