# 4. ★★★ 再設計 — 入力を2つに畳む

```
★汚職 = (1 − AdminFill) × (1 − 監視)

   ★AdminFill  ＝ 行政財の充足        ⚠既存（★官僚を雇えているか＝【量】）
   ★監視       ＝ 報道自由 × メリトクラシー × 議会の予算権
                   ⚠既存      ⚠既存           ★新（3つのパイ）
```

## ★ 消えるもの

| ⚠ 消える | ★ 畳み先 |
|---|---|
| ⚠⚠ **`CleanGovernance` ストック**（★ 汚職根絶支出） | ★★ **「監視」に吸収**（⚠ 根絶とは報道と資格任用と議会である） |
| ⚠ `debtRoom` / `corruptionRoom` / `AntiCorruptionFloor` | ★★★ **自己言及ごと消える** |
| ⚠ `span`（統治スパン・2本） | ★ **`AdminFill` が既に人口・州数に比例**（⚠ 二重計上だった可能性） |
| ⚠ `civicGraft`（国民意識） | ★★ **議会の予算権に吸収**——⚠ **「利害が一致しない共和制は汚職を生む」＝議会が予算権を握っていない状態** |

★★ **係数 12本 → 2〜3本**（★ `CorruptionMax` / `CorruptionLegitimacyErosion` ＋ 監視の重み）。

## ★ 深さ

```
★深さ0  予算権のパイ
★深さ1    └ ★汚職＝(1−行政)×(1−監視)
```

⚠ **深さ1で止まる。★ サブのサブが無い。**

# 5. ★★★ 漏れの行き先を「政治」にする

## ⚠ 現状：漏れ → 官僚の貯蓄（★ そこで止まる）

## ★★★ 提案：漏れ → 官僚の貯蓄 → **官僚が改革に反対する**

```csharp
Ideology.cs:140  r[0] = 2 * rentier + 0.5;                              // ★伝統＝地代依存
Ideology.cs:141  r[2] = (IsModernElite ? 3.0 : 1.0) + 3*rich*(1−rentier);  // ★自由＝富裕非地代
```

⚠ **官僚は `IsModernElite = true` なので、★ 富むと【自由】が伸びる**——
⚠⚠ **しかし汚職で富んだ官僚は改革に反対する**（★ 改革＝自分の収入源が消える）。

★★★ **つまり汚職所得は `earned` ではなく `rent`（地代的所得）として計上すべきである。**

> ⚠ **汚職は【官職という財産からの地代】である。**
> ★★★ **売官制・徴税請負・胥吏の口銭は、すべて「官職を持っていることから生じる不労所得」だった。**

★ **`rentier` が上がる ⇒ `r[0]`（伝統）が伸び、`r[2]`（自由）が死ぬ**（⚠ `(1−rentier)` が0へ）。

## ★★★ そして「制度疲労」がここから出る

```
⚠行政が足りない → ★汚職が増える → ⚠官僚が官職地代で富む → ★官僚が改革に反対する
      ↑                                                              ↓
      └──────────── ⚠行政改革が通らない ←──────────────────┘
```

★★★ **自己強化ループ＝『制度疲労』が、⚠ 国名も倍率もなしに出る。**
★ **§11-6 で消した `InstitutionalDecay` の受け皿が、これになる。**

## ★ 脱出口も自然（★ すべて法）

| ★ 手段 | ⚠ 効き方 |
|---|---|
| ★ **報道自由を上げる** | ⚠ 監視が増える |
| ★ **メリトクラシー（資格任用）** | ⚠ 縁故が減る＝官職が財産でなくなる |
| ★ **議会に予算権を渡す** | ⚠ 監査 |
| ★ **行政府を建てる** | ⚠ `AdminFill` の供給を増やす |

★★ **どれも議会を通さないと動かない。**⚠ **そして議会は、汚職で富んだ官僚が反対する。**
★★★ **これが清の洋務運動が漏れた理由の、⚠ 特例なしの表現である。**
