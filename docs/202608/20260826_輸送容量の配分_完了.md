## ★★★ 結論 — **配分では貿易は直らない**

⚠ **配分を最適化しても総量が変わらないので、貿易は増えなかった。**
★★ **＝ 均等割りは症状ですらなく、貿易については無関係だった。**

## ★★★ 真因（⚠ 作者の情報 2026-08-26）

> ★ 作者：「実は交易の原因は割と究明していて、**現在の経済モデルは供給でのみ決まり、需要により価格が高まらないため、
> ⚠「高需要をたくさん作って輸出する」モデルが成立しない**ためだ。
> ★ しかし、それを修正しても、**GDP比8%**で、まだ課題は多い（⚠ おそらく、**輸送コストが必要以上に高く、採算をとる閾値が高い**）」

★★ **本測定はこの診断を別の入口から裏づけた**——⚠ **容量をどう配っても、運びたいものが無ければ運ばない。**

★ 「輸送コストが高すぎる」の傍証（⚠ 設計環境で確認）：

```

内陸州           114 (53%)   ← ★★パリ・モスクワ・ベルリン・京都・バーミンガム・カイロ
```

⚠ **内陸53%が `InlandPortDistanceDecay` で距離減衰され、さらに `railToPort` が州数で割られる＝二重に絞られている。**
★ `Trade.cs:26` の「鉄道0なら0」（★ ユーザー指示）と合わせると、⚠ **実効的に「ほとんどの内陸が閾値未満」になっている可能性。**
