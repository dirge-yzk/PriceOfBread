# 2. 現物のアフリカ（★ 2026-08-12 実測）

## 2-1. 領土の器は3層ある

| 器 | 中身 | 個数 |
|---|---|---|
| ★**州**（`Region`） | 階級POP・市場・政治・文化・宗教・港。⚠ **軍が毎月ここから計算される** | 184 |
| ★**植民地**（`Colony`） | 住民数・蓄え・不満・識字・開発度・入植者・マラリア地。★ **州へ昇格できる**（2026-08-09実装） | 45 |
| ⚠**抽象標的**（`Power.Nation == null`） | ⚠ **名前・軍の数値・国庫・植民地リストだけ。**外交をしない・GDP0・脅威にならない | 11 |

★★ **植民地化の単位は「州」ではなく「勢力」である。** ⚠ 標的が抽象なら植民地リストを丸ごと接収し、国なら属国化する——★ **どちらの経路も州を作らないし、州を要求しない。**

## 2-2. アフリカに今あるもの

| 区分 | 中身 |
|---|---|
| ★**州を持つ国**（4） | モロッコ(3州)／エチオピア(1州)／マダガスカル(2州)／**ダホメ王国(2州)** |
| ⚠**抽象標的**（5） | バルバリ→アルジェ／アシャンティ／ソコト／コンゴ／南アフリカ（★ **各1植民地のみ**） |
| ★**既に列強の植民地**（5） | セネガル(仏)／沿岸西アフリカ(英)／ケープタウン(蘭)／ザンジバル(オマーン)／マスカリン諸島(仏) |

★★ **アフリカは無人ではない。**⚠ しかし**動く勢力は4つしかなく、残り5つは動かない器に入っている。**

## 2-3. ★ 植民地化の経路（現物）

```csharp
Diplomacy.cs  TryAiColonize：AiColonizeChance = 0.12/四半期/列強（覇権は自制で減る）
              標的は RankOf(q) == Minor・未従属・非交戦
              q.Nation is null && q.ColonyList.Count == 0 なら【無視】   ★取り尽くすと永久に対象外
              proj = Projection(距離・制海権) × ExpeditionLift(遠征技術)
              value = (植民地数 + 1 + GDP項) × proj / (1 + 標的の軍)

Diplomacy.cs  Colonize：
              willCost = InvadeWillBase(8.0) + InvadeWillPerMilitary(2.0) × 標的の軍
                         ÷ (1 + ColonizeWillSuperiorityDiscount(1.0) × max(0, force/(3×標的の軍) − 1))
              submit   = force ≥ ColonizeSubmitRatio(3.0) × 標的の軍
                 submit かつ 抽象  → 植民地を丸ごと接収（★無血併合・不満 0.3 が立つ）
                 submit かつ 国    → 属国化（SetDependency・住民に遺恨 0.3）
                 拒否              → 【開戦】
```

★★ **キニーネの実費は2箇所しかない**（全数確認）：

| 場所 | 何のコストか | 稼働 |
|---|---|---|
| `Colonial.cs`（維持費ループ） | ★**保有中**の毎期消費（`if (col.Malarial) quinineWant += MalariaQuininePerColony`） | ★**稼働中** |
| `World.cs`（`Invade` の中） | ★**取得時**（未防護の兵が疫病致死率で死ぬ） | ⚠ **§3-3 参照** |

# 3. ⚠⚠⚠ 抽象標的の3つの構造欠陥（★ 本書の中核・2026-08-12 発見）

## 3-1. ★★★ 欠陥①：軍が永久に動かない

```csharp
Diplomacy.cs  Step() 冒頭：
    foreach (var p in Powers)
    {
        if (p.Nation is not { } nw) { p.NavalShare = c.AbstractNavalShare; continue; }
        //  ★コメント：「経済を持つ国は軍/GDP/財庫を毎月同期（抽象的な外国は静的値のまま）」
        ...
        p.Military = nw.SoldierSize() / c.SoldiersPerMilitary * nw.MilitaryReadiness * (...) * techQuality;
    }
```

★★ **`.Military` への書き手は、コード全体でこの1箇所だけである**（grep 全数確認）。⚠ **そこは `Nation != null` の内側にある。**

⚠⚠⚠ **したがって抽象標的は、`world.json` に書いた `military: 0.6` を1783年から1934年まで持ち続ける。**

★ 屈服線は `3.0 × 0.6 = 1.8` で**固定**。⚠ 一方 `force` は列強の `LandPower × 投射 × 遠征技術` で**成長し続ける**。

★★★ **ある時点を境に「拒否＝戦争」が二度と起きなくなり、以後は全部が無血併合になる。**

⚠⚠ **旧稿が「譲れない条件」に挙げたアドワ（人口の大きい勢力は `target.Military` が大きくなり `submit` が立たない）は、抽象標的では原理的に成立しない。**——★ 人口を持たないので、軍が人口から出てこない。

## 3-2. ★★★ 欠陥②：取得コストが時間とともにゼロへ向かう

★ 意志コストの割引は正しい設計である——「圧倒優位なら小遠征で足りる＝議会承認が安い（砲艦外交）」。

⚠ **ただしそれは標的の軍 M が動く前提で書かれている。**

```
willCost = (8.0 + 2.0×M) ÷ (1 + 1.0 × max(0, force/(3M) − 1))
```

★★ M が固定だと、分母が `force` とともに単調に伸び続け、**止める経路が無い。**

⚠ 膨張度の上限は `ExpansionWillCap = 10`、補充は戦争熱経路 最大 0.5/四半期＋ブルジョワ経路 `0.4 × 近代ブロック`。
★ **後期には数年に1個のペースで取れる。**⚠ 試行機会は `0.12/四半期 × 列強7カ国 × 604四半期 ≒ 500回**。

⚠ さらに `MaxDependents = 8`（帝国の過伸展の上限）は `SetDependency`＝**国が標的のときだけ**に効く。
★★★ **抽象標的は `ColonyList.AddRange` なので、上限が一切かからない。**

## 3-3. ★★★ 欠陥③：マラリアの障壁を通らない

⚠ 取得時のキニーネ代価は `World.Invade`（宣戦布告の動詞）の中だけにあり、★★ **`Colonize` の屈服分岐は `RequiresQuinine` を一度も見ない。**

★ そして `Invade` 自体が：

```csharp
SelfPlay.cs  if (w.Coef.EnableActiveInvasion) TryInvade(w);
             // ★「能動侵略は既定で【廃止】（経済ゲーム＝戦争は緊張から創発）」
```

★★★ **AIは `Invade` を一度も呼ばない。**⚠ 欠陥①で屈服が既定になるので、**取得時のマラリア障壁は実質存在しない。**

★ ⚠ これは非対等ではない（プレイヤーも `Colonize` を選べば同じく回避できる）——★★ **問題は「取得時にマラリアが効く経路が事実上死んでいる」ことである。**

## 3-4. ★★ 結論：抽象標的は「数を増やす器」ではない

> **抽象標的は「取られるためだけの器」で、抵抗の実体を持たない。数を増やすと、その空洞さが N 倍になる。**

⚠ **ヴィクトリア2の空白地との違いは、名前が付いていることだけである。** ★ V2（一度きり）と V4（純粋な得）がそのまま戻ってくる。

⚠ 現状アフリカで発生しうる植民地化は、★ **抽象標的から5回＋国の属国化4回＝合計9回**（604四半期・列強7カ国で）。
★ 史実の分割は約50領域だった。

# 4. ★★★ 案A — 抽象標的を「国」へ格上げし、数カ国を足す

> **アフリカに必要なのは「空白地」でも「抽象標的の数」でもなく、Minor power として実在する【国】である。**

★ 国にすれば `Diplomacy.Step` が毎月 `Military` を再計算する——⚠ **軍が人口と技術から育ち、抵抗が生まれ、アドワが起こりうる。**

★★ 却下した代案（抽象のまま `Military` を `人口 × 世界技術水準` から出す）は §7 に記録した。

## 4-2. ★★★ 譲れない条件 — アドワが起きうること

⚠ **勢力を弱く置きすぎると walkover になり、V2 が戻ってくる。**

★★★ **1896年アドワの戦い**：エチオピアがイタリアを破り、独立を守った。★ 20世紀までアフリカで唯一、植民地化を免れた。

★ **なぜ勝てたか**（⚠ **技術で勝ったのではない**）：

| | |
|---|---|
| ★**兵力** | エチオピア約10万 vs イタリア約1.7万 |
| ★★**装備** | ⚠ **メネリク2世は仏・露から近代小銃を輸入していた**（＝技術は買える） |
| ★**補給** | イタリアは遠く、山岳で、地図が誤っていた |

★★ **この3つは全部、現物の機構が既に持っている**——ただし**国にしたときだけ**：

```
Diplomacy.Step  p.Military = SoldierSize()/SoldiersPerMilitary × 即応度 × 装備充足 × 結束 × 軍国 × techQuality
                techQuality = TechMilLowFloor + (1 − TechMilLowFloor) × Clamp(TechLevel/TechMilFullLevel, 0, 1)
                                ★低技術でも【床】がある＝アヘン戦争の非対称として設計済み
Diplomacy       proj   = Projection(距離・制海権) × ExpeditionLift(遠征技術)
Diplomacy       submit = force ≥ 3.0 × target.Military      ★軍が大きければ屈服しない
```

★★★ **アドワは特例でなく、人口と距離の帰結として出る。**⚠ **したがって、置く国の人口を史実に忠実に置くことが唯一かつ最重要の作業である。**
