# 3. 設計

## 3-1. ★ 資本移動の法（2値）

```
資本移動  [自由 ／ 規制]
```

★ 既存の `PolicyAxis` に1本足す。⚠ **政治ゲート・議会の綱領・勢力の要求は、既存の機構がそのまま受ける。**

### ★★ 賛否は保有から創発する（⚠ 新しい選好を書かない）

| | 立場 |
|---|---|
| ★**資本家・投資家** | ⚠ **自由を望む**（★ 海外へ投資でき、海外から資金を呼べる） |
| ★**国庫** | ⚠ **状況で割れる**——★ 借りたいときは自由、⚠ **資本逃避が起きているときは規制** |
| ★**地主・労働** | ⚠ **規制を望む**（★ 資本が国内に留まれば国内の雇用と地価を支える） |

★★ **`PolicyPreferences` の既存の書き方（保有から導出）に従う。** ⚠ **新しい選好の型を作らない。**

### ⚠ 効き先＝`CapitalOpenness` の導出を差し替える

```
現行  openness = Clamp(1 − CapitalOpennessTariffWeight × Tariff, …)
新    openness = 資本移動の法（自由=1 ／ 規制=CapitalControlOpenness）
```

★★★ **関税との連動を切る。** ⚠ これで「**関税は高いが資本は自由**」（★ 19世紀後半の独・米）が表現できる。

⚠ **完全にゼロにしない**（★ 密輸と同じ理由——★★ 規制しても抜け道はあった）。

## 3-2. ★★★ 金利を「レバー」から「帰結」へ

### ★ 3つの状態

| 兌換 | 資本移動 | ⚠ 金利 |
|---|---|---|
| ★**維持** | ★**自由** | ⚠⚠ **操作不能。** ★★★正貨のカバー率を守るために自動で動く |
| ★**維持** | ⚠**規制** | ★ **操作できる**（⚠ ただし外資が来ないので国債の調達が細る） |
| ⚠**停止** | ★**自由** | ★ **操作できる**（⚠ ただし為替が動きインフレになる） |
| ⚠**停止** | ⚠**規制** | ★ **操作できる**（★★ 戦間期の型。⚠ 交易も投資も細る） |

★★★ **選べないのは1つだけ**——⚠ **「兌換維持 ＋ 資本自由」のときだけ金利が自分のものでなくなる。**

★ これが史実である：⚠ **誰も「金融政策の自律」を選ばなかった。** ★★ 金本位と資本移動を選び、**金利が自分のものでないことを発見した。**

### ★★ 自動則（⚠ 新しい概念を置かない）

```
兌換維持 ＋ 資本自由 のとき：
  ★正貨のカバー率が目標を下回る → 金利を上げる
  ★カバー率が十分     → 金利を下げる
```

★★★ **これで既存の配線がそのまま受ける**：

```
金利↑ → ★PolicyRateCapitalDraw で外資（正貨）が来る → ★★カバー率が戻る → 金利が下がる
```

⚠ **自己安定する。** ★ 目標カバー率は既にある（`ConvertibilityCoverageBand`）。

### ★ UI（⚠ 思想⑦）

```
政策金利  ▓▓▓░░  32%   ⚠【操作不能】
```

★★ **スライダーは残すが、掴めなくする。** ⚠ **消してはならない**——★ 「いま金利がいくらか」は見えている必要があり、★★★ **見えているのに動かせないことが、トリレンマの体感そのもの**である。

⚠ **説明文は書かない**（思想⑦）。★ 掴めないことと、兌換・資本移動の法の状態が並んでいれば足りる。

## 3-3. ★★★ そして「離脱の決定」が本物になる

⚠ **金利が欲しければ、兌換を停止するか、資本を規制するしかない。**

| 選択 | 代価 |
|---|---|
| ⚠**兌換を停止する** | ★ 金利は自由。⚠ **国債金利の兌換割引（4割引）を失い**、⚠ 為替が動きインフレになる |
| ⚠**資本を規制する** | ★ 金利は自由。⚠ **外資が来ないので国債の調達が細る**（⚠ 資本逃避も止まるが、流入も止まる） |
| ★**両方を保つ** | ⚠ **金利を諦める** |

★★★ **1931年に英国が金本位を離脱したのは、金利の自由（＝景気対策）を取るためだった。** ★ その決定が、この3行から出る。
