### 2-1. 既存の是正が効かない理由

`CapitalAbsorptionBlend`（2026-08-02）と `CatchupAbsorptionBlend`（2026-07-10）は
**まさにこの症状**（「1913年の工業化がダホメ4.02〜英3.56と全球で密集」）に対する是正で、
どちらも既に 1.0 で点火済みである。にもかかわらず効かないのは、**掛けている吸収能力が
識字×報道自由しか測っていない**ため。ダホメ王国は識字57%・報道自由なので吸収 = 1.0 で素通りする。
是正の**形**は正しく、**測っている量**が足りていない。

### 2-2. 副次的に見つかった逸脱

- **立憲君主制は報道が中間段（`FoundingPress`）** ＝ 英型は構造的に吸収0.75止まり。
  共和政の小国（報道自由1.0）に対して恒久的に不利。史実の主導的工業国の政体が罰を受けている。
- **アメリカが報道自由から検閲へ退行**（初期値 FreePress → 1923年 Censorship）。
- **アメリカの識字28%** ＝ 主要国で最低。史実は逆に最高水準。
- **日本が140年間 宗教教育のまま**＝技術0.17。明治維新が一度も起きない。
- 報道自由化の選好は「旧支配層が抵抗・近代/大衆が賛成」（`PolicyPreferences`）。
  貴族層の厚い大国ほど改革できず、失うもののない小国ほど自由に改革できる。史実と逆向き。

## 3. 実装（休眠・厳密恒等）

`TechEducation.AbsorptionOf` に経済側の項を、革新項に規模の項を足した。既定はどちらも不走行。

| 係数 | 既定 | 意味 |
|---|---|---|
| `AbsorptionIncomeWeight` | 0.0 | 吸収能力に1人あたり所得を入れる重み |
| `AbsorptionIncomeRef` | 0.0 | 吸収が満点になる1人あたり所得（0で不走行） |
| `ResearchScaleWeight` | 0.0 | 革新を研究基盤の絶対規模でスケールする重み |
| `ResearchBaseRefPop` | 0.0 | 研究基盤の参照人数（この規模で倍率1.0＝恒等点。逓減は平方根） |

`AbsorptionIncomeRef` は技術と資本の**両方**の吸収に効く（同じ写像を2箇所に書き分けない＝既存の設計方針）。

**1783年の開始状態は正しく並んでいる**（イギリスの工業化1.11がダホメ王国0.08の14倍・所得格差は約4倍）。
それが10年で壊れる：

1. **所得格差が4倍→1.5倍へ収束**（2.89〜0.76 → 4.78〜3.18）
2. **先進国の識字が下がる**（ネーデルラント56→23・アメリカ60→38・プロイセン55→34・イギリス49→39）
3. **後進国の識字が上がる**（ラオス26→44・モロッコ28→41・ヒヴァ33→42）

先進国の識字低下は人口の希釈である。`PopDecision.cs:81` は移住先の識字を
`(dst.Literacy*dst.Size + src.Literacy*amount)/newSize` で加重平均する＝**非識字の流入が平均を薄める**。
これは物理として正しいが、規模が壊れている：

| 国 | 1783年 人口k | 1793年 人口k | 10年の倍率 |
|---|---|---|---|
| ネーデルラント | 2,429 | 5,198 | **×2.14**（年8.3%） |
| アメリカ | 4,419 | 10,542 | **×2.39**（年9.6%） |
| イギリス | 15,980 | 18,678 | ×1.17 |
| フランス | 30,628 | 31,802 | ×1.04 |
| ロシア | 30,548 | 24,442 | **×0.80** |

小さくて豊かな国が移民の吸い込み口になり、10年で人口が倍化して自分の識字を破壊している。

### 4-2. 因果の連鎖（確定）

```
開始10年で所得と人口が共通のアトラクタへ収束
   → 先進国の識字が希釈で下落／後進国の識字が上昇
   → Elite（＝識字×世俗水路）が横並び
   → 技術は Elite と法だけの関数なので横並び（52/60カ国が3.0〜4.2に密集）
   → 工業化・GDP・満足度も横並び
   → 国力スコアの上位12カ国が13%以内に密集
   → 列強クォータ（上位7）が雑音で決まる ＝ ヒヴァ・ラオス・ダホメ王国が列強
```

技術の吸収に経済を入れる（§3）のは**症状の側**であり、根は「開始10年の収束」にある。

## 5. ★★真の根：モロッコがイギリスを完膚なきまでに叩き潰している

多エージェント調査（読み取り専用・反証2票つき）の副産物として、**イギリスが検閲に留まる理由が判明した**。

```

   → 英の吸収能力が恒久的に0.75倍（技術側の press 係数）
   → 一方 勝者側は自由報道の共和国として先端へ
   → 技術・工業化・所得・スコアが横並び
   → 列強クォータがヒヴァ・ラオス・ダホメ王国を選ぶ
```

→ `BourgeoisCoupNeedsCrisis = 1.0` を追加（0で旧挙動）。新しい閾値は増やさず、既存の危機ゲートを共有する。
