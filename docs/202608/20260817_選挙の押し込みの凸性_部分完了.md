# 1. ⚠⚠ 「代価を逓増」は外科的だった

| ⚠ 代価を逓増 | ★ 便益を逓減 |
|---|---|
| ⚠ **「強く押すと罰せられる」** | ★ **「強く押しても効かなくなる」** |
| ⚠⚠ **ペナルティの導入＝外科的** | ★★ **収穫逓減＝自然法則** |

★★★ **本プロジェクトの共通言語は明らかに後者：**

```
★NationalScore   gdpScale /= 1 + gdpScale / 12      ⚠経済規模の逓減
★軍事項          MilitaryDiminishingCap = 12         ⚠同上
★寡占マークアップ  μ = 1 + Max / EffFirms             ⚠供給者が増えると1へ漸近
★価格の在庫ギャップ (Target−Stock)/(Target+Stock)     ⚠自己有界
★軍事投射        1 / (1 + km/10000)                  ⚠距離減衰
★工業の限界収益   Gain / (sat × sat)                  ⚠逓減
★近代化投資      demand/(1+demand/half)              ⚠ソフト逓減（2026-08-16）
```

⚠ **「代価を歪める」形は、★ この中に一つもない。**

# 2. ⚠⚠⚠ そして逓増には、**設計意図と逆の穴**があった

★ **作者の設計意図（⚠ 9b・2026-08-14）：「全て工作できて良いが、★ 3つ行うと非常にコストがかさむ」**

⚠ **代価が看板ごとに別々に逓増すると：**

```
★1つの看板を全力で押す      → 代価 c × 1.0² ＝ c
★3つの看板を3分の1ずつ押す  → 代価 3 × c × 0.33² ＝ 0.33c   ⚠押し込みの合計は同じ
```

★★★ **薄く広く撒くほうが3分の1で済む＝作者の意図と逆。**

⚠ **さらに、べき乗は原点付近がほぼ無料になる**（★ k=1 で強さ0.1の代価は線形の1割ではなく**1%**）。

# 3. ★★★ 確定形（★ 作者案）

```
★レバー   ＝ 裁量余剰の何%を注ぐか       ⚠他の支出と同じ土俵に乗る
★投入額   ＝ 裁量余剰 × レバー%
★効き     ＝ 投入額から逓減で（⚠割らない・★下記）
★金の代価  ＝ 投入額そのもの（⚠曲げない）
★正統性   ＝ 世論に逆らった度合い（⚠2026-08-14 の裁定「世論が既にその向きなら0」）
```

## ★★★ ① 予算の取り合いに入ることが本質

⚠ **今の「強さ」は、他の何とも比べられない独立した数値。**
★★ **「裁量余剰の何%」にすると、⚠ 軍事費・教育費・福祉と【同じ物差し】に乗る。**

★★★ **政治工作に注いだ分だけ、⚠ 他が減る。**

## ★★ ② 「極端が有用なのは限られた状況」が**機会費用から出る**

| ⚠ 局面 | ★ 収入の50%を注ぐのは |
|---|---|
| ★ **平時** | ⚠ **狂気**——★ 軍も学校も止まる |
| ⚠ **政権が倒れそう** | ★★ **合理的**——⚠ 生き延びなければ何も残らない |

★★★ **新しい機構ゼロ。⚠ 罰を作らずに「振り切りが正解になる局面が限られる」が実現する。**

## ★ ③ 効きは【額面通り】に見る（★ 割らない）

> ⚠ **作者「効果は注入額のままでよい。★ 大国は必然的に人口が多い。**
> ★★★ **そもそも社会保障は直接のバフではなく医療の代理購入などの筈だから、そのまま額面通り渡してよい」**

⚠ **「収入で割れ」は二重正規化になる**——★ **金は財を買い、⚠ 大国は人口が多いので一人あたりが薄まる＝市場が自動で正規化する。**
★ **既存の実装がその形**（⚠ `adminNeed = AdminNeedPerPop × 人口`）。

## ★ ④ 逓減の形

```
★効き ＝ 投入額 / (1 + 投入額 / s)
```

| ★ | ⚠ 理由 |
|---|---|
| ① | ★★ **`gdpScale /= 1 + gdpScale/D` と同じ型**——⚠ 既にある形 |
| ② | ★ **自己有界**（⚠ 上限へ漸近＝思想⑧の条件②） |
| ③ | ⚠ **原点の傾きが1**——★ **微小に押すのが異常に得、にならない** |
| ④ | ★★★ **`s` を大きくすると線形に戻る＝ビット恒等**（⚠ 思想③を満たす） |

⚠ **`log` は上限がないので②を満たさない。**
⚠⚠ **`強さ^m (m<1)` は避ける**——★ **原点の傾きが無限大＝ごく弱い押しが異常に効く。**

## ★ ⑤ 「3つ押すと高い」は**固定費**で

```
★代価 ＝ 看板ごとに（固定費 ＋ 投入額）
             ↑⚠3つ押せば固定費が3倍
```

⚠ **強さは罰されず、★ 手を広げることだけが高くなる。**
★★ **意味も自然**——⚠ **政治的な注目は有限で、★ 3つの争点に同時に手を出すと薄まる。**

⚠ **ただし「裁量余剰の何%」という予算制約が既にあるので、★ 固定費は要らないかもしれない**（⚠ 3つ全部を強く押すには収入の大部分が要る）——★ **実測で判断。**

# 8. ★★★ 実装（2026-08-17 夜・実装側）——**§3 の確定形をそのまま入れた**

★ **§1〜§3 の裁定どおり、⚠ 代価は曲げず・★ 効きを曲げた。**
⚠ **前任の「代価の逓増」（`ElectionPushCostConvex`）は §7d に従って撤去した**（★ 休眠のまま残さない＝二重化の芽を潰す）。

## ★★ 8-1 確定形（⚠ 実際の変数名）

```
★レバー   ＝ World.ResolveElection(ideology, lever) の第2引数（0..1）
              ＝ ⚠【裁量余剰の何%を注ぐか】（旧「0..1の押す強さ」ではない）

★投入額 A ＝ World.ElectionSpendOf(lever)
              ＝ Clamp(lever,0,1) × World.FiscalCapacity        ⚠余剰0の国は1銭も注げない

★半減点 h ＝ World.ElectionPushHalfPoint()
              ＝ Coefficients.ElectionPushHalfPerVoter × 有権者数 × (NominalGdp ÷ TotalPopulation)
                 ↑⚠新設した係数はこの1本だけ（§7dの撤去と差し引き±0）
                 有権者数 ＝ Σ pop.Size × InterestGroups.FranchiseVoice(pop, Suffrage, Coef)
                            ＝ ★Parliament.ComputeVotes が議席を数えるのと**同じ重み**

★効き e   ＝ World.ElectionPushEffectOf(lever) ＝ A/(A+h) ∈[0,1)
              ＝ ⚠作者裁定 §3-④の A/(1+A/h) を半減点で無次元化しただけ（★A=h で e=0.5）

★金の代価 ＝ **A そのもの**（曲げない）
              World.Pay(TreasuryCat.OtherOut, −A) → Pay(OtherOut, DistributeToVoters(A))

★正統性   ＝ net≥0 → 0（⚠世論が既にその向き＝2026-08-14の裁定のまま）
              net<0 かつ |net| > 余白(MandateWeight×(Legitimacy−0.5)) → **不成立**（⚠金も1銭も払わない）
              それ以外 → Legitimacy −= |net| × e     ⚠**効きに比例**（実際に押し込んだ分だけ払う）

★得票     ＝ Parliament.ComputeVotes：(1 + World.ElectionPushStrength × ElectionPushScale) 倍
              ⚠**ElectionPushStrength に入るのは e（効き）**であってレバーではない
```

⚠ **口は1つのまま**——★ プレイヤー（UIのボタン）もAI（`UtilityAgent.DecideElection`）も `World.ResolveElection` を通る
＝⚠ 余白判定・金の支払い・正統性・記帳の**すべてが同一命令列**（★ ON経路テストがビット一致で番をしている）。

## ★★★ 8-2 未決 7a の解決 — **半減点は「有権者1人あたりの単価 × 有権者数」**

⚠ **作者裁定は「効きは額面通り＝収入で割るな」（§3-③）。★ だが半減点まで絶対額にすると壊れる：**

| ⚠ 半減点の置き方 | ★ 何が起きるか |
|---|---|
| ⚠ **絶対額**（全国共通の定数） | ⚠⚠ **大国は常に漸近線の上**＝どれだけ注いでも効きは1付近＝**振り切りが再び最適**／★ 小国は永久に押せない |
| ★★ **有権者1人あたりの単価 × 有権者数** | ★★★ **「有権者1人にいくら配れたか」で効きが決まる**＝⚠ 規模中立 |

★ **これは「収入で割る」ではない**（⚠ 二重正規化ではない）——★ 分母は**買う相手の頭数**であって国家の収入ではない。
★★ **既存の同型がプロジェクトにある**：⚠ `adminNeed = AdminNeedPerPop × 人口`（★ 裁定 §3-③ が名指ししている形）。
⚠ **票を買う相手は人口ではなく有権者**なので、錨は人口でなく**有権者数**（★ `FranchiseVoice` 加重＝議席の数え方と同一の重み）にした。

★ **副産物（狙って選んだ）：⚠ 参政権が広がるほど選挙は買えなくなる。**

```
★腐敗選挙区（制限選挙・有権者が人口の3〜8%）  → ⚠半減点が小さい＝安く買える
⚠大衆民主制（有権者が人口の55%〜）            → ★半減点が10倍以上＝**買収は事実上不可能**
```

## ★★ 8-3 AI（`SelfPlay.DecideElection`）——**機会費用で決める**

⚠ レバーの意味が金になったので、★ AIも「押したいか」でなく**他の支出と比べて**決めるように差し替えた
（⚠ 新しい観測はゼロ・★ AIが既に読んでいる量だけ）：

```
★レバー ＝ 切迫 × (1 − 逼迫) ÷ (1 + 紛争記憶 MandateSpent)

★切迫  ＝ 与党（族）の得票が不信任線 NoConfidenceThreshold にどれだけ近いか
           ⚠線の2倍の得票で0（平時）・線に触れて1（倒れる寸前）＝**既存の線そのものを目盛りに使う**（新しい閾値なし）
★逼迫  ＝ UtilityAgent.FiscalStressOf（⚠国庫が維持費・利払い・行政・軍装備の請求書の何か月分か）
           ★1に近い＝軍も行政も払えていない＝選挙に注ぐのは狂気
```

★ **余白（マンデート）は「そもそも動かせるか」の門としてだけ使う**（⚠ `price=|純支持| ≤ margin`）
＝★ 押しの大きさは金の予算制約が決める＝⚠ **二重に使わない**（§7d と同じ規律）。
⚠ 旧 `AiElectionMandateBudget`（余白の何割を賭けるか）は**撤去**＝役目が消えた。

★ 看板の選択＝`align × (1 − price/margin)`（⚠ 同じ額なら効きは看板によらない＝金の代価は曲がらないので、
★ 選ぶ基準は「望みの強さ」と「食い潰す余白」だけ）。⚠ 余白0でも**無償の看板は押せる**（price=0 で割引1）。

★ 実測（⚠ 点火・6カ国300四半期）：
