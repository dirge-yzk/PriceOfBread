# 3. ★★★ ②主犯は生存効用（教義でも緊張でもない）

```

⑤ 最終断面で軍備が勝っている国 60/61。その項を0にしたら降りる国の数：
   教義底上げ 1 ／ 緊張項 8 ／ 植民地防衛 0 ／ **生存 36** ／ 教義と緊張の両方 37
```

★ **生存効用だけが単独で36カ国を軍拡に縛っている。** 教義底上げ（2.5）を消しても1カ国しか降りない。

## 3-1. ⚠⚠ 生存効用は「脅威に応じた軍拡」ではなく、事実上の**定数4.5**である

```csharp
// SelfPlay.cs:391-399
ratio    = maxReach / Math.Max(1e-9, spS.Military);
survival = SurvivalMilitaryWeight * Math.Clamp(ratio - SurvivalThreatRatio, 0, 3);   // 1.5 × clamp(ratio−1.5, 0, 3)
```

上限は **4.5**。実測の平均は 3.9〜4.2 で、**131年間ずっと飽和帯**にある。⑥がその理由を出した：

```
⑥脅威の出所
  1788年: 清 60カ国から最大脅威と見なされる（比の中央値 20.5）
          脅威比 四分位 12.9 / 中央 20.4 / 31.9   最大 5470万   閾値1.5未満の国 2/61
  1863年: シク連邦 36カ国 ／ ポーランド 11カ国 ／ ルーム 11カ国
          脅威比 四分位 7.8 / 中央 75.6 / 309.0   最大 337万
  1933年: 清 60カ国（比の中央値 398.1）
          脅威比 四分位 10.4 / 中央 257.1 / 1796.9   最大 **141億**   閾値1.5未満の国 4/61
```

★ 閾値は **1.5**。中央値が20〜257、最大が141億。⇒ `clamp(ratio−1.5, 0, 3)` は**開幕から最終まで上限3に張り付き**、
生存効用は恒久的に 4.5。**脅威の大きさの情報は完全に潰れている。**

⚠⚠ **これは「比のガードを絶対値で書かない」の再発である。** `Math.Max(1e-9, spS.Military)` という極小の床は、
自国の軍事力が痩せた瞬間に比を天文学的な値へ飛ばす（実測 1.4×10¹⁰）。そして飛んでも飛ばなくても clamp が同じ 4.5 を返すので、
**バグが結果に現れず、常時ONの定数として静かに生き続けていた。**

## 3-2. ★★ なぜ自国の軍事力が痩せるのか＝装備がフローだから（監査で確定）

`MilitaryReadiness = 士気充足 × 装備充足` には **EMA も床も無い**（`Military.cs:216`）。
装備充足 `MilitaryEquipFill` は `equipGot/equipWant` ＝ **その月に首都市場で買えた比率**（`EconomyStep.cs:1839`）で、在庫の概念が無い。
⇒ **1ヶ月の調達失敗が全軍を消す。**

これが `armyshape long` の異常値の正体でもある：

| 断面 | アメリカ | イギリス | 清 |
|---|---|---|---|
| 1850年 | 海0.00 / 陸0.00 | 海0.01 / 陸0.01 | 海0.02 / 陸0.07 |
| 1914年 | 海0.00 / 陸0.00 | 海1.35 / 陸0.96 | **海31.25 / 陸23.24** |

★ 陸海が**同時にちょうど0**になるのは `Military` 自体が潰れているときだけ（艦隊要因なら陸は残る）＝監査の指摘と一致。

## 3-3. ⚠ 第二の錠：軍は自分の削減に拒否権を持つ

`Government.Move` は純支持が負なら**その向きへ一歩も動かない**硬いゲートで（`Government.cs:536`）、
純支持には `ArmyPower(w) × ArmyStake(a) × sign` が入る（`PolicyPreferences.cs:606`）。
削減方向は sign=−1 なので、**軍の政治力がそのまま削減への反対票**になる（`ArmyPower = 5.0 × 兵士比 × (1−議会統制)`）。

⚠ ただし**いまは効いていない**。AIが削減を望んだ回数がほぼ0（30断面で延べ1回）だからである。
⇒ **第一の錠（スタンス）を外した瞬間に、この第二の錠が現れる。** 順序を間違えると「直したのに動かない」になる。

# 4. ★★★ ③理想の軍隊は発散していない。むしろ誰も読んでいない

実兵数÷理想兵数（`NeedMen`）＝ **15.7（前半平均）→ 1.9（後半平均）**。乖離は**縮んでいる**。
ただし縮んだのは軍が理想に寄ったからではなく、**理想の方が実態に追いついた**から。理想の1.2倍超の国は 58/61 → 15/61。

理由は明快で、**理想は兵数の決定に25%しか混ざっていない**（`ArmySustainWeight = 0.25`）。残り75%は「軍事費スライダー×人口」。

## 4-1. ⚠⚠ 「海軍国度」が2つあり、金と装備が別々の式で動く

| 量 | 材料 | 何を駆動するか |
|---|---|---|
| `ShapeNavalShare` ＝ `NeedSea/総必要` | 理想の軍隊の形 | **軍需調達**の陸海再配分（`EconomyStep.cs:792`） |
| `Diplomacy.GeoNavalShare` | **地理だけ**（外洋に開くか＋植民地数） | **維持費（金）**の陸海配分（`SelfPlay.cs:831`） |

★ 監査が算術で裏を取った：**1914年の日本の支出海比 0.214 は「地理0.20 → 5%刻み量子化 → 0.15/0.70」で小数第3位まで再現できる。**
一方その時の理想海比は **0.554**。⇒ **金は陸軍へ、装備は海軍へ。** これは再発バグ型（分子と分母の非対称）の同型である。

⚠ さらに **`SeaEscortPerTradeValue = 0.0`＝護衛項はいまも未点火**。理想海比は「守るべき海上価値」ではなく注意配分の残りだけでできている。
⇒ 「英の海軍が世界最大になるか」を決める唯一の較正点が、一度も入っていない。実測の艦隊ストックは **1位 清 611261 ／ 2位 内モンゴル 215593 ／ 7位 イギリス 80213**。

## 9-3. ⚠⚠ 最初の設計は間違っていた（差し戻した）

★ 旧設計＝**発注と見積を「目標在庫との不足分」にした**。これは硬性ゲートを赤にした。

```
ハノーファーの名目産出（seed5）   Q40    Q160   Q200   Q240   Q320
  基線（フロー）                  3451   6428   6969   7268   8248
  旧設計（不足分を発注）          3593   6957   2723    533    441
```

⚠ Q200 の時点で**装備充足は 1.000**だった＝**国庫を装備の穴埋めに注ぎ込んで経済ごと潰していた**。
実測 `損失financing 115.5%`（閾値35%）＝硬性ゲート赤。基線では seeds 1〜5 で床割れが1件も出ない。

★★ 機構＝在庫が目標を割ると「不足分」が `estCost` を34倍に膨らませ、`afford` を34分の1へ潰す。
ところが `afford` は**基本段の全財で共有**なので、**弾薬まで巻き添えで絞られる**。
装備↓→不足↑→afford↓→装備↓ の**正のフィードバック**。
⇒ **再発バグ型そのもの**（比の分子を変えて、その比を誰が読んでいるかを確かめなかった）。

## 9-4. ★★★ 正しい形＝発注は1ビットも変えない。変えるのは**測り方だけ**

```
目標在庫 = 平時規模 × レート × 陸海の再配分 ÷ 摩耗率
充足     = min(在庫, 目標) ÷ 目標          （「その月に買えた比率」ではなく）
```

★ 摩耗は `warWear = 0.02 × 戦時倍率` なので **摩耗 × 目標 ＝ 従来の発注量**が恒等的に成り立つ。したがって

```
定常： 在庫 = 納入/摩耗 、 目標 = 発注量/摩耗  ⇒  充足 = 納入/発注量 ＝ **従来の充足と厳密に同じ値**
```

⇒ **違いは時定数（1/摩耗 ≒ 50ヶ月）だけ。** 「1ヶ月の調達失敗で全軍が消える」が「数年かけて劣化する」になる。
予算・需要・価格・戦時の軍需ブームは一切触れていない。⚠目標には**陸海の再配分を必ず掛ける**（E1と同型の非対称を作り直さない）。

# 10. ★★★ ②生存効用の飽和の是正 — **点火**（2026-08-26）
