# 2. ★★ 全数調査の方法（⚠ 網の設計）

⚠ 2026-08-17 の「支出から直接バフを排除する」では**網に穴があった**（★ 「支出→バフ」を探して「法/州の状態→バフ」を見落とした）。
★ 今回は**4つの形すべてに網を張った**：

```
★形①  if (状態 >= 係数) 効果            ← ⚠最も明白
⚠形②  if (フラグ) 効果                 ← ★フラグがどこで立つかを追う（Institutions が典型）
★形③  x > y ? A : B                   ← ⚠二値分岐
⚠形④  Math.Max(0, x − 閾値)            ← ★値は連続だが【傾きが不連続】
```

## 2-1. ⚠ 除外した3つ（★ 理由つき）

## 2-2. ★★★ 作者裁定による絞り込み

> ⚠ 作者：「**状態→効果の閾値 これは廃止する。★ 行動の可否ゲート→これはそのままで良い だいたいはAI挙動なので**」
