# 1. ★★★ 作者設計

> ★ 「まず国を置く。例えば中国。この中国州は明らかに大きすぎる。なので、適切な閾値になる州の数を考える。
> ⚠ すると北京や上海、あといくつかの州ができる筈だ。**順番は有名な順で良いだろう**。
> ★ すると、**面積ルールに反するものが出てくる。一定以上の空白は許容しない。**
> ⚠ 満州や、開発度の低いベトナムの北部などが空白になる筈だ。これはルール違反なので、州が置かれる。
> ★★★ これを繰り返すと、おのずと**領土と経済規模を両立した州配置**になるのではないか」

★★ **重要な性質：これは【実行時の機構】ではなく【データを作る規則】。**⚠ **マップシステムも実行時のコードも変えない。**

## 1-1. ★ 1つの規則で「分割」と「空白埋め」が両方できる

```
★規則：陸地上のどの点からも、最寄りの州都までの距離が閾値を超えてはならない
   ⚠超える点がある → そこに州を置く
   ★「大きすぎる州」＝その州の中に州都から遠い点がある ＝ 同じ違反
```

⚠ **分割と追加が同じ操作になる。**★ 繰り返せば収束する。
★★ 「有名な順に置く」は初期配置の順序で、⚠ **最終的な配置は初期順序にあまり依存しない**（★ 空白が埋まるまで繰り返すため）＝**主観の影響が小さい。**

## 1-2. ★★★ 「人口が無い所にも置く」（⚠ 作者裁定）

> ★ 作者：「人口が無い所に州を置いても意味がない、いや、**それでも置くべきだと思う。
> 置かないルールより、置くルールの方が一貫性がある**と思う」

★★★ **正しい。**⚠ 「サハラには置かない」は**誰かが「サハラは例外」と判断すること**＝思想②（外科的・国別特例の禁止）に触れる。

★ **機能的にも「置く」ほうが良い理由：**

| ★ | ⚠ 内容 |
|---|---|
| ★ **害が無い** | ⚠ 人口 share が 0.001 の州は**何も起こさない**だけ |
| ★★ **領土が連続する** | ⚠ 今は「州が無い＝土地が無い」。★ 置けば**サハラを通って侵攻する**が書ける |
| ★★★ **植民地化の対象になる** | ⚠ **アフリカ分割は無人の土地を線で分けた行為**。★ 州が無ければ分けられない |

# 4. ⚠⚠ 代償（★ 測定済み）

## 4-1. ⚠ `Pops.Count` が変わる＝**厳密恒等が原理的に取れない**

★ 2026-08-17 の記録：⚠ **「`Size=0` の空POPも無害でない（`Pops.Count` がループ長に効く）」**
★★ **＝ 州を増やすと POP が増え、⚠ 全世界の軌道が動く。一発勝負になる。**

⚠ ただし**前例はある**——★ 2026-08-12 の「アフリカ植民」で抽象標的を国へ格上げし6カ国追加している。

## 4-2. ⚠⚠ 計算時間（★ 実測 2026-08-26）

```
100四半期 : 181 秒
200四半期 : 342 秒     ← ★きれいに線形
                        ⚠1四半期あたり 1.7 秒
                        ⚠★1試合（604四半期）≒ 17 分
```

★ `selfplay-batch 10` は**並列実行**なので、⚠ 10試合でも1試合ぶんの時間で済む（★ 実測10分 ≒ 500四半期の14分と整合）。

★★★ **交易が唯一の二乗項**（⚠ `BilateralMarket` のコメント：「交易主体＝**全active州**。距離は下の**対ごと**に引く」）：

```
216州 →  46,656 ペア
500州 → 250,000 ペア   ⚠5.4倍
350州 → 122,500 ペア   ★2.6倍
```

⚠ **500州なら1試合60〜75分**（★ 交易が全体の5〜7割として）。⚠ **試行回数が1/4になる。**
★ **350州なら1試合30〜35分**＝⚠ 許容範囲。

## 4-3. ⚠ 「粒度を下げる」案の評価（★ 作者提案）

> ★ 作者：「500州にするとして、**計算に値しない州は、月ごとに計算するなど粒度を下げる**ことはできるか」

| ★ 案 | ⚠ 帯への影響 | ★ 効き |
|---|---|---|
| ⚠ **A: 容量ゼロのペアをスキップ** | ★★ **厳密恒等** | ⚠⚠ **効かない**（★ §4-4 で実測） |
| ★ **B: 頻度を下げる（月→四半期）** | ⚠⚠ **帯が動く**（★ 近似になる） | ★ 確実に3倍 |
| ★★ **C: 州数を350前後に抑える** | ⚠ 南米は埋まるが、★ サハラ等は粗いまま | ★ 二乗が2.6倍で済む |

### ⚠⚠ A が効かない理由（★ 実測）

```
港州（coastal）  102 (47%)
内陸州           114 (53%)   ← ★★パリ・モスクワ・ベルリン・京都・バーミンガム・カイロ…
```

⚠ **内陸州は「辺境」ではなくヨーロッパの中心そのもの。**★ **「交易容量が厳密にゼロだからスキップできる州」はほとんど無い。**

### ★ B をやる場合の必須条件

⚠ **交易はランク分類と性質が違う**（★ 間引くと**在庫が溜まる**）。⚠ 「3か月分をまとめて1回で処理する」形にしないと保存則が壊れる。
★★★ **そして「どの州を粗くするか」の判定は【片道ラチェット】にすること**：

```
⚠粗い → 細かい は許す（★開発されたら細かくなる）
★細かい → 粗い は禁止
```

⚠ 閾値の前後で出入りすると**不連続に飛ぶ**——★ 2026-08-13 の記録「**2式が拮抗する国で支配側が切り替わるたび値が不連続に飛ぶ（軍の3回目の失敗の原因）**」と同じ罠。
★ `TreatyPortLapse` が「片道ラチェット」と明記しているのが作法の前例。
