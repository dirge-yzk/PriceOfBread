# 1. 現物（2026-08-12 の座標・§7 で再取得すること）

## 1-1. ★★★ 戦勝点は「押し合いの差」で動く。攻守の区別は無い

```csharp
Diplomacy.cs:2005  double aPush = war.A.LandPower / Math.Max(1, fronts[war.A]) * fundRatio[war.A]
                                 * Projection(war.A, war.B, c) * landP
                                 * (1.0 + c.AirControlPushWeight * (acP − 0.5));
Diplomacy.cs:2006  double bPush = war.B.LandPower / … * (1.0 + c.AirControlPushWeight * (0.5 − acP));
Diplomacy.cs:2011  war.Score = Clamp(war.Score + c.WarPushSpeed * (aPush − bPush) + luck, −CollapseScore, CollapseScore);
```

★ `aPush` の中身：**陸戦力 ÷ 戦線数 × 戦費充足 × 投射力 × 陸の係数 × (1 ＋ 制空権の項)**

★★★ **ここに「制空権が押しを増減させる」項が既にある**（`AirControlPushWeight`）——⚠ **本設計はこれと同じ形を使う。新しい作法を作らない。**

## 1-2. ★ 装備の充足率は「段ごと」に取れる

```csharp
EconomyStep.cs:1625  region.MilitaryEquipFill   = 基本装備の充足

EconomyStep.cs:1660  region.MilitaryTier3Fill   = tier3の充足        ★戦車・弩級戦艦
EconomyStep.cs:1678  region.MilitaryAirFill     = 空軍装備の充足
```

Coefficients.cs:1391  MilitaryTier3Goods   = [122, 123];   // ★戦車・弩級戦艦

⚠⚠ **重要な制約：機関銃と装甲艦が同じ段、戦車と弩級戦艦が同じ段にある。** ★★ したがって**「機関銃だけの充足率」「戦車だけの充足率」は、現状では取れない。**

## 1-3. ⚠ 現状で何が起きていないか

★ 陸戦の押しは「陸戦力 × 戦費 × 投射力」だけで決まる。⚠ **装備の世代が押しの【向き】を変えない。**

★★★ **したがって、1914年の戦争は1870年の戦争と同じ速さで決着する。** ⚠ 塹壕戦の膠着も、それが生んだ厭戦と革命も、構造として出ない。

# 3. 設計

## 3-1. ★★★ 式

```
陣地の壁(i)  ＝ TrenchDefenseWeight × 相手の上位装備充足率
突破力(i)    ＝ 自分のtier3充足率
実効の押し(i) ＝ 押し(i) × ( 1 − 陣地の壁(i) × (1 − 突破力(i)) )
```

★ 具体的には `Diplomacy.cs:2005-2006` の末尾に、制空権の項と同じ形で1つ掛ける：

```csharp
aPush *= 1.0 − c.TrenchDefenseWeight * qualB * (1.0 − t3A);   // qualB＝Bの上位装備充足、t3A＝Aのtier3充足
bPush *= 1.0 − c.TrenchDefenseWeight * qualA * (1.0 − t3B);
```

★★ **読む量はすべて既存**：`Region.MilitaryQualityFill` と `Region.MilitaryTier3Fill`。

## 3-2. ★★ この形が満たすもの

| 局面 | 上位装備 | tier3 | 陣地の壁 | 帰結 |
|---|---|---|---|---|
| ★**1783-1860** | ⚠ **未解禁＝0** | 0 | **0** | ★従来どおり（⚠ **厳密恒等**） |
| ★★**1870-1914** | **高い** | ⚠ **未解禁＝0** | ★★★**最大** | ⚠ **双方の押しが削がれ、戦線が動かない** |
| ★**1916-** | 高い | ★**戦車あり** | ⚠ **打ち消される** | ★★**持っている側だけが動かせる** |
| ⚠**貧しい国** | 低い | 0 | **低い** | ★ **機関銃を買えない相手には壁が立たない**（★★ 植民地戦争は従来どおり速い） |

★★★ **暦年を1つも書かずに、1914年の膠着が出る。**

## 3-3. ★★★ なぜ「相手の上位装備」を読むのか

⚠ **自分の機関銃は自分を守るが、相手を攻める役には立たない。** ★★ 壁を作るのは**守る側の機関銃**である。

★ したがって `aPush`（Aが押す力）を削るのは **Bの上位装備充足率**。⚠ **自分の充足率で自分の押しを削ってはならない**（★ それは「装備が整うほど弱くなる」という倒錯になる）。

## 3-4. ★★ なぜ「自分のtier3」で取り戻すのか

★ 戦車は**攻める道具**である。⚠ 守るために戦車は要らない。

★★★ **`(1 − 突破力)` の形にしてあるので、tier3充足が1.0なら壁は完全に消え、0なら壁がそのまま立つ。** ⚠ 途中は線形。

## 3-5. ⚠⚠ 既知の不正確さ（★ 意図的に受け入れる）

**① 機関銃と装甲艦が同じ段にある。**

⚠ **したがって「装甲艦を大量に持つ海軍国」も陸戦の壁が立つ。** ★★ これは不正確だが、⚠ **段を分けると新しい状態と新しい充足率が要る**ので、本段では受け入れる。

★ **緩和策**：陸戦の押しにしか掛けないので、⚠ **海戦には影響しない。** ★ そして海軍国は陸戦力自体が小さいので、実害は限定的と見込む。

⚠ **測定で問題が出たら、そのときに段を分ける**（§8-a）。

**② 戦車と弩級戦艦が同じ段にある。**

⚠ 同じ理由で、**弩級戦艦を持つ国も陸の壁を破れてしまう。** ★ ①と対になっているので、⚠ **海軍国どうしでは相殺される**（★ 双方に同じ歪みが乗る）。

**③ 浸透戦術・砲兵準備・毒ガスを表現しない。**

★ 作者の指示は「戦車が必要」なので、⚠ **突破の道具を戦車1本に絞る。** ★★ 毒ガスは既に `MilitaryAirGoods` に入っていて厭戦へ効いている（`Diplomacy.cs:1928`）ので、二重には作らない。

## 3-6. ★ 較正の見当（⚠ 値は測ってから決める）

★★★ **`TrenchDefenseWeight` の意味＝「上位装備が満額の相手に対して、押しが何割削られるか」。**

⚠ **1.0にしてはならない**——★ 押しが完全にゼロになると、**戦争が永久に終わらなくなる**（⚠ 厭戦での終結は残るが、戦勝点が動かないので白紙講和しか出なくなる）。

★ 史実の見当：**西部戦線は1914年11月から1918年3月まで、戦線がほぼ動かなかった。** ⚠ ただし東部戦線は動いており、⚠ **イタリア戦線もカポレットで大きく動いた。**

★★ **出発点の提案：0.6〜0.8。** ⚠ **必ず §6 の観測を見てから決めること。**
