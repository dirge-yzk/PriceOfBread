# 1. ★★★ なぜ廃止するか

## 1-1. ⚠ 代理を置いていた

★ 53件はすべて `effectTarget: Industrialization`、⚠ `effectMode: add`、★ `effectValue: 0.10〜0.30`。
⚠ **鉄道もトンネルも運河も地下鉄も港も、全部「工業化が少し上がる」に潰れている。**

★★★ **本来の効果は「輸送容量が増える」であって、⚠ 工業化は【その結果】である。**
⚠ **因果を1段飛ばして代理を置いていた。**

★★ **これは 2026-08-19 の威信と同じ構図**——⚠ 巨大建造物170件のうち87件が「効果の置き場が無いもの」として
`Prestige`（★ 正統性への一回加算0.05）に潰されていたのと同型。

## 1-2. ★ 「民間か国家か」は【投資の動機】だけの違いになる

⚠ 実体は**同じ輸送容量**。★ 違うのは**何を見て投資するか**：

```
★民間鉄道：交易潜在量を見て投資     ⚠既存（Transport.cs の target）
⚠国家鉄道：脅威を見て投資           ★新規（20260826_安全保障と戦略鉄道.md §3-1）
```

★★★ **＝ 鉄道という個別の建設行為が丸ごと要らなくなる。**⚠ **機構が1つ減る**（思想⑧）。

## 1-3. ⚠ 台本が消える

⚠ **「シベリア鉄道」「ベルリン＝バグダード鉄道」を名指しで置くのは台本的**（★ 作者指摘）。
★★ 廃止すれば、⚠ **「ロシアが極東を持ち日本の脅威が高いから輸送投資が出る」という帰結**に変わる。
