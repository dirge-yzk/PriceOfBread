# 1. ★★★ 形 — **分岐を1つも書かない**

```
各POPについて
  ★重み w   ＝ Size × 発言権            ⚠意識は掛けない（§1-3）
  ★闘争度 m ＝ Militancy

  ★aC ＝ SupportAt(popの思想分布, Absolutist座標,           slope)   王権への親和
  ★aP ＝ SupportAt(popの思想分布, Republic座標,             slope)   議会への親和
  ★aA ＝ SupportAt(popの思想分布, MilitaryDictatorship座標, slope)   軍部への親和
  ⚠aR ＝ (AffMax + AffMin) − max(aC, aP, aA)                        革命＝どこからも遠いこと

  ★★★制度に届く reach ＝ 1 −(1 − 参政権)×(1 − 王権への信任)        ⚠noisy-or
  ⚠体制の外 outside   ＝ m ×(1 − reach)

  ★(1−outside)×w → 王権/議会へ softmax(aC, aP) で按分
  ⚠  outside ×w → 軍部/革命へ softmax(aA, aR) で按分

★★ **あるのは【座標表】と【距離関数】と【乗算】だけ。**⚠ **`if (国)` `if (政体)` を書く場所が構造的に無い。**

## 1-2. ⚠ 革命だけが座標を持たない

★ **革命＝闘争的で、かつ【どの機関からも遠い】層。**⚠ 折り返しは既存定数から導く：

```
best = AffMax（どれかに非常に近い） → aR = AffMin（革命は最低）
best = AffMin（どれからも遠い）     → aR = AffMax（革命が最大）
```

★★ これは旧 `PowerShares.RevolutionLeak`（＝`AvgMassMilitancy ×(1 − Openness(Suffrage))`）の**一般化**である。
⚠ `Openness(Suffrage)` は**議会への親和の粗い代理**でしかなく「参政権が無い＝全部革命」になるが、
★★★ **距離なら「王権が受け皿になっている場合」も拾える**（⚠ ロシアの農民は参政権が無くても皇帝を信じていた＝革命勢力ではない）。

## 1-3. ⚠ 意識（`Consciousness`）を重みに掛けない理由

★★ **二重計上になるから。**⚠ 意識は既に `Ideology.cs` で**思想の形成**に効いており（★ `r[2] += 2.5 × 意識 × prog`＝啓蒙→自由主義）、
★ 思想座標の【参加】軸として親和に入っている。

★★★ **＝ 作者設計の「王権←政治意識なし／議会←政治意識あり」は【参加軸から自動的に出る】。**⚠ **意識を直接使う必要が無い＝機構が1つ減る。**

⚠ `Ideologies.National` は意識を掛けるが、★ **あちらは「政体引力を動かすのは意識ある層」という別の問い。**
★★ **こちらは【意識の無い層こそが王権正当性の母数】なので、掛けると母数が消える。**

## 1-4. ★★★ 制度に届く（reach）が非対称なのは意図的

```
★reach ＝ 1 −(1 − 参政権)×(1 − 王権への信任)
```

⚠ **議会に届くには【参政権】が要るが、★ 王権には【信仰】でよい。**

| ★ 史実 | ⚠ 内容 |

# 4. ★★★ ラチェット問題 — **既に配線済みで解ける**

> ⚠ 作者の懸念：「政治意識は時代と共に増えるので、議会の権力が増え続け、**王権が盛り返すことがない**」

★ **ゲーム期間の最後（1920-34）はまさに議会制の後退期。**

## ★★ 解1 — 「政治意識がある」は「議会を支持する」ではない

⚠ **ファシズムの支持者は政治意識が【極めて高い】。★ しかし議会を否定した。**⚠ ボリシェヴィキも同じ（★ 前衛主義＝議会否定）。

★★★ **既存の思想座標に【強権】軸があり、⚠ そこが自動的に効く：**

```

⚠1反動 0.75   6共産 0.85   9ファシズム 0.90  ← ★★議会を否定

## ★★★ 解2 — 国民意識がナショナリズムを押す（⚠ 実装済み）

```

★★ **ナショ座標は参加0.45（中間）。**⚠ **＝ 教育（政治意識）が参加軸の【高い】思想を押す一方、★ 国民意識は参加軸の【低い】思想を押す。**
