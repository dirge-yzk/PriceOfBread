# 3. ★★★ 確定形 — **監視は「余りの行き先」を決める**

## ⚠ 監視を消してはならない理由

★ **V2 の「監視」＝報道自由 × メリトクラシー × 議会の予算権**（⚠ noisy-or）。
⚠⚠ **汚職を消すと、★ 報道自由を上げる意味も資格任用の意味も消える。**

## ★★ 式

```
★余り ＝ 予算 − 実支出

⚠国庫へ戻る       ＝ 余り × 監視
★配布先へ均等分配  ＝ 余り × (1 − 監視)
```

| ⚠ 状態 | ★ 帰結 |
|---|---|
| ⚠ **監視が低い** | ★ **余りが配布先へ**＝**汚職** |
| ★ **監視が高い** | ⚠ **余りが国庫へ戻る**＝**清廉** |

★★★ **史実的に正確**——⚠ **会計検査院・議会の予算監督は、まさに「余った金を国庫へ戻させる」制度だった。**

## ★★★ 配布先は【官僚のみ】（★ 作者裁定 2026-08-17）

> ★ **「全ての予算は一度官僚に流れる筈です。⚠ 全て官僚に流してよいのでは？」**

```
★余り × (1 − 監視) → 官僚POPへ（⚠頭数割り）
   ⚠カテゴリを問わず全て同じ宛先
```

★★ **史実的に正確**——⚠ **19世紀の財政は「徴税 → 財務省 → 各省 → 支出先」で全て官僚を通った。**

### ★★★ これで未決2件が消える

# 10. ★★★ 先行実装 — **暮らせない官僚は汚職に手を染めやすい**（★ 作者要望 2026-08-17・⚠ 実装側）

> ★★★ **作者「金のないPOPほど……汚職に手を染めやすい」**

⚠ **本書（§3）の「余りへ畳む」大改修は【まだ入っていない】。**
★ その前に、⚠ **現行の `EffectiveCorruption` に対して同じ因果を1項だけ足した**（★ 係数1本・既定0＝休眠）。
★★ **これは大改修の【前倒し】ではなく【同じ導出量の先取り】**——⚠ 詳細は §10-5 の申し送り。

## ★★ 10-1 式（⚠ 係数1本・既定0＝休眠）

```
★実効汚職 ＝ (1−行政) × (1−監視) × ( 1 ＋ 重み × max(0, 1 − 官僚の生活の充足) )
                └────── 現行のコア ──────┘   └──── 新設の1項 ────┘

★官僚の生活の充足 ＝ Σ_官僚 前月満足度_p × 規模_p ÷ Σ_官僚 規模_p        （World.OfficialWelfareFill・[0,1]）
★重み             ＝ Coefficients.CorruptionPoorOfficialWeight            （⚠既定0）
```

| ★ 状態 | ⚠ 帰結 |
|---|---|
| ★ **充足＝1.0**（⚠ 欲しい財を全部買えている） | ★★ **上乗せゼロ＝コアと【ビット同値】**（⚠ 否定形ガードで即 return） |
| ⚠ **充足＝0.5** | ★ 漏れが (1＋重み×0.5) 倍 |
| ⚠⚠ **充足＝0**（★ 清の胥吏＝無給） | ⚠ 漏れが (1＋重み) 倍（★ ただし実効汚職は0..1でクランプ＝`CorruptionMax` が漏れの上限である意味を壊さない） |

⚠ **既定0では `World.EffectiveCorruption` が否定形ガードで即 return**＝★ 式も結合順も1文字も変わらない
（⚠ **恒等は「値を0」でなく「経路を作らない」**）。★ 官僚が1人も居ない世界・NaN・負値は**全て 1.0（上乗せなし）へ倒す**
（⚠ 基準が立たないなら罰さない＝fail-safe）。

## ★★★ 10-2 物差しが「俸給比」でなく **満足度** である理由（★ 作者裁定）

> ★ **作者「嗜好品を購入できているか、で見るべき」**

★ 実装の初手は **俸給比**（⚠ 官僚popの1人あたり所得 ÷ 全国の1人あたり所得）だった。⚠ **これを捨てた理由が3つある：**

| ★ | ⚠ 理由 |
|---|---|
| ① | ⚠⚠ **相対比は【絶対的な窮乏】を取り逃す**——★ **全員が貧しい国では「官僚所得÷平均所得」が 1.0（＝世間並み＝適正）になるのに、⚠ 官僚は飢えている。**★★ 清の胥吏もロシアの下級官吏も「世間並み」だった＝⚠ **比では汚職の理由が説明できない** |
| ② | ★★ **満足度は[0,1]に有界＝比ではない**——⚠ **分母の下限が要らない**（★ 俸給比だと「全国の1人あたり所得」という**痩せうる分母**が要り、⚠ 『比のガードは絶対値で書かない』の同型バグを1つ増やす）。★ 上乗せ側も max(0,1−充足)∈[0,1] で**片側有界**＝発散しない |
| ③ | ★★★ **闘争度・犯罪率と【同じ物差し】に合流する**——⚠ `Politics` の want＝1−満足度／`Crime` の困窮＝1−満足度／★ ここも 1−満足度。⚠⚠ **汚職は【エリート版の同じ不満】**＝★ 式を2つ作らない（⚠ 思想＝機構を増やさない） |

## ★★★ 10-5 設計側への申し送り — **「余りへ畳む」が入ったら、この項は【分配率】へ移す**

⚠ **本書 §3 の改修が入ると、汚職は「量」ではなく「余りの行き先」になる：**

```
★現在（本節）  実効汚職 ＝ コア × ( 1 + 重み × (1 − 官僚の生活の充足) )
★改修後（§3）  官僚へ流れる額 ＝ 余り × (1 − 監視) × ( 1 + 重み × (1 − 官僚の生活の充足) )
                                                      └── ⚠**同じ導出量をそのまま読み替えるだけ** ──┘
```

★★ **`World.OfficialWelfareFill` は純関数（⚠ 新しい状態を持たない）＝★ 読み手が変わるだけで移設できる。**
⚠ **したがって本節は §3 の障害物にならない**（★ むしろ「暮らせない官僚ほど余りを懐に入れる」＝⚠ §3 の分配率の**素**が先に用意される）。

⚠ **移設時の注意（★ 二重計上）**：§3 では**余りの量**が既に行政力（＝官僚の頭数）で決まる。
★ ここで足すのは **「同じ人数でも、暮らせていない官僚ほど多く抜く」** という**別の軸**なので二重にならないが、
⚠ **もし将来この重みを「監視」から導出したくなったら、それは §3-2 と同じ二重計上**（★ 固定の割引率が正しい）。
