# 侵略と植民地化の1本化／要求余剰戦力の国力比化（2026-08-23 作者裁定）

作者指示（逐語）:
> これを国力比にして、弱小には50%ぐらいでいけるようにして。
> また植民地化と侵略は1本化する

前段の指示（同日）:
> 外交タブ 『植民地化」→『侵略」に変更 / どの国も攻め込む余剰戦力が同じなので修正

---

## 1. 診断（新設した計器 `willprobe`・Q200＝1833年）

改修前の要求余剰戦力（上限比）:

| 行為者 | 植民地化の要求 | 侵略の要求 |
|---|---|---|
| イギリス（陸軍力1.72） | 7〜90%（幅83%） | 82〜90%（幅8%） |
| フランス（0.02） | 80〜90%（幅10%） | 82〜90%（幅8%） |
| 日本（0.15） | 80〜90%（幅10%） | 82〜90%（幅8%） |
| アメリカ（0.00） | 80〜90%（幅10%） | 82〜90%（幅8%） |
| プロイセン（0.28） | 48〜90%（幅42%） | 82〜90%（幅8%） |

原因は2つ。

1. **侵略の要求に標的依存が事実上ない**＝`InvadeWillBase(8.0) + InvadeWillPerMilitary(2.0)×標的の軍事力`。
   侵略の標的は抽象標的だけで、その軍事ゲージは world.json の静的値（0.1〜0.5）＝`Diplomacy.Step` の月次同期の対象外＝131年間不変。
   よって 8.2〜9.0＝上限10に対し **82%〜90% の4通り**しか取らない。距離も制海権も自国の陸軍力も式に入っていない。
2. **植民地化の割引が「屈服線を超えた側」にしか効かない**＝`÷(1+D×max(0, 実効戦力/屈服線 − 1))`。
   屈服線に届かない国（英以外のほぼ全て）では割引項が恒等0＝全標的が素の固定費80〜90%に貼り付く。

## 2. 採用した式（国力比・新しい定数なし）

```
国力比 adv = 実効戦力（陸軍力×投射×遠征技術） ÷ 屈服線（標的の軍事ゲージ×ColonizeSubmitRatio）
要求余剰戦力 = ExpansionWillCap ÷ (1 + ColonizeWillSuperiorityDiscount × adv)
```

- adv=1（ちょうど屈服させられる相手＝弱小の標準）で**上限の50%**＝作者指示の「弱小には50%ぐらい」。
- adv=0（届かない）で満タン、adv→∞（圧倒）で0へ漸近＝**上限を超えない＝「不可能」を新設しない**。
- 撤去＝`InvadeWillBase`・`InvadeWillPerMilitary`（固定費）・`InvadeWarFeverMin`（戦争熱の別閾値）・`EnableActiveInvasion`・`ColonizeByMiddlePowers`。
  意欲の物差しは**余剰戦力1本**にした（戦争熱0.95を植民地化にも課すと、熱の低い自由主義的な商業帝国が構造的に拡張不能になり、
  2026-07-10に商業ロビーで直した穴を再び開ける）。

### 屈服線の二重定義を解消（この改修で発見）

要求量の分母は `max(0.05, 軍事力)`、屈服判定は `max(1e-9, 軍事力)` と**別の床**を使っていた＝同じ「屈服させるのに要る力」が
画面とエンジンで違う値になる（分子と分母の非対称の型）。`Diplomacy.SubmitLine(target, c)` 1本へ統合し、床は
`ColonizeSubmitFloorMilitary = 0.05`（無防備な標的にも最小限の遠征が要る）として係数化した。読み手＝屈服判定・要求量・UI・計器。

## 3. 1本化（動詞・ゲート・AI・UI）

| | 旧 | 新 |
|---|---|---|
| 可否 | `World.CanColonize`（列強のみ・実在弱小＋抽象）／`World.CanInvade`（抽象標的のみ・ランク不問） | **`World.CanInvade` 1本**（標的が弱小なら抽象・実在を問わない／行為者のランク条件なし） |
| 動詞 | `World.Colonize`／`World.Invade` | **`World.Invade` 1本**（余剰戦力・船・糧食・キニーネを消費 → `Diplomacy.Subjugate` が屈服か開戦かを決める） |
| 結果 | 屈服＝属国化/併合・拒否＝開戦（植民地化のみ）／即開戦（侵略） | 屈服＝属国化/併合・拒否＝開戦（**両方**） |
| AI | `SelfPlay.TryInvade`（毎四半期・戦争熱で選ぶ）＋`Diplomacy.TryAiColonize`（確率・富と到達で選ぶ）の2経路 | **`Diplomacy.TryAiSubjugate` 1本**。候補の可否はプレイヤーと同じ `CanInvade`＝「払えない標的を選んで無言で空振り」が構造的に消える |
| UI | 「植民地化」「侵略」の2ボタン＋2つの確認モーダル | **「侵略」1ボタン＋1つの確認モーダル**（要求余剰戦力・実効戦力/屈服線・屈服の見込み・狙い先） |
| 属国上限 | AI 呼び出し側のみ（プレイヤーは無制限） | ゲートへ移設＝AI・プレイヤー同一 |

行為者のランク条件を撤去できたのは、**要求量が国力比になったから**。弱い国が強い相手を狙えば自動的に満タン近くを要求される
（計器の実測：陸軍力0.01のロシアは全標的で92〜100%）＝ランクで禁じる必要がない。

### 記録：経済規模 −11pt の読み

参照8カ国のGDP世界順位が2位ほど下がる（英8→10・仏8→10・露9→11・普15→17）。この次元は「±3位以内」の合否なので
**約1カ国ぶんの移動**で11pt動く粗い物差しである点に注意。世界が動的になった（首位交代4.6→5.9・勝者13→17カ国・分離独立21→35）
ぶん、史実の大国が順位を保ちにくくなったと読める。アフリカ小国の順位はほぼ不変（アシャンティ12→11位・コンゴ17→18位）なので、
「弱小が無制限に食い合う」形にはなっていない。

## 6. 申し送り

- **未裁定**：AIの試行頻度（`AiColonizeChance=0.12/四半期`）は旧「植民地化」側の値をそのまま使っている。旧「侵略」側は毎四半期だった＝
  列強の征服頻度は下がり、その分だけ小国に門が開いた。1本化した動詞の頻度をどこに置くかは較正の裁定事項。
- **未裁定**：`ColonizeWillSuperiorityDiscount`（＝50%アンカーの位置）と `ColonizeSubmitFloorMilitary`（無防備な標的の床）は
  Search の再較正対象に入れるべき係数。
- 併せて修正：国号の二重付与（「ハワイ王国王国」＝データ側の名前に既に国号が入っている国に政体の国号を足していた）。
  剥がしてから付ける形にしたので、共和政になれば「ハワイ共和国」と政体に追随する。
