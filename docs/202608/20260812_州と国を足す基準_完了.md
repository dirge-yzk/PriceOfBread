★★ **距離を基準にしてはならない。**⚠ 距離ゲートは、**世界の正しい姿を「欠陥」として大量に検出する。**

## 2-2. ⚠⚠ 誤検出の記録：カイロの「不整合」

★ 機械照合で「`world.json` の `coastal` と `landmass.json` の `coastal` が食い違う州」を1件検出した——⚠ **これは誤りだった。**

```
world.json    coastal  →  Region.IsPort ＝「海に出る口を持つ州か」        【機能】
landmass.json coastal  →  「陸横断棄却の対象外にするか」                  【幾何】
                          ★「沿岸州の近傍は定義上海がある＝沿岸航路を過剰棄却しない」
```

★★★ **カイロは「機能としては港・幾何としては内陸」で、両方正しい。**

⚠ **意味の違う2つのフラグを、名前が同じというだけで突き合わせた。**★ 同種の照合をするときは、**まず両方の定義を読むこと。**

# 3. ★★★ 州を足す基準

> ## ⚠ エンジンが読む値（**港・海盆・文化・宗教・資源**）のどれかが、
> ## **その国の既存のどの州とも違う**ときだけ足す。
> ## ★ もしくは、**地政学の2つの型**（§3-4）のどちらかで名指しできるとき。

★ `Region` からエンジンが実際に読むのは、これで全部である：

| 読み取り値 | どこが読むか | ★ 足す理由になるか |
|---|---|---|
| `IsPort` ＋ 座標 | 海の口・海盆・輸送スロットル・冬季閉鎖・通過港 | ★★ **なる** |
| `SeaBasin` | 封鎖・冬季閉鎖・航路 | ★★ **なる** |
| `Culture` / `Religion` | 民族統一度・分離主義・変名機構・緊張の差分化 | ★★ **なる** |
| `Resources` | 比較優位・交易 | ★★ **なる** |
| `Malarial` / 気候帯 | 風土病・作物 | ★ なる |
| `share`（人口配分） | 階級POPの按分 | ⚠⚠ **ならない** |

★★★ **`share` だけが違う州は、人口を2つに割るだけで何も表現しない。**

## 3-4. ★★★ 地政学の2つの型（作者裁定 2026-08-12）

> ⚠ **「地政学的に重要」はそのままでは何でも通す。**★ **2つの型だけに絞り、いずれも「名指し」を要件にする。**

### ★ G5a 咽喉（チョークポイント）

★ 海峡・運河の扼者になる地点。

⚠⚠ **ただし、ほとんどの場合 州を足す必要は無い。**★ 咽喉は `world.json` の `chokepoints` 配列のデータで、⚠ **`host` に既存の州名・植民地名を書けば成立する。**

```
既存5件   gibraltar(ジブラルタル) / bosporus(イスタンブール) / malacca(マレー)
          suez(カイロ) / panama(パナマ)
```

★ 欠けている咽喉と、⚠ **その host になれる既存の地点**：

| 咽喉 | ★ host になれる既存地点 | ⚠ 名指しできる政治 |
|---|---|---|
| ★**ズンド海峡** | **コペンハーゲン**（既存州） | ⚠⚠ **ズンド海峡通行税**＝デンマーク国庫の柱。★ **1857年に列強が買い取った** |
| ★**ホルムズ海峡** | **マスカット**（既存州） | ★ 英・オマーンの海上協定（1820・1853） |
| ★**バブ・エル・マンデブ** | **アデン**（既存州・ラヘジ） | ⚠ **1839年 英が占領**＝紅海航路の門 |

★★★ **3件とも州を1つも増やさずに実装できる。**

### ★★★ G5b 世界産出の集中（★ 25%ルール・作者裁定 2026-08-12）

> ## ⚠ 1783〜1934年のどこかの時点で、ある**賦存財**の
> ## **世界産出の 25% 以上**を単独で占めた土地。

#### ⚠⚠ 却下した最初の案：「列強が戦争・条約を動かしたと名指しできること」

★ 本書は当初こう書いた。⚠ **これは台本寄りだった。**

| ⚠ なぜ悪いか | |
|---|---|
| ★ **結果から理由を作っている** | ⚠ 「戦争が起きたから重要」は後知恵 |
| ★★★ **「ここで戦争が起きるべき」という期待を持ち込む** | ⚠⚠ **思想①（台本禁止）に触れる** |

★★★ **25%は土地の属性（地質・気候）である。**⚠ **戦争が起きるかどうかはエンジンが決める。**

#### ★★ この閾値が測っているもの

> ⚠ **「その土地を押さえれば、世界を人質にできるか」**

★ 25%を超える土地は、⚠ **失えば世界の供給が崩れる**。★★ **だから列強が争った**——⚠ **争ったから重要なのではない。**

#### ★ 閾値の妥当性（★ 現物で検算した）

★ 全賦存財の産出地を数えたところ、閾値はきれいに効いている：

| 財 | 産出地の数 | ★ 25%を超えるか |
|---|---|---|
| ⚠ 麦54件・畜産51件・果実39件・木34件 | 多 | ★ **超えない**（どこも独占しない）＝**通らない** |
| ★ 硫黄2件（パレルモ・蝦夷地） | 少 | ★★ **シチリアが19世紀の世界の硫黄の約90%**＝通る → ✅ **実装済み** |
| ★ グアノ1件（ペルー） | 1 | ★★ **事実上100%**＝通る → ✅ **実装済み** |

⚠ **多数の場所で採れる財は自動的に落ちる。**★ **閾値が選ぶのは「咽喉になる財」だけである。**

#### ⚠ 全数照合の結果 — 欠落は4件

★ 賦存財の全産出地を機械列挙して照合した：

| # | 財 | 場所 | ★ 史実の集中度 | ⚠ 現状 | ★ 対応 |
|---|---|---|---|---|---|
| **1** | ⚠**硝石** | **チリ（アタカマ）** | ★★ **1880-1910 世界のほぼ100%**（⚠ ベンガル硝石を置き換えた） | ⚠ 硝石5件にチリが無い | ★ **植民地を新設** |
| **2** | ⚠**生ゴム** | **アマゾン** | ★★ **1880-1910 世界の野生ゴムのほぼ全て**（⚠ マナウスのゴム景気） | ⚠ ブラジル植民地は `[サトウキビ,コーヒー,金,トウモロコシ]`＝**生ゴムが無い** | ★ **植民地を新設** |
| **3** | ⚠**錫鉱** | **マレー** | ★★ **1900年頃 世界の約50%** | ⚠⚠ **マレー〈抽象〉は `[香辛料, 生ゴム]` で錫が無い** | ★★ **資源を1つ足すだけ** |
| **4** | ⚠⚠**金鶏樹皮** | **ジャワ** | ★★★ **1900年頃 世界の約90%** | ⚠⚠ **バタヴィアに金鶏樹皮が無い** | ★★ **資源を1つ足すだけ** |

★★★ **4件すべて、州を1つも増やさない。**

> ★ **金鶏樹皮＝キニーネの原料**であり、⚠ `Colonial` の維持費ループが **マラリア地の植民地ごとに毎期キニーネを要求する**。
> ★★★ **史実では蘭領ジャワが世界のキニーネのほぼ全てを供給し、それがオランダの戦略的地位そのものだった。**
> ⚠ 現在ジャワにキニーネが無いので、**アフリカ植民の供給制約が正しく効いていない**
> （★ `20260812_アフリカ植民.DONE.md` の V3＝キニーネの恒久輸入依存に直結する）。

### ★★★ G5c 遍在財の例外（★ 補則・作者裁定 2026-08-12）

> ## ⚠ どの土地も25%を占めない財は、産地を置く理由が「集中」ではなく「**品質**」になる。
> ## ★★ **史実で「その産地の名が財の名になった」ものだけを置く。**

★ **語源という文献的事実**なので検査できる。⚠ 「良質な産地」という主観では通らない。

★★ **既存データと整合している**——⚠ **プラハの珪砂＝ボヘミアングラス**は、まさにこの規則で入っている。

#### ⚠⚠ なぜこの補則が要るか

★ 全賦存財を数えたところ、⚠ **賦存指定が0件の財が2つあった**：

| 財 | 賦存指定 | ⚠ 結果 |
|---|---|---|
| ⚠**石灰石**(7) | ★★★ **0件** | 全184州が `ResourceScarcity = 0.4` 倍 |
| ⚠**粘土**(9) | ★★★ **0件** | 同上 |

★ **「どこでも生産されない財」は無い**——⚠ 非列挙RGOも 0.4× で作られる
（★ `Simulation` のコメント：「賦存に乏しい＝最低限の自給はあるが輸入依存。**ゼロにしない＝封鎖即飢饉を回避**」）。

⚠⚠ **しかし「どこの得意でもない」財が2つあった。**★ そしてこの2つが繋がっている先が重い：

```
石灰石 → 鉄(0.25) ／ セメント(1.0) ／ ガラス(0.3) ／ 住居(0.2)
粘土   → 陶磁器(0.6)

  鉄鉱石 + コークス + 石灰石 → 鉄 → 鋼      ⚠工業化の基幹
  石灰石 + 石炭 → セメント                   ⚠建設の基幹
  製材 + 石灰石 → 住居                       ⚠生活水準の柱
```

★★★ **石灰石はこのゲームの2大連鎖の両方に入っているのに、世界のどこも得意でない。**
⚠ **遍在する鉱物を、世界で最も乏しい財として扱っていた。**

★ 25%ルールでは**永久に足せない**（⚠ 遍在財に25%の土地は原理的に存在しない）ので、この補則を置く。

#### ★ 却下した代案

| 案 | 却下理由 |
|---|---|
| ⚠ **「遍在財」の分類を作り `ResourceScarcity` を財ごとに変える**（石灰石・粘土・珪砂を 1.0 に） | ★ 地理的には正しい。⚠⚠ **しかし比較優位が生まれない＝交易が生まれない**＝「正しいが何も起きない」。★★ **石灰岩は遍在しても、良質な石灰石とカオリンは偏在した**というのが史実 |

#### ⚠ 本ルールの限界（★ 正直に書く）

★ **136財すべてに産出統計を当てるのは、この場ではやっていない。**
⚠ **集中が広く記録されている財**（金属・鉱物・熱帯産品・薬用）について適用した。
★★ **新しい財を足すとき・新しい土地を検討するときは、その財の産出統計を1つずつ当てること。**

## 3-1. ⚠ 却下条件（★ 読み取り値が違っても置かない）

| # | 却下 | 数字の根拠 |
|---|---|---|
| **R1 近すぎる** | ⚠ 既存のどの地点からも **25km 未満**なら置かない | ★ 現行191点の最近傍は**最小27km**（横浜/江戸）＝**違反0**。⚠ **現状を追認する線** |

## 3-2. ★ 予算（⚠ 基準の自己検査）

# 4. ★★★ 国を足す基準（★ 州の基準とは別）

> ## ⚠ **1783年に実在した独立政体で、既存のどの国の州としても表現できないもの。**

★★ **州の基準は「データの区別」だが、国の基準は「政治の主体」である。**
⚠ 同じ文化・同じ資源でも、**別の国**なら別の外交・別の戦争・別の植民地化の標的になる。

## 4-1. ⚠ 却下条件

| # | 却下 | 例 |
|---|---|---|
| **R2' 1783年に政体が無い** | ⚠ 建国が開始年より後 | ★ ズールー(**1816**)・マフディー国家(**1881**)・ドイツ帝国(1871) |
| **R4 既存の国に埋めれば足りる** | ⚠ 州として置けば表現できる | ★ **エジプト**＝オスマンの「カイロ」州で足りている |
| **R5 抽象標的で済ませない** | ⚠⚠ **抽象標的は軍が育たず・代価が消え・マラリアも効かない**（★ `20260812_アフリカ植民.DONE.md` §3） | ★ 足すなら**州を持つ国**として足す |

## 4-2. ⚠ R2' の抜け道について

★ ソコト(1804)・ハワイ王国(1795統一)・タヒチのポマレ朝(1788) は、**開始年にその名の政体が無い。**

★★ **本プロジェクトは既にこの齟齬を抱えている**——⚠ ソコトが抽象標的として実装済み。

★★★ **一貫した扱い**：
> ⚠ **地域と人々が1783年に実在するなら置いてよい。**★ 名前が後年のものになる齟齬は **doc に明記**し、
> ★ **変名機構（`20260731_変名機構の一般化.PARTIAL.md`）が入ったときに正す。**
> ⚠⚠ **暦年で「登場させる」のは台本なので、絶対にやらない**（思想①）。
