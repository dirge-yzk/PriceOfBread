## 2. 完了：教師の自己閉鎖（作者裁定②）

### 2-1. 根

### 2-2. 修正の経緯（原則で2度直した）

1. 初版＝`higherEdu` と `ownEdu` の**線形混合**。→ `ownEdu < higherEdu` の国で**既存の資格経路を黙って下げ**、

2. **max へ変更**（単調＝下げる方向に働かない）。「エリート層に余剰がある」か「本人が学校を出た」かの**どちらかで資格になる**。
   → まだ赤。
3. **官僚を対象外に**（一貫性）。官僚は既に「宗教社会も官僚制は築ける（科挙・寺社官僚）」として世俗の水路を免除されている
   ＝近代教育の系に属さないと既に判断済みの職。そこへ近代的就学の経路だけ足すのは矛盾する。→ まだ赤。
4. 原因は希釈でなく**供給側**と判明。教師/技師/医者へ人を引き抜くと都市労働者が薄くなり**行政の産出が落ちる**
   （`adminNeed` は総人口比例なので需要側は不変）。これ自体は実在のトレードオフ（学校に人を置けば役所に人が足りない）。
   ただし当のテストは行政予算を0.8に固定しており、「行政力が落ちたら行政費を上げる」応答が無効化されている。
   0.5 は根拠なく選んだ値だったので、**既存の挙動アンカーを壊さない範囲（崖は0.18〜0.2）から余裕をとって 0.15**。

### 5-1. 通貨改革（切下げの死のスパイラル）

作者の問題提起「金本位制に入れず、外資流出が起こり続けた時、関税を上げれなくなり、復帰不可能になる。諦めるしかないか」。

検証の結論は「**脱出口はあるが極めて狭い**」。

- `CumulativeDevaluation` を**減らす代入がコード上に1つも無い**（全数確認）。国家破産でも消えない。セーブ・ロードでも残る
- 閾値の位置が悪い＝`CapitalFlightDistrustThreshold=0.02` は**年GDP比0.17%＝実質ゼロ**、飽和は年GDP比8.5%。
  慢性赤字国は数か月〜1年で飽和に達し、以後 permanently 不信=1.0
- 環は物理的に閉じている（資本逃避→投資家貯蓄→建設予算→工業化→GDP の連鎖はどこも切れていない）。
  ただし GDP 脚の時定数は20年級で、**実効の主経路は「切下げ→国債金利→利払い→赤字→切下げ」の短絡路**
- 一方で**為替と対外信用は自己回復する**（`ExchangeRate` は一次遅れで両方向・切下げのインフレ圧は一過性）。
  回復しないのは distrust（国内投資家向け）だけ。**この2つが別の式であることが本件の核心**
- 投資家貯蓄はゼロに漸近せず**正の定常へ収束**する（逃げた金が `CapitalAbroad` シェアで還流するため）

★史実の脱出口＝**通貨改革**（レンテンマルク1923／ポワンカレ・フラン1926）。共通するのは
「過去の減価を、預金を犠牲にして帳消しにする」「旧平価でなく実力に合った**新平価**で戻る」の2点。
英1925の旧平価復帰はデフレ不況を招いた失敗例＝**どちらを選ぶかがプレイヤーの決断**になり得る。

## 9. 通貨改革（作者採用 2026-08-13）

### 9-1. 一文

> **旧通貨を清算し、実力に合った新平価で通貨を建て直す。** 過去の切下げの記憶（`CumulativeDevaluation`）を消す代わりに、
> **現に残っている預金を焼却**し、平価を高く取るほど焼却は増える。

史実の3例が同じ1本のレバーに乗る：

| 史実 | 本機構での位置 |
|---|---|
| レンテンマルク（独1923） | 記憶の帳消し＋大量焼却。財政再建が同時に成立した国だけが成功した＝**発動ゲートに「切下げゼロの実績」を置く**根拠 |
| ポワンカレ・フラン（仏1926） | 新平価＝現在の `ExchangeRate`（実力）→ 焼却ゼロ。痛みは平価の恒久的な引き下げで払う |
| 英1925の旧平価復帰 | 新平価＝1.0 を選ぶ → 焼却が最大化し `PriceLevel` が落ちて需要が縮む＝**デフレ不況が既存の物理から自動で出る** |

### 9-2. 実装

- 動詞は1つ＝`World.RequestCurrencyReform(parity)`。**プレイヤーのボタンもAIも同じ口**を通る（`RequestBorrow` と同型）
- AI は実力どおりの平価を選ぶ（ポワンカレ型）。**旧平価という自傷はプレイヤーだけが選べる選択肢**＝機構は対称・判断だけが違う
- 焼却量＝`max(記憶の代価, 平価の代価)` を総貯蓄の上限と**正貨カバー率の自己制限**で抑える
  （改革が自分で金本位復帰のゲートを閉じては本末転倒なので、既存係数 `GoldCoverMin × GoldRejoinCoverMargin` までで止める）
- 新平価は `Convertibility > 0` でしか効かない＝**「金本位に戻った日に履行される約束」**。改革直後に為替は跳ねない
- `PriceLevel` は**直接触らない**。焼却で貨幣が減り物価が落ちる＝デフレは焼却の帰結として創発する
  （ここを外科的に代入すると英1925の痛みを自分で消してしまう）

### 9-3. 保存則

`CumulativeDevaluation` は Invariants の恒等式（4項）に**入っていない**ので、消しても番人は微動もしない。
焼却は pop→**消滅**（国庫へ渡さない）＝切下げ（pop→国庫の純移転）との本質的な違い。帳尻は
`CumulativeFiatIssued` の**負方向**（不換の回収）で閉じ、**意図額と基礎貨幣の実測減少が一致することを先に検査**して
不一致なら例外を投げる（番人を空洞化させない）。

### 9-4. 状態

休眠既定（`CurrencyReformEnabled = 0`）で厳密恒等・テスト286緑・savetest 0.0E+000。
点火しての発動確認（`chronicle`）と、財政タブのボタン（発動条件を満たしたときだけ出す＝押せないボタンを置かない）は進行中。

### 9-5. 実測と点火

発動は131年・55カ国で**4回**（1797仏・1854西・1869モロッコ・1914マラータ）＝稀で重い事件として妥当。

## 13. 陸分の充足率と塹壕

### 13-1. 塹壕より前に既に出ていた害

上位段とtier3は**陸海が同居**している（上位=[機関銃104, 装甲艦105]・tier3=[戦車122, 弩級戦艦123]）。

**弩級戦艦しか持たない国の陸軍力が +120% される**。塹壕を入れると同じ穴が2度使われる（壁も突破も海で買える）。

（調達側 `MilMul` と同一の判定）＝**新しい分類表を作らない**。合算 Fill は据え置き（`Power.Military` の較正に触れない）。

### 13-2. 塹壕（`TrenchDefenseWeight`・既定0＝恒等）

```
aPush *= 1 − w × (Bの機関銃) × (1 − Aの戦車)
bPush *= 1 − w × (Aの機関銃) × (1 − Bの戦車)
```

守る側の機関銃が壁を作り、攻める側の戦車だけが壁を消す。読むのは**陸分**の充足率。

★**接触強度（`contactStrength`・戦死と戦災）には掛けない。**
「戦線は動かないが人は死ぬ」がWWIの実相で、接触側にも壁を掛けると塹壕戦が**穏やかな戦争**になり、
狙い（厭戦→革命）が消える。意図的な非対称としてコメントに明記した。

★NaNガードは**否定形**（`!(x >= 0 && x <= 1)`）で書く＝`Math.Clamp` は NaN を除去しない（既知の罠）。

### 13-3. カスケードの設計が古くなっていた（doc訂正）

`20260812_理想の軍隊の形.md §3-3` は「大軍国は基本段で予算を使い切り上位段が構造的にゼロ」と書くが、

## 16. 財の地理ゲート（裁定⑥）

希少鉱物6財（硫黄5・金4・銀120・クロム98・錫鉱117・硝石118）を**産地でしか採れない**財にする。
原油は対象外（裁定⑥）。石炭・鉄のような遍在鉱物も含めない＝「どこでも少しは採れる」のが正しいため。

```
非産地 → 厳密に0（旧は 0.4 で自給できていた）
産地   → E = ( k×4.0 + (N−k)×0.4 ) / k     k＝産地の州数・N＝州の総数
```

**k は world.json から数える**＝産地を足せば E は自動で下がる（doc §4-1 の要求＝手で書かない）。
N は**州のみ**（植民地は生産者を1つも持たないことを確認済み）。

★docの表と実測が食い違った：docは硫黄 E=40.4（州のみ）と書くが、これは k=2（パレルモ＋蝦夷地）で計算されている。
**蝦夷地は抽象標的で州ではない**ので k=1 が正しく、E = 4.0 + 183×0.4 = **77.2**＝現行最大の約20倍。
裁定⑥の「E≈78」が正しい。

`ScarceMineralGate=0` で厳密恒等。裁定⑥どおり `ScarceMineralOnlySulfur=1`（既定）で**硫黄1財だけ**を対象に測る。

# 20. 自由鋳造＝価格の床（2026-08-14・作者裁定ラウンド）

## 20-1. 裁定の記録

1. **銀の暴落は「需要曲線のシフト」ではなく「床の消滅」**。造幣局は平価で数量無制限に買う約束（free coinage）＝
   市場価格はその水準を割れない。各国が造幣局を閉じるたびに床が消えた（独1871→ラテン同盟1874/78→米1873→印1893）。
   ⚠旧実装は「産出の20%まで・国内鉱山限定」＝上限つきの買い手＝消しても曲線が1/6ずれるだけ＝暴落の余地が構造的に無かった。
2. **銀のぜいたく品化は不採用**（作者「無理にぜいたく品にする必要はない」）。理由＝①宝飾/時計経由で富裕層は既に買っている
   （二重表現になる）②投機・退蔵はフロー消費でなく**ストック**＝暴落時に吐き出される側＝ぜいたく消費にすると増幅が消える
   ③弾力性の高いぜいたく需要は床が抜けたとき浅く止まる＝狙いと逆向き。
3. **金と銀は対称**（作者「どちらが優れているかではなく、覇権国の側につくのが正解であるべき」）。
   金の暴落も原理的に起こりうる——史実でも**インフレという名前で2回起きている**（1848-55金鉱発見後・1896以降ランド/青化法）。
   金だけが暴落しなかったのは覇権国（英）が金にいたという**初期条件**であって金の性質ではない。
4. **法の並びは 不換<銀<金 のまま**。この順序は通貨の硬さ＝債務者vs債権者の政治軸と一致（ブライアン1896）＝壊さない。
   台本なのは並びでなく**目標の決め方**（工業化閾＝「金が行き先」の埋め込み）。銀↔金の横移動は、目標を
   交易加重の相手の本位から出せば1次元の梯子のまま実現する（→タスク#75・床の測定後）。

### 真因＝このモデルには価格を錨で留める構造が3つあり、どれも産金属に対して働く

| # | 錨 | 実測 |
|---|---|---|
| 1 | **供給が弾力的**：鉱山はRGO＝儲かれば拡張する。床の standing offer が保証買い手になり、**金の産出が13.3倍に膨張**して供給が需要へ追いつく＝価格は限界費用（≈0.49）に固定される | 金産出 42k→566k/四半期 |
| 2 | **需要が弾力的**：銀の Elasticity=2.0＝需要曲線 (RefPrice/P)^2。価格が下がればすぐ買い手がつく＝深い下落を吸収 | Catalog.cs:215 |
| 3 | **貧国が銀から出ない**：工業化閾では常に15カ国前後が銀に残る＝最後の買い手が消えない（史実の「closing the mints」の連鎖が完結しない） | 1934年 銀15カ国 |

★ 史実の銀暴落の前提＝**供給が非弾力**（鉱脈は有限・発見は塊）だった。このモデルの鉱山は資本と労働で
スケールする普通の生産者なので、需要側をどう変えても供給が調整して限界費用に戻す。
**60%の持続的な相対価格変動は、供給弾力的＋弾力2.0の財ではこの価格系の中で構造的に起こりえない。**

### 3段の switchback の記録（それぞれ実在の欠陥だったが、どれも十分条件でなかった）

1. 需要の未計上（`MintDemandCounted`）→ 直した（会計の欠落＝点火済み）→ 暴落せず
2. 上限つきの買い手 → 床にした（`MintPriceFloorGate`）→ 床は機能した → 暴落せず
3. **供給の弾力性**＝ここが本丸。直すには鉱物の地理固定（ScarceMineralGate系）か枯渇/発見の機構が要る
   ＝**別の大工事**（ScarceMineralGate は肥料/ダイナマイト消滅で差し戻し済みの前科あり）

### 処分

- `MintPriceFloorGate` ほか床一式＝**休眠のまま残置**（既定0＝厳密恒等。前提＝供給の非弾力、が入れば動く）
