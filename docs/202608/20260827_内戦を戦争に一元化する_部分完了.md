#### ★★★ 段② 法が通ったときに **運動から抜ける**経路

⚠⚠ **ここが本丸である。**★ 2026-08-19 に「⚠ 満足度は純粋に『必要なものをどれだけ買えたか』」と裁定したため、
⚠ **法による満足ボーナスは全て撤去された**（★ `WelfareSatBonus`/`PensionSatBonus` は実測0、⚠ `ShorterHoursSatBonus`/`UnionSatBonus` は撤去）。

★ **代わりに 2026-08-19 が置いたのが `reach` である：**

```
⚠reach   ＝ 1 − (1−franchise)(1−crownTrust)   ★体制の中に取り込まれているか
★outside ＝ Militancy × (1 − reach)            ⚠体制の外＝運動
```

⚠⚠ **闘争度は下がらないが、★【運動へ流れる分】が減る。**⚠ 作者裁定の形と一致している。

★★ **ただし `reach` は参政権しか読んでいない。**⚠ 報道の自由を読ませるには、⚠⚠ **noisy-or を政策軸全体へ一般化する：**

```
⚠reach(POP) ＝ 1 − Π( 1 − その POP のイデオロギーが求める政策の充足度 )
                     ↑★Pop.IdeologyShares（⚠per-POP・既にある）
```
