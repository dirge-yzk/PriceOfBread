★ 判定は3つ：

| 判定 | 基準 |
|---|---|
| **採用** | 現物で欠落・符号違い・崖・休眠が確認でき、かつ既存の量だけで直せる |
| **棄却（前提違い）** | レビュアーの前提が現物と異なる（実装済み・別名で存在・意図的な設計） |

★ **採用の判断で最も重視したのは「この指摘は既存の裁定と同じ向きか」** である。
　⚠ 倍率排除／壁でなく逓減／新しいマジックナンバー禁止／国名分岐禁止／AI＝プレイヤー対称——

## 2. 構造に効く7本（本体）

### 2-1. ★★★ 主食の価格弾力性の符号が逆（ギッフェン財）

★ 現物：`Coefficients.cs:37 PriceFactorMin = 0.4`（価格弾力の下クランプ）。
⚠ 需要量に「参照価格÷買い手価格」が掛かるため、**パンが高いほどパンを欲しがる量が減る**。

★★★ 主食に対してこれは**符号が逆**である。19世紀の主食（黒パン・ジャガイモ）の教科書的性質は、
値上がりすると肉・衣料・奢侈を諦めて**主食への支出をさらに集中させる**こと——ギッフェン財の実例そのものがアイルランドのジャガイモである。

⚠ 帰結：価格高騰が需要を自動的に冷ますので、市場が早く均衡し、**飢饉が起きにくい方向に構造バイアスが掛かる**。
★ 既存の `CrossElasticity=0.6`（パン→芋の乗り換え）は正しいが、**階層内の乗り換え**と**階層をまたいだ支出の集中**は別物である。

◇ 設計の向き（未確定）：主食Tierだけ弾力の下限を分ける。1.0付近（非弾力）か、1.0超（ギッフェン）まで許すか。

### 2-2. ★★★ 貯蓄があるのに餓死する（緩衝の休眠）

★ 現物：`Coefficients.cs:2105 HoardDishoardRate = 0.0`＝**休眠**（機構は書かれていて0で止まっている）。
◇ `HouseholdCreditMonths` は現物に見当たらない（仕様書のみの存在か別名）。

⚠ 集団は貯蓄を持っているのに、主食が買えなくなったときそれを取り崩せない。
★★ 19世紀の飢饉の実相は「まず貯金を使い、家財を売り、質屋に行き、それでも足りずに死ぬ」であり、
　この順序があるから**餓死が遅れて来る**し、**生き延びた家も没落する**（回復が非対称になる）。

⚠ 現状は所得フローが切れた瞬間に飢餓判定へ直行するので、飢饉が**速すぎ・浅すぎ・可逆すぎ**。

### 2-3. ★★★ 国内小作制の地代が存在しない

★ 現物：`Coefficients.cs:1752 PlantationRentShare = 0.6` のコメントが「**その州の輸出向け一次産品**」と明記＝**輸出RGO限定**。

⚠ したがって、19世紀の階級対立の本体である**国内穀作の地主-小作関係**が経済側に存在しない：
　アイルランドの不在地主／南イタリアのラティフンディア／ロシアの賦役／プロイセンのユンカー領。

★★ 帰結：地主（貴族）の所得が土地税と穀物法だけで決まるので、**「穀物法を守る地主」の動機が薄い**。
⚠ 土地改革・農奴解放が「取り分の上限を下げる」と定義されている以上、下げる対象が国内農業にも要る（現状は輸出RGOしか下がらない）。

★ 関連：[[2-6 完成工場の休止]] と同じ問い＝**損失と余剰を誰が負うのか**。

### 2-4. ★★★ 規模の経済の分母が「自国需要」

★ 現物：`EconomyStep.cs:494 boost *= 1.0 + ScaleEconomyGain * u / (u + ScaleEconomyHalf)`、
　`Coefficients.cs:921-922 ScaleEconomyGain = 0.3 / ScaleEconomyHalf = 1.5`、**u ＝ 産出 ÷ 自国需要**。

⚠ 二重に歪む（レビュアー2名が独立に指摘）：
1. **輸出でいくら量を積んでもコストが下がらない** → 貿易特化・モノカルチャーが構造的に成立しない
2. **自国需要の小さい小国が少し作っただけで最大+30%を取る** → ベルギー・スイスが構造的に有利、内需の巨大な清・印は絶対量で世界一を作っても届かない

★★ 史実はマンチェスターの綿もクルップの鋼も**世界市場向けの絶対量**で単位コストを下げた。
◇ 設計の向き：分母を絶対産出か世界産出シェアへ。**新しい係数はゼロ**（分母の差し替えのみ）。

⚠⚠ **ただし単独で入れてはならない**——これは 2-5 が警告する正帰還の最たるものである。負帰還と同時に入れる。

★追記2026-08-31（コードプローブ）：輸出は `Market.LastExport` 別記帳で `LastDemand` に入らないが、
輸出工場は **Output＞地元需要 ⇒ u＞1** で既に規模ボーナスを得ている＝**指摘①「輸出で下がらない」は半分誤り**
（飽和 u/(u+1.5) の途中までは輸出が効く）。**指摘②「地元需要比の飽和＝小国有利」は事実**（清の絶対世界一でも u≈1）。
分母の絶対化には世界集計（財別世界需要/産出）の州同期という新しい配管が要る＝2-5と同時の専用ラウンドで設計。

### 2-5. ★★★ 正帰還に対応する負帰還の欠落（メタ）

★★★ レビュー3本目のメタ指摘：**「ある条件が成立すると、その条件自身がさらに同じ方向へ進む」機構が多く、対応する負帰還が薄い。**

★★ この項目は「新機能の追加」ではなく **「既存の勝ち筋に値札を付ける」** 作業である。
　◇ 候補：工業化→賃金・地価・混雑／輸出→海外依存・保護主義の誘発／徴兵→人的損失・民族対立。

### 2-6. ★★★ 完成した工場が倒産しない（休止状態の欠落）

★ 現物：`BuiltScale` が `Scale` の**下限**（`EconomyStep.cs:2165` に floor のキャップ処理あり）。
⚠ 採算に関わらず操業が続くため、**退出できない慢性赤字が資本家の負債（LossFinanced）へ垂れ流される**（既知の痛点と同一犯）。

★★ レビュアーの分解が正しい形：
```
★施設は残る／⚠企業は倒産する／★休止する／⚠買収・国有化される
```
★ 現物には**国有化・接収**（点火済み）と**倒産退出**（実装済み・既定オフ）が既にある。
★★★ **欠けているのは「休止（mothball）」だけ**＝設備は残るが操業せず、維持労働も産出もゼロ、採算が戻れば再開。
⚠ これが入れば倒産退出を既定オンにする道も開く（既定オフの理由＝「本来黒字の財まで倒産させる」が緩和される）。

### 2-7. ★★★ 住宅の閾値45%は算術的に到達不能

★ 現物：`Coefficients.cs:1651 HousingUrbanThreshold = 0.45`（住居需要が立つ都市率の下限ゲート）

⚠ つまり**家賃も過密も、ほぼ全ての国・全ての期間で存在しない**。マンチェスターのスラム、パリ改造、ウィーンの住宅問題という19世紀都市政治の中心が、閾値ひとつで消えている。

★ 加えて **これは「全ては連続的であるべき」docの取りこぼし**である（閾値でオンになる形そのもの）。

#### ★★ 私（Claude）からの追加発見：`UrbanCapacityPenalty` は少子化が扶養力の服を着ている

★ 現物：`Coefficients.cs:1491 UrbanCapacityPenalty = 0.12` のコメント＝「都市化で扶養力低下（**近代家族＝少子化＝人口転換の後半**）」。
