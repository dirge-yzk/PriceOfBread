## 2. ★ 何が起きたか（物語）

### 2-1. 1783 — 政治は開幕から詰んでいた

★ 開幕の政治力：**旧支配層 −1.05 対 近代エリート +0.08 ＝ 13対1**。大衆は表に出てこない（参政権なし・政治意識0.003）。
★ 押せる軸＝人頭税 +1.14／関税 +0.91／穀物法 +0.80／鎮圧力 +0.71／徴兵 +0.71。**すべて反動側**。
⚠ 教育法・土地改革・農奴解放・女性の権利は**すべて −0.97**（旧支配層 −1.05 が単独で全部を止める）。

### 2-2. 1787〜1799 — 工場が1つも建たない

★ 国費で26回着工したが工業化は伸びず。原因は**建材の束の価格**：
```
建設1単位の束： 参照 4.23 ／ 市価 13.12（比 3.10）
鋼 3.99倍　機械 4.83倍　輸入はすべてゼロ
★建設可能率 0.013 ／ 着工に要る床 0.50
```
★ `BuildFactory` は `ConstructionAfford < 0.5` で**着工不可**。半減点は束の比 **2.5倍**、鋭さ **16**（ほぼ崖）。
⚠ 清の比は3.25〜4.88＝**工場は建てられない。難しいのではなく、不可能。**

★ 鎖を辿ると根が出た：**鉄1.36倍 → 鋼3.57倍 → 機械部品3.29倍 → 機械9.96倍**。
★★★ 鋼の近代レシピは**解禁点 技術0.55**。1783年から使えるのは**坩堝鋼だけ**で、参照価格で見た投入費は **4.59 に対し産出2.18**。
　⇒ ★**構造的に、鋼は高い価格でしか成立しない。だから建材の壁を越えられない。**

★ 輸入で逃げようとしたが、**自分の関税80%が資本財を止めていた**。
⚠ そして**関税引き下げは旧支配層が拒む**（関税強化の追い風 +0.91）。目標を0.10に置いても**20年間80%のまま**動かなかった。

### 2-3. 1799〜1835 — 補助金だけが壁を開けた

★ 産地のある州（上海・天津・南京・杭州ほか）の**鉄・鋼・機械部品に90〜95%の補助金**を入れ続けた。
★ 効いた：束の比 3.28 → 2.75 → **建設可能率 0.013 → 0.180 → 0.986**（1835年）。
★ 副産物：政体が専制 → **絶対王政**、生活水準 0.426 → 0.495、GDP 257k → 536k。

⚠⚠ **しかし政治は逆に固まった。** 近代エリートの政治力が **+0.08 → +0.05 → +0.02** と下がり続けた。
★★★ 原因＝**旧支配層の政治力は地代に比例する**（`InterestGroups.cs:32-33`＝`LandRent × 8000`）。
　経済が成長すれば地代も増える ⇒ **成長するほど旧支配層が強くなる**。近代エリートは相対的に薄まる。

⚠⚠ さらに：**補助金で生活水準が上がった結果、闘争度が 0.228 → 0.125 に下がった。**
★★★ **善政が革命圧力を消し、改革の唯一の道を塞いだ。**

### 2-4. 1845 — 60工場の同時着工で国庫が破綻し、そして革命が起きた

★ 壁が開いたので60工場を一斉に着工した。結果：
- 国庫 **2,732,108 → 271**
- pop貯蓄 **1億3,650万 → 6,308万（半減）**
- GDP 536k → 363k
- 建設可能率 0.986 → 0.310（壁が閉じ直した）

⚠ **60回の着工に対し、警告は一つも出なかった。**全部「着工」と返ってきた。

★★★ そして1855年、**革命が起きた**。政体が絶対王政 → **共和国**、自由度 0.20 → 0.65、闘争度 0.151 → 0.486、議会が成立。

★★★ ⚠ **151年で唯一の政体変化を起こしたのは、私の善政ではなく私の失政だった。**

### 2-5. 1855〜1934 — 共和国になっても何も通らなかった

⚠ 議会は**保守党が優位**で、旧支配層の意思を増幅しただけだった：
```
教育法（強化）： −0.983（絶対王政期） → −2.672（共和国・議会期）
　　［旧支配層 −2.09 ／ 議会・保守党 −1.31 ／ 議会・自由党 +0.51 ／ 議会・社会党 +0.21］
```
★★★ **共和国になって、教育法はむしろ2.7倍通りにくくなった。**

⚠ 参政権拡大も通らない（−0.95）。しかも**自由党すら反対**（−0.34＝制限選挙を守る側）。
★ 通せた進歩的レバーは **労働時間短縮（+0.32）ただ1つ**。

★ 経済は回復した（1934年：GDP 146万・国庫337万・中核州の工業化は上限5.0）。
⚠ しかし技術は 0.10 → 0.19。世界先端は 2.28 → 4.30。**差は開き続けた。**

## 3. ★★★ 構造の所見（設計へのフィードバック）

### 3-1. ⚠⚠ 工業化度と技術が完全に分離している

★ 清の中核5州は工業化度 **4.9〜4.97（上限5.0）**＝イギリスの平均3.98より高い。
★ にもかかわらず技術は **0.19 対 4.30**。
⇒ ★ **資本ストックは金で買えるが、技術は買えない。**これ自体は設計として正しい（別の量である）。
⚠ ただし**倍率が23倍**は分離しすぎで、「工業化した中世」という奇妙な状態を作る。

### 3-2. ★★★ 技術の追い上げはエリート不足で起動しない

★ `EliteForCatchup = 0.25` に対し清のエリートは **0.019 → 0.026**（151年で+0.007）。
⇒ ⚠ **追い上げ天井（先端の0.5倍）に到達する以前に、追い上げ経路そのものが起動していない。**
★ エリートは教育から来る。教育法は政治で止まっている。**技術の敗北は経済の問題ではなく政治の問題だった。**

### 3-3. ⚠⚠⚠ 成長が反動を強める（負帰還の欠落の実例）

★ 旧支配層の政治力 ＝ **地代 × 8000**。地代は経済成長とともに増える。
⇒ ★★★ **成功するほど政治が固まる。** これは「帰還構造の全数調査」（同日）が予測した
　「貴族の政治力が稀少に応答しない」の**実プレイでの確認**である。
⚠ 近代エリートの力は工業から来るはずだが、実測では **+0.08 → +0.02 と減り続けた**。

### 3-4. ⚠⚠ 建材の壁は「壁でなく逓減」の規律に反している

★ `FactoryBuildPriceCeil = 2.5`（半減点）＋ `FactoryBuildAffordSteep = 16`（コメント自身が「大きいほど旧来の崖に近い」）
　＋ `FactoryStartAffordFloor = 0.5`（＝ちょうど半減点）。
⇒ ★★★ 束の比 2.5 を境に**着工が離散的に不可能**になる。逓減の衣を着た崖である。
⚠ 後発国は開幕時点でこの壁の向こう側にいる（清は3.1〜4.9倍）。

### 3-5. ★ 補助金が唯一の脱出路だった（そしてそれは正しい）

★ 江南製造総局の形＝**産地に補助金を入れて既存生産者の規模を伸ばす**だけが壁を開けた。
⇒ ★ これは史実的に妥当で、設計として良い（洋務運動の手触りが出ている）。
⚠ ただし**36年かかった**（1799→1835）。そして開けた直後に建てすぎて閉じ直した。

### 3-6. ⚠ 議会化が反動を強める

★ 共和国になると議会（保守党）が旧支配層の意思を**増幅**した（−0.98 → −2.67）。
◇ 制限選挙のまま議会を作ると、旧支配層が二重に票を持つ構造になっているのではないか。
⚠ 参政権拡大を**自由党が反対する**のは史実的だが、結果として**誰も選挙権を広げない均衡**が生まれている。

### 3-7. ⚠ 世界の側：技術の全球収束が実プレイでも出ている

★ 1934年の国力上位10：**キューバ王国187 ／ イギリス167 ／ 阮氏145 ／ カリフ国133 ／ マカッサル王国117 ／ アシャンティ王国111 ／ シャム帝国109**。
★ 技術は **4.13〜4.23 でほぼ全員横並び**。
⇒ ⚠ 既知の「技術の全球収束」（コード内に「ダホメ4.02〜英3.56」の記録あり）が、そのまま出ている。
★★ そして清だけが 0.19 で**収束の輪に入れなかった**＝二極化している（全員同じか、完全に脱落か）。

⚠ 以下は**ヘッドレスのハーネス越し**の所見なので、UI本体では解決済みのものが混じる。⚠実験α（目隠し・UI経由）で確かめ直すこと。

| 1 | `CoercionTarget` を「0〜1のスライダー」と誤解して **686.5 → 0.5** に潰した | ★**レバーの尺度が名前からも型からも分からない**。UIならスライダーの上下限で分かるが、値の意味は依然として不明 |
| 2 | 補助金を42組に設定 → **産地の無い州では黙って何も起きない** | ★`SetSubsidyRate` は void で、`FindFactory` が null なら即 return。⚠UIは `CanSubsidize` で理由を出すので**UI側は正しい**。⚠ただし「産地がどこにあるか」を探す画面が要る |
| 3 | `BuildFactory` が「不可」だけ返す | ★理由が4通りある（産地なし／建設中／**建材が高い**／国庫不足）のに区別できない。⚠UIは `StageHint` 相当を持つが、工場側にあるか未確認 |

| 6 | 関税の目標を0.10に置いたのに20年間80%のまま | ★同上。⚠**目標と現実が乖離したまま何年も進む**ことへの通知が無い |
| 7 | 名目GDPが減った期があったが理由が読めなかった | ★AI審査 3-12（パンの値段の説明台帳）と同型の要求 |

★★ **逆に良かった点**：`SupportBreakdown`（誰が何点で賛成/反対か）は**極めて有用**だった。
　これが無ければ、私は151年間「なぜ通らないのか」を推測し続けるしかなかった。
　⇒ ★**この情報がUIに出ているなら、AI審査の懸念（説明文なしで因果が追えるか）への強い反証になる。**⚠出ているか要確認。

## 5. ★★★ 判定（設計doc §5-3 の3択）

| 結果 | 判定 |
|---|---|
| 楽勝 | ✕ |
| **不可能** | ★**技術・制度の近代化は不可能だった**（教育法が151年間通らない＝エリートが育たない＝追い上げが起動しない） |
| 難しいが道がある | △ **工業化だけは可能だった**（補助金→建材の壁を開く→州上限まで。ただし36年＋失政による革命が要った） |

★★★ **設計docの言葉でいえば「動詞不足」ではなく「政治の袋小路」である。**
　⚠ 動詞（補助金・建設・税・法の目標）は十分にあった。⚠**足りないのは、旧支配層の力を削ぐ経路**である。
　★ 土地税 −3.83／土地改革 −2.47／農奴解放 −2.67 ＝ **地主の力を削る手段はすべて地主が拒否する**。
　★★★ **これは論理的に閉じた円であり、外力（戦争・革命・外圧）以外に破る道が無い。**

◇ 史実の清も同じ円の中にいた。⇒ ★**これは「正しい」とも読める。**
⚠ ただし**プレイヤーの唯一の勝ち筋が「自国を破綻させて革命を起こす」であること**は、ゲームとして意図的か要判断。
