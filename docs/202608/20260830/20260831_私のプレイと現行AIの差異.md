★ 材料＝清（604四半期・278手）とプロイセン（604四半期）の実プレイ、および `SelfPlay.cs` の UtilityAgent の実装。
★ 目的＝作者依頼「AIをより強化したい」。⇒ **私が正しかった箇所だけがAI強化の候補**である。
凡例：★＝現物で確認 ／ ⚠＝注意 ／ ◇＝未確認

## 0. 結論（一文）

★★★ **決定的な差は1つ。AIは補助金を一度も使わない。**
　★ 呼び手を全域grepすると `World.SetSubsidyRate` を呼ぶのは **`GameViewModel.Production.cs`（UI）だけ**で、

　★★ そして**私が清で建設の壁を破った唯一の手段が、その補助金だった**（建設可能率 0.013 → 0.986）。

★ 逆に、私が明確に負けていた点も3つある（§2の2・4・6）。⚠ うち1つは私の見落とし、2つは**AIのほうが規律正しい**。

## 2. ★★★ 私が正しかった点（＝AI強化の候補）

### 2-1. ★★★ 補助金を使わない（最大の欠落）

★ 事実：
```
World.SetSubsidyRate の呼び手（全域grep）
  → PriceOfBread.App/ViewModels/GameViewModel.Production.cs:1440   ← UIのみ
  → SelfPlay.cs からは 0件
```
★ しかも `SelfPlay.cs:1365` のコメント自身が
> 「プレイヤーは `World.SetSubsidyRate` にRGO除外が無く生産タブから既にRGOへ補助できた＝**思想⑤の片側欠落**」

と、**非対称の存在を認めている**（ただし認識は「RGOへの補助の可否」の話で、**補助金そのものを使わない**ことには触れていない）。

★★★ **実プレイでの重みづけ**：清では、補助金だけが唯一の脱出路だった。
- 建設の束が参照の 3.1〜4.9倍 ⇒ `ConstructionAfford < FactoryStartAffordFloor` ⇒ **工場が1件も建たない**
- 輸入で逃げる道は自国の関税（政治で下げられない）が塞ぐ
- **既存生産者の規模を補助金で伸ばす**ことだけが建材を安くした（36年かかった）

⚠ ⇒ **後発国のAIは、この脱出路を知らないまま建材の壁の前で止まっている可能性が高い。**
◇ これは「AIが弱い」だけでなく、**「後発国が構造的に工業化できない」という症状の一因**かもしれない
　（＝技術の全球収束の裏で、実は**建材の壁で足踏みしている国がある**）。

★ 実装の向き：`TryBuildFacility` の直前に「**建材が高いなら、まず建材そのものへ補助金**」という判断を足す。
　⚠ 既存の量だけで書ける＝`ConstructionAfford(w)` が床を割っているとき、`SteelGoodId/MachineGoodId/機械部品/鉄` の
　　**産地がある州**（`CanSubsidize` が true）へ補助率を上げる。新しい定数は要らない（床と半減点は既にある）。
　⚠ 費用の律速は `TryBuildFacility` と同じ財政バッファを流用する。

### 2-2. △ 工業化の自主上限（2.5）は正しいのか

★ 現物：
```csharp
private const double IndustrializationCeiling = 2.5;   // 後発工業化の設計包絡（投資を絞る目標上限）
EffectiveIndCeiling(w) = max(2.5, AiIndustrialCeilingFrontier(0.6) × IndustrialFrontier)
```
★ コメント自身が非対称を明記：
> 「secondDeliver を下げる主体の不在の直接原因（診断B-4）。**プレイヤーは州上限5.0まで踏める非対称**」

★ 実測：私のプロイセンは **5.00（州上限）** に到達。1934年の技術は世界最高 4.46。
⚠ しかし国力は9位。**工業を極めても列強にはなれなかった**（人口が支配的・§3-3）。

⚠ AI側の自制には記録された理由がある：
> 「無制限だと露が規模常勝」／「点火は段階掃引 α=0.6/0.8/1.0（一気に1.0へ上げない）」

★★ ⇒ **これは「AIが弱い」のではなく「バランスのために弱くしてある」。**
　◇ ただし**自制の代償が診断B-4（世界価格を下げる主体が居ない）として記録されている**ので、
　　補助金（2-1）を足したうえで α を段階的に上げる、という順序なら試す価値がある。

## 3. ★★ AIが正しかった点（＝私の判断ミス）

### 3-1. ★★ 着工の速度制限（AIの勝ち・しかも私が反例になった）

★ AIは財政バッファで律速している。⚠ その根拠として記録された事故：
> 「実測（R16）＝軍事独裁が 5.0%→53.4%＝**世界中で国家が財政破綻して軍が政権を取った**」

★★★ そして同じコメントにこう書いてある：
> 「**プレイヤーは自分で押すので暴走しないが**、AIは毎期押す＝同じ動詞でも**頻度が違う**」

⚠⚠ **この前提は私の実プレイで崩れた。** 私は60件を一括で押し、国庫を2.7Mから271へ落とし、pop貯蓄を半減させた。
　★ 警告は1つも出なかった（60回とも「着工」と返る）。
⇒ ★**プレイヤー側にもAIと同じ律速（または警告）が要る。** これは「AI強化」ではなく**UIの安全装置**の話だが、
　同じコメントが根拠なので併記する。

### 3-2. △ 関税：どちらが正しいかは国の位置で変わる

★ AI＝`ReactProtectiveTariff`（輸入が溢れたら上げる）＋スタンス既定値。
★ 私＝清で「関税80%が資本財の輸入を止めている」と判断し、下げようとした（政治に阻まれた）。

★★ **どちらも一面で正しい。** ⚠ 問題は**関税が国に1本しかない**こと：
　農業を守るために上げると、**同じ率が資本財にも掛かる**。史実の後発国はここを関税表で使い分けた。
◇ ⇒ AI強化の前に、**財ごとの関税（または資本財の免税）という動詞が要るのではないか**という設計論点になる。
　★ 既に `SetTradeBias`（財ごとの売買方針）と `SetConsumptionTaxRate`（財ごとの物品税）はある。⚠関税だけが一律。

### 3-3. ★ 財ごとの売買方針（TradeBias）は私が使い損ねた

★ AIは `TryTradeBias` で毎期使う。⚠ 私は清で「鋼と機械が欲しい」と分かっていながら、**この動詞を一度も使わなかった**。
★ `TradeBias` は買い手側の敷居を下げる（`buyDear`）＝**欲しい財を高くても買う**意思表示。
⇒ ★ 清で機械を確保するのに使えた可能性が高い。**AIのほうが道具箱を正しく使っている。**

## 4. ★★★ AI強化の優先順（実装可能な順）

| 順 | 内容 | 根拠 | 費用 |
|---|---|---|---|
| **1** | **建材が高いとき、建材そのものへ補助金を出す** | ★私の清が実証した唯一の脱出路。AIは動詞ごと未使用 | ★小（既存の動詞・既存の床と半減点・律速も流用） |
| **2** | ⚠**プレイヤー側の着工に律速か警告を付ける** | ★私が国庫を破綻させた（AIの前提「プレイヤーは暴走しない」の反例） | ★小 |
| **3** | ◇**補助金を入れたうえで `AiIndustrialCeilingFrontier` を段階掃引** | ★診断B-4（世界価格を下げる主体の不在）は自制の代償として記録済み | ⚠中（露の常勝を必ず見る） |
| **4** | ◇**資本財の関税を分ける動詞** | ★後発国は「農業を守りつつ機械を入れる」が要る。⚠現状は関税が一律1本 | ⚠中（設計論点） |

⚠ **1と2は対になっている**：AIに補助金を与えるなら、プレイヤーの暴走も同時に塞がないと、
　「AIは賢く、プレイヤーは自滅する」という非対称になる。

## 5. ⚠ 判定の限界

⚠ 私の清プレイは**近代化投資レバーを使っていなかった**（`ModernizationFrac` を151年放置）ので、
　「補助金が唯一の脱出路だった」という結論は、**その手を欠いた条件下での結論**である。
◇ ⇒ **近代化投資を正しく使えば補助金なしでも壁を越えられた可能性は残る。**
★ ただしプロイセン（近代化投資0.6で開始）でも、**開幕の建設可能率は 0.000**（束が参照の9.00倍）で、
　壁を開けたのは補助金を入れた後だった。⇒ ★**補助金の有効性そのものは2走とも一貫している。**

◇ 決着させるなら：**清を「近代化投資あり・補助金なし」で1走**すれば、補助金の必要性が単独で測れる。
