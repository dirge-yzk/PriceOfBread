## 1. ⚠⚠⚠ まず訂正：第1走（清）の結論は**部分的に誤っていた**

★ プロイセン第1回目の走行中に、**私が最大の動詞を使っていなかった**ことが判明した。

```csharp
// World.cs:939
public double ModernizationFrac { get; set; }   // 近代化投資レバー（0..1）… ★UI/AI 共通の動詞
// Simulation.cs:1358
if (!self.IsPlayer) World.ModernizationFrac = UtilityAgent.AutoModernizationFrac(World, fs);   // ★AIだけ毎期更新
```

⚠ **`ModernizationFrac` は `NationPolicy` ではなく `World` 直下にある。**
　私のハーネスは `NationPolicy` をリフレクションで舐めていたので、**この1本だけ拾えなかった**。
★ 開幕値は 0.08 が全国に入り、**AIは毎期更新するがプレイヤーは放置される**（UIのスライダーで動かす前提）。

★★ 証拠＝プロイセンの世界では**AIが打った清が1798年に工業2.29**に達していた。⚠**私が打った清は同時期に約0.5**。
　⇒ ★**AIのほうが私より遥かにうまく清を工業化させていた。**

★ 第2走ではこれを0.6にして開始した。⇒ プロイセンは25年で建設の壁を越えた（★清は36年かかった）。

★★★ **したがって「清は工業化に苦戦した」の一部は私の操作ミスである。**
⚠ ただし**政治側の結論は無傷**：教育法・土地改革・農奴解放は151年間一度も通らず、これは近代化投資とは無関係である。

## 3. ⚠⚠ 最大の所見：技術世界一でも列強になれない

★ 1934年の国力上位10：

| 順 | 国 | 国力 | 工業 | 技術 | 人口 |
|---|---|---|---|---|---|
| 1 | **中華**（清の変名・AI） | 172 | 3.66 | 3.28 | **197,041** |
| 2 | イギリス | 157 | 3.41 | 4.31 | 24,218 |
| 3 | ネーデルラント | 154 | 3.99 | 4.31 | 16,104 |
| 4 | ペルー王国 | 140 | **5.18** | 4.29 | 13,250 |
| … | | | | | |
| **9** | **プロイセン** | **121** | **5.00** | **4.46（最高）** | **18,174** |

★★★ **技術が世界最高で工業が上限でも9位。** ⚠国力が**人口に支配されすぎている**。
⚠ そして**ドイツ統一が起きなかった**＝プロイセンは151年間 5州・人口1.8万のままだった。

◇ 史実のプロイセンは統一によって列強になった。⇒ ★**統一（formable）が発火しないと、この国は構造的に列強になれない。**
　⚠ これは記録済みの症状「**史実の列強が列強にならない（再現率15 %）**」の、プレイヤー側からの確認である。

## 4. ⚠ 副次的な所見

### 4-1. ★ 小国ほど建設の壁が高い
★ 建設の束（対参照）：清 3.10倍（人口344k・26州）／**プロイセン 9.00倍（人口6.3k・5州）**。
⚠ 市場が薄いほど価格が跳ねる ⇒ **小国は開幕時点で工場を建てられない**。
◇ 一方で規模の経済は「産出÷**自国需要**」なので小国が有利＝**同じ小ささが、建設では不利・生産性では有利**という逆向きの2つが同居している。

### 4-2. ⚠ 世界は再び技術収束している
★ 1934年：英4.31・蘭4.31・ヴェネツィア4.31・ダホメ王国4.31・ペルー王国4.29 ＝ **多数が同じ値に貼りついている**。
★ 上位に**ペルー王国・ダホメ王国・ヴェネツィア・アンダルシア**が並ぶ。⚠ 既知の「技術の全球収束」がそのまま出ている。

### 4-3. ⚠ 教育費スライダーは一度も流れなかった
★ 目標を0.9〜1.0に置き続けたが、**教育費は151年間ずっと0 %**（政治抵抗 −0.55）。
★ にもかかわらず識字は 56.7 % → 90.0 % に上がった。
◇ ⇒ **識字は教育費でなく教育法（公教育→義務教育）で決まっている**らしい。⚠ならば教育費スライダーは何のためにあるのか、プレイヤーには読めない。

### 4-4. ⚠ セーブが係数の追加で壊れた
★ プレイ中に実装側が `FactoryStartAffordFloor` を World の定数から Coefficients の係数へ移した（⇒ ★私が第1走で指摘した「建設の壁」への対応）。
⚠ その結果、**古いセーブが読めなくなった**（`Boolean cannot be converted to Double`）。
★ 保存はフィールド名順で読むので、**係数を1本足すと以降の位置がずれる**。⚠バージョン耐性が無い。

## 5. ★★★ 2走を通した判定

| 問い | 答え |
|---|---|
| 経路（教育→エリート→技術追い上げ）は機能するか | ★★**する**。プロイセンは追いつき率100 %に到達 |
| 清の袋小路は設計の欠陥か | ★**違う。制度の帰結であり、史実的に正しい** |
| プレイヤーは近代化できるか | ★**制度が開いていればできる。閉じていればできない**（＝正しい形） |
| ⚠ では何が壊れているか | ⚠**列強の再現**。技術世界最高・工業上限でも9位。**国力が人口に支配され、統一が発火しない** |

★★★ ⇒ **次に直すべきは「近代化できるか」ではなく「近代化した国が列強になれるか」である。**
　★ 具体的には (a) 統一（formable）の発火条件 (b) 国力に占める人口の重み。
　⚠ どちらも AI審査・帰還構造調査では上がっていなかった**新しい発見**である。
