# 3. ★★★ コアの定義 — 過不足ベクトル

> ★★★ **外交は、国内で解決できなかった問題の放出である**（★ 作者裁定）。

## ★ 各国は2つの量を持つ

```
★s(a) ∈ [−1,+1]^8   ⚠カテゴリごとの過不足（−1＝不足 / +1＝過多）
★P(a) ∈ [0,1]       ★軍事力（⚠相対・逓減あり — §5-2）
```

## ★★★ 関係は符号の積で決まる

```
★競合度(a,b) ＝ s_a · s_b        ⚠同符号優勢＝【正】＝競合
★補完度(a,b) ＝ −競合度          ★異符号優勢＝【正】＝補完

⚠⚠内積の符号をそのまま「補完度」と呼ぶと逆転する（★実装AIが最も間違えやすい点＝§0の単体テスト）
```

| ⚠ s_a | ⚠ s_b | ★ 力 | ⚠ 帰結 | ★ 史実 |
|---|---|---|---|---|
| ★ 過多 | ★ 過多 | 両方高 | ★★ **敵対** | ⚠ 英⇔独 1900（★ 市場の奪い合い） |
| ★ 不足 | ★ 不足 | 両方高 | ★★ **敵対** | ⚠ 同じ産地の奪い合い |
| ★ 不足 | ★ 過多 | 両方高 | ★★ **協力** | ⚠ **独ソ不可侵条約 1939** |
| ★ 不足 | ★ 過多 | 低 vs 高 | ★★ **強制** | ⚠ **市場を開かせる**（★ 不平等条約） |
| ★ 過多 | ★ 不足 | 低 vs 高 | ★★ **逆向きの強制** | ⚠ **英がインドを取った**（★ 原料の確保） |

★★★ **「植民地化」は双方向に起きる。⚠ どちらも「異符号 × 力の差」で式は1本。**

## ★★ そして「衰退する帝国が攻撃的になる」が出る

> ⚠ **国内問題が大きいほど `|s|` が大きくなる。⚠ 力が弱くても放出圧は高い。**

★ **オスマン**（⚠ 財政破綻・イェニチェリ・地方の離反）／★ **オーストリア＝ハンガリー 1914**（⚠ 崩壊寸前だからこそ開戦）／

★★ **学術的には社会帝国主義（Sozialimperialismus）＝ヴェーラーがドイツ帝国について用いた概念。**

> ⚠ **判定：「その項は、`s` が全部プラスのとき自動的に高くなるか？」——★ なるなら二重。**

| ★ `NationalScore` の項 | ⚠ `s` が全部+のとき | ★ 判定 |

| ★★ **Military** | ⚠ **変わらない**（★ 軍を作るかは別の選択） | ★★★ **独立** |
| ★ GDP規模 | ⚠ やや上がる | ⚠ 弱い相関 |
| ★ 工業化 | ⚠ 変わらない | ★ 独立 |

| ⚠ **Finance** | ⚠ 上がる | ⚠ **二重** |

★★★ **完全に独立なのは Military だけ。⚠ よって `P = 軍事力` とする。**

## ★★ そして「軍拡が直接に外交を動かす」ようになる

### ⚠ 発散しない理由

★ **英独は両方工業品過多だったので軍拡→疲弊→さらに敵対**（⚠ 史実通り）。
⚠ **発散を止めるのは「戦争が起きて終わる」こと。**

# 6. ★★★ 「できる」— 阻害と要求

> ⚠ **作者裁定：「不足物を輸入し、余剰物を輸出【できる】ペアは同盟になりやすい。」**

★★★ **内積が異符号（補完）は【可能性】であって、⚠ 実際に交易できるかは別。**

| ⚠ 状態 | ★ 帰結 |
|---|---|
| ★ **補完 かつ 交易できている** | ⚠ **同盟** |
| ★★★ **補完 なのに 交易できない** | ⚠⚠ **最も危険** |

## ⚠⚠ 「補完なのに交易できない」が、戦争の3大事例

| ⚠ 事例 | ★ 何が阻んだか |
|---|---|
| ★★★ **アヘン戦争 1839** | ⚠ **広東システム・一港制限** |
| ★ **ペリー来航 1853** | ⚠ **鎖国** |
| ★ **1930年代** | ⚠ **ブロック経済の関税**——★★ これが「持たざる国」を作った |

★ **補完度が高いほど、⚠ 閉じられたときの圧力が大きい。**

## ★★★ 阻害が【要求の中身】になる

```
★潜在交易(a,b) ＝ max(0, 補完度) × 交易到達度   ⚠循環しない・補完ペアにのみ立つ
★実交易(a,b)   ＝ BilateralMarket の成約        ★観測
★阻害(a,b)     ＝ max(0, 潜在 − 実際)          ⚠⚠強制の動機（★単位合わせは 13j）
```

⚠ **阻害の原因は【相手の法】**（★ 関税・禁輸・鎖国）。

★★★ **したがって強制の要求は「関税を下げろ」「港を開け」＝ ⚠ 不平等条約そのもの。**
★ **`20260814_戦争を政治の延長にする.HOLD.md` で「要求が無い」と書いた穴が、⚠ ここで埋まる。**

## ⚠⚠ 循環に注意

★ **「実交易」を関係値の入力にすると、⚠ 関係が悪い→交易が減る→関係が悪くなる、の自己強化ループになる。**
★★★ **汚職の `corruptionRoom` と同じ自己言及**（⚠ `20260814_汚職をサブシステムにする.PARTIAL.md` §2）。

> ★ **関係値の入力は【潜在交易】（⚠ 循環しない）。**
> ⚠ **【実交易】は「阻害」の計算にだけ使う。**
