# 4. ★★★ 設計 — 総量保存ゲート

> ## ⚠ **総量は変えない。分布だけを変える。**

## 4-1. ★ 式

★ 産地の数 `k` の財について、賦存量 `E` を **世界総産出が不変になる値**に取る：

```
E(good) = ( k × 4.0 + (N − k) × 0.4 ) / k        ★N＝産出しうる地点の総数
```

⚠ **つまり「非賦存地が作っていたぶんを、賦存地へ移す」だけ。**

★★ **`k` は `world.json` から数える**＝⚠ **産地を足せば `E` は自動で下がる**（★ **手で書かない**）。

### ⚠⚠ `N` に植民地を含めるか（★ 未決 11e が本質的な理由）

★ 産地の内訳を数えたところ、⚠ **鉱物の産地は州より植民地に偏っていた**：

| 財 | ★ 州 | ★ 植民地 | 計 | ⚠ 産地の場所 |
|---|---|---|---|---|
| ⚠**金** | ★ **1件** | ★★ **6件** | 7 | ⚠⚠ **州はオムスクだけ**。他は全部 植民地・抽象標的 |
| ⚠**硝石** | ★ **1件** | ★ **4件** | 5 | ⚠ 州はグワーリヤルだけ。ベンガル2・ペルー・ラ・プラタは植民地 |
| ⚠**硫黄** | ★ 1件（パレルモ） | ★ 1件（蝦夷地） | 2 | — |
| ★ 銀 | 3件 | 3件 | 6 | — |
| ★ 銅鉱 | 3件 | 3件 | 6 | — |
| ★ 原油 | 5件 | 2件 | 7 | ★ 州が主 |
| ★ 錫鉱 | 2件 | 2件 | 4 | — |
| ★ クロム | ★ **3件** | 0件 | 3 | ★ **州のみ** |
| ★ 鉛鉱 | 2件 | 0件 | 2 | ★ 州のみ |

★★★ **金は、州にはオムスクにしか無い。**⚠ **残り6件はすべて植民地・抽象標的である。**

⚠⚠ **したがって、鉱物のゲートは植民地機構と強く絡む**——★ **金を押さえるとは、植民地を押さえることである。**

| `N` の取り方 | 硫黄 | 硝石 | クロム | 錫鉱 | 銀 | 金 | 原油 |
|---|---|---|---|---|---|---|---|
| ⚠ **州のみ**（N=184） | ★ 40.4 | ★ 18.3 | ★ 28.1 | ★ 22.0 | ★ 15.9 | ★ 14.1 | ★ 14.1 |
| ★★ **州＋植民地**（N=229） | ★ **49.4** | ★ **21.9** | ★ **34.1** | ★ **26.5** | ★ **18.9** | ★ **16.7** | ★ **16.7** |

★★ **植民地も 0.4× で産出しているなら、`N = 229` が正しい。**
⚠ **着手前に「植民地ビルダーが非賦存の鉱物生産者を持つか」を現物で確認すること**（§10-6）。

## 4-2. ★★★ これで何が起きるか

| ★ 起きること | |
|---|---|
| ★ **世界の総供給は（ほぼ）変わらない** | ⚠ 火薬も肥料も総量は保たれる＝**§3 の破局を回避** |
| ★★★ **産地を押さえた国が、世界を人質にできる** | ⚠ **封鎖・戦争・植民地化の価値が跳ね上がる** |
| ★★ **失えば代替がない** | ⚠ **非賦存州には 0 しかない**（★ 熱帯産品と同じ） |
| ★ **枯渇が効く** | ⚠ `IsMineral` は「採掘RGO＝枯渇対象」——★ **集中すると枯渇の影響が大きくなる**（§11-a） |

★★★ **これが「地政学」の実体化である。**⚠ 台本を1行も書かずに、**シチリアの硫黄・チリの硝石・バクーの石油が世界政治の焦点になる。**

## 4-3. ★ 思想②に触れない理由

★ 既存のコードに**同じ形式の先例がある**：

```csharp
// ★「倍率排除⑧：列挙財の賦存量を good の地理的性質から導く（uniform な手置き×3.5 を廃止＝賦存の大小が一次データから出る）」
// ★「鉱物・石油（IsMineral）は点在鉱床＝産地では集中的に豊富＝高い賦存（4.0・ルール炭/ペンシルベニア炭/アナトリアのクロム/ガリツィアの石油…）」

```

★★★ **「財の地理的性質から賦存量を導く」という設計思想は既にある。**
⚠ **本書はそれを2段階（鉱物4.0／その他3.5）から、偏在度に応じた段階へ細分するだけ**である。

⚠ **国ごとの倍率ではない**＝思想②に抵触しない。

## 5-1. ★★★ 判定は2つの問いだけ

```
Q1  この財は【どこでも採れるか】（＝気候にも地質にも縛られないか）
      はい   → ★普遍原料
      いいえ ↓
Q2  1783〜1934年のどこかで、1つの土地が【世界産出の25%以上】を占めたか
      いいえ → ★局地資源
      はい   → ★希少資源
```

★★ **Q2 は `20260812_州と国を足す基準.DONE.md` の G5b と同じ閾値である。**⚠ **2つの規則を持たない。**

## 5-2. ★ 3分類とルール

| | ★**普遍原料** | ★**局地資源** | ★**希少資源** |
|---|---|---|---|
| **意味** | ⚠ どこでも採れる | ★ 適地でのみ採れる（産地は多い） | ⚠⚠ **数カ所が世界の大半** |
| ★**地理ゲート** | ⚠ **無し** | ★ **有り**（賦存地のみ） | ★ **有り**（賦存地のみ） |
| ★**非賦存地の産出** | ★ `ResourceScarcity = 0.4` | ⚠ **0**（生産者ごと除去） | ⚠ **0** |
| ★**賦存地の賦存量** | ★ `4.0`（鉱物）／`3.5`（他） | ★ `4.0` / `3.5` | ⚠⚠ **総量保存 E**（§4） |
| ★★**産地を足す規則** | ⚠⚠ **語源ルール**——**産地の名が財の名になったものだけ** | ★ **気候・地質の適地なら足してよい** | ⚠⚠⚠ **25%ルール**（★ 足すと独占が薄まる＝**慎重に**） |
| ★**失ったら** | ★ 自給できる（高くつく） | ⚠ **輸入するしかない** | ⚠⚠⚠ **代替が無い＝人質になる** |

★★★ **「地理ゲートの有無」は2値である。**⚠ 3分類の意味は、**産地を足す規則と賦存量の決め方が違う**ことにある。
