# 1. 最終形 — 計算は1つ「各階級が、どの機関をどれだけ支えているか」の表1枚

```
表 ＝ 階級（旧支配層 / 近代エリート / 大衆 / 小営業 ＋ ★王そのもの）
     × 機関（執行権 / 議会 / 将校 / 兵卒 / 革命勢力）

  取り分     ＝ 表の【列】の合計       （軍部 ＝ 将校 ＋ 兵卒）
  貴族率     ＝ 表の【行】の比          （執行権＝集権度の逆／議会＝議会の性格／将校＝将校団の性格）
  全セルの合計 ＝ 1                     ★同一スケールの芯
```

★ **取り分も貴族率も近代エリート率も大衆率も、この1つの表からの導出**＝コードの重複が無い。
★ 階級は**既存の利益ブロックをそのまま使う**（`InterestGroups`）＝新しい概念ゼロ。

# 2. 史学検証で棄却した写像と、その反証（★docsに残す指示による全数記録）

## 2-1. 検証1 — 「王権＝貴族／議会＝近代エリート」は採れない

⚠ 明確に成り立つのは全「国×時代」セルの **15〜20%**（1815-1870の西欧中欧立憲君主国に集中）。
⚠ しかも**符号が反転する型が非西欧・後発国の標準形**である。

| # | 反証 | 事例 |
|---|---|---|
| 1 | ⚠**英1783-1832の議会は貴族的** | 後援者統制309〜359議席／上院は文字通り貴族院／**1815年穀物法は議会が地主利益を押し通した立法**。しかも英は本作の中心国＝設計だと符号が逆 |
| 2 | ⚠**貴族が議会側に付く**（6か国以上） | 1787-88仏の名士会・高等法院の対王権反乱／1789年8月4日の特権廃止は貴族自身の提案／1832英改革法はグレイ伯のホイッグ貴族内閣／ハンガリー貴族の自由主義／デカブリスト・カデット公爵／カヴール伯 |
| 3 | ⚠**ブルジョワが王権側に付く**（5か国以上） | 第二帝政のクレディ・モビリエとオスマン改造／1879独「鉄とライ麦」／**普の三級選挙法は貴族的でなく金権的**（第一階級の1票が第三階級の17.5倍）／明治の政商／露十月党 |
| 4 | ⚠**議会が近代エリート以外を代表**（1870年以降は**多数派**） | スウェーデン農民身分／デンマーク・ノルウェーの農民党／独中央党・社民党／アイルランド党・労働党／仏急進社会党／ベルギーカトリック党 |
| 5 | ⚠**王権が貴族と対立**（8例以上＝**防衛的近代化の標準形**） | ヨーゼフ2世／シュタイン改革／1861露農奴解放／1826マフムト2世のイェニチェリ殲滅／**1871-76明治の廃藩置県・秩禄処分** |
| 6 | ⚠**王権が普通選挙を武器にした** | 1867ビスマルクの北ドイツ連邦（農村保守票で自由主義議会を無力化）／ナポレオン3世の人民投票／1907墺＝「参政権拡大は常に議会を利する」という**単調性が誤り** |

★ **採った形**＝陣営は**内生**（§3-3）。同じ貴族POPが、執行権のふるまい次第で両側に立つ。
⚠ **2階級で閉じてはならない**（反証4＝議会に大衆と小営業の行が要る／反証3＝執行権も近代エリートと大衆を抱えられる）。

## 2-2. 検証2 — 軍部は「漏れ」だけでは足りない

| # | 発見 | 実装 |
|---|---|---|
| A | ⚠**執行権が最強のときこそ軍の取り分が最大化した型が大国で反復**（露の近衛が皇帝を殺す1801／独の軍事内閣・最高陸軍指揮部1916-18／1930年代日本）。**軍は執行権の対抗者ではなく道具であり、道具が主人を食う** | 軍部シェア＝**常在項 ＋ 漏れ**（`ArmyBaseline`）。⚠**宮廷クーデタは計上しない**（1801露・1825露・1903セルビア・1876オスマン＝君主が代わるだけで体制型は不変） |
| B | ⚠**史実では軍の政治力の大半はクーデタでなく拒否権として行使された**（日本1912の二個師団増設問題＝陸相の単独辞職＋後任を出さず内閣崩壊＝**予算権を持つ側が予算以外の手段で負けた**／普の軍事内閣／オスマンの帷幄上奏／スペインのフンタ／英カラーの反抗1914／伊1922の不作為） | `VetoPower`＝制度の梃子 × 軍部の総主張。⚠**統帥権という独立の状態変数を足さずに**表現 |
| C | ⚠純軍政は約4件に1件。**単独支配を選んだ国で軍が強かったのではなく、組む相手がいなかった**（ペルー1930・ポルトガル1926・チリ1927・ギリシャ1925）。軍が最も圧倒的だった局面（ギリシャ1909・ポルトガル1910・オスマン1908）では**文民に権力を渡している** | 閾値を**絶対値から相対値へ**＝`SeeksMilitaryRule`（軍部が最大 かつ どの相手も `PartnerViableShare` に届かない）＝**規則が1つ減る** |

⚠ **プロイセン1862を「軍は金を出す方につく」の反例として使ってはならない**（記録）——議会は予算を**拒否する権利**を持っていたが**徴税を止める力**は無く、ビスマルクは欠缺理論で税を取り続けた＝**給与を払っていたのは王権のまま**。例外的個人の話であって機構に足す理由にならない。

★ 代わりの根拠は2つの型：
- ★**正統性の崩壊型**（誰も信じていない体制のために兵は撃たない）＝1830七月革命／1848ウィーン・ベルリン／**1917ペトログラード守備隊**／1918キール軍港
- ★**将校団の思想的分裂型**＝1820年代スペイン／**1936スペイン**（共和国が払っている軍の半分が蜂起）／1930年代日本の青年将校

## 2-4. 検証4 — 欧州・ロシア（15事例＋理論）

# 3. 写像の全定義と根拠

★ すべて既存量からの写像。**新しい係数は1つだけ**（`PartnerViableShare = 0.5`＝作者裁定「組む相手として成立する取り分の下限」）。

## 3-1. POP の重みと陣営

| 量 | 定義 | 根拠 |
|---|---|---|
| `PopWeight` | **資産 × 発言権**。資産＝`Savings` ＋ 閉鎖階級の**土地の資本化**（`LandRent × LandedPowerCapitalization`）。発言権＝`InterestGroups.FranchiseVoice` | ★「参政権を通じて支えている」が自動で選ばれる＝**1783英は資産保有者が地主なので議会が自動的に貴族的になる**（特例を書かずに反証1が解ける）。1890日本の地租15円有権者も同じ式 |
| `PrivilegeIntact` | 農奴制（`SerfEmancipation`）＋ 免税（1 − clamp(土地税+累進課税)）＋ 身分（`Bureaucracy`）の平均 | 執行権が貴族の特権を守っているか＝**符号が両方向に出る**（反証2・5） |
| `StatePatronage` | 関税 ＋ 国家発注（軍事費）＋ 秩序（`PublicOrder`）の平均 | 執行権が資本家に供給しているか（反証3） |
| `PopExecutiveLean` | 思想（保守族シェア）と供給の平均（閉鎖階級→特権／近代エリート→恩顧／他→思想のみ） | ★**階級の固定対応を書かない**。参政権拡大の**非単調性**もここから出る（反証6） |

## 3-2. 執行権 vs 議会

| 量 | 定義 |
|---|---|
| `StateCapacity`（**王そのもの**） | `FiscalFundingRatio × (組織された武力 ＋ 行政効率)/2`。★社会的支持が全部剥がれても執行権はゼロにならない／★財政破綻で貴族に譲歩（1787仏）と国庫潤沢で貴族を要らなくなる（ヨーゼフ2世・明治）が**両方**出る |
| `ParliamentGrip` | 年次議決の歳入（所得税＋累進）÷ 全歳入 と 起債（`GovDebt/NominalGdp`）の **noisy-or** |
| `LockedSpending` | 政体の国家軍軸 × `MilitaryFloorScale`（＋戦時の下限ロック） |
| `ParliamentEffective` | `ParliamentControl × ParliamentGrip ×(1 − LockedSpending)` |
| `ExecutiveWeight` κ | `(王そのもの ＋ 執行権側の基盤 ＋(1−pc)×議会側の基盤) / (王そのもの ＋ 1)`、下限＝`ArmyBaseline` |

⚠ **制度（`ParliamentControl`）を残した根拠**＝これは「広い参政権 × 低い統制力」（プロイセン/明治）を表すために作られた軸そのもの。**社会が基盤・制度が変換器**であって、どちらかがどちらかの代理ではない。

## 3-3. 軍部

| 量 | 定義 | 入力の系統 |
|---|---|---|
| `CivilianInstitutions` | 議会の実効統制・官僚の専門化・政党（参政権の開放度）・**正統性**の平均 | 制度 |
| `ArmyBaseline`（常在項） | `ArmyPoliticalWeight × 常備軍の対人口比 ×(1 − 文民制度の厚み)` | 組織 |
| `OfficerComposition` / `ArmyNobility` | 資格任用が開くほど平民将校が入る。⚠**徴兵法は入れない**（プロイセン＝皆兵＋ユンカー将校団が矛盾なく出る） | 制度 |
| `ArmyExecutiveTilt` | `(ArmyAllegiance ＋ 将校の任免権の所在 ＋(2×将校の貴族率−1))/3` | **人事系譜** |
| `ArmyBinding` | `|帰属| × 正統性` ⚠**金を掛けない** | 名分 |
| `OfficerGrievance` | 自律の喪失 と 身分の剥奪 の平均 | **制度**（賃金では動かない） |
| `SoldierWelfare` | 兵士POPの人口加重平均満足度 | **物質**（金は実質で測る） |
| `RanksLeak` | 兵の重み ×(1−実質待遇)×(1−規律の文民依存)×(1−組織労働) | **物質** |
| `OfficerLeak` | 常在項 × 将校の不満 ×(1−束縛)×(1−規律の文民依存)×(1−組織労働) | **制度** |
| `ArmyClaim` | 常在項・兵卒の漏れ・将校の漏れの **noisy-or**（自己有界） | — |
| `VetoPower` | 制度の梃子 × min(1, 軍部の総主張 ÷ `PartnerViableShare`) | 制度（法でない） |
| `Level` | 影響 → 恐喝 → 更迭 → 簒奪（議会が実効を持つ国は恐喝で頭打ち） | — |

## 3-4. 表の組み立て

```
執行権の列 ＝ 王そのもの ＋ Σ 各階級の（傾き分 ＋ 統制の無い議会の基盤の捕獲分）   倒し先＝王そのもの
議会の列   ＝ Σ 各階級の（議会側の傾き）× 議会の実効統制                          倒し先＝大衆
将校の列   ＝ 軍部 × (常在項＋将校の漏れ)/(…) を将校団の階級構成へ
兵卒の列   ＝ 軍部 × (兵卒の漏れ)/(…)（担い手＝大衆）
革命の列   ＝ 革命勢力の取り分（担い手＝大衆）
漏れ       ＝ 1 −(1 − 軍部の総主張)(1 − 革命勢力)   ★noisy-or＝自己有界
```

## ⚠ 欠陥A — `ParliamentGrip` が議会を全世界で消している

⚠ **1800年・1815年の12監視国すべてで議会の列が 0%**（立憲君主制の英も共和制の米も含む）。
★ 原因＝「歳入を止められるか」を *年次議決の税 ÷ 全税* と *`GovDebt/NominalGdp`* の noisy-or で書いたが、
**現物の税構成は人頭税・関税が主で所得税は薄く、国債残高もGDP比で小さい**（英1783で掌握 0.08・1815で 0.12）。
これを議会の変換に**掛けた**ので列ごと消えた。
⚠ **史学検証4の一般則（普憲法第109条／日憲法第71条）は正しい。誤ったのは起債の代理量**——
史実の英1783国債は対GDP150%超だが**現物には入っていない**。
★ 処方の候補＝(a) 掛け算をやめて下限つきの変調にする (b) 起債の代理を別の既存量へ替える
(c) 掌握を議会の**取り分**でなく**拒否権の強さ**の側だけに効かせる。

## ⚠ 欠陥B — `RevolutionLeak` に `RevolutionPressure` を使ったのはカテゴリの誤り

⚠ 英・米が**革命95〜97%**でパイを丸ごと飲んでいる。
★ 原因＝`Politics.RevolutionPressure` ＝ `clamp(動員 ÷ 実効保持力, 0, 1)` は、エンジンでは
**政体遷移の敷居判定に使う述語**であり、**動員が保持力を超えた瞬間に 1 へ飽和する**。
これを**取り分（シェア）として読む**と 1 に張り付き、noisy-or 経由で漏れ→1、本体（執行権＋議会）→0 になる。
⚠ **欠陥Bが欠陥Aを覆い隠していた**（漏れが1なら議会が0でも見えない）＝切り分けは **B → A の順**。
★ 処方＝革命勢力の取り分は**飽和しない量**（反体制動員の対人口比など）から引き直す。

### ✅ 欠陥Bの解消（2026-08-18・同日中に適用済み）

置き換え＝**制度が吸収しそこねた組織的不満**。

```
革命勢力 ＝ Politics.AvgMassMilitancy(w) ×（1 − Ideologies.Openness(w.Suffrage)）
```

★ 根拠＝作者の設計「権力は執行権と議会の奪い合いで、**漏れ**を軍部と革命勢力が担う」に照らすと、革命勢力の取り分は
「保持力に勝てるか」ではなく「**制度に入りそこねた不満がどれだけあるか**」でなければならない。
参政権を持つ大衆の闘争度は議会へ流れ、持たない大衆の闘争度が革命へ流れる＝**英1832/1867が運動を吸収した側**と、
**チャーティズムが参政権の外にあったから街頭に出た側**が、同じ機構の両面になる。
