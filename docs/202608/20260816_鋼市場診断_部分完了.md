# 鋼市場診断：なぜ131年間、鋼の世界価格は崩れないのか（2026-08-16・静的読解）

作者の問題提起：最速の鋼供給連鎖は世界価格より大幅に安く、溢れた中間財の輸出が**簡単・ノーリスク**で大金になる（鋼と素材が値崩れしない）。先行者レント自体は史実どおりOK＝欠けているのは第二幕（レント→参入→価格崩壊＝1873-96大不況）。修正はAIを賢くする方向・鋼の数値の外科手術禁止。

## 結論：4つの独立構造の重畳（どれか1つでは第二幕は起きない）

| # | 構造 | 所在 | 帰結 |
|---|---|---|---|
| β | **裁定流量の定数蓋**＝売り手Flowは在庫×規模×TradeSpeed(0.05)で**価格差を見ない** | BilateralMarket.cs:251-258 | 国内の値崩れが世界へ伝播しない・ダンピングで世界価格を下げられない＝「世界価格より大幅に安い」楔は生産性でなく**裁定の目詰まり**が作る |
| α | 「世界価格」は265州の局所価格の**単純平均という統計**（力学側の読み手ゼロ・Clamp下限0.1×Ref） | InternationalMarket.cs:20 / BilateralMarket.cs:218-228 | 日本8州が床まで崩れても表示は3%しか動かない |
| γ | 成約単価＝**次善の売り手の着値**（リカード的＝それ自体は正しい） | BilateralMarket.cs:287-308 | 問題はsecondDeliverを下げる主体が世界に現れないこと（B節） |
| δ | 輸入州の価格は**自国の限界費用に錨**（margin→Scale縮小→価格が自国費用へ戻る）＋鋼はIntermediate＝倒産しない | EconomyStep.cs:2041-2060, 2084-2090 | レント＝費用差−輸送楔が131年固定 |

## リスクの不在（早期重工業投資の5リスクが全て無害化）
- **倒産なし**：BuiltScale>0の棟は永久に倒産条件を満たさない＋鋼はTier免除（EconomyStep.cs:2084-2090）
- **赤字は国庫が自動全額吸収**：国営持分の永続補助金（意図された設計＝EconomyStep.cs:2021）＋Scaleの下限=BuiltScale＝不採算でも操業継続
- **恐慌の資本破壊はBuiltScaleに掛からない**（DepressionScrapRateはInd/ヴィンテージのスカラー3本のみ＝Simulation.cs:1648-1653）＝工場は1棟も消えない
- **恐慌時の世界同時需要崩壊なし**（伝染は資本フローのみ・BilateralMarketに恐慌項ゼロ＝CapitalMarket.cs:99）
- **国際市場の買い手に予算制約なし**：netFlow[買い手国]−=value は無条件・事後に全pop貯蓄から徴収（BilateralMarket.cs:328）＝破産寸前の国でも局所価格が高ければ買う。国内popは予算制約下（EconomyStep.cs:1209）＝**非対称**

## 鋼の買い手（BaseNeed=0＝pop直接消費ゼロ）
価格非感応シンク＝①民間建設（ConsSteel=1.0が最大シンク・投資額決定に材料価格が1文字も入らない＝EconomyStep.cs:551-587）⑤下流工場のLeontief投入⑥再点火トリクル⑧軍需（完成財の価格しか見ない＝鋼が安いと**調達量がむしろ増える**）。国家建設系はStateProcurePriceGateで高値側のみ絞る（安値では満額＝値崩れを止める力ゼロ）。
外資の行き先：**国庫には1円も入らない**（輸出課税なし）。資本家pop貯蓄50%＋全pop貯蓄比例＋基礎貨幣膨張→与信→金融スコア。

## AI資本が競争に来ない構造
- **B-1 私的投資にセクター選択が存在しない**：constructionはスカラー・固定束購入・Industrialization向け。財別の私的工場建設経路は**コード上に存在しない**（BuiltScale増はプレイヤー/AIのBuildFactoryとRGO自動投資のみ）
- **B-2 世界価格がAIに原理的に届かない**（Market.Price[]の読み手はUI/Validation/銀本位のみ）
- **B-3 AI国営の財選択は逆インセンティブ**：relExcess=局所価格/参照−1 →**安い輸入が来るほど建てない**（史実「安い英国鋼→独米が製鉄所+関税」の逆）＋四重ガード（FiscalStress=0必須・全国同時1件・月次0.10×バッファ・製鉄70,000は中小国に届かない・四半期1回＝年4棟）
- **B-4 近代化投資が工業化2.5で自主停止**（プレイヤーは5.0）＝secondDeliverを下げる主体の不在の直接原因
- **B-5 連鎖の逆算が実行不能**（1四半期1件・先読みなし・上流を建てると評価が反転）。ProductionDiag（価格/稼働率の分解・純関数）は**UIしか読んでいない**＝プレイヤーだけが律速を読める
- **B-6 技術は参入障壁でない**：鋼はComplexity3≤FreeDepth6＝1783年から全61カ国が生産可能。止めているのは判断機構のみ

## 2. 恒等の作り方（0で新しい読み書き・注入・診断呼び出しがゼロであること）

- **否定形ガード**：`if (!(coef > 0)) return;` / `bool relax = coef > 0;` ＝有限値では厳密同値・NaN は**休眠側**へ倒れる（`pob-nan-fail-open-guards`）。
- **確保しない**：#3 の `pendingRegion`/`bestGr`/`bestScoreR`、#2 の `World.WorldGoodsPrices`、#5 の `_importEma` は**フラグONのときだけ**新規確保する。
  0では配列が存在しない＝「読み手が null 枝しか通らない」ではなく「そもそも配列が無い」＝取り違えようがない。
- **注入側で止める**：#2 は読み手（SelfPlay）だけでなく**書き手**（MultiNationSim の四半期同期）を係数で囲った。
  番人テスト `世界価格の注入はフラグが握る`（OFFを明示ピンして2四半期回すと全国 `WorldGoodsPrices == null`／ONでは非null）がこれを固定する。
- **式を通す**：#1 は分母を定数からヘルパ呼び出しに替えたが、0で `IndustrializationCeiling` を返すので**ビット恒等**。
  単一国シムは `IndustrialFrontier=0` なので α>0 でも 2.5 のまま＝較正・単体テストは点火後も不変。
- **純関数だけを読む**：#4 が呼ぶ `ProductionDiag.ExplainCost` は力学の状態を1ビットも書かない（`StepLawToward` が `GateInfo` を読むのと同じ作法）。
- **条件時のみ書く**：#5 は条件が成立した四半期だけ `TariffTarget` に触る。関税スライダーは `CountOpenFronts`（Government.cs:247）の対象なので、
  毎期無条件に書くと**幽霊戦線を1本増やし**全軸の政治押し予算 (1/N)^0.5 を薄める。条件が引けば戦線は自然に閉じる
  （`Move` が `w.Tariff` を目標へ寄せ、差が5%量子化を割れば戦線から外れる／産業・軍備スタンスは翌期に自分の定数で目標を書き直す）。
- **順序**（#5の要）：関税目標の既存の書き手3つ（`Apply` のスタンス定数／ダンピング解除／`RelieveOpulence` の減税乗算）の**後**に置く。
  前に置くと同じ四半期の `Apply` が上書きして反射が一度も効かない＝「衝突」ではなく「無効化」になる。
- **セーブ**（設計判断・確認済み）：`SaveGame` は `MultiNationSim` から全インスタンスフィールド（private/readonly含む）を辿るので、
  `Simulation._agent` → `UtilityAgent._importEma`（double[]）も、`World.WorldGoodsPrices`（double[]）も**自動で往復する**。
  専用のセーブ/ロード処理は書いていない（陳腐化しない）＝点火後も savetest はビット一致のはず。新しい**値型**は1つも増やしていない
  （既存の `double[]`＝`ExportsByGood/ImportsByGood` と同型）＝`pob-savegame-primitive-gap` の罠は踏まない。
