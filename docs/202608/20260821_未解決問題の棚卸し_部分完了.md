# 初期状態の手置きの限界について（作者の問いへの見解）

> ★ 作者「初期状態を手置きすることに限界があると思うが、あなたの見解は？」

**半分同意です。ただし限界があるのは「手置きそのもの」ではなく「結果だけを手置きして、それを支える在庫を置かないこと」だと考えます。**

英の識字0.84が維持できないのは、手置きが多すぎるからではなく**少なすぎる**からです：識字という**結果**は置いたが、それを支える**教育市場の在庫**（教師POP・EducationFill・教育支出の慣性）を置いていない。だから1か月目から「支えの無い識字」として減衰が始まります。仏だけに国債を置いて英に置かなかったのも同型（結果の一部だけを写した）。

選択肢は3つ：
1. **原因だけを置いて結果を創発させる**（教育制度と支出を置き、識字は助走で収束させる）＝理屈は美しいが、**1783年の識字は1600年からの蓄積**であり、151年のゲームの前に180年の助走は回せない。⚠却下。
2. **結果を置き、支えを逆算して一緒に置く**（識字0.84を置くなら、それを維持するのに要る EducationFill・教師POPを式から逆算して同時に置く）＝★**推奨**。手置きは1国1点のままで、整合だけを機械が保証する。「初期整合パス」として起動時に1回走らせれば、world.json の列を増やす必要も無い。
3. **減衰の側を史実の物理に合わせる**（識字は一生もの・失われるのは世代交代分だけ）＝`LiteracyDecayIsGenerational`（休眠実装済み）。**2と独立に正しい**ので両方やる価値がある。

つまり「手置きの限界」の正体は**整合性の未検証**です。手置きした値の間の整合（識字↔教育供給・国債↔議会の実効・特権↔貴族の政治力）を**起動時に検算して警告する**仕組みを入れれば、手置き自体は今後も最良の方法だと考えます——初期条件は歴史であり、歴史は創発できないからです。
