PairKm = min( 海経由（従来）, 陸直行（PathGraph の最短路 × LandSeaCostRatio） )

2. 海外植民地の**征服**の付け替え（CedeTerritory は首都距離制約で遠方植民地が外れる＝制海権×海路の旧経路を州側へ）
3. 昇格後の空白を provgap で測り直し→州の追加（作者指定＝座標の最長距離を州数1.5倍相当＝約850kmまで）
4. (2)鉄道と人力の分離（陸の辺の属性）
5. (3)地形の1枚表（places.json に列を足す・**作者レビュー1回**＝運河の指定は作者判断）
6. (4)余剰の再配分／(5)輸送コストの較正（監査済みの参考＝RGOのRefPrice全て0.54・石炭1万kmで着値×2.75・史実の3〜5倍高）
7. Locked の完全削除・instprobe/armsdebug 等の計器はそのまま恒久化

# 5. ★ 計器（このラウンドで新設）

| 計器 | 何を出すか |
|---|---|
| `timeprobe` | 構築/助走/本走の所要と内訳（POB_TIME=1で日次/市場の分解） |
| `provgap [追加数] [格子] [島嶼閾値]` | 陸マスク→州の面積・空白地点・最遠点貪欲法の候補（島嶼除外つき） |
| `transportsplit [Q]` | 輸送力の州割りの取りこぼし（頭割りvsプール） |
| `instprobe` | 4カ国世界の制度閾値の内訳（Freedom/Elite/ブロック力/法/政体） |
| `armsdebug <seed> <国> <from> <to>` | 1国の軍需在庫・発注・生産者採算の時系列 |
