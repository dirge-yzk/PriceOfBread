## 1. 機構（2段・全て休眠）

### 1a. 入植（Colonial.Step §2b・月次）
`Colony` に入植者の器を追加（`SettlerSize` / `SettlerSavings` / `SettlerLiteracy`）。
本国の大衆（農民・労働者）が植民地へ移住する：

```
flow = ColonySettlerRate × 本国大衆の総数 × attract        （上限＝母数の月1%＝物理停止弁）
attract = 1/(1 + 海路距離km/10000) × (マラリア地 ? キニーネ鎮静率 : 1)
```

- 距離＝維持費・独立holdと**同じ海路距離**（スエズ/パナマ開通で短絡）＝新係数を作らない
- マラリア＝**キニーネ鎮静率（malariaFill）そのもの**＝「白人の墓場」はキニーネが届くまで入植が立たない＝アフリカ分割の物質的前提が入植側にも働く
- **農奴の門**＝農民の送出は農奴解放の法段階（None=0／Limited=0.5／Full=1）で律速。労働者（賃労働）は常に自由。
  ⚠これが無いと**露の巨大な農民プールがアラスカを1年で入植過半にする**（試算＝月1.7単位・史実の露領アメリカは露人800人）。
  英Full/蘭Full＝入植帝国、仏西葡Limited、露普日None→**解放後に入植が始まる**（シベリア/1861年の史実の順序が法から出る・国名条件ゼロ）
- **保存則**＝送出popから Size/Savings を物理移転（越境移民 MigrateBetween と同型）。植民地は台帳の外なので `PopulationDelta −=` / `CumulativeTradeFlow −=` で国家台帳を閉じる
- 入植者の人口動態＝現地住民と同じ月次成長・マラリア死。**搾取死は受けない**（搾取の主体側）
- 乱数不使用＝決定論。台本なし＝国名条件ゼロ（距離・マラリア・法・人口という物理だけ）

### 1b. 昇格（Colonial.Step §5・月次）
```
昇格 ⟸ SettlerSize/(SettlerSize+PopSize) > ColonyPromotionCoreShare(0.5)
     かつ SettlerSize+PopSize ≥ ColonyPromotionMinPop(60)
```
`ColonyPromotionMinPop=60`（6万人）＝**北西部条例1787「自由人口6万人で州昇格を申請できる」**の一次データ。

追加ガード＝**同名州が既に居る国では昇格しない**（例：蝦夷地＝日本の辺境州と征服標的の二重在籍。州名は座標表・地図・扼者解決のキー＝一意性を守る）。

昇格＝`Simulation.PromoteColonyToRegion`（BuildFrontier を雛形にした完全な州の実体化）：

| 項目 | 値 | 根拠 |
|---|---|---|
| Tier / HeldSince | Integrated / 現在年 | 原典裁定（議席あり・維持費なし・Coreにしない） |
| IsPort / 座標 | true / Climate.CityCoord(植民地名) | 作者指示2026-08-02「植民地は全て港州」。座標＝史実の積出港（landmask機械検証済み） |
| pop | 現地住民＋入植者**だけ**。骨格11階級は Size0（辺境の兵士Size0と同じ作法）＝社会移動・国内移住が埋める | 保存則＝湧かさない |
| 現地住民 | 農民pop へ（Literacy/Militancy/蓄えを運搬・**CoreEthnicShare=0**） | 民族の実体＝分離圧力・同化・国民意識が既存機構で働く |
| 入植者 | 農民/労働者へ着地（AddImmigrants と同型・Ind0＝農民寄り）・CoreEthnicShare=1 | 州平均コアシェア＝昇格条件を映す |
| 農制 | 自作農（farmLordShare=0・プランテーション上書きなし） | 北西部条例/ホームステッドの物理（昇格の定義＝入植者多数の州） |
| 市場在庫 | **0で開始**（初期200を持たせない） | 「AI国庫×初期在庫200の開幕工業化バースト」（indprobe実測2026-07-27）を新州で再現しない |
| 台帳 | `PopulationDelta += P` / `CumulativeTradeFlow += S`（州の実合計値＝両辺同値） | AddImmigrants / CedeTerritory の作法 |
| Id | 既存max+1の非ゼロ | CedeTerritory と同じ（Id0=首都不変条件） |
| Culture/Religion | 首都州と同じ | 入植者多数＝本国文化が主流。現地の民族はCoreEthnicShareが担う |

## 2. 座標追加（45件）

`Geo.ColonyCoord`（46植民地・史実の積出港・landmask機械検証済み）を `Climate.CityCoord` へ**同値で複写**
（Geo.cs:59 の予告「昇格時はこの表から Climate.CityCoord へ移す」の実施）。蝦夷地のみ Climate 既存値を維持＝重複回避で**45件**。
App側も対で追加＝`MapData.CityCoords` 45件＋`MapData.CityEn` 45件（未登録だと昇格州が地図から消える／和名で浮く）。

⚠ `Geo.ColonyCoord` 自体は**据え置き**（Climateへ委譲すると蝦夷地の座標が 43.1,141.3→43.06,141.35 に動き、
植民地段階の距離計算がビット単位で変わる＝恒等が壊れる）。**新植民地を足すときは Geo/Climate/landmass.json/MapData の4箇所へ同値で**。

## 4. 接続の確認（実装時に検証した危険箇所）

- **チョークポイント**：host植民地が昇格しても `ResolveOwner` が Region 保有国へフォールバック（MultiNationSim.cs:725）＝扼者は途切れない
- **忠実度計器**：昇格で `s.Colonies`（ColonyProvinces1914軸）が減り、HomeProvinceCount が増える（上振れは不問）＝**帯リスクの本体**（§6で実測）
- **国内移住・議会・分離独立**：昇格州は通常の州として全機構に自動参加（Integrated＝議席あり）。現地住民はCoreEthnicShare=0で民族機構に載る
- **保存量プローブ**：Colonial.Step 直後の `ProbeCheck("月次植民地")` が入植/昇格の記帳漏れを検出する位置にある（leakhunt恒久化の内側）
- **セーブ**：Colonyの新フィールド3本はリフレクション直列化が自動追従（double＝既存Tag）。savetest実施（§5）
