# 1. ★★★ 診断 — なぜ議会が意識されないか

## 1-1. 議会はちゃんと止めている


★ **止めていないのではない。**⚠ **プレイヤー側の操作の形が問題である。**

## 3-0. ★★★ 骨格（★ 作者裁定 2026-08-14）

## 3-7. ★★★ 権力は3つのパイである（★ 作者裁定 2026-08-14）

> ⚠ **正統性だけでは「打ち倒されない政権」を表現できない。**
> ★★★ **権力を3つに分け、それぞれを4つの主体が奪い合う。**

### ★ 骨格

```

予算権 100% ＝ 王権 ＋ 議会 ＋ 軍部              ⚠革命勢力は持たない
統帥権 100% ＝ 王権 ＋ 議会 ＋ 軍部 ＋ ★革命勢力
```

| パイ | ★ 意味 | ⚠ 欠けると |
|---|---|---|
| ★**正統性** | **名分**（★ 誰が統治すべきか） | ⚠ 支持されない |
| ★**予算権** | **金**（★ 誰が資源を配分するか） | ⚠ **統治できない** |
| ★**統帥権** | **力**（★ 誰が暴力を独占するか） | ⚠⚠ **打ち倒される** |

★★ **これはウェーバーの支配の3資源とほぼ一致する**——⚠ 正統性・行政（財政）・暴力の独占。

### ★★★ 3つ揃って初めて安定した統治になる

⚠ **欠けると、それぞれ違う病理が出る：**

| ⚠ 欠けるもの | ★ 帰結 | ⚠ 史実 |
|---|---|---|
| ⚠ **正統性だけ無い** | ★★ **打ち倒されないが支持されない** | ⚠⚠ **プロイセン 1862-66**（★ 下院が予算を拒否しても**軍が王に従った**のでビスマルクは統治できた） |
| ⚠ **予算権だけ無い** | ★ **統治できない** | ⚠ 憲法紛争1862／★ **1909年 人民予算**（貴族院が拒否） |
| ⚠⚠ **統帥権だけ無い** | ★★★ **クーデタで倒れる** | ⚠ 1926ポーランド／1930s日本／1936スペイン |

★★★ **「国民からは支持されていないが打ち倒されない政権」が、この表1つで説明できる。**

## 3-7a. ★★★ パイが縮むと、協力せざるを得ない

```
奪って得られる利得   = Δシェア × パイ
協力して得られる利得 = Δパイ  × 自分のシェア
```

⚠ **パイが大きいときは、奪うほうが得**（★ 1%を奪えば大きい）。
★★ **パイが小さいときは、奪っても意味がない**（⚠ 1%が小さい）→ ★★★ **パイを大きくするほうが得。**

⚠⚠ **これは「分配ゲーム → 生産ゲーム」の切り替えである。**
★★★ **したがって「協力度」という別の量は要らない**——⚠ **パイの水準が、そのまま協力の動機になる。**

| 事例 | ⚠ 何が起きたか |
|---|---|
| ⚠ **1789 三部会** | ★ 財政破綻 → **王が175年ぶりに議会を呼んだ** |
| ⚠ **1832 英選挙法改正** | ★ 革命の脅威 → **貴族院が折れた** |
| ⚠⚠ **1914 城内平和** | ★★ 開戦＝国家の危機 → **王権と議会が休戦した** |
| ⚠⚠⚠ **1917 ロシア** | ★★★ **正統性が崩壊し、王権も議会も両方が消えた**——⚠ **協力が間に合わなかった** |

★★ ⚠ **協力しても間に合わないことがある。★ それが革命である。**

## 3-8. ★ 3つのパイの中身

### 3-8a. ★★ 正統性 — 革命勢力も持つ

### 3-8b. ⚠ 予算権 — 革命勢力は持たない

### ★★★ 取り分は「誰がどれだけ動かせるか」そのものである（★ 作者裁定 2026-08-14）

# 4. ★★★ 強権（`MandateSpent`）の廃止 — 正統性へ統合

> ⚠ **作者裁定 2026-08-14：強権（`MandateSpent`）は廃止し、正統性に統合する。**
> ★ **警察力（`Coercion`）は残す。**

## 4-1. ★ `MandateSpent` は既に3役しか持っていない

```csharp
World.cs  MandateSpent      // ★消費ストック（MandateRecoveryRate で減衰・上限なし）
World.cs  MandateSpentNew   // ★今期増分

```

| 役 | ★ 読み手 | ⚠ 廃止したら |
|---|---|---|
| ★**①正統性への減算** | `Politics`（`leg -= MandateSpentNew`） | ★★ **`w.Legitimacy` を直接引けばよい**（⚠ 二重計上に注意・§4-3） |
| ★**②UIの「強権」表示** | `GameViewModel.Refresh.cs`（`CoercionHeaderText`） | ★ **消す**（⚠ 作者指示「強権は廃止」） |
| ⚠**③紛争記憶** | `CrownParliament`（`memory = Min(1.0, MandateSpent)`） | ⚠⚠ **代替が要る**（§4-4） |

## 4-2. ★★★ 押し切れる余白は、既に正統性だけから決まっている

```csharp
Government.MandateMargin(w, a, targetLevel)
    theta = w.Coef.MandateWeight * (w.Legitimacy - 0.5);
    theta = w.Legitimacy < 0.5 ? theta * MandateNegativeScale : theta;
    if (theta > 0) theta *= w.PoliticalPushBudget;                        // ★開いた戦線数で正規化
    if (IsConstitutional(a, targetLevel)) theta *= ConstitutionalMandateScale;  // ★憲法級は押し切れない
```

★★★ **`MandateSpent`（ストック）は余白に一切効いていない。**
⚠ **したがって、廃止しても「押し切れる/切れない」の判定は1ビットも変わらない。**

## 4-3. ⚠ 二重計上の罠（★ 既存のコメントが警告している）

```
// ★「ストック正統性では前期の減算が残留する→毎期ストック全額を引くと増幅率≈1/RegenRate=50倍の二重計上
//    （一歩ΔM=0.125で累積≈6.25＝即崩壊・2026-07-10再設計）
//    →【今期増分 MandateSpentNew だけを一回減算】し、回復は再生項に一本化」
```

★★★ **`MandateSpentNew`（今期増分のアキュムレータ）は残す必要がある。**

## ★★★ 9-e. 解散 — 公約を果たせたかで裁く（★ 作者裁定 2026-08-14）

> ⚠ **議会が停滞すれば解散する。★ 解散のしやすさは政体による。**
> ★★★ **議会の正統性は「選挙で議題に上がった法律を通せたか」で判断する。**
> ⚠⚠ **通せずに解散した場合、解散した側の正統性にダメージが入る。**

★★ **これは「プレイヤーが選挙を前倒しする動詞」ではない。**⚠ **盤面の状態から自動で起きる帰結**である（思想①＝台本禁止に沿う）。

### ★★★ 9-e-1. 公約 — 選挙で出した議題3つが、そのまま約束になる

★ §3-2 で、選挙のたびに**議題3つ**（`ComputeDemands` の上位）を提示している。
★★★ **その3つを「今期の公約」として記録する**（⚠ 新しいフィールドは**1本だけ**＝軸3つの配列）。

```
選挙  → ★議題3つを提示（★ComputeDemands の上位）
       → ★★その3軸を【公約】として保存
次まで → ★Government.StepEnum が、その3軸を動かせたかを見る
       → ★★★達成率 ＝ 動いた軸数 ／ 3
```

⚠ **新しい判定を1つも作らない**——★ 「通ったか」は `MandateGate` が既に返している。

### ★★★ 9-e-2. 空振りの判定 — 選挙結果ではなく、公約の達成

⚠ **当初案（同じ党が第一党なら空振り）は却下する。**

| 案 | ⚠ 却下理由 |
|---|---|
| ⚠ **A：解散前と同じ党が返ってきたら空振り** | ★ 単純だが、⚠⚠ **党が替わっても法が通らなければ意味がない**（★ 議席の入れ替えでなく**立法の停滞**が問題） |
| ★★★ **B（採用）：公約3つを通せたか** | ⚠ **約束を果たしたかで裁く**＝★ **議会が機能しているかの直接の物差し** |

```
                  ★★★議会制の信認が削れる（RegimeTrackRecord[1]）
                  ＝⚠ワイマール末期・第三共和政の短命内閣
```

★★★ **`RegimeTrackRecord[0]`（君主）と `[1]`（議会制）は既に別ストックとして存在し、既に点火済み**である（§9-e-6）。

### ⚠ 9-e-4. 解散しなければ罰は無い

★ 罰は**解散という行為**に紐づく。⚠ **停滞したまま解散しなければ、正統性は削れない**（★ ただ何も進まないだけ）。

| | |
|---|---|

| ⚠ 負ければ | ★★ **解散した側の信認が削れる** |
| ★ 賭けなければ | ⚠ **停滞が続く**（★ 法が1本も動かない） |

### ★ 9-e-5. 解散権の所在は政体による

| 政体 | ★ 解散権 | ⚠ 史実 |
|---|---|---|

# 11. ★★★ 緊縮を「政治」へ置き換える（★ 作者裁定 2026-08-14）

> ⚠ **緊縮（`Austerity`）の意図は正しかった。★★ 経路が間違っていた。**

## 11-0. ★ 元の意図（★ 作者の説明・2026-08-14）

> ★★ **国債の買い手は資本家であり、資本家は弱者救済を拒む。**
> ⚠ **つまり「国家が国債の買い手に逆らえない」という機構の表現であった。**

★★★ **この直感は正しい。**⚠ **19世紀の財政政治そのものである**——
★ 借金が嵩むほど債権者（★ 資本家）の発言力が増し、⚠ **緊縮と逆進課税が「市場の要求」として押し付けられた。**

## 11-1. ⚠⚠ しかし実装が「見えない手」だった

```csharp

// ⚠「借金がかさむほど【弱者救済を削り】【逆進課税を上げる】」
// ⚠「貴族免除の人頭税＝【負担は弱者に集中】」
```

⚠⚠ **誰も決めていないのに、国庫が勝手に弱者救済を削り、逆進課税を上げる。**

⚠ **「誰が決めたか」が消えると、プレイヤーもAIも介入できない。**

## 11-2. ★★★ 置き換え — 既存の鎖4本が、既に繋がっている

⚠ **新しいルートを作る必要はない。**★ **緊縮という近道が、既にあるルートを隠していただけである。**

```csharp

                // ★★★自由主義 ＝ 資本（【富裕】非地代）・教育

③  InterestGroups.Blocs(w)
    LandedWealth(p) = Savings + (Closed ? 土地の資本化 : 0)
    // ★★ブロック力 ＝【富のシェア】——⚠資本家が富めばブロック力が上がる

    // ★「給付は受ける側が賛成」＝⚠資本家は反対
```

★★★ **借金 → 資本家が富む → 自由主義が伸びる → 社会保障が通らなくなる、は既に成立している。**

## 11-3. ⚠⚠ ただし富裕化は【2つ】に分岐する

```csharp
Ideology.cs
double rich    = Clamp01((wealthRel - 1) / 3.0) * 3.0;   // ★平均超の富（＝失う物）
double conserv = Clamp01(rich / 2.0);                     // ⚠反動への執着（富裕ほど強い）

```

★ コメントが明示している：⚠ **「富裕ほど旧秩序を脅かす急進左派を恐れ反動化 ＝ 1848のブルジョワ反動」**

| ⚠ 条件 | ★ 富んだ資本家の行き先 |
|---|---|
| ★ **意識（`cons`）が高い・社会が安定** | ⚠ **自由主義**（★ 参政権拡大・自由貿易を求める） |
| ⚠ **闘争度（`mil`）が高い・社会不安** | ★★★ **反動**（⚠ 労働者の蜂起を見て秩序へ回帰） |

★★ **これは史実そのものである**——⚠ **1830年代の資本家は自由主義、★★ 1848年以降は反動。**

⚠ **どちらも「社会保障を削る」方向なので結論は同じ**だが、★ **通る法の中身が違う**（⚠ 自由党なら自由貿易・保守党なら検閲強化）。

## 11-4. ★★★ そして選挙と直結する

⚠ `ComputeDemands` は**ブロック力で重みづけ**される（★ `score = strength × Headroom`）。

```

  → ★資本家が富む
  → ⚠ブロック力が上がる

```

★★★ **これが「見えない手」と「政治」の決定的な違いである**——
