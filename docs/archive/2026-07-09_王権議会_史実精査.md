# 王権-議会の史実精査（2026-07-09）— 並列2軸モデルに必要な挙動の抽出

対象期間1789-1914。目的＝「政体ラダー廃止・王権/議会の並列化」案（2026-07-09_設計メモ）に必要な**挙動要件**の導出。

## 1. 史実の主要構成（モデルが表現すべき状態空間）

| 国 | 構成 | モデル上の含意 |
|---|---|---|
| 英 | 王権は既に象徴化（1689年決着）。19世紀の闘争は**議会内部**（選挙法改正1832/67/84＝franchise拡大） | 王権≈0・議会1.0の端点。動学は「議会の中の民意拡大」＝現行Suffrage機構で表現済み |
| 仏 | **振動**：絶対王政→革命議会→ナポレオン（人民投票的独裁）→復古王政の欽定憲章→七月王政→48年共和→ナポレオン3世（**選出大統領の自己クーデタ**→後年「自由帝政」譲歩）→第三共和政 | 革命/敗戦による不連続ジャンプ・**合法的後退（自己クーデタ）**・人民投票的正統性のハイブリッド |
| 普/独 | **憲法紛争1862-66**＝議会が軍事予算を拒否→ビスマルクは**予算なしで統治**（忠実な軍+官僚+王権正統性）→普墺戦争勝利→**事後免責（Indemnität）**で議会が追認。帝政期＝男子普選のReichstagはあるが**大臣は皇帝にのみ責任・軍は議会統制外** | **最重要事例**：議会の「存在/franchise」と「行政・予算・軍への統制力」は**別次元**。勝利→正統性→強行の追認、という換金経路 |
| 露/墺 | 革命圧力下の渋々の下賜（1905年ドゥーマ＝敗戦+革命で強制）→**ストルイピンのクーデタ1907＝選挙法を狭める後退**。基本法で王権留保 | 下賜は圧力の関数・下賜後の**部分的後退**が現実に起きる |
| 日 | **明治欽定憲法1889**＝王権が主導権を保ったまま**先制的に**議会を下賜（正統性・国際的地位のため）。予算不成立時は前年度予算執行＝**議会の予算武器を設計段階で弱体化**。元老・統帥権は議会外 | 「上からの改革」の完成形＝**弱く設計された議会**という選択肢。現行ReformFromAboveの延長線 |
| 墺斯曼 | 1876年憲法→**1878年スルタンが停止（議会を30年間廃止＝完全ロールバック）**→1908年青年トルコ革命（**軍が議会を強制再開**） | 後退の極端形＝停止。軍の帰属が決定打 |
| 西/中南米 | プロヌンシアミエント＝**軍が王権と議会の仲裁者**として振る舞う | 軍の忠誠は独立した第3の状態 |

## 2. 抽出された動学（＝必要な挙動）

- **A. 下賜（上からの改革）**：圧力対応（露1905）or 先制（明治）。**下賜は「弱く」設計できる**（予算トリック・大臣責任の留保・制限選挙）→ 実装済みのReformFromAbove(0.4)の一般化で表現可能。
- **B. 議会権限の多次元性**：franchise（現行Suffrageが担当）と**行政・予算統制力**（新規軸）は独立。プロイセン/明治＝「広いfranchise×低い統制力」が実在＝**1軸では表現不能の決定的証拠**。
- **C. 予算闘争が議会の主武器**：拒否→王権の対抗は「予算なし統治」（要：軍の忠誠+正統性+官僚）。**勝てば追認（免責）＝強行の事後正当化**。→ ゲーム的には「議会が財政スライダーを拒否 vs 王権がマンデートを燃やして強行」＝**実装中のマンデートマージンがこの闘争の核を既に持つ**。勝利→正統性回復（追認）の換金経路が追加要件。
- **D. 戦争の勝敗が均衡を動かす**：勝利→王権へ（普1866）・敗戦→議会/革命へ（仏1870・露1905/1917・WWI後の4帝国崩壊）→ DefeatShock実装済み・勝利側の正統性ブーストが追加要件。
- **E. 合法的後退**：自己クーデタ（ナポレオン3世）・選挙法縮小（ストルイピン）・停止（墺斯曼1878）。要件＝高い王権正統性or軍の忠誠+危機の口実。→ **実装中のワイマール機構の一般化**（後退の段階：franchise縮小→統制力剥奪→停止）。
- **F. 軍の帰属が憲法紛争の決定打**：普（王権側→王権勝利）・露1905（忠誠維持→体制生存）vs 1917（離反→崩壊）・青年トルコ（議会側→再開強制）。→ **「軍は王権と議会のどちらに応えるか」が独立状態**として必要（現行の軍事クーデタ機構の一般化）。
- **G. 正統性の源泉が二系統**：王権＝王朝的/宗教的/成功による・議会＝選挙的/人民的。ボナパルティズム＝王権型執行部×人民投票正統性のハイブリッド（現行BourgeoisDictatorship系で近似可）。→ 単一Legitimacyを「王権分/議会分」に分けるかは設計判断（LegitimacyIsStock #17と同時にやるべき）。
- **H. 財政破綻が議会を呼ぶ（原点）**：1789年全国三部会＝**破産した王権が課税同意のため議会を召集**。金が要る→同意が要る→権力を割譲。→ **最も創発的なフック**：国庫危機×新税needs→議会力の強制上昇（StateRevenueAllTaxes圧と接続可能）。「代表なくして課税なし」の逆＝「課税のためには代表を」。

## 3. ゲームへの写像（既存 vs 新規）

**既に持っている部品**：下賜（ReformFromAbove）・革命/敗戦ジャンプ・選挙/議席/綱領・軍事クーデタ・マンデートマージン（=予算闘争の王権側）・franchise軸（Suffrage）・敗戦ショック。

**新規に必要**：
1. **議会統制力**（franchiseと独立の第2議会軸）＝大臣責任・予算権の強度
2. **予算闘争イベント**（議会拒否→無予算統治→勝利で免責 or 敗北で譲歩）
3. **勝利→正統性ブースト**（Dの勝ち側・免責の原資）
4. **軍の帰属状態**（王権/議会/自律の3値 or 連続）
5. **破産→議会召集/強化**（Hのフック）
6. 後退の段階化（E：縮小→剥奪→停止）

## 4-b. 拡張（ユーザー発案2026-07-09）：力関係 × 協力度の2次元

力関係（支配される議会/制限する議会/無力化した議会）だけでは動機が表現できない。**協力度（協調⇔敵対）を直交軸**に加えると史実の全構成が埋まる：

| | 協力（利害一致） | 敵対 |
|---|---|---|
| **王権支配** | **翼賛議会**＝議会を利用する王権（ナポレオン3世の人民投票議会・ビスマルクの普選の賭け＝大衆でブルジョワ自由派を挟撃・正統性ロンダリングと課税同意の装置） | 憲法紛争（普1862）・**議会をつぶしたい王権**（墺斯曼1878停止の誘惑） |
| **均衡** | 立憲的協調（機能する立憲君主制） | **二重権力**（露1917二月〜十月・1848フランクフルト vs 諸侯）＝**最不安定・ショーダウン（クーデタ/内戦/一方の屈服）で解消される過渡状態** |
| **議会支配** | **象徴君主制**（英の帰結＝王権は協力的で有用だから生存） | 廃位待ちの王権（仏1792/1848） |

**含意**：
- 協力度は各構成の**安定性と軌道**を決める。二重権力＝「均衡×敵対」の角＝革命前夜の状態として自然に定義される（既存の内戦機構＝challenge vs coerce に接続）
- **AIの動機が書ける**：協力的議会を持つ専制＝議会を**維持**する（安い正統性+課税同意）／敵対的議会×高王権＝停止・後退の誘惑（実装中のワイマール機構の一般化）
- **協力度は創発的に導出できる**（このプロジェクトの流儀）：ストック新設でなく、①**政策距離**＝与党綱領と現行Policy目標の乖離（既存データから計算可能）②**紛争の記憶**＝マンデート燃焼の履歴（本日実装のMandateSpentがそのまま敵対の蓄積器になる！）③譲歩で回復。＝新規状態は最小で済む
- 協力度の効果側：協力的議会→王権正統性への上乗せ（ロンダリング）・財政同意ボーナス／敵対→立法停滞・二重権力リスク

## 4-c. ユーザー方針の明確化（2026-07-09）：「近代化した幕府」は可
幕府の存続＝鎖国の維持とは限らない。**近代化しつつ幕府のまま**（史実でも慶応期幕府は仏式陸軍・横須賀製鉄所と近代化していた＝大政奉還が無ければ「近代化した幕府」は実在しえた）も稀な経路として歓迎。
**含意**：現行の問題は「近代法の採用→政体ラベルが立憲に遷移」という**ラベルと法の結合**にある。TraditionalistLawGate（黒船ゲート）は**暫定処置**＝AI挙動の抑制で出現数を守っているだけ。**本筋は本ドキュメントの2軸化**：政体ラベルを制度構造（王権優位×議会の有無/統制力）から導出すれば、「近代法を持つが議会に権力を渡さない幕府」＝プロイセン型の日本版が自然な点として存在できる。2軸化の際に TraditionalistLawGate は縮小/撤去候補。明治維新の頻繁化も「外圧→王権が議会を弱く下賜」の経路として非外科的に出る。

## 4. 結論
「王権1軸×議会1軸」では**プロイセン/明治型が潰れる**（B）。最小構成は**王権正統性×議会franchise（既存）×議会統制力（新規）＋軍の帰属（新規）**の3.5軸。段階導入案（設計メモ）の(i)は「議会統制力」の内部状態化から始めるのが史実適合的。前提のLegitimacyIsStock（#17）はC/D（追認・換金）の土台として必須。

## 5. 政治システム4アクター案（ユーザー設計2026-07-10）と判断
**構成**：王権（正統性保持）・軍・議会（常設3〜4政党）・世論——各々独立し協力度を持つ。

**判断①：4勢力で十分か → 十分。ただし役割の型が異なる**
- 王権・軍・議会＝**貯蔵される制度**（状態を持つ機関）
- 世論＝**派生面**（pop層の満足/闘争/意識/イデオロギーの集計＝既存データの表面。新規状態ほぼ不要。行動経路は投票・街頭・正統性承認の3つ）
- 軍の独立アクター化は史実精査F（軍の帰属が憲法紛争の決定打）の正式化＝妥当

**判断②：利益団体（trad/modern/massブロック）は廃止でなく降格**
- ブロックは「階級＝物質的基盤」・4アクターは「機関＝権力の器」で**別レイヤ**。廃止すると経済→政治の創発（本作の魂）が切れる
- 再配置：ブロックは**各機関のスタンスの給源**になる（王権の基盤=旧支配層・議会政党の支持=各ブロック/pop・軍=将校(旧支配層)×兵卒(大衆)の合成・世論=pop加重）。**法のゲート権はP2で機関へ移譲**（現行のNetSupport直接ゲート→王権×議会×軍の機関間解決へ）。ブロック自体はpop派生の計算量なので保持コストほぼゼロ

**判断③：協力度は6ペア行列でなく3チャネル**：軍↔王権・議会↔王権・世論↔体制。導出（政策距離＋階級親和）＋紛争記憶ストック（MandateSpentの前例）。議会↔世論は選挙が既に担う

**必須要素2件（ユーザー指定）の機構化**
1. **識字不足×自由選挙→極端政党へ**（肉屋を支持する豚）：識字率=論理的判断力と定義。投票配分に extremity 項＝(1−識字)×(不満 or 闘争)で極端政党（反動/共産/無政府/帝国系）へ流れる。**識字(判断力)と政治意識(動員度)は直交**＝「高意識×低識字」が最危険回廊（ファシズムの大衆基盤）として自然に表現される。※受け皿問題：現行3政党は穏健系のみ＝**極端政党は創発的国内勢力（Faction）の政党化で第4党として供給**（設計メモ3と接続）
2. **文盲の不満は暴力へ**：不満のルーティングを識字で分岐＝識字者→投票/政党/請願（議会圧力）・文盲→暴動/ジャクリー（既存challenge経路・DesperationChallengeWeightの識字加重化）。史実対応＝農民一揆 vs 組織労働運動
