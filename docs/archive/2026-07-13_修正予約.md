## 2. 普通選挙と女性財産権の紐付けが非歴史的
**問題点**：参政権の最高段階 `Universal` の導入条件が「`WomenPropertyLaw` 成立が前提」。19世紀の多くの国では**男性普通選挙が先**、女性参政権は20世紀。女性財産権を男性普通選挙の前提とするのは史実因果として不自然。

**コード所在（確認済み）**：
- [Government.cs:19-20](Successor.SimCore/Government.cs)：`var sufTarget = p.Suffrage == Suffrage.Universal && !w.WomenPropertyLaw ? Suffrage.AdultMale : p.Suffrage;` ＝Universalは女性財産権法が無いとAdultMaleへ差し戻す。
- [Policy.cs:6](Successor.SimCore/Policy.cs)：`enum Suffrage { None, Census, AdultMale, Universal }`。
- [InterestGroups.cs:52](Successor.SimCore/InterestGroups.cs)：`double fem = s >= Suffrage.Universal ? 1.0 : 1.0 - p.FemaleShare;`＝女性はUniversalまで投票不可（票が女性比ぶん欠ける）。

**注（正確化）**：ラダーは既に **`AdultMale`＝男子普通選挙** と **`Universal`＝男女普通選挙** を分けており、「男性が先／女性が後」の順序自体は表現済み。非史実なのは**Universal（＝女性の参政権付与）を女性"財産"権に紐付けている**点。

**修正案（ユーザー）**：`WomenPropertyLaw` は女性の財産権・法的主体の確立にとどめ、**女性参政権は別の法 `WomenSuffrage` として後から解禁**する設計に。＝女性の財産権と女性参政権を脱結合し、Universalの前提を財産法でなく専用の女性参政権法にする。

## 3. 一部イデオロギーの出現時期・強度設定
**問題点**：
- **ナショナリズム**が1789年から存在し、兵士POPに高い基礎値（4.0）。
- **帝国主義**が1860年以降に独立イデオロギーとして扱われるが、明確な政治運動としての結晶はさらに後（1880年代?）が自然。

**コード所在（確認済み）**：
- [Ideology.cs:101](Successor.SimCore/Ideology.cs)：兵士POPの基礎分布 `r[4] = 4; r[8] = 2; r[0] = 1; r[1] = 1;`（インデックス4=ナショナリズム=4.0・8=帝国主義=2）＝**1789年から無条件で兵士にナショ4.0**。
- [Ideology.cs:24](Successor.SimCore/Ideology.cs)：`double eraImp = Clamp01((year - 1860) / 40.0);`＝帝国主義の暦年ゲートは1860起点（1900まで40年でランプ）。
- [Ideology.cs:47](Successor.SimCore/Ideology.cs)：発展度ゲート `devImp`（IdeologyGateImpOnset）で暦年順序を発展度で再現。

**修正案（ユーザー）**：
- ナショナリズムはフランス革命後に**徐々に強まる**よう時期ゲート（1792年?段階上昇）、または識字・兵役経験で後天的に伸びる設計に（兵士基礎値4.0の無条件付与を弱める）。
- 帝国主義は「ジンゴイズム的膨張政策」として**1880以降**に限る、あるいは**横断的な政策選好**として扱い独立イデオロギーから外す選択もある（暦年ゲート1860→1880へ、または政策軸化）。

## 4. 政策金利という近代的金融政策
**問題点**：`World.InterestRate` が「政策金利レバー」として存在し、中央銀行のように政府が操作できる。19世紀の大半は中央銀行による能動的金利操作が未発達で、金利は正貨準備・国際金移動に従属（英銀のバンクレートも受動的側面）。後進国は中央銀行自体が長く不在。

**コード所在（確認済み）**：
- [World.cs:92](Successor.SimCore/World.cs)：`public double InterestRate`（0..1・現在値。金融政策＝低いほど銀行が貸す＝信用ブーム、高いほど引締）。
- [World.cs:421](Successor.SimCore/World.cs)：為替バイアスに「政策金利（高金利→資本流入→自国通貨高＝バンクレートでペッグ防衛）」＝既に金本位ペッグ防衛の受動側面は一部配線。

**修正案（ユーザー）**：
- **金本位制（`OnGoldStandard`）下では政策金利操作を不可/極限定**にし、兌換離脱・管理通貨制度への移行後に初めて積極操作可に。
- あるいは `InterestRate` を「公定歩合の目標」でなく**国債利回りと同様に市場で決まる変数**とし、政府は間接的影響に留める。

## 5. 自給率（Subsistence）が永続固定
**問題点**：`Pop.Subsistence` が「永続」パラメータで、農民の市場外自給度合いが変化しない。史実では交通発達・商業化・囲い込み・農奴解放で自給経済→市場依存へ大転換。時代を通じて固定は不自然。

**コード所在（確認済み）**：
- [Model.cs:109](Successor.SimCore/Model.cs)：`public double Subsistence;`（自給率0..1・必需の一部を市場外で自足＝農民・市場で飢えない）＝pop初期化以降不変。

**修正案（ユーザー）**：
- インフラ整備・鉄道解禁・穀物法撤廃などに応じて自給率が**低下**（市場統合が進む）動的パラメータに。
- 自給率を地域ごとに変動させ、伝統的農民層の市場経済への包摂を表現。

**実装メモ**：Region に既に Infra/鉄道/CornLaws があるので、Subsistence を「初期値からインフラ・鉄道普及・穀物法撤廃で単調低下」させる動的化は外科的でなく既存状態から導出可能。較正中立＝低下率0で恒等の休眠係数として入れれば安全。

## 6. 似た変数・統一できる変数のチェック（ユーザー指示2026-07-13「機能がごちゃついてきた」）
**問題意識**：機能追加が積み重なり、似た役割の状態変数・係数が増えてきた。倍率排除キャンペーンが「マジックナンバー」を創発化したのと同型で、今度は**状態変数**の重複・統一可能性を棚卸しする。

**着手時に見る候補（既に目に付くもの・要精査）**：
- **「体制の立ち位置」系ストックの林立**：`Legitimacy`（正統性）／`MandateSpent`（政治資本消費）／`RegimeTrackRecord[4]`（実績・信認⇔失望・2026-07-13新設）／`CoopParliamentCrown`・`CoopArmyCrown`・`CoopPublicRegime`（協力度3チャネル）／（新設予定）`NationalConsciousness`。**同じ「政権の安定/信頼」の別側面**＝一部は導出関係で畳める可能性（例：CoopPublicRegimeは満足−闘争の即時値＝派生面）。
- **民族/国民の結束系**：`EthnicUnity`（民族均質度・与件）と `NationalConsciousness`（市民的国民意識・構築＝新設予定）は**別物として設計するが役割の境界を要監視**（EthnicUnityは既にUnityAdminBonus[World.cs:347]で行政に効く＝国民意識の汚職ゲートと二重計上しないか）。`Pop.Consciousness`（政治意識・per-pop）とも語が近い。
- **意識/識字/教育の駆動**：`Literacy`・`Consciousness`・`EducationFill`・`EducationEma`・`SchoolingConvStock` が近い水路を共有。
- **闘争度ドライバ群**：`MilLiving/MilVoice/MilJobs/MilWar/MilCrowd/MilGap/MilNation/MilForeign`（診断用内訳）＝計算には不使用のはずだが要確認。
- **不作/収穫系**：`HarvestFactor`・`WeatherBandFactor`・`CropHealth[]`（三重積算・意図的重層だが確認）。

**方法**：領域別に**多エージェントで並列スキャン**（似た名前・似た型・似た更新箇所・導出で畳めるペアを列挙）→敵対検証→「意図した重層／畳める重複」に分類→ユーザー裁定。**Workflowツールのファンアウトに好適**（30弱のSimCoreファイルを横断）。二重計上監査（docs/全域監査＝挙動の二重）とは別軸＝**変数の存在の重複**。実装リファクタは各回帰番人＋savetest＋chronicle byte一致で恒等を保証しつつ。
