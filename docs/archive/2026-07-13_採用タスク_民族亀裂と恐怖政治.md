## タスクA：民族を「社会の亀裂」として導入（メイン・採用）

### A-0. 核心思想（②設計書・ゲーム哲学と整合）
民族は階級（旧/新エリート・大衆）を**横断するもう一つのアイデンティティ軸**。**民族が直接戦争を起こすのでなく**、同階級内の連帯を阻害し・国家忠誠を弱め・既にある経済的不満を政治的に活性化する**触媒**。統一戦争・分離独立はこの亀裂が臨界を超えた**創発**。＝台本でなく創発、内政が主舞台（戦争は帰結の一つ）。

### A-1. ミニマムデザイン（②のまま採用）
1. 州に**中核文化（Core Culture）**を1つ設定（既存の `Region.Culture` 文字列ラベルを活用）。
2. 各POPに**所属民族ID＋国家忠誠度(Loyalty)**を付与（既存 `CoreEthnicShare` を「どの民族か＝複数ID」へ拡張）。
3. 忠誠度が低いと：大衆の組織力が**反政府動員（分離圧力）**へ流れる／旧エリートも民族が違うと連合が組めず政治力が目減り（＝多民族帝国の慢性的低安定・改革遅滞が創発）。
4. **国民化政策**（教育投資・公用語・兵役＝新興エリートが推進、地域特権貴族と地域固執農民が抵抗）で忠誠度が徐々に上昇＝「上からの国民化」。
5. 戦争で取った領土の被征服民は忠誠度が極めて低く長期の統合コスト＝**属国化が合理的になる**（既存の属国機構と噛む正のインセンティブ）。

### A-2. Claudeの採用条件（★vetting・うのみにしない部分）
1. **三重計上を作らない（最重要・U2の教訓）**：ゲームは既に `EthnicUnity` を行政(UnityAdminBonus)・軍質(UnityMilitaryQuality)に、**今セッションの国民意識**を汚職に配線済み。ここに忠誠度→分離を足すと「民族のバラつき」が3経路で三重に効く。→**忠誠度を一次量(primitive)にし、EthnicUnity・国民意識をその分布から導出(subsume)して置き換える**。層を足すのでなく既存を吸収。国民意識(civic同化の成功度)と忠誠度(亀裂)は**補完＝統合し別々に持たない**。
2. **休眠係数＋batch規律**：忠誠度効果=0で厳密恒等→段階点火→**多民族帝国の脆弱性を batch で測る（脆いが即崩壊はしない狭い帯）**。至上基準＝墺洪/オスマン/露は慢性不安定だが1914まで概ね持つ。
3. **段階化（Phase）**：
   - **Phase1（まずここ）**＝per-pop民族ID＋大衆の忠誠度→分離圧力（EthnicUnity吸収）＋国民化政策で忠誠度上昇。これで多民族帝国の脆弱性・国民形成・R8（分離の民族宗教化）を達成。
   - Phase2＝旧エリート内の民族分裂（ハンガリー人地主 vs スラブ小貴族）＝ブロックが階級で一枚岩でなくなる。
   - Phase3＝外交（イレデンティズム/汎スラヴ・汎ゲルマン・国外同胞保護の干渉圧＝戦争の口実だが直接トリガでない・独立地域の同民族国への統合＝リソルジメント）。
   - Phase4＝民族的職業偏在（ユダヤ人金融・アイルランド都市下層＝階級闘争が民族対立の様相・反ユダヤ主義の利用）。※先日の「階級×性別（使用人0.75）」と同型のデータ拡張。

## タスクC：市場の権利構造（Market Entitlements）とカルテル（採用・vetted）

### C-0. 核心思想
経済の硬直性を生むのは「**供給する権利・流通させる権利・価格を決める権利**」を誰が握っているか＝**既得権益の物質的基盤**。3層で定義し、その**政治的解体（＝19世紀の「市場の自由化」）をゲームの駆動軸**にする。
| 層 | 実体 | 誰の地代か | 解体手段 |
|---|---|---|---|
|①王権・特権による独占|塩専売(仏gabelle)・東インド会社の茶・鉱山王有権・**ギルドの営業権**|**旧エリート**|営業の自由／専売撤廃／ギルド廃止|
|②産業カルテル・トラスト|鉄道プール・スタンダード石油・独石炭鉄鋼カルテル|**新エリート（大資本）**|独占禁止法／反トラスト法|
|③労働の参入制限|熟練ギルドの徒弟制限・閉鎖的雇用慣行|**大衆の一部（熟練工）**＝大衆が割れる|徒弟制廃止／自由労働法|

### C-1. ★設計の要（外科的注入を避ける・提案からの修正）
提案の「**財ごとにカルテル支配度を設定**（塩=高・茶=高）」は**外科的注入で不採用**（本作は倍率排除キャンペーンで財別の恣意スカラーを創発化してきた）。**既存の休眠レバーの方が既に正しい設計**：
```
μ = 1 + DomesticMarkupMax × (1/EffFirms)    ← 市場支配力が「有効生産者数」から創発（EffFirms→∞でμ→1の自己有界）
```
**採用する因果**：
```
法・特権（専売/ギルド/独占禁止法） → 参入障壁 → 有効生産者数 EffFirms → 市場支配力 μ → 価格マークアップ → 超過利潤 → 支配ブロック(旧/新エリート)へ
```
1789の塩専売・東インド茶・ギルドは「**法的独占権が該当財の EffFirms を1（低値）に固定する**」という**法データ**で表現（恣意的マークアップ値でなく）。解体＝**参入障壁の除去 → EffFirms が増える → μ が自然に1へ**。＝創発的・既存機構をそのまま使う・より安い。

### C-2. 実コードの現況（★提案の前提誤りの訂正・着手前に必ずgrep確認）
- **`MonopolyMarkupMax = 0.5`（`Coefficients.cs:520`）＝既にlive**（休眠ではない）。世界価格にHHI経由で作用（`InternationalMarket.cs:295-314`）。**既知バグ「偽独占」＝HHIに残余世界を含めず、モデル内1国だけが作る財に偽の独占価格**（史実検証チェックリストA）→ **本改修で一緒に直す（ボーナス）**。
- **`DomesticMarkupMax = 0.0`（`Coefficients.cs:522`）＝休眠**。国内寡占マークアップ `μ=1+これ×(1/EffFirms)`（`MarketFlow.cs:73-74`・EffFirms橋渡しは`EconomyStep.cs:1186-1190`・0なら配列確保すらせず中立）。→ **これが起動対象**。
- **`PriceFactorMax = 1.4`（`Coefficients.cs:24`）＝需要弾力の上クランプ**＝§1 #1（R1）。**先に直すこと**（下記）。

### C-3. R1（需要弾力）依存＝先に直す
現状は需要がほぼ非弾力なので、**独占者は「量を減らさず値上げ」でき、最適マークアップの探索も供給制限のトレードオフも成立しない**（値上げし放題）。ただし**政治チャネルは現状でも効く**（高値→大衆が買えない→満足度↓→闘争度↑→解体の政治圧力）＝ゲームとしては今でも駆動可能。→ **R1（§1 #1★・着手順の最初）を先に直すと経済として正しくなる**。ブロッキングではないが強く推奨。

### C-4. Phase1のみで開始（ユーザー裁定・スコープ確定）
**Phase1＝法的解体 一本**。これだけで19世紀前半の主要な経済的自由化（塩・ギルド・東インド）が動く。
1. **法的独占権データ**：塩専売（仏gabelle等）・東インド会社の茶・ギルドの営業独占を「法的独占が該当財の EffFirms を1に固定」として定義（データ）。
2. **`DomesticMarkupMax` 起動**＝μが立ち価格上昇。**超過利潤は支配ブロック（旧エリート／資本家pop）へ**流れる（**保存則＝消費者popからの移転で台帳を閉じる**・新規貨幣を作らない）。
3. **解体法を Policy に追加**（営業の自由／専売撤廃／独占禁止法）→ 施行で法的独占が解除 → EffFirms が自由化 → **μ→1 → 価格下落・大衆の生活水準向上**。
4. **旧エリートは激しく抵抗**＝`PolicyPreferences` で反対に設定すれば**既存の法ゲート（利益集団の力・マンデート）がそのまま政治闘争を生む**（新機構不要）。
5. **偽独占バグ修正**（HHIに残余世界を含める）を同時に。
- **期待される体験**：塩専売撤廃→塩価格半減→大衆の生活水準↑＋化学工業（ソルベー法）の原料コスト↓／ギルド廃止→職人の参入自由化／東インド独占撤廃→茶価格下落。＝「**誰のための経済か**」を問う能動的目標。

### C-5. 後続Phase（今回は着手しない）
- **Phase2 経済的挑戦者**：高μに惹かれた新規参入がEffFirmsを自然増。要「参入の資本要件」「既得権益の対抗（訴訟等）」＝法改正より重い。
- **Phase3 国際的圧力**：自由貿易帝国（英）が条約で他国の専売廃止を迫る＝外交システムの拡張（§1 #5関税同盟・#21多国間講和と同系）。
- **Phase4 労働の参入制限**（熟練ギルドの徒弟制→**大衆が熟練 vs 非熟練に割れる**）＝**最も繊細**（大衆ブロックの分裂は政治モデルへの影響大）。※ギルド廃止はPhase1の営業独占解体と一部重なる。

### C-6. 対象外（スコープ確定）
- **サボタージュ・暗殺・買収・ロビー活動＝設計外**（本作は陰謀シミュレータでない）。政治闘争は pop の意識・闘争度・支持で表現され、**法改正という形で決着**する。
- **デビアス／ダイヤモンド＝時代外**（1888+・126財に不在）。**塩・茶・ギルドに集中**。

### C-7. 規律
**価格の根幹に触る＝帯影響大**。`DomesticMarkupMax=0` で厳密恒等（`chronicle`政変122を確認）→段階点火→`selfplay-batch 30` で史実帯（exact/◎/破綻/**満足度**＝独占で大衆が困窮しすぎないか）を測る。R1と同時に動かすと切り分け不能＝**R1を先に採用確定してから**着手。
