# POP動詞3種の設計（2026-07-19ユーザー裁定）

裁定：「POPを能動的に操作できない」への対応として①階級への優遇と弾圧②職業誘導③選別的徴兵を採用。外交の能動化は後回し。移住奨励は不採用。

設計原則（プロジェクト規律）：
- プレイヤー/AI対称（同じ動詞・AIは決定論規則で使用）
- 保存則厳守（金流は必ず 出し手→受け手。無からの満足度/闘争度の直接改変は禁止＝金や人の流れから導出）
- 中立恒等（動詞を使わない限りビット恒等＝レバー0/「なし」で全経路不走行）
- 外科倍率禁止（効果は既存の物理チャネル＝生活水準・発言権・人口フローを通す）

## ①階級への優遇と弾圧

**状態**：`World.ClassStance[classId]` ∈ {中立(0), 優遇(1), 弾圧(2)}。国単位（全州の同階級へ適用）。初期は全て中立＝恒等。

**優遇（栄典・恩顧・減税的贈与）**：
- 月次コスト＝`ClassFavorCostPerPop × 階級人口`を国庫から当該階級の貯蓄へ移転（恩給・下賜＝保存）。国庫が払えない月は按分（払えた率＝実効）。
- 効果は金流そのものから創発：貯蓄↑→生活水準↑→満足度↑（既存チャネル）。加えて「地位の承認」＝MilVoice（政治的疎外）を実支払い率×`ClassFavorVoiceRelief`だけ緩和（買われた忠誠＝金が届いた分だけ）。
- 副作用：他階級の格差不満（MilGap）は既存の格差機構が自動で拾う（貴族を優遇すれば大衆の格差感が上がる＝無料ではない）。

**弾圧（監視・集会禁止・結社規制）**：
- 月次コスト＝`ClassRepressCostPerPop × 階級人口`を国庫→官僚・兵士pop（憲兵・密偵の俸給＝保存）。
- 効果：当該階級の闘争度の**政治表出**を抑制（Politics の勢力計算で当該階級の寄与×(1−`ClassRepressDamp`×実支払い率)）。闘争度そのものは消えない。
- **遺恨ストック**：弾圧中は `ClassGrievance[classId] += ClassRepressGrievanceRate × 闘争度` を蓄積。弾圧を解いた時・革命/内戦の点火時に闘争度へ還流（抑えた分は消えず、いつか噴く＝1848型）。
- 検閲法・圧政（Coercion）との関係：既存の全国一律の圧政に対し「階級を狙い撃つ」選択が新規部分。コストは圧政より安いが遺恨が残る。

**AI規則（決定論・SelfPlay）**：専制系＝闘争度最大の非特権階級が閾値超で弾圧（国庫余力ゲート）／立憲系＝中流（近代エリート）の闘争度が高い時に優遇。1階級まで・四半期判定。

**UI**：POPタブの各行に「優遇/弾圧」ミニボタン（トグル・active表示）＋行ホバーに月次コスト。

## ②職業誘導

**状態**：`Policy.TrainingSpending`（職業訓練＝農民→労働者）と `Policy.ScholarshipSpending`（奨学金＝下流→専門職/技師）。0..1レバー2本（POPタブ下部）。0＝恒等。

**機構**：既存の階級移動（Meritocracy＝**四半期実行**）に追加フローを乗せる：
- 職業訓練：四半期コスト＝`TrainingCostPerConvert × 転換数`。転換数＝`TrainingSpending × TrainingBaseRate × 農民人口`（TrainingBaseRate は四半期率＝月次意図0.004の×3）、ただし**都市労働需要ゲート**（都市賃金>農村賃金の差に比例＝失業への転換はしない。物理＝訓練しても職が無ければ移らない）。支払い先＝教師pop（訓練の担い手＝保存）。
- 奨学金：同型で下流→技師/専門職。識字ゲート（識字者しか進学できない＝`× 当該popの識字率`）。支払い先＝教師pop。
- どちらも移動は Meritocracy の既存 MoveCohort 系（貯蓄・属性の持ち運び規約に従う＝人口保存）。

**AI規則**：産業スタンスのAIが工業化期（労働需要逼迫＝都市賃金プレミアム閾値超）に TrainingSpending を上げる。福祉スタンスは奨学金。

**UI**：POPタブ下部にレバー2本（0〜100%全幅・SliderLimitなし）＋実効転換数/月の表示。

## ③選別的徴兵

**状態**：`World.ConscriptionSource` ∈ {均等(0)=現行, 農民中心(1), 都市労働者中心(2), 貴族士官(3)}。初期＝均等＝恒等。

**機構**（Military.cs の徴兵按分の重み変更＝人口フローのみ・金流なし）：
- 均等：現行どおり農民・労働者から人口比例。
- 農民中心：徴兵の80%を農民から（農村の疲弊・都市工業の保護＝露/墺型）。
- 都市労働者中心：80%を労働者から（工業の労働力を削る＝リスク・都市の不満）。
- 貴族士官：士官比率を厚く＝`OfficerCasualtyShare`×2・ArmyAllegiance の導出式に王権傾き `ConscriptAllegianceLean` を加算（導出値は毎四半期再計算のため率でなく傾き）＝軍の帰属を金でなく人事で買う。戦死時に貴族の血が流れる（既存の士官戦死機構が増幅）。
- 政治帰結：徴兵された階級の闘争度に `ConscriptGrievanceRate × 徴兵率` を加算（取られた家の不満）。厭戦・戦死の既存経路と合成。

**AI規則**：専制＝農民中心／軍事独裁・親軍主義＝貴族士官／共和・立憲＝均等。政体から決定論で導出。

**UI**：POPタブ下部に ComboBox「徴兵」（4択・現行値と効果はホバーで説明APIの内訳）。

## 係数（全て新設・中立恒等）

```
ClassFavorCostPerPop      = 0.02   // 優遇の月次コスト/人口1
ClassFavorVoiceRelief     = 0.5    // 実支払い率×これだけ MilVoice を緩和
ClassRepressCostPerPop    = 0.01   // 弾圧の月次コスト/人口1
ClassRepressDamp          = 0.6    // 闘争度の政治表出の抑制率（実支払い率でスケール）
ClassRepressGrievanceRate = 0.02   // 遺恨の蓄積率/四半期（Politics は四半期実行）
TrainingBaseRate          = 0.012  // 職業訓練の基礎転換率/四半期（＝月次意図0.004×3。レバー満額・需要ゲート前）
TrainingCostPerConvert    = 2.0    // 転換1人口あたりコスト
ScholarshipBaseRate       = 0.006  // 同・四半期（＝月次意図0.002×3）
ScholarshipCostPerConvert = 5.0
ConscriptSourceSkew       = 0.8    // 農民中心/労働者中心の偏り
ConscriptAllegianceLean   = 0.3    // 貴族士官の軍帰属の王権傾き（導出式へ加算）
ConscriptGrievanceRate    = 0.05   // 徴兵階級の闘争度加算×徴兵率
```
