# 改良点の洗い出し（2026-07-07）

対象＝ゲーム全体（UI・遊びの成立・AI対等性・バランス・エンジン残課題）。コード実地確認（Successor.App / SimCore / HANDOFF）に基づく。
エンジンのリアリティ監査は第3回まで全件実装済みのため対象外。UIに説明文を書かない方針（恒久指示）に反する提案は含まない。

## A. ゲームの土台として欠けているもの（最優先）

| # | 項目 | 現状（根拠） | 備考 |
|---|------|------|------|
| A1 | **セーブ/ロードが無い** | コード全域に保存処理なし（GameViewModel 全域・TitleView） | 125年のプレイが中断不能。オートセーブも無い。SimCore は決定論なので「シード＋操作ログの再生」方式と「状態の完全シリアライズ」方式の設計判断が要る（Region の World 間移転・RNG 状態まで含む後者はコスト大） |
| A2 | **終局が無い** | Q500/1914年の到達判定・リザルト画面なし＝時間が流れ続ける | NationalScore・列強ランキングは実装済みなのでリザルトは作れる。「勝った/負けた」をプレイヤーが知る手段が無い |
| A3 | **敗北の定義が無い** | 全州喪失は最後の1州で止まる・属国化/革命は継続 | 属国化・革命（政体転覆）・ソブリンデフォルト時にゲームとしてどう扱うか未定義（継続でも「何が起きたか」の提示が要る） |
| A4 | **タイトル/国家選択へ戻れない** | ゲーム中のリスタート・新規ゲーム手段なし | シード指定 UI も無し（Runner のみ） |
| A5 | **設定画面・音が無い** | 音量/ウィンドウ切替/キー一覧の画面なし。BGM/SE は一切なし（audio 参照ゼロ） | F11 フルスクリーンのみ |

## F. 提案する優先順位（私見）

1. **A1 セーブ/ロード**＋**A2 終局**＝「ゲームとして完結する」ための最小セット
2. **B4 重大イベント通知**（自国への宣戦・デフォルト・疫病）＝プレイ中の死角の解消
3. **B1 マップモード**＋**B2 ランキング推移**＝125年を眺める楽しさ
4. **C2 AI Phase2**＝プレイヤー動詞の一方的優位の解消（対等化の完成）
5. **D3/D2 バランス調整**（PensionOldWeight・決着遅延の扱い＝ユーザー判断）
6. E群は #17 再較正の一環として
