■ 致命1：ExpansionWill ゲートが構造的に閉じている（点火0の Probe が必ず 0 を返す）

  willCost /= 1.0 + ColonizeWillSuperiorityDiscount(1.0) × max(0, ColonizeForce/(ColonizeSubmitRatio(3.0)×target.Military) − 1)

割引が効かないことは証明できる：
 ・`ColonizeForce = great.LandPower × Math.Max(0.05, Projection) × ExpeditionLift`（Diplomacy.cs:1296-1297）

 ここで仕様の動機ゲートは `SideMilitary(winner, g) ≥ 1.0 × SideMilitary(g, winner)`、同盟なしなら `winner.Military ≥ g.Military ≥ ColonizeForce(g, winner)`。
 ⇒ `ColonizeForce/(3×winner.Military) ≤ 1/3 < 1` ⇒ **割引は厳密に 0**。
