## 1. 空の都市の階級の値打ちの形（問い 1・AI の案・確証なし）

記号：P_L＝州の労働（LaborId 84）の値段・P_F＝州の農業労働（FarmLaborId 92）の値段（Market.Price・人数に依らず毎月ある）。u_U・u_R＝工員と農民の失業（Pop.UnemploymentRate・EconomyStep.cs:2461）。ℓ＝州の一人あたりの労働の量＝(労働の生産者の Capacity＋農業労働の生産者の Capacity)÷(工員＋農民の人数)（EconomyStep.cs:971 の既にある欄・PopDecision.cs:52 が合計＞0 を既に要る）。

### 案 A（推奨）：州の労働の値段で評価した働き口（期待される賃金〈推：Harris と Todaro 1970 の型〉）

- V_u＝ℓ×P_L×(1−u_U) − 家賃
- V_r＝ℓ×P_F×(1−u_R) ＋ 自給の値の一人あたり（今の PopDecision.cs:26 のまま）
- g と流れは今の旗 1 の式のまま（g＝2(V_u−V_r)/(V_u+V_r)・流れ＝Mobility×g×送り手の人数）。
- 良い所
  - **空かどうかを読まない 1 本の式**（決まり③・Meritocracy.cs:99 の型＝空を名指して開ける例外を重ねない）。人数 0 でも P_L と ℓ は正＝g＞−2＝農村から入る。
  - 人数が正の側では、賃金の部分は〈売った労働×値段÷人数〉と同じ量（失業＝売れ残り率の定義から）＝今の一人あたりの稼ぎのうち賃金の分に一致する〈推・式の上の読み〉。違いは非賃金の所得（自作の地代・移転）を移る人の値打ちに数えないこと＝移る人は居る人の地代を受け取らない〈推〉。
  - 新しい状態 0・新しい係数 0（値段・失業・Capacity は全て既にある・思想⑩）。閾値 0。
  - 失業が値打ちに入る＝Meritocracy の職探しの溜まりが農村と都市の間でしていた〈失業で動く〉働きを PopDecision の 1 本が持てる（§2 の 1 本化の前提）。
  - 鏡：農村 0 でも ℓ×P_F＞0＝都市から戻れる（自給の項は 0 のままだが賃金の項が吸収を解く）。
- 難しい所
  - 工員 0 の州は工場の能力も 0（EconomyStep.cs:971）＝労働の需要 0＝P_L は動かず前の値が残る（MarketFlow.cs:75 の flow＝0）。開幕から 0 の植民地格の州は開幕の値段のまま＝入り始めの強さは開幕の値段で決まる。入った後は工場が動いて需要が出る〈推〉。
  - V_r から自作の地代が抜ける＝旗 1 の (1296) より都市へ寄る向き。どれだけかは段 U0 の計器で紙に読む（未確認）。
  - ℓ は農業労働と工場の労働の単位を足す（建てる時は同じ LaborProductivity×FullChainProductivityScale・Simulation.cs:425・:429。毎月の boost は発見の門で違う）＝単位の混ざりを名乗る。
  - 計算量：州×月ごとに労働の生産者 2 本を探す（生産者の並びを 1 周・EconomyStep.cs:1010 と同じ型）＝〈推〉0.3 秒以下。足りなければ州の欄の添字（既にある MeritFromIndex と同じ型の読み）を使う。

### 案 B：同じ国の他の州の都市の一人あたり（州の物価の比で直す）

- V_u＝Σ_国 工員の稼ぎ ÷ Σ_国 工員の人数 × (州の PriceLevel ÷ 国の PriceLevel) − 家賃。
- 良い所：国に工員が居れば必ず正。値段の読み 1 つ。
- 難しい所
  - 人数が正の州でも州の差を消す＝州の工業の差で人が動かなくなる。避けるには〈空の時だけ国の値〉＝0 の特別扱い（決まり③・:99 と同じ型）。
  - 州の間の移民（Territory.cs:101 の WagePremium＝州の間の賃金の差）と同じ量で引く＝**二重計上（思想⑨）**。
  - 植民地格の州が本国の都市の賃金で引かれる＝〈推〉史実の植民地の町の賃金は本国より低い。

### 案 C：州の工場が労働に払える値（需要の側の限界の値打ち）

- 労働 1 単位の値＝Σ_工場 LaborWeight×(値段−労働の外の投入の費用)÷LaborPerOutput ÷ ΣLaborWeight（EconomyStep.cs:817・:822 の rentR と LaborWeight は人数に依らず毎月ある）。V_u＝ℓ×その値−家賃。
- 良い所：働き口の側から値が出る＝工場があって人が居ない州ほど強く引く〈推：労働の不足の地の高い賃金〉。
- 難しい所
  - 釣り合いでは P_L が同じ量の市場の読み＝案 A と同じ物を生産者の側から組み直す＝新しい関数・新しい道（思想⑨の恐れ・計算量は工場×投入）。
  - 値段−費用には持ち主の取り分も入る＝賃金より高く読む。
