## 2. v の中 3 を解く（問い 2）

### 2-1 焼却の平価の項

- 案：`burn = min(max(φ·burnMem, burnParity), 貯蓄×BurnCap)`。平価の項には φ を掛けない。
- 理由（式）：
  - burnParity ＝ TotalMoney×max(0, 1 − 1/(parity×PriceLevel)) は、選んだ平価（World.cs:1354 の GoldParity が読む）に貨幣の量を合わせる代価。記憶の大きさに依らない。
  - φ を掛けると、φ→0 の月に〈焼却 0・正統性 0・平価だけ付け替え〉の改革ができる。今は付け替えに必ず代価が付くので、新しい抜け道になる。
  - 掛けなければ、φ＝0 の改革は〈帳消し 0・平価の代価だけ払う〉＝頼む側が必ず損をする。AI は頼まない（§4 の口）。閾値を足さずに済む。
- 下書き (1286) §0 の〈代価は記憶に比例〉は〈正統性と焼却の記憶の項は帳消しの額に比例・焼却の平価の項は選んだ平価に比例〉と読み直す。
- 正統性：`forgiveRatio = min(1, φ·X)`（φ·min(1, X) ではない）。
  - 洗いの不等式：min(1, a)＋min(1, b) ≥ min(1, a＋b)。だから、小さな改革を n 回して同じ額を消すと、正統性の減りの和は 1 回で消すより小さくならない。焼却の記憶の項は額に線形で、和は同じ。上限（貯蓄×BurnCap）は 1 回ごとに効くので、分けた方が多く焼ける＝やはり安くならない。
  - φ·min(1, X) では X＞1 で分けた方が安くなる（例 X＝1.5・φ＝0.5 を 2 回：0.35×(0.5＋0.375)＝0.306 ＜ 0.35）。
- 紙：前の改革から 3 か月以内の改革は M 6・S11 0・N1 2・N2 6（material §4-1）。国×種の正統性の減りの和の最大は 2.77（N1 の英 13 件）。

## 3. φ の定義（問い 3）

- φ_t ＝ R⁺_t ÷ (R⁺_t ＋ D_t)。R⁺_t ＝ max(0, budgetBase_t)（Fiscal.cs:94）。D_t ＝ devalued（Fiscal.Step の引数＝Simulation.cs:1963 で CumDev に足したのと同じ値）。
- 同じ月・同じ定義か：
  - D_t と budgetBase の税の部分は同じ月 t の流れ。budgetBase の関税の部分は最後の清算÷清算の月数（月あたりに割った値）で、分子と分母に同じ変数として 1 回ずつ入る＝分子と分母の非対称は無い。
  - 次元は両方とも〈お金／月〉。
- 0/0 と負と NaN（否定形で書く）：
  - D_t ＝ 0 ⇒ φ ＝ 1（R に依らない）。R⁺＝0 ∧ D＝0 の 0/0 はこの枝で出ない。
  - D_t ＞ 0 ⇒ R⁺＋D ＞ 0 ⇒ 割り算は常に定義される。budgetBase ≤ 0 なら φ＝0。
  - `!(D ≥ 0)` か `!(budgetBase ≥ 0 ∨ budgetBase ＜ 0)`（NaN）⇒ φ ＝ 0（帳消しをしない側に倒す）。Math.Max は NaN を残すので、max の前に否定形で見る。
- 新しい状態（決まり ②・思想 ⑩）：
  - φ は毎月の局所変数から導く。欄を足さない＝新しい状態 0。
  - AI の `NoDevaluationMonths ≥ 1` は既にある欄（World.cs:860・セーブに載る）を読む。
  - 焼いた後：係数 −2（CalmMonths・CooldownMonths）・状態 −1（CurrencyReformCooldown）・旗 −1。旗の間だけ旗 +1。
- 連続：φ＝1 で今の改革と同じ値になる。1.0×x は浮動小数で x と同じなので、旗 1 でも φ＝1 の月は今とビットで一致する。

### 案 B（推奨）：120 か月を消し、24 か月を φ への比例に替える

- 機構（Fiscal.cs:104〜:137・プレイヤーと AI は同じ口）：

  - `burnMem = BurnShare×(φ·CumDev)`・`burn = min(max(burnMem, burnParity), cap)`。
  - `forgiveRatio = min(1, φ·CumDev÷ngdp)`（:129 の 1 行のまま）。
- AI（SelfPlay.cs:666〜:669）：`述語 ∧ NoDevaluationMonths ≥ 1`（前の月に印刷が無い）。φ＝0 の改革は損なので、印刷している月は頼まない。
- 良い所：係数 −2・状態 −1・新しい状態 0・閾値の追加 0。旗 0 と φ＝1 の月は今と同じ値。紙で国×種の最大 14 件（英）・種あたり 4.6〜7.4 件。
- 難しい所：
  - 英の影が多い（M 14・N1 13）。根は印刷の財政（df・財政の桁の側）。
  - 吸収状態はほとんど減らない（broken の月 −2〜4%）。L3（世代の減衰）が要る。
  - 1 か月の印刷なしは弱い合図（24 か月の〈実績〉の意味は消える）。Sargent の型〈推〉では体制の転換と同時でよい。

### 案 B′：φ を平価の項にも掛ける（下書き (1286) の元の形）

- 良い所：代価の全てが φ に比例し、式が 1 行短い。
- 難しい所：φ→0 で平価の付け替えがほぼ無料になる（§2-1）。推奨しない。

### 案 B″：φ を〈閉じた予算の割合〉＝min(1, R⁺÷請求) にする

- 良い所：未払いで閉じた予算（印刷なしで払っていない月）を φ＝1 と数えない。
- 難しい所：請求の定義（Simulation.cs の claims）に依る量が増え、支払い率の門（≥ 0.85）と同じ情報を 2 回読む＝思想 ⑨ に近い。推奨しない。持続の別案（ExpectedInflationPerYear）も同じ理由で採らない。
