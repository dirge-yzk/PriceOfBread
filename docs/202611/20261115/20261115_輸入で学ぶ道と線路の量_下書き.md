## 0. 何を直すか（材料の要点）
- lo（EconomyStep.cs:1047）は機関車の需要と払いを**買い手自身の発見**で 0/1 にする。機関車の行の運び手 3 つのうち〈機関車〉の輸入がこれで消える。
- 1883 年に機関車を知らない国×種の 89%（M 415/465）は 1840〜1883 年に知る国から運び手を 1 度も買わず、その 8 割強は蒸気機関も知らない＝**輸入の道に限れば片方向の錠**（自分の未発見が自分の学ぶ道を 0 にする）。
- 同じエンジンの需要の門（EconomyStep.cs:741）は「どこかの国が作れる財は輸入で手に入る」＝**世界の発見の和**で読む。lo だけが別の規則。
- 史実は〈輸入して使い、後で作る〉（露 1837・日本 1872・独 1835・米 1829〜1831）。

## 2. 案 A：機関車の行の運び手に線路を足す
- 形：Catalog.cs:448 の発見の行に運び手の追加のデータ（例 `ExtraCarriers: [RailId]`〈仮〉）を置き、Discovery.CarriersByRow（:337〜:379）がそれを足す。lo は今のまま。
- 新しい係数 0・新しい状態 0・新しいデータの欄 1。
- 良い所：
  - 線路の需要には門が無い＝発見の前の国はすでに線路を大きく輸入している（運び手 3 つの和の 6〜40 倍・10 年ごとの標本の年）＝その国の道がすぐ開く。
  - lo の門と番人はそのまま。
  - 史実：米は 1850 年代まで英の軌条を多く輸入した〔記・中〕。
- 難しい所：
  - 分母（世界の運び手の越境の額）が 1.3〜2.5 倍になる＝今、蒸気機関の輸入で学んでいる国（伝わりが要った E 行 98 のうち 67）の接触が薄まる。
  - 分子は線路の輸入国で 6〜40 倍＝伝わりの項が飽和へ跳ぶ恐れ（旧の旗 0 の 22.0 を越える側）。売り手が機関車を知るかは計器が書かない＝**計器を先に**。
  - 運び手の表に手で 1 本を足す＝結果を狙った選び方（外科に近い）。lo の〈自分の未発見が自分の道を閉じる〉形は残る＝§1-8 の点は直らない。
  - 下流の旗（p06:111）が線路を投入に持つ発見つきの財を足すかを確かめる要がある。
- 読み手ごとの新÷旧：運び手の表（機関車の行 3→4 財）・AccumulateDiscovery（線路の取引が機関車の行に積む）・接触の分母 ×1.3〜2.5・計器 discflow_s の財の行が増える（恒等の計器の表が変わる）・蒸気機関の行は 1。
- 門の素案：G-A1 q400 の中央 ≧ 18・G-A2 ≦ 25・G-A3 機関車の行の運び手がちょうど 4・G-A4 蒸気機関の行の運び手と接触が同じ盤面で 1・G-A5 組み直しの接触とエンジンの接触が相対 1e-6 で一致（分子だけ・分母だけの誤りを拾う）。
- 突然変異：全ての行に線路を足す→G-A4 赤・分子だけ足す（分母に線路を入れない）→G-A5 赤・分母だけ足す→G-A1 赤。
- 計算量：+0.1〜0.3 秒〈推〉。

## 3. 案 B：機関車の門を接触の大きさで比例に開く
- 形：自国が知らない州の locoGate＝前の四半期の伝わりの項÷70（0〜1）。
- 良い所：§1-8 の〈入力の大きさに応じた判断〉そのもの・発見に近づくほど輸入が増える。
- 難しい所（採らない理由）：
  - 前の四半期の項はセーブに載らない（World.LastDiscoveryView は `[NonSerialized]`）＝載せれば新しい状態（思想⑩）・載せなければ月の途中のセーブでマルコフ性が割れる。
  - **接触 0 の国では門も 0 のまま**＝錠の大半（輸入の道を持たない 89% の国）に効かない＝狙いを外す。
  - 接触→門→輸入→接触の正の鎖（上限 1 で止まるが速い）。
- 門の素案（参考）：G-B1 q400 の中央 ≧ 18（予言：届かない〈推〉）。

## 4. 推奨
