## 3. 案

### 案 A：文化の距離は入れない＋EthnicDraw と差別の重みを消す＋国教の法は lawCap の 1 か所（推奨・AI の案・確証なし）

- **文化の距離は移民に入れない**（作者の問い「参照すべきか」への AI の答え＝しない）。
- EthnicDraw と DiscriminationLiteracy は、R6 で組にして消す。置き換えない。S13 の推奨どおり、R1 より前には消さない。
- 宗教は国教の法だけで効かせる。〈国教のみ〉の国は、異教の流れの受入の上限を min(移民制限法の率, ImmigrationSelectiveFrac) にする。
  - 入る場所は `MultiNationSim.cs:1712` の lawCap の 1 か所。
  - 縮め方（`:1779-1786`）：
    - まず旧の scale を全ての計画の行に掛ける（旧と同じ）。異教の受け入れを h、同教を s とする。
    - 次に、異教の小計だけを h′＝min(h, Cap_x×min(lawCap, Sel)÷lawCap) に削る。同教は s′＝s のまま。
    - 削った分は送出州に残る（裁定 B3）。空いた枠を同教へ回さない。合計は旧の Cap_x を超えない。
  - 異教の判定（状態 0 の形が主）：出る州の宗教の札 ≠ 行き先の国の主流の宗教の札（等しさ 0/1）。宗教の族の座標（FamilyCoord）は使わない。
    - 失う物：植民地格の州は宗主国の札なので、英領ベンガルの移民は英へは同教、清へは異教になる。州の中の少数派（ユダヤなど）は表せない。
    - POP が宗教の割合を持つなら（§5 の問い 1）、移る POP の異教の割合で判定し、この 2 つの失う物は消える。
  - 〈内心の自由〉以上の国には上限を掛けない。〈内心の自由〉の〈市民権なし〉は段 3（下）。
- 新しい係数 0（ImmigrationSelectiveFrac を使う）。この部分の新しい状態 0（一時の配列だけ）。消す係数 2。
- 良い所
  - 作者の範囲（法の制定だけ）に収まる。機能の削減の方針と思想⑨⑩に合う。
  - 移民制限法と同じ道に入る＝法が移民を絞る道は 1 本。閾値でなく率で効く（README §1-8）。
  - 片方向の錠を作らない（法は議会と AI が両方向に動かす）。
- 難しい所
  - 国教の法が動かない（前提 4）。効く国がほぼ固定され、〈選別〉でなく、国ごとの静的な絞りになる。段 3 の前に、国教の法の梯子が動かない根を読む線が要る（(1042) の Q2 と同じ）。
  - 効く量が小さい（前提 5）。働いた側の門が雑音の内になる恐れがある（教訓㉗）。
  - 掛け算の形（lawCap×Sel）にすれば効く量は大きくなるが、二つの法が重なり、今の盤面ではまず選別の清と閉鎖の日本への流れを削る。向き（前提 1）を直す前は採らない。

- 新しい状態は 0。係数は距離の倍で書けば 0 にできるが、強さは選べない。
- 良い所

  - 国内の移民の入口（`Territory.cs:59` の EntryFrictionTerm）と同じ形で書ける。
- 難しい所

### 段 1 の形：POP の宗教の構成（POP が宗教を持つかは答え待ち・形の選択は AI の案・確証なし）

採った推奨〈ユダヤ教は段1 の初期値へ〉は、州の札では書けない（州の中の少数派）。書くには POP が宗教を持つ必要がある。持つ場合の形の候補は 2 つ。

- **C1：割合 1 本**（推奨・(1042) Q4 と同じ）
  - POP は〈国の主流の宗教と同じ人の割合〉を 1 本持つ。CoreEthnicShare と同じ型（Share）・同じ運び方で、同化しない（改宗しない）。
  - 国の主流の宗教は、州の札の人口加重の多数派（`Diplomacy.cs:89`）。
  - 越境のとき、受け手での割合は次のように決める。
    - 移る組の主流の部分は、出る国の主流と行き先の国の主流が同じなら 1、違えば 0。
    - 異教の部分は 0 のまま。
  - 征服や割譲で国が替わるときも、同じ規則で割合を置き直す。
  - 新しい状態 1 本。新しい係数 0。
  - 誤る場面：少数派の宗教が、移った先の国の主流と同じ場合。例：英のカトリックが仏へ移ると異教のまま扱われる。
  - 国の主流の宗教が替わる（征服・割譲・州の得失で多数派が入れ替わる）と、全ての POP の割合の意味が変わる。置き直しの規則がそこにも要る。
  - 主流の宗教は Power.Religion（毎月の同期）を読む。M12（外交の宗教の緊張を消す）の後に、この同期が残るかは未確認。
- **C2：宗教ごとの割合のベクトル**
  - 誤りは無い。代わりに、状態が POP×宗教の数（16＋ユダヤ教）になり、運搬とセーブが重い。推奨しない。
- どちらの形でも、植民地の住民の宗教は初期値のデータが要る。world.json の植民地には欄が無い。cr（21 州）の外の、別のデータの線になる。
