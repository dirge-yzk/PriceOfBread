## 2. 問い 2：EthnicDraw の読み手と効き

### 2-1 現物

- 係数：`Coefficients.cs:935` `EthnicDraw = 0.7`・`:952` `DiscriminationLiteracy = 0.45`。
- 読み手は **1 か所だけ**（全体の grep で 3 行＝定義 2・読み 1）：`MultiNationSim.cs:1706-1708`。
  - 式：`dstA[d] = (1 + EthnicDraw×(1−EthnicUnity)) × Clamp01(AvgLiteracy / DiscriminationLiteracy)`。
  - EthnicEnabled の国だけ。全 61 カ国が EthnicEnabled（`Simulation.cs:120`）。
  - EthnicUnity は全ての POP の CoreEthnicShare の人口加重（`World.cs:882`）、AvgLiteracy は植民地を含む（`PoliticalQuantities.cs:91`・coreOnly=false）。
- 効く場所：`:1753`（`wSum += g × dstA`）と `:1770`（`f = flow × (gap × dstA / wSum)`）。
  - dstA は**行き先の間の配分の重みにだけ入る**。出る州の総流量 `flow`（`:1765`＝`min(EmigrationRate×gMax, maxFrac)×Size`）は dstA を読まない。
  - 総量を変える道は 2 つだけ。受入の上限（`:1782`）で縮む量の変化と、その階級の POP が居ない行き先の分（`:1769`）。
  - 受入の上限の半分を超える所に入る流入は、少なくとも 2 割強ある（§3-2・主に選別か閉鎖の清と日本）。dstA は向きを動かし、上限が掛かる所では総量にも効く。

### 2-2 量の桁（開幕＝四半期 0・種 1 の近似・flows.out）

近似の作り方
- 民族統一度：本国の州は、札が主流と一致で 1・不一致で 0・空欄で 1（`Simulation.cs:146-167`）。植民地格の州は 0（secession_s の四半期 0 の Colonial の行で core＝0.00 を確かめた）。人口は region_s の四半期 0。
- 識字：reform_s の四半期 0 の literacyShare（9 カ国・植民地を含む）。他の国は world.json の literacy（本国だけ＝★）。
- 限界：★の国のうち植民地を持つ国（蘭・西・葡）は、識字の因子を高めに見ている。

| 因子 | 範囲 | 例 |
|---|---|---|
| EthnicDraw の因子 1+0.7(1−U) | 1.00〜1.57 | 英 1.57（U 0.19・植民地の人口 66%）・墺 1.55（U 0.21）・オスマン 1.46・西 1.44・蘭 1.42・米 1.00 |
| 識字の因子 Clamp01(L/0.45) | 約 0.05〜1.00 | 米・普 1.00・仏 0.80・日本 0.61・英 0.49（植民地を含む識字 0.22）・清 0.45・露 0.11・オスマン 0.07 |
| dstA（積） | 約 0.02〜1.42 | 蘭 1.42★・丁 1.34★・米 1.00・英 0.76・清 0.47・露 0.14 |

- **識字の因子の幅が大きい**（約 20 倍 対 1.57 倍）。
- EthnicDraw は〈坩堝＝アメリカ〉を狙った項。実際には米の統一度は 1.00 で、引くのは植民地の住民（core=0）を抱える帝国と、札の多い国（英・墺・オスマン・西・蘭）。**狙いと逆に効いている。**
- 途中の四半期の識字（lawgate_s の literacyHome・種 1・9 カ国）：清 0.19〜0.22（因子 約 0.45〜0.49）・露 0.05→0.46（1903 年）・米 0.42〜0.65。
- 清は dstA が約 0.47 のまま、流れの 38% を受ける。向きを決めているのは機会の差 gap で、dstA ではない（(1042) と同じ読み）。
- 途中の dstA は、民族統一度の列が無いため作れない。secession_s の core は分離の候補の州（四半期 0 で 136 行）だけで、国の値には足りない。→ §1-1 の attract_s。

### 2-3 置き換えた時に失う物と得る物（〈移る費用を、行き先の居住者との距離の人口加重の平均で下げる〉形）

## 4. 問い 4：史実の形と計算量

### 4-1 史実の形（要約・出典は一般の通史・数は概数）

**アイルランドの移民**
- 1815〜1914 年に約 700〜800 万人。1845〜52 年の大飢饉の時期に約 100 万人が渡航した。
- 押し：飢饉と小作。引き：米東部と英の工業都市の賃金、既にある同胞の社会（連鎖移民）。米では 1850 年代にノウ・ナッシングのカトリック排斥があった。
- モデル：
  - 飢饉の押しは FaminePushMaxFracBoost（`Coefficients.cs:2381`）として既にある。
  - アイルランドは英の州（札〈アイルランド〉・カトリック）。英本国への移動は国内の移民なので、国教の法の対象外。米は内心の自由なので、上限は掛からない。
- 得る物：国教の法の形は、英→米の向きでは効かない（史実と同じ）。
- 失う物：連鎖移民は、札が静的な限り出ない。POP の宗教の割合があっても、出身の文化は運ばない（作者「混ざり合いは実装しない」）。

**東欧のユダヤの移民**
- 1881〜1914 年に約 200 万人以上が米へ渡った。
- 押し：露の 5 月法（1882）・ポグロム・居住区域。宗教は、出る国の法として押しの側で効いた。
- モデル：world.json に〈ユダヤ〉の札は無い（宗教の札は 16）。州の中の少数派は札では表せない。
- 採った推奨（§0-5）は〈ユダヤ教は段1 の初期値へ〉。POP が宗教を持つか（答え待ち）しだいで、書ける形が変わる。
- POP が宗教を持つなら、得る物：米（内心の自由）へは異教のまま入る。国教のみの国には上限が掛かる。
- 持たないなら、州の札しか無いので、ユダヤの少数派は表せない。
- 失う物：押しの側（出る国の法が異教の住民を押し出す）は、作者の範囲（受け入れを絞る）の外。

**華僑**
- 19 世紀に東南アジア・米・豪へ数百万人。年季契約の苦力が多い。
- 引き：植民地の錫鉱・ゴム・砂糖の労働需要。行き先の多くは植民地格の州。
- 受け入れ側の制限は、米の排華移民法（1882）・豪の移民制限法（1901）。人種と国籍の法で、宗教の法ではない。
- モデル：行き先の植民地格の州は宗主国の札を持つ。米は内心の自由なので、国教の法の形は効かず、既存の移民制限法が対応する。
- 得る物：国教の法を宗教に限れば、排華の法と二重にならない。
- 失う物：行き先の札が宗主国なので、〈居住者との距離〉で引く形は誤る。

**国教の法が受け入れを絞った例**
- ユグノーの受け入れ：普・英・蘭が新教の難民を歓迎した＝同教の優遇。
- 19 世紀の大量移民の時代には、受け入れ側の宗教の法は主因ではなかった（米は 1791 年に国教を禁止）。

### 4-2 計算量

- 越境の組の走査は、既に O(送出州×全ての州)＝`CostLedger.MigrationPairs`（`MultiNationSim.cs:1777`）。開幕で約 308×308≒9.5 万組/四半期。
- 札で異教を判定する形：札を整数の番号にして、組ごとに比較 1 回。追加の走査は 0。
- POP の異教の割合で判定する形：計画の行ごとに読む（組の走査の外）。追加は計画の行の数に比例。
- 行き先の国の宗教の構成：国ごとに四半期 1 回の州の和（O(州)）。
  - 既にある量は `Diplomacy.cs:1258-1272`（毎月・保護の利害の前計算＝国×宗教の人口）。M12 が消すと、この前計算も消える。
- 州×州の距離の和（行き先の州の居住者の人口加重）は要らない。札は州に 1 つなので、州の単位では 0/1。国の単位でも、国×札の割合の表 1 枚を O(1) で引ける。
- POP ごとに宗教の構成のベクトルを持つ形だけが重い。運搬は移る行ごとに O(宗教の数)、セーブは POP×宗教の数。
