## 1. 形の案（新しい状態と係数 0 を先に）

### 案 1（推奨）：鉄道の need の取り分＝州の産出の名目の比

- 形：
  - need_r＝目標×(Y_r÷Σ Y)。Y_r＝州の産出の名目（役務を除く Output×RefPrice の和）＝今の `Diplomacy.RegionOutputValue`（Diplomacy.cs:3394）と同じ式。
  - ΣY≦1e-9 なら均等（今の ShareBasis の倒し方と同じ）。
  - 読み手は 2 つだけ：敷き（Transport.cs:207・:225）と清算の φ の分母（BilateralMarket.cs:372・:465）。両方が同じ関数 1 本を呼ぶ。
  - 清算の容量の配り（:378〜380＝鉄道以前の陸と船）・割譲（Territory.cs:318）・港・Discovery は、今の潜在量の比のまま。
  - 関数は 1 本にする（削減の方向）：`RegionOutputValue` を州の側（Model.cs の Region）へ移し、Diplomacy の割譲の選びもそれを呼ぶ。この移しは恒等で、腕の前に ident で確かめる（㉒）。
- 良い所：
  - 既にある量だけ（思想⑩）。新しい係数なし。
  - 史実の敷き方（見込みの貨物・産業・人口の大きい所）に近い。四半期の裁定の向きに沿わない。
  - 比例で両方向に動く。片方向の錠を作らない（README §1-8）。上がれば月 15% で追い、下がれば月 2% の減耗で落ちる（今の非対称のまま・錠ではない）。
  - 今の生での揺れ：産出の参照値の取り分の前年比は 0.884／1.000／1.139（|ln| の中央 0.0455）。今の潜在量の比は 0.374／1.000／2.705。
- 難しい所：
  - 取り分の規則が 2 本になる（容量の配り＝潜在量・鉄道の need＝産出）。二重計上ではない（別の量を 1 回ずつ数える＝思想⑨は破れない）。ただし Transport.cs:123〜126 の注〈清算と移しが同じ規則〉の意味が変わるので、注を直す。
  - 〈線路は交易のある州に〉（(1095) の下書き §1 R3 の良い所＝AI の文）から〈経済の大きい州に〉へ意味が変わる。作者の 2026-08-26 の言葉〈輸送量が適切に分配されるなら〉（material §3-7）がどちらを指すかは読めない。作者に聞く（§4）。
  - 荷は多いが産出の小さい州（中継の港など）は need が小さくなり、わずかな線路で φ＝1 になる＝陸の費用だけが鉄道の値になる。紙の数：産出の取り分が今の取り分の 1/4 未満の州×年が 0.109（そのうち今 φ＜0.99 が 0.80）。産出 0 の州（93 行・0.0004）は need＝0 で RailPhi の守りの枝に入る。
  - 産出の名目は、工場の多い州へ寄る。工業州の T が今より厚く、植民地の採掘の州が薄くなる見込み（向きは史実と合う・推測）。
  - 計算量：州ごとの Producers の走査が、月に 2 回増える。

### 案 2：鉄道の need の取り分＝州の人口の比

- 形：案 1 の Y_r を州の人口（`Region.SumPopulation()`・Model.cs:1239）に替える。
- 良い所：一番遅い（|ln| の中央 0.0011）。一番安い。新しい状態・係数 0。
- 難しい所：
  - 農業の大州（ベンガル・清の内陸）の need が大きくなる。そこは確かに買えない（X2）が多い州＝買えない側を広げる見込み。
  - 史実の 1 人あたりの線路は、工業州と農業州で桁が違う。人口の比はそれを消す。
- 推奨しない。

### 案 3：形を変えない（揺れは潜在量の性質として残し、門と記録を直す）

- 形：エンジンは触らない。
  - G1′（0.50）は揺れで通った、と記録に残す。
  - φ＜1 の割合は〈潜在量の揺れ＋速さの非対称〉の結果として読む。
  - 潜在量の揺れそのものは、貿易の置き換え（設計 2026-11-12 の段 T0〜T3：値段の競争）の後に測り直す。
- 良い所：削減の方針に一番合う。挙動の線が 1 本減る。
- 難しい所：
  - 陸の脚の費用が、四半期の揺れで上下し続ける（φ が 0.37〜2.7 倍の need で動く）。
  - 貿易の置き換えが潜在量の揺れを小さくするかは分からない（今の設計に、揺れの門は無い）。
- 次点。案 1 が答え待ちで止まるなら、これで待つ。
