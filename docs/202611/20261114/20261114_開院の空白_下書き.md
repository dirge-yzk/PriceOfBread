# 開院の空白を閉じる — 設計の材料と下書き・AI の案・作者の確認待ち

（(1115) c107op・2026-11-13。材料は同じフォルダの material.md。ここに書く案は全て〈AI の案・確証なし〉。決めるのは作者と波108 の事前登録。）

## 0. 狙い（(1099) gp の狙いの言い直し）

- 選挙の政体の国では、法の門が回る全ての四半期に議会の席が座っている。
- 席は同じ得票で決まる：開幕は直近の選挙の結果、移行は移った時の得票。
- 今は 2 か所で 1 四半期ずつ空く。
  - 開幕の四半期 0（8 国・gp の前から）
  - 非選挙→選挙の移行の次の四半期（gp から）
- 内戦の国の空白（Parliament.Step が頭で戻る）は別の型。この案の外（記録）。

## 1. 案（新しい係数と新しい状態を作らない形を先に）

### 案 1（推奨）：Parliament.cs の中だけで、開院を思想の有無に替え、開幕は議会の前に思想を 1 度出す

- 形（旗 1 本・既定 0。名は仮に ParliamentSeatsWithoutGap）
  1. Parliament.Step の頭（ComputeVotes の前）：
     - 条件は、旗が正・選挙政体・席が空・思想が無い（全 POP の IdeologyShares の和が 0＝ComputeVotes が保守へ退避するのと同じ量）。
     - このとき Ideologies.UpdateShares(w) を 1 回呼ぶ。
     - 実際に当たるのは開幕の四半期 0 の選挙政体の 8 国だけ。移行の国は思想が既に有る。
  2. 開院の条件
     - 旗が正：`席が空 && 思想が有る && 選挙政体`。
     - 旗 0：今のまま `席が空 && QuartersSinceElection≥1 && 選挙政体`。
- 良い所
  - 持ち主は Parliament.cs だけ。
  - 移行と開幕の両方の空白を閉じる。開院の後の与党の決め方（Winner）と選挙の暦（QuartersSinceElection の増え）は変えない。
  - 開幕の守りの元の理由（思想が 0 で保守 100% の議会）は、思想を先に出すことで解く。守りを外して嘘の議会を座らせることはしない。
  - 〈思想が有る〉は、得票が定まるかどうかの 2 値。調整する閾値ではない＝README §1-8 の〈閾値より比例〉に当たる量が無い。
  - 片方向の錠も天井も作らない。
- 難しい所
  - UpdateShares を呼ぶ所が 2 か所になる（Politics.Step と、開幕の議会）。
  - UpdateShares は前の四半期の思想を不満度の理想点で読む（Ideology.cs:54 の注）。＝開幕の 8 国の四半期 0 の末の思想が、今の木から少し動く。
  - その 8 国では、四半期 0 の Parliament.Step から Politics.Step までの読み手（Government.Step ほか）が 0 でない思想を読む。
  - AI の判断（Parliament.Step より前）は動かない。
  - UpdateShares の中に計器の呼び出しがある（PrdsBegin・PrdsAdd・PrdsEnd＝prds_s は〈UpdateShares が走った国×四半期〉の行）。旗 1 では開幕の 8 国の四半期 0 の prds_s の行が増えるか変わる＝計器の表の差として事前登録に予言する。
  - 四半期 0 の頭の盤面で UpdateShares が読む量（MembershipContext・PrivilegeIntact・POP の Consciousness と Militancy の初期値）が出そろっているかは未確認。保守に偏れば、番人 (a) の〈保守の席 <0.99〉と G4b は変異なしでも赤になりうる。
  - 席が空かどうかの判定の前に POP を走査するのは、席が空の時だけ（普段は席の和の比べで終わる）。

### 案 2：開院を思想の有無に替え、開幕の思想は構築で出す（Simulation のコンストラクタに 1 行）

- 形
  - 開院の条件は案 1 の 2. と同じ。
  - 構築の終わりで、PoliticsEnabled の国に Ideologies.UpdateShares を 1 回呼ぶ。
- 良い所

### 案 3：移行だけ閉じる（案 1 の 2. だけ）・開幕は記録

- 良い所
  - 最も狭い。gp が持ち込んだ増え（移行の距離 1）は閉じる。
- 難しい所
  - 開幕のアメリカの 1783 年の最低賃金法（M で 1894 年より前の行の 28%・N2 で 38%）が残る。
  - 反証役 v の〈G4 は同じ穴を守りとして残す〉に当たる。

### 採らない形（理由だけ）

- **C1 RegimeTenureQuarters≥1**
  - 移行の四半期の末に ApplyRegime が 0 に戻す。＝移行の次の四半期には立たない（ソースの順から読んだ）。
- **読み手の側で、街頭の譲渡を席の和に比べて減らす**（ParliamentStreetSupersede×席の和）
  - 法の門は `net > −余裕` と、反対の大きさで払う政治資本の量で決まる（Government.cs:827〜831）。
  - 空白で消えているのは議会の反対の項。街頭を 2 倍に戻しても、その項は戻らない。効くかどうかがソースから読めない。
  - 内戦の国の長い空白にも及ぶ。
- **助走の終わり（MultiNationSim.StartWarmup）で思想を出す**：段 C′ の持ち主のファイルと重なる。
- **開幕だけ、思想によらない得票（ブロックの力など）で席を置く**
  - 新しい判断を持ち込む。2026-08-04 の注の〈新しい判断を持ち込まず〉に反する。
