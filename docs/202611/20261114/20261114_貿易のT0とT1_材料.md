## 4. 今の式（cfd8de3e0〈現物〉）

- 供給①（生産者 s・眠りと倒産を除く）：
  - target_s＝Capacity_s×LastInputFill_s×ProfitFactor(s, price, mc_s)×InventoryAdjust(region, g)（:1009・:1011）。
  - Output_s ← Output_s＋0.15×(target_s−Output_s)（:1012）。負なら 0（:1013）。未発明なら 0、目標が正でなく床未満なら 0（:1016〜1018）。
  - P＝m.LastProduced＝Σ_s Output_s（:1020・:1932）。
- ProfitFactor（:2740）＝price≦mc なら 0、他は min(1, (price−mc)÷(mc×SupplySlope 0.5))。人力の労働は原点を通る線形（:2734〜2738）。
- 清算の量（:961〜963）：xPrice＝D×powVal−(P＋I)（powVal＝(rpT÷unitA)^{2ε}）・xNeed＝TS＋D−P−S・X＝access×max(0, min(xPrice, xNeed))。行の門（:827）は xNeed≦0 で飛ばす。
- A-1（設計 §2-1）を今の行で書くと〈AI の算術・式の写し〉：
  - u′＝min(unitA, lp)（unitA は :937〜938）。u′_loc＝u′÷exRate[買い手の国]。
  - P̂(p)＝Σ_s F(Output_s, Capacity_s×LastInputFill_s×ProfitFactor(s, p, mc_s)×InventoryAdjust_s)。F(x, t)＝x＋0.15×(t−x) の後に :1013・:1016〜1018 の切り捨て。眠った・倒産・未発明は 0。入力（Capacity×LastInputFill×InventoryAdjust・mc・Output）は**供給①の時点の値**（清算の時点の在庫で InventoryAdjust を読まない）。
  - 国内の見込み Q＝min(P, P̂(u′_loc))。退き＝P−Q≧0。
  - 産出が目標に座る行（Output_s＝target_s(lp)）では P̂(lp)＝P、退き＝**0.15×Σ_s(target_s(lp)−target_s(u′))**（target_s(u′)≦target_s(lp) の行）。0.15 は SupplyAdjustSpeed（Coefficients.cs:15）。
  - xPriceA＝D×powVal−(Q＋I)・xNeedA＝TS＋D×√powVal−Q−S・X＝access×max(0, min(xPriceA, xNeedA))。
  - 行の門：TS＋D×(rpT÷u_min)^ε−min(P, P̂(u_min))−S≦0 で飛ばす（u_min は lbOn のとき最良の売り手の値段×lbMul、−1 の売り手の位置は lbMulCheap・lbOn でないときは min(lbMul, 1)）。
