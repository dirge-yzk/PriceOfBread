## 1. 史実の要約（出典は一般の通史・この線では本文を引いていない＝確証：中）

- 最低賃金の法
  - 最初はニュージーランドの 1894 年の産業調停仲裁法。
  - 続いて、オーストラリアのヴィクトリア植民地の 1896 年の賃金委員会、英の 1909 年の Trade Boards Act。
  - アメリカは、州の法がマサチューセッツの 1912 年から。連邦の法は 1938 年の公正労働基準法。
  - ＝1783 年のアメリカに最低賃金の法は無い。
- 1783 年の議会
  - 英には 1780 年の総選挙で選ばれた議会が座っている（Parliament.cs:56 の注と同じ）。
  - アメリカには連合会議がある（代表は州の議会が選ぶ）。
  - ＝開幕に〈議会が空〉は、史実でも設計でもない。
- 政体の移行の直後に労働の法がまとまって通る例は史実にもある（1918〜19 年）。直す理由は史実ではなく機構に置く（(1108) と同じ）。

## 3. 今の式（読み）

- **移行の空白**
  - 移行の四半期 q0：非選挙の枝で席が 0・QuartersSinceElection が 0。その後の Politics.Step で選挙政体へ移る。
  - q0+1：席は空。QuartersSinceElection＝0＝開院しない。Government.Step は議会の項なし・街頭は半分。
  - q0+2：開院する。
- **開幕の空白**
  - 構築は席も QuartersSinceElection も書かない。助走は PoliticsEnabled を偽にする＝議会も思想も動かない。
  - ＝四半期 0 の Parliament.Step は席が空・QuartersSinceElection＝0＝開院しない。同じ四半期の Government.Step は議会の項なし。
  - 移行の空白と**同じ条件**（席が空・QuartersSinceElection＝0・選挙政体）。違いは思想：開幕は全 POP の IdeologyShares が 0（UpdateShares を 1 回も通っていない）。
  - ＝条件を〈思想が有る〉へ替えるだけでは開幕は閉じない。思想が 0 のまま開院すると、旧の注の〈丸ごと保守〉に戻る。
- **内戦の空白（別の型）**
  - 内戦の国は Parliament.Step が頭で戻る＝席が動かない。試合の途中で生まれた選挙政体の国は、生まれてからほぼ 4 四半期以上は内戦（下の表）。
  - 法の門が内戦で止まるかは読んでいない。Government.cs と PolicyPreferences.cs に InCivilWar の戻りは無い（grep）＝回る見込み（推測）。
  - 開院の条件の置き換えでは閉じない。この材料の母集合の外に置き、記録だけにする。
