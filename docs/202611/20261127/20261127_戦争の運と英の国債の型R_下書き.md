# B 英の国債の型 R

## 今の式（Fiscal.cs:168〜:173）
- `repay = min(GovDebt, spare, max(GovDebt × BondRepayFracPerMonth, Treasury − OpulenceLine))`（支払い率≥1・spare＞0 の月）。
- 目標の残高の項が無い。線の上の余りが続く限り 0 まで返す（material 表 B1・B2：R 27/40・0 の前の返済の 93〜96% が余り）。
- 同じ余りを 3 つの読み手が取り合う：返済（毎月）・AI の減税 RelieveOpulence（四半期）・SpendableRevenue（年 0.6）。返済が毎月先に取るので、減税の読み手は余りを見ない〈推〉。

## 案 B-1〈推奨〉：返済を床だけにする（(C) の RepayFloorOnly）
- 式：`repay = min(GovDebt, spare, GovDebt × BondRepayFracPerMonth)`。余りは国庫に残り、既にある 2 つの読み手（減税・歳出）が使う。
- 目標の残高：新しい状態にしない。床は残高に比例する＝残高は指数で減るだけで 0 にはならない。
- 良い所：項を 1 つ消すだけ（新しい係数も状態も無い）。史実の減債基金（定めた額を返す・ピット 1786・ノースコート 1875）の形に近い。余りの使い道が AI の今の方針（減税）へ戻る。
- 難しい所：
  - 床は年 1% で、戦争の借入が無ければ 1783→1950 で残高は約 e^(−1.67)＝約 19% まで下がる。史実の名目の返済は年約 0.25%〈推〉。床の率を変えるのは別の挙動の線（記録だけ・係数は変えない）。
  - 国庫が線の上に積もる国が出るかもしれない（減税の読み手が無いプレイヤー国）。減税の道は AI もプレイヤーも同じ政策の動詞（機構は対称）。記録で数える。
  - 返済は国債の持ち手（世帯）への移転（Fiscal.cs:181 World.Transfer の DebtRepay）。返済が減ると持ち手の収入が減る＝金利生活者の道（記憶 pob-rentier-pump-collapse）を関連の機構として点検する。
- 新しい旗：RepayFloorOnly（仮・既定 0→1・段 2 の焼き込みで消す）。既存の係数では表せない（max の形を変える）。

## 案 B-2：余りの返済を利払いの重さで比例させる
- 式：`repay = min(GovDebt, spare, max(floor, excess × clamp01(LastInterest ÷ (MaxInterestShareOfRevenue × LastRevenue))))`。
- 目標の残高：利払い÷歳入が 0 に近づくほど余りの返済が細る＝暗黙の目標。新しい状態も係数も無い（MaxInterestShareOfRevenue 0.67 は借入の門の既存の係数）。
- 良い所：重い国は余りで返し、軽い国は余りを減税と歳出へ回す。連続で閾値が無い。
- 難しい所：
  - 1 本の係数が 2 つの役（借入の門と返済の重み）を持つ＝片方を調整すると他方が動く。
  - 割合の掛け算を 1 つ足す（倍率の排除の向きに逆らう）。
  - R の 7 種の 0 の前の利払い÷歳入は 0.03〜0.11（表 B2）＝余りの返済は 4〜16% に細る〈推〉。それでも長い年月で 0 に近づく形は残る。
- 推奨：B-1 を先に。B-1 で国庫が積もると読めた時の候補として残す。
