## U1. 案 A（推奨）：足切りを参加の単位で書き直す

- 式：国の参加の総量 `P_n = Σ_k S_k = Σ_p N_p π_p`（旗 1 で π＝D）。足切り `S_k ≥ φ P_n`（φ＝MinSizeFraction 0.01 のまま）。読む 3 か所（Factions.cs:38・:73・FactionSnapshot.cs:86）は同じ 1 つの関数から読む。
- 意味：〈国の不満の頭数の 1% 以上を占める州×ブロック×思想の組〉が運動になる。チェノウェスの 3.5%（材料 S2〈推〉）と同じ〈参加の割合〉の物差し。
- 良い所
  - 分子（参加の重みの頭数）と分母（今は人口の頭数）の型が揃う（分子と分母の非対称の型を消す）。
  - 新しい係数・閾値・状態が無い。P_n は ComputeClusters の同じ回りで足す（POP の回りは増えない・保存しない導いた値）。
  - 物差しの尺度に依らない：全ての D を λ 倍にしても勢力の組は同じ。D の式を次に変えても（例 D2＝G/R）足切りを較正し直さなくてよい。
  - 勢力の数は 1 国 1/φ＝100 以下（Σ_k S_k＝P_n から出る・上限を置いたのではない）。
- 難しい所
  - 蜂起は戻らない（U0-1）。
  - 満ち足りた国（P_n が小さい）でも小さい運動ができる。強さは小さいので蜂起はしないが、画面の一覧が長くなる（App の読み手は〈次の波〉5 の束）。
  - 旗 0 の参加（max(D, M)）でも世界が変わる＝旗が要る。計器 prdf・prds・dcont と PrdsShadowTests の 4 行（材料 S6）を同じ線で直す。
- 計算量〈推〉：POP の回り +0。勢力の数が増える分の合流 F²（最悪 1 国 5,000 対／四半期）で +0.5 秒以下。数え口 CostLedger に〈勢力の対〉を 1 行足して推定に入れる。

## U2. 案 B：足切りを消し、強さの側だけで決める

- 計算量〈推〉：書き直した後で +1〜3 秒・書き直さなければ +数秒〜十数秒。
