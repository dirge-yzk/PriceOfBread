## §2 問い 2：売れ残りの信号を、どの 1 本の経路で判断へ戻すか

前提：全体の世界では、売れ残りは既に値段で判断へ戻っている（在庫の差→MarketFlow.cs:68 の値段→ProfitFactor）。戻らないのは形 乙（値段が在庫に応じない財）だけ。

### 案 (i)：R2〈判断の値段を、売れた量の収入（国内＋輸出）÷作った量にする〉

- 良い所：判断と帳の量の非対称を根で閉じる。新しい係数 0・状態は LastRevenue を使う。値段が在庫に応じない財（形 乙）にも効く。
- 難しい所：
  - 値段が在庫に応じる財では、同じ売れ残りが値段（在庫の差）と〈売れた割合〉の 2 回で判断に入る＝二重計上（思想⑨）。形 甲（行き過ぎて凍る）を深くする向き〈推〉。
  - 輸出の代金を LastRevenue に記す直しが前提。PaySales（InternationalMarket.cs:29）の分け方と、読み手 Simulation.cs:1580（国営持分の赤字の見込み）の挙動が変わる。
  - 清算の買いの見込み（BilateralMarket.cs:289 の ProfitFactor(p, pLoc, mc)）と判断が別の値段を読むことになる＝揃えるなら同じ線で 2 箇所。
  - 1 か月目の赤（ColonialPopTests）は前の月の帳を読むので直らない。

### 案 (ii)：InventoryAdjust を在庫の量に比例する形へ（利得は今の InventoryAdjustGain＝0.1 のまま）

- 中身（EconomyStep.cs:2776 の 1 行）：invGap の分母を (desired＋Stock＋Eps) から desired へ。desired は TargetStockFloor＝1 以上なので Eps は要らない。
  - 今：invAdj ∈ [0.9, 1.1]（在庫が 100 倍でも 0.9）。
  - 案：invAdj＝max(0, 1＋0.1×(desired−Stock)/desired)。在庫 0 で 1.1（今と同じ）、在庫＝desired で 1、在庫 ≥11×desired で 0。上の端は在庫 ≥0 から自然に出る。下の 0 は今の Max(0, …) のまま＝天井も片方向の錠も足さない（README §1-8）。
- 利得の出どころ：Metzler・Lovell の在庫の調整の模型〈推〉＝差の 1 か月あたりの埋め率。今の 0.1 を〈差の 10%/月〉と読み直す。係数の値は変えない。
- 良い所：1 行・新しい係数 0・新しい状態 0。読み手は同じ 1 本（供給①・生産の診断・T1Base を通して清算の見込み）＝判断と清算が自動で揃う。値段の形成には触れない。
- 数の目安（material §3 の値から〈推〉）：
  - 沿岸西アフリカの金（旗1）：在庫 1,141〜1,296・需要 381〜433 → 今 0.95 → 案 約 0.80。
  - 盤面のジャマイカのコーヒー（旗1）：2 か月目の在庫 500・需要 68 → 案 0.36、3 か月目から 0。
- 難しい所：
  - 全ての生産者が変わる（在庫が desired を超える財は全て弱まる）＝大きな挙動の線。基線の売れ残りの多い財の規模が縮む（20261111 の下書きが挙げた石灰石・野菜の注は今の EconomyStep.cs に見当たらない＝どの財かは腕の前に計器で数える〈未確認〉）。空洞化と主食が主な関所。
  - 1 か月目の赤（ColonialPopTests）は、最初の在庫が小さいので直らない。
  - 形 乙の金は〈売れた量に代金が付かない〉のが先の問題かもしれない〈未確認〉＝(ii) は症状を抑えるだけになりうる。
