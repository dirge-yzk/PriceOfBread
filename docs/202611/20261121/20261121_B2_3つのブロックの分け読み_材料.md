## 4. 史実の形（要約・〈推〉）

- 身分（法の地位）の境：1789 の三部会は身分で分かれた。8 月の法令は人身の権利を無償で廃し、土地に付く権利の多くを買い戻しとして残した（無償の廃止は 1793）＝第三身分の中の利害は既に割れていた（Lefebvre『大恐怖』ほか・(1078) の訂正のとおり）。
