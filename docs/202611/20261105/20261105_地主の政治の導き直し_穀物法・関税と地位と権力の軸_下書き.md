## 1. (C) C1 の書き直し：穀物法と関税の地主の項

### 案 C1（元の形・σ）

- 中身：ブロック b の保護の利害＝Σ穀物 rentBg×σ_g÷国の地代の和。σ_g＝(輸入−輸出)÷(輸入＋輸出＋産出)（国境を越えた分だけ）。今の `RentProtectionWeightCoef × e.Rent[b]` の Rent[b] をこれに置き換える。
- 良い所：状態 0・係数 0・計器 cornint_s が既に同じ量を数えている。
- 難しい所（m852 で確かめた）：
  - 分子が 6 割の行で厳密に 0（地代の付いた穀物が国境を越えない）＝保護の利害が消える。上限でも今の 1/2 前後。
  - 反射の罠：保護が効くと輸入が減り σ が下がり支持が消える。
  - 符号が四半期の貿易の揺れで振れる（C1 の符号の反転 中央 5〜7 回/世紀・p90 40〜46 回・今の式は 0 回）。
  - σ は〈今どれだけ輸入しているか〉であって〈保護を外したら何を失うか〉ではない＝作者の要約〈輸入と競うか輸出か〉の〈競う〉を流れで測っている。

### 案 C1′（推奨）：次の一段で動く穀物の地代（反実仮想・LordStake と同じ型）

- 中身（式は AI の案）：
  - 穀物の財 g（`Staple` か `GrainChain`＝`BilateralMarket.cs:808` と同じ客体）ごとに、国内の値段 p_g と、楔 d での着値 L_g(d)（買い手を外した売り手の重み付き平均×(1＋運賃＋d)）を使う。楔 d＝関税＋穀物法の段の `CornFactor`×`CornLawImportPenalty`（`InternationalMarket.cs:171`・`Coefficients.cs:256`）。
  - 減らす向き（保護を 1 段外す）で失う分＝国内の値段のうち、1 段下の楔の着値より上に支えられている分：S↓_g＝max(0, min(p_g, L_g(d))−L_g(d−))÷p_g（値段だけ・流れを読まない）。
  - 進める向き（保護を 1 段足す）で得る分＝次の楔の分×今どれだけ輸入が国内の値段を抑えているか：S↑_g＝m_g×(L_g(d＋)−L_g(d))÷p_g。m_g＝国境を越えた輸入の割合（輸入÷(輸入＋国内の産出)・`World.ImportsByGood` と同じ国境の量）。
    - 値段だけで S↑ を書くと（max(0, min(p, L(d＋))−L(d))÷p）、裁定で国内の値段が着値に張り付いた状態（p＝L(d)＝輸入が値段を抑えているまさにその状態）で 0 になる＝足す利害が消える誤り。ここだけは流れを使う理由がある：保護が効いて輸入が止まれば〈さらに足す〉利害が消えるのは正しい飽和（もう守る物が無い）で、振れではない。戻す向きの利害（S↓）は値段だけで残る＝反射の罠は〈戻す向き〉の罠で、反実仮想はそこに効く。
  - ブロック b の利害＝Σ_g（ブロック b が国内で売る穀物 g の地代）×S_g÷国の地代の和 Tr（向きごとに S↑ か S↓）。`DirectionAware` に穀物法の旧支配層を足す形（農奴解放・土地改革と同じ・`PolicyPreferences.cs:650`〜`651`）＝同じ式で進めると戻すを読む（§1-8〈同じ門で戻れる〉）。
  - 穀物法の旧支配層の選好＝`RentProtectionWeightCoef`×その利害（係数は 1.0 のまま・新しい係数 0）。近代と大衆の −1 は残す（C2 は次の段＝1 テーマ 1 計測）。
- 3 つの型（AI の読み・利害は値段で・型の分け方は流れで）：
  - ①輸入と競う国（関税なしの着値が国内より安い）：楔が国内の値段を支えている＝S↓＞0＝保護を守りたい（英 1815〜46 の型）。保護で輸入が止まっても、外せば入ってくる分が S↓ に残る＝反射の罠に効く。輸入が流れていれば S↑＞0。
  - ②楔が効かない国（国内がもとから着値より安い）：S＝0＝穀物法に無関心。
  - ③輸出する国：着値が国内より高い＝S＝0。〈負〉にはならない（自国の穀物法は輸出の地代を動かさない）。
  - ②と③は値段だけでは同じ条件（p＜L(0)）＝利害はどちらも 0 でよいが、門 G2 の母集合（③）は流れで分ける（穀物の `ExportsByGood`＞0）。
  - 普のユンカーの 1879 の転換は、米と露の穀物の着値が下がって②→①へ移る形で、所得から出る（史実の年は記録）。
- 良い所：
  - 戻す向き（S↓）は流れを読まない＝保護が効いている国（限定・全面）では、σ で厳密に 0 だった行でも 0 でない値を持ちうる（上限の中央 0.11・材料 2-2 の下げる向き）。進める向き（S↑）は輸入の割合 m を掛ける＝穀物が国境を越えていない行では σ と同じく 0（ここは正しい飽和の 0・材料 2-2 の上げる向きの上限 0.14〜0.22 は m を掛ける前の値＝真の値はもっと小さい）。0 になる理由はどの行でも〈地代の付いた穀物が無い〉〈楔が効かない〉〈輸入が流れていない〉のどれかで説明できる。
  - 保有から導く（地代×値段の差）・札は旧支配層の 0 の位置だけで、向きは所得と値段から出る。
  - 持ち分（B1）が入れば、土地を買った資本家にも同じ式で同じ向き（札でなく持ち分）。
  - 消費者の側（C2）も同じ S_g で書ける（主食の支出×S＝楔が押し上げている値段の分）＝1 本の量の両側。
- 難しい所：
  - **着値は 1 国の選好の中から見えない**（§0 の 1）。置き方は 3 つ：
    - (a) 四半期の判定の段で国ごとに利害（ブロック 3×2 向き＝6 個）を数え、`World` のセーブに載る欄へ書く＝**新しい状態 1**（導ける量だが、1 国の中からは導けない。`DiscoveryPrice` が〈1 国に財の数＋1 の 1 本〉で残された先例と同じ理由）。
    - (b) `[System.NonSerialized]` の作業領域へ書く＝ロードの直後に null＝ロードした月から次の判定までの選好が違う＝**セーブの往復で軌道が割れる**（savetest の型の誤り）＝採らない。
    - (c) 毎月、多国の段で組み直す＝計算量（判定の段の頭は四半期に 1 回の前提で組まれている）・`DiscoveryPrice` は四半期にしか進まない＝月ごとに組み直しても値は四半期の値と同じ＝無駄。
    - ＝**推奨は (a)**。作者に聞く物 Q1。
  - **大きさが今の 1/5〜1/10 に下がる**：今の +1.0（地代のシェア≈1）に対し、上限の中央でも 0.1〜0.2（真の値は上限以下）。穀物法の議会と要求の地主の押しが大きく弱まる＝記録の先頭。係数を上げて大きさを合わせることはしない（新しい係数を作らない・倍率の削除の方針＝作者 2026-10-16「全てのバフ・デバフ(特に倍率を変更するもの）は全て削除したいです。」）。
  - 正の帰還：保護が国内の値段を上げると S が増え、保護の支持が増える。上限は L_g(hi)（楔の分）と国内の値段の天井で決まり、発散はしない。リカードの〈保護は地代を上げる〉の形そのもの＝史実の型。片方向の錠かは門 G4 で記録する。
  - 国内の値段は平滑化した値段（`DiscoveryPrice`）を使う＝着値と同じ種類（README §1-9）。参照価格は読まない（作者 2026-10-20 の参照価格のリワークの根を増やさない）。
  - Q は固定（値段が下がっても作る量は変えない一次の近似）＝地代の動きの過大の側。
- 計算量：四半期に 1 回・国×穀物の財×売り手の国（約 60）＝+0.1 秒前後の見込み（要測定）。
