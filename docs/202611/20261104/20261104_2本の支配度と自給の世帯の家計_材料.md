## 4. 史実の出典（短い要約・作者への返答で使った物）

- ルイス（1954、「無制限な労働供給による経済発展」）：伝統部門（自給の農家）は限界生産がほぼ 0 の余った労働を抱え、取り分は平均の生産物（生存の賃金）。近代部門は生存の賃金に少し上乗せした賃金で、その余った労働を際限なく吸い上げる＝工業化＝農村から都市へ人を引き出すこと。吸い上げが尽きた点（転換点）で賃金が上がり始める。
- ミント（1958、余剰のはけ口）：19 世紀の植民地の輸出の伸び（ビルマの米・ゴールドコーストのカカオ・東南アジア）は、自給の農家の遊んでいた土地と労働を輸出作物へ回した結果で、自給の生産を大きくは減らさなかった＝〈非効率ながら外貨を得る〉の史実の型。
- 明治の地租改正（1873）：収穫の現物（石高）の年貢から、土地の値（地価）の 3%（1877 に 2.5%）を貨幣で毎年納める定額へ。豊凶に関わらず額が同じ＝凶作や米価の下落（松方デフレ 1881〜85）の年に農民は多く売らされ、土地を手放して小作が増えた。
- 永代査定（ベンガル・1793）：ザミンダールの地税を貨幣で永久に固定・納めないと土地を競売（日没の法）＝取り立ての圧力が小作へ転嫁され、在地の地主が土地の持ち主になった。
- アイルランドの大飢饉（1845〜52）：小作と日雇い（コッティア）はジャガイモの自給で食べ、穀物と家畜は貨幣の地代を払うために売った。胴枯病で自給が崩れても地代のための輸出は続いた。死者約 100 万・移民約 100 万以上。
- 補い（作者への返答では使っていない・要約だけ）：チャヤーノフ（1925）＝農家は家族の消費と労働の苦の釣り合いで働く量を決める（家族の大きさで生産が決まる）。スコット（1976、モラル・エコノミー）＝定額の貨幣の請求（地税・人頭税）は凶作の年に生存線を割らせる＝収穫の割合の請求より反乱を生む（1930 年代のビルマ・ベトナム）。
