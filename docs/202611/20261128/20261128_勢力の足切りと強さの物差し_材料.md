## M1-2. 史実の出典の要約（〈推〉・AI の一般の知識・本は開いていない）

- 運動の大きさの物差し：チェノウェスとステファン（2011）の 3.5% は〈その場の人口に対する参加の割合〉。全国の運動なら国の人口、地方の蜂起なら地方の人口が分母〈推〉。1871 のパリ・コミューン、1830〜40 年代のリヨンの絹織工の蜂起、1905 のロシアの地方の農民蜂起のように、19 世紀の蜂起の多くは 1 都市か 1 地方の頭数で起きた＝国の 1% に届かない組でも、その州では大きい。
- 暴力と組織：ティリー『動員から革命へ』（1978）＝集合暴力の規模は〈利害の共有〉より〈組織と動員できる頭数〉で決まる。ガー（1970）＝不満が暴力に転じるかは正当化と組織で決まる。→ 不満（D）は組をつくる側、戦う頭数は闘争度（M）の側という分け方の裏づけ〈推〉。
- 小さい組の結党：19 世紀の社会主義の小党は数十人〜数百人の結社から始まった例が多い（例：1875 のゴータ合同の前の諸団体）〈推〉。得票は結社の頭数でなく有権者の思想で決まる＝今の Parliament.cs:180〜:190 の動的な党の得票の式と同じ向き。

### M3-3 尺度に依らない形（問い 2 の 3）

- 人口の尺度（N→λN・各 POP の D・M・C は同じ）：F と H と L は全て λ 倍＝比は変わらない。φN・φN_r・φP_n の足切りも変わらない。今の式は既に満たす。
