## K1. 足切りの下限（問い 1）

### K1-1 案 A（推奨）：足切りの分母を州の人口にする `S_k ≥ φ N_r`

- 式：組 k＝(r, b, i) は `S_k = Σ_{p∈k} N_p π_p ≥ φ · N_r`（φ＝MinSizeFraction 0.01 のまま・N_r＝州の人口＝Region.SumPopulation、LocalizedHold（Politics.cs:671）が読む同じ量）。
- 意味：〈その州の人口の 1% 以上が、同じブロックと思想で不満を持つ〉組が運動になる。チェノウェスの割合を〈その場の人口〉で読む形（材料 M1-2〈推〉）。保持力 H_r も州の割合で按分している（Politics.cs:667〜:674）ので、勢力と保持力が同じ場所の物差しになる。
- 良い所
  - 新しい係数 0・新しい閾値 0・新しい状態 0。今の φN の分母を国から州へ替えるだけ（1 段・例外なし）。
  - 分母が D で縮まない：国の全ての D が 0 へ寄れば組の大きさが 0 へ寄り、勢力はできない（満ち足りた国に運動なし）。
  - 下限が観測量で書ける：勢力の大きさ ≥ φ × 州の人口 ≥ 1.2 人（基準の州の最小 120 人）・p1 で 37 人（材料 M3-4）。1 人に満たない勢力は州の人口が 100 人を割るまで出ない（O1）。v2 の〈P_n 100 人未満で勢力のある行〉は、1 万人未満の州（州×四半期の 3.6%）を持たない国では勢力 0 になる〈推〉（S_k ≤ P_n < 100 人 ≤ φN_r）。
  - 単一の州の国では今の φN と同じ。多い州の国（仏 33 州ほか）で地方の運動ができる＝1 地方の蜂起の史実の型（材料 M1-2）。
- 難しい所
  - 辺境の小さい州（ナイン・イカルイト・チャーチル・ロレートほか・1 万人未満が州×四半期の 3.6%）で、数人〜数十人の勢力ができ、結束 0.3 で全国の党を立てられる（Parliament.cs:221〜:226 は大きさを読まない）。党の得票は有権者の思想で決まる（:180〜:190）ので議席の桁は動かない〈推〉が、記録の観測量にする（K4 の O3）。
  - π の尺度には依る（D を半分にすると勢力が減る）。これは狙い（材料 M3-3）。
  - 勢力の数が増える〈推〉：上界は州ごとに 100 × D̄_r。旗 1 の参加の割合の中央 0.0154（国）なら、1 州あたり 1〜2 本〈推〉。
- 計算量〈推〉：州の人口は組の同じ回りで足せる＝POP の回り +0。

## K2. 強さの物差し（問い 2）

### K2-0 どの項が組の大きさに比例するか

- `F = Size × AvgMilitancy × Coh × σ`（Politics.cs:621）。Size（=Σ N π）が大きさに比例。AvgMilitancy（π の重みの平均 M）・Coh・σ は大きさに依らない。H（Politics.cs:667〜:674）は国の人口と州の割合に比例、L は他のブロックの頭数に比例。
- 121→5（m1425 で 157→5）は π＝D にした Size の縮み（同じ盤面の中央 0.26 倍）と、AvgMilitancy が M の高い POP を重く読まなくなった分（比の中央 0.11 倍・材料 M3-2）。結束の門の行は増えた（55,668→64,736）＝足切りの道ではない。

### K2-1 案 S2（推奨・sd の 3 回目）：強さの頭数を闘争度で数える `F = Σ_{p∈k} N_p M_p² × Coh × σ`

- 式：勢力の器が〈戦う頭数〉`FightHeads_k = Σ_{p∈k} N_p M_p`（暴力の参加＝闘争度）を持ち、AvgMilitancy を〈闘争度の重みの平均〉`Σ N M² / Σ N M` に読み替える。`F = FightHeads × AvgMilitancy × Coh × σ`。Size（=Σ N D）は政治の大きさとして足切り・Kappa・合流・画面が読むまま。
- 意味：作者 2026-11-25「不満度はあくまで政治アクションの値です」の分け方を、勢力の中で〈組をつくる＝D〉〈戦う＝M〉に分ける。
- 良い所
  - 新しい係数 0・閾値 0。**旧の強さとほぼ同じ桁**：基準の盤面で Σ N M² ÷ 旧の Σ N max(D, M) M の中央 0.982（材料 M3-2）＝H・L・FactionOverwhelmFactor 1.5 の較正を動かさない。腕の盤面での反実仮想は強い行 5→385〈推〉（基準 157 の 2.5 倍・10 倍の線の内）。
  - D は強さに入らない＝D の式を次に変えても（例 D2）強さは変わらない。
- 難しい所
  - M を 2 回読む（参加の重みと強さ）＝思想⑨の型。旧の旗 0 の強さ（max(D, M) ≈ M）と同じ型で、新しく増やすのではない〈推〉。(1417) U3 が〈⑨の型〉と書いた物を残す。

### K2-2 案 S3：戦う頭数だけ `F = Σ_{p∈k} N_p M_p × Coh × σ`
