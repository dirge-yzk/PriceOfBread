## 4. 史実の要約（AI の一般の知識＝〈推〉・数は確かめていない）

- 〈推〉国の暴力の独占（ウェーバー）は国の取り分（Rule[0]）に当たるが、秩序そのものは在地の支配でも保たれた：清の保甲と郷紳・オスマンのアーヤーン・ロシアの領主と村の共同体。治安＝国家の取り分とすると、在地が治める秩序を数えない。
- 〈推〉英の警察は首都（1829）→都市（1835）→州（1839 任意・1856 義務）＝届く範囲が首都から地方へ広がった。フランスのジャンダルムリ（1791）は農村の道を受け持った。届く力は人口あたりの頭数と距離で決まる。
- 〈推〉治安の崩れは統治の崩れより速い：財政の破綻や敗戦の後、数か月で盗賊が増え、統治の区分（徴税の届き）は年の単位で崩れる（南イタリアの匪賊 1861〜65・清末の地方）。
- 〈推〉警官や兵の密度は人口あたりで比べるのが普通（〈人口千人あたりの警官〉の型）。今の式は人口あたりでない（1 節）。
