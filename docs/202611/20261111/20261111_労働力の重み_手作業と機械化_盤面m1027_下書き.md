## 1. 前提（材料 §1 の要約）

- 労働力のレシピ（蒸気機関・電動）は産出の 1% 未満。機械化度 Mechanization は IndustrializationOff で恒久 0。
- 生きている機械化の信号は、工場の蒸気・電化の充足（1790 で 0.06→1930 で動力の割合 0.93）。
- 労働の財は 1 本の均質な役務＝買い手ごとに女・子の重みを変える道は無い。重みは売り手の work（EconomyStep.cs:1086）に掛けるしかない。
- 正規化（:1095）で t=0 の水準は打ち消す＝効くのは変化だけ。

## 2. 案（どれも〈AI の案・確証なし〉）

### 案 1（推奨）：州の〈動力の割合 m〉で手と機械の重みを按分する

- **式**（POP が LaborId を売る時）：
  - m＝Σ_工場 L_f × p_f ÷ その州の LaborId の前月の売れた量。
    - L_f＝前月に工場 f へ**実際に移った** LaborId（Output × 投入の実効量〔:3209 の式のまま〕× LastInputFill〔Model.cs:721〕、または台帳の購入量）。分母の〈売れた量〉と同じ基準（実際に移った量）にそろえる＝分子の和が分母を超えない（分子と分母の非対称を作らない・教訓⑮）。もう一つの選択は両側を需要の側（分母＝前月の需要）でそろえる形。どちらかを事前登録で固定する。
    - p_f＝ElecFill＋(1−ElecFill)×SteamFill（:1617 の蒸気の需要と同じ分け方）。
    - 建設など工場でない買い手は分母にだけ入る＝手作業として数える。
    - 分母が 0（最初の月・工場の無い州）は m＝0。否定形 `!(分母 > 0)` で書く＝NaN も 0 の側（NaN と fail-open のガードの規律）。
  - w_女＝w_女手＋(w_女機−w_女手)×m。w_子＝w_子手＋(w_子機−w_子手)×m。
  - work＝男(15〜64)＋女(15〜64)×part×w_女＋OldLaborFactor×(男(65〜)＋女(65〜)×part×w_女)＋AgeShare(10,15)×w_子×ChildLaborRate。
- **POP ごと**：
  - 農民（FarmLabor）＝m＝0 で固定（農業・鉱山の機械化の経路が現物に無い＝§4）。
  - 工場労働者（LaborId の 5 本のレシピ）＝州の m を共有。
  - 最初の月：SteamFill・ElecFill は Producer の初期化子に代入が無い（Simulation.cs・Model.cs を grep）＝既定 0 から移動平均で上がる＝m もほぼ 0 から始まる。
  - 技師（AdvLabor）：読みが 2 つある。
    - (i)【推奨】重みを掛けない＝女・子とも重み 1、子は今の ChildWorkFactor の旧の値のまま（係数なし）。Catalog.cs:172「監督・保守・運転」は力の仕事ではない。技師の子に機械の重み 0.8 人前を置く根拠が無い。
    - (ii) 機械の端として m＝1。
    - (i) にすると、ChildWorkFactor を手の子の重みへ置き換えた時に技師の行が動く。技師の行だけ旧の 0.5 を読む分岐が要る（または技師の子の項を 0 にする別の問い）＝作者に聞く物 4。
- **場所**：m は工場の能力のループ（:1016）の前に、州ごとに 1 回だけ導く（laborTotalW と同じ置き方）。前月の値だけを読む＝ループの中の順に依らない。毎月導くので**新しい状態 0**（思想⑩）。
- **InitialWork の捕捉**：5 本のレシピが同じ m を共有＝work は同じ＝捕捉がレシピの評価順に依らない（問い 1 の順の問題が消える）。最初の月の m は充足が 0 から上がるのでほぼ 0＝手の重みで捕捉される。
- **良い所**
  - 1783 年の手の世界の差は、較正済みの水準に吸われる（壊さない）。
  - 機械化が進むほど、工場労働者の実効の労働が比例で増える（紙で 1930 年に +17〜19%）＝「機械化により是正」がそのまま変化として出る。
  - 閾値なし・片方向の錠なし・天井なし（m∈[0,1] は割合の定義で、削る上限ではない）＝README §1-8。
  - 入力は全て既存の量。
- **難しい所**
  - 計算量：州ごとに工場を 1 回なめる（:1016 のループと同じ件数・掛け算だけ）。推定 +0.3〜1 秒（AI の見込み・未測）＝余り約 17.5 秒の中。
  - 同じ ElecFill・SteamFill を 4 本目の読み手が読む（材料 §7）。合算で、電化の完了した州は労働の需要 −40%・供給 +18〜20%＝失業が同じ向きに増える（帰結として名乗る）。
  - 新しい州の POP は、最初の月の m で捕捉する＝機械化の進んだ州の新しい POP は是正の伸びを持たない（★(1027)① と同じ型の記録）。
  - 職人と RGO の自分の能力は work を読まない＝重みが届かない（既知のずれ）。

### 案 2：財で固定する（m を作らない）

- 農業労働力＝手の重み・労働力＝機械の重み・高度労働力＝機械の重み。
- **良い所**：分岐だけ・計算量 0・読み手 1 つ。
- **難しい所**：
  - t=0 で打ち消し、時間とともに動く量が無い＝「機械化により是正」が出ない。
  - 1783 年の工場（水車・畜力・手）が機械扱い。効くのは参加率・児童労働・戦死への応答の大きさだけ。

### 案 3：労働力のレシピごとに重みを置く（指示の素案）

- 人力＝手・畜力と水車＝中間・蒸気機関と電動＝機械。InitialWork は〈手の重みの work〉で捕捉＝`InitialWork = work(w_手)`。boost_r＝work(w_r)÷InitialWork。
- **良い所**：レシピの名前と意味が合う。
- **難しい所**：
  - 掛ける先がほぼ無い（蒸気機関＋電動で 1% 未満）＝是正はほぼ起きない。
  - レシピの「蒸気機関」は工場に据える原動機の売り物で、〈機械を操作する人〉ではない＝置き場がずれる。
  - 機械のレシピの能力が t=0 から +20% 動く＝×2.0・×2.5 の較正と採算（:3197 の自己費用の割り算）が動く。

## 4. 農業と採掘（問い 2・3）

- 農業：農業労働力は手作業 1 本・畜力の犂は RGO の増強材〈馬〉（Catalog.cs:305）にあるが、選んだ財が Producer に残らない（effChosen は月ごとの局所の配列）。
  - 二択（AI の案・確証なし）：
    - (a)【推奨】記録の限界にする＝農民は手の重みのまま。理由：19 世紀の農業の機械化（刈取機・脱穀機）は女の生産性を上げるより人を減らした（英では女が畑から退いた・Burnette）。是正が史実で大きくなるのはトラクター（1920 年代〜）。
    - (b) EffFill を代理にする（肥料が混ざる＝誤り）＝推さない。
  - 次の段の候補（別の線）：穀物の増強材に〈機械〉を足す（刈取機・発見の門つき）＋選んだ財を区別できる形。これは新しい状態か新しいデータが要る＝作者に聞く物。
- 採掘：鉱山は農民の農業労働力を買う＝売り手が同じ POP。重みは売り手に掛かるので、手掘りの鉱山と蒸気で揚水する鉱山を生産者ごとに分けられない（RGO に蒸気の充足も無い）。手の重みのまま＝史実の向き（1842 年の鉱山法）とも合う。記録の限界として名乗る。
