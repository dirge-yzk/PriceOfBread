## §3 段 0 の計器の仕様（恒等の計器・作者が確かめを望む場合だけ）

ソースの不等式で段 0 は出るので、**推奨は計器を作らない**（記憶〈回す前に必要性を確かめる〉）。作るなら次の形。

  - `billDrawnPerQuarter`：払いの段で、その州の商人の Debt の増え（CearnImportPayRegion(r) の時点の値と、次の呼び〔次の州か null〕の時点の値の差）＝実際に動いた額（教訓 ⑮）。

  - `billExcessPerQuarter`：清算ごとの max(0, drawn−collateral) の和。
- 置き場：InstrumentsCearn.cs の CearnAcc（清算の頭の写しは作業領域・読み手の無い欄は作らない）。エンジンの関数は呼ばない・エンジンの局所変数（costA・due・have）を受け取らない。
- 試験（機構の試験・旗 0）：
  - C1：〈高く買う〉の財（bias 1）・r＝0.1・距離 0 の 2 州の試験世界で、払い手の貯蓄 0 なら excess ＞0。

  - C3：方針なし・遠い海路なら excess＝0 で、drawn ＞0（対照の件数の Assert）。
- 突然変異：
  - Mi1：担保＝払った額 → excess は常に 0 → C1 が赤（同語反復を拾う）。

  - ソースの予言は〈ほぼ 0〉＝no-go。
- 費用：清算の頭で州×財の 2 つの値を写す＝計器が入っているときだけ。
