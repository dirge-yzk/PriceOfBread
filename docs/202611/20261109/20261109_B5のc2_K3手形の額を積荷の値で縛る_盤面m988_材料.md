## 4. 今の式（〈ソース〉）

1 単位あたり（買い手の州 t・最良の売り手・fac2 ≧1）：
- 払い手が払う額（自国通貨）：costA＝unitA×(1＋duty＋frA＋portT＋portS＋prem)÷fac2÷exRate。
- 高く買う補助（振り出しの前に入る）：unitA×buyDear×r÷fac2÷exRate（r＝FiscalFundingRatio）。
- 手形で賄う額（貯蓄 0 の払い手）＝costA−補助。
- 担保の値（K3 の定義＝買い手の州のその財の市場の値段）：m.Price＝lp÷exRate。
- 比 ρ＝(手形の額)÷(担保の値)＝(unitA÷lp)×(1＋duty＋frA＋portT＋portS＋prem−buyDear×r)÷(1＋mar2＋duty−buyDear＋bb2)。
- 分子−分母＝(frA−mar2)＋(portT＋portS＋prem)−bb2＋buyDear×(1−r)。
- 既定の係数で：mar2 ≧0.18×(1＋k)（k＝km÷1万・FreightRevolution＝1.0）・frA ≦0.10×k・港と保険 ≦0.023。
  - ＝分子−分母 ≦−0.157−0.08×k＋buyDear×(1−r)。
- **ρ ＞1 になり得るのは buyDear×(1−r) ＞0.157＋0.08×k のときだけ**＝高く買う方針の財（buyDear＝0.25）で、かつ支払い率 r が約 0.37−0.32×k より低いとき。
  - 方針の無い財（buyDear＝0）では、全ての成約で ρ ＜unitA÷lp ≦1。
  - TryTradeBias は財政が逼迫すると方針を畳む（SelfPlay.cs:1264）＝r の低い国で方針が残る場面は少ない〈推〉。
- 縁の場合（fac2 ＜1）：同国の取引で buyDear ＞mar2＋bb2（k が小さい・約 3,900 km 未満）のとき、売り手の値段が lp を超え得る＝unitA ＞lp（最大 1÷fac2 倍）。この縁の r の線は上の〈約 0.37〉と別で、導いていない。これも buyDear が要る＝〈buyDear＝0 なら ρ ＜1〉は変わらない〈ソース〉。
- grep の裏づけ：candF の書き手は :931（候補を足す時に fac2）と、:1010・:1076 の候補の入れ替え（同じ添字の 4 つの表を一緒に動かす）だけ＝candF[bestPos] は常に最良の売り手の fac2。
- 振り出し（:1145）は清算ごとに州で 1 本（due−have）＝ρ の比べは成約の和で効く。

**K3 の担保を m.Price で数えると、手形の額が担保の値を超える成約は〈高く買う方針の財で、支払い率が低い〉ときにしか出ない**〈ソース〉。段 0 の予言〈着値 ≦地元の値段が大半なら K3 は何もしない〉の条件は、着値（:942 の着値）については構造で 100%（成約の条件そのもの）。残るのは〈払った額〉と〈着値〉の差（運賃と港・保険と方針）だけ。

担保の値段の 2 つの候補（反証役 ③ の読み直し）：
- m.Price（州×財の市場の値段・lp の元）。国の PriceLevel の床 0.4 は**これには直接掛からない**。反証役 ③ の〈州は国の床を継ぐ〉は r.PriceLevel（rpT の元）の話。
- rpT＝RefPrice×r.PriceLevel×exRate（X の価格の腕の値段）。床の国では 0.4×RefPrice。(980) の突然変異表では M3〈担保を rpT で数える＝誤り〉に当たる。担保を rpT にすると縛りは強く効くが、これは効き目で値段を選ぶ形＝採らない〈AI の案〉。

K2（割引料）の訂正〈ソース〉：手形の払い手は budget＝∞（:583）＝:988 の `budget/costA` は量を縛らない。X は unitA（:959）と xNeed で決まり、costA を読まない。**割引料を costA に足しても量は下がらず、振り出しの額が増えるだけ**（(980) §3-3 の〈X の価格の腕で量が下がる〉は外れ）。量に効かせるには、手形の払い手の行だけ着値の倍率 fac2 に割引の分を足す（:927・:942 の打ち切りに効く）形が要る。割引の率は既存の物では PolicyRate×PolicyRateLoanWeight（Coefficients.cs:902・重み 0.0＝何もしない）しか無い＝新しい係数か重みの点火が要る。割引料の受け手（銀行の持ち主）の道も無い＝新しいお金の道。
