# 教育の三層化と高等教育／年金の社会保障接続／法の適用範囲 — 仕様（2026-09-11・作者指示）— 設計・**部分完了**（2026-09-12＝段1 の器 `EduProducersCoexist`＋FactorySpec 94/95/136 の明示登録を実装・休眠。点火＝段3 の batch30 単独は未）

## 0. 作者の指示（原文の要旨）
1. **教育のオーバーホール**：教育法を廃止し、宗教学校→公教育→義務教育を**無段階**に。「義務教育：なし／あり」を新設（教育費を非常に高める）。聖職者＝無から教育を生み出し、生活費は十分の一税など特権から。教師＝学校を使い教育と、非常に少ない高等教育を生み出す。生活費は教育を売って得る（教育費＝教育を買い取り無償で配る行為）。**工房と工場の関係に近い**。
2. **高等教育の実装**：教授＝大学を使い高等教育を生み出す。生活費は高等教育を売って得る。**買い手は識字POPに限る**。
3. **年金は社会保障費に接続する**。
4. **法律関係**：自国民（国名＝文化、または最多文化）／異民族／植民地の3つで法を分離（投票・官僚・児童労働など）。**自国民の得ていない権利を他が得ることはできない**。

⚠2026-09-06 に私は「教育法の廃止＝費用対効果で保留」と裁定したが、**今回の案はそれとは別物**である。前回評価したのは「段を滑らかにする」だけだった。今回は**教育を三層の生産者に分ける機構**であり、特権システム・高等教育・社会移動に接続する。保留を撤回して採用する。

## 2. 教育の三層化（教育法の廃止と無段階化）

### 2-1. 形＝同じ財に生産者を2本並べる
今の「毎月どちらか一方に差し替える」をやめ、**聖職者の学校**と**教師の学校**を同時に州へ置く。労働配分（準レントの重み・`EconomyStep.cs:441-465`）が自動的に混在を解く。

⚠これは**新しい作法ではない**。E-13 の堆肥／黄鉄鉱法・坩堝鋼／錬鉄レールと同じ「同じ財に複数レシピを並べる」型である。

| 生産者 | 担い手 | 投入 | 生産性 | 生活費の出所 | 性質 |
|---|---|---|---|---|---|
| **教区学校** | 聖職者 | 紙(61)×0.05 | `ClergyEduProductivity`（現 2.0） | **十分の一税が主**＋教育の売上 | 価格が下がっても供給が落ちにくい＝**市場の外に足がある** |
| **公立学校** | 教師 | 書籍(112)×0.05 | `TeacherEduProductivity`（現 5.0） | **教育の売上のみ** | 国庫が買えば増え、買わなければ減る＝**市場の中** |
| **大学** | 研究者（＝教授） | 書籍(112)×0.4 | `UniversityProductivity`（現 2.0） | **高等教育の売上のみ** | 買い手は識字POP＋国庫 |

**これが作者の言う「工房と工場の関係」である**：教区学校＝職人の工房（特権に守られ、効率は低いが潰れない）、公立学校＝工場（効率は高いが採算に従う）。既存の職人／工場の並存と**同じ機構**で表せる。

### 2-2. 無段階化＝8系統の4値スイッチを1つの連続量へ
法が効いている8系統（`Simulation.cs:1890-1918`／`TechEducation.cs:11-14, 280-286, 293`／`Institutions.cs:32`／`Politics.cs:63-67`／`CrownParliament.cs:218,240`／`MultiNationSim.cs:1469`）を、**世俗担い手シェア**へ置換する。

```
secularShare = 教師の教育産出 / (教師 + 聖職者の教育産出)        ∈[0,1]
```
⚠**これは既に `TechEducation.EmergentElite` が計算している量である**（`secular / total`）。生産者を並置すれば、**同じコードが自動的に連続値を返すようになる**。

| 系統 | 現行（4値） | 置換後 |
|---|---|---|
| ② 識字速度 | const 0.0001/0.004/0.005/0.007（**係数ですらない**） | `LiteracyRateBase × (1 + SecularLiteracyBonus × secularShare)` ＋義務教育の項。⚠まず係数化が要る |
| ③ 世俗水路 `EliteMultiplier` | 0.0/0.1/1.0/1.2 | **`secularShare` そのもの**（`EmergentElite` が既にこの形） |
| ④⑤ 革新・特許の解禁 | 公教育以上 | `secularShare` の連続ゲート（`Discovery.Unlock` の既存の形を使う） |
| ⑥ 政治意識の変換 | 0.1/0.15/1.0/1.0 | `secularShare` で補間 |
| ⑦ 国民意識の天井 | 0.9/0.7/0.4/0.2 | 同上 |
| ⑧ 同化ボーナス | 公教育以上に加算 | `× secularShare` |
| ① 担い手・生産性・投入 | 毎月の差し替え | **撤去**（2本並置で不要） |

### 2-3. 「義務教育：なし／あり」＝新しい法1本
- **2値**。効果は**需要と国庫の買い取り**の両方。
```
義務教育なし： 国庫の買い取り率 = PublicEduFundingShare × EducationSpending
義務教育あり： 国庫の買い取り率 = EducationSpending（満額）
               かつ 就学の義務＝need が予算で切られない（affordable のクランプを外す）
```
- 作者の「教育費を非常に高める」はこの2つ（満額の肩代わり＋予算で切られない需要）で出る。
- ⚠**前提として児童労働と衝突する**。`LawPrereq` に「義務教育ありは児童労働の禁止が前提」を置くのが史実（英1870→1880、仏フェリー法）。既存の `ChildLaborLiteracyPenalty` と二重にならないよう、**penalty は残し、法の前提だけを足す**。

> ⚠**訂正（2026-09-12・LIST §0-8-B/B2・§0-10 の裁定を本文へ書き戻し）**：上の `LawPrereq`「義務教育ありは児童労働禁止が前提」は**史実と食い違う**。英1833年工場法は全面禁止ではなく**半日労働＋就学義務**であり、英は 1870（フォースター法）→1880（義務化）→1891（無償化）の順で**義務化が先**。仏フェリー法（1881-82）も児童労働の全面禁止（1874年法は12歳未満の制限）とは別の法である。
> したがって前提条件（`LawPrereq`）にはしない。正しい形＝**義務教育が `LaborSupply.ChildLaborRate` の機会費用項 `(1 − Need(p))` を、既存の行政力ゲート `enforce`（`Simulation.cs` の児童労働の書き手）越しに打ち消すゲート**（LIST §0-8-B「したがって正しい形＝優先度ではなくゲート」・§0-10 の教育法 #1 の置換先＝**同一箇所・同一作業**）。`ChildLaborLiteracyPenalty` は残す。段3（義務教育法の新設）の「`LawPrereq` に児童労働の前提」の文言はこの訂正で無効。

### 2-4. 十分の一税との接続（作者の「特権から得る」の実装）
現行の十分の一税は `EducationLaw` を一切見ない（`Privileges.cs:95-111`）。したがって宗教学校期の聖職者は**授業料と教会税を同時に**得ている。
- **裁定が要る点**：十分の一税の率を `secularShare` に連動させるか否か。
- **推奨＝連動させない**。理由＝十分の一税は教育の対価ではなく**特権**（`Privileges` の台帳に載っている）であり、剥がすのは国教法と特権の剥離が担うべきだから。教育を教師に奪われても教会税は残る（史実＝仏1789まで、英のタイズは1836年まで）。これで「教会が教育から締め出されても、特権を剥がすまでは富み続ける」という正しい形になる。

### 2-7-2. 唯一の設計判断＝在庫をどう扱うか
`Spoilage = 1.0` のまま通常財にすると壊れる。`MarketFlow` の通常経路は在庫ギャップ `(TargetStock − Stock)/(TargetStock + Stock)` で価格を動かすので、**在庫が毎月全損すると gap が恒常的に最大＝価格が上がり続ける**。

**採る形＝`Spoilage` を下げ、在庫を「就学の機会（空席）」と読む。**
- 目安 0.25（パンと同じ＝数ヶ月で消える＝**学期**の感覚）。売れ残った授業は席が空いたまま学期が終わって消える。
- 蓄積された教育は市場在庫ではなく **pop の `Literacy`** に載る（既存）。したがって市場在庫が短命でも二重にならない。
- ⚠点火時に価格の挙動を必ず見る（`Spoilage` と `TargetStockBuffer` の組で gap が暴れないこと）。

### 2-7-3. 消費順序（Tier の選択）
通常財は Tier で消費順序が決まる（主食→日用品→奢侈品→…→役務）。現在の教育は**最後**。
- **`Daily`（日用品）が妥当**＝主食の次、奢侈品より前。予算で切られるので貧しい pop は買えない（正しい）。
- ⚠**教育需要が増える方向に較正が動く**（今より前で買われる）。単独計測。

### 4-1. 先に直す実バグ4件

### 4-2. 接続の形＝1つの予算・1つの充足率・1つのクランプ
```
社会保障の要求 = 現金給付の要求 + 年金の要求 + 医療保険の補填の要求
社会保障の予算 = WelfareRevenueShare × FiscalCapacity × SpendingCapFactor   （1本）
充足率        = 実支出 / 要求                                               （1本＝WelfareFunding を3者共通に）
緊縮・国庫クランプ = 3者に等しく掛かる
```
- **等しく削る**のが中立。どちらが守られるかは**政治が決める**＝`PensionOldWeight = 2.5`（live）が既にあるので、老年の発言権が強い国では年金段が維持され、若い国では削られる、が創発する。**新しい優先順位の定数を作らない。**
- 勘定は `TreasuryCat.Welfare` / `Pension` の2区分を**表示のために残す**（合算予算の内訳）。医療補填は `OtherOut` から `Welfare` へ移す。
- 死蔵の `Policy.Pension` は**削除**（法の段だけを正とする・削減方向）。
- ⚠給付は現在 `p.Savings` に加算されており `p.Earned` に入らない＝**所得税の課税ベースに入らない**。これは意図か否かの裁定が要る（史実＝年金課税は20世紀後半なので、現状維持が妥当）。

## 5. 法の適用範囲（自国民／異民族／植民地）

### 5-1. 軸を3倍にしない — 各法に「範囲」を1つ付ける

- **「自国民の得ていない権利を他が得ることはできない」が構造的に保証される**（範囲は自国民から外へ広がるだけなので、逆転が起こりえない）。

### 5-6. 現状の範囲2法は実質死蔵（是正の対象）
- `ColonialSuffrage` の live な読み手は `Fiscal.cs:46`（課税への同意）**1箇所だけ**。分離圧力の枝は `SuffrageScopeUnified = 1.0` によって **else 枝が到達不能**になっている。

- ⚠**建国時の法継承に範囲2法が無い**（`MultiNationSim.cs:488-505` の継承リストに欠落）＝独立のたびに範囲がリセットされる。`Policy.CopyFrom` には両方あるので**漏れているのは建国経路だけ**。

### 5-7. 配線の実測＝`PolicyAxis` 1本につき16箇所
過去の記録「7箇所」は**過小**だった。最新2軸（Guild 2026-09-07／CivilianArms 2026-09-11）を追跡した実測は16箇所。
