# 忠実度の3断面（1820／1870／1913）＋WW1帰結の1920断面 — 設計（**完了** 2026-09-05：E-08 1820/1870 断面＋E-09 1920 断面を SelfPlay/HistoricalReference/Runner に実装・batch の「断面」行で併記）

作者指示（2026-09-03）：「1950年まで伸ばす想定なので、開始〜1950のうち3か所ぐらいで測定すべき。原因をより究明しやすい」「WW1の結果は監視する必要がある（先の課題）」。

## 1. 断面の選び方（史実の物差しに合わせる）
- **1820／1870／1913** ＝ Maddison の基準年（世界GDP推計が最も厚い3年）。1913は既存。
- 1820＝ナポレオン戦争後の初期条件（清が世界最大・英が工業化の入口）。1870＝第二次産業革命の入口（独伊統一・米南北戦争後・日明治）。1913＝第一次グローバリゼーションの頂点。
- **1920**（E-09）＝WW1の帰結＝帝政4つの消滅（独墺露オスマン）・新国家・米の債権国化。政体次元だけ先に監視（経済は戦時攪乱で物差しにならない）。

## 3. 実装の形（新機構なし・物差しの追加のみ）
- `HistoricalEntry` に `GdpRank1820`/`GdpRank1870`（int?）と `PolityExact1820/1870/1920`（既存の PolityOk 群と同型）を足す。無い国は null＝その断面では採点しない（既存の作法）。
- `fidelity` コマンドと `selfplay-batch` の集計に **断面の四半期**（1820=Q148・1870=Q348・1913=Q520・1920=Q548；開始1783Q1）を足し、各断面で `NationFidelity` を出す。帯の主指標◎7割は**1913のまま**（既存基線を壊さない）。1820/1870/1920は**併記**（新しい列）。
- 1820/1870の順位は Maddison 2010（1990年国際ドル・全実体込みの世界順位＝1913と同じ規約）。⚠表の値は記憶ベース＝**出典で再確認してから入れる**（Maddison Project Database 2020 の MPD2020 表）。

## 5. 1920断面（E-09）の政体参照（史実）
独＝共和（ワイマール）・墺＝共和・露＝共産独裁（ソヴィエト）・オスマン＝崩壊中（1922廃止）・英仏伊＝変化なし・日＝立憲・米＝共和・清（中華民国）＝軍閥＝軍事独裁/共和の near。**敗戦国の帝政消滅**が主目的＝「敗戦×左派×恐慌」のファシズム器（FascismCrisisWeight）とも同じ材料。
