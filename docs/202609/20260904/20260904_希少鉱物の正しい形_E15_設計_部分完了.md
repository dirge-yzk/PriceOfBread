# 希少鉱物の正しい形（E-15）— 設計（**部分完了** 2026-09-05：肥料の硫酸化＝コスト中立で採用（J-013）。黄鉄鉱法・後期産地・産地天井の3器は休眠（点火4回とも下流消滅で差し戻し）＝プログラム終了）

## 1. 何が分かったか（2026-09-04・E-13の差し戻し）
- `ScarceMineralGate=1`（硫黄のみ）は世界総量を保存して**産地1州**（両シチリア＝world.json で硫黄(5)を持つ唯一の州）に集める。賦存は302倍になるが、**産出は50年で410**（ゲート0の20,376の2%）・価格31倍。下流＝化学薬品−93%・火薬−94%・肥料消滅。
- 産出が伸びないのは賦存でなく**拡張**＝RGOの `BuiltScale` は着工（`built×IndPerConstruction×RgoCapitalShare`・上限 `rgoCap`）で伸びる＝**両シチリアの国庫と着工予算**が世界の硫黄需要を賄う速さの上限になる。史実のシチリア硫黄ブーム（1820〜40年代に産出10倍超）は**英仏の資本**が掘った＝本作に無い経路（国境を越えるRGO投資）。
- ⚠貿易/GDP 20.3%は価格の人工物（数量×価格）＝採用根拠にならない。

## 2. 史実の解き方（ゲートでなく代替）
1838年の硫黄危機（ナポリ王国が仏企業に独占権→英が艦隊で威圧）の後、世界が採ったのは**黄鉄鉱からの硫酸**（リオ・ティント＝1873年英資本・ノルウェー・スペイン）＝**原料の代替**であって、産地の多重化ではない。1894年フラッシュ法（ルイジアナ）で米が新産地＝**発見で解禁される後期産地**。

## 3. 設計（推奨1本）＝硫黄の代替レシピ＋後期産地の発見
- **代替レシピ**：化学薬品（と火薬の硫黄入力）に第2レシピ「黄鉄鉱法」＝入力＝鉄鉱石＋石炭（黄鉄鉱を新財として足さない＝「幅に足さない」規約）、生産性は硫黄法より低い（コスト高＝史実の代替は高くついた）。解禁＝**発見**（`DefaultRecipeOnset` の表に1行＝灯油・冷蔵と同じ注入パターン `XxxFromYyyEnabled`）。
- **後期産地**：ルイジアナ（米）・日本（九州）・チリの硫黄を `Resources` に足すが、**産出は発見（フラッシュ法＝深部採掘）で解禁**＝1783年の地図には無い産地を「技術で掘れるようになる」形。＝金鉱と同じく発見の技術カテゴリに入る（ユーザー指示「時代フィルタは全て発見に注入」と整合）。
- **ゲート本体**は `ScarceMineralGate=1`＋`ScarceMineralOnlySulfur=1` のまま（産地集中は史実）。代替と後期産地が揃って初めて点火。
- ⚠国境を越えるRGO投資（英仏資本がシチリアを掘る）は別プログラム（資本移動＝金融のテーマD）。ここでは扱わない。

## 6. 追記（拡張の上限の正体・2026-09-04）
- RGOの拡張上限 `rgoCap` は `RgoElasticityGate=1.0`（点火済み）の下で**カテゴリ定数** `MineralScaleCap`（鉱物）／`FarmScaleCap`（農）＝**賦存に依らない絶対上限**。産地1州に302倍の賦存を与えても、掘れる規模は他の鉱山州と同じ天井＝硫黄産出410はこの天井。
- 従って E-15 の第3の腕＝「希少鉱物の産地では上限を賦存に比例させる」（`rgoCap = MineralScaleCap × ScarceEndowment/ResourceEndowment`＝総量保存と同じ倍率で天井も上がる＝新しい数を作らない）。史実＝シチリアは1820年代→1830年代で産出10倍超・世界の9割。代替レシピ（黄鉄鉱法）と同時に入れて測る。
- 値＝`MineralScaleCap=1.5`（「既存鉱脈の増産余地は+50%まで」）・`FarmScaleCap=3.0`・`ScaleMax=3.0`。硫黄1州の産出が世界需要の2%で止まる理由はこの1.5。賦存比例にすると両シチリアの硫黄だけ天井が302×1.5になる＝総量保存の倍率と同じ（新しい数なし）。
