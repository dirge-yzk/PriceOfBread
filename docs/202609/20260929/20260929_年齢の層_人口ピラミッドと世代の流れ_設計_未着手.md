## 2. 器の設計

### 2-1. 16本は割合か人数か（推奨＝割合）

| 観点 | 割合（合計1）＋`Size` が主 ◎ | 人数16本（`Size`＝和の導出） |
|---|---|---|
| `Size` の読み書き | 触る約550行（うち SimCore の代入28行）はそのまま【確】 | 書き28行・`new Pop { Size = … }` の初期化・テストの POP の組み立てを全て層へ直す |

### 2-2. 加齢の流れ

```
毎月・各 POP・各性 s について（前の値から同時に）：
  n'[0,s] = n[0,s] − n[0,s]/120 （＋出生）
  n'[b,s] = n[b,s] − n[b,s]/120 + n[b−1,s]/120   （b = 1..6）
  n'[7,s] = n[7,s] + n[6,s]/120                   （70以上は死でだけ出る）
```

- 置き場＝今の加齢の行（Simulation.cs:2479-2486）を**その場で置き換える**＝月次・助走中は止まる（:2230-2231 の門の内側）【確】。新しい関数を作らない。四半期に1/40 と同じ量。
- 精度：層の中を一様とみなす＝0〜9歳のように若い側が厚い層では出ていく流れを多めに数える。改良案＝境界の密度を隣の層との平均 (n[b]+n[b+1])/2/120 で読む（新しい数0）。**4e-1 の計器で両方を史実のピラミッドと比べて選ぶ**【推】。
- 性の移り変わり：子供の層は男女半々で生まれ（§7-3 Q11）、成人の職業の性比は今と同じく社会移動の性別の選抜（`ProfessionGenderGate`）が保つ。

## 5. 世代の流れで性質を混ぜる

### 5-1. 式

```
POP ごと・毎月（加齢の直後）：
  E = (n[1,男]+n[1,女]) / 120 × Size         … 20歳になって大人に入る人数
  A = Σ_{b≥2} n[b,·] × Size                 … 入る前の大人（20歳以上）
  X ← (A·X + E·X_in) / (A + E)               … 大人の値 X に、伝わった値 X_in の若者を混ぜる
  大人の死・移出：X は変わらない（平均で出る）
  移入・社会移動：I の Blend が「移る大人の人数」で混ぜる（Size でなく）
国の水準の記憶 M（毎四半期）：
  R_nat = Σ_pop E ÷ Σ_pop (A+E)              … 国の置き換わり率（毎回導く＝貯めない）
  M ← M × (1 − R_nat × (1 − τ))              … τ＝伝わる割合（0＝1世代で薄れる・1＝薄れない）
```

- 大人の境を20にする理由＝層の境で按分が要らない・識字と就学は20歳までに終わる（§7-3 Q5）。
- R は1783年の標準の構成で四半期0.89%（半減期 約20年）。**高齢化すると R が下がり記憶が長くなり、若者の膨らみでは速くなる**＝人口の模型から自動で追従する（9-2 の後も1か所を読むだけ）。
- 置き換わり率を読む関数は1本（国の R）。今の「半減期から毎回 `Math.Pow(0.5, 1/半減期)`」の3か所（Politics.cs:188・CrownParliament.cs:219・Diplomacy.cs:3258）と減衰の3か所（CrownParliament.cs:215・Military.cs:28・TechEducation.cs:105）を置き換える。
- 「若い大人と年上の2値」は今は持たない。世代間で価値が分かれる必要が出たとき（思想の世代差）に、識字や国民意識から先に2値化する（§7-3 Q12）。
