# Equal Earth 図法への差し替え（作者指示 2026-09-05）— 設計（**差し戻し**＝同日の作者判定「座標系のズレ・視覚的に優れない」・ソースは変更前へ厳密復元）

## 0. 前提の訂正
現行はメルカトルではなく**正距円筒（プレートカレ）**＝`MapData.Project` が緯度経度を直線でキャンバス（2000×780・緯度82〜−56にクロップ）へ写す。背景＝`Assets/worldmap.svg`（Wikimedia BlankMap-World6-Equirectangular・2,289パス・viewBox 2752.766×1537.631・緯度98〜−100・経度−166.4〜193.6＝中心+13°E）。陸マスク（SimCore `Landmask`）は0.1°の緯度経度格子＝図法に依存しない。

## 1. 方針＝ベクターを新たに入手せず、**コードで再投影**する
- 真実源は緯度経度（places.json・州座標・Landmask）。Equal Earth（Šavrič–Patterson–Jenny 2018・等積擬円筒）の閉形式を **SimCore の Geo** に置く（Tests は SimCore だけを参照する＝往復テストを置ける）。
  - θ：sinθ = (√3/2)·sinφ。x = (2√3/3)·λ·cosθ / (A1 + 3A2θ² + θ⁶(7A3 + 9A4θ²))、y = θ(A1 + A2θ² + θ⁶(A3 + A4θ²))。A1=1.340264・A2=−0.081106・A3=0.000893・A4=0.003796。逆変換＝θ をニュートン法で解く（数回で1e−12）。
- App `MapData.Project` を Equal Earth に置換＋`Unproject` を追加。キャンバス定数＝x範囲 ±(2√3/3)·π/A1…（実測値をコードで算出＝定数を手書きしない）。
- 背景の焼き（`GameView.BuildLandBitmap`）＝SVGの `d` を自前で解析（M/L/H/V/C/S/Q/Z の絶対/相対＋transform）→曲線を平坦化→各点を SVG画素→緯度経度（線形）→Equal Earth→キャンバス画素に写して StreamGeometry で描く。`Geometry.Parse` は使えない（アフィン変換しか掛けられない）。
- 政治の塗り分け（`MapFill`）＝塗りの計算は緯度経度格子のまま（東西ループ含む）。**ラスタ化だけ**をキャンバス画素→逆投影→格子参照に変える。型紙（`CaptureDrawnLandMask`）も同じ逆投影で読む。
- 東西ループ（背景2枚＋`ClampAndWrap`）は**廃止**（擬円筒は横に継げない）＝地図は楕円1枚・パンはクランプ。継ぎ目は太平洋（現行の中心+13°Eを保つ）。
- シム側は投影を読まない（距離＝大圏・陸判定＝緯度経度格子）＝**挙動は1ビットも変わらない**＝UIのみ・バッチ測定不要。硬性ゲート＝フルスイート＋uishot の目視。

## 2. 手順
1. SimCore `Geo.EqualEarth/EqualEarthInverse`＋往復テスト（1e−9・既知点＝(0,0)→(0,0)・赤道での x = 2√3/3·λ/A1）。
2. App `MapData`：Project/Unproject・キャンバス寸法（幅2000は据え置き・高さは投影のy範囲から算出）。
3. `BuildLandBitmap`：パス解析＋再投影（`CumulativeTransform` はSVG画素空間で先に適用）。
4. `MapFill`：逆投影ラスタ化＋型紙の読み出し。
5. ループ廃止・パン/ズームのクランプ・ラベル/○/航路の描画は `Project` 経由なので自動。
6. `--uishot` で目視（大陸の形・州○が陸に乗る・政治塗りが海にはみ出さない）。
