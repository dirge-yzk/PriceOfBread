## 0. 量（§4）
```
①支配力【述語】   ＝ 行政力×0.5 + 軍事力×0.5（既存＝§15-0）                → 徴税・秩序・送金・関税権
②支配度【ストック】＝ 前期 + (引き留め − 離脱圧力) × 速度                          → 0 で独立（§14-6）
③同化度【ストック】＝ 世代交代・教育・通婚（数十年）                             → 離脱圧力を下げる（既存の CoreEthnicShare が実体）
④離脱圧力【述語】 ＝ 現地POPの闘争度 × 規模 × (1−③) × 距離（＝E-05段1の投射で減衰）
```
守る条件＝水準はストック・速度は述語／「上げる」ボタンは作らない／②の書き手は統治ステップの1箇所。

## 1. 置き場（既存に絡める・新ファイル禁止）
- `Region.Dominance`（double・0..1）を **植民地格の州と従属領（属国＝Power 単位）** に持つ。本国州（Core/Integrated）は 1 固定＝読まない。
- 書き手＝`Politics.CheckSecession` の直前（四半期）＝E-05段1/2 が計算している `hold`（保持力×投射÷共有分母）を**引き留め**、`pressure`（闘争度×規模×文化距離）を**離脱圧力**として `Dominance += (hold − pressure) × DominanceSpeed`（`DominanceSpeed` は既存の分離判定の速度と同じ物差し＝新しい数を作らない候補＝`SecessionPressureRate`）。
- 独立の判定＝現行「pressure > hold 閾値」を **`Dominance <= 0`** へ置換（器 `DominanceIsStock=0`＝0で現行と厳密同値・1で置換）。
- 初期値＝`HeldSince`（保有年数）から＝`Dominance0 = Clamp01((Year − HeldSince) / DominanceMatureYears)`（成熟年数＝同化の世代長＝既存の `GenerationYears` を流用）。
- 属国（Power 単位の従属）＝同じ式を `Power.Dominance` で（宗主の投射＝E-05段1の `proj`）。離反＝0到達。
