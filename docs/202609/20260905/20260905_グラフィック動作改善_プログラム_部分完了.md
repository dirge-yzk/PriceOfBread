## A1'' 速度クロックの真相（13:10・tick計測）
- ticks=1,346・tick間の実経過の合計=67.5秒（＝50ms×1,346）・壁時計283.8秒・進んだ日数1,350日。**遊んでいる時間だけで見れば 1,350日/67.5秒＝20日/秒＝設計どおり**（1四半期4.5秒）。
- 壁時計の76%は `Playing=false`（OnTick が早期return）＝**ポップアップの自動一時停止**（戦争・危機・外交の2択など）を無人計測が閉じないため。プレイヤーは閉じるので実プレイの体感は設計どおり。＝「速度3が4倍遅い」は計測の穴。
- 計算＋UIは1四半期1.7秒＝速度3の予算4.5秒の38%（速度4＝45日/秒でも予算2.0秒＝計算は収まる）。
- 結論＝動作の本命は **起動の助走31秒** と **フレーム41〜54ms**。無人計測はポップアップを自動で閉じるようにする（計測の穴を塞ぐ）。

## A2' 助走キャッシュ＝**成功**（13:35 cold／13:39 warm）
| | cold（キャッシュ書き込み） | warm（キャッシュ読み込み） |
|---|---|---|
| 助走 | 約31秒＋書き込み（38.5MB） | **読み込み 1.2秒** |
| 起動→盤面 | 42秒 | **約6秒**（起動13:39:07.8→盤面13:39:14） |
鍵＝SimCore の MVID＋playerIndex＋助走長（`warm_<mvid>_<player>_20.pob`）。SaveGame の往復＝savetest でビット恒等＝挙動不変。
- 速度3の四半期＝ポップアップを閉じる無人計測で **4,563ms＝設計どおり（20日/秒）**。計算1.7〜2.2秒＝予算の半分。
- フレーム時間＝州○/ラベル/障壁を外しても52.7ms・政治塗りを外しても55.6ms・背景の補間を落としても不変＝**層に依存しない固定費**＝無人計測の窓が非フォーカス（DWMの背景窓スロットル≈20fps）の疑い＝フォーカス状態の実測が要る（作者の体感で判断）。
- ⚠鍵に MVID を使う帰結＝**ビルドのたびに初回だけ再助走**（約31秒・キャッシュ書き込み）。プレイヤーは配布ビルドが変わらない限り2回目以降は数秒。開発中の無人計測は「同じビルドで2回目」を測る。
- **真の warm（同じビルドで2回目・13:46）＝起動→盤面 10.4秒**（キャッシュ読み込み1.9秒・背景の焼き0.4秒・残りはUI構築）。cold 35〜42秒→**約1/4**。四半期4.57秒（設計どおり）。
