## 2. 所見（2026-09-05 19:46・辺1087・バリア67・峠6）
### ① 内海・外洋を「歩く」陸の辺
- **304/1087 本**が連続30km以上の水を渡る（400km以上 75本・200〜399km 81本）。実例＝上海↔釜山（813km 黄海）・バルセロナ↔リヴォルノ/フィレンツェ/ボローニャ（689〜693km 地中海）・ラングーン↔中核ベンガル（667km ベンガル湾）・バンコク↔マレー（745km シャム湾）・ウラジオストク↔アナディリ/ペトロパヴロフスク（オホーツク海）・ペルー↔チリ・ブラジル↔プンタアレナス（大西洋）・パナマ↔キト/ペルー（太平洋）・ルイジアナ↔中央メキシコ（メキシコ湾）・パース↔アデレード（グレートオーストラリア湾）。
- 根＝`PathGraph.BuildEdges` は**陸塊（landmass.json）が同じなら水を見ない**（別陸塊だけを切る）。同じ陸塊の内側の海（地中海・黒海・バルト海・黄海・ベンガル湾・メキシコ湾・オホーツク海…）は素通り。陸マスク（`Landmask`）は海グラフの陸判定にしか使われていない。
### ★ 陸マスクの穴（副産物・重大）
- `landmask.bin` は**スーダン〜チャド東部〜エジプト南部〜紅海西岸〜ヒジャーズ/アシール（サウジ西部）**が「水」（lat 10〜25N・lon 25〜45E）。実測点＝スーダン内陸(15N,30E)水・センナール水・ドンゴラ水（チャド内陸・南スーダン・コンゴは陸）。ASCII図で穴の形を確認（scratchpad の python 出力）。
- 影響＝①の304本のうちアベシェ↔センナール/ドンゴラ↔ファショダ/カイロ↔センナール等のサハラ・スーダン内陸の辺は**偽陽性**（穴を水と数えた）。海グラフ側（CrossesLand）も同じ穴を見ているが、紅海↔地中海/ペルシア湾の直線はエジプト・中央アラビアの陸で止まる＝現行の海路は壊れていない（要再確認）。
- 対処＝SVG→マスクの再生成（docs/20260802 手順）で欠けたポリゴン（スーダン/エリトリア/サウジ西部…）を復元。
### ② バリア（山脈・砂漠）
- 壁は**点線**：語幹30群のうち 13群が1点（半径110kmの島＝アナトリア内陸・バルカン内陸・ダリエン・パタゴニア・マシフサントラル・カラコルム・シュレスヴィヒ・ユトランド・上エジプト…）。多点の群も点の間隔が 220km（＝半径×2）を超える隙間だらけ（アルプス最長518km・カフカス578・ヒマラヤ694・サハラ697・ロッキー602）。
- **隙間を抜ける辺 19本**：ベルン↔ミラノ（アルプスをゴッタルド/ベルニナの間で）・トビリシ↔グリエフ（カフカス主稜を横断＝誤り）・カブール↔コーカンド/サマルカンド/タシュケント（ヒンドゥークシュ）・クラウゼンブルク↔クラクフ/ルブリン（カルパチア）・アデン↔ブーシェフル/カティーフ（ルブアルハリ横断1600〜1900km＝誤り）・セントポール↔ソルトレーク（ロッキー）・コンゴ盆地4本・クルマン↔キサンガニ（3119km・カラハリとコンゴ盆地を両方横断）。
- **地元免除で抜ける辺 9本**：トリノ↔ベルン・ベルン↔ミラノ（端点がモンブラン/ゴッタルド点から110km以内）・アルジェ/タンジェ/フェズ/オラン↔タマンラセット（1550〜1810km・タマンラセットがアハガル点の脇＝サハラ縦断が免除で通る）。

## 3. 直し方（案・作者裁定不要＝既存の真値と既存の規則を使うだけ。全て器=0で恒等→点火計測）
1. **陸マスクの再生成**（データ修正）：欠けたポリゴンを復元。42点の既知座標に加え、スーダン/ヒジャーズ/チャド/エリトリアを検証点に足す。
2. **陸の辺は水を渡らない**（`LandEdgesAvoidWater`）：BuildEdges の候補に「内部サンプル（格子の半分刻み・海グラフと同じ作法）に連続した水が3格子（≈33km）以上あれば棄却」を足す。判定は収縮を戻した4近傍で（沿岸の町の脇の帯を水と数えない）。河口・湖は33km未満なら通る。島・別陸塊の規則はそのまま。
3. **バリアを折れ線に**（`BarrierWallSegments`）：同じ語幹の点を700km以内で結んだ線分も壁とし、辺の大圏弧が線分と交差すれば棄却（点の110km圏の規則は残す）。地元免除は**点だけ**に残し線分には効かせない（免除で山脈を縦断する辺を止める）。
4. **峠データ**：ゴッタルド（46.56,8.56）・シンプロン（46.25,8.03）・デルベント（42.06,48.29）・ゼンメリング（47.63,15.83）を `pass` として追加、ゴッタルドのバリア点は峠へ置換。
5. 計測＝`landgraph` の代表経路（帯×0.6〜1.7）＋連結成分＋`landaudit` の①②が0本近くへ→batch10（貿易/GDP・列強再現・本国/植民地）→採否。

## 4. 陸マスクの焼き直し（2026-09-05 19:52〜）
- 原因＝旧マスクの生成器が **SVG の `transform`（スーダン `id="sd"` は matrix(3.2254,…)）を無視**し、`<g class="land coast sa/er/ye">` の子パス（無クラス）も取りこぼした。App の `BuildLandBitmap` は両方を正しく扱う（画面のスーダンは正常）。
- 対処＝App に `--bakemask <out.bin>` を追加（`DrawLandPaths` を背景の焼きと共用＝**見えている陸と判定の陸が同じ描画器**）。0.1°格子へ等距円筒で描き、収縮1格子・LSB先の同形式で書く。
- 版A（多数決＝赤>青）＝陸セル 2,049,396→2,059,057（差41,495）。スーダン/センナール/ドンゴラ＝陸に復元。**ジブラルタル(35.95,−5.6) が水**（旧は格子で潰れて陸＝通路の迂回防止に寄与していた）。ヴィクトリア湖・バイカル湖＝水（旧は陸）。
- 版B（少しでも陸なら陸）＝海峡は潰れるが**海グラフが壊れる**（辺222→221・成分2→4＝バルト海と白海が孤立・リスボン沖の辺が落ちロンドン→ナポリ ×1.19→×1.52）＝不採用。
- 次＝版Aで seagraph 診断（成分・通路の迂回比）を旧と比較→ジブラルタルの自動辺による迂回が出るなら、海グラフ側に「通路の線分を横切る自動辺は張らない」規則を足す（海峡は通路が担うという既存の設計を明文化）。
- 修正スクリプト（連鎖後に適用）＝scratchpad/landgraph_fix.py：`LandEdgesAvoidWater` / `BarrierWallSegments`（+`WallLinkKm`）を Coefficients に（PathGraph は `new Coefficients()` で静的に読む＝POB_COEF が効く）・峠6件追加（ゴッタルド/シンプロン/ゼンメリング/デルベント/ドゥクラ/サラン）・登録簿2件。
