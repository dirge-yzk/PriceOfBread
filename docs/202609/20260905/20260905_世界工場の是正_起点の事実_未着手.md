## 2. 何を意味するか
- 思想の到達順（E-12b）がアジア先行・欧州遅れなのは伝播でなくこの地図。E-03（暦年ゲート撤去）が◎−3で落ちるのも同根。列強再現率（史実の列強がならない＝主問題）も同根＝**アフリカ・アジアが1880年代に欧州と同じ技術水準に達する**。
- 作者の2026-09-03の見立て＝「近代化投資のレバーが最初からオープンで、受け入れられる状況かの減衰が無い（幕府が鎖国のまま外国人技術者を雇える）」＝E-01の器 `StateAbsorptionBlend`（吸収ゲート）が既に配線済み・休眠。

## 3. 推奨（1つ）
- **E-01 を点火測定する**（`POB_COEF="StateAbsorptionBlend=1"` batch10・基線E-15b2）。受け入れ＝(a) 1883年のアシャンティ/朝鮮の技術水準が欧州を下回る（`pairprobe` の技術列）、(b) 欧州内シェアが上がる、(c) 列強再現率が上がる、(d) ◎/exact が基線−2以内。到達順（`diffprobe - 5`）は副次の物差し。
- 器の中身（Coefficients のコメント）を読んでから点火。吸収の実体＝識字・都市化・所得（AbsorptionIncomeWeight/Ref）＝「受け入れられる状況」を既存量から作る。

## 4. 器の中身（EconomyStep・確認済み）
- `sabs = CapitalCreditFloor + (1−CapitalCreditFloor) × TechEducation.AbsorptionOf(world)`＝技術（CatchupAbsorptionBlend）・外資（CapitalAbsorptionBlend）・私的建設（PrivateAbsorptionBlend）の3経路と**同じ写像・同じ床**。国庫の近代化投資（StateBuildQueue→stateConstruction）だけにこの絞りが無かった＝「洋務運動が英と同じ効率で工場を建てる」の直撃点。
- 速度を絞るだけで天井を作らない（デッドロック無し）・絞った分は請求が蒸発するだけ（保存不変）・world=null は素通り（恒等）。
- ⚠非西欧の近代化はほぼ全て国庫経由（AI の ModernizationFrac）なので、この1箇所で世界工場の地図が動くはず。動かなければ根は別（発見の伝播＝技術水準の均一化）。
