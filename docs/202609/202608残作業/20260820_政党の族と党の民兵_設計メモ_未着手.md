# 政党の族と、党の民兵（★設計メモ 2026-08-20・⚠実装は後）

> ★ **作者**「議会が自由主義政党が与党で、保守・社会主義政党のシェアがほとんどない場合、ファシストはどの政党を支持する？」
> ★ **作者**「やはり自由・保守・社会の3政党しかないのは限界があるか。今はやらないが、**極端族（極右・極左）**など、いくつかの政党を増やすべきかもしれない」

---

# 1. ★ 現物の答え（実測）

`PoliticalQuantities.FamilyOf(ideo)` ＝ `2 or 3 → 自由族` ／ `5,6,7 → 社会族` ／ **残り全部 → 保守族**。
⇒ ★**ファシズム(9)も王党派(10)も保守族**。⚠ 保守党のシェアがほぼ0でも、ファシストの票は保守族に入り**保守党がそこから伸びる**。**自由党は支持しない。**

★★ **これは史実に合っている**——独でナチ党が食ったのは**自由主義と保守の中間層政党**（人民党・民主党・国家人民党）で、
プロテスタント中間層の政党が1930〜32年に丸ごと崩れた（⚠ 中央党と社民党は持ちこたえた）。
⇒ ★ ファシストは自由党と組むのではなく、**自由党と保守党の票を吸って自分が右派になる**。作者の設定（保守が空）は**ファシストが埋めるべき空白**そのもの。

---

# 2. ⚠⚠ ただし軍部への経路が史実とずれている（★穴）

`poweraff` の写像表：**ファシズムは闘争的なとき 軍部84% ／ 革命16%** へ行く。★**ここが誤り。**

⚠ **ファシズムは軍の運動ではない**：
* ★ 伊のファシスト民兵（MVSN）は **RDL n.31/1923 で国家が給与を払いながらムッソリーニ個人に宣誓**する状態が**18か月**続いた（⚠ 1924-08-04 の勅令でようやく国王への宣誓へ）。**正規軍とは別物。**
* ★ 1922年のローマ進軍で**軍は容易に鎮圧できた**（⚠ プリエーゼが鉄道5か所を切り橋を固め、相手は「26,000名・貧弱な武装・食料なし・豪雨」）。**王が命令を出さなかっただけ**で軍がファシストを支持したのではない。
* ★ 独も同じ＝突撃隊は**党の民兵**、国防軍は別で疑い深く、**1934年の粛清は「突撃隊を潰せ」という軍の要求**だった。
* ⚠ 1918-11-10 のエーベルト＝グレーナー協定と同型＝軍が守ったのは**軍という制度**であって政治運動ではない。

⇒ ★★★ **党の民兵が現物に存在しない**ので、闘争的なファシストの行き場が軍部しかなく、**ファシズムが軍国主義に化けている**。
⚠ これは史学検証で記録済みの穴（「**金を出す側と宣誓の相手が分かれる形は paymaster モデルでは表現できない**」）と同一。
★ ブルガリアのオレンジ護衛隊が**2度**効いた（⚠ 1922年のクーデタ計画はそれを恐れて中止・1923年のクーデタの**最初の作戦行動はその武装解除**）
＝**軍部とも革命勢力とも別の第4の武装**として実在した。

# 3. ★★★ 族を増やすなら「数」ではなく「反体制かどうか」

⚠ **5族にしても、5つ目が「普通に与党になれる政党」なら政治は変わらない。**

★ サルトーリの**分極的多元主義**＝決め手は数ではなく3つ：**反体制政党の存在** / **双方向の対立**（左右の極が互いに組めない） / **遠心的な力学**。
⚠ ワイマールの問題は共産党とナチ党が居たことではなく、**両者が合わせて「否定的多数」を持っていた**こと
＝**政権を倒せるが作る気がない** ⇒ 議会が機能せず**大統領内閣が第48条で統治**した。
★★★ **ヒトラーは議会の連立で首相になっていない**（⚠ 大統領周辺の取引）。**ムッソリーニも議会ではなく王が任命した。**
⇒ ⚠ **極右が普通に与党になれる仕組みだと、この最重要の史実が再現できない。**

## 3-1. ★ 割り方の提案（⚠ 族の数を増やすのではなく、既存の6思想を正しく分ける）

⚠ 現状は**保守族に6思想**（伝統・反動・ナショナリズム・帝国・ファシズム・王党派）＝**ここが一番粗い**（自由族2・社会族3）。

| ★ 族 | ⚠ 中身 |
|---|---|
| 保守 | 伝統・王党派 |
| 自由 | 自由・共和 |
| 社会 | 社会 |
| ★★ **反体制右** | 反動・ファシズム（⚠ 帝国とナショナリズムは状況次第） |
| ★★ **反体制左** | 共産・無政府 |

## 3-2. ★ 反体制かどうかは【新しい定数ゼロ】で出る

⚠ フラグを足す必要が無い＝**既に計算している距離**から出る：
★ 政党の理想点が**現実に到達しうるどの体制からも遠い**なら反体制（`Ideologies.SupportAt` ＋ 政体座標は既存）。

★★ そして反体制政党が議席を持つと、**議会正統性 Lp は高いのに議会がそれを使えない**
＝作者の新コア（2026-08-20）で言えば **Lp が大きいのに予算法を動かせない**状態。
⇒ ⚠ **その空白に執行権か軍が入る**＝ワイマールがそのまま出る。
