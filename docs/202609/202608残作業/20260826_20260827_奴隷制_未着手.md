## ★ 0. 結論

⚠⚠⚠ **奴隷は【POP】である。⚠ 材にしてはならない。**
★★ **そして「材にしないと貿易できない」という前提が偽である**——⚠ **POP を国家間で移送する器が、★ 既に2つ現物にある。**

```
★奴隷貿易 ＝ 【招聘】の鏡像
             ⚠保存する（送出国が減り受入国が増える）
             ★機会の勾配に逆らう
             ⚠受入側が払う
             ★自己制限的（送出側が枯れると値が上がる）
             ⚠禁止法の枠が既にある（SpecialistExitBan）
```

⚠ **違うのは【本人の意思がゼロであること】と【誰が払うか】だけである。**

## ★★★ 2. 前提の訂正 — ⚠ 「材にしないと貿易できない」は偽

⚠ `MultiNationSim.cs:1256` の注記：

> ⚠⚠ 大衆移民と**主語が逆**である。★ **大衆は【自発的に】動く**＝機会の高い方へ流れる。
> ⚠ **技師は【呼ばれて】動く**＝★★ **機会の勾配に逆らって**動く。

> ⚠ **保存**（★ 作者裁定 2026-08-16「POPは無からわかない」）：⚠ **送出国が減り受入国が増える＝ゼロサム。**

### ★ 国家間 POP 移動の三類型

| ★ | ⚠ 本人の意思 | ★ 機会の勾配 | ⚠ 誰が払う | ★ 保存 |
|---|---|---|---|---|
| ⚠ **大衆移民** | ★ **自発** | ⚠ **従う** | ★ 本人 | ⚠ 非ゼロサム（★ モデル外から流入） |

| ⚠⚠ **奴隷貿易** | ★★ **ゼロ** | ★★ **逆らう** | ⚠⚠ **資本家/地主** | ★★ **ゼロサム** |

★★★ **三番目は二番目の【鏡像】である。⚠ 新しい機構を発明する必要がない。**

## ⚠ 3. 三案の比較

### ★ A案：材（財）にする — ⚠⚠ **棄却**

| ★ | ⚠ 致命傷 |
|---|---|
| ⚠⚠⚠ **思想⑨違反** | ★ 財は**生産関数から生まれる**。⚠⚠ **人間を無から産むことになる** |
| ⚠⚠ **保存則違反** | ★ 世界人口が生産で増える。⚠ `PopulationConservation`（`Simulation.cs:258`）が**不変条件として既に入っている**＝**テストが落ちる** |
| ★★ **解放できない** | ⚠ 1863年に**倉庫の在庫が人間になる**のか |
| ★★★ **蜂起しない** | ⚠ ハイチ革命・逃亡・反乱が**構造的に出ない** |
| ★ **消えてしまう** | ⚠ 財は消費される。★ 奴隷は消費財ではない |
| ★★ **食べない** | ⚠ **需要にならない**（★ 奴隷への食料供給は南部経済の実体だった） |

### ⚠ B案：POP にするが、貿易は諦める — ★ 不足

★ 保存も解放も蜂起も出る。⚠ **しかし「大西洋奴隷貿易」という**★★ **19世紀最大の経済現象の一つが出ない。**

### ★★★ C案：**POP であり、移送が貿易である** — ⚠⚠ **確定形**

⚠ **史実がまさにこの形である。**★★ **大西洋奴隷貿易は人間を【生産】していない。⚠ 捕らえて【運んだ】のである。**

```
⚠西アフリカから乗せられた   約1,250万人
★大西洋を渡って着いた       約1,070万人
⚠★★中間航路で失われた      約15%
```

★★★ **送出側の人口が減り、⚠ 受入側で増え、★ 途中で失われる。⚠⚠ 保存則で書ける。**

## ★★★ 4. 確定形

### ⚠ 4-1. 階級

```
★PopClass.Slave = 14
⚠Closed = true      ★★既存フラグ＝「世襲の特権身分。⚠移民の出入りをしない（史実の身分制）」
                    ⚠⚠特権ではないが【出入りしない世襲身分】という述語は完全に一致する
```

| ★ 性質 | ⚠ 既存の器 |
|---|---|
| ★★ **働く** | ⚠ 既存の労働配分（★ プランテーション＝`IsRgo` の賦存州） |
| ⚠ **食べる** | ★ 既存の `Staple` 消費＝**需要になる** |
| ★★★ **蜂起する** | ⚠ `Militancy`（★ POP が既に持つ） |
| ★ **貯めない** | ⚠ `Savings ≈ 0`・★ 賃金を受け取らない |
| ⚠ **識字しない** | ★ `Literacy` が低く抑えられる（⚠ 史実：**教えることが違法だった**） |
| ★ **投資しない** | ⚠ `IsModernElite = false`（★ `Closed` だが `NobleInvests` の対象外にする必要がある——⚠ §10-4） |

⚠⚠ **`Closed` を貴族と共有する点は要注意。**★ 現物の `Closed` は**貴族・聖職**を指し、⚠ `NobleInvests`・`LandedPowerCapitalization`・`RevolutionTerror`・`ClosedWealthMultiple` が**すべて `Closed` を読む**。
★★★ **奴隷を `Closed` に入れると、⚠ 貴族向けの4つの機構に巻き込まれる。⚠⚠ 述語を分ける必要がある**（★ §10-4）。

### ★★ 4-2. 移送 — ⚠ 招聘の鏡像

⚠ 現物の招聘（`MultiNationSim.cs:1313`）：

```
★premium = 1 + max(0, srcO − dstO) / RecruitPremiumScale     ⚠相手が豊かなほど高い
★       ×= 1 + 距離km / RecruitDistanceScale                  ⚠遠いほど高い
⚠perHead = RecruitCostPerHead × premium
★heads   = min(予算 / perHead, pool × MaxFracOfSource) × (1 − ban)
```

★★★ **奴隷貿易はこの式の【符号を一つ変えるだけ】である。**

```
⚠premium = 1 + max(0, dstO − srcO) / SlavePremiumScale       ★★受入側が豊かなほど高い（⚠符号が逆）
★       ×= 1 + 距離km / SlaveDistanceScale                    ⚠中間航路は遠い
⚠perHead = SlaveCostPerHead × premium
★heads   = min(購入予算 / perHead, pool × SlaveMaxFracOfSource) × (1 − ban)
⚠着いた数 = heads × (1 − MiddlePassageLoss)                   ★★★保存を破らずに惨禍が出る
```

#### ⚠ なぜ符号が逆になるか

★ **招聘**：⚠ 呼ぶ側は**貧しい**（後進国が先進国から買う）。★ 相手が豊かなほど**引き剥がすのが高くつく**。
⚠ **奴隷**：★ 買う側が**豊かである**。⚠ 買い手が豊かなほど**値が上がる**（★ 綿花価格が高い年ほど奴隷が高かった）。

★★★ **史実：1850年代の綿花ブームで奴隷価格は倍以上に高騰した。⚠ この式はそれを自動的に出す。**

#### ★★ 送出元をどう決めるか — ⚠ 地名を一つも書かない

⚠⚠ **思想②（国別特例の禁止）に触れずに「どこから運ばれるか」を出す必要がある。**

```
★送出元の適性 = (1 − 行政力) × (1 − 軍事力/人口) × 港からの近さ
⚠           ＝【国家が守れない人々のいる、船の着く土地】
```

★★★ **これは一般則であり、⚠ 史実の全ての奴隷貿易を同時に説明する：**

| ★ | ⚠ 史実 |
|---|---|
| ⚠ **西アフリカ** | ★ 沿岸・国家能力が分散・**大西洋貿易の主源** |
| ★ **バルバリ海賊** | ⚠⚠ **1530–1780 に約100万人のヨーロッパ人**を奪った（★ 地中海沿岸の弱い領主領から） |
| ⚠ **オスマン・クリミア** | ★ 黒海奴隷貿易＝**東欧のスラヴ人**（⚠ "slave" の語源） |
| ★ **東南アジア** | ⚠ スールー海のイラヌン襲撃 |

★★ **＝「アフリカだから」ではない。⚠⚠ 「国家が守れないから」である。⚠ 守れる国は守った。**

⚠ **そしてこれは自己制限的である：**★ 送出側の人口が減る → ⚠ `pool` が縮む → ★ 値が上がる → ⚠ 買えなくなる。★★ **新しい上限が要らない**（⚠ 招聘の注記と同じ論法）。

#### ★ 需要側

```
⚠買い手 = プランテーション財（綿花・砂糖・葉煙草・珈琲）の賦存州を持ち、労働力が足りない州
★予算  = その州の地主/資本家の Savings（⚠国庫ではない）
```

★★ **`PlantationRentShare`（2026-07-30）で既に「賦存州の残余は地主へ厚く落ちる」形になっている。**
⚠ **＝ 買う金の出所が既にそこにある。**

### ★★★ 4-3. 資産としての奴隷 — ⚠ **これが南北戦争の動機である**

⚠⚠ **A案（材）を棄却してなお、⚠ 「奴隷は資産だった」という事実を式に入れなければならない。**

★ **1860年、⚠ 米南部の奴隷の資産価値は【全米の工場と鉄道の合計を超えていた】。**

```
⚠奴隷は【資本家/地主が払って手に入れた】
        ↓
★その支払いが IlliquidWealth（⚠既存フィールド。★招聘でも運ばれている）へ記帳される
        ↓
⚠解放（法）→ ★★その記帳が【ゼロになる】
        ↓
⚠⚠⚠資本家・地主が【猛烈に反対する】   ★FactionSnapshot が既に賛否を階級別に計算する
        ↓
★★内戦・分離の圧力が【台本なしに】出る
```

★★★ **材にすると、⚠ この動機が一切出ない**（★ 在庫が減るだけで、⚠ 誰も戦わない）。
⚠ **POP にして、★ 支払いを地主の帳簿に残すからこそ、⚠⚠ 「解放すると破産する」が出る。**

#### ⚠ 補償という選択肢

★ **英は 1833 年、⚠ 奴隷所有者に【2,000万ポンド】を支払って解放した**（★★ 当時の**国家予算の約40%**）。
⚠ **＝ 補償は「反対を金で買う」既存の形**（★ `MandateSpent` と同型）。⚠ **国庫が払えば通り、払えなければ通らない。**

★★ **補償ありは英、⚠ 補償なしは米（★ 戦争になった）。⚠⚠ どちらも台本なしに出る。**

### ⚠ 4-4. 法 — ★★ **禁止と解放は【別の法】である**

⚠⚠ **ここを一つにしてはならない。⚠ 史実で 60 年ずれている。**

| ★ 法 | ⚠ 対象 | ★ 史実 |
|---|---|---|
| ⚠ **① 貿易の禁止** | ★ **移送を止める** | ⚠ 英 1807 ／ ★ 米 1808 |
| ★★ **② 制度の廃止** | ⚠⚠ **既にいる奴隷を解放する** | ★ 英植民地 1833 ／ ⚠ 米 1863 ／ ★ ブラジル **1888** |

★★★ **①が通っても②は通らない。⚠ その 55 年間に米の奴隷人口は【自然増で】100万→400万へ増えた。**

```
⚠PolicyAxis.SlaveTradeBan      ★なし → 限定的 → 全面    （⚠移送の (1−ban) 項へ入る）
★PolicyAxis.SlaveEmancipation  ⚠なし → 限定的 → 全面    （★SerfEmancipation と同型）
```

#### ★ 外圧 — ⚠ 阿片戦争と同型

⚠ `SelfPlay.cs:1271` が既に言っている：

> ★ この形は**奴隷貿易（⚠ 英海軍の圧力）**・児童労働（★ 国際労働規制）へ**再利用できる**。

★★ **英が自国で禁じた後、⚠ 海軍で【他国の船】を臨検した**（★ 西アフリカ戦隊）。
⚠ **＝「自国の法を他国に押し付ける」機構がそのまま使える。⚠⚠ そして密輸ではない**——★ **相手国の法を変えさせる側である。**

```

★MoveSpecialists             ⚠比例配分・保存・人的資本の運搬
⚠SpecialistExitBan           ★★禁止法の枠（⚠(1−ban) 項が既に式に入っている）
★PolicyAxis.SerfEmancipation ⚠なし→限定的→全面の三段（★同型で書ける）
```

## ★★★ 10. 残る論点

### ⚠ 10-1. 自然増 — ★ **米だけが増えた**

⚠⚠ **大西洋世界で、⚠ 奴隷人口が自然増で増えたのは【北米だけ】である。**

```
★米   ⚠輸入停止1808 → ★1860年に400万（⚠自然増）
⚠カリブ ★死亡が出生を上回り続け、⚠輸入し続けなければ維持できなかった
```

⚠ **原因は労働の苛烈さ（★ 砂糖 vs 綿花）と男女比・気候・疫病である。**
★★ **設計としては：⚠ 奴隷 POP の出生死亡を【その州の生活水準と労働強度】から出せばよい**（⚠ 既存の人口動態が読む量）。★ **地名を書かずに差が出る。**

⚠ **ただし `Closed` 階級（★ 貴族・聖職）の自然増が現在どう扱われているかを ★★ 実装前に確認する必要がある。**

### ★ 10-2. 逃亡

⚠ **地下鉄道・マルーン・キロンボ。**★ **`Militancy` が高く監視が薄い州から、⚠ 自由州/未開拓地へ流出する。**
★★ **`SerfMobilityGate` の【逆】である**（⚠ あちらは移動を塞ぐ法・★ こちらは塞がれた移動が漏れる）。
⚠ **本 doc では扱わない。★ 移送と法が入った後の段。**

### ⚠ 10-3. 農奴と奴隷の関係

```
★農奴  ⚠土地に縛られる。★売買は土地とともに。⚠人格は認められる
⚠奴隷  ★人が動産である。⚠単独で売買される。★人格が無い
```

★★ **別の制度として並存させる**（⚠ 露は農奴・米は奴隷）。⚠ **一本化してはならない。**
★ **ただし `SerfMobilityGate` の「移動を法で塞ぐ」機構は共有できる**（⚠ 奴隷は係数 1.0 相当）。

### ★★★ 10-4. ⚠ `Closed` の巻き添え — **最大の実装リスク**

⚠⚠ **現物の `Closed` は【貴族・聖職】を意味し、★ 4つの機構が読んでいる：**

```
⚠NobleInvests             ★「近代化した国の貴族は投資する」    → ⚠⚠奴隷は投資しない
★LandedPowerCapitalization ⚠旧支配層の政治力に土地を算入        → ★★奴隷に政治力は無い
⚠ClosedWealthMultiple     ★貴族・聖職の初期資産の倍率          → ⚠⚠奴隷は資産を持たない
★RevolutionTerror         ⚠革命で失脚した旧支配層を粛清        → ★★★奴隷は粛清される側ではない
```

⚠⚠⚠ **奴隷を素朴に `Closed = true` にすると、★ 革命のたびに奴隷が粛清され、⚠ 奴隷の土地が旧支配層の政治力になる。**

★★ **処方：**⚠ `Closed` を**「移民の出入りをしない」という物理**に限定し、★ 上の4つは**別の述語**（⚠ `IsOldRuling` など）へ移す。
⚠ **これは奴隷を入れる前に単独でやるべきリファクタである**（★ §8 の手順 2）。⚠ **既存4機構の意味を変えないので厳密恒等が取れる。**

### ⚠ 10-5. 扱いの節度

★★ **本 doc は奴隷制を経済機構として記述する。**⚠ **UI・カード文・年表の文言は別の裁定を要する。**
★ **現物の `NationBrief` が既に「アメリカの文章に『自由な国』と書いてはならない」という規律を持っている**——⚠ **実装後はその制約が解ける代わりに、★ 何をどう書くかを改めて決める必要がある。**
