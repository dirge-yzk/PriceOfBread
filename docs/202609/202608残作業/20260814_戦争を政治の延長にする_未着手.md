# 3. ★★★ ① 要求 — **【阻害】が要求になる**（★ 確定形 2026-08-14）

> ★★★ **`20260814_緊張度をコアにする.PARTIAL.md` §6 で決着した。**

```
★潜在交易(a,b) ＝ max(0, 補完度) × 交易到達度   ⚠循環しない・補完ペアにのみ立つ
★実交易(a,b)   ＝ BilateralMarket の成約        ★観測
★阻害(a,b)     ＝ max(0, 潜在 − 実際)          ⚠⚠これが要求の中身（★単位合わせ＝確定形 13j）
```

⚠ **阻害の原因は【相手の法】**（★ 関税・禁輸・鎖国）。
★★★ **したがって要求は「関税を下げろ」「港を開け」＝ ⚠ 不平等条約そのもの。**

★ **史実の3大事例**：⚠ **アヘン戦争（広東システム）／ペリー来航（鎖国）／1930年代（ブロック経済）**——
★★ **すべて「補完的なのに交易できない」状態だった。**

# 5. ★★★ ③ 諦める経路 — **これが最も欠けている**

```

   ⚠要求X を得たい
```

## ★★★ 諦めることには代価がある

> ⚠ **要求を諦める ＝ 弱腰 ＝ 正統性が下がる。**

★★ **これが「政治の延長」の接続点である。**
⚠ **諦めが安ければ誰も戦わない。★ 諦めが高くつくから、⚠ 勝てない戦争にも踏み切る国が出る。**

★ **史実**：⚠ **1914年のオーストリアは、★ セルビアに譲れば多民族帝国が崩れると考えた**——
★★★ **「戦争の費用 > 収益」でも開戦した。⚠ 諦めの代価のほうが高かったから。**

# 6. ★★★ 「政治の延長」の核心 — **誰が決めるのか**

> ⚠ **戦争を決めるのは「国」ではない。★ 国の中の【誰か】である。**

★ 3つのパイ（`20260814_選挙を動詞にする.HOLD.md`）と直結する：

| ★ 主体 | ⚠ 戦争への態度 | ★ なぜ |
|---|---|---|
| ★ **軍部** | ⚠ **望む** | ★ **統帥権の取り分が増える** |
| ★ **議会** | ⚠ **嫌う** | ★ **予算権を持つほど費用を負担する** |
| ★ **王権** | ⚠ **威信を求める** | ★★ **正統性が低いほど外に敵を求める** |
| ★ **革命勢力** | ⚠ **敗戦を望む** | ★★★ **敗戦は体制を倒す**（⚠ 1905・1917） |

## ★★ 開戦は「4主体の取り分の関数」になる

```
★開戦の圧力 = 軍部の統帥権 × 期待収益
             + 王権の正統性不足 × 威信の必要
             − 議会の予算権 × 期待費用
```

⚠ **正統性が低い王権 ＋ 強い軍部 ＝ 外に敵を求める**（★ **ナポレオン3世・1870**）。
★ **強い議会 ＋ 高い正統性 ＝ 戦争を避ける**（⚠ **英国の1830-50年代**）。

