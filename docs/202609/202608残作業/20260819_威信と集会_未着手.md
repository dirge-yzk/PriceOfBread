# 1. ★★★ 威信（確定形）

## 1-1. コア — **国際的地位が、国民の要求水準を決める**

```
★供給 s      今の地位                      ⚠ 0..1
★参照点 r    s の記憶（指数移動平均）        ★「長くいることで溜まる」の正体
★国民意識 NC 既存の NationalConsciousness

★威信満足 = PrestigeWeight × (s − r) × NC     ⚠ 満足度へ加算（正で満足・負で不満・0で無感動）
```

★★★ **「溜まる」のは満足ではなく【期待】。**⚠ **溜まったものは資産ではなく【負債】。**

## 1-2. ⚠⚠ s の定義 — **順位ではなく【最強国比】**（★ 作者裁定）

```
★top = max over 全実在国 of NationalScore.Of(w)      ⚠ Nation を持つ勢力すべて
★s   = NationalScore.Of(自国) / top
```

### ⚠⚠⚠ 母集団を「全実在国」にする理由（★ 作者裁定・★★ ここを変えてはならない）

★ 既存の `TreatyPortLapse` は `RankOf(p) == PowerRank.Great` で絞って `top` を取っているが、⚠ **威信では絞ってはならない。**

| ⚠ 絞ると起きること | ★ 全実在国なら |
|---|---|
| ⚠ `PowerRank` は**キャッシュ**（★ `_rankClock` / `RankUpdateIntervalQuarters=4` で**年次**にしか更新されない） | ★ キャッシュを読まない |
| ⚠⚠ **分類が古い1年の間に、新しく最強になった国が Great 集合に入っていないと `s > 1.0`** | ★★★ **定義上 `s ≤ 1.0` が保証される** |
| ⚠ 抽象勢力が独立→拡張→1位になる経路で壊れる | ★ **Nation を得た瞬間に自動で母集団へ入る** |

★★★ **＝ クランプを使わずに有界。**⚠ **思想⑧②（極限でコアへ還る・クランプ不可）に合致。**
★★ **母集団の述語は「Nation を持つか」の1本だけ。**⚠ **ランク分類という第2の述語に依存させない。**

### ★ なぜ順位（1/n）ではないか

⚠ 作者の当初案は `1位=1 / 2位=1/2 / … / 8位=1/8`。★ **値の感触は最強国比とほぼ同じ**（⚠ 国力が Zipf 分布に従う限り `シェア ≈ 1/n`）。
★★★ **違うのは「僅差のとき」だけで、そこが決定的：**

| ⚠ 場面 | ★ 1/順位 | ★★ 最強国比 | ⚠ 判定 |
|---|---|---|---|
| ★ **僅差の1位↔2位が入れ替わる**（⚠ 序盤に頻発） | ⚠⚠ **1.0 ⇄ 0.5** | ★★★ **0.99 ⇄ 1.00** | ⚠ **ノイズが消える** |
| ★ **長期的に2位以下へ（本当に差がつく）** | ★ 0.5 | ★ 0.45 | ★★ **痛い**（⚠ r=1.0 のまま9年） |
| ⚠ **一瞬でも10位以下へ** | ★ 0.1 | ★ 0.08 | ★★★ **痛い** |

⚠⚠ **そして：最強国比で 0.08 まで落ちるには【本当に国力が9割落ちる】必要がある。**
★★★ **＝「一瞬の10位転落」はノイズでは起こらず、起きたときは本物の事件（敗戦・国家分裂）だけ。**

### ⚠ 12か月平均を採らない理由

★ 作者の懸念（⚠ 序盤に1位が頻繁に入れ替わり国が荒れる）は正しいが、★★ **根は「月次で見ること」ではなく【順位という離散化】。**
⚠⚠ **平均はノイズを薄めるだけで、同時に「一瞬でも10位以下」を消してしまう：**

```
⚠12か月平均：1か月だけ10位に落ちても  (11×1.0 + 0.1)/12 = 0.925 ＝ ほとんど動かない
```

★★★ **＝ 平均では「ノイズを消す」と「事件を拾う」が両立しない。**⚠ **最強国比は両方を同時に満たす。**
★ したがって **s は平滑化しない**（⚠ 平滑は r ただ1つ。★ 二重に平滑すると思想⑧の深さが1段増える）。

### ★ 既知の限界（⚠ 承知のうえで切る）

⚠ **1位は常に `s=1.0`** なので、★ 「僅差の首位になった不安」（⚠ 1900年前後の英の相対的衰退）は**出ない**。
★★ 要求に無く、⚠ **例外の例外**（思想⑧）として切る。★ 出したければ「上位N国内シェア」だが**採らない**。

## 1-3. ★ 参照点 r — **時定数は新設しない**

```
★r ← r + PrestigeMemorySpeed × NC × (s_前期 − r)
```

⚠ **速度は既存の根拠を流用**。`Coefficients.cs:112`：

> ★ 「0.02 ≒ **半減期35四半期 ≒ 9年** ＝ **列強の地位を得るにも失うにも十年単位かかる**（史実の列強概念＝蓄積された地位）」

★★★ **`PrestigeMemorySpeed = 0.02` を既定とする。**⚠ **新しい時定数を作らない**（★ 桁の根拠があるものを二度作らない）。

⚠⚠ **`NC` を掛ける理由：**★ NC が低い間は r が s を追わない → ⚠ **s−r が正のまま維持 → ★上昇中の新興国は長く満足する**（★ 明治の高揚）。
★★ NC が育つと r が急速に s へ追いつき、⚠ **満足が消える。**
★★★ **＝「国民国家の完成 ＝ 威信の慢性的な飢餓の始まり」。**⚠ **1890年代以降の列強の狂騒（世界政策・建艦競争・アフリカ分割）が台本なしで出る。**

⚠⚠ **実装の必須条件：★ r は【前期の s】を読む。**★★ 同一ティック内で s を更新してから r を更新してはならない（⚠ §1-10）。

## 1-4. ★★★ 決算 — **N年に一度、r が s へ一気に寄る日**（★ 作者設計「桃鉄の決算」）

```
★通常期   r ← r + PrestigeMemorySpeed  × NC × (s − r)     ⚠ 0.02 ＝ ゆっくり慣れる
⚠決算日   r ← r + PrestigeSettlement   × NC × (s − r)     ★ 例 0.50 ＝ 一気に「これが新しい普通」になる
```

⚠ **判定は無状態**（★ `TreatyPortLapse` と同型 ＝ `month % spanMonths == 0`・**フィールドを増やさない**）。
★ **`PrestigeSettlement = 0` で決算が1回も走らない＝厳密恒等**（思想⑧①）。

### ⚠⚠ なぜ「決算日に満足を配る」ではないのか

★★★ **満足度は毎期再計算される派生値。**⚠ **決算日に大きな値を1回入れても翌期に消える＝意味がない。**
★★ **したがって決算が動かせるのは `r` だけ。**⚠ **そして r を動かすことが、そのまま「清算」になる。**

### ★ 決算が生む挙動

| ⚠ 国 | ★ 決算までのN年 | ⚠ 決算日 |
|---|---|---|
| ★ **上り調子** | ★★ 満足を享受する | ⚠ **「これが普通」になり、満足が消える** |
| ⚠ **下り坂** | ⚠ 不満が溜まる | ★★ **諦めがつく**（⚠ **N年たてば人は忘れる**） |

★★★ **＝ 桃鉄の決算そのもの。**⚠ **溜まっていたものが清算されてゼロに戻り、★ 次のN年でまた開く。**

★ **NC が掛かっているので、⚠ 国民意識が高い国ほど清算が速い＝適応が速い。**
★★ 史実：⚠ **1871年に敗れたフランスは1880年代に植民地帝国を築いた。★ 対してオスマン（NC低）は栄光を19世紀いっぱい引きずった。**

### ⚠ 決算は s をホールドしない

★★★ **s は毎期そのまま計算する。**⚠ **s をN年固定すると「一瞬でも10位以下に落ちる」が拾えなくなる**（★ 決算日までに回復していれば見逃す）。
★ **急落は決算を待たず即座に s−r に出て、⚠ 次の決算で清算される。**

## 1-5. ★★★ 国民意識ゲート — **威信は「私の国」がある者にしか届かない**

⚠ **威信とは「私の国が偉い」という感情。★ 帰属が無ければ感じようがない。**

| ★ 史実 | ⚠ 内容 |
|---|---|
| ⚠ **イタリア統一** | ★ 「イタリアは作った。次はイタリア人を作らねばならない」——⚠ **栄光を感じたのは都市のブルジョワだけで、シチリアの農民には何も無かった** |
| ⚠ **ハプスブルク** | ★★ **ケーニヒグレーツの敗北を、チェコ人は悲しまなかった** |
| ⚠ **オスマン** | ★ 帝国の栄光を感じたのはトルコ系ムスリムだけ。⚠ アルメニア人・ギリシャ人・アラブ人には他人事 |

### ★★ 副産物1 — 序盤の荒れが自動で消える

⚠ 開幕の国民意識は `NationBuildInitialDefault = 0.075`。
★★★ **＝ 1783年に首位が入れ替わっても、満足への影響は 7.5%。**⚠ **これが序盤の荒れを消す最大の装置で、追加の機構は要らない。**

```
   → ★列強であっても威信満足が薄い → ⚠不満が減らない
   → ★だから「威信のために無理をする」しかない
```

★★★ **＝「なぜ多民族帝国は必死に威信を追ったのに国民に報われなかったか」。**⚠ **国別特例ゼロ。**

### ★★ 副産物3 — 国民形成に【正の見返り】がつく

⚠ 現状 `SecessionConsciousnessWeight`（★ 育った州は離れない）という**損失回避しか無い**。
★★★ **威信を繋ぐと「国民国家を作った国だけが、列強である果実を国民の満足として受け取れる」。**

### ⚠ 政治意識（`Consciousness`）とは混ぜない

★★ **2つの意識が2つの機構に1対1で対応する。**⚠ **積にして直列ゲート2枚にすると、どちらが効いているか分からなくなる。**

| ★ 意識 | ⚠ 決めるもの |
|---|---|
| ★ **国民意識 NC** | ⚠ **威信が国民に届くか**（＝私の国か） |
| ★ **政治意識 Consciousness** | ⚠ **不満が集会になるか蜂起になるか**（＝組織できるか・§2） |

## 1-6. ★★★ 革命による r の半減 — **これは【罰】ではなく【解放】**

★ 作者裁定：⚠ **王権の転覆などで威信を半減させる。**★★ **半減の対象は `r`（参照点）であって `s` ではない。**

| ⚠ 対象 | ★ 挙動 | ⚠ 判定 |
|---|---|---|
| ⚠ **s を半減** | ★ 地位が落ちる | ⚠⚠ **二重計上**——★ 革命で国力が落ちれば `NationalScore` 経由で s は**既に**下がる |
| ★★★ **r を半減** | ⚠ **「昔の栄光」が焼き払われ、★ 国民は満足しやすくなる** | ★★ **採用** |

★★ **史実：⚠ 仏革命がブルボンの記憶を断った／明治維新が徳川の秩序を捨てた／1918年ワイマールは帝国の威信を継がなかった。**

### ★★★ 既存の「ナポレオンの鎖①」と同じ場所で合流する

⚠ `RevolutionConsciousness=0.25` ＝ **「暴力革命の成立 → NC += これ×(1−NC)」** が**既にある**。★ **同じ処理点に r の半減を置く。**

```
⚠革命 → ★国民意識が跳ね上がる（既存）
       → ⚠威信の参照点 r が半減（新規）
```

★★★ **＝「昔の栄光を忘れた、より強く国を意識する国民」。**⚠ **フランス革命そのもの。**
★ r が低いまま s が上がる ＝ **革命後の熱狂が最大化**され、⚠ **r が追いつくと熱狂は終わる**（★ 1812年以降、フランス人はもう満足しなかった）。

## 1-7. ★★ 建造物由来の威信 — **s と r の【両方】を上げる**

⚠ **これを外すと「金で恒久バフ」＝思想⑨違反になる。**

```
⚠建てる → ★s が上がる → ★満足が上がる
                       ↓
                 ★★r も上がる
                       ↓
        ⚠数年後、同じ s では満足しなくなる
```

★★★ **＝ 一時の満足と、恒久の期待。⚠ 純効果はゼロかマイナス。**

⚠⚠ **「威信の罠」が機構として出る。**★ note が既に実例を名指ししている：
★ **ノイシュヴァンシュタイン城**（「バイエルン王家を破産させた**＝威信の罠の実例**」）／
★ **頤和園の再建**（「西太后が**海軍経費を流用**して再建」）。
⚠ **今は「金を食う」側だけが実装され、★ 得る側が空だった。**

★ **史実の裏づけ：**⚠ 1900年パリ万博の後、フランスは1889年の熱狂を再現できなかった（★ 「万博疲れ」は実在した）。

### ⚠ `MegaprojectPrestige` は撤去して威信へ移す（★ 作者裁定「威信と正統性は切り離す」）

| ★ | ⚠ 正統性 Legitimacy | ★ 威信 Prestige |
|---|---|---|
| ★ 何の | ⚠ **統治する権利**（体制の国内的な足場） | ★ **国の格**（国民の誇り） |
| ★ 失い方 | ⚠ 流血・約束破り | ★ 敗戦・格下げ |
| ★ 効き先 | ⚠ 政変の抵抗力（challenge vs coerce） | ★ **満足度** |

★★★ **切り離すと「威信は高いが正統性は低い」国が書ける。**
⚠ **第二帝政フランス**——★ クリミア・イタリアで勝ち威信は高いが、⚠ **クーデタ政権で正統性は低い**。★★ **セダンで威信が消えた瞬間に崩壊した。**
★ 逆も出る：⚠ **スイス・北欧＝正統性は高いが威信は無い。そして国民は威信を求めない**（★ r が低いから）。

## 1-8. ★★ ナポレオンの鎖② — **列強への上昇 → 国民意識**

★ 逆流（威信→NC）は**片方だけ**入れる。

| ★ 経路 | ⚠ 判定 |
|---|---|
| ★★ **s が閾値を超えた瞬間 → NC の一回加算** | ★★★ **入れる**＝⚠ **「ナポレオンの鎖②」**。★ **離散イベントなので閉路にならない**。⚠ **1871年の帝国宣言・1905年のポーツマス** |
| ⚠⚠ **屈辱（s−r が負）→ NC を煽る** | ⚠⚠⚠ **入れない** |

### ⚠⚠ 屈辱→NC を入れてはならない理由（★ ここは実装AIが「史実的だから」と足しがち）

★ 史実としては実在する（⚠ 1919年の独・1895年の臥薪嘗胆）。★★ **しかし発散する：**

```
⚠NC が上がる → ★満足への係数が大きくなる（掛け算）
             → ⚠s−r が負なので【さらに大きな負】
             → ★不満が増える → ⚠NC がさらに上がる …
```

★★★ **＝ 正のフィードバック。⚠ 止めるにはクランプが要り、思想⑧②（クランプ不可）に触れる。**★ **足さない。**

## 1-9. ★ 捨てた案（⚠ 再提案を防ぐための記録）

| ⚠ 案 | ★ 捨てた理由 |
|---|---|
