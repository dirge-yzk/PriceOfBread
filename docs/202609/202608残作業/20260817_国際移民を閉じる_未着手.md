# 3. ★★★ 直し方 — **器はそのまま、供給源だけ変える**

```
⚠現在：poolSize ＝ 世界人口 × 係数        ★湧く
★提案：poolSize ＝ Σ 各国の流出量          ⚠集める
              ↑★流出量は既存の EmigrationRate × 押し出し圧で決まる
```

★★ **配分側は一切変えずに済む**——⚠ `pull` 比例／土地逓減／住宅摩擦／差別（`DiscriminationLiteracy`）／
★ 民族の引力（`EthnicDraw`）／⚠ 識字の運搬（`ImmigrantLiteracyCarry`）／★ cap余剰の再配分。

# 4. ★★★ そして、設計がむしろ良くなる

⚠ **今は2つの経路が併存している：**

| ★ 経路 | ⚠ 中身 | ★ 問題 |
|---|---|---|
| ⚠ `MigrateInternational` | ★ プールから配る（⚠ **湧く**） | ⚠⚠ 保存則の例外 |
| ★ `MigrateBetweenNations` | ⚠ **1対1**で移す | ⚠ **多重排水の危険**（★ 「最良の1国だけ選ぶ」で回避中） |

★ **`MigrateBetweenNations` の対策コメント：**

```csharp
MultiNationSim.cs:1138
// ⚠全組判定だと1国が同時に多数へ毎四半期上限まで流出する多重排水
//   （★プロイセン技術0.38へ空洞化を実測）＝移民は最良の行き先を選ぶ
```

★★★ **プールに一本化すると、⚠ 両方の問題が同時に消える：**

```
★① 各国から流出量を集める     ⚠送出は1回だけ＝多重排水が【構造的に】起きない
★② プールを pull 比例で配る    ★既存の配分ロジックをそのまま使う
```

⚠ **「最良の行き先を1つだけ選ぶ」という工夫が不要になる＝★ 機構が1つ減る。**

# 5. ⚠⚠ 覚悟すべきこと

## ⚠ ① アメリカの人口が史実に届かなくなる可能性

★ **米は 1790年390万 → 1900年7600万（⚠ 約20倍）。**⚠ **自然増だけでは足りない。**
★★ **外部プールは、おそらくこれを埋めるために入れられた。**

⚠ **閉じると、★ 欧州から実際に抜く必要がある**——⚠ **史実でもアイルランドは人口が半減した。**

★ **安全弁は既にある：**

```csharp
⚠EmigrationFloorSize   ★「最後の住民は故郷を捨てない」＝流出の自己制限
⚠MigrationFarePerkKm   ★渡航運賃＝貧しすぎると出られない
```

## ⚠⚠ ② 帯が大きく動く

★ **人口は忠実度の主要次元に効く。**⚠ **段階移行と実測が必須。**
