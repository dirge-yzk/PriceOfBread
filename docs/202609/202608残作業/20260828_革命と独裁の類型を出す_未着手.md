## ★★★ 1. 最大の欠落 — ⚠ 兵士の【第三の道】

### ⚠ 1-1. 現物

```csharp
★Politics.SoldierForce
⚠f = Σ 兵士規模 × (0.2 + 兵士の闘争度)
★return f × MilitaryCoupWeight × (1 + WarExhaustionCoupBoost × 厭戦)
       // ⚠⚠「厭戦軍ほどクーデタ力が高い（★戦争崩壊型）」とコメントに明記

⚠Coercion（体制の保持力）＝ 兵数 × 即応度 × CoercionPerSoldier(5.0)
                            ↑★★闘争度を【読んでいない】
```

★★★ **＝ 兵士が怒っても、⚠⚠ 体制の保持力は落ちない。**
⚠ **出るのは「★ 軍が自分で権力を取る（軍事独裁）」道だけ。**

### ★ 1-2. 兵士には道が3つあるはず

```
⚠①体制を守る            ★Coercion       → ⚠有
★②自分で権力を取る       ⚠SoldierForce   → ★有（軍事独裁）
⚠⚠③革命側につく          ★★★【無い】
```

⚠ **史実では③が起きた：**

```
★露 1917  ⚠ペトログラード守備隊が発砲を拒み、⚠⚠労働者側へ
⚠独 1918  ★キール軍港の水兵反乱 → ⚠労働者評議会と合流
★仏 1871  ⚠国民軍が政府側から離反し、⚠⚠コミューンの武力になった
⚠洪 1919  ★赤軍が編成される
```

⚠⚠ **4型とも「軍事独裁」にはならなかった。⚠ 兵士は【労働者と合流した】。**

### ⚠ 1-3. 処方

```
★兵士の闘争度が高い → ⚠体制の保持力(Coercion)が【落ちる】
                     ⚠⚠かつ、★革命側の力(challenge)に【加わる】
```

⚠ **どちらへ行くかを決めるのは「⚠⚠ 兵士のイデオロギー」**（★ 既に per-POP で持っている）：

```
⚠兵士のイデオロギーが【現政体に近い】     → ★体制を守る
★兵士のイデオロギーが【ナショ/帝国】寄り  → ⚠自分で権力を取る（軍事独裁）
⚠兵士のイデオロギーが【社会/共産】寄り    → ⚠⚠革命側につく   ← ★これが無い
```

★★★ **＝ 新しい分岐ではなく、⚠ 既存の思想距離（`Ideologies.AffinityOf`）で連続に決まる。**

⚠ **そして「なぜ兵士が左傾するか」も既にある**——★ 兵士は徴兵で**農民・労働者から変換される**（`SoldierRecruitClassA/B`）。
⚠⚠ **元の階級のイデオロギーを持ってくる**（★ `MoveCohort` が運搬している）。

⚠ **＝ 総動員した国ほど、★ 軍が大衆のイデオロギーを帯びる。⚠⚠ これは史実そのもの。**

### ★ 1-4. これで 2026-08-27 の3本と繋がる

```
⚠『戦死者を時代で変える』  ★総力戦 → ⚠大量動員 → ★★軍が大衆化する
⚠⚠『内戦を戦争に一元化』   ★離反した兵士が反乱側の【領土と軍】になる
★『研究＝解禁の唯一の形』  ⚠軍事研究「総力戦」が動員の深さを決める
```

★★ **＝ 「⚠ 総力戦を戦った国ほど革命が起きる」が構造から出る。**⚠⚠ **1917/1918 の形。**

## ★ 3. 議会政治 → 一党独裁 4型の精査

    && ★平均満足度 < DominanceInstabilitySatisfaction(0.66))   ← ⚠危機ゲート
{
    ★maxSeat = max(保守, 自由, 社会)
    if (maxSeat > ⚠PartyDominanceThreshold(0.6))                ← ★一党支配

## ★★★ 4. F・G・H は **一つの機構**にまとまる

⚠ **ワイマール型もイタリア型も、★ 同じ形である：**

```
⚠①議会が過半数を作れるか（★思想距離で連立できるか）
   YES → ⚠第一党/連立が組閣（★現状と同じ）
   NO  → ⚠⚠【組閣不能】
          ↓
★②議会外の任命：⚠君主（立憲）／★大統領（共和）が指名
   ⚠候補 ＝ 議会の党 ＋ ★★議会外の派閥（FactionStrength）
   ★基準 ＝ 任命者の思想座標に近く、かつ強い
          ↓
⚠③任命された勢力が独裁化（★既存の DominanceCoupWeight 経路）
```

### ⚠ 4-1. ①組閣可能性 — ★ 既存の思想座標で書ける

```
★連立できる ＝ 思想距離が近い党同士（⚠Ideologies.AffinityOf）
⚠過半数を作れる組み合わせがあるか
⚠⚠無ければ【組閣不能】
```

⚠ **新しいデータを持たない。**★ **政党は既にイデオロギーのクラスタである**（⚠ `Parliament.cs:6`）。

### ★ 4-2. ②議会外の任命権 — ⚠ 既存の量で決まる

```
⚠任命者の裁量 ＝ 1 − ParliamentControl（★議会の統制力・既にある）
★立憲君主制  → ⚠君主が指名
⚠共和制      → ★大統領が指名（⚠⚠現物に大統領は無い＝要判定）
```

⚠ **`CrownParliament.cs` に `ParliamentControl` がある。**★ **統制力が低いほど議会外の裁量が大きい。**
⚠⚠ **＝ 既存の量がそのまま「⚠ 誰が首相を決めるか」を決める。**

### ⚠ 4-3. ③派閥の圧力 — ★ 候補に議会外を含める

```
⚠現物：候補 ＝ 議会の3党（or 動的政党）
★新  ：候補 ＝ 議会の党 ＋ ⚠⚠FactionStrength が閾値を超える派閥
                            ↑★ローマ進軍＝議会外の暴力が政権を作る
```

★★★ **＝ 「⚠ 民兵の圧力で王が任命した」が、⚠⚠ 派閥の強さから出る。**

### ★ 4-4. これで4型が揃う

| ⚠ 型 | ★ 経路 |
|---|---|

## ⚠ 9-6. 危機ゲートの連続化（★ 作者質問・2026-08-28）

### ★ 現在の3条件のうち、⚠ 1つは **既に傾斜**

```csharp
⚠domExcess = (maxSeat − 0.6) / 0.4
             ＝ ★Clamp((maxSeat − onset)/span, 0, 1) で onset=0.6・span=0.4
```

⚠⚠ **＝ 連続化は要らない。★ 必要なのは onset を下げることだけ**（⚠ 0.6 → 0.35 で **ワイマール型（NSDAP 37.3%）が射程に入る**）。

### ⚠ 政体の判定は `ParliamentControl` で置き換えられる

```
⚠共和 1.00 ／ ★立憲 0.65 ／ ⚠ブルジョア独裁 0.30 ／ ★プロ独裁 0.20 ／ ⚠軍事独裁 0.10
```

★★ **＝ 「議会がどれだけ実権を持つか」が既に連続量。**
⚠ **意味論的にも正しい**——★ 議会が実権を持つほど議会経由の独裁化が起こりうる。⚠⚠ **既に独裁の国では 0.1〜0.3 なので二重に独裁化しない。**

### ★ 満足度側だけが **本当の閾値**

```
⚠現在：満足度 < 0.66（★ステップ）
★新  ：Clamp((0.66 − 満足度) / span, 0, 1)
```

⚠ **上側は変わらない**——★ 英0.87・米0.90 は依然として **0**。⚠⚠ **「安定国を守る」性質は壊れない。**

### ★★ 最終形 — ⚠ 3つの連続量の **積**

```
★引力 += DominanceCoupWeight
       × ⚠議会の実権   （ParliamentControl・★既存）
       × ★危機の度合い （⚠Clamp((0.66 − 満足度)/span1, 0, 1)）
       × ⚠支配の度合い （★Clamp((maxSeat − onset)/span2, 0, 1)）
```

### ⚠⚠ なぜ noisy-or ではなく **積**か

⚠ **2026-08-28『悪い形の全数調査』§7 の裏側の原則：**

```
★【独立な理由】どれか一つで十分   → ⚠⚠noisy-or（★闘争度の入力）
⚠【必要条件】  全部揃わないと駄目 → ★★積      （⚠今回の3つ）
```

⚠ **議会がなければ議会経由の独裁は起きない。★ 危機がなければ起きない。⚠ 一党支配がなければ起きない。**
⚠⚠ **＝ 3つとも必要条件なので積が正しい。**
