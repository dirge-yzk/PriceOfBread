# 2. ⚠⚠⚠ 診断 — **富が簿価のままである**（★ 推定）

## ★ 労働者と資本家の非対称の正体

```
★労働者   賃金（フロー）が止まる → ⚠貯蓄が薄いので即座に飢える
★資本家   利潤（フロー）が止まる → ⚠貯蓄が厚いので何十年ももつ
```

⚠ **これだけなら「厚みの差」であって設計の誤りではない。**

## ⚠⚠ しかし決定的なのは、**工場が無価値になっても富が減らない**こと

```csharp
EconomyStep.cs:529（★8/14 断面）
budget = IndInvestmentFrac * Math.Max(0, Savings − IlliquidWealth);
```

★ **`IlliquidWealth` は `Savings` の内数**（⚠ 引いた残りが投資に回る流動分）。
★★ **つまり「工場に化けた富」を表す器は既にある。**

⚠⚠ **問題は、それが【投じた金額の累積＝簿価】で積まれている可能性が高いこと**（★ §7-1 要確認）。

```
★簿価なら：工場が倒産しても IlliquidWealth は減らない
           → Savings も減らない
           → ⚠⚠転落閾値を割らない
           → ★★★「恐慌で貯蓄が溶けると大量転落」が【空手形】になる
```

★★★ **既存コメントが約束している挙動が、⚠ 実際には起きていない可能性がある。**——★ **これが最も強い疑いである。**

# 3. ★★★ 処方 — **流動化**（⚠ 新しい機構はゼロ）

> ★ **作者裁定：「株式の材化などは不要で、⚠ 通貨以外の資本（金・銀・株式）を流動的にすれば十分か」**

## ★★★ 因果の順序 — 流動化が原因、時価は結果

> ★ **売れるものには値段がつく。⚠ 値段がつくから、値段が下がる。**
> ⚠⚠ **逆に言えば——売れないものには時価がない。★ だから簿価のまま残る。**

★★ **私は「時価評価」と呼んだが、⚠ 正確には【流動化】が先である。**

## ⚠⚠ 「材化」が誤りである理由

```csharp
MarketFlow.cs（★8/14 断面）
m.Price *= 1 + (PriceAdjustSpeed * gap + FlowAdjustSpeed * flow) / div * amp;
//                                ↑⚠在庫ギャップ
```

⚠⚠ **株式を財にすると、★ 株価が【在庫ギャップ】で決まってしまう。**
★★ **株価は期待利潤で決まるべきで、⚠ 需給の在庫では決まらない。**——★ **136財に足さないのが正解。**

## ⚠⚠⚠ 非対称は逆だった — 国営工場は既に流動的

```csharp
World.cs:1344  ★SellFactory ＝ 国営工場の民間売却（1棟ずつ）
World.cs:1334  ★UnitSalePrice ＝ 年間利益 × SoeSaleYears
```

★★★ **国が持つ工場は売れて、値段がついている。⚠ 資本家が持つ工場は売れない。**
⚠ **流動的でないのは【民間】のほうである。**

## ★ 時価の式は既にある

```csharp
World.cs:1334（★8/14 断面）
/// ★払い下げ1棟ぶんの買取価格＝年間利益 × Coefficients.SoeSaleYears ×（1棟／国営持分）
```

★★★ **`SoeSaleYears` は PER（株価収益率）そのものである。**
⚠ **国有工場の払い下げ価格＝株価。★ 同じ式で、同じ意味。**

## ★★ 変えるのは評価関数1つだけ

```
⚠現状（推定）：IlliquidWealth ＝ 投じた金額の累積（簿価）
★提案：       IlliquidWealth ＝ Σ 所有工場の【時価】
                                  ＝ Σ (SmoothedMargin ベースの年間利益 × SoeSaleYears × 持ち分)
```

★ **`SmoothedMargin` は既にEMA**（⚠ 一過性の赤字では潰れない＝平滑済み）——★ **株価の乱高下も自動的に抑えられる。**

## ★★★ そして「大量転落」が初めて真になる

```
⚠恐慌 → 利益↓ → 工場の時価↓ → IlliquidWealth↓ → Savings↓
       → ★転落閾値を割る → ⚠⚠上流→中流の大量転落（★既存機構が発火）
```

## ★★ 器は1つにできる（⚠ 金・銀は後から足せる）

```
⚠現状：Savings（★単一スカラー・⚠内数の IlliquidWealth）

★提案：Savings ＝ 現金 ＋ 【非通貨資本】
                            ↑★売買可能だから時価がつく
   ⚠内訳は「何を持っているか」の表
      工場持ち分 → ★時価 ＝ 年間利益 × PER（⚠UnitSalePrice が既存）
```

★★ **器（`IlliquidWealth`）は既にあるので、⚠ 中身の評価を差し替えるだけ。**

| ★ 案 | ⚠ 評価 |
|---|---|
