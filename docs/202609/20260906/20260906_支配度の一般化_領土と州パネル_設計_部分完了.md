# 支配度の一般化 — 州の内訳・領土・州パネル — 仕様（2026-09-06・作者採用）— 設計・未着手

## 0. 裁定（作者・2026-09-06 設計フォーク）
- **採用**：州の支配度を「誰の強制力と行政が及んでいるか」の4区分（合計1）に分け、円グラフで表示し、州に対する動詞をこれに合わせて作り直す。
- **教会は区分にしない**：教育は法、聖職者の取り分は特権で表せる（教皇領は「国家＝聖職者が支配階級」、ミッレトは在地権力）。
- **条約港は機構ごと廃止し、「外国」区分へ統一する**（設置・返還の動詞も廃止）。
- **追記裁定（同日・第2ラウンド）**：①支配度を 0..1 の連続量とし、**割譲・属国化・保護領・条約港・勢力圏を1つの量へ畳む**（§6b）。②`MaxDependents=8` を撤去し、維持費で自然に上限を出す（§6c）。③**植民地の現地協力者は在地権力区分へ統合**（§2b）。④**法の不可逆を撤去**し、後退を3層で表す（§13）。⑤戦争目的は**後回し**（講和の選択は戦後で良い＝現行の事後選択を残す）。
- **教育法の廃止（提供を連続量へ）＝保留**：費用対効果で不採用。代替の小改修（法の効果を数年で追従させる在庫化・2箇所）を P2 に置く。

## 1. 何を直すか
- 今の `Region.Dominance` は分離判定だけが読むスカラー（書き手1・読み手1・UIなし）。徴税・徴兵・公共財・法の到達は、行政力・課税同意・汚職漏れ・特権が**別々の倍率**で表しており、「その土地を誰が統治しているか」という共通の分母が無い。
- 19世紀は仲介者（領主・藩・氏族長・都市）を通した間接統治から、官僚による直接統治へ国家が版図の中身を奪い返した時代であり、清と英の財政能力の差（税収/GDP 2〜3% 対 10%超）はこの分母の差から出る。

## 2. 4区分（州ごと・合計1）
| 区分 | 定義 | 取り分の行き先 | 届くもの | 動かす量（既存量のみ） |
|---|---|---|---|---|
| 国家 | 官僚が直接に徴税・徴兵・裁く範囲 | 国庫 | 法の全部、教育・インフラ・保険 | ↑行政費/人口・道路/鉄道/電信の到達・識字・国民意識・駐留軍　↓敗戦・内戦（断裂の窓）・財政崩壊 |
| 在地権力 | 国家でも外国でもない土地の実力者（地主・領主・藩・氏族長・都市参事会・ミッレトの長・土司） | その州の保有階級（既定＝貴族。州データで 農民＝氏族／聖職者＝宗教共同体 を指定可） | 法は仲介者が選んだ分だけ（徴兵は村請け・学校は建たない）。劣化版の秩序（領主裁判） | ↓農奴解放・土地改革・官僚制度の専門化・直轄化の動詞　↑国家の財政崩壊・戦争 |
| 外国 | 条約港・租界・占領・保護領の宗主の強制力 | 外国の国庫と商人 | 自国の法は及ばない。外国のインフラは**届く** | ↑講和の通商特権・占領・不平等条約　↓自国の国力比の回復（旧・失効条件）・独立・講和での返還 |
| 無統治 | 誰の強制力も及ばない（山地・遊牧・盗賊圏・辺境） | 誰にも流れない | 何も届かない | ↓軍の投射・道路・入植　↑反乱・犯罪・戦災 |

### 2b. 現地協力者＝在地権力区分（統合・2026-09-06 追記）
植民地・従属の保持力は今、軍・即応度・距離・按分だけで決まり（`Colonial.cs:288-304`）、現地の誰の損得も入らない（外部レビュー(13)＝VALID）。**新機構は作らず、在地権力区分がこれを担う**。
- 植民地・属国の州の在地区分＝現地エリート（首長・地主・現地官僚・現地商人）の支配範囲。
- 協力の利益＝その州の在地区分から現地エリート pop へ流れる取り分（既存の `ColonialPayShare=0.3` を人口按分の定数から**在地区分×階級**へ置換＝削減方向）。
- 独立は「軍が足りない」だけでなく、**取り分が切れて在地区分が国家（宗主）側へ協力しなくなる**経路で起きる（インド大反乱＝改革が在地の取り分を脅かした／アルジェリアのカイド制）。
- 懐柔の器は既にある＝植民地参政権による分離圧力の減衰（`Politics.cs:1571-1582`・`SuffrageScopeGate=0` で休眠）。これを在地区分の取り分と同じ台帳に載せる。

**落とした区分**：教会（法と特権で表現済み）・徴税請負/名望家（特権 B2）・軍政（国家の一形態。統帥権の設計で必要なら「国家分のうち軍が握る割合」の属性を後で足す）。

## 3. 原則（法・特権と重ねない）
- 区分は**土台**、特権は土台の上の**流れ**、法は**規則**。領主権の取り分は在地区分の上で、身分制免税は国家区分の課税ベースの上で計算する（同じ現象を2回数えない）。
- 法は国家区分に全部、在地区分に一部（仲介者の選択）、外国・無統治には及ばない＝「法を変えても田舎まで届かない国」が法の値を変えずに出る。
- 既存の倍率（行政力の徴収効率・課税同意・汚職漏れ・分離の保持力）は、この区分から**導出**する形へ置換する（削減方向）。`Region.Dominance` は国家区分に吸収して一本化する。
- 4区分はストック。支配度ストックと同じ作法で積分し、タイマーを作らない。金の流れは pop→pop または pop→国庫の移転で書き、貨幣保存に触れない。

## 4. 動力学（案）
- 状態：`Region.Rule[4]`（国家・在地・外国・無統治、合計1・保存対象）。
- 毎四半期：各区分の目標値を既存量から作り、`DominanceSpeed` と同じ速度で寄せる（新しい速度定数を作らない）。
  - 国家の目標＝行政の到達（官僚 pop 比・行政費/人口）× 通信の到達（道路/鉄道/電信の州到達＝既存の輸送・鉄道・電信の量）× 国民意識（pop 属性）に、駐留軍の投射を加算。
  - 在地の目標＝特権台帳の領主権強度（`Privileges.Seigneurial` の保有年数）と農奴解放/土地改革/官僚制度法の段で決まる残高。
  - 外国の目標＝講和・占領で与えた通商特権の残高（§6）。自国の国力比（旧 `TreatyPortLapseRatio` の物差し）が上がるほど減る。
  - 無統治＝1−上3つ。軍の投射・道路・入植で減り、反乱・犯罪・戦災で増える。
- 初期値：`world.json` の州データ（`resources` と同じ一次データ）。無い州は 国家1.0＝現行と同じ挙動（恒等）。例＝清の中核州 国家0.6/在地0.35/無統治0.05、英 0.9/0.1、露 0.5/0.45/0.05、オスマン 0.5/0.4/0.1、植民地は在地（間接統治）＋無統治が主。

## 6. 条約港の廃止と外国区分への統合
今の条約港＝国単位の**個数**（講和で付与・関税自主権を港数×0.25で失う・国力比0.5で4年ごとに1港ずつ失効）。これを州ごとの外国区分へ置き換える。
| 今の要素 | 置換後 |
|---|---|
| 講和で条約港を与える（`TreatyPortReparationMult` の代替） | 講和で**敗者の港州**（勝者が選ぶ最大の港）の外国区分を上げる。通商特権の残高として記録 |
| `TreatyPortTariffLoss`（港数×0.25で実効関税が落ちる） | その州の貿易のうち外国区分の分は勝者の関税で決済＝実効関税は外国区分の加重平均で自然に落ちる（個数の式は撤去） |
| `TreatyPortLapse`（国力比≥0.5で4年ごとに1港） | 外国区分の目標値が国力比で下がる連続形（刻みも一斉検査も撤去＝タイマー撤去の方針と一致） |
| 条約港の設置・返還の動詞（AI・プレイヤー） | 廃止。開港は講和・最後通牒の帰結、返還は国力比の回復（関税自主権の回復1930＝日本・トルコ）として創発 |
| 条約港の失効の状態条件（2026-08-14 の「例外を作らない」型） | 同じ思想＝外国区分は持続条件（勝者の投射と貿易の存在）で残り、条件が消えると風化する |
| 貿易タブ・通知・News の条約港表示 | 州パネルの外国区分と地図モードへ移す |
撤去する係数＝`TreatyPortTariffLoss`・`TreatyPortLapseRatio`・`TreatyPortLapseYears`・`TreatyPortWinnerDistanceKm`（距離は講和の地理制約として外国区分の付与側に残す）。忠実度参照に条約港が入っていれば「外国区分>0の州数」へ物差しを移す。

## 6b. 領土の連続化 — 割譲・属国化・保護領・条約港を1つの量へ（2026-09-06 追記裁定）
**問い（作者）**「支配度も 0-1 にすれば、割譲とも連続化するか？」→ **できる。しかも動詞が1本になる。**

今は同じ「他国の支配が及ぶ」現象が4つの別機構になっている＝割譲（州の所有者を離散で移す）・属国化（国単位のフラグ）・条約港（国単位の個数）・植民地（別の型）。これを**州ごとの外国区分（誰の分かを持つ 0..1）**に統一する。

| 現象 | 統一後の表現 |
|---|---|
| 割譲・併合 | **講和で所有を移す離散イベント**（下の ⚠訂正 を見よ）。外国区分が高いほど要求できる量が増えるが、**自動では入れ替わらない** |
| 保護領・租界・条約港 | 外国区分が 0<x<本国区分（所有者は変わらない。港州だけなら条約港、全州に薄くなら保護領） |
| 属国・勢力圏 | 従属国の全州に宗主の外国区分が薄く乗る（`Dependency` のフラグは導出ラベルへ） |
| 植民地 | 在地区分＋宗主の外国区分（間接統治）／入植地は宗主の国家区分（直接統治）＝**同じ式で表せる** |
| 軍事占領（戦時） | 戦勝点の押し合いが前線を動かし、前線の後ろの外国区分が一時的に上がる。講和で確定するか戻る |

⚠**訂正（2026-09-06・作者指摘「実効支配と法的支配を同一量で管理するのは無理がある／2つに分けるのは過剰実装」）**
初版の「所有者＝最大シェアの導出」は**撤回する**。理由＝①占領は所有ではない（史実でも講和の署名まで所有は動かない）②導出にすると戦争中に所有が飛んで戻る＝**却下したはずの離散フリップが別の場所から戻ってくる**③忠実度の物差し（本国州・植民地州の一致率）が毎四半期揺れる。
**正しい形＝新しい量は1本だけ。所有は既にある。**
| | 型 | 誰が持っているか | いつ動くか |
|---|---|---|---|
| **支配度**（4区分） | **連続場**（新規・州ごとの配列1本） | 新規 | 毎四半期 |
| **所有** | **離散のポインタ** | **既存**（州は国のリストに入っている＝今のまま） | 講和・独立・建国のときだけ |
⚠したがって**二重管理ではない**（新しい量は1本で、所有は既存のものをそのまま使う）。「2つに分ける」ように見えたのは、私が所有を導出へ作り替えようとしたせいである。

**講和の形（戦争目的は後回しでよい理由）**：戦勝点が決めるのは「**移せる支配度の総量**」1つだけ。勝者は戦後にそれをどの州へどれだけ配るかを選ぶ＝**支配度だけ移せば**保護領・条約港・勢力圏、**支配度と所有を一緒に移せば**割譲、従属国の全州へ薄く撒けば属国化。⚠**所有を移すかどうかは講和の側のフラグ1つ**（州ごと）＝4つの別機構が「連続量1本＋フラグ1つ」に畳まれる。賠償は現行のまま（金は別の量）。事前の目的宣言は要らず、**選択は戦後**という作者裁定と一致する。
**利点**：①「侵略の1本化」の思想が領土にも通る ②属国化と割譲の断続が消える ③条約港の個数式・4年ごとの失効・距離の硬いゲートが全部消える ④AIの効用が「支配度の増分 ÷ 代価」の1本になる。
**注意**：忠実度の「本国州・植民地州の一致率」は所有者ラベルを読む。**所有者を導出に切り替えると基線が動く**ので、段5は単独計測・基線の取り直しが要る。

## 6d. 外国区分を「誰の」ベクトルにする（作者提案 2026-09-07・実装側の評価＝採用推奨）
**問い（作者）**「支配度が複数国になった場合、属国機構が廃止できる他、独立間際のエジプトなども表現できるのではないか」→ **できる。§6b の統一が1段深くなる。**

- **形**＝外国区分を1つのスカラーでなく**主体つきの持分**（(国ID, 持分) の小さな配列・合計は外国区分）にする。国家・在地・無統治は今のまま。
- **導出ラベル**（すべて式でなく読み出し）：
  - 所有者＝州で最大の持分を持つ主体（国家 vs 各外国）。外国の持分が国家を上回れば割譲（§6b）。
  - **宗主／属国**＝ある国の全州に同じ外国の持分が薄く乗っている状態。`Dependency` の表・`InDependency`（読み手8箇所・Diplomacy 内の参照38）は**この読み出しへ置換して撤去**。離反＝持分の風化（宗主の投射と貿易が持続条件＝vassal2 と同じ物理）。
  - **勢力圏**＝複数の外国の小さな持分が競合している状態（同じ州に英仏の持分＝ファショダ型）。
  - **共同統治**＝2つの外国の持分が並ぶ（英埃スーダン）。
  - **独立間際のエジプト**＝カイロ（オスマンの州・文化アラブ）で**在地（ムハンマド・アリー朝）が国家（オスマン）を上回り**、1882年以降は英の持分が乗る＝「自治」（在地>国家）→「保護領」（外国>国家・所有者は変わらず）→ 独立（在地が国家を上回った状態が持続し、在地権力を国家とする新しい国が建つ）。**分離独立（E-06 の Dominance）もこの読み出しに畳める**（在地>国家＝支配度0と同じ意味）。
- **利点**＝属国・保護領・条約港・割譲・勢力圏・共同統治・自治・独立が**1つの量の読み出し**になり、外交の動詞は「持分の増減」1本（AI の効用＝持分の増分÷代価）。史実参照の従属41件（宗主の一致＝exact）もそのまま読める。
- **罠**＝①セーブ形式（主体つき配列＝int[]+double[] の2本で持つ・辞書は使わない）②`Dependency` の読み手38箇所の一斉置換は段8で1回（半端に残すと二重計上）③在地が国家を上回った瞬間に国を建てると振動する＝**持続条件**（世代長 DominanceMatureYears の積分）で建国＝タイマーを作らない ④忠実度の本国/植民地/従属の物差しは所有者ラベルを読む＝段8は単独計測・基線の取り直し。
- **段の割り当て**＝段1（今の器）は外国区分をスカラーのまま置く。主体つきの配列へは**段5（条約港の外国区分化）で切り替える**（外国の持分が初めて意味を持つ段）。段8で `Dependency`・`MaxDependents`・E-06 の Dominance を読み出しへ畳む。

## 6c. 属国上限の撤去（`MaxDependents=8`）
`Coefficients.cs:1384` の硬い定数（侵略の硬性ゲートと講和の宗主権継承の2箇所が読む）は撤去する。上限は**維持費**から自然に出す＝外国区分を保つ費用（行政費×距離×投射の不足）が財政を超えたら区分が落ちる。離反判定 `hold = LandPower×Projection×VassalHoldScale` が既に軍事×距離を担っているので、**維持費は財政側だけに置き二重計上しない**。副次バグも同時に消える＝今の上限は標的が抽象勢力（実際には植民地接収になる）でも侵略を止めている（`World.cs:1675`）。

## 13. 法の後退（不可逆の撤去・2026-09-06 追記裁定）
`Government.cs:546-570` の `BlockedByIrreversibility` は bool のハード禁止で、参政権・女性の権利・社会保障は完全不可逆、労働時間・児童労働は戦争中のみ可。既存の政治コスト機構（`MandateMargin`/`MandateGate`）は**前進方向にしか接続されていない**（不可逆判定が先に return するのでコストに到達しない）。史実は制定→制限→停止→復活を繰り返す（1850年5月31日法で仏の有権者3割剥奪／1878年独の社会主義者鎮圧法／1907年露の選挙法改悪／米南部の選挙権剥奪）。

**後退は3層で表す。新しいゲートも動詞も作らない。**
| 層 | 何が起きるか | 実装 | 史実 |
|---|---|---|---|
| ①法そのものが戻る | 後退も前進と同じ**純支持ゲート**を通る。通れば戻る | bool 禁止を撤去し `MandateGate` へ流す。後退側は既得層の闘争度が跳ねる＝**特権剥離と同じ式**（`PrivilegeStripMilitancy`）を共有し、別の式を作らない | 1850年5月31日法・1907年6月3日 |
| ②法は残るが実効が戻る | 中央が通した法が在地区分・外国区分の範囲に届かない | §3 の「法は国家区分に全部、在地区分に一部」がそのまま担う＝**支配度の統合で自動的に出る** | 米南部の Jim Crow（憲法修正15条はあるのに在地権力が無効化） |

**誰が戻すのか（プレイヤーの動機の問題）**
- **要求経路が既にある**：`Politics.ApplyDemand` の `StepEnumAxis` は `LawPrereq` しか見ず `BlockedByIrreversibility` を呼ばない＝**旧支配層の要求経由では今も後退が通る**（202608残作業 08-4 が「穴」と記録）。これを穴でなく**正規の経路**にする＝後退を要求する主体は特権階級・軍・王権・在地権力（PowerShares と特権台帳が既に持っている）。
- **プレイヤーの利益は既に engine にある**：参政権を狭める＝闘争度の高い層を政治から締め出し特権階級の純支持を得る（革命の引力が下がる）／社会保障を削る＝財政が浮く／労働時間を戻す＝産出が上がる。**禁止されているから使えないだけ**で、禁止を外せば動機は自動的に立つ。したがって「戻す動機」のために新機構を足す必要はない。
- **強制的な後退**：断裂の窓（クーデタ・内戦制圧・敗戦＝既存 `RuptureWindowQuarters`）では純支持ゲートが緩む。ここは既存のまま。

**器**：`IrreversibleLaws`（現行1.0）を 0..1 の連続へ＝1.0 で現行（禁止）、0 で「純支持と怒りだけ」。中間は後退時のコスト倍率。段階点火できる。

## 14. 投射の起点を「支配下の州」へ（海軍基地網・2026-09-06 追記裁定）
**作者の条件**：「港レベルは作りたくない。ボトルネックを探す作業も、州に立てて回る作業も面倒（鉄道と同じ）。要るなら工場同様に自動でサイズが変わる形。それなら最初から不要か？」→ **不要。新しい建物も新しい状態も作らずに解ける。**

### 14-1. 根
`Diplomacy.Projection`（`Diplomacy.cs:3057-3068`）の距離の起点は **`xw.Latitude, xw.Longitude`＝首都の座標1点**。
```
km    = Geo.SeaDistanceKm(首都 → 目標, スエズ/パナマの開閉)
decay = 1 / (1 + DistanceWarDecay × km / DistanceNormKm)
```
したがって**ジブラルタル・マルタ・アデン・シンガポール・香港を持っていても射程が1kmも伸びない**。英がインドへ力を投射できたのはまさにその鎖があったからで、逆に遠方の港を失っても現状は何も起きない。

### 14-2. 形＝起点を「首都」から「実効支配している州の集合」へ
```
起点集合 S = { 自国および従属国の州 p | 国家区分(p) ≧ ProjectionRuleMin }
km = min over p in S of ( 港州なら 海路距離(p → 目標) ／ 陸続きなら 陸路距離(p → 目標) )
```
- **新しいデータも建物も動詞も作らない**。州も港も既にあり、どの州をどれだけ支配しているかは支配度（§2）が持っている。
- **支配度が効く**＝在地権力が強い州は基地にならない（オスマンの紅海沿岸がイスタンブルの投射を伸ばさない、という史実の形）。港レベルの代わりに**支配の実効性**が容量の役をする。
- **首都は集合の1要素**に落ちる。`ProjectionRuleMin = 1.1`（到達不能な値）で **S = {首都} ＝現行と厳密恒等**＝この1本で段階点火できる。
- **陸路も同時に直る**。今の投射は陸続きでも海路距離しか見ない（露の中央アジア・シベリアが海を回る）。起点集合を陸路グラフでも引けば、鉄道の延伸がそのままシベリアへの投射になる。

### 14-3. 「サイズ」は要らない（作者の問いへの答え）
- 二値（支配している港が近くにあるか）で史実の信号のほぼ全部が乗る＝ジブラルタル/マルタ/アデン/シンガポール/香港の鎖、露の不凍港問題、米のハワイ・フィリピン。
- それでもサイズが要ると分かった場合に備えて **器は既にある**＝`Region.PortCapacity`（`Model.cs:338`）は国家と資本家の投資で**自動的に増減する**（`MultiNationSim.cs:1246` で投資に比例して増え、`:1227` で `PortDecay` で減る）。**プレイヤーが港を建てて回る作業は元から無い。**
- したがって「まず二値で測る」→ 足りなければ `ProjectionPortWeight`（既定0＝二値）で `PortCapacity` を重みに掛ける、の2段。**最初から不要**という作者の見立てが正しく、器だけ残す。

### 14-4. リスク
- `Projection` は**戦争・割譲圏・属国の保持・植民地の保持・調停の可否が全部読む**単一関数＝1腕で全次元が動く。**単独計測**。
- 海洋帝国の保持力が上がる＝植民地の独立が減る方向。植民地の忠実度（25.8%）が下がりうる＝**同じバッチで植民地の帯を必ず見る**。
- 英は今49位に沈む側なので投射の強化は列強再現に効く見込み。ただし**英が沈む根（内戦分裂・Militarize 固着）を先に潰す**（§12 の順序）。

### 14-5. 段
| 段 | 内容 | 器 | 恒等 |
|---|---|---|---|
| 14a | 起点集合を海路で（港州のみ） | `ProjectionRuleMin=1.1` | S={首都}＝厳密恒等 |
| 14b | 陸路の起点も加える（min(海,陸)） | `ProjectionUsesLand=0` | 0で海路のみ＝現行 |
| 14c | 港の容量を重みに（必要と分かったときだけ） | `ProjectionPortWeight=0` | 0で二値＝14a と同値 |

**実装状況（2026-09-07）**＝14a・14b の器を実装（`Diplomacy.Projection`＝`ProjectionRuleMin<=1.0` のとき自国と従属国（`OriginNations`）の州のうち `Rule[0]>=ProjectionRuleMin` の港州を `Climate.CityCoord` の座標から海路距離で起点に加える。`ProjectionUsesLand>0` で非港州も `PathGraph.LandDistanceKm` の陸路で起点。既定 1.1/0 で集合={首都}＝厳密恒等・ビルド緑・番人緑）。制海権の乗数（IsSeaCrossing）は首都基準のまま＝起点だけ動かす。14c は係数を置かない（読み手の無い係数＝B14型の死係数を作らない・必要と分かった時に足す）。**単独計測は英の沈む根（§12）の後**。

## 15. 平時の植民地徴兵に遺恨を付ける（2026-09-06 追記裁定）
`Military.cs:191-193`：`wartimeConscript`（法≧選抜 or 総動員）のときだけ `DrawFromPool(..., conscription: true)` に真を渡す＝**平時の常備軍は誰からも恨まれない**。英印軍・セネガル狙撃兵は**平時の常備軍**であり、現地の不満（血税）はそこで発生した。
- 形＝`PeacetimeConscriptGrievance > 0` のとき、平時の徴募でも植民地格・在地区分の大きい州から引いた分だけ遺恨を積む（`DrawFromPool` の既存の引数を使う＝新しい経路を作らない）。
- 既定0で厳密恒等。S。
- ⚠これは「植民地軍が無い」の是正ではない（徴募ループは既に格を読まず、植民地popは徴兵されている）。**「植民地軍が本国軍と同じ規則で徴られる」の是正**である。
- **実装状況（2026-09-07）**＝器を実装（`Military.cs`＝平時の徴募で `r.Tier==Colonial` または `Rule[1]>Rule[0]` の州から引いた分に `ConscriptGrievanceRate×PeacetimeConscriptGrievance` の遺恨。`DrawFromPool` に倍率引数を1つ足しただけ＝新経路なし。既定0＝厳密恒等・番人緑）。計測＝実バグ第3波の群の後に単独 batch4。

## 16. 支配度の塗り分けと国色（2026-09-06・作者案への設計回答）
**作者案**：「州の支配度で塗り分けを変える。50%ずつなら2国の色を50%ずつ混ぜる。支配度の漏れは黒で表現し、支配が届かない州の周囲は黒くなる。合わせて国家カラーをより明るくする必要があるか？」

### 16-1. 採用。ただし**色のチャネルが1つ足りない**
4区分あるのに、案では色相（混色）と明度（黒）の2つしか使っていない。**在地権力の受け皿が無い**。3チャネルを3つの意味に1対1で割り当てる。

| 意味 | 視覚チャネル | 見え方 | なぜそれか |
|---|---|---|---|
| **誰のものか**（国家・外国） | **前線＝距離場の等値線**（州の外側から食われる・§16-4-6）＋**法的国境＝既存の所有の境界** | 2本の線の間の帯＝占領地。⚠**量は1本・パスも1回** | 混色は灰色に潰れ（16-4-1）、網目は差分を伝えず（16-4-2）、州の色替えは州数が少ないと飛ぶ（16-4-3） |
| **国家が届いているか**（在地権力） | **彩度＝色あせ** | 旗はあるが薄い | 名目上は自国、実質は領主・氏族長 |
| **誰のものでもないか**（無統治） | **透過＝地の色が出る**（＋軽い暗化） | 辺境が地形に還る | 国家が無い＝ただの土地 |

### 16-2. 「黒」は**地の色への透過＋軽い暗化**に変えることを推奨
**理由**：純黒は明度チャネルを占有する。すると明度が国の識別に使えなくなり、**61色パレットの全面作り直し（等明度化）が要る**。実測でその代償は大きい。
- 現行の主要国は **L 幅 0.377〜0.862（差0.485）＝明度が国の識別子として使われている**（日本 L=0.40・マダガスカル L=0.38 が暗く、オーストリア L=0.86・清 L=0.83 が明るい）。
- 全国を L=0.74 に揃えると、**色相の衝突が11組**露わになる＝清と教皇領とオーストリアが1度差（3国とも黄）、アメリカとプロイセンとフランスが1度差（3国とも青）、ネーデルラントと阮氏が1度差。
- 一方、**地の色への透過は既に実装済み**（`MapFill.cs:176` の `FillAlpha × Seed.Weight`・支配度モードで `Rule[0]` を重みにしている）。意味的にも正しく、追加コストがほぼ無い。
- ⚠純黒は**海・地図の外・国境線**とも衝突しやすい（州の輪郭が消える）。暗化を入れるなら **L の下げ幅は最大0.25程度**に留める。

### 16-3. 国色を明るくする必要があるか＝**一律の明るさは不要。必要なのは彩度の下限と、隣接2組の是正**
| 論点 | 判定 |
|---|---|
| 一律に明るくする | **不要**（16-2 で明度チャネルを空けないので、明度は国の識別に残せる） |
| **彩度の下限 C ≥ 0.10** | **必要**。在地権力で彩度を落とすので下げ代が要る。オーストリア C=0.030・プロイセン C=0.054・阮氏 C=0.077 は**色あせた瞬間に灰色**になり隣と混ざる |
| 全61色の作り直し | **不要**。隣接だけ違えばよい（四色定理の実務版）。隣接グラフは `PathGraph` の陸の辺で既に持っている＝彩色は自動計算できる |
| **既に見分けにくい隣接2組** | **要是正**。欧州の隣接38組を Oklab で実測＝**ライン諸邦↔バイエルン ΔE=0.062／フランス↔プロイセン ΔE=0.085**（どちらも ΔE<0.10＝ほぼ同色）。**支配度の濃淡を入れる前から見分けにくく、濃淡が入るとさらに縮む**。ここだけ先に直す。次点（ΔE<0.15）＝オスマン↔ロシア0.104・スイス↔サルデーニャ0.123・サルデーニャ↔トスカーナ0.132・ライン諸邦↔スイス0.139 |

### 16-4. 混色も網目も使わない — **塗り＝実効支配者／縁＝法的所有者／変化＝一時の強調**（2026-09-06・作者指摘「傾斜は見やすくない。EU4でどこを占領したか分からなくなった」）

#### 16-4-1. まず混色が壊れることの実測（記録）
現行の主要10カ国の全組み合わせを Oklab で平均した結果：

| 混ぜる色数 | 平均の彩度 C | 最悪の例 |
|---|---|---|
| 単色（比較） | 0.125 | — |
| **2色** | **0.083**（−33%） | **仏×西 → `#7E7F7E`（C=0.001＝完全な灰色）**／普×墺 → `#888F96`（C=0.013） |
| 3色 | 0.063 | 仏×墺×西 → `#9B9992` |
| 4色 | 0.052 | 仏×露×普×蘭 → `#656867` |

⚠**最悪のペアが補色でなく「隣接国どうし」**なのが決定的。隣接国は見分けるために色相を離してあるので混ぜると打ち消し合う。占領も条約港も属国も隣接国どうしで起きる＝**混色は最も使われる場面で最も壊れる**。→ 混色は却下。

#### 16-4-2. 網目も却下する理由（作者の EU4 体験の分析）
「露でオスマンに攻め入ってどこを占領したか分からなくなった」は縞の設計上の必然である。
1. **縞は絶対状態しか伝えない**。プレイヤーが知りたいのは「**自分が何を取ったか**」＝**差分**。長い戦争では地図全体が縞になり、今回の戦果が埋もれる。
2. **縞は自色の面積を半分にする**。遠目には結局「混色に近い見え」に戻る＝混色の問題が解けていない。
3. **縞は州の輪郭と干渉する**。小さい州が密集する地域（バルカン・独領邦・北イタリア）で最悪になる。
4. ⚠**そもそも EU4 が縞を必要とした前提が本作には無い**。EU4 の占領は法的所有と別の一時状態だから両方を同時に描く必要があった。**本作の支配度は実効支配そのもの**（税も徴兵も公共財もそちらへ流れる）＝「誰が握っているか」は**1つの答え**で足りる。

#### 16-4-3. 州の色を切り替えるのも却下（作者指摘「パラド式すぎる。州数の少ない本作には向かない」）
**指摘が正しい。** 塗りを「最大シェアの国」にするのは**離散フリップ**＝Paradox の表現であり、1000州あるゲームの前提に立っている。本作は302州で仏7州・英5州＝**1州が色を変えると国土の7分の1が飛ぶ**。「前線が100km動いた」が「フランスが7分の1を失った」に見える。
⚠さらに悪いことに、これは**§6b で自分が設計した連続占領を捨てている**。§6b は「戦勝点の押し合いが前線を動かし、前線の後ろの外国区分が上がる」＝**占領は連続量**と決めた。それを描画で離散に戻したら設計の利点が消える。

#### 16-4-4. 前線を州の中に通す（初版＝重み付きボロノイ・**16-4-6 でより安い形に置き換えた**）
塗りは既に**種（州の代表都市）からの距離場**で作っている（`MapFill.BuildCore` の多始点ダイクストラ）。**外国に食われている州の種を弱くする**だけで、境界が州の中へ押し込まれる。

```
押しの強さ  push(P) = 1 / (1 − 他国の外国区分(P) + ε)
距離の加算   nd = dc + step × push[owner[c]]      ← Relax の引数に掛け算1つ
```
- 外国区分0.5の州は種が**半分の強さ**でしか押せない → 隣（＝占領者）の色が州の中ほどまで入る。
- 外国区分1.0で州は完全に相手の色になる（＝離散フリップは**連続の極限**として自然に含まれる）。
- ⚠**在地権力と無統治では種を弱くしない**（それらは彩度と透過が担当・§16-1）。領土を削るのは**他国の支配**だけ。
- 弱った種は自国の隣州にも押し負けるが**同じ色なので無害**（自己補正）。
- 海からの上陸など隣接種を持たない占領は、占領者の**仮想種**をその州に置き重み ∝ シェア（第2段）。

#### 16-4-5. 2本の線は**2つの量ではない**（作者指摘「2つに分けるのは過剰実装」への答え）
描くのは2本だが、**持っている量は1本**である。
- **法的国境**＝**既存の所有ポインタ**の境界。今そのまま描いているもの（`MapFill.cs:182-196`）。追加コスト**ゼロ**。
- **前線**＝**新しい支配度**の等値線。これが唯一の新規。
⚠「実効支配と法的支配を別々に管理する」のではなく、**所有は元からある・支配度だけが新しい**。§6b の訂正と同じ話である。

#### 16-4-6. 実装は**1パスで済む**（2回焼かない）
重み付きボロノイ（16-4-4）は距離場をもう1回焼く必要があったが、**その必要は無い**。既存の1パスが吐く `dist[]`（種からの距離）と `owner[]`（どの種の領域か）だけで前線が引ける。

```
州 P の外国区分が f のとき：
  P の画素の dist の分布から (1−f) 分位点 θ を取る
  dist[c] > θ の画素 ＝ 占領されている側（占領者の色）
  dist[c] ≤ θ の画素 ＝ まだ握っている側（自国の色）
```
- **占領は「州の外側から食われる」＝都市から遠い所から落ちる**。史実の形（城市は最後に落ちる・包囲戦）と一致し、しかも**それが無料で出る**。
- 分位点は既存の**バケツ**（ダイクストラが整数距離でバケツを使っている）をそのまま数えれば取れる＝**ヒストグラム1本**。追加の探索は無い。
- f=0 なら θ=∞ で1画素も変わらない＝**平時は完全に現行と同じ**（厳密恒等）。
- f=1 で州全体が相手の色＝離散フリップは連続の極限として含まれる。

⚠これで **16-4-4 の「種の重みを弱める」も不要**になる（そちらは全方位に効いてしまう弱点もあった）。**距離場は今のまま1回・前線は等値線・法的国境は既存**＝新しく足すのはヒストグラムと閾値だけ。

#### 16-4-7. 見え方
戦争が進むと**敵の色が州の外周から都市へ向かって食い込む**。法的国境は動かないので、「自分の色が国境を越えて相手の州に入り込み、相手の都市を包囲していく」形になる。講和で所有が移れば法的国境が前線に追いつく。⚠**縞も混色も州の色替えも無い。**

#### 16-4-8. 残る限界（承知の上で捨てるもの）
- 3勢力以上が同じ州を分け合う状態は、最大の1つだけが食い込む。内訳は**州パネルの円グラフ**で見る。
- 食い込みの形は代表都市からの距離で決まるので、峠や河川に沿わない。沿わせたければ距離場の歩幅に地形コストを入れる（`TerrainCostEnabled` が既にある・第3段）。
- 海からの上陸は「外側から」と一致するので特別扱い不要。⚠内陸から包囲されたのに海側が残る形にはならない（そこまでの精度は捨てる）。

### 16-5. 変調は非線形に（1783年が読めなくならないように）
1783年は国家区分が薄く在地権力が厚い＝**地図全体が淡くなる**。それ自体は正しい（**131年かけて地図が色づいていく＝国家形成そのものが絵になる**＝この案の最大の価値）が、開始盤面が読めないと困る。
```
彩度の低下 ∝ 在地権力^1.5     // 小さい在地は無視し、大きいものだけ効かせる
透過の増加 ∝ 無統治^1.5       // 同上
明度の低下 ≤ 0.25             // 上限を切る（国境線と海を残す）
```
