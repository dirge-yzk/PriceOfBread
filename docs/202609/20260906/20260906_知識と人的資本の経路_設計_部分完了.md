## 0. 裁定（作者・2026-09-06 設計フォーク）
外部レビューの現物照合（一覧 §0-3）で採用となった3件をまとめる。
- **R6 識字の一極集中を解く**＝「識字率と専門人材率を分離するのは有用か」→ **有用**。採用（「いい感じにしてください」）。
- **R7 教師の質と学校密度**＝採用（「いい感じにする」）。

## 1. 根＝1つの変数が全部を説明している
`TechEducation.cs:123` の1行がすべての起点である。
```
w.Elite = EmergentElite(w) ?? AvgLiteracy(w) × EliteMultiplier(EducationLaw)
w.TechPower = w.Elite
```
`EmergentElite` は「教育の産出のうち世俗教師が担った比率 × 平均識字」＝**広さ1本**。ここから伸びる入口は実測14箇所（技術の採用・革新・外資の headroom・私的建設・昇格ゲート・職探し効率・政治意識・出生率・新聞需要・同化抵抗・移民差別・国民形成・大量消費・吸収）。しかも `AbsorptionOf`（`TechEducation.cs:145`）は**技術の吸収と資本の吸収で同一の写像を共有**している（`CapitalMarket.cs:85`・`EconomyStep.cs:620,675`）。

**史実の反例**：露は識字2割でもメンデレーエフとロバチェフスキーを出した（厚みはあるが広さが無い）。米は識字が高くても1900年まで基礎科学は弱い（広さはあるが厚みが無い）。日本は識字の広さの上へ高等教育を短期間で接続した。**この3型は1変数では書き分けられない。**

なお、レビューが求めた4分割のうち**行政の脚**（`AbsorptionAdminWeight=0.5`）と**報道の脚**（`PressFactor`・新聞財）は既に独立して live である。欠けているのは**厚み**と**接触**の2本。

## 2. R6 — 識字（広さ）と専門人材（厚み）の分離

### 2-1. 用語
| 概念 | engine | UI 表記 | 意味 |
|---|---|---|---|
| 広さ | `w.Elite`（現行のまま） | **識字率** | 読み書きできる層の厚みと世俗水路。コピーの担い手 |
| 厚み | **`w.Expertise`（新設）** | **専門人材率** | 高等教育を修めた層。革新の担い手 |
⚠「エリート」は権力の取り分（`PowerShares`）と紛れるので UI には出さない。表示は「識字率」と「専門人材率」の2語だけ（漢字1字の略称は使わない）。

### 2-2. 厚みの定義（新しい状態を作らない）
既存の pop 属性 `Pop.HigherEduFill`（`Model.cs:172`・書き手は `EconomyStep.cs:1381/1432`）を人口加重で集計するだけ。
```
Expertise = Σ(近代エリート層 pop の HigherEduFill × Size) / Σ(全 pop の Size)
```
新しいストックは持たない（`World.cs:1508` の「新しいスカラーは置かない」規律と同じ）。

### 2-3. 使い分け＝採用は広さ、革新は厚み
| 経路 | 現行 | 変更後 |
|---|---|---|
| 技術の**採用**（コピー・後追い） | 吸収 = 広さ × 報道 × 所得 × 行政 | 同じ式の広さの項を `広さ^(1−a) × 厚み^a`（a=`AdoptExpertiseWeight`）へ。**a は小さい**＝読める職工がいればコピーはできる |
| **革新**（先端の押し上げ） | 同じ吸収を流用 | 厚みの重み `InnovateExpertiseWeight` を大きく取る＝**大学が無ければ先端は押せない** |
| 昇格（技師・研究者） | `PromotionGateHigherEdu=0`（休眠） | そのまま点火して使う（新規実装なし） |
両係数とも**既定0で現行と厳密恒等**（`広さ^1 × 厚み^0` ＝ 広さ）。

### 2-4. 点火の順序（ここを間違えると何も動かない）
`HigherEduNeedPerEducated = 0.0`（`Coefficients.cs:174`）＝**高等教育の需要がゼロ**なので、今 `HigherEduFill` はどの国でもほぼ0のまま。したがって厚みを混ぜる前に**需要を立てる**必要がある。
```
段A：HigherEduNeedPerEducated を点火（大学の需要が立つ→市場→Fill が動く）
段B：Expertise の集計（観測のみ・誰も読まない）
段C：AdoptExpertiseWeight / InnovateExpertiseWeight を点火
段D：PromotionGateHigherEdu を点火（昇格の資格）
```
8月の設計 doc が言う「大学が先」はこの順序のことである。順序を守らないと段Cは全国 Expertise≈0 で吸収を一律に潰す。

### 2-5. 実装で分かった前提（2026-09-07）
- 大学の生産者は **`ResearcherFrac>0`** のときだけ構築時に足される（8月doc「大学が先」の実体）＝段2の腕は `ResearcherFrac=0.05;HigherEduNeedPerEducated=0.05`。
- 需要式は `k×前月の就学×識字×人数` だと既に識字の高い英仏普のエリート（学校を買わない）の需要が0になり清・日だけに大学が立った＝**識字のストックでも数える**（max(前月の就学, 識字)）へ是正。
- 是正後は西欧にも専門人材率が立つ（英1798＝0.012）が、**英仏の大学は書籍の在庫0で止まる**（ロンドン書籍価格3.65・パリ11.9）。段2の実効は書籍（紙→印刷）の供給に律速＝受け入れ判定の前に書籍の鎖の診断が要る。
- 器＝段1 `Expertise`（導出）／段3 `AdoptExpertiseWeight`・`InnovateExpertiseWeight`（厚み＝世界先端比）／段5 `TeacherQualityWeight`／段7 `EduFundingCashClamp`／段8 `CatchupContactWeight`（接触度＝貿易の強度÷世界）＝実装済み・既定0。計器 `knowprobe`。

## 3. R7 — 教師の質と学校密度

### 3-1. 質＝法の2値から連続へ
現行は `Simulation.cs:1812/1820` で `ep.Productivity` に定数を代入するだけ＝**宗教学校2.0／公教育5.0の2値**。教師pop自身の識字も高等教育も一切入らない（役務は `EconomyStep.cs:442` の baumol 扱いで技術・工業化の倍率を全部外している）。
```
ep.Productivity = 定数 × (1 + TeacherQualityWeight × (教師popの識字 × 教師popのHigherEduFill − 1))
```
`TeacherQualityWeight = 0` で ×1.0＝厳密恒等。**師範学校の効果**（教師を育てると教育の生産性が上がる）がこれ1本で出る。R6 段A で高等教育の需要が立った後に効く＝順序は R6 の後。

### 3-2. 密度＝別機構を作らず支配度に比例させる
`ServiceRank`（`EconomyStep.cs:2473`）は農民も工場労働者も同じランクで比例配給し、`LaborSupply.cs:17` の `HasSchool` は市場配列長の判定＝**事実上の恒真**で「学校の無い村」を表現できない。
- **支配度の一般化 doc §5 の「公共財の到達＝国家区分に比例」がそのまま学校密度である**。教育役務の配給量にその州の国家区分を掛ける。
- 州内の都市/農村差は既存の `IsUrban` で `ServiceRank` を分ける（都市の学校が先に埋まる）。
- ⚠**新しい距離・校舎・通学の量は作らない**。密度は「国家区分 × 都市化」で足りる。

### 3-3. 実バグ＝教育だけ国庫の現金クランプが抜けている
軍事費（`Simulation.cs:1760`）も行政費（`:1830`）も `StateBudgetCashScale()` を掛けるのに、`CompulsoryEduFunding`（`Simulation.cs:1805-1806`）だけ掛かっていない＝**在庫がある限り国庫残高を無視して買え、赤字は事後精算**。1行を掛けるだけで直る（S）。⚠ただし較正は動く（貧しい国の識字が下がる）＝単独計測。

## 4. R8 — 後追いに「接触」の脚を足す

### 4-1. 根
`TechEducation.cs:151-168`：
```
adoptionCeil   = Max(AdoptionCeiling(0.5), WorldTechLevel × catchFrac)
catchFrac      = CatchupFraction(0.5) + (CatchupFractionAdvanced(0.97) − 0.5) × 吸収
```
`catchFrac`・`adoptRate` の入力は吸収（識字×報道×所得×行政）だけで、**貿易相手・港・接触の有無を1つも読まない＝鎖国国でも同じ速度で先端に追いつく**。

### 4-2. 史実
徳川日本と李朝は開国まで追いつかず、開国後に急加速した。清も条約港の周辺から工業化が始まった。**技術は人の往来と物の流れに乗って動く。**「アジアの過近代化」「世界工場」の根の1本がここである。

### 4-3. 形
```
adoptionCeil = Max(AdoptionCeiling, WorldTechLevel × catchFrac × contact)
contact      = 1 − CatchupContactWeight × (1 − 接触度)
```
- **接触度は思想の到達と同じ入力を使う**（`MultiNationSim.cs:925-937` の「自国のペア貿易量 ÷ 世界貿易」＋港の有無）。新しい量を作らない。
- **`AdoptionCeiling`（孤立国の床0.5）は掛けない**＝鎖国しても基礎技術は失われない。接触が効くのは**床より上の部分だけ**。これで「鎖国国が原始に戻る」破綻を構造的に防ぐ。
- `CatchupContactWeight = 0` で ×1.0＝厳密恒等。

## 7. 罠
- **二重計上**：吸収は技術と資本で同じ写像を共有している。厚みを混ぜるときは**両方に同時に効く**ことを意識する（片方だけ直すと非対称になる）。
- **順序**：§2-4。需要が無いまま厚みを混ぜると全国が一律に落ちる。
- **役務のボーモル**：教師の質を入れると役務に初めて生産性の次元が入る。他の役務（医療・行政）に波及させないこと（この段では教育だけ）。
- **`AdoptionCeiling` の床**：接触で床を割らせない（§4-3）。
- **UI 語彙**：「識字率」「専門人材率」。説明文は書かない・漢字1字の略称は使わない。
