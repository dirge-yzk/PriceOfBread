# 実バグ21件の是正 — 仕様（2026-09-06）— 設計・未着手

## 0. 出所と原則
第3レビュー（他AI・75点）を現物照合する過程で見つかった、**批評には無い現物の欠陥**。一覧 §0-6 の表が索引、本書が是正の設計。

**是正の原則**（既存の規律に従う）
- 新しい機構・新しいファイルを作らない。**既存の量と既存の述語を共有する**（リファクタは削減方向）。
- 直したら**恒等か非恒等かを宣言**する。非恒等なら単独 or 群で計測する。
- **単独 batch10 で exact+2 程度は採用の根拠にしない**（2026-09-06 に測ったノイズ床＝exact ±2・列強再現 ±3.3・◎ ±5）。

**重要な性質**：`selfplay-batch` は全国が AI（`UtilityAgent`）なので、**プレイヤー経路だけを直す是正は帯を1ビットも動かさない**（B6・B7・B8）。これらは計測なしで入れられる。

## 1. 型A — 型の統合の後始末（`ColoniesAreRegions` / `CivilWarAsWar` の点火で旧読み手が沈黙）

### B1. 入植と植民地の昇格が原理的に発火しない
**根拠**：`MultiNationSim.cs:138,149-166` の `PromoteAllColonies` が `ColoniesAreRegions=1.0` で開始時に全植民地を州化し `ColonyList` から `Remove` する。実在国の `ColonyList` は Q1 から恒久的に空。したがって入植の流量（`Colonial.cs:169`）も昇格判定も1度も走らず、`ColonySettlerRate=0.00015`（**「点火」を自称**）・`ColonyPromotionCoreShare=0.5`・`ColonyPromotionMinPop=60`・`Colony.SettlerSize/SettlerSavings/SettlerLiteracy` が**読み手ゼロ**。カナダ・豪の自治領化（`RegionTier.Integrated` への昇格）が131年間1件も起きない。

**直し方＝判定の主体を Colony から「植民地格の州」へ移す（新しい状態を作らない）**
入植者比率は**既存の量で表せる**＝`AvgRegionCoreShare(r)`（宗主の中核民族の比率）。したがって：

```
昇格の条件： r.Tier == Colonial
           && AvgRegionCoreShare(r) >= ColonyPromotionCoreShare
           && r.SumPopulation() >= ColonyPromotionMinPop
昇格の効果： r.Tier = Integrated（本国だが非中核）
入植の流量： 宗主の本国州 → 植民地格の州への州間移民（既存の Territory 経路）に
           ColonySettlerRate を掛ける
```

- `Colony.SettlerSize/SettlerSavings/SettlerLiteracy` は**削除**（州の pop と `CoreEthnicShare` が同じ情報を持つ＝二重表現の解消）。
- ⚠`RegionTier.Integrated` は現状 world.json 経路から1件も生まれない（B14 と同根）＝この是正で初めて第3の格が実在する。
- 非恒等（昇格が起き始める）＝**単独計測**。受け入れ＝植民地の忠実度（25.8%）と、加・豪・南アが1914年までに `Integrated` へ昇格すること。規模 M。

### B2. `Colonial.cs` の4ブロックが全死し、生きた読み手が0を読み続ける
**根拠**：`Simulation.cs:1702` の `r.ColonialResources = selfP.ColonyList.SelectMany(...)` が恒等的に空配列 → `Colonial.cs:96` の投資ブロックが常に偽 → `Colonial.cs:30` の減衰だけが毎月走り `ColonialInfra → 0`。その `ColonialInfra` を **`Diplomacy.cs:2488` が生きた入力として読んでいる**＝「開発された帝国ほど植民地が堅い」というバランスの一柱が黙って抜けている。同じ根で `IndependentColonies`（独立した旧植民地＝自由な供給者）と独立ショックも永久に空。

**直し方＝国スカラー `ColonialInfra` を廃し、読み手を州の量へ張り替える（削減方向）**

```
Diplomacy.cs:2488 の ColonialInfra → その植民地州の r.Infra（既存）
Colonial.cs の投資・減衰ブロック → 削除（州の Infra は既存の投資経路が動かしている）

```

- ⚠**死蔵の削除ではなく、0を読んでいた項が初めて非0になる**＝非恒等。単独計測。規模 M。

### B3. 内戦の一元化を点火したのに `CivilWarYears` が0のまま
**根拠**：`Politics.cs:1113-1122` の `CivilWarAsWar` 分岐は `PendingRebelRegions`／`HadCivilWar`／`RevoltingFaction` を書くだけで **`StartCivilWar` を呼ばない**。`MultiNationSim.cs:326-343` も親の `CivilWarYears` に触らない。結果、`CivilWarAsWar=1.0`（点火済み）の主経路で内戦中でも `CivilWarYears == 0` となり、**内戦を検知する6箇所が沈黙**する＝内戦の経済麻痺（`CivilWarEconomyDisruption=0.2`）・軍需2倍（`Simulation.cs:1714`）・同盟の参戦判断（`Diplomacy.cs:1495`）ほか。

- 差し替え自体は S だが、**経済麻痺と軍需2倍が実ゲームで初めて効き出す**＝非恒等。単独計測。規模 M。

## 5. 型E — 死蔵と、記録が現物と食い違うもの

### B4. 予算法・統帥法を機構として生かす（**作者裁定 2026-09-06＝残す。主に内戦時**・M）
**根拠（死蔵の事実）**：書き手は `Simulation.cs:107,113` の初期化1回のみ、読み手は `PowerAffinity.cs:360,371` → UI/Runner の表示だけで**エンジンは1度も読まない**。テスト0件。結果、1783年の値が**131年固定**＝1866年プロイセンの予算紛争の決着も、1889年明治憲法も、1906年ドゥーマも表現されない。

**裁定**：削除せず**法として生かす**（作者「主に内戦時に重要」）。以下はその設計。

#### B4-1. なぜ内戦で決定的か（史実）
内戦とは「国家が二つに割れたとき、**軍はどちらに従い、金はどちらに集まるか**」の問題である。両方とも憲法上の所在＝この2法が決める。
- **統帥法**：普1862-66 の憲法紛争では軍は王に属し、議会は予算を拒んでも軍を止められなかった。日本の統帥権独立（明治憲法11条）は内閣が軍を統制できない構造を作った。英は反乱法（Mutiny Act）で軍の存在自体を毎年の議会承認に係らしめた。**軍が誰のものかで、政変が成功するか内戦になるかが変わる**。
- **予算法**：英内戦も米南北戦争も、勝敗を分けたのは徴税と起債の能力だった。議会が反乱側に付いた国は戦費を集められない。

#### B4-2. 統帥法の効き方（3つ・すべて既存量）
既存の `PowerAffinity.CommandShares(w)` は `(Crown, Parliament)` を**正統性×法の重み**で正規化して返す（実装済み）。政府がどちら主導かは既存の `w.ParliamentControl ∈[0,1]`。
```
統帥の所在  cmd   = CommandShares(w).Crown        （1＝王が軍を握る）
政府の所在  gov   = 1 − w.ParliamentControl        （1＝王権主導の政府）
一致度      align = 1 − |cmd − gov|                （新しい量を作らない）
```
- 絶対王政（王が統帥・王が統治）＝align 1.0 → 軍は全部政府側。
- **統帥権の独立**（王が統帥・議会が統治＝普1862/日）＝align 0 → **軍は政府に従わない**。
- 英（議会が統帥・議会が統治）＝align 1.0。
- 分割（Split=0.5/0.5）＝どちらの極でも align 0.5 → **軍が割れる**。

| # | 効き先 | 式 | 史実 |
|---|---|---|---|
| ① 内戦の決着 | `coerce ×= (1 − CommandMisalignWeight × (1−align))`、乖離分は反乱側 `attack` へ加算 | 政府が軍を握れない国では内戦に勝てない | 1917年露（軍が離反）・1936年西（軍が反乱側そのもの） |
| ② クーデタの引力 | `SoldierForce ×= (1 + CommandMisalignWeight × (1−align))` | 統帥が政府から乖離するほど軍政の引力が上がる | 日の統帥権独立→軍部の台頭／英は軍政が起きない |
| ③ 軍事費の同意 | 軍事費スライダーの `Move` に `MandateGate` を `CommandShares.Parliament` に比例して掛ける | 議会統制なら軍拡に議会の同意が要る | 普109条＝軍事費だけ議会の外 |

#### B4-6. 器と恒等
