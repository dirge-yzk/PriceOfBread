# 分裂の断層（拮抗の内戦で誰が離れるか）— 設計・器実装（2026-09-06）

## 根（作者設計 20260906_特権システム §12）
`CivilWarSplitEnabled` は拮抗の内戦で「思想の傾きが国の平均より反乱側の州」を離脱させる。**地図の上の断層を読まない**ので、同文化の中核州が割れる
（新基線＝マンチェスター王国・ルアーヴル王国・リヨン王国・サンクトペテルブルク共和国が勝者に出る／英の人口×0.69・列強12位）。
史実＝内戦で国が割れるのは**断層**（民族・地域アイデンティティ）がある所だけ（南北戦争＝南部・グラン・コロンビア＝地域）。スペイン1936やフランスの内乱は割れない＝革命か鎮圧。

## 器 `SplitRequiresFaultLine`（既定0＝従来）
- 離脱候補の条件に **民族の断層＝中核度 `AvgRegionCoreShare(r) < 0.5`** を足す（分離の内乱の民族分岐と同じ物差し＝新しい数を作らない）。
- 断層の無い一様な国では拮抗の内戦は分裂せず、通常決着（反乱勝利＝革命／中央勝利＝鎮圧）へ落ちる。
- 国民意識（pop属性）を第2の断層にする案は保留＝「平均未満」は常に半数を選ぶので物差しにならない。要るなら閾値の根拠を先に。

## 計測
`splitfault` 腕（batch10）＝G3 アブレーションの後。受け入れ＝英の人口倍率と列強順位・欧州中核州の分裂国家が勝者から消える・建国数・硬性緑。
