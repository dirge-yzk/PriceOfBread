# 法と特権の仕分け — 設計（2026-09-06・作者指摘「法や既存ルールと重複している」）

前提＝[20260906_特権システム_制度疲労の置換_設計_部分完了.md](20260906_特権システム_制度疲労の置換_設計_部分完了.md)／[20260906_特権の候補一覧_階級別_設計_部分完了.md](20260906_特権の候補一覧_階級別_設計_部分完了.md)。
⚠この文書が仕分けの**正**。候補一覧の30本のうち9本は法へ移す。特権は**相続型21本（§4）＋授与型10本（§9）**の2系統。

## 1. 判定基準（2つのテストを順に当てる）

**テスト1＝一般性**：その規則は**全員に同じように**適用されるか。
- はい（全員に同じ義務／誰でも使える手続き）→ **法**
- いいえ（特定の身分だけを外す・別扱いにする）→ **特権**

これは19世紀そのものの定義でもある。近代法とは「一般性」であり、身分制とは「例外の束」である。**特権とは一般規則からの除外**にほかならない。

**テスト2＝重複回避**：その内容が既存の法の段で**完全に表現できる**か。
- できる → **法**（特権台帳に載せない）
- できない（「**誰が**例外か」という情報が要る）→ **特権**

## 2. 構造＝法はフロー、特権はストック

- **法** ＝ 今期の決定（議会・王権が動かすレバー・全員に同じ）
- **特権** ＝ 積み上がった例外の**在庫**（誰がどれだけ持っているか・保有年数で既得権化）
- **法を一般化すると、矛盾する特権が剥離される**＝ここで政治（怒り・補償・断裂の窓）が起きる
- **制度疲労 ＝ 特権ストックの残高**

この形なら重複は原理的に消える。法は「原則」、特権は「原則の外にいる者の名簿」であり、同じ主題に両方があってよい。

| 主題 | 法（原則・全員に同じ） | 特権（例外・名簿） |
|---|---|---|
| 税 | 土地税・累進課税の率 | 貴族/聖職の免税、教会領の永代免税 |
| 兵役 | 徴兵法（志願/選抜/皆兵） | 免役の身分（貴族・聖職・科挙・村請け） |
| 官職 | 官僚制度法（任用の原則） | **既に売られた官職の在庫**（法改正では手放さない＝補償か怒り） |
| 営業 | 独禁法・営業の自由 | 個別の専売許可・特許会社・関門の徴収権・ギルドの親方株 |
| 土地 | 土地改革・囲い込み・農奴解放 | 領主権の残高・入会権の残高・教会領・屯田 |
| 司法 | （必要なら新軸「法の下の平等」） | 免笞・領主裁判・軍法・治外法権 |
| 給付 | 社会保障法（普遍給付） | 家禄・恩給（身分に紐づく給付） |
| 教育・技術 | 教育法・特許法・高等教育 | 免許（資格独占）・官学位 |
| 戸籍 | 国家の登録（新軸は作らない） | 教区簿冊の管理（聖職者） |

## 5. 近代の階級と特権（⚠2026-09-06 訂正）

**初版の「資本家と労働者は特権を持たない」は言い過ぎだった**（作者指摘）。正しくは：

- 彼らの**中心的な**利益は一般法にある（営業の自由・契約の自由・法の下の平等・普通選挙・普遍的な社会保障）。ここは変わらない。
- しかし史実では、彼らも**名指しの例外**を確かに受け取った。国家はそれを「一般法を与えずに済ませる道具」として使った。
  - 資本家＝鉄道・鉱山・港湾の**利権（コンセッション）**、**特命調達**（政商＝三井/三菱・クルップ）、工業誘致の**免税**、勅許植民地会社。
  - 労働者＝**クローズドショップ**（組合員以外を雇わせない＝未組織労働者に対する例外）、**官業労働者の身分保障と恩給**（鉄道・造兵廠）、戦時の**就業による徴兵免除**（軍需・鉄道）。
  - 農民＝解放時の**分与地**、**村の自治**（ミール・村請け）。
- したがって特権は「旧体制の遺物」だけではない。**相続した特権（旧体制型）と、与えた特権（授与型）の2系統**がある。§4の21本は前者に偏っていた。

残る非対称は次の形で正しい：**旧体制の階級は特権が収入の柱であり、近代の階級にとって特権は補助である**。だから前者は一般化に抵抗し、後者は一般化を要求しながら、目の前の例外は受け取る。この温度差が `Ideology`（`NoblePrivilegeWeight` の特権加算・`ReactionFromLoss` の喪失からの反動）の符号と一致する。

## 6. 法と特権の相互作用（規則は1本）

**法をより一般的な段へ動かすと、それに矛盾する特権が剥離される。**

| 法の動き | 剥がれる特権 | 史実 |
|---|---|---|
| 土地税・累進課税↑ | 貴族/教会の免税 | 1789年8月4日、1799年英の所得税 |
| 徴兵法→国民皆兵 | 免役の身分 | 仏1793レヴェ・アン・マス、日1873徴兵令 |
| 官僚制度法→専門任用 | 既得の官職 | 仏1789の売官廃止（補償で財政破綻）、清1905科挙廃止 |
| 独禁法→カルテル禁止/解体 | 個別の専売 | 英1813/1833の東インド会社の独占廃止 |
| 土地改革→全面 | 領主権・入会権 | 露1861、独の共同地分割、英の囲い込み |
| 国教法→信仰の自由 | 十分の一税・教会領・戸籍 | 仏1792の民事身分登録、西のdesamortización |
| 社会保障法→年金 | 家禄・恩給（普遍給付が身分給付を吸収） | 日1876秩禄処分→恩給制度 |

- 剥離の怒り＝特権の**強度ストック**に比例（長く持っていたものほど荒れる）。
- 剥離が通る窓＝既存の `RuptureWindowQuarters`（革命・内戦制圧・クーデタ・敗戦の直後）。新しいタイマーは作らない。
- 平時は既存の**法の純支持ゲート**（`MandateWeight`）で通らない＝「強すぎる特権は剥がせない」が新ゲートなしで出る。

## 7. 新しい法の軸は最大1本

上の仕分けで新設が要るのは「**法の下の平等**（司法の一般性）」だけ（免笞・領主裁判・軍法・治外法権を1本で受ける）。⚠これも第1段では作らない——当面はそれらの特権を既存の農奴解放法／官僚制度法／条約港に紐づけ、軸の新設は説明力が足りないと分かってからにする（新しい軸を作らないほど良い）。

# 9. 授与型の特権（作者提案「不満を和らげるために与える側が欲しい」）

## 9-1. 難しくない。むしろ欠けていた半分である
譲歩の動詞はすでにある（`ConcedeToFaction` / `CompensateFaction`）が、**支払いの通貨が「法の段」しかない**。特権を足すと通貨が2つになる：

| 通貨 | 何を払うか | 誰が払えるか |
|---|---|---|
| **法**（一般化） | 全員に同じ権利・規則 | 議会制＝払える（権力を失わずに払える） |
| **特権**（例外） | 名指しの階級に例外 | 専制＝**これしか払えない**（法で払うと権力そのものを失う） |

これは国名を1つも書かずに「専制は特権を配り、議会制は法を通す」を出す。ビスマルクの反射（本丸の要求は拒み別の軸で埋め合わせる＝既存の `FactionCompensation`）と同じ骨で、その埋め合わせの選択肢に特権が加わるだけである。

## 9-2. 授与型の特権（階級別）
| 階級 | 授与型の特権 | 取り分 | 歪み（表裏） | 史実 |
|---|---|---|---|---|
| 資本家 | **利権（鉄道・鉱山・港湾のコンセッション）** | 独占的な収益権＋用地の収用 | 財政（用地・利子保証）・後発の参入排除・汚職の温床 | 米の土地付与鉄道、露のヴィッテ、日の官有物払下げ |
| 資本家 | **特命調達（政商）** | 随意契約の国家発注 | 調達価格↑（財政）・競争の消滅で軍需の質↓・他資本の怨嗟 | 三井/三菱、クルップ |
| 資本家 | **工業誘致の免税** | 一定期間の非課税 | 徴税ベース↓ | 明治の勧業、露の外資優遇 |
| 工場労働者 | **クローズドショップ** | 賃金と雇用の保障 | **未組織労働者の排除**＝労働者内部の分断・雇用の硬直で投資↓ | 英のクラフト・ユニオン、米の closed shop |
| 工場労働者 | **官業労働者の身分保障・恩給** | 解雇されない＋年金 | 財政の固定費・行政の効率↓ | 普の鉄道員、日の官業・造兵廠 |
| 工場労働者 | **就業による徴兵免除** | 兵役の回避 | 動員ベース↓（総力戦で効く） | 第一次大戦の軍需・鉄道の徴用免除 |
| 農民 | **分与地（解放時の割当）** | 土地 | 地主への補償＝財政/国債（買戻金） | 露1861 |
| 農民 | **村の自治（ミール・村請け）** | 自治と再分配 | **移動の制限**＝都市への労働供給が来ない | 露のミール |
| 官僚 | **終身官・恩給** | 身分の安定と年金 | 財政の固定費・改革時の抵抗が固くなる | 独のBeamte、日の恩給 |
| 兵士 | **恩給** | 退役後の給付 | 財政の固定費 | 日1875、各国の傷痍軍人年金 |

## 9-3. 「つけ得」を潰す4つの代価（すべて既存の量で書く）
1. **財政・効率の代価**＝歪みそのもの（徴税ベース↓・調達価格↑・行政効率↓・労働移動の凍結）。
2. **排除された階級の怒り**＝特権は例外なので、外された階級の闘争度が上がる。**与える相手を選ぶ＝敵を作る**。
3. **ラチェット**＝与えた特権は強度ストックとして積み上がり、後で剥がすときの怒りは**保有ストックに比例**する。**今の平和を、将来より高い代価で買う**（仏の売官の補償で財政破綻・日の秩禄処分）。
4. **受益者の保守化**＝収入が特権に依存するほど、その階級の思想が現状維持へ寄る（既存の所得構成→思想の経路＝`NobleWeightsFromIncome` と同型）。**改革の味方を1つ失う**。

⚠これで「特権を配って不満を消す」戦略は成立するが、配るほど①財政と効率が痩せ②敵が増え③将来の改革が高くつき④改革の支持基盤が消える。**短期の安定と長期の硬直の交換**＝制度疲労はこの交換の帳簿にほかならない。

## 9-4. AI＝プレイヤー対称
AI も同じ2通貨で払う（法の段 or 特権）。専制のAIは特権で払い、議会制のAIは法で払う——**分岐は政体ラベルではなく「法で払ったときに失う権力の大きさ」**（既存の `MandateSpent`／`CrownParliament` の量）で決まる。

## 9-5. 実装の位置
- 付与＝`CompensateFaction` の選択肢に「特権の付与」を1つ足す（新しい動詞を作らない）。
- 剥離＝§6のとおり法の一般化が引き起こす。
- 器＝`PrivilegeGrantEnabled`（既定0＝付与の選択肢を出さない＝厳密恒等）。
- 第1段（§8）には**入れない**。旧体制型4本の台帳と数値恒等を先に固め、授与型は第3段（剥離の怒り）の後に足す。
