## 0. 要点（1枚）

1. **今の能力と効率は、根拠が数値の都合の乗数と定数の重ね合わせ**（§1）。月5%の追従は注記が「供給の振動を防ぐ」だけ＝史実・物理の根拠なし【確】。**建てた工場が無くても、採算が良ければ規模が最大3倍まで膨らむ**【確】＝資本なしに能力が湧く。
2. **市場から導く3本**：
   - **どの製法を使うか＝費用**（今もそう）。
   - **広がる速さ＝資本**：能力は**建てた分だけ**。既存の工場は**価格が変動費を上回る間は動く**。設備は**物理的な寿命で減る**だけ。
   - **機械化・電化＝「動力」の財**（作者裁定①）：工場は動力を買い、動力は人力・畜力・水車・蒸気・電動のレシピで作る。どれを使うかは費用＝**賃金が高く石炭が安い国ほど蒸気**（アレンの高賃金説）が費用の比較だけで出る。
3. **市場だけで足りないもの＝習熟**。**学習曲線**を画一的なルールとして置く（作者裁定②）：投入の量が「最初の世代の割高さ k」から「成熟した値（レシピのデータ）」へ、経験の倍加 h 回ごとに半分ずつ近づく。**経験＝設備の総量**（新しい状態なし）。**普遍の定数は k と h の2つだけ**。
4. **消えるもの**：月5%の追従・規模の下限と上限・新規参入の規模・休止の速度・蒸気／電化／効率化材の＋30%・工業化の生産性 `indMult`・機械化度・旧世代の陳腐化・**技術水準の一律の生産性 `techProd`**・レシピの解禁の傾斜 `RecipeTechScale`。
5. ⚠ **較正への影響がとても大きい**＝3回に分けて、1回ずつ腕A（着手前のコミット）に対して測る（§6）。

## 2. 動力の財（作者裁定①）

### 2-1. 形

```
労働（人の時間）── POP が売る（賃金＝この価格）
        ↓
動力 ＝ 工場が買う（州の中で作って使う＝運べない）
   人力  ＝ 労働
   畜力  ＝ 馬 ＋ 飼料（麦） ＋ 少しの労働
   水車  ＝ 機械 ＋ 少しの労働                （川のある州だけ）
   蒸気  ＝ 機械 ＋ 石炭 ＋ 少しの労働
   電動  ＝ 機械 ＋ 電力 ＋ 少しの労働
        ↓
工場（例：綿布）＝ 綿花 ＋ 動力 ＋ 高度労働力
```

- 今の「労働力」の財（`LaborId`）は、すでに人力・畜力・水車・蒸気機関・電動のレシピを持つ（Simulation.cs:1147-1156）【確】＝**実質は動力**。これを正面から「動力」とし、人の時間を「労働」として分ける。
- **工場が買うのは動力と高度労働力**。人の労働は動力のレシピを通して入る。
- **役務（家事奉仕・行政・教育・医療）は労働をそのまま使う**＝動力で置き換えにくい＝ボーモルの病が残る。

### 2-2. 何が出るか

| 史実 | 出方 |
|---|---|
| 英国の機械化（高賃金・安い石炭） | 賃金が高く石炭が安い州で「蒸気の動力」が「人力の動力」より安い＝市場が蒸気を選ぶ |
| 清・インドで機械化が進まない | 賃金が安い＝人力が安い＝蒸気を選ばない |
| 機械が賃金を抑える（ラッダイト） | 動力の価格の上限を蒸気の費用が押さえる＝人力の動力の価格（＝賃金）が上がれない |
| 技術的失業 | 蒸気の動力は労働を少ししか使わない＝同じ動力を少ない人で作る＝労働の需要が減る（`Mechanization`・`LaborSaveRate` が要らない） |
| 馬からトラクターへ | 農業の動力（§2-3）の畜力→内燃機関のレシピを費用で選ぶ |

### 2-3. 決めたこと・決めること

| # | 論点 | 案 |
|---|---|---|
| 1 | 動力は運べない | 電力と同じく州の中で作って使う（NonTradeable）。電動の動力は送電網の範囲の電力を使う |
| 2 | 水車の立地 | 川のある州だけ。賦存に「水力」を足すか、今の地形のデータから導く【推】 |
| 3 | 機械は資本 | 動力のレシピで機械を「毎月、耐用年数に応じた分だけ消費する」投入にする＝資本の在庫を別に持たない。耐用年数は史実のデータ（機械は十数年） |
| 4 | 工場ごとの動力の強さ | 紡績は動力を多く・家具や時計は高度労働力を多く＝**レシピの投入の量（データ）**で表す |
| 5 | 農業の動力 | 「農業の動力」（今の `FarmLaborId`）を人力・畜力・内燃機関のレシピにする＝同じルール |
| 6 | 賃金・雇用・失業の付け替え | 今の労働力（`LaborId`）はコードの約90か所から読まれる【確】＝賃金・雇用・失業の読み手を「労働」の側へ付け替える |

## 3. 能力は建てた分だけ

| 今 | 案 |
|---|---|
| 規模は 1＋採算へ月5%で近づく（設備と無関係に最大3倍） | **能力＝建てた設備の量**（工場の建設＝資材・工期・お金＝既存の仕組み） |
| 下限0.1・上限3.0・新規参入0.3 | 撤去。新しい工場の規模は建てた量 |
| 赤字の工場は月5%で休止 | **価格が変動費（投入費＋動力＋高度労働力）を下回れば止め、上回れば動かす**＝短期の供給の教科書どおり |
| 旧世代の陳腐化（0.5） | 撤去。古い製法の工場は変動費を賄える間は残り、賄えなくなれば止まる＝市場が陳腐化を決める |
| — | 設備は**物理的な寿命で減る**（耐用年数のデータ＝建屋は数十年・機械は十数年） |

- 新しい製法は「儲かるので投資家が新しい工場を建てる」速さで広がる＝投資の資金（貯蓄・与信）と資材と工期が律速。
- ⚠ **産地で採れる財（RGO）は工場と違う**：能力は土地と賦存で決まり、労働を足すほど効率が落ちる（収穫逓減）形で導く。今ある耕地の量 `ArableLand` を使う【推】。

## 4. 学習曲線（作者裁定②）

### 4-1. 形

```
そのレシピの投入の量 ＝ 成熟した値 × ( 1 ＋ (k − 1) × 2^( −n ÷ h ) )

n        ＝ log2( 経験 ÷ 最初の設備の量 )      （経験の倍加の回数・0 未満は 0）
経験     ＝ 自国のそのレシピの設備 ＋ 伝播 × 世界のそのレシピの設備
伝播     ＝ §1A-7（財の削減の設計書）の取引の割合＝発見の伝播と同じ物差し
k        ＝ 最初の世代の割高さ（全レシピで共通の1つの値）
h        ＝ 割高さが半分になるまでの倍加の回数（全レシピで共通の1つの値）
成熟した値 ＝ レシピの投入の量のデータ（今の goods.json・Producer の値を「成熟した製法」と読む）
最初の設備の量 ＝ 解禁して最初に建てた工場の規模
```

### 4-2. 外科的にならない理由

| 外科的になる原因 | この形での解き方 |
|---|---|
| どこまで下がるかが決まらない（ライトの法則は際限なく下がる） | 下がり切った先＝**レシピのデータ（成熟した値）**。割高さは k 倍から1倍へ有界に近づくだけ |
| いつ下がるかが決まらない | 暦でなく**経験（設備の量）**で進む＝儲かって工場が建つほど早く学ぶ＝市場が時期を決める |
| 今の一律の生産性と二重に数える（設計思想⑨） | **一律の `techProd` を撤去して、生産性の伸びを学習曲線へ移す**（§4-4） |
| レシピごとの手当て | 定数は k と h の2つだけ・レシピごとの値を置かない。尺度は「最初の設備との比」の倍加の回数＝財の大小に依らない |
| 新しい状態 | 経験＝設備の総量＝§3 で能力の実体として持つ量＝新しい状態なし（設計思想⑩） |

### 4-3. k と h の錨（全レシピで共通の値を一度だけ決める）

| 錨 | 史実（おおよそ） |
|---|---|
| ベッセマー鋼 | 英国の鋼の価格が1850年代の約40ポンド/トンから約20年で5分の1ほどに |
| 電力 | 発電の単位費用が1880年代から1910年頃までに数分の1に |
| T型フォード | 生産が約100倍になる間に価格が約3分の1（進歩率およそ0.85） |
| 綿紡績 | 機械化の初期に糸の単位あたりの労働が桁違いに減った（極端＝錨から外す候補） |

- 見込み：k はおおよそ3〜5倍・h は数回の倍加【推】。数字は計測で決める。**レシピごとに合わせない。**
- 動力のレシピ（§2）にも同じ式が当たる＝ワットの機関→複式→タービンの改良が同じルールで出る。

### 4-4. 技術水準の役目の縮小

- 今の技術水準（`TechLevel`）は、**全ての生産者に一律の生産性**を掛けている（`techProd`・Simulation.cs:2156）＋ 発見の時計＋ 各種の門。
- 案：一律の生産性をやめ、技術水準の役目は**発見の技術力（難易度にどれだけ近いか＝財の削減の設計書 §1A-2）**と教育・制度の門に限る。
- 史実の手触り：19世紀の生産性の伸びは新しい製法を使った部門（綿業・製鉄・鉄道）に集中し、農業・役務の伸びは小さかった（クラフツらの成長会計）＝一律の乗数は全部門を同じ速さで伸ばしてしまう。
- ⚠ 世界全体の生産性の伸びが今と大きくずれないように k・h を決めて移すのが安全（§6 の段3）。

### 4-5. 鶏と卵

- 最初の世代は割高＝旧来の製法より高いうちは市場が選ばない＝誰も建てない＝学習が進まない。
- 突破口：
  1. **発見の必要性の項**（割高な原料に苦しむ国＝旧来の製法が高い国）＝そこでは最初の世代でも旧来より安いことがある＝その国が最初に建てる（財の削減の設計書 §1A-4）。
  2. **国営工場と懸賞の機構**（別の設計書）＝史実でも初期の製法は軍需と政府の支えで立ち上がったものが多い。
- それでも動かない製法が出るかを計測で確かめる（「解禁したが一度も建たない製法」を数える計器）。
