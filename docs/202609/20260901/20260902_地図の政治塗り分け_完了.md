# 地図の政治塗り分け（Vic風）＋全景の国名ラベル【完了】

2026-09-02〜03 作者指示。表示のみ（SimCore の力学は一切読まない・触らない）＝419テスト緑。

## 1. 塗り分け（`PriceOfBread.App/MapFill.cs`）

**規約**：所持州（本国州＋植民地）を種に、**陸の上だけ**を多源流ダイクストラで同時に広げ、他国の塗りとぶつかった所で止める。

- **上限距離＝`Places.MaxSpacingKm`（850km）＝州を敷いたときの最長間隔と同じ値**（作者裁定2026-09-02）。
  州はその規約で置かれているので、同じ距離で切れば「そこに置かれ得た**未保有の州の領分**」まで塗りが伸びない。
  ⚠新しい調整値を作らない＝規約の共有。SimCore 側の定数1本だけを読む（値を動かすときは places.json の生成規約と一緒に）。
- **格子**：`Landmask` と同じ 0.1°（3600×1380）＝航路判定の真値と同じ物差し。東西は端で巻く（東西ループ）。
- **歩幅は実距離**：南北11.1km・東西は cos(緯度) で縮む・斜めは √(dx²+dy²)。
  ⚠4近傍だけだと前線が45°の直線に折れて「ひし形の国」になる（実測で確認→8近傍へ）。
- **型紙＝背景の絵そのもの**：背景SVGを焼いた直後にその画から陸を読み出し（陸色は赤>青・海/湖色は青>赤の1本で判別）、
  塗りはその内側にだけ置く。⚠陸マスクは**湖を陸として持つ**（湖は海ではない＝航路の都合）ので、これが無いと
  五大湖・グレートベア湖・ロッホネイが国色に染まる（実測で発生→修正）。海岸線の1格子ぶんのずれも同時に消える。
- **島**：州を持たない島は塗らない（海を渡らない）＝Vic風の素直な帰結。

**性能**：焼き直しは**所有が変わった時だけ**（所有の指紋が一致すれば何もしない）。背景スレッドで焼く＝征服の瞬間に時間が止まらない。
実測 150〜500ms（種302・作業配列は使い回し・`lock` で1枚ずつ）。UI は待たない。

## 2. 全景の国名（英語）

州名が消えるズーム帯（`_dotZoom < LabelThreshold`）で、代わりに**国名を英語**で出す。

- 位置＝**中核州の人口重み重心**。⚠植民地格の州を入れると、スペイン/ポルトガル/ネーデルラントの名が大西洋・インド洋へ流れる（実測→除外）。
- 重なりは人口の多い国から置く貪欲（州名と同じ作法）＝全景で小国が潰し合わない。
- 英語表記は `MapData.EnNation`（world.json の61カ国＋建国名40）。未登録は日本語のまま（`En` と同じ作法）。
- **州名のカタカナ残り80件を解消**（作者指摘）：辺境・植民地標的（Siberia/Vladivostok/Timbuktu 等）が `CityEn` 未登録で
  日本語のまま出ていた。全338件で未登録0を機械確認。

## 4. 後回し（作者裁定）

**塗りの明度を州の支配度で変える**（低支配度＝黒く）＝**支配度そのものが未実装**。州が持つのは犯罪率・インフラ・戦場強度で、
「掌握の度合い」に当たる量は無い（国単位の行政力・正統性・強権はある）。導入するなら
「行政力×距離減衰×犯罪率×戦災」あたりから州の支配度を作る設計が要る。塗りは1格子ごとに色を書いているので、
支配度が入れば**その1行に明度係数を掛けるだけ**で足りる（器はこのまま使える）。
