## ⚠ §1 余剰戦力は【既に存在し、既に3つで取り合っている】

### ★ §1-1 現物

```csharp
Coefficients.cs:1033  ExpansionWillGrowth    = 0.5;    // ⚠四半期あたり ×(戦争熱−閾値)
Coefficients.cs:1034  ExpansionWillCap       = 10.0;   // ★貯蓄上限
Coefficients.cs:1120  ExpansionWillBourgeois = 0.4;    // ⚠ブルジョワ・ブロック力（★東インド会社の実体化）

// ★既存の消費先が3つ
Diplomacy.cs:1791  gw.ExpansionWill -= willCost;                     // ⚠植民地化
Diplomacy.cs:1871  gn.ExpansionWill -= InterventionWillCost(...);    // ★他国への干渉
Politics.cs:977    w.ExpansionWill  -= SuppressFactionWillCost;      // ⚠国内鎮圧（2.0）
Coefficients.cs:1540  SuppressFactionWillCost = 2.0;   // ★満タンで約5回
```

⚠⚠ **＝ ドクトリン変更は【4つ目】の消費先になる。**★ **新しい資源を作らない（思想⑨）。**

### ⚠⚠ §1-2 取り合いから史実が出る

```
⚠植民地を取る ／ ★他国に干渉する ／ ⚠国内を鎮圧する ／ ★ドクトリンを変える
                  ⚠⚠全部が同じプール（上限10）を奪い合う
```

| ⚠ 国 | ★ 余剰戦力の行き先 | ⚠ 結果 |
|---|---|---|
| ★ 清 | ⚠ 太平天国・回民・捻軍の鎮圧で使い切る | ★ **軍を近代化できない** |
| ⚠ 露 | ★ 1905以降の国内鎮圧＋バルカン干渉 | ⚠ **1914に旧ドクトリンのまま** |

⚠⚠⚠ **＝ 「帝国を経営する国は軍を近代化できない」が創発する。**

## ⚠ §3 A案 ＝ 常に1つだけ保持

> ★ 作者裁定：「⚠ **A案でよい**」

```
★保持しているドクトリン ＝ 各軍種につき【1つ】
⚠tierを上げる  → 入れ替え（★余剰戦力を消費）
★列を変える    → 入れ替え（⚠余剰戦力を消費）
⚠変更しない    → ★費用ゼロ（そのまま戦える）
```

⚠⚠ **A案でなければ「変更に費用がかかる」ことに意味が無い**（★累積するなら失うものが無い）。

### ★ §3-1 費用の形

```
⚠変更費用 ＝ DoctrineSwitchWillCost × (1 + 現在の軍の規模 / 基準)
```

★ **＝ 大きな軍ほど作り替えるのが高くつく。**⚠ **史実：大陸軍を持つ国ほどドクトリンが硬直した。**

⚠⚠ **そして `ExpansionWillCap = 10.0` に対して `SuppressFactionWillCost = 2.0` なので、**
★ **ドクトリン変更は 3〜5 程度が妥当**（⚠ 鎮圧2回分＝「国が荒れていると変えられない」）。

### ⚠ §3-2 費用が【情報】の代わりをする（★重要）

⚠ **ドクトリンは秘密ではない。⚠⚠ 相手のドクトリンは見える。**

★ **それでも史実が出るのは、⚠ 見えても【すぐには変えられない】からである：**

```
⚠1940 仏は独の機甲部隊を知っていた
  → ★しかし1918年の勝利のドクトリンから乗り換える余剰戦力が無かった
    → ⚠⚠敗北
```

⚠⚠⚠ **＝ 情報の非対称を作らずに、★ 判断の失敗が出る。**⚠ **思想⑤（プレイヤーとAIは完全対等）を守れる。**

## ★★ §4 ドクトリンは【理想の軍隊そのもの】を定義する

> ⚠ 2026-09-01 作者裁定：「★ **ドクトリンそのものに修正値を加えるのには反対。**
> ⚠ **ドクトリンは運用できる国力に対する兵力（理想の軍隊）を定義する。**
> ★ **古いドクトリンのままでは小さな、または低品質な軍隊しか組織できない、というのが正しいのではないか**」

### ⚠ §4-1 却下された形 ＝ 修正値

```
⚠却下：「電撃戦は突破力 ×1.15」「縦深防御は防御力 ×1.2」
```

⚠⚠ **＝ これは思想②（外科的倍率の禁止）そのものである。**
★ **戦闘の式に係数を足すと、⚠ ドクトリンの数だけ特例が増える。**

### ★★★ §4-2 正しい形 ＝ 国力から軍への【変換】

```
⚠国力（人口・経済・技術）は変わらない
  → ★ドクトリンが「その国力から何人を、どんな装備で組織できるか」を決める
    → ⚠古いドクトリンは【小さい軍】か【低品質な軍】しか出せない
```

⚠⚠ **＝ ドクトリンは戦闘力に触れない。⚠ 触れるのは【組織できる軍の形】だけ。**

★ **戦闘の式は1本のままである**——⚠ 押し合いも接触強度も戦死も、何も書き換えない。

### ⚠⚠ §4-3 tier と列の意味が確定する ＝ 編成上限

> ⚠ **用語注：**★ 本 doc では「フロンティア」という語を使わない。
> ⚠ 既にプロジェクト内で2つの別の意味を持つため：
> ★ ①**技術フロンティア**＝`World.IndustrialFrontier` / `WorldTechLevel`（⚠世界最先端の水準というスカラー・生きている）
> ⚠ ②**地理のフロンティア**＝未開拓の locked 州（★8/28『従属の一般化』で「未開拓地」という属性へ置換済み）
> ⚠⚠ ここでは **編成上限** と呼ぶ。

```
       ★質（1兵あたりの装備・訓練）
         ↑
         ｜  ＼                      ⚠tier4 の編成上限
         ｜   ＼  ＼                 ★tier3
         ｜    ＼   ＼  ＼           ⚠tier2
         ｜     ＼    ＼   ＼  ＼    ★tier1
         └──────────────────→ ⚠量（兵数）
```

| ⚠ | ★ 意味 |
|---|---|
| ★ **tier** | ⚠ **編成上限が外へ動く**（★同じ国力からより大きい／より質の高い軍） |
| ⚠ **列** | ★ **その上限を量に振るか質に振るか** |

```
⚠列A（機動）      → ★兵数は少ない・質は最高（⚠装備と訓練に金がかかる）
★列B（陣地・火力） → ⚠中庸
⚠列C（量・動員）   → ★兵数は最大・質は最低（⚠安く多く）
```

⚠⚠⚠ **＝ 「小さいか、低品質か」という作者の言葉が、⚠ そのまま編成上限の2軸である。**

### ★ §4-4 `ArmyShape` との関係 ＝ 需要と供給

```csharp
ArmyShape.cs:7  // ★理想の軍隊 ＝「自国に向けられている他国の武力」＋「自力で守らねばならない資産」
ArmyShape.cs:4  // ⚠作者指示「根本問題は需要と供給の関係が存在しないこと。
                //   ★理想の軍隊の形を定義する関数を用意し、
                //   ⚠なるべく理想を目指す構造がモノ・ヒト・カネの需要の過不足を生むようにする」
```

⚠ **現行の `ArmyShape` は【需要】だけを計算している。**

★★ **ドクトリンは【供給】である：**

```
⚠必要量（ArmyShape）   ＝ 脅威と守るべき資産が決める      ← ★変わらない
★組織可能量（ドクトリン）＝ 国力 × ドクトリンの編成上限      ← ⚠これが欠けていた
⚠⚠実際の調達          ＝ 両者の差が モノ・ヒト・カネの過不足を生む
```

⚠⚠⚠ **＝ 作者指示の「需要と供給の関係が存在しない」の【供給側】が、⚠ ドクトリンで埋まる。**

### ⚠ §4-5 これで出るもの

```
★清 ：脅威は認識していた（⚠洋務運動）
      → ⚠しかし旧ドクトリンでは近代軍を組織できない
        → ★必要量に届かないまま敗北を重ねる

⚠仏1940：国力は独と同等
      → ★しかし tier3（要塞主義）のまま
        → ⚠tier4（電撃戦）の独と同じ国力から【違う軍】が出る
```

⚠⚠ **＝ 「国力が同じでも軍が違う」が、⚠ 戦闘の式に一切触れずに出る。**

### ★★ §4-6 軍需バンドルの比率は【結果】である

⚠ **前案では「ドクトリンが `MilitaryRates` を決める」と書いたが、⚠⚠ 因果が逆だった。**

```
⚠正しい因果：
   ★ドクトリンが「兵数と1兵あたり装備」を定義する
     → ⚠その軍を編成するのに必要な物が決まる
       → ★MilitaryRates は【そこから導出される】
```

⚠⚠ **＝ 比率は手で置かない（思想⑨）。**
★ **「電撃戦は自動車を厚く買う」は指定でなく、⚠ 機械化された軍を編成した結果である。**

## ⚠ §5 tier の解禁 ＝ 敗戦の記憶

### ★ §5-1 史実の証拠が1つに寄っている

```
⚠1871 仏が敗北 → ★参謀本部を作った
★1905 露が敗北 → ⚠軍改革
⚠1918 独が敗北 → ★電撃戦（1940）
★1940 仏は1918に【勝った】ドクトリンのまま → ⚠⚠敗北
```

⚠⚠⚠ **＝ 勝った国は変えない。★ 負けた国が変える。**

### ⚠ §5-2 入力は既存の量

```
★動機 ＝ 敗戦の記憶（⚠8/28 §15 の三次の量・環状バッファ）
⚠費用 ＝ 余剰戦力（★ExpansionWill）
```

⚠⚠ **どちらも既存。⚠ 新しい定数は「変更費用」1つだけ。**

### ★ §5-3 バランス装置としても働く

⚠ **勝ち続ける国が硬直し、★ 負けた国が追いつく。**

⚠⚠ **＝ 覇権 snowball の抑制が、⚠ 外科的な係数でなく【歴史の因果】から出る。**

### ⚠ §5-4 技術水準も要る（★ tierの上限）

⚠ **敗戦だけでは1800年に電撃戦へ行けてしまう。**
★ **tier の上限は技術水準が決める**（⚠ `RecipeTechScale(onset, techLevel)` と同じ傾斜）。

```
★動機（敗戦）  → ⚠変えたくなる
⚠上限（技術）  → ★どこまで行けるか
⚠⚠費用（余剰戦力）→ ★実際に変えられるか
```

⚠ **＝ 3つの条件の積。**★ **思想⑪（必要条件は積）に合格。**

## ⚠ §7 3つの型 ＝ 研究／法／ドクトリン

★ **本 doc で、⚠ 制度の型が3つに整理された。**

| ⚠ 型 | ★ 決まり方 | ⚠ 可逆性 | ★ 費用 | ⚠ 例 |
|---|---|---|---|---|

| ⚠ **法** | ★ **可決される** | ⚠ **可逆だが稀**（★賛否がある） | ★ 政治的余白 | ⚠ 社会保障法・国教法 |

⚠ **そして3つとも「どれが正しいか」を判定する基準が違う：**

```

⚠法       → 誰が得をするか（★分配）
★ドクトリン → 相手と時代に合っているか（⚠⚠正解が動く）
```
