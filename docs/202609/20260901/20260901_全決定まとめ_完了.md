# ★★★ §1 ドクトリン

## ⚠ §1-1 結論

⚠⚠ **ドクトリンは【研究ではなく選択】である。**★ **そして選択には費用がかかる。**

| ★ | ⚠ 決定 |

## ★★★ §1-2 【修正】3軍種すべて 軍質 ⇔ 軍量 の一軸である

> ⚠ 作者裁定：「★ **ドクトリンはそれぞれで軍質←→軍量になるように修正**」

⚠⚠ **旧案では軍種ごとに違う軸を使っていた**（★陸＝機動/陣地/量・⚠海＝決戦/通商破壊/防御）。
★ **これは誤りである。⚠ 3軍種とも同じ一軸に揃える：**

```
★質側 ←──────────────────────→ ⚠量側
少数・高価・高練度        中庸        多数・安価・低練度
```

⚠⚠ **＝ 列の意味が3軍種で共通になるので、⚠ 「この国は質の国／量の国」が軍種を跨いで言える。**

★ **そしてこの修正は、⚠ 旧案で私が挙げた問題を解消する：**

> ⚠ 旧懸念：「★ 陸軍 列B tier4『縦深戦術』はソ連の**攻勢**ドクトリンであり、⚠ 列B（防御）の性格と逆に見える」

⚠⚠ **列Bを「防御」でなく「中庸（質と量の中間）」と定義すれば、★ 縦深戦術は正しく中庸に座る**
（⚠ 機械化＝質 と 大量動員＝量 の両方を要求するのが縦深作戦である）。★ **懸念は消える。**

## ★★★ §1-4 効き先 ＝ 理想の軍隊の【供給側】

> ⚠ 作者裁定：「★ **ドクトリンそのものに修正値を加えるのには反対。**
> ⚠ **ドクトリンは運用できる国力に対する兵力（理想の軍隊）を定義する。**
> ★ **古いドクトリンのままでは小さな、または低品質な軍隊しか組織できない**」

### ⚠ 却下された形 ＝ 修正値

```
⚠却下：「電撃戦は突破力 ×1.15」「縦深防御は防御力 ×1.2」
   → ★思想②（外科的倍率・国別特例の禁止）そのもの
```

### ★★ 正しい形 ＝ 国力から軍への【変換】

```
⚠国力（人口・経済・技術）は変わらない
  → ★ドクトリンが「その国力から何人を、どんな装備で組織できるか」を決める
    → ⚠古いドクトリンは【小さい軍】か【低品質な軍】しか出せない
```

⚠⚠ **戦闘の式は1本のままである。**★ **押し合いも接触強度も戦死も、何も書き換えない。**

### ⚠⚠ tier と列 ＝ 編成上限

> ⚠ **用語注：**★ 本 doc では「フロンティア」という語を使わない。

> ⚠ ②**地理のフロンティア**＝未開拓の locked 州（★「未開拓地」という属性へ置換済み）
> ⚠⚠ ここでは **編成上限** と呼ぶ。

```

         ↑
         ｜  ＼                      ⚠tier4 の編成上限
         ｜   ＼  ＼                 ★tier3
         ｜    ＼   ＼  ＼           ⚠tier2
```

| ⚠ | ★ 意味 |

⚠⚠⚠ **＝ 「小さいか、低品質か」という作者の言葉が、⚠ そのまま編成上限の2軸である。**

## ★★★ §1-5 【修正】費用 — ⚠ 変更は【割合】／侵略は【実数】

> ⚠ 作者裁定：「★ **ドクトリンは変更コストは割合（国家規模にかかわらず修正可能）、⚠ 侵略コストは実数としよう**」

### ★ 余剰戦力は既に存在する

```csharp
Coefficients.cs:1033  ExpansionWillGrowth    = 0.5;    // ⚠四半期あたり ×(戦争熱−閾値)
Coefficients.cs:1034  ExpansionWillCap       = 10.0;   // ★貯蓄上限
Coefficients.cs:1120  ExpansionWillBourgeois = 0.4;    // ⚠ブルジョワ・ブロック力（★東インド会社の実体化）

// ★既存の消費先が3つ

Politics.cs:977    w.ExpansionWill  -= SuppressFactionWillCost;     // ⚠国内鎮圧（★2.0＝実数）
```

### ⚠⚠ 実数のままにしてはいけない理由 — ★ 同じ罠の記録が現物にある

```csharp
Diplomacy.cs:1834  // ⚠willCost=8+2M が ExpansionWillCap=10 とほぼ同額＝
                   //   ★標的軍M>1の実国が【恒久不能】だった構造の是正
```

⚠⚠⚠ **＝ 「実数の費用 ≒ 上限」にすると、⚠ 条件を満たせない国が【永久に】その行動を取れなくなる。**

★ **旧案で私は「⚠ 大きな軍ほど作り替えるのが高くつく」と書いたが、これは同じ罠である**——
⚠⚠ **大国は変更できず、⚠ 小国は貯まらないので変更できない＝誰も変更しない。**

### ★★ 決定

```
⚠ドクトリン変更 ＝ ExpansionWillCap × DoctrineSwitchFrac
                 ＝ 10 × 0.5 ＝ 5
   ★＝【上限に対する割合】。⚠国家規模にも軍の規模にも一切依存しない

★侵略・干渉 ＝ 実数（⚠現行のまま）
   ⚠willCost = 8 + 2M   // ★相手の大きさに応じた絶対量
```

### ⚠ なぜこの非対称が正しいか

| ★ 行動 | ⚠ 相手 | ★ 費用の形 | ⚠ 理由 |
|---|---|---|---|
| ⚠ **侵略・干渉** | ★ **他国** | ⚠ **実数** | ★ 要求量は【相手の大きさ】が決める |
| ★ **ドクトリン変更** | ⚠ **自国の軍** | ★ **割合** | ⚠ 自分の規模に比例するので、⚠⚠**割合で表せば規模が消える** |

⚠⚠ **＝ 対外行動は絶対量、⚠ 対内の作り替えは割合。**

### ★ 「現在の保有量の割合」ではない理由（⚠ 記録）

```
⚠案：cost = 現在の ExpansionWill × 0.5
   → ★保有0のとき費用0＝【無料で変更し放題】＝退化する
```

⚠⚠ **＝ 割合は【上限に対して】取る。⚠ そうすれば下限が立ち、★ 全国共通の定数になる。**

### ⚠ 効果 ＝ 費用は【門】でなく【テンポ】である

```
★満タン(10) → ⚠変更に5を払う → ★残5＝鎮圧2回分は残る
⚠3しか無い → ★変更できない（5に届かない）→ ⚠数年貯める
```

⚠⚠ **＝ 「⚠ 変更できない」ではなく「★ 変更すると他のことができない」。**

### ★★★ 取り合いから史実が出る

```
⚠植民地を取る ／ ★他国に干渉する ／ ⚠国内を鎮圧する ／ ★ドクトリンを変える
                  ⚠⚠全部が同じプール（上限10）を奪い合う
```

|---|---|---|
| ★ 清 | ⚠ 太平天国・回民・捻軍の鎮圧で使い切る | ★ **軍を近代化できない** |

## ⚠ §1-6 tier の解禁 ＝ 敗戦の記憶 × 技術水準 × 余剰戦力

### ★ 史実の証拠が1つに寄っている

```
⚠1871 仏が敗北 → ★参謀本部を作った
★1905 露が敗北 → ⚠軍改革
⚠1918 独が敗北 → ★電撃戦（1940）
★1940 仏は1918に【勝った】ドクトリンのまま → ⚠⚠敗北
```

⚠⚠⚠ **＝ 勝った国は変えない。★ 負けた国が変える。**

### ⚠ 3条件の積

```
★動機（敗戦の記憶）  → ⚠変えたくなる
⚠上限（技術水準）    → ★どこまで行けるか（⚠敗戦だけでは1800年に電撃戦へ行けてしまう）
★費用（余剰戦力）    → ⚠実際に変えられるか
```

⚠ **＝ 必要条件は【積】で合成する（思想⑪）。**★ **加算しない。**

⚠⚠ **技術の上限は既存の傾斜をそのまま使う**（★ `RecipeTechScale(onset, techLevel)` と同型）＝⚠ 閾値を新設しない。

### ★ バランス装置としても働く

⚠ **勝ち続ける国が硬直し、★ 負けた国が追いつく。**
⚠⚠ **＝ 覇権 snowball の抑制が、⚠ 外科的な係数でなく【歴史の因果】から出る。**

### ⚠ 提案の内容

★ 「⚠ 同盟の選好に思想距離を1項足せば、二極（冷戦）が創発するのではないか」


★ 座標（`Ideologies.BasePolityCoord`）と距離関数（`PowerAffinity.SupportAt`）は両方あり、⚠ 接続だけが無い。

### ⚠⚠ 却下の理由

> ★ 作者裁定：「⚠ **王政清と王政フランスが同盟を組むので**」

⚠⚠ **これは正しい。★ そして提案は【時代限定でない】ため致命的である：**

```
  → ★清・仏・墺・普・露が「思想が近い」ので組む
    → ⚠⚠ゲーム全期間が壊れる
```

★ **暦年で切れば思想②（外科的倍率・国別特例の禁止）と暦年ゲート禁止に違反する。**

### ★★★ 提案が間違っていた本質 ＝ 原因と結果の取り違え

⚠ **神聖同盟（1815 露普墺）は思想が近いから組んだのではない。**
⚠⚠ **【共通の敵（革命）】があったから組んだ。**

★ **冷戦の二極も同じである。**⚠ **思想が同じだから組んだのではなく、⚠⚠ 共通の敵がいたから組んだ。**

```

⚠そして脅威の共有は既に実装されている
  （Diplomacy の脅威チャネル＝ThreatGdpWeight / ThreatColonyWeight / ThreatMilitaryWeight）
```

⚠⚠⚠ **＝ 思想距離は【二極の結果】であって原因ではない。**
★ **結果を入力に置くのは悪い形⑬（二次的な値からの導出）そのものである。**
