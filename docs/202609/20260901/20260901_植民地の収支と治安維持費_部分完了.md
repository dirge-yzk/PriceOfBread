## §2 収益側 — 復旧せず削除する

### §2-1 根拠

作者裁定「植民地と本州で別のルールを適応したくない」に照らすと、
搾取率・採取費の分け前・捕囚市場・入植は**すべて植民地専用の収益ルール**なので、復旧は裁定に正面から反する。

### §2-2 これが「昇格の不連続」そのものを消す

```
現状：ColonyList にいる間だけ 搾取率・分け前・捕囚市場 が走り、
      州へ昇格した瞬間に全部消える  ← 大幅に計算が変わっているのは今
削除後：州は最初から最後まで同じ式で稼ぐ  ← 不連続ゼロ
```

### §2-3 撤去対象

```

  :247 捕囚市場・:268/269・:285・:289・:318 独立判定）＝約230行
読み手を失う係数 約25本（ColonialPayShare / ColonialSpendRate / ColonialMarketGoods /
  ColonySettlerRate / ColonialIndependenceMilitancy / ColonialHoldScale 等）
```

⚠ **維持費のブロック（`Colonial.cs:36-90` の `AccumUpkeep` と州分岐）は残す**（§3 で置き換えるまで）。

## §3 費用側 — 治安維持費

### §3-1 支配度を入力にしてはいけない

作者の問い「支配度・距離から算出するロジックでよいか」に対して、**向きが逆**である。

- `支配度` は現物に**存在しない**（`Dominance` で当たるのは `PartyDominance`＝一党支配と、海盆の敵支配度）
- それ以上に、**支配度は維持費を払った結果**である。費用を支配度から出すと二次的な値からの導出（悪い形⑬）になり、自己参照になる

```
正しい向き：
  抵抗 × 距離        → 必要な治安維持費
  払った額 ÷ 必要額  → 支配度（結果）
```

### §3-2 既存の形にそのまま乗る

```csharp
Crime.cs:20   double order = Math.Clamp(effCoerce / Math.Max(1e-9, pop * c.CrimeOrderPerPop), 0, 1);
              // 治安 ＝ 投入した強制力 ÷ 抑えるべき対象
```

**新しい形を作らない。** 治安維持費は同じ形の州版である。

### §3-3 式

```
治安維持費(州) = 抵抗(州) × ( 駐屯係数 × 物理距離 + 統治係数 × 情報距離 )

  抵抗(州)   = 州人口 × 闘争度        ← 既存の量（Crime.cs と同じ物差し）
  物理距離   = 首都 → 州              ← 兵・石炭・糧食が動く
  情報距離   = 首都 → 州              ← 命令と監督が動く

支配度(州)  = clamp( 実際に払った額 / 治安維持費, 0, 1 )
```

### §3-4 帝国のパラドクスがここから出る

```
電信を敷く → 情報距離↓ → 統治の費用↓ → 支配度↑
           → 同時に現地の識字層へ報せが届く → 闘争度↑ → 抵抗↑ → 費用↑
兵の展開は速くならない（物理距離は不変）→ 駐屯の費用は下がらない
```

**台本ゼロ。どちらにも正解が無い。** そして AI とプレイヤーで完全に対等。

## §4 適用範囲 — 全州

作者裁定「植民地と本州で別のルールを適応したくない」は維持費にも及ぶ。

| 州 | 距離 | 抵抗 | 費用 |
|---|---|---|---|
| 本国の近い州 | ≈0 | ≈0 | **≈0**（現行とほぼ恒等） |
| アイルランド・ポーランド・アルザス | 中 | **高** | **高** |
| 遠い植民地 | 大 | 高 | 最大 |

- **昇格の不連続がゼロ**（格が変わっても式が同じ）
- 格による分岐が消える＝「州は全て同じ型・従属は属性」へ前進（トリアージ `9-2`）
- **本国内の不穏な州が自動で費用を持つ**。英のアイルランド駐屯・露のポーランド駐屯は史実で実際に高くついた。
  植民地限定にすると、これが表現できない
- `ColonyUpkeepBase`（植民地専用の定数）が消える

⚠ **較正は動く。** 本国の州にも（小さいとはいえ）新しい支出が乗るため。単独バッチで測ること。

## §4-2 支払いは無言（スライダーを立てない）

> 2026-09-01 作者裁定：「植民地維持費は無言で支出に加えて良いと思う」

既存の福祉と**同型**にする。新しいレバーを1本も足さない（UI最小主義）。

```
必要額 ＝ 治安維持費(州)                      ← §3-3 の式（法や約束に相当）
払えた額 ＝ min(必要額, 財源上限)              ← 国庫が払えるだけ払う
支配度(州) ＝ clamp(払えた額 / 必要額, 0, 1)   ← Fiscal.cs:511 WelfareFunding と同じ形
```

⚠ 必要額が0のときの `0/0` を避けること（否定形ガード `!(need > 1e-9)` で支配度=1）。

### 正のフィードバックと、その終端

```
払えない → 支配度↓ → 税収効率↓ → さらに払えない
```

これは**正のフィードバック**であり、行政の死のスパイラルで一度刺された形である。
ただし今回は**終端がある**：

```
支配度が落ち切る → 分離圧力が保持力を超える → 州が離脱する → 費用ごと消える
```

**＝ 発散せずに離脱で終わる。** そして「しがみついた国が消耗し、手放した国が伸びる」が
報酬の台本なしに出る。AI とプレイヤーで完全に対等。

⚠ ただし実装時に確認すること＝**離脱までの間に国が死なないか**。
　 スパイラルの速さは「税収効率の落ち方」が決めるので、そこは逓減（1/(1+k(1−支配度))）で入れ、壁を置かない。

## §4-3 低支配度の帰結

> 2026-09-01 作者裁定：「低支配度は税収効率・治安悪化・高不満時の分離独立でよいのではないか？」

3つのうち**2つを採り、治安は帰結ではなく支配度そのものへ統合する**。

| 帰結 | 判定 | 理由 |
|---|---|---|
| **税収効率** | 採用 | 州ごとの徴税に支配度を掛ける。逓減で入れる（壁を置かない） |
| **治安悪化** | **統合** | 下記 |
| **高不満時の分離独立** | 採用 | `CheckSecession` の hold へ支配度を入れる。下記 §4-4 |

### 治安を別の帰結にしない理由

```csharp
Crime.cs:20   double order = Math.Clamp(effCoerce / Math.Max(1e-9, pop * c.CrimeOrderPerPop), 0, 1);
              // 治安 ＝ 投入した強制力 ÷ 抑えるべき対象   ← 国単位のスカラー
```

支配度も「投入 ÷ 抑えるべき対象」である。別に立てると**同じ概念が2つの型で実装される**（悪い形⑭）。

**処方＝支配度が州の治安そのものである。**
国単位の `w.PublicOrder` を、州別支配度の**人口加重平均**へ降ろす（導出量にする）。
`Crime.cs` は既に `foreach (var r in w.Regions)` の州ループを持ち、`order` だけが国単位なので形はそのまま。

⚠ これで量が1つ減る（新設ではなく**置換**）。`CrimeOrderPerPop` は支配度の分母へ吸収される。

## §4-4 独立判定 — 削除ではなく、既に走っていない

```csharp
Colonial.cs:278   if (w.SelfPower.ColonyList.Count > 0)   // ← ColoniesAreRegions=1 で空
Colonial.cs:281   double baseHold = Military * Readiness * ColonialHoldScale;
Colonial.cs:294   double distDecay = 1.0 / (1.0 + ColonialHoldDistanceDecay * km / DistanceNormalizeKm);
Colonial.cs:297   if (col.Militancy > ColonialIndependenceMilitancy && col.PopSize*col.Militancy > hold)
```

**2026-08-26 以降1度も発火していない。** 片づけるのは死骸であって、機能の削除ではない。

**代わりは既にある**：

```csharp
Politics.CheckSecession   foreach (var r in w.Regions)
                              if (r.State != Active || r.Id == 0) continue;   // 首都だけ除外
```

＝ **植民地格の州も既に分離独立の対象**。道は事実上もう1本になっており、
トリアージ `2-8`（CheckSecession への一元化）は**半分達成済み**である。

### 残っている穴 ＝ hold に距離項が無い

```csharp
Politics.cs   hold = w.Legitimacy / (1 + w.TotalPopulation * c.SecessionHoldPerPop);   // 国単位・距離項なし
```

地球の裏側の州と隣の州が同じ保持力で抑えられている。
（`SecessionHoldDistanceDecay` は現物に**存在しない**＝トリアージ `2-8` が指摘した非対称。）

**支配度がちょうどこの欠けた項である。** 州ごとの支配度を hold に掛ければ、
距離・抵抗・財政が1本で分離圧力に効く。`Colonial.cs` 側の帝国的な式（軍×即応度×距離減衰）は不要になる。
