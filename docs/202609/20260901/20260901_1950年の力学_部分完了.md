## ★★ §2 核抑止 ＝ 開戦判断に「予想損害」が入る場所が無い

### ⚠ §2-1 材では原理的に出ない

★ **核兵器を【材】として足しても、⚠ 出てくるのは「持つと軍事力が上がる」だけである。**

⚠⚠ **核の本質は【使わないことで効く】ことなので、⚠ 保有量が戦力に足し込まれる形では表現できない。**

### ★ §2-2 現物の確認 ＝ 開戦は緊張の蓄積だけで決まる

```csharp
Diplomacy.cs:1165  // 緊張100以上が WarTriggerMonths 続いたペアを開戦（攻守区別なし）
```

⚠⚠ **＝ 開戦判断に【戦争の予想損害】が入る場所が一切ない。**

```
★勝敗の期待値 → 読んでいない
⚠被害の期待値 → 読んでいない
★読んでいるのは：緊張の蓄積・厭戦ゲート・休戦期限 だけ
```

⚠ **＝ 核を材として足しても、⚠⚠ 開戦の式には触れないので抑止は絶対に出ない。**

### ⚠⚠ §2-3 処方 ＝ 既存の【同じゲート】に乗せる

★ **厭戦は既に開戦を止めている**（`WarWearyThreshold`）。⚠ **そこへ「まだ戦っていない戦争の疲れ」を足す。**

```
★現行：厭戦（戦った結果の疲れ）     → WarWearyThreshold → 開戦しない
⚠追加：予想される被害（戦う前の恐れ） → 同じゲート        → 開戦しない
```

⚠⚠ **＝ 新しい型を作らない。⚠ 書き手も増えない（思想⑫「一つの量には一つの書き手」に合格）。**

### ★ §2-4 8/27 の「相手の予想」にそのまま乗る

⚠ **8/27 §14-12 で「相手が総動員/残虐行為をどう設定するかの予想」を設計済み。**★ **核抑止はその予想の一用途にすぎない。**

```
⚠相手が残虐行為をONにすると予想
  → ★核が使われると予想
    → ⚠予想死者が跳ね上がる
      → ★開戦前の厭戦がゲートを割る
        → ⚠⚠開戦しない
```

### ⚠ §2-5 これで出る史実（★台本なし）

| ★ 状況 | ⚠ 出る挙動 | ★ 理由 |
|---|---|---|
| ⚠ 核保有国 × 核保有国 | ★ **直接戦争が起きなくなる** | ⚠ 双方の予想死者が跳ね上がる |
| ★ 核保有国 × 非保有国 | ⚠ **戦争は起きる** | ★ 相手に報復力が無い＝予想死者が上がらない |
| ⚠ 非保有 × 非保有 | ★ **従来どおり** | ⚠ 予想損害の項がゼロ＝厳密恒等 |
| ★ 片側だけ保有・相手に同盟核国 | ⚠ **抑止が効く** | ★ 同盟の参戦が予想に入る＝傘 |

⚠⚠⚠ **＝ 「1945年以降、列強同士が直接戦わなくなり、⚠ 代理戦争だけが残る」が暦年ゲート無しで創発する。**

### ★ §2-6 連続性の確認（思想⑩）

⚠ **閾値を置かない。**★ **予想損害は連続量：**

```
予想被害 ＝ 相手の非人道兵器の保有量 × 相手が残虐行為をONにする予想確率 × 接触強度
```

⚠ **＝ 核を1発持った瞬間に世界が変わるのではなく、⚠⚠ 保有量が増えるほど滑らかに抑止が立つ。**
★ **そして残虐行為の許可（8/27）と同じく片道ラチェットではない**——⚠ 保有量が減れば抑止も減る。

### ⚠ §2-7 主フラグ

```
NuclearDeterrenceWeight = 0.0   // ★0で1命令も走らない厳密恒等（思想③）
```

⚠⚠ **1783〜1934の較正には一切触れない**（★ 非人道兵器の保有量が0の時代は項が消える）。

## ★★ §4 なぜ植民地が負債になったのか

### ⚠⚠ §4-1 前提の訂正 ＝ 「1945年に反転した」のではない

★ **多くの植民地は【もともと本国の財政には赤字】だった。**

```
⚠Davis & Huttenback『Mammon and the Pursuit of Empire』(1986) の英帝国研究
   → 帝国防衛費は全納税者が払い、収益は少数の投資家に入った
   → ★本国全体では【移転】であって利得ではない

⚠Marseille『Empire colonial et capitalisme français』(1984) の仏帝国研究
   → 1930年代には帝国は仏資本主義の【ブレーキ】になっていた
```

⚠⚠ **＝ 反転したのではなく、【隠せなくなった】。**

★ **したがって設計上の問いは「いつ反転するか」ではない。**
⚠⚠ **「何が収支を隠していて、何が隠せなくしたか」である。**⚠ **4つの成分に分かれる。**

### ⚠ §4-2 成分1：独占市場の価値 ← **世界が豊かになると薄まる**

★ 捕囚市場が価値を持つのは「そこでしか売れない」時だけである。

⚠ **植民地は貧しい。**⚠⚠ **豊かな国同士の貿易のほうが儲かる。**

```
★1850年：本国の市場 ≒ 植民地の市場         → ⚠独占に意味がある
⚠1950年：西独1国の購買力 ≫ 帝国全体の購買力  → ★独占が誤差になる
```

⚠⚠ **戦後に最も速く伸びた貿易は【富裕国どうし】であって、⚠ 本国-植民地ではなかった。**

★★★ **＝ 分母（世界の購買力）が育つと、分子（植民地の購買力）の相対価値が落ちる。**
⚠ **これは【比】なので暦年ゲートを要さない。**

### ★ §4-3 成分2：独占原料の価値 ← **代替材が発明されると消える**

```
⚠合成染料（1856〜）              → 藍のプランテーションが死ぬ
★合成硝石（ハーバー・ボッシュ1913） → チリ硝石が死ぬ
⚠合成ゴム（1930s）               → マレーのゴム独占が死ぬ
★石油                           → そもそも旧植民地帝国の【外】にあった
```

⚠⚠ **＝ 技術水準が上がると、特定産地への依存が下がる。**

★ **これは現物の【並存レシピ】で完全に表現できる**（⚠ §8）。

### ⚠⚠ §4-4 成分3：鎮圧費 ← **被支配側の発展とともに上がる**（★本命）

★★ **そしてこれは【皮肉の構造】を持つ：**

```
⚠搾取するには開発が要る（港・鉄道・学校・行政）
  → ★開発は識字・都市化・新聞をもたらす
    → ⚠識字・都市化・新聞は【組織された抵抗】をもたらす
```

⚠⚠⚠ **＝ 植民地は、自分を追い出す人間を自分で育てる。**

★ **加えて、火器の非対称が消える（技術は伝播する）：**

```
⚠1898 オムドゥルマン     英戦死は数十人 ／ 相手は槍と旧式銃
★1954 ディエンビエンフー  仏は要塞ごと壊滅 ／ 相手は【砲兵】を持っていた
```

⚠ **そしてゲリラ戦は費用非対称を【反転】させる**——★ 安い兵器で高い軍を消耗させる。

⚠⚠ **＝ 8/27『研究＝解禁の唯一の形』§5「伝播＝貿易×メディア」がそのまま効く。**

### ★ §4-5 成分4：兵員価値 ← **生産力戦になると消え、しかも反転する**

```
⚠歩兵の時代    ：植民地は常備軍を供給した       → ★資産
★生産力の時代  ：人数は戦車を作らない           → ⚠無価値
⚠⚠戦後       ：動員した植民地兵が独立運動の中核 → ★負債
```

### ★★★ §4-6 結論 ＝ 4成分のうち3つは【発展の関数】

| ⚠ 成分 | ★ 何の関数か | ⚠ 向き |
|---|---|---|
| ① 独占市場 | ★ **世界全体の発展** | ⚠ 上がるほど価値が**下がる** |
| ② 独占原料 | ⚠ **技術水準** | ★ 上がるほど価値が**下がる** |
| ③ 鎮圧費 | ★ **被支配側の発展** | ⚠ 上がるほど費用が**上がる** |
| ④ 兵員 | ⚠ **戦争の形（生産力化）** | ★ 進むほど価値が**下がる** |

⚠⚠ **暦年ではない。**

```
★発展が遅い世界 → 1900年でも植民地は黒字のまま
⚠発展が速い世界 → 1880年でも赤字になる
```

⚠⚠⚠ **これが正しい挙動であり、⚠ 暦年ゲートを1本も書かずに済む（思想⑧に合格）。**

★ **そして①②③はいずれも「植民地を保有し開発すること自体」が引き起こす**
⚠⚠ **＝ 自壊の構造が保有側の行動から創発する。**

## ⚠ §7 処方

### ★★ §7-1 処方B（推奨）＝ 植民地項を収支にする

```
植民地項 ＝ ColonyBalanceGate × Σ_植民地 ( 収益 − 費用 ) / スケール

⚠収益 ＝ 送金（支配度 × 経済規模）                       ← 8/28 §14 の支配度
       ＋ 捕囚市場（col.Savings × ColonialSpendRate）    ← Colonial.cs:220（既存）

★費用 ＝ ColonyUpkeepBase × (1 + ColonyUpkeepMilitancyScale × 闘争度)   ← 既存
       ＋ ColonyUpkeepCoalPerDist × 距離                              ← 既存
       ＋ ColonyUpkeepFoodPerDist × 距離                              ← 既存
```

⚠⚠ **新しい定数はゼロ。⚠ 右辺は全て既存の量である（思想⑨に合格）。**

```
ColonyBalanceGate = 0.0   // ★0で現行と厳密恒等（主フラグ・思想③）
```

### ⚠ §7-2 処方A（最終形）＝ `ColonyWeight` を削除する

★ **測って問題が無ければ、⚠ 加算項そのものを消す。**

⚠⚠ **理由：収支は既に GDP・国庫・物理消費に全部流れている。**

```
★送金・捕囚市場 → 本国popの所得 → GDP↑・満足度↑ → 既に NationalScore.Wealth に入る
⚠維持費        → 国庫から流出   → 他の支出を圧迫  → 既に効いている
★石炭・糧食    → 物理消費      → 市場から消える  → 既に効いている
```

⚠⚠⚠ **＝ `+ Colonies × 1.5` は【上振れだけを二重に数えている】。**

⚠ **副産物：`Diplomacy.cs:1757` の自己強化ループが消える。**

### ★ §7-3 推奨の順序

```
⚠① ColonyBalanceGate = 0 で実装（★厳密恒等を確認）
★② 0 → 0.5 → 1.0 と掃引して列強序列の帯を測る
⚠③ 収支項が安定したら ColonyWeight を削除（★処方A）
```

⚠ **この engine の作法（新機構は必ず0で恒等から入る）に合わせる。**

### ⚠⚠ §7-4 これで出る史実（★台本なし）

| ⚠ 状況 | ★ 収支 | ⚠ 理由 |
|---|---|---|
| ★ 小人口・高レント・低識字の産物植民地 | ⚠ **黒字** | ★ 鎮圧費が小さく独占レントが大きい |
| ⚠ 巨大人口・巨大送金・巨大駐留 | ★ **ほぼトントン** | ⚠ Davis & Huttenback の結論と一致 |
| ★ 高識字・高都市化・高闘争度の植民地 | ⚠ **大赤字** | ★ `ColonyUpkeepMilitancyScale` が2〜3倍に効く |
| ⚠ 代替材が発明された産地 | ★ **赤字** | ⚠ 独占レントが消え費用だけ残る |
| ★ 遠い植民地 | ⚠ **赤字になりやすい** | ★ 石炭・糧食が距離比例 |

### ★★★ §7-5 最も重要な副産物 ＝ 「手放す」が【選択】になる

⚠ **現行、独立は闘争度だけで決まる**（`ColonialIndependenceMilitancy = 0.85`）
★ **＝ 植民地は「出ていく」ものであって、⚠ 本国が「手放す」ものではない。**

⚠⚠ **収支が可視化されると、宗主側に初めて【判断】が生まれる：**

```
★赤字の植民地を抱え続ける  → ⚠国庫と兵を消耗し、本国の発展が遅れる
⚠手放す                   → ★送金は消えるが、駐留軍と予算が本国へ戻る
```

⚠⚠⚠ **＝ 「手放した国が伸び、⚠ しがみついた国が消耗する」が、★ 報酬の台本なしに出る。**

⚠ **そしてこれは AI とプレイヤーで完全に対等である**（思想⑤）。
