# 支配度は【ストック】にする — 2026-09-03 の再裁定（★設計・未実装）

> ★作者「支配度は根源的な値から導出するという裁定をしたが、これは正しいか？
> **ストック性にして、常に減衰を上回るコストを払い続けられるか**、の方が史実に近い気がする。
> 根源的な値から導出すると、**戦争で軍隊が大幅に減少した瞬間に、全ての植民地が同時に独立する**ようなことが起こるのではないか」

## 1. ★結論＝作者の指摘は正しい。そして仕様書は**半分だけ**それを既に言っていた

原典 `docs/202608/20260828_従属の一般化_部分完了.md` は §14 で「導出」と書いたあと、**§15-0 で自分を訂正している**。

```
⚠①支配力【述語】     ＝ 行政力×0.5 + 軍事力×0.5  → 徴税・秩序・送金・関税権 → 【即座に変わる】
★②同化度【ストック】 ＝ 世代交代・教育・通婚      → 割譲後に上がる/上がらない → 【数十年かかる】
⚠③離脱圧力【述語】   ＝ 現地POPの闘争度 × 規模 × (1−②) → 独立
```

★§15-1 の論拠＝「行政力も軍事力も**既に二次ストック**なので、支配力自身がストックである必要はない」。
　史実の裏取りも正しい＝**オスマン1875の財政破綻で地方の徴税は即座に崩壊**・清の太平天国で中央の徴税が即座に落ちた・露1917で数週間で地方行政が消滅。

⚠**しかし、この訂正は「支配の軸」からストックを消してしまった。**
　②同化度は「**我々になったか**」の軸であって、「**まだ押さえているか**」の軸ではない。
　同化しない領土（英領インド）は ②≈0 のまま150年保たれた。それを保っていたのは①だけ、ということになる。
⇒ ①が即座に落ちる量である以上、**軍が壊滅した瞬間に、未同化の領土が一斉に離脱する**＝作者の指摘した破綻がそのまま起きる。

## 2. ★史実＝支配は在庫である（4例）

| 例 | 支配力の崩壊 | 実際の独立 | 差 |
|---|---|---|---|
| スペイン帝国 | 1805 トラファルガー・1808 仏軍侵入 | 1810〜1826 に地域ごと | **16年** |
| イギリス | 1945 財政破綻・復員 | 印1947・馬1957・ケニア1963・アデン1967 | **22年** |
| フランス | 1940 完全な軍事的敗北 | ⚠植民地は独立していない（宗主が替わっただけ） | — |
| ★ポルトガル | 慢性的に欧州最貧＝支配力は常時低い | アンゴラ・モザンビーク **1975** まで保持 | **数十年** |

★**ポルトガルが決定的**。「根源的な値から導出」する限り、ポルトガルは19世紀のうちに帝国を失っていなければならない。
実際に帝国を終わらせたのは**本国の政治**（カーネーション革命）であって、国力の帳尻ではない。

⚠逆向きの検算＝§15-1 が挙げた3例（オスマン1875・清・露1917）は**どれも「徴税と秩序」の話**であって、
　「領土の喪失」の話ではない。⇒ **①が述語で正しい**ことと、**支配の水準がストックである**ことは両立する。

## 4. ★再裁定＝3量を4量にする（①は述語のまま・支配の軸にストックを1本足す）

```
①支配力【述語・即座】   ＝ 行政力×0.5 + 軍事力×0.5     → 徴税・秩序・送金・関税権（§15-0のまま）
★②支配度【ストック】    ＝ 前期の支配度 + (引き留め − 離脱圧力) × 速度
                          → **独立はこれが0に達したとき**（§14-6 が既に書いていた形）
③同化度【ストック・数十年】＝ 世代交代・教育・通婚          → 離脱圧力を下げる
④離脱圧力【述語】       ＝ 現地POPの闘争度 × 規模 × (1−③) × 距離
```

★これで作者の言う「**常に減衰を上回るコストを払い続けられるか**」がそのまま形になる＝
　引き留め（駐留・行政費・投射）を払い続ける限り②は保たれ、払えなくなった年から**下り始める**。

⚠**守るべき条件（これを外すと逆の破綻が出る）**
1. **減衰の速度は根源的な値が決める**＝ストックにしても「死んだ帝国が永久に保たれる」を許さない。
   ★水準はストック・**速度は述語**、という分担にする（§14-5 の狙いはここで生きる）。
2. **「支配度を上げる」ボタンは作らない**＝プレイヤーが動かすのは駐留・行政費・講和条件だけ。§14-5 の裁定はこの点で有効。
3. 一つの量には一つの書き手＝②を書くのは統治ステップの積分1箇所だけ。
