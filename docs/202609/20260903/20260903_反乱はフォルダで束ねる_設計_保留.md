# 反乱は「結合」でなく「同じフォルダ」＝作者裁定 2026-09-03（★設計・未実装）

> ★作者「『反乱の結合』は実装が不必要に複雑化する恐れがある。同じ反乱になるのではなく、
> **同じフォルダに入る→反乱鎮圧コストが合計になる**、といった実装の方がスマートではないか」
> ★追記「今後、政党の属性を増やした際、**同じギミックで連立政権を表現できる**気がする。これはまだ実装しなくてよいが、アイデアとして記録」

## 1. 現物（＝何を置き換える話なのか）

`Factions.Step` の**段6「合流」**（2026-08-30 実装）。⚠**是正2026-09-08**：本docは `FactionMergeRangeKm = 0` で休眠と書いていたが、現物は `Coefficients.cs` の `FactionMergeRangeKm = 800.0`＝**点火済み**（2026-08-30の合成先行で点火）。以下の「休眠だから安全」を前提にした記述は読み替えること。

```
条件＝同ブロック × 同イデオロギー × 変異状態の一致 × 距離がFactionMergeRangeKm以内
処理＝大きい方が小さい方を吸収（結束を継ぎ足し・怨嗟は深い方が残る）／小さい方は結束0で次の掃除で消滅
```

⚠**現行実装の問題は3つある。**

1. **消える**。吸収された運動は結束0にされ、忘却経路で消滅する＝パネルからも年代記からも居なくなる。
2. **条件が厳しすぎて、史実の面白い合流がひとつも起きない**。同ブロック**かつ**同イデオロギー**かつ**同じ変異状態が要る
   ＝合流できるのは**ほぼ同一の運動だけ**。⚠キール軍港の水兵反乱＋労働者評議会（1918独）や、太平天国＋捻軍のような
   **異質な運動が同じ敵に向かう**形は、定義上いつまでも起きない。設計の狙い（§革命と独裁の類型 欠落C）に届いていない。
3. **走査が O(N²)＋整列＋連鎖防止の HashSet**＝「1四半期1件」を守るためだけの機械が要る。

## 2. ★裁定＝フォルダ方式を採る

**運動は消えない。同じ「戦線（フォルダ）」に入るだけ。国家が払う鎮圧コストがフォルダ単位で合計になる。**

★これが良い理由は4つ。

1. **実体を壊さないので、参照の後始末が要らない。**⚠当プロジェクトで最も高くついた失敗は「型の統合が起こす静かな破損」
   （2026-08・旧 `ColonyList` の読み手49箇所が沈黙）である。**実体の統合は、参照を持つ全員を直す仕事**を必ず連れてくる
   （`RevoltingFaction`・セーブ・UIパネル・年代記）。フォルダは**タグを1つ足すだけ**なので、その仕事が発生しない。
2. **物理として、こちらの方が正しい。**⚠太平天国と捻軍は「1つの生き物になった」のではない。
   **国家が同時に2つを相手にしなければならなくなった**のである。効くのは国家の側の分母であって、反乱側の同一性ではない。
3. ★**同じ形が既にこのコードベースにある**＝`ColonialHoldSharedArmy`（同時多発の按分＝分母 `1+k×(不穏数−1)`）。
   植民地で「同時に起きた不穏は駐留軍を割る」を既に書いている。⚠新しい写像を作らずに同じ形を国内へ広げるだけになる。
4. **異質な運動を同じフォルダに入れられる**＝1の条件（同ブロック×同イデオロギー）を捨てられる。
   フォルダの結成条件は**敵が同じ（＝同じ国家に向かっている）ことと、距離**だけでよい。水兵＋労働者評議会が出る。
   ⚠解散も自明＝タグを外すだけ（合流だと「分裂」を別機構として書く羽目になる）。

### 実装の骨子（★着手時に書くこと。まだ書いていない）

- `FactionState` に**フォルダの鍵を1つ**（同じ鍵＝同じ戦線）。⚠新しいリストや新しいクラスは作らない（規律「分割禁止・削減方向」）。
- 鍵の決め方＝距離と「同じ国家に向かっている」ことだけ。⚠イデオロギーは**見ない**（そこが現行との違い）。
- 読み手は**国家の側**＝鎮圧の判定でフォルダの強さを合計し、保持力を `ColonialHoldSharedArmy` と同型の分母で割る。
- 勝ったときに誰が政権を取るかは**フォルダ内の最強**（1行の規則）。⚠合流だと「吸収後の主体」を作り込む必要があった。
- ⚠既定0で厳密恒等（休眠）。点火はバランスのラウンド。
- ★段6（現行の合流）は**この置き換えが点火できたら削除**する（両方を残さない＝規律「重複は片方を消す」）。

## 3. ★連立政権への転用（作者追記・⚠実装しない・記録のみ）

★**同じギミックで連立政権を表現できる**＝「別々の実体が、同じフォルダに入り、合計で閾値を越える」。
反乱では**国家の鎮圧コストが合計**になり、議会では**議席が合計**になる。⚠形は同じである。

⚠現行の連立は近似で置いてある＝`CoalitionWeakensPlatform`（与党議席<0.5なら綱領を議席比で弱くしか通せない）。
★これは「連立相手が誰か」を持たない**代理変数**であって、フォルダを入れれば**本物に置き換えられる**
（誰と組んだかで通る政策が変わる＝現行は「弱くなる」しか表現できない）。

⚠その際に必ず直すこと＝AUD-09③で見つけた**綱領の str 迂回**（自由党の関税と、自由/社会の福祉が生代入で連立妥協を通っていない）。
器は `CoalitionCoversContinuousTargets`（休眠0）で入れてある。**フォルダを入れる前に、まず全部が str を通る状態にしておく**
＝そうでないと「連立相手が誰か」を実装しても、効かない軸が残る。

★政党側に要る属性（着手時の見取り）＝イデオロギー座標（既にある）・譲れない一線（新規）・組める相手（座標距離から導出＝新しい表を作らない）。
