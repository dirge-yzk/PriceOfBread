## 4. 疑いのある変更（wave2 適用137件のうち、残骸国家/POPの受け手集合に触ったもの）

⚠ 未検証。ここから二分探索を始めるのが早い。

1. **`Territory.cs:25`**（medium）＝Territory 独自の `DistributeToPops`（`w.Regions` を直接走査＝**分離凍結中(Seceded)州のpopも受け手に含めていた**）を
   `Colonial.DistributeToPops`（`AllPops()` 基準＝Seceded を除外）へ統一。
   → **受け手集合が変わった**。残骸国家＝州がほぼ Seceded なら、受け手が0件になりうる。**最有力**。
2. `Colonial.cs:373` ＝上記のため `DistributeToPops` を private → internal へ（変更そのものは無害）。
3. **`CrownParliament.cs:308`** ＝`AccumulatePopConsciousness` の州ループに `if (r.Seceded) continue;` を追加。
   → 国民意識の分子/分母を `AllPops` に揃えたが、残骸国家で**全州が Seceded なら意識が積まれない**。
4. `Fiscal.cs:545` ＝年金配分を受け手リストと分母を同一フィルタで作り直し（`elderSize`）。受け手0件のときの挙動を要確認。

1. **再現**：`selfplay-batch 30 "" 0 1 604` の seed28（マレー）が最短。より速い再現は
   `selfplay 28 604` 系のプローブで残骸国家の満足度を直接見る。
2. **切り分け**：`scratchpad/wave2_applied.md` に137件の適用記録がある。§4 の1→3→4 の順に
   1件ずつ `snap_w1`（wave1完了時のスナップショット）へ戻して再測定。

3. **観点**：満足度0.00 は「受け手が0件で分配が届かない」か「分母が0で比が定義されない」のどちらか。
   §4-1 と §4-3 はどちらも**受け手集合から Seceded を外した**変更なので、残骸国家＝全州 Seceded の場合に
   空集合になる可能性がある。`Colonial.DistributeToPops` の受け手0件時のフォールバック（国庫残置）が
   残骸国家で常に発動していないかを最初に見る。
