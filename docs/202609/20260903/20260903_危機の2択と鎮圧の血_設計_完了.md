# 国内危機を2択にする／鎮圧に血を流させる — 作者裁定 2026-09-03（★器を投入・点火待ち）

> ★作者「無数の反乱勢力をちくいち鎮圧ボタンで下げるのは面倒。戦争と同様に、閾値まで伸びた際に
> **『受諾する』『鎮圧する』の2択ダイアログ**を出すのがプレイ感として優れていそう。
> **反乱コストは規模による→払えない場合は受諾せざるを得ない**」
> ★続「**最も暴力的な集団（政権打倒）は絶対に受諾できない→鎮圧するしかない。その鎮圧コストを払えないなら、政権は崩れる**」
> ★続「反乱の鎮圧は人が死にますか？ **差し向けられる軍隊と反乱軍（軍質の低い自国民）の疑似的な戦争**で処理するのが良いのでは。
> **独自経路を作るべきではないか**」
> ★別軸「ビスマルク式（別の法を通して本命は通さない）は**ダイアログではなく、プレイヤーが気付いて行うべき領分**」

## 1. ★実測（`firecheck 400`＝seed 1789・100年・61カ国）

```
機構                       試行     成立
FactionConcede               19        1   成立率 5.3 %
FactionSuppress              19        0   ★一度も起きない
FactionCompensate            19        0   ⚠計器の穴（AI側の分岐に刺し忘れ・修正済み）
FactionRevolt                19        0   ★一度も起きない
```

⚠**内訳の合計が分母に合わない**ことから、AI側のビスマルク分岐に計器を刺し忘れていたのが分かった。
★**この「合計が分母に合うか」という読み方自体が番人として効いている**（本日3例目＝プローブの隔離／試行と成立の粒度／今回の刺し忘れ）。

★確定＝**鎮圧0回・蜂起0回・危機は100年で19回だけ**。国内危機の subsystem はほぼ不活性。

## 2. ★鎮圧では一人も死なない（現物）

現行コードのコメントが明言している——「鎮圧は闘争度に触れず、その回の蜂起を打ち消して**余剰戦力を消費するだけ**（勢力は残り再燃）」。
代償は余剰戦力（`SuppressFactionWillCost`）と正統性のみ。⚠死者があるのは**蜂起（内戦）になった場合だけ**で、
そちらには `CivilWarCivilianToll` があり「太平天国の主死因は戦闘でなく飢餓・虐殺・流民」と書かれている。

### ⚠史実（§9 の検算）＝鎮圧こそが19世紀最大の死因

| 事件 | 死者 |
|---|---|
| ピータールー 1819 | 18人・負傷約700 |
| ニューポート蜂起 1839 | 約22人 |
| 六月蜂起 1848（パリ） | 戦闘で約3,000・その後1万人超が逮捕/流刑 |
| パリ・コミューン 1871「血の一週間」 | 1〜2万人 |
| ★**太平天国 1850-64** | ★**2,000〜3,000万人**（19世紀最大） |

⇒ 血の流れない鎮圧は**人口の次元に直接効く穴**である。

## 3. ★裁定の実装（4つの器・すべて休眠0）

| 器 | 中身 |
|---|---|
| `SuppressIsCivilWar` | 鎮圧を**既存の内戦経路**（`CivilWarAsWar`＝反乱国家を建てて戦争システムで戦う・点火済み）へ落とす。⇒ 択は自然に「受諾するか、戦うか」の2つになる。★**独自経路を作らない**＝作者裁定そのまま |
| `SuppressCostFromScale` | 鎮圧の値段を**規模比例**へ（定額×(1+k×(勢力÷実効保持力−1))）。⚠この比は危機の判定で既に計算済み＝新しい量を作らない |
| `CrisisConcedeBlockedForRegimeChange` | **体制転覆を求める相手には受諾も埋め合わせも許さない**（＝鎮圧するしかない）。⚠AIは元から体制内の要求しか受諾しない＝これでプレイヤーと対称 |
| （UI・未着手） | ダイアログを2択へ。⚠ビスマルク式は**選択肢から外す**＝法律画面から通す操作と同じ経路なので、**手段は失われず**「気付いて行う領分」になる |

★併せて `World.PendingFactionCrisisCost` / `PendingFactionCrisisIsRegimeChange` を追加＝
UIが**値段を表示**し、余剰戦力が足りなければ「鎮圧する」を出さない＝「払えないから受け入れるしかない」が**画面の上で分かる**。

## 4. ⚠点火時に見ること

- **規模で伸縮するか**＝ニューポート（死者22人）が全国内戦にならないこと。物差しは「勢力÷実効保持力」がそのまま使える。
- **人口の次元**＝太平天国級が出ると清の人口が史実方向へ動くはず（現在の逸脱の一因）。
- **上からの改革は残すこと**＝史実の三本道（先回りの改革／鎮圧／崩壊）のうち、`ReformFromAboveEnabled` の経路は塞がない。
  ⚠明治1868・独1918・英1832 はいずれも「体制が自分を作り変えて生き延びた」形である。
- ★点火後は無血鎮圧の分岐（`SuppressFactionWillCost` / `FactionSuppressionOmit`）が**到達不能**になる＝削除できる（削減方向）。
