# 反乱の経路を1本にする＝作者裁定 2026-09-03（★設計・実装は段1のみ）

> ★作者「植民地反乱も、現在の反乱と同じルートに合流させたい」
> ★作者「つまり、**あらゆる反乱は1つの経路で発生し、1つの方法で対処する**形式にする。**植民地反乱と国内反乱でルールが異なるのはダメ**」

## 1. 現状＝経路が3本ある（うち1本は死んでいる）

| 経路 | 主体 | 実測 |
|---|---|---|
| ⚠①`Colonial` の独立判定 | `Power.ColonyList` の帳簿行 | ★**完全に死んでいる**＝`firecheck` で131年・**試行0**（一度も評価されていない）。`ColonyList` が常に空 |
| ②`Politics.CheckSecession` | 州（Tierを問わない） | 生きている。⚠ただし `SuffrageScopeGate` で `Tier==Colonial` を見る分岐が1つある |
| ③`Politics.CheckFactionRevolt` | 組織運動（`FactionState`） | 生きている（太平天国型） |

★①が死んでいる理由＝植民地が**州へ昇格**して `ColonyList` から居なくなったため。
⚠**同じ根で反帝世論も死んでいる**（`firecheck`：試行20,283・**成立0**）＝旧型の読み手が残っている（型の統合が起こす静かな破損）。
⇒ ①に付いていた物理（距離減衰・駐留軍の按分・搾取×識字の弁証法）は、**誰にも効いていない**。

## 2. ★裁定＝「植民地だから」という条件を**1つも書かない**

⚠植民地が離れやすいのは**格が違うから**ではなく、**遠いから**である。
⇒ 分離の判定に「植民地なら」を足すのは**規則を2本にすること**であって、作者裁定に反する。

### ★保持力は「軍が届く分だけ」効く

エンジンには既に「軍が届くか」の物差しが**1本だけ**ある＝`Diplomacy.Projection`
（`1/(1+DistanceWarDecay×km/DistanceNormKm)` × 海越えなら制海権）。
`Diplomacy.cs` 自身が「**その物差しはエンジン内で1本のままにする**」と宣言している。⇒ それを州へ当てる。

```
分離の成立条件（現行）： 圧力 > 閾値 かつ 圧力 > 保持力
分離の成立条件（是正）： 圧力 > 閾値 かつ 圧力 > 保持力 × 投射（首都→その州）
```

★これだけで、格を1度も見ずに次が全部出る。

| 州 | 投射 | 帰結 |
|---|---|---|
| 隣接州 | ≈1 | ⚠**従来どおり**（＝較正が壊れにくい） |
| シベリア・西部辺境 | 中 | 遠い辺境は保ちにくい（★国内にも同じ規則が効く＝ここが要点） |
| インド・ジャワ | 小 ×**制海権** | ★**海軍を持たない国は海外領を保てない**＝史実の規則が、植民地という語を使わずに出る |

⚠副産物として `SuffrageScopeGate` の `Tier==Colonial` 分岐も**要らなくなる**方向＝代表を得た州が離れないのは
既に `SecessionConsciousnessWeight`（国民意識の割引）が一般形で持っている。⇒ 段3で統合を検討する。

## 3. ★同時多発は「フォルダ」で足す（→ 20260903_反乱はフォルダで束ねる_設計_保留.md）

⚠1つの帝国で植民地の蜂起と本国の蜂起が同時に起きたとき、**国家の軍は割れる**。
これも格を見ない＝「同時に起きている運動の合計に対して保持力が割れる」だけ。
★既存の同型＝`ColonialHoldSharedArmy`（分母 `1+k×(不穏数−1)`）。⇒ 一般化してフォルダの分母にする。

## 4. 消すもの／残すもの

- ⚠`Colonial` の独立判定と植民地POPの弁証法（搾取×識字→不満）は、**一般の州の不満**へ吸収する。
  ⚠ただし `ColonyList` は同名衝突時のフォールバックで非空になり得る（B-08実測＝1件・**J-006 の裁定待ち**）。
  ⇒ **削除は J-006 の後**。それまでは新経路と併存させず、旧経路は休眠側に置く。
- ★`CheckFactionRevolt`（組織運動）と `CheckSecession`（州の分離）は**別の主語**（運動 vs 土地）なので1本にしない。
  ⚠作者裁定の「1つの経路」は**植民地と国内で規則を分けない**という意味であって、
  「運動の蜂起」と「州の分離」を同じ関数にしろという意味ではない（両者は既にどちらも内戦→建国の同じ出口へ落ちる）。
