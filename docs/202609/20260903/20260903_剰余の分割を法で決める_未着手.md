# 剰余の分割を法で決める — トリクルダウンを機構でなく制度の帰結にする

> 2026-09-03 ／ 作者裁定
> 「私はトリクルダウンは発生しない（歴史上、機能したことがない）と考えている」
> 「政府の補助金は、産業の効率化つまりは少人数化に機能し、労働者の賃金を上げる方向に作用することはない」
> 「資本家を富ませ工業化を加速させる経路と、労働者の生活水準を上げる経路を別途に持たず、
> 　これらは同経路だが法で機能が決まる、という形式が良い」

> ## これは【未実装の設計】である
> 提案部分はまだ一行も実装されていない。引用した係数名・行番号は 2026-09-03 時点の現物の観測結果。

## §0 結論

**同経路に賛成。** 剰余は1つ、分割式は1本、そこへ法が入る。新しい機構は要らない。
ただし3点を修正する。

| | 決定 |
|---|---|
| 経路 | **1本**。`rent = rentShare × valueAdded; wages = valueAdded − rent` を唯一の分岐点にする |
| 入力 | **法 × 労働の希少性**。法だけにしない（§3） |
| 法の性質 | **自由なスライダーではない**。交渉力にゲートされる（既にそうなっている・§4） |
| 追加する量 | **資本の相対価格** 1つだけ。補助金の効果と Allen の高賃金説を**同じ量**で表す（§5） |
| 新定数 | 分割式に重み4本／資本の相対価格に1本 |
| 主フラグ | `LaborShareFromLaw = 0.0`・`CapitalRelativePriceGate = 0.0` — 両方0で厳密恒等 |

## §1 経済学と歴史の確認 — なぜ「同経路」が正しいか

### §1-1 政策としてのトリクルダウンは支持されていない

- Hope & Limberg (2022)：OECD18か国・50年。富裕層減税は**上位1%のシェアだけを上げ、成長にも失業率にも有意な効果がなかった**
- 米議会調査局 (Hungerford 2012)：1945-2010年の最高税率と成長に相関なし。不平等との相関は強い

**＝ 作者の見立ては実証財政学の多数派と一致する。**

### §1-2 ただし「成長が賃金に届いた時代」は実在する

| 時期 | 産出 | 実質賃金 | |
|---|---|---|---|
| 1780-1840 英 | 労働者一人あたり **+46%** | **+12%** | **エンゲルスの休止**（Allen 2009）＝ほぼ全部が利潤へ |
| 1830-1900 英 | — | **約3倍** | 届いた |
| 1900-1980 先進国 | — | — | **労働分配率が 60〜70% で安定** |
| 1979-現在 米 | 生産性 **+60%** | 中位報酬 **+15%** | 労働分配率 64%→56% ＝再び切れた |

さらに**東アジアが厄介な反例**：韓国・台湾は輸出補助金を**労働集約的**製造業へ投じ、
韓国の実質賃金は30年間ほぼ年7%で伸びた。最も産業政策的な国で最速の賃金上昇が起きている。

### §1-3 違いを作ったのは技術ではなく制度

休止が終わったのは資本蓄積が続いたからではない。**分け前を強制できる条件**が揃ったからである。

```
労働の希少化（大陸への移民流出）
団結権と実効的なストライキ
参政権拡大 → 工場法・時間法
鉄道と移動の自由が【買い手独占】を壊した（辞めて他所へ行ける）
```

**＝ 分配は制度が決めた。** ゆえに「常に滴る」でも「絶対に滴らない」でもなく、
**「制度が強制できたときだけ滴った」** が唯一の忠実な形である。

⚠ 現行のシムは `rentShare` が**定数**なので「常に滴る」側に固定されている。
　 経路を切れば「絶対に滴らない」側に固定される。**どちらも史実の半分しか出せない。**

## §3 【修正1】法だけにしない — 労働の希少性も同じ式に入れる

**理由**：法の無い世界でも賃金は動いた。

```
黒死病後の西欧（1350-1450）  労働力の激減 → 実質賃金が2倍以上。法はむしろ抑圧側（労働者勅令1349）
フロンティア期のアメリカ     土地が無償で手に入る → 雇うには高く払うしかない
飢饉後のアイルランド         人口流出 → 残った者の賃金が上がる
```

法だけを入力にすると、**余剰労働の清と、労働が希少な新大陸が同じ分配率になる**。これは誤り。

### 分割式

```
rentShare = 基準
          × (1 + RentScarcityElasticity × 土地の希少性)      ← 既存（RGOのみ・点火済み）
          × (1 − LaborShareFromLaw × 交渉力)

  交渉力 = LaborScarcityWeight  × (1 − 労働の余剰)      ← 市場（法が無くても効く）
         + UnionBargainWeight   × 組合の段 (0 / 0.5 / 1)  ← LaborUnionLaw
         + HoursBargainWeight   × 時間法の段              ← WorkHours
         + SuffrageBargainWeight × 参政権の広さ           ← 既存の Suffrage
```

- **1つの式・1つの書き手**（思想⑫）。分配を触る箇所は最後まで `EconomyStep.cs:2152` の1行だけ
- 入力は**全部既存の量**（新しい概念ゼロ・思想⑨）
- `LaborShareFromLaw = 0` で**乗算パスに入らない＝厳密恒等**（思想③）
- 壁でなく逓減。閾値を1つも置かない（思想⑩）

## §4 【修正2】法は自由なスライダーではない — 既にそうなっている

⚠ **「法で機能が決まる」を「法を選べば結果が決まる」と読むと、スライダーの言い換えになる。**

史実では**法は交渉力の帰結**だった。工場法が通ったのは労働者が票と組合を持ったからである。

現物は既に正しい。

```csharp
Government.cs:69   w.LaborUnion = StepEnum(w.LaborUnion, p.LaborUnion, w, PolicyAxis.LaborUnion);
                   // StepEnum は純支持（層別選好 × 発言権）が要る＝望んでも通らない
```

**＝ プレイヤーもAIも「法を望む」ことしかできず、通るかは政治が決める。** ここは変更しない。

そして**二重の因果になっているのが正しい**。

```
交渉力 → 法が通る          （Government.StepEnum・既存）
交渉力 → 分け前が動く      （§3 の式・新規）
法     → 分け前が動く      （§3 の式・新規）
```

⚠ 実装時の注意＝交渉力が法**経由**でも直接でも効くので、
　 `SuffrageBargainWeight` を大きく取ると参政権が二重に効く。段7で単独に分離すること。

## §5 【修正3】資本の相対価格 — 補助金の効果と Allen の高賃金説を1つの量にする

### §5-1 作者の補助金論は正しい。ただし符号を固定してはいけない

**正しいところ**：資本への補助は資本を労働より安くするので、資本集約化を促す。

```
EU の共通農業政策・米国農業法   補助金のピーク期に EU の農業雇用は約7割減
ソ連・インドの重工業補助        巨額の資本を吸って雇用シェアはごくわずか
レント資本化                    米オポチュニティ・ゾーン／映画税額控除／スタジアム補助は
                                ほぼ地価と所有者利得に消え、賃金効果はほぼ検出されていない
ソフトな予算制約（Kornai）      補助の恒久化が効率化圧力そのものを消す
```

⚠ 最後の点は**既に実装されている**：`SubsidyDependence`（`SubsidyDependenceRate = 0.007`）と
　 `SubsidySoftBudgetDecay = 0.4`（補助依存が実効生産性を蝕む）＝Kornai の機構そのもの。

**言い過ぎのところ**：符号が逆の補助金が実在する。

```
賃金補助          米 EITC は母子世帯の就業を大きく押し上げた（Eissa & Liebman 1996）
インフラ補助      労働と【補完的】。米農村電化は雇用も賃金も上げた（Kitchens & Fishback 2015）
                  ＝本プロジェクトが行政費から分離しようとしている「公共事業費」がまさにこの側
規模効果 対 代替効果   補助が産出を拡大する速さが資本代替を上回れば雇用は増える
東アジア          労働集約部門への輸出補助 ＋ 史上最速の賃金上昇
```

**＝ 純効果は代替弾力性次第で、符号は先験的に決まらない。** 固定すると国別分岐と同じ罪になる。

### §5-2 処方 ＝ 1つの量に統合する

```
資本の相対価格 ＝ 資本財の価格 / 賃金

これが低いほど資本集約化が進む（同じ産出をより少ない労働で作る）
  補助金 → 分子を下げる（資本を安くする）        ← 作者の補助金論
  高賃金 → 分母を上げる（労働を高くする）        ← Allen の高賃金説
```

**同じ機構を別の側から読んだものである。** そして帰結が違う理由も出る。

| 駆動 | 資本集約化 | 背後の賃金 | 需要 | 結果 |
|---|---|---|---|---|
| **補助金**による資本の安さ | 進む | **上がっていない** | 増えない | 少人数化だけが残る＝**作者の見立て** |
| **高賃金**による労働の高さ | 進む | 上がっている | **増える** | 労働生産性↑・市場↑＝**Allen の英国** |

⚠ **これを入れないと失うもの**：Allen の高賃金説は
　「なぜ中国でなく英国で産業革命が起きたか」の主要な説明である（高賃金＋安い石炭が
　労働節約的機械を採算に乗せた）。分割を純粋なゼロサムにすると、賃金を払うことは
　常に工業化にとって純損失になり、**1783年から始まるゲームの因果の中心が書けなくなる。**

```
CapitalRelativePriceGate = 0.0   // 0 で1命令も走らない厳密恒等
```

| **1870-1914 英独** | 容認 | 10時間 | 拡大 | 移民流出で希少化 | **賃金が伸びる**＝分配が動く |
| **清・露** | 非合法 | 無制限 | なし | 余剰労働が無尽蔵 | **工業化しても滴らない** |
| **フロンティア期の米** | 非合法 | 無制限 | 広い | **極端に希少** | **法なしで賃金が高い**（§3の修正が効く） |
| **補助金依存の重工業** | — | — | — | — | 資本集約化＋`SubsidyDependence` ＝**少人数化だけ** |
| **高賃金の英** | — | — | — | 希少 | 資本集約化＋需要増 ＝**Allen の経路** |

そして**プレイヤーの選択が本物のトレードオフになる**。

```
資本家に寄せる  → 投資予算↑（IndInvestmentFrac × Savings）→ 工業化が速い
                → 生活水準↓ → 闘争度↑ → 革命の危険

                → 蓄積は遅いが持続する
```

⚠ **どちらにも支配的戦略がない。** そして AI とプレイヤーで完全に対等（思想⑤）。
