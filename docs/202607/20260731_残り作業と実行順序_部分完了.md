## S3. 残余予算カスケード（軍量問題の本体）

```csharp
EconomyStep.cs:553  double remaining = Math.Max(0, region.MilitaryBudget - estCost * afford);
```

⚠ `afford = min(1, Budget/estCost)` なので、`afford < 1` のとき `estCost × afford = Budget` ちょうど → **`remaining = 0`**。★★★ **大軍は数学的に一切の近代装備を持てない。**

★★ **採る形（作者裁定 2026-07-31）＝予算を軍の規模に連動させる。ただし `min()`：**

```
MilitaryBudget = min( 歳入シェアの上限（現行）, 兵数 × 1兵あたり装備費 )
```

★ **根拠**：`SoldierPayBudget = min(Treasury, size × civWage × SoldierPayMult)`（`Simulation.cs:1313`）が**既に兵数比例**。⚠ 装備予算（`Simulation.cs:1246`）だけが非連動で、**同じ軍事支出の中に2つの流儀が同居している**＝取り残しの可能性が高い。

★★ **却下した案**：⚠ **「上位装備に予算の一定割合を留保する」**。理由：★ 全国一律なので**大軍と精鋭の区別が消える**（⚠ 露1914の砲弾不足と英の弩級戦艦競争が同じ比率になる）。★★ そして**留保率は時代不変でありえない**（1783年に上位装備は存在しない）＝掃討基準のC級に該当する新規係数。

⚠ **注意**：`Fiscal.cs:153` の `militaryClaim` も同じ式に揃えないと、請求額と実支出がずれる。
