# 3. 基準

## 3-0. ★★★ 2段の判定

> **① その定数は、時代にかかわらず不変の法則か？**
> **　　YES → ★定数でよい**
> **　　NO  → ②へ**
>
> **② それは時代の関数になっているか？**
> **　　YES → ★★形状パラメータは定数でよい（★較正の記録をコメントに書く）**
> **　　NO  → ★★★掃討対象**

### ★ 検査の問い＝「1783年と1934年で、同じ値でよいか？」

| ★許される（時代不変） | 例 |
|---|---|
| **物理・幾何** | 地球半径・緯度・海路の接続・`SeaRescueKm = 150`（実装の許容誤差） |
| **気候** | ★`CottonBeltLatMax = 37.0`（**綿花の生育緯度は変わらない**）・米の適地 |
| **地理** | 咽喉の位置・海盆の帰属・州の座標 |
| **数学的定義** | 0除算回避・定義域・単位（`DaysPerYear`・`MigrationFareDistanceUnitKm`）・**過半数=0.5** |

| ⚠許されない（時代依存） | なぜ |
|---|---|
| ★**技術で変わる** | 投射圏・運賃・伝播速度・行政の到達距離・軍の射程 |
| ★**制度で変わる** | 何が「近い」か・何が統治可能か |
| ★**経済で変わる** | 何を養えるか（★**軍の4%がこれ**） |

⚠ **②の例外が重要**：`TransportRevolutionMax = 0.5` は「運賃がどれだけ下がるか」の強さで、**法則ではない**。
★★ **しかし時代の関数の形状パラメータであり、史実の実測に較正されているので正当。**

## 3-1. ★★★ 危険度の順序（軍の失敗から帰納）

| 級 | 署名 | なぜ危険か | 実例 |
|---|---|---|---|
| ★★★**A** | **均衡を決める × 帰還経路なし × スケール変数と掛かる** | ⚠**その値が答えそのもの**。誰も是正しない | ★軍 `4% × 人口`（修正済）／★★`TransportTargetPerPop`／`AdminNeedPerPop` |
| ★★**B** | **信号を殺す飽和・上限** | ⚠費用項が**あるのに効かない**＝Aと症状が同じ | ★`profitFactor` が 1.5×mc で 1.0 に張り付く／`ScaleMax = 3.0` |
| ★★**C** | **不連続を作る切替**（`Math.Max(式A, 式B)` で支配側が入れ替わる） | ⚠**軍の修正で3回目の失敗の原因**。★値でなく**形**が壊す | ★軍の1〜2回目の試み |
| ⚠**D** | 均衡を決めるが**帰還経路あり**（採算・需要が押し返す） | ★誤差が吸収される | 送電容量（需要追従） |
| ★**E** | **時定数**（速度・平滑・半減期） | ★★**値がずれても均衡は変わらない**——遷移が速い/遅いだけ | `Rate` 95 ／ `Speed` 25 ／ `Half` 7 |
| — | 単位変換・一次データ | ★思想②が明示的に許す | `DaysPerYear`／`world.json` の share |

★★★ **E（約130本）は一掃しなくてよい**——これが最大の絞り込み。

## 3-2. ★ 判定に使える2つの問い

```
★★「その目標は、払えなくなったら下がるか？」    ← A級/D級の切り分け
★★「1783年と1934年で、同じ値でよいか？」        ← 時代不変性
```

| 対象 | 払えなくなったら下がるか | 判定 |
|---|---|---|
| ★**輸送容量** | ⚠**下がらない**（人口が減らない限り目標は同じ） | ★★**A級** |
| 産出 `Output` | ★下がる（`profitFactor`） | ⚠**ただし飽和**＝B級 |
| 操業規模 `Scale` | ★下がる（`margin`） | ⚠**ただし上限3.0**＝B級 |
| 送電容量 | ⚠需要には従うが採算は見ない | ★D級（中間） |
| ★植民地開発度 | ★★**下がる**（限界価値と費用を比較） | ★**正しい** |
| ★軍（修正後） | ★★**下がる** | ★**正しい** |

## 3-3. ★★ 掃討の出口は3つ（削除とは限らない）

| 出口 | 例 |
|---|---|
| ★★★**機構に置き換える**（値が要らなくなる） | ★軍＝「払えているか」で増減。★★**上限も下限も消えた** |
| ★★**アンカーを与える**（値は残るが根拠が付く） | `ColonialPopScale` ＝ ベンガルの実人口から逆算 |
| ★**較正して記録する**（測って選んだと書く） | B4 の bisect（1/8 赤・1/16 緑） |

★★★ **A級は「値を直す」のではなく「機構ごと置き換える」と、限界値まで消える**——★軍がその実例。
