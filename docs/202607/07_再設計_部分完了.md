# 1. CrownFormMutation（王権の形の変異）＝実体駆動への再設計

**過去の失敗**：支持座標駆動＝1789年に亜細亜の専制が一斉絶対王政化（形の登録簿は軸で区別しない＝P2知見と矛盾）。

**再設計＝形ごとの実体トリガー**（国名特例なし・形自体が条件を運ぶ）：

| 変異 | トリガー（すべて既存の実体量） | 史実対応 |
|---|---|---|
| 幕府 → 絶対王政（親政） | 外圧（TraditionalistLawGateと同じ3条件＝緊張>40／存亡脅威／闘争>0.5）**かつ**（敗戦 or 闘争>0.5） | 大政奉還→明治 |
| 専制 → 絶対王政（官僚絶対主義） | AdminEfficiency > 0.6 が8四半期継続 | プロイセン型 |
| 絶対王政 → （立憲へ） | **変異しない**＝君主制の外への遷移は既存の政体遷移（Polity側）が担当。CrownForm変異は君主制内部の形だけ |

- 後退（絶対王政→専制）は**入れない**（行政力の崩壊は既存のInstitutionalDecayが政体側で罰する＝二重化しない）
- 幕府条件が事実上日本にしか発火しないのは「幕府という形が日本にしかない」ため＝データが運ぶ＝思想②適合
- コストM（トリガー2本＋変異1関数）。帯直撃（日本の1868が動く）＝単独バッチ＋fidelity必須

# 3. CurrencyHoldingRatio ＋ Bank.Gold の独立ストック化

**現状**：Bank.Gold は毎日 `BaseMoney×(1−ratio)` で上書きされる導出量（04で「独立に書くな」と明記済み）。

**再設計（2段階）**：
1. **静的分割（先行）**：ratio=0.1 を点火するだけ＝準備が恒常的に9割になる。Gold は導出のまま＝二重ソース化しない。実装S。
2. **動的退蔵（本命）**：ratio_eff = ratio × (1 + HoardPanicWeight × (1 − bank.Confidence))。恐慌で Confidence↓ → 退蔵↑ → 準備↓ → maxLoans↓ → 信用収縮の自己強化（B3自己成就期待の銀行版と同根）。Gold は**導出のまま**でよい（ratio_eff が状態関数なら二重ソースは生じない）＝Bank.Goldの独立ストック化は**不要と再結論**。実装S+。
- 保存則＝現金退蔵は BaseMoney の内訳変化のみ（量不変）＝安全。
- ★推奨＝2段階とも実施（1でbatch→2でbatch）。B3（§5）と同じラウンドが効率的。

# 4. ゾンビ国家清掃（MigrationFarePerkKm の前提）

**問題**：住民≈0まで流出した国が残存しO(N²)を膨張（batch12倍低速化・#54実測）。

**★再設計＝上流ガード＋保険の2層**：
1. **上流（主対策）**：移民の送出下限＝送出州の対象popが閾値（例：総人口50千人）未満なら流出停止（「最後の住民は故郷を捨てない」）。ゾンビ化自体を防ぐ。実装S。
2. **保険（例外処理）**：それでも総人口<閾値がN=8四半期継続した国は**抽象標的化**＝Nation を落とし植民地化可能な Power へ戻す（既存の抽象標的機構を再利用＝新機構なし）。残余の国庫・popは（a）最大債権国へ、無ければ（b）人口比で全国按分＝建国の逆＝既存台帳で保存。実装M。
- 併合方式（隣接国へ無血併合）は**採らない**＝「誰が隣接か」の判定が新たに要る＋タダで領土が増える歪み。

# 5. B3 自己成就期待（備蓄・資金逃避）

**(a) ★戦時備蓄（先行推奨）**：緊張が閾値（40＝黒船と同水準）超の国は、主食＋軍需財の TargetStock を `1 + StockpilePanicWeight × (tension−40)/60` 倍に引き上げ（国家・pop両方＝対称）。需要スパイク→価格↑→隣国も備蓄（緊張は相互）＝自己成就。在庫飽和で自己有界＝既存 TargetStock 機構に乗るだけ。実装S+。「戦争の匂いでパンが高くなる」＝表題の連鎖の新しい顔。

# 6. D3 海空＝厭戦（乗算）／陸戦＝押し合い（加算）の分離

**検証結果（設計前提）**：03手順6/7でこの分離は**8割完成している**＝封鎖→厭戦（LastBlockadeRisk）・空襲→厭戦（WarExhaustionAirRaid）は率側、陸のScoreは押し合い側。海軍がScoreへ直接入る項は**投射効率（海越えの制海権ゲート）のみ**＝これは「陸兵を運ぶ効率」であり陸戦の一部＝設計に適合。

**残る設計＝2点だけ**：
1. **艦隊決戦の実損**：現状 NavalPower は摩耗しない。交戦中、海盆別に敵と接触する艦隊が相互摩耗（NavalAttrition × min(own,enemy) presence）＝トラファルガー後の制海権固定が出る。実装M。
2. **検証の番人**：「海空のみの戦争（陸接触0）はScoreが動かない」をテスト化＝D3の形式保証。実装S。
- ★制空の押し合い補正（AirControlPushWeight）は**陸戦支援として存続**（航空優勢が陸を助けるのは陸戦の増幅であり「空だけで決着」ではない）。

# 8. 軍艦⇄商船の連動（04 §5-10）

**検証結果**：護送船団は手順6/7で実質実装済み（自国海軍のpresenceが敵支配度を下げる＝リスク減）。建艦の財裏付けも軍需調達で接続済み。**残るのは徴用のみ**。

**★設計＝戦時徴用**：開戦中 `ShipCapacity_eff = ShipCapacity × (1 − RequisitionRate × mobilize)`（総動員の深まりに比例）。徴用分は投射効率へ小さくプラス（輸送船団）。商船が減る→貿易容量↓→リスク料と重なって「長い戦争は貿易を窒息させる」。実装S。優先度は低（06の評価どおり）＝パッケージCの末尾。

# 10. 独占系の一括再設計（DomesticMarkupMax / HhiIncludesRestOfWorld / MonopolyResentmentMilitancy）

**過去の失敗の構造**：①独占レントが伝統帝国（清）を富ませ entrench ②Resentment直接加算が政治を自律撹乱 ③偽独占（モデル国のみのHHI）が一部の国を史実に寄せる load-bearing。

**再設計（3点セット・#17内で一括）**：
1. **レントの不胎化**：独占レントは所有者popの**退蔵傾斜**を上げる（投資・消費に回る率を下げる）＝「独占は静的に富むが動的に成長しない」＝entrench の遮断。レント総量は既存の移転＝保存。
2. **政治帰結は既存経路のみ**：大衆の実質所得減→Satisfaction→闘争度（既存）に任せ、Resentment 直接加算は**廃案**（②の教訓）。
3. **偽独占の是正は RestOfWorldElasticity アンカーと同時**：HHI分母の残余世界（HhiIncludesRestOfWorld）は、世界価格の残余世界弾力性と同じラウンドでしか入れない（③のload-bearingを別の物理で置換してから外す）。
- ★#17再較正ラウンドの中でのみ実施（帯の物差しが動く前提の変更のため）。

## 12-1. A4への回答：国が空になることは歴史上起こりえたか

**起こっていない。** 最悪の事例はアイルランド（1845〜1914＝飢饉死＋移民で人口約半減・800万→440万）だが、ゼロには程遠く国として機能し続けた。ノルウェー・南イタリア・スウェーデンも自然増の3分の1〜相当を送り出したが枯渇していない。
**移民は自己制限的**だから＝人が減るほど (1)労働が希少になり賃金が上がる（引き留め） (2)土地が空いて機会が増える (3)渡航費・縁故のネットワークが細る。
つまり「住民≈0まで流出」はモデルの欠陥（自己制限の弱さ）であり、国の消滅処理で対症するのは誤り。**正しい修正＝送出州の人口が減るほど Opportunity（賃金項）が上がって流出が止まるフィードバックの強化＋送出下限**。

## 12-3. A7の再設計：国境通過ベースの関税

- **原則＝関税は国境を跨ぐ瞬間に発生する**。国内の州間取引＝国境を跨がない＝関税ゼロ（問題が定義から消える）
- 輸入関税（現行＝仕向国の関税）は既存のまま＝これは「自国境を入る瞬間」の税として既に正しい
- **新規＝通過税（transit）**：内陸国・内陸州が第三国の領土を陸路で通過して港へ出る場合、経路グラフの通過国ごとに通過国の関税率×通過係数を加算。高関税国は迂回される（経路グラフの最短路が価格込みで選ぶ）＝「回避される国が出てもよい」の裁定どおり
- 海路は公海＝無税（海峡・運河の通行料は既存機構）

## 12-4. A8への回答：なぜジェノヴァ→ナポリに大西洋までの距離がかかるのか

現在の市場は**世界にひとつのプール**で、誰も「誰かと」取引していない。ジェノヴァは「世界」に売り、ナポリは「世界」から買う。その「世界」の所在地＝全参加国の取引加重平均座標＝大西洋〜欧州沖にあり、双方がそこまでの距離を払う。二国間の組み合わせが存在しないので、「その財は地中海の中で500km動けば済んだ」をモデルが知り得ない。

**再設計＝海盆プール制**（裁定「そこで終わる筈」に沿う）：
- 財ごとの価格プールを海盆単位（7つ）に分割。州は自分の海盆のプールと取引（距離＝海盆内）
- 海盆間は**通路（ジブラルタル等）を通る裁定取引**が価格差を均す（距離＝海盆間・封鎖リスクが乗る＝封鎖が「海盆を世界市場から切り離す」を自然に表現）
- ジェノヴァ→ナポリは地中海プール内で完結。地中海の純輸出入だけがジブラルタルを流れる
- コストL（価格層の分割＝市場コードの大改修）。**踏み台としてα混合（§9）を先に入れ、海盆プールは地理仕上げパッケージの主課題とする**

# 14. 世界市場の廃止（2026-07-29・作者質問への設計回答）

**問い**：陸・海とも交易ルートが取れる今、世界市場（単一プール）は廃止しても問題ないか。表示用の「現在価格 vs 世界」の比較は残したい（全商品の平均値または中央値でもよいか）。

**回答＝廃止できる。ただし海盆プール（A8裁定）を経由する**：

- 世界市場の役割のうち距離判定・封鎖・運賃決済は03/04で経路側へ移管済み。残るのは**価格形成（1本の世界価格）だけ**
- **海盆プール制を入れた時点で「世界にひとつの市場」は消滅**（7つの海域市場＋通路の裁定取引だけになる）＝実質の廃止
- 完全な州間二国間取引まで一気に行かない理由：(1) 165²×136財の組み合わせ＝計算量の桁が変わる (2) 単一プールの清算が担っていた価格安定が消え、点火済みの期待（在庫循環・投資外挿）と重なって振動が増幅する恐れ。海盆プールで観測→#17後に再検討

**表示用「世界価格」の統計（力学に戻さない＝表示専用）**：

| 用途 | 計算 |
|---|---|
| 財ごとの比較（この州の鉄は世界より高い/安い） | **取引量（or生産量）加重平均**を推奨（単純平均は辺境の小市場が歪める）。中央値は頑健な次善 |
| 全商品1本の物価比較（この国の物価は世界より高い） | 絶対価格の平均は高額財に引っ張られる→**参照価格比に直してから中央値**（or 消費バスケット加重）＝実質は物価指数・インフレ表示にも流用可 |

⚠規律：この統計を機構が読むと単一世界市場が裏口から復活する＝**表示専用**を明記して実装する。
