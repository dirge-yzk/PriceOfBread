## 2. 新設：列強軸（忠実度の計器）
**動機**＝「1914年に誰が列強か」は政体軸でも法軸でも人口軸でも測られておらず、歪みがどの帯にも露出していなかった（人口軸を追加する前に人口の歪みが温存されていたのと同じ構造）。

**実装**（人口軸B-中7と同じ型）：
- `HistoricalEntry.GreatPowerOk`（bool?・null＝測定対象外）を史実1914の列強8カ国に true＝英仏独(普)露墺伊(サルデーニャ)米日
- `NationFidelity.GreatMatch` / `RankMean`
- `HistoricalReference.Evaluate` で Q524断面のスコア降順順位を算出し `rank <= GreatPowerCountForFidelity` を判定
- **exact/near には合算しない独立の1行**（過去測定との比較可能性を守る）
- 判定定員は `Coefficients.GreatPowerCountForFidelity = 7`（**const・較正で動かさない**）＝ゲーム側の `GreatPowerCount` とは別物
- **理論上限は 7/8＝88%**（史実8カ国に対し定員7＝必ず1つ外れる。イタリアが外れるのが史実的に自然）。100%を追わないよう出力に明記

## 4. 原因の切り分け（実測に基づく）
### (a) スコア式が意図的に反規模【最大の要因・ユーザー裁定事項】
`NationalScore` のコメントが明記：
> **規模偏重の是正（ユーザ指定）**：GDPと軍の比重を下げ、1人あたりの発展度の比重を上げる＝大人口だけで上位に立てないようにする

清の人口一強（1799–1914ずっと清が1位）を抑えるための意図的な設計。実際の重み＝**intensive（1人あたり）: 工業化×9・満足×12・Tech×12・金融≤6 ＝最大約57** vs **extensive（規模）: GDP≤12・軍≤12・植民地 ＝約24-27**＝**約2:1でintensiveが支配**。

### (b) 工業化が全国3前後に収束＝差がつかない
intensiveの最大項（工業化×9＝27点）が全国ほぼ同値になり、**差別化に寄与せず全員の点数を嵩上げするだけ**。結果、seed1では7位90点・8位89点＝**1点差で列強が入れ替わる**。

### (c) 工業化に床が無く、敗戦国は0へ落ちる
`region.Industrialization *= 1.0 - 0.003`（月次）は**無記憶の指数減衰で床が無い**。投資が止まると `(1−0.003)^1812 ≈ 0.004` ＝**約50年で実質ゼロ**。seed1の英は1788年に仏へ敗れ属国化し、126年かけてゼロへ。**工業化0.00は27点の喪失**＝103点(仏) vs 50点(英) の大半を説明する。

## 5. 実装：開発度の記憶 `DevelopmentMemory`（休眠＝現在0.0）
史実の資本は設備が失われても**体化された技術・熟練・制度が残り、再建と維持が速い**（独日の戦後復興）。ピークから離れるほど**物理減価を緩めて0へ漸近**させる。
```
dep = IndDepreciation
if (DevelopmentMemory > 0) {
    totNow = Industrialization + OldVintageCapital
    if (totNow > DevelopmentPeak) DevelopmentPeak = totNow
    dep *= 1 - DevelopmentMemory * (1 - clamp(totNow / DevelopmentPeak, 0, 1))
}
Industrialization *= 1 - dep;  OldVintageCapital *= 1 - dep
```
- **資本を注入しない**（減価率を緩めるだけ）＝保存則・単調性に非接触
- 新規state＝`Region.DevelopmentPeak` 1本（SaveGameはリフレクション直列化なので自動追従）
- `DevelopmentMemory=0` で `dep` は `IndDepreciation` そのもの＝**式も掛順も不変＝厳密恒等**（chronicle 112 で実証済み）

## 6. 残る判断（ユーザー裁定が要る）
**「清の人口一強を防ぐ」と「史実の列強が列強であり続ける」は、現在のスコア式では両立していない。** これはユーザー自身の過去裁定（規模偏重の是正）と今回の要望の衝突であり、勝手に反転すべきでない。選択肢：
- **(A) 現状維持**＝列強の顔ぶれは測るが直さない（政体・法の忠実度を優先）
- **(B) intensive項に上限を入れる**＝工業化×9が全員27点を配る問題を潰す（差別化しない項が点数を嵩上げしている）。清一強は招かない（清の工業化も3前後＝同じ上限）
- **(C) 開発度の総量（工業化×人口）を逓減つきで加える**＝extensiveだが逓減で清の暴走を抑える。ユーザーの「開発度で硬く」に最も近い
- **(D) P13スコア式の凍結を解いて再較正**＝影響は列強判定・勝者判定のみ（AI・較正には非使用）だが、清勝率の物差しが動く
※(B)(C)(D)はいずれも**P13（スコア式は据え置きと裁定・2026-07-15）に触れる**。
