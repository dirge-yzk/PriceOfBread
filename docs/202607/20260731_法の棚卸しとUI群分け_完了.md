# 3. 設計

## 3-0. ★★★ 基準の改訂（これを書かないと同じ棚卸しを繰り返す）

> **改訂基準（2026-07-31）**
> **新しい法軸が正当化されるのは、賛否連合か機械的効果のどちらかが既存のどの軸とも違うとき。**
> **連合も効果も同じときだけ畳む。**

★ 旧基準（連合のみ）は**足すかどうかの判定**には十分だったが、**畳むかどうかの判定**には不足だった。
★★ 効き先が違えば、連合が同じでも**別の決定**である。

## 3-1. ★ 畳めるもの＝1組のみ

| **判定** | ★★**畳める** |

## 3-2. ★★ 足すもの＝移民制限法

| | |

★ 移民法があれば、その流れが出る。

⚠ 段数は未決（2段＝自由/制限 か、3段＝自由/選別/禁止 か・§6-2）。

# 5. 却下すべき案

| 案 | 却下理由 |
|---|---|
| **旧基準（連合のみ）を機械的に当てて8軸を畳む** | ★★**却下。** `Censorship`(新聞/闘争度)・`SecretBallot`(選挙)・`Bureaucracy`(行政力)・`StateReligion`(十分の一税)・`EducationLaw`(識字/同化) は**効き先が全部違う**。畳むと機構が5つ消える。★**基準を改訂する**（§3-0） |
| **穀物法を関税に畳む** | ★効き先が違う——`CornLawImportPenalty` は**Staple のみ**に掛かる（`InternationalMarket.cs:285`）／関税は全財。⚠**1846年の撤廃時も他の関税は残った**＝史実でも別の決定 |
| **農奴解放を土地改革に畳む** | ★**制度・地理・廃止年が全部別**（農奴＝露普墺東欧・1807/1848/1861／動産奴隷＝英仏蘭西の植民地・米南部・伯）。統合すると「露の農奴解放で西インドの奴隷が解放される」 |
| **徴兵法を親軍に畳む** | ★★**英が反例**——**大海軍を持ちながら1916年まで徴兵なし**。「大きな軍」と「徴兵」は史実で分離可能だった |
| **秘密投票を参政権に畳む** | ★効き先が違う（**票の質** vs 有権者の範囲）。英でも1832/1867（選挙権）と**1872（秘密投票）**は別の戦い |
| **阿片保有と阿片輸出を畳む** | ★**別の国の別の決定**（輸入する側＝清／輸出する側＝英印）。★英は自国で禁じずに輸出だけ続けた |
| **累進課税を所得税に畳む** | ⚠最も弱い候補。★ただし「所得税を作るか」と「累進にするか」は別の19世紀の論争（英1799創設／累進化は1909人民予算） |
| **`WomenSuffrage` も一緒に畳む** | ⚠ **2026-07-13(2)・修正予約7 で意図的に脱結合した**（`Coefficients.cs:245 DecoupleWomenSuffrage = 1.0`）。★**当時の判断を確認するまで再結合しない** |
| **軸を減らして「多すぎる」を解決する** | ★★★**問題は数ではなく平坦な一覧。** 8群に分ければプレイヤーが一度に見るのは8つ。★軸を削ると**機構が消えて政治の肌理が失われる** |
| **群名に説明を書く**（「税制：国庫収入を左右します」等） | ★**規律①違反。** 群名は**分類の名前**であって説明ではない |
