# 1. 前提（このラウンドの運用）

## 1-1. ④帯を壊さない は「ゲート」から「計器」へ

**batch30 は回し続け、数字も記録する。それを理由に差し戻さない。**

記録すべき最小セット：`exact / near / ◎ / 固着 / 逸脱過多 / 人口一致 / 破綻 / 清の勝率 / chronicle総政変`

**測るのはやめない。** 帯は「機構が間違っている」と「数値が要調整」を区別する唯一の手段。ゲートを外すのであって計器を外すのではない。

## 1-2. 硬性ゲートは外さない

`dotnet test` 169緑／`leakhunt` 清潔／破綻0/30／決定論。**保存則を破る変更だけは、面白くても入れてはいけない**（較正で直せない種類の壊れ方だから）。

## 1-3. #17較正ラウンドの実施時期を先に決める

「後で」ではなく「いつ」。**第5段を入れ切った時点で1回**、と決めておかないと記録だけが積み上がって誰も帯を戻せなくなる。

## 1-4. 1項目＝1バッチ

差し戻さないからこそ、どれが何を動かしたかの記録が要る。本日の15本一括点火は既にこの原則から外れている。
