# 2. ★診断 — 真因はレバーの不在ではなく、市場が応答しないこと

## 2-1. 州内のRGO労働配分は**厳密なゼロサム**

```
EconomyStep.cs:246-249  fraction = 0.85 × (prodW/Σ) + 0.15/N
Σ fraction = 0.85 + 0.15 = 1.0
```

★ 州のRGO総capacityは**農民pop規模で天井**が決まり、**ある財の増産は必ず他RGOからの奪取**。
全RGO生産者は `Simulation.cs:704` `LaborPopIndex = 1`（農民）で単一プールを共有する。

## 2-2. ★★ 価格応答が**二重に飽和**する

```
profitFactor  は P = 1.5 × mc で 1.0 に張り付く   （EconomyStep.cs:314・SupplySlope=0.5）
Scale         は P = 3   × mc で上限 3.0          （:1402・ScaleMax=3.0）
価格の天井    は参照価格の 100倍                  （PriceCeilFactor=100）
```

畜産(19)の実測：`mc = MarginalCost(0.34) + 農業労働価格 × 0.4 = 0.34 + 0.4×0.5 = 0.54`
——これは**畜産の参照価格 0.54 と厳密に一致する**（`RgoVa 0.34 + 0.4×0.5`）。

| 価格 | 起きること |
|---|---|
| **P = 0.54（参照価格ちょうど）** | ★**profitFactor = 0。供給しない** |
| P = 0.81（1.5倍） | profitFactor 飽和 |
| P = 1.62（3倍） | Scale 上限 |
| P = 54（100倍） | ★**何も変わらない** |

★★★ **参照価格の3倍〜100倍という広大な区間で、価格上昇が供給を1単位も増やさない。**

## 2-3. ★★ 物量加重による**逆フィードバック**

労働配分の重みは `prodW = LastDemand × Scale`＝**物量加重**（`EconomyStep.cs:172`）。
畜産は `BaseNeed = 0`（pop直接需要ゼロ）で、**需要は全額が派生需要**（羊毛0.5・革0.5・肉0.6・チーズ0.6・馬0.6）。

```
畜産が不足 → 下流の産出が落ちる → 畜産の派生需要そのものが縮む → 労働シェアが上がらない
```

★ 配給率0.5が続く場合の実測展開：**3年経っても ×1.35 止まり**（飽和上限 ×2.53 に対して）。
**不足が不足を強化している。**

## 2-4. 応答が遅い

| | 速度 | 半減期 | 90%到達 |
|---|---|---|---|
| `Output` | 0.15/月 | 1.42四半期 | — |
| **`Scale`（労働シェアを動かす）** | **0.05/月** | 4.5四半期 | ★**15四半期＝3.7年** |

## 2-5. ★ 耕地はほぼ非拘束

158州のうち土地が効いているのは**開始時点でネーデルラント4州のみ**（landFactor=0.9745）。
中央値の州は**農村人口が58.5%増えるまで** `landFactor = 1.0`（`ArableLand = peasant.Size × LandHeadroom(1.8)`）。

★ **土地の奪い合いが現状ほとんど起きていない。**

★ **したがって「人を注入する」配線は既にある。** 奴隷の着地はこれを雛形にできる。

### ⚠ 最大の障壁

★★ **カリブ（Colony）と米南部（Region）が別の型**なので、**この案の眼目である両者の対比が二重実装なしには書けない。**
そして**西アフリカは州として存在しない**——158州のうちサハラ以南アフリカは
**ゴンダール（エチオピア）とアンタナナリヴ（マダガスカル）の2州のみ**で、ギニア湾周辺は**0州**。
西アフリカの現在の表現は5件で、2件が Colony（沿岸西アフリカ・セネガル）、3件が Nation=null の抽象標的
（アシャンティ・ソコト・コンゴ）。★**抽象標的は Region も Market も Pop も Producer も持たない**ので、
**「奴隷州が奴隷を算出する」は現状の型では書けない。**

### ★ 費用対効果の訂正

「1807/1808 で終わる機構に価値があるか」は**誤り**。貿易の廃止は q96/q100 だが、
**ストックと解放は q200〜q420 まで生き、604四半期の約70%に跨る。**

# 5. ★ 却下すべき案

| 案 | 却下理由 |
|---|---|
| **奴隷財を「通常の新財」として無条件に足す** | ★全州の全RGOの Capacity が **−0.484%** 動き、**厳密恒等が原理的に取れない**（`Simulation.cs:697-713` が非Service の全財に自動で生産者を作り、`LaborFloorMix=0.15` の均等床を通じて全生産者の `fraction` が下がる）。**入れるなら単独バッチで帯を測る** |
| **奴隷財を `IsColonial` にする** | ★輸送容量・咽喉・通商破壊・関税を**全部回避**して首都州の在庫へテレポートする。三角貿易も海軍の取締も出なくなる |
| **奴隷ストックを「市場在庫の腐敗率」で表す** | ★役務は `Spoilage=1.0` で**在庫を持てず**、腐敗は**地域別にできない**（財IDだけの switch） |
| **1807/1808 を暦年で発火させる** | ★**思想①違反。** 既存の時計は技術水準か内生条件のみ（`AdvancedTechScale`・`RecipeTechScale`・`railGate`・`Megaprojects.TechGate`） |
| **農場の型を「価格への応答速度」のパラメータにする** | ★**建設動詞のほうが良い。** パラメータは新しいスカラー（マルコフ性の負債）を生むが、動詞は既存機構の再利用で済む |
| **`OverheatFragility` 型の閾値操作で罠を作る** | 平時の全州が常時発火する。**外科的倍率に堕ちる** |
| **漁獲(20) を無理に含める／除外する** | ★土地を占めないので罠が働かない。**除外は例外を1つ作る**ので、含めて「罠にならない」を許容するほうが規律的には綺麗（要判断） |
