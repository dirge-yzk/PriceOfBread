# 政治ポート規約（第8段8-3/8-4・2026-07-28制定）

台帳の実体は生成物：`政治ポート台帳_生成.md`（再生成＝`PriceOfBread.Runner.exe portledger PriceOfBread.SimCore > docs/政治ポート台帳_生成.md`）。
本書は**手で守る規約**のみを持つ（生成物に手書きを混ぜない）。

## 規約3（既存・再掲）：同じ根を2ポートから叩かない
同じ実体量（満足度・失地・外圧…）を複数の経路から効かせるときは、出力先が異なること（例＝機能7-6裁定：失地→緊張は対外敵意・失地→r[4]は国内分布）を裁定として書き残す。裁定なき二重は違反＝台帳生成で [PORT] タグと係数一覧を突き合わせて検出する。

## 規約5（既存・再掲）：AI/プレイヤー対称
どの動詞・コスト・ゲートも両者同一式。片側だけの経路は較正保護のための明示的な例外（Mobilized等）としてコメントに残す。

## 規約6：最小状態
新しい状態変数（World/Popフィールド）は、既存の量から毎期導出できるなら作らない。ストックが本当に要る（履歴が意味を持つ）ときだけ作り、**減衰か消費のどちらかを必ず持たせる**（無限蓄積の禁止＝FamineMemory/LostRegionsCumulative/VictoryShockが型）。

## 規約7：マルコフ性
四半期の頭の全状態から先の軌道が決まること。保存されない隠れ状態（静的キャッシュ・前回呼び出しの残滓）への依存は禁止。
検出器＝`savetest`（既定Q300往復＝長期ほど違反が蓄積して露見する・第8段8-5で硬性ゲート化）。

## 規約8：新項の受け入れ条件
[PORT] への新規加算は次を満たすこと：
1. 係数は「0＝恒等・休眠」（逆規約は 20260727_変数リファレンス.md 冒頭の一覧に追記＝機械判定の保護）。
2. 1項目＝1バッチ（または --zero 帰属つき合同バッチ）で chronicle 総政変の差を記録する。
3. 硬性ゲート（dotnet test 緑・leakhunt 清潔・破綻0・決定論）を通過する。帯（exact/near）は計器＝差し戻し理由にしない。
4. 保存量（貨幣・人口）に触れる場合は両建て記帳の作法（CedeTerritory/CivilWarCivilianTollが型）。
5. Legitimacy 等の説明API対象への書き込みは必ず記帳する（クランプ差分も＝ExplainTestsが番人）。

## コメント規約（8-3）
係数コメントは次の形を守る：`// [由来と日付] 意味＝機構の一行。0で恒等（または逆規約の明記）。点火/棄却の履歴`。
禁止＝値と矛盾する状態表記（「点火済み」で値0等）。**コメントより値を信じる**が原則だが、矛盾を見つけたら第2段（嘘コメント是正）の作法で即直す。
