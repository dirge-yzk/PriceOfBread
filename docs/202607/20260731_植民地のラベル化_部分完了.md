# 1. 何をするか

**`Colony` という独立した型を廃し、植民地を「非コアの州」にする。**

```
Colony（ColonyList の要素）  →  Region（RegionTier = Colonial）★格は3値（Core / Integrated / Colonial）
col.PopSize（集計スカラー）   →  Pops（階級とイデオロギーを持つ実体）
搾取・マラリア・開発度        →  機構は残す。RegionTier を見る修正項として置き直す
独立                        →  ★分離独立へ一元化（作者裁定）
```

★ **廃止ではなくラベル化。** 植民地の機構（搾取・マラリア死・開発度・捕囚市場・独立圧力）は
**史実的に正しく、捨てない**。⚠ 誤っているのは**置き場所**であって中身ではない。

## 1-1. 作者の判断

> **作者（2026-07-31）**：「現状、**自国/植民地のメリットより、一貫した実装ができないデメリットの方が大きい**ように感じる。
> そうであれば、植民地は廃止、あるいは**州情報につけるラベル化**しようと考えている」
> 「まずは植民地のラベル化を行い、**植民地POPにもイデオロギーなどを持たせましょう**」

## 3-1. 型：`Colony` → `Region`（★**bool でなく3値**・作者裁定 2026-07-31）

> **作者**：「議席ですが、**非コア州は持つが、植民地州は持たない**が自然に感じる。
> もちろん、ここで**非コア編入州に議席を与えるかの法**を用意しても良い」

★★ **したがって `IsCore`（bool）では足りない。3つの状態が要る。**

```csharp
public enum RegionTier { Core, Integrated, Colonial }
    Core        中核州（titular・本国）              ★議席あり
    Integrated  非コア（併合・編入）                  ★議席あり   例＝アイルランド1801合同法・アルザス=ロレーヌ
    Colonial    植民地（海外領土）                    ★議席なし   例＝インド・アルジェリア（初期）
```

⚠ **`RegionState`（`Model.cs:71` ＝ `{ Active, Locked }`）とは別物。** 名前を衝突させないこと
（★あちらは州の**生死**、こちらは州の**格**）。

★ **史実の三分法そのもの**——アイルランドは1801年に英議会へ議席を得たが、インドは最後まで得なかった。
**「併合」と「植民地化」は別の行為**だった。

★★ **`Core` / `Integrated` の判定規則は §3-1a、それぞれの「仕事」は §3-1b。**

★★ **プロジェクト自身の成功パターンと同じ形**：

```

## 3-1a. ★★★ コアの判定＝**1633年から保有**（作者裁定 2026-07-31）

> **直近150年で併合した州は、自国領ではあるがコア州ではない**」
> 「**コアはゲーム中で不変**」

```

判定   IsCore ⟸ (1783 − heldSince) >= 150      ★すなわち 1633年以前から保有

|---|---|

## 3-3a. ★★ 独立と分離独立の一元化（作者裁定 2026-07-31）

> **作者**：「独立と分離独立は一元化したい。**事実上同じようなものなのに挙動が違うのは不自然**」

### 現物の2つの式

```csharp
// 分離独立（Politics.cs:1225-1245）
pressure = |国の関税姿勢 − 州の関税利害| × 州の平均闘争度 × SecessionPressureScale × (1 + CultureSecessionWeight × 文化距離)
         + SecessionCultureAdditive × MinorityMilitancy × 文化距離 × (1 − 中核民族シェア) × 闘争度      ← 民族主因（点火済 3.0）
分離 ⟸ pressure > SecessionThreshold かつ pressure > hold（中央の保持力）

// 植民地独立（Colonial.cs:186）
圧力（人口 × 不満）が 本国の抑え（軍 × 即応度）を超えた大植民地は離反
```

★ **構造は既に同じ**（圧力 vs 抑え）。違うのは**項の中身**だけ。

### ★★★ 一元化の鍵は「距離」——これ1項で植民地の特例が消える

```
圧力 = 闘争度 × 乖離（関税利害 ＋ 文化/宗教 ＋ 民族）× 規模（人口）
抑え = 中央の保持力（軍 × 即応度 × 行政力）★ ÷ 距離
```

★★ **なぜ植民地が独立し、アルザスがしなかったのか**——**遠いから**。
★ 現行の分離独立の式には**距離の項が無い**（本国の州しか対象にしていなかったので不要だった）。
★★★ **距離を `hold` に入れれば、植民地は「遠くて抑えの効かない州」として自動的に離反する。特例が1本も要らない。**

★ **距離は既に計算されている**：

```
Colonial.cs:29    「距離は物理消費（汽船の石炭＋駐留の缶詰）」＝本国首都からの大圏距離が既に維持費に効いている
Geo.SeaDistanceKm 海路距離（既存・InternationalMarket が使用）
```

⚠ **`Colonial.cs` の「人口×不満」は、分離独立側の「闘争度 × 規模」と同じもの。** 名前が違うだけ。

### ⚠ 一元化で変わること（帯リスク）

| | 旧（植民地） | 新（統一） |
|---|---|---|
| 駆動因 | 人口 × 不満 のみ | ★**＋関税利害・文化/宗教・民族**が加わる |
| 抑え | 軍 × 即応度 | ★**＋行政力 ÷ 距離** |
| 帰結 | — | ★★**文化の異なる遠い植民地は離反しやすくなる**（インド・アルジェリア）。★**文化の近い近い植民地は残る**（豪・加＝英系入植地） |

★★ **これは史実的に正しい方向**——白人自治領（加1867・豪1901）は「独立」でなく自治で残り、
文化の異なる植民地（印・アルジェリア）が最も激しく離れた。⚠ **ただし帯が動くので単独バッチで測る**（実施順 P7）。
