## 帯リスク
【器】帯は**1ビットも動かない**（上記 identityProof）。

【F1＝兌換の法化】★予測＝**金本位の加入が減り、加入までの年数が延びる**。
 理由の連鎖：
 - 現行は `Policy.GoldStandardTarget`（SelfPlay.cs:317＝工業化>1.5 で即 true）が**政治ゲートを通らずに** Fiscal.cs:356 の信用ゲートへ直行する。法にすると Government の `MandateGate`（純支持>−θ）を通る一歩になる。
 - F2 が入る前（Pref=0…実際は F1 単独では K2 の case が `return 0` のまま）は**賛否ゼロ＝純支持0**なので、`net > -MandateMargin(w)` の判定は「0 > 負の余白」＝**ほぼ常に通る**。つまり F1 単独では遅延は1四半期程度で、帯への影響は**小さい**と予測する。
 - ⚠ ただし `BlockedByIrreversibility`（Government.cs:365-385）の default は false なので双方向に動ける＝離脱→再加入のチャタリングが法の1段刻みで**遅くなる**方向。現行基線「兌換停止118回/30シード」（99_実装ログ:71）は**減る**と予測。
 - 副作用の経路：加入が減る → `GoldStandardRateDiscount = 0.6`（Coefficients.cs:524）の4割引を失う国が増える → 国債金利↑（Fiscal.cs:365 の convDiscount）→ 財政・列強次元。
 - ★忠実度の**法次元は動かない**：HistoricalReference の LawScore（HistoricalReference.cs:76-84）が測るのは 参政権/教育法/農奴解放/年金/穀物法/親軍 の6軸のみ。MonetaryStandard は対象外＝LawMatch 不動。exact/near は**経済規模・列強次元経由でのみ**動きうる。

【F2＝賛否の導出】★予測＝**帯は F1 より大きく動く**。

## 帯リスク
【器（器A〜器H）】帯は**1ビットも動かない**（読み手ゼロ・全州 Core・器Gは `!= Colonial` が全州で真）。

【点火①（Colony→Region）＝最大の変位。方向の予測】
・★**英・西・仏・蘭の総人口とGDPが跳ね上がる**。35植民地ぶんの pop が `TotalPopulation`・`AllPops()`・`Gdp` に入るため。`NationalScore.Wealth` の GDP 項と人口項が両方効く＝**英の国力が上がる方向**。⇒ 覇権抑制（memory の「英一強／清43%」の系譜）と**逆向き**に働く。
・★**領土次元は器Gで守られている**（`Tier != Colonial` を数えるので `HomeProvinces` は不変）。⇒ 点火⑦（征服州を `Integrated`）を**同じか直後のバッチで必ず入れる**こと。入れないと征服州が Core に数えられ、分子が膨らんで英/露の領土スコアが偽増する。
・★**捕囚市場を(b)削除で通すと英の可処分が落ちる**（本国完成財の需要が消える＝Colonial.cs:154-184 の `m.LastDemand += want` が消える）。(a)列挙差し替えのみなら中立。
・★**維持費の俸給が植民地popにも配られる**（`DistributeToPops` が `AllPops()` を回る＝Colonial.cs:244）＝本国popの取り分が薄まる。英の本国満足度が下がる方向。
・人口保存の是正で `PopulationDelta` の絶対値が増える（湧き消えが台帳内へ）＝`leakhunt` は**改善**方向。

【点火③（独立の一元化＋距離）】
・★**文化の異なる遠い植民地が離反しやすくなる**（インド・アルジェリア型）／**文化の近い遠い植民地は残りにくくなる**（加・豪も距離で不利）。⇒ 英の植民地数が減る方向。`HistoricalReference` の `ColonyProvinces1914`（±50%）に対して**英が下振れするリスク**。
・pressure 側に関税利害・文化/宗教・民族が加わる（Politics.cs:1232/1237）＝doc §3-3a の表のとおり駆動因が増える。`SecessionCultureAdditive = 3.0` が既に点火済みなので、**植民地州は文化距離1.0・CoreEthnicShare 0 で圧力が最大化しうる**＝独立が多発する危険が実在する。★点火③は単独バッチ必須。

【点火④（議席除外）】
・英の議会構成が変わる。植民地popの階級構成（農民・職人が主）は保守票を出しやすいので、除外すると**英が自由化しやすくなる**方向の可能性。ただし `FranchiseVoice`（参政権ゲート）で植民地popが元々ほぼ投票しない可能性もあり、**実測しないと符号が決まらない**。

【点火⑤（昇格）】
・`CoreEthnicShare = 0` で植民地州を作れば（点火①の必須条件）、`EthnicAssimilation = 0.0025/四半期`＝世紀単位でしか 0.5 に届かない ⇒ **1783-1934 の151年ではほぼ発火しない**（doc §6未決11 の見立てどおり）。帯への影響は小さい。⚠ 逆に `CoreEthnicShare` を既定1.0のまま作ると**全植民地が初回判定で即昇格**して機構が空転する。

【総合】exact/near は点火①で一度大きく崩れるのが自然。作者裁定（2026-08-01）＝**帯の悪化だけでは差し戻さない／悪化値は必ず記録する**に従い、破綻0・デッドロック0・要注意フラグ0・leakhunt清潔だけを硬性ゲートにする。
