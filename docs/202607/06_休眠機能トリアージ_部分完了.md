# 5. 方法メモ

- 休眠の定義＝`portledger` の「休眠（0）」出力（Coefficients反射・2026-07-29断面＝33件）。**点火済みだがパラメタ裁定待ち**のもの（例：SchoolingConvStock g=1.0）は休眠でないため対象外
- 過去の点火実測（差し戻し・却下）はCoefficients.csのコメントに全件記録されており、本書はそれを覆さない（再測定は#17再較正で帯の物差し自体が動いた後のみ意味を持つ）
- 面白さの判定基準＝「パンの値段→飢え→怒り→政変」の連鎖に新しい因果の顔を足すか（概要doc 1-1/1-5）。プレイヤーに見えない整合系は必要性（正しさ）側で評価した
