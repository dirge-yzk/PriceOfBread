# 1. 問題提起と判断基準

> **作者**：「金利バーがあるが、よくわからない問題がある。金利を下げると経済にどのように影響するのかが不明瞭。
> **『Aな場合、Bすると良い』なら、そもそもレバーである必要がない。**」

★ **判断基準＝常に正解が決まっているものは決定ではなく作業。**
レバーであるべきなら「何かを得て何かを失う」トレードオフが要り、**どちらが良いかは目的によって変わる**必要がある。

そして現状の AI 実装が、その指摘をそのまま体現している：

```csharp
// SelfPlay.cs:396-399
if (drawdown > 閾値)        p.InterestRateTarget = 0.05;   // 後退＝緩和
else if (heat > 閾値)       p.InterestRateTarget = 0.45;   // 過熱＝引締
else if (heat > 閾値×0.75)  p.InterestRateTarget = 0.32;   // 兆候＝予防的引締
else                        p.InterestRateTarget = 0.22;   // 平時＝中立
```

**4つの if と4つの定数で決まるなら、それは決定ではない。**

# 2. 診断（3点・代数で確定）

## 診断① 金利は自分の像しか見ていない ＝ 経済に接続していない

```
Credit.cs:99   bank.Heat    = Loans / effMaxLoans
Credit.cs:100  targetLoans  = effMaxLoans × Confidence × appetite
                              ↑ 分子分母で完全に約分される

→ 定常で   Heat = Confidence × appetite
   appetite = clamp(1 − InterestRateEffect(1.5) × InterestRate, 0, 1)
```

★★ **`effMaxLoans`（＝`bank.Gold × (CreditMultiplier−1) × devFactor × (1−run) × (1+lolrBoost)`）が
丸ごと約分されるため、`BaseMoney`・金の流出入・工業化度による信用深化（devFactor 0.35→1.0）・
銀行取り付け・最後の貸し手が Heat に一切現れない。**

そして **AI はその Heat を読んで金利を決めている**（`SelfPlay.cs:395`）＝**自分の出力を自分の入力にしている**。

| InterestRate | appetite ＝ Heat（Conf=1） | coverage |
|---|---|---|
| 0.00 | 1.000 | 0.403 |
| 0.05（AI緩和） | 0.925 | 0.422 |
| 0.20（AI中立の実効） | 0.700 | 0.491 |
| 0.25（既定） | 0.625 | 0.520 |
| 0.30（AI予防引締の実効） | 0.550 | 0.551 |
| 0.45（AI引締） | 0.325 | 0.675 |
| 0.50（プレイヤー上限） | 0.250 | 0.730 |

## 診断② 利下げの代償が**代数的に存在しない**

```
Coefficients.cs:426-427   OverheatFragility = 1.1 ／ OverheatFragilityThreshold = 1.0
Credit.cs:56              overheatFragility = 1.1 × max(0, Heat − 1.0)

Heat の定常値 = Conf × appetite ≤ 1.0
→ max(0, Heat − 1.0) ≡ 0
```

★★★ **金利を 0 まで下げても超過分はちょうど 0。**
コメントが謳う「低金利→信用ブーム→ある日 Confidence 崩壊で恐慌」（`Credit.cs:65`・`EconomyStep.cs:382`）は
**レバー操作からは構造上到達できない。**

Heat が 1 を超えるのは分母 `effMaxLoans` が縮むときだけ＝
(a) 取り付け（`avgSat < ConfidencePivot 0.65` が原因・**金利は無関係**）
(b) 金流出で `BaseMoney` 減
(c) 金本位のカバー率抑制
——**いずれも金利レバーの外側の事象。**

### 他の経路も潰れている

| 経路 | 実態 |
|---|---|
| ①貸出→投資→工業化 | ★**投資予算アームが約10⁴倍の余裕で非拘束**。拘束条件は `S < 25C` だが実際の投資家貯蓄は 8,000,000（`Simulation.cs:502`）。**Loans が注入されても建設は1単位も変わらない**。レバー全振り(0.05→0.45)で **ΔInd ≒ 0.039・生産性 indMult で 0.46%・到達に約30年** |
| ②国債金利 | 上乗せ最大 0.008〜0.010 が `BondRateMax = 0.30` のクランプに**丸ごと飲まれる**（典型値で寄与100%消滅）。★**債務/年GDP が 17.4% を超えた瞬間に導関数が厳密に0** |
| ③外資引き付け | 相対では最大（覇権国で ret の +80%）。だが着地先の投資家貯蓄が非拘束なので**工業化に1単位も効かない**。★実質は「**無利息の国内与信を、年8%を払う外資に置き換える一方向の劣位交換**」 |
| ④為替 | ★**金本位（Convertibility=1）では `World.cs:580` の `rateTarget = floatTarget + (1−floatTarget)×Conv` が floatTarget を打ち消し、恒等的にゼロ** |
| ⑤物価（**未文書の5本目**） | Conv<1 のとき `money = BroadMoney + (BaseMoney−BroadMoney)×Conv` に Loans が丸ごと乗り、**物価水準を約×1.73動かす**。★**ここに本物のトレードオフがある**（インフレ→債務プレミアム↓＝得／fisher で名目国債金利↑・通貨減価→対外信用が最大42%削れ資本逃避が約3倍＝損）。**ただし金本位下では完全に死ぬ** |

## 診断③ 金利の両端が**同じ財布**に着地する

**利下げ（与信・`Credit.cs:112-118`）も利上げ（外資・`CapitalMarket.cs:122`）も、
同じ投資家POPの同じ `Savings` に入る。** 正反対の操作なのに着金先が同じ
——これが**レバーがトレードオフに見えない構造的原因**。

## 4-4. ★ B5 — 時間非対称が「後から効く決断」を作る

`convTarget` を bool から coverage の連続関数へ（**新しいスカラーを増やさない**＝`Convertibility` は既存の World 状態）。

```
信認を失う（Conv 1.0→0.6）：DropSpeed 0.34 → 90%到達 5.5四半期 ≒ 1.4年
買い戻す  （Conv 0.6→1.0）：RiseSpeed 0.05 → 90%到達 44.9四半期 ≒ 11.2年
                                                    ＝ 8倍の非対称
```

★ **「今の利下げは安い。戻すのに11年かかる」**——既存の係数がそのまま牙になる。

**バンドの置き方（既存係数だけで組む）**：
`lo = GoldCoverMin × GoldRejoinCoverMargin = 0.25 × 1.3 = 0.325`
`hi = lo × (1 + GoldCoverCreditRestraint) = 0.4875`

★ **強制離脱線 `GoldCoverMin = 0.25` はそのまま残す**（到達不能でよい）。停止は貿易・戦争・賠償・資本逃避といった**外生の金流出**が来たときに起きるべきもの。

★ §4-B5 が入ると **coverage が金利で動く**ので、AI は初めて

⚠ **塞ぐべき抜け穴**：`Fiscal.cs:332` により**自発離脱にはクールダウンが付かない**（強制離脱だけが5年）。

# 5. ★ 却下すべき案（すべて計算で潰した）

| 案 | 却下理由 |
|---|---|
| **`OverheatFragilityThreshold` を下げる** | 効かせるには θ≈0.45〜0.50 が要るが、そこでは**平時の全国が常時発火**する。θ=0.65 でも Confidence −2.4% にしかならない。**外科的倍率に堕ちる（思想②違反）** |
| **`PolicyRateBondWeight` を上げる** | `Fiscal.cs:365 Min(BondRateMax=0.30, ·)` に飲まれる。**債務/年GDP ≥ 0.174 で導関数が厳密にゼロ** |
| **`GoldCoverCreditRestraint` を上げる** | 作動域 [0.25, 0.375] を到達可能域 [0.403, 0.730] へ引き上げると、低金利側で常時発火＝**利下げが即座に与信を絞る＝符号が逆** |
| **金利に `PolicyAxis` を与える** | `Government.cs:151-152` が `CountOpenFronts` から**明示的に除外**（「機械追従・無抵抗レバー＝金利」）。13本の法と枠を奪い合う |
| **正貨準備の独立ストックを新設** | `World.cs:989 BaseMoney` が既に準備で、`Invariants.cs:26-35` が全断面で検査している。**二重定義になる** |
| **`InterestCeil` を 0.5 超へ** | `appetite = 0` は IR = 1/1.5 = 0.667。上限を上げると**プレイヤーが信用を完全停止できる**——1783-1934のバンクレートにそんな力は無い |
| **UIに説明文を置く** | ★**思想⑦違反。** 可読性は**符号付き寄与量の並び**（`GameViewModel.cs:1011-1019 ExplainTerms`・描画は `GameView.axaml:295-299`）と**帯**で示せる |

★ 最後の1件について——作者は「ここだけ例外を置いてホバーで各選択肢のメリットを出す」案を出したが、
**`HANDOFF.md` のUI規律は「データを並べるツールチップはOK」と既に許可している。**
禁じられているのは「〜すると〜になる」という散文だけ。**差分表（選ぶ前→後の数値）なら規律の内側**で、
しかも盤面依存なので汎用の説明文より情報量が多い。

```
金本位
  国債金利     0.078 → 0.047
  兌換          0.00 → 1.00
  正貨カバー    0.31   必要 0.25
  金利          自由 → 準備に従属
```

⚠ **まず差分表を作り、それで足りなければ1行足す**——逆順（先に散文を書いて削る）より安全。
例外を置く場合は**場所を限定して記録し、各項1行に制限する**こと。

# 6. 実装から帰納した「良いレバーの5条」

| 条 | 内容 | 金利は満たすか |
|---|---|---|
| **1** | **政治価数がある**（`PolicyAxis` に載り、保有から賛否が創発する） | ✗ `PolicyAxis` 全26要素に金利は無い |
| **2** | **払う代価がある**（`CountOpenFronts` で `MandateSpent` を燃やす、または国庫を消費） | ✗ **コードが明示的に除外** |
| **3** | 主体によって最適が違う（教義・与党・国情で割れる） | ✗ **53カ国・4教義・3与党が全て同一の4定数を使う** |
| **4** | 効果が観測できる（UIに入力と結果が出る） | ✗ AIが読む2入力（`GdpDrawdown`/`FinancialHeat`）は**UIに数値表示が一切ない** |
| **5** | 単調でない（上げ続ける/下げ続けるが最適でない） | ✗ 診断②により**完全に単調** |

★ **金利は5条すべてを満たさない。** そして**唯一〈連続スライダー・教義非依存・政治コストゼロ・53カ国同一・入力非表示〉を全て満たすレバー**でもある。

⚠ **AIが単純な if で決めているレバーは他に8件ある**（金利が筆頭）。同じ基準で棚卸しする価値がある。
⚠ **法26行のうち15行はどのAIも一度も書かない＝プレイヤー専用**（思想⑤「プレイヤーとAI完全対等」の未達）。
⚠ **書き手ゼロの死んだレバーが3本ある**（AIもUIも書かない）。
