# 3. 設計

## 3-1. pop 属性化と漸近形

```csharp
Pop に追加   public double NationalConsciousness;   // ∈[0,1]

毎期        p.NationalConsciousness += rate × (target − p.NationalConsciousness)
            target = 新聞・ラジオ・徴兵から立つ「その pop に届いた国民形成の水準」
```

★ **教育（`TechEducation.cs:42`）と厳密に同じ形**——「買えた水準へ漸近」。
★ 世代減衰（`LiteracyGenerationalDecay`）と同型の減衰も踏襲できる（`CrownParliament.cs:235` の `lose` が対応物）。

★★ `World.NationalConsciousness` は**人口加重平均を返す読み取り専用プロパティ**として残す（§2-3 の6箇所が無改修で動く）。

## 3-2. ★★★ 「直接的な値でなく」が、財の性質だけで成立する

⚠ **作者の要求＝植民地・遠隔・非コアで上がりづらいこと。ただし倍率を書かない。**

★★★ **書かなくてよい。財の性質が既にそれを与えている。**

| 経路 | 財 | ★なぜ植民地・遠隔で細るか |
|---|---|---|
| **教育** | 教育(94) **Service・NonTradeable**（`Catalog.cs:148`） | ★★**運べない＝現地で生産するしかない**。教師のいない植民地は**教育の充足が構造的に0** |
| **新聞** | 新聞(134) **Daily・交易可**（`Catalog.cs:252`） | ★★**物として運ばれる**。遠隔州は輸送スロットル（`LastTradeThrottle`）で細り、★**港のない内陸は鉄道が無いとそもそも交易網に非接続**（⚠ 2026-08-12以降は二国間交易＝州と州の実経路） |
| **ラジオ** | ラジオ(135) **Daily・交易可** | 同上＋電化インフラが要る |
| **徴兵** | — | ★総動員時のみ（§3-4） |

★★★ **二重の門になる：**

```
教育が届かない → 識字が上がらない → ★新聞の需要すら立たない（需要は識字比例）→ 国民意識が上がらない
```

★ **どこにも「植民地は ×0.5」と書かずに、構造だけで遅くなる。**

★★ **距離も同じ形で入る**——「距離 → 国民意識」という直接項ではなく、
**「距離 → 輸送スロットル → 新聞が届かない → 国民意識」**という3段の経路。

### ★ 史実の裏づけ

★★ **Eugen Weber『農民をフランス人にした』（1976）**——1870年のフランスは人口の半分がフランス語を話さなかった。
国民意識は**学校・徴兵・鉄道・新聞**が作った。★★★ **ブルターニュが遅れたのは抵抗したからではなく、
学校も鉄道も新聞も無かったから。**

★ 本設計はこの因果をそのまま実装している——**遅さは態度ではなく物流の帰結。**

## 3-3. ⚠ 非コアの扱い＝民族と国民意識を混同しない

★ **`CoreEthnicShare`（民族）と `NationalConsciousness`（国民意識）は別物。**

| | |
|---|---|
| **民族** | 何であるか。★ブルトン人はブルトン人のまま |
| **国民意識** | 誰と同一化するか。★**ブルトン人はフランス人になった** |
| ⚠ 反例 | ★**アルジェリアのムスリムは「統合」されてもフランス人にならなかった** |

★★ **したがって「非コアだから上がりにくい」を民族シェアで直接書かないこと**（それは同化の話で、別の量）。
★ 非コアが遅れるのは**教育法・新聞・鉄道がそこに向かなかったから**であって、民族そのものではない。

⚠ ただし**間接的な結合はある**——`AssimilationEducationBonus = 0.007`（公教育の同化加速・`Coefficients.cs:464`）
＝**同じ学校が、同化と国民意識の両方を進める**。★ これは二重計上ではなく、**同じ物（学校）が2つの結果を持つ**。

## 3-4. ★★ 植民地徴兵＝総動員時のみ（作者裁定・★法を作らない）

> **作者**：「植民地徴兵は法律化（あるいは**総動員時のみ動員される**）とし、**軍量と軍質のトレード**とするのはどうか」

★★★ **「総動員時のみ」を採る。新しい法軸を作らない。**

| 理由 | |
|---|---|
| ★**法軸の増設基準を満たさない** | 「新しい法軸が正当化されるのは**賛否連合が既存のどの軸とも違うときだけ**」。⚠統合後は植民地 pop も**大衆**なので、`ConscriptionLaw` と連合が重なる |
| ★★**史実がそのまま** | **仏がセネガル狙撃兵を大量徴集したのはWWI**（戦前は限定的）。英印軍も両大戦で激増。★**植民地徴兵は戦時の非常措置だった** |
| ★**器が既にある** | `w.Mobilized`（プレイヤーの戦時レバー）＋`MobilizationConscriptFrac = 0.22` |

### 実装＝2点だけ

```csharp
① 徴兵の対象を RegionTier で分ける（Military.cs:44 の foreach に条件）
     平時    ： Colonial を除外
     総動員時： 全州

② ★国民意識ゲートを「国のスカラー」から「その州の pop 加重平均」へ（Military.cs:42）
     旧  conscriptFrac *= f(w.NationalConsciousness)          ← 国1個
     新  州ごとに      *= f(その州の pop の国民意識)           ← ★pop化の直接の帰結
```

★★ **これで墺洪が正しく出る**——**中核州（独語圏）は深く動員でき、チェコ・ガリツィア・クロアチアは浅くしか取れない。**
★ 国の平均で潰さず、**州ごとに違う深さ**になる。

### ★★★ トレードオフは自動で立つ

```
平時     植民地 pop は国民意識が低い → ★徴兵ゲートで実質的に取れない
総動員   植民地 pop も徴集される     → ★量は増える
                                     → ⚠ 国民意識が低いので、その州のゲートが深さを削る（質）
                                     → ★★★ 徴集された植民地 pop の闘争度が上がる → 分離圧力へ
```

★★★ **これが1919年**——**WWIで従軍したインド兵・セネガル兵の経験が、戦後の独立運動を育てた。**
★ **新しい機構がゼロ**で、国民意識の pop 化と分離独立の一元化の帰結として出る。

## 3-5. ⚠ 史実の補正：「多国籍軍＝弱い」は半分が神話

★ 設計の駆動因を誤らせるので記録しておく。

| | |
|---|---|
| **墺洪** | 弱さの主因は**コンラートの攻勢ドクトリンと展開の失敗**。⚠チェコ第28連隊の投降は**例外的で、後にチェコスロヴァキア民族主義が神話化した** |
| ★**実態** | **同族と戦うかで変わった**——クロアチア・ボスニア部隊は対伊/対セルビアで精強。チェコ部隊は対露で弱く（汎スラヴ）、対伊では戦った |
| ⚠**英印軍** | ★**むしろ精強**（WWIで130万人従軍）。長期服役の職業兵 |
| ⚠**セネガル狙撃兵** | ★同じく有効 |
| ★★**1857 インド大反乱** | ★**植民地兵の真のリスクは「弱い」ことではなく「牙を剥く」こと** |

★★★ **したがって「植民地兵＝低品質」という直接の倍率を書かないこと。**
★ 正しくは——**国民意識が低い兵は動員の深さが取れない**（既存実装どおり・量）／**質は民族統一度が担う**（`UnityMilitaryQuality`）／
★★**牙を剥くリスクは闘争度→分離圧力**（§3-4）。

## 3-6. ★★★ 国民意識は分離圧力を軽減する（作者裁定 2026-07-31）

> **作者**：「**国民意識は分離圧力を軽減する**」

### ★★ 3つの量が、それぞれ別の仕事をする

```
分離圧力 ∝ ★文化距離        （別の帰属先が【存在する】）        ← Region.Culture・★静的
         × ★少数派比率       （その人々が【実際にいる】）        ← 1 − CoreEthnicShare
         × ★★(1 − 国民意識)  （いまの国に【同一化していない】）  ← ★★★これが新規
```

★★ **民族と国民意識を取り違えないこと**——★ 止めるのは**民族構成ではなく、いまの国家への同一化**。

| | 文化距離 | 少数派比率 | 国民意識 | 帰結 |
|---|---|---|---|---|
| ★**アルザス 1871-1918** | 大 | 大（独系） | ★**独への意識が高い** | ★★**激烈な失地回復運動** |
| ★**ブルターニュ 1900** | 大 | 大（ブルトン） | ★★**仏への意識が高い** | ★**分離しない** |
| ★**ハンガリー 1848** | 大 | 大 | ★**ハンガリーへの意識** | ★**分離を試みる** |

★★★ **ヴェーバー『農民をフランス人にした』がそのまま式になる**（§3-2 と同じ因果）。

### ★★★ 閉じた輪になる

```
★学校・新聞・鉄道が届く   → 国民意識↑ → ★★分離圧力↓
⚠届かない（植民地・遠隔）  → 国民意識↓ → ★★分離圧力↑
```

★★ **§3-2（財が届かないから上がらない）と噛み合う**——**遠隔州は輸送スロットルで新聞が届かない**
→ 国民意識が低い → **距離の項を別に書かなくても分離しやすくなる。**

⚠★★★ **したがって「分離独立の `hold` に距離の項を足す」案は不要になるかもしれない**
（別docで提案したが、**距離 → 新聞が届かない → 国民意識が低い → 分離圧力**という3段で代替できる）。
★ **直接的な値を1本減らせる**＝今日の基準（時代不変でない定数を関数へ）に合致。

```
            → ★★安定した19世紀後半のヨーロッパ
```

★★★ **「分離の時代」が前半に集まるのは史実どおり。**
