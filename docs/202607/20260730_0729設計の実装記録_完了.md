## 2-13. B5 兌換目標をカバー率の連続関数へ

```

```

★ **加入していても準備が薄れれば兌換は目減りする**＝金本位期でも物価・国債金利・資本・為替のチャネルが死なない
（診断④「金本位では為替経路が恒等的にゼロ」・診断②-⑤「金本位下では物価経路が完全に死ぬ」の解除）。
★ **牙は既存の非対称速度が持つ**＝信認を失うのは1.4年・買い戻すのは11.2年（**8倍**）＝「今の利下げは安い。戻すのに11年かかる」。
★ 強制離脱線 `GoldCoverMin = 0.25` はそのまま（停止は外生の金流出が来たときに起きるべきもの）。
★ `ConvertibilityCoverageBand = 0` で旧 bool へ縮退＝厳密恒等。

# 5. ★ 新たに判明した未決（ユーザー裁定が要る）

| # | |
|---|---|
| 1 | ★**個別建設の動詞はプレイヤー専用のまま**。`World.BuildFactory` の呼び出しはUIの1箇所だけで、**AIは工場もRGOも個別には建てない**（AIの対応物は集約投資 `IndustryInvestFrac` → `StateBuildQueue`）。RGO解禁でこの非対称が1財種ぶん広がった。AIに「どの財をどの州で建てるか」を与えるかは**帯リスク大の別ラウンド**。 |
| 2 | 漁獲(20) をRGO建設に含めるか（土地を占めないので囲い込みの罠が働かない）。★**現状は含める**（除外は例外を1つ作るため）。 |
| 3 | RGOの建設費が `FactorySpec` の既定フォールバック（軽工業・30,000・4四半期）である点。カテゴリ名はUIに出ないので実害は「額が一律」だけ。RGO型の `FactorySpec` を足すかは未決。 |
| 4 | ★★**B4（民間貸出金利）は機構の作り直しが要る。** 現行は「残高×年率」を「借り手の現金」から引くので、与信を投資に回した借り手ではクランプが恒常的に binding する。**利息の課税ベースを当期の利潤（フロー）にする**か、**払えない分を債務へ繰り延べる**かの裁定が要る。それまでは 1/16（年0.125〜0.625%）＝方向だけ正しい弱いレバー。 |
| 5 | ★**U5（金本位／資本移動／金融政策の3択）には「資本移動の可否」という独立レバーが要る。** 現行 `CapitalOpennessTariffWeight` は関税連動で、資本規制を国が選べない。作るなら `Policy.CapitalControls`（bool）＋`CapitalMarket` の流入/流出ゲート＋「金本位×資本移動が自由なら金利は準備防衛に従属（＝金利バーが自動運転）」の3点。**この従属は `Government.Step` に置く**（プレイヤーとAIの両方が同じ経路を通る唯一の場所＝思想⑤）。 |
| 6 | 阿片の輸出法のAI規則＝「自国が全面禁止に至った国だけ輸出も禁じる」で暫定実装した。史実の英は**自国で禁じずに輸出だけ続けた**ので、輸出法を別の条件（外圧・緊張・道徳運動）で動かすかは未決。 |
