# 設計メモ（2026-07-09・ユーザー発案／未実装）

## 3. 創発的な国内勢力（一揆・太平天国・地方軍閥・政党の統一機構）【アイデア段階】
**要求（ユーザー）**：新勢力はハードコードでなく「不満＋目的＋（可能なら）イデオロギー」から国内に生まれる。内乱もこれに合わせる。目的による結合・分裂は政党にも流用したい。

**核心設計＝勢力(Faction)は「派生オブジェクト」**（人を新たにシミュしない）：
- **出現**＝既存状態のクラスタリング：闘争度>閾値のpop群を「イデオロギー座標の近さ×階級×地域」で束ねる（国民イデオロギー9軸・per-pop闘争度・ブロックは実装済み＝材料は全部ある）
- **要求ベクトル**＝そのクラスタの `PolicyPreferences` と現行法/政策の**乖離が最大の軸 top-k**（法をゲートする同じPref表から要求が導出される＝**要求のハードコード不要**という対称性が美しい）
- **一揆は州単位でよい**（州別FoodFill・州別popは実装済み。食料・税の暴動＝州、綱領的運動＝国）
- **解決の3択**＝鎮圧（既存 challenge vs coerce）／**譲歩＝要求軸の強制法改正**（マンデートマージンの逆符号＝反乱は「負のマンデート」として政治ゲートを外から破る）／経済的宥和（既存の福祉・減税）

**結合・分裂のルール（ユーザーの懸念への答え）**：
- 結合条件＝同一標的（反政府）**かつイデオロギー距離<閾値**。距離が遠いと結合しない——ここが史実的に重要：
  - **太平天国の実史**＝紳士層（貴族相当）は農民反乱と結合**せず**、異端イデオロギーとの距離ゆえ**王朝側で郷勇（湘軍）を組織**した。つまり同じ距離ルールが「貴族+農民の結合」（フロンド・1789初期）と「貴族が体制側に付く」（曽国藩）の**両方を無料で生む**
  - 結合しても**呉越同舟＝脆い**：勝利or主要求達成で分裂（革命は子を食う＝勝利後の第二内戦リスク）。1789の貴族立憲派と農民の8月4日的決裂もこれ
- **地方軍閥の創発**＝長期内戦で鎮圧側の州軍が力を蓄積→戦後も中央に戻らない（太平天国後の督撫重権）＝結合ルールの副産物として出る
- **政党への流用**＝同じFactionが「制度チャネル（franchise/議会）がある所では政党として選挙で戦い、無い所では運動/反乱になる」＝英の社会主義者は政党・露では革命家。**王権議会モデルの制度チャネル＝圧力弁とそのまま接続**。将来的に3固定政党をFaction由来に置換可能

**「上手くいかない気がする」への段階検証案**：
- Phase 1＝州一揆のみ（既存機構の組合せ・3択イベント）
- Phase 2＝**Factionクラスタを読み取り専用で表示**（「国内勢力」パネル）→ selfplayで清1850年代に太平天国様のクラスタが**実際に出現するか観察してから**牙を与える（＝安価な検証で設計不安を先に潰す）
- Phase 3＝結合/分裂＋内乱の書き換え＋体制側義勇軍
- Phase 4＝政党の統一
**修正（ユーザー方針2026-07-09）＝「変な勢力」を肯定する**：本作は史実再現ゲームではない。太平天国自体が「中国でキリスト教系の大反乱」という人類史級の異形＝**異形はバグでなく仕様**。例：墺で「大ドイツ主義×神道」の教団が反乱→独へ侵攻→国教法を神道に——**稀なら**この種の展開は歓迎、稀なら国家運営まで許容。
- **距離ルールは壁でなく勾配**：イデオロギー距離は結合の確率/コスト/脆さを決めるだけで禁止しない（遠い結合＝稀で壊れやすいが可能）
- **異端の変異（heterodox mutation）**：勢力の旗はクラスタ平均の写像だけでなく、**低確率で大きく逸脱**できる（洪秀全の受洗＝外来思想×土着不満の習合）。変異確率は**危機で増幅**（飢饉・敗戦・アヘン戦争後の広西＝千年王国運動は危機に湧くという史実法則そのもの）＋**外国接触で方向づけ**（交易・宣教＝墺の神道教団は対日接触があれば説明が付く）
- **頻度ノブ**＝変異確率×距離コスト曲線の裾＝「意味不明な勢力/政党が稀に生まれ、ごく稀に勝つ」を係数1〜2個で制御
- **決定論**：「稀に」は独立RNG系列（Discovery/Epidemicと同パターン）で実装＝較正/リプレイ安定
- **依存**：国教化などの要求先として宗教法ラダー（文化・宗教1D/2D座標ビジョン・未実装）が受け皿として欲しい＝勢力機構と宗教座標は同時期に入れると相乗

## 1. 二重計上監査 — 【実施時期＝全機構有効化の後・最後にやる】（ユーザー指示）
貨幣系は不変条件が構造的に保護済み・機会的除去も多数実績あり（圧政=軍一本化・財15 LastSold・PrizeLossProrated等）。**未監査＝非貨幣5系統**：満足度への加算群／闘争度のドライバ群／生産性乗数チェーン（techProd×労働時間×組合×鉱物×植民地…）／扶養力の修飾群／緊張のドライバ群。
休眠係数の大量有効化（A58）で「同じ根源が複数チャネルから同じ変数へ届く」構成が急増（例：貧困→InequalityMilitancy＋Crime経由＋飢饉経由が全て闘争度へ／汚職→財政leak＋正統性侵食＋閉鎖割引の三重）。**各変数への全流入経路を列挙→根源同一のものを「意図した重層／不自然な二重」に分類→ユーザー裁定**、の多エージェント監査（プレリリース監査と同型：発見→敵対検証）。**B43の判断やヴィンテージ資本等、機構の出入りが落ち着いてから実施すると効果最大**＝最後に回す。トリアージC判定の`PressureWeight`（重複経路）が先行事例。

## 2. 王権と議会の並列化 — 【アイデア段階・実装しない】（ユーザー発案）
**現状**：政体は離散ラダー（絶対君主→専制→立憲→共和…）＝Polity enumと遷移グラフ。
**案**：王権(CrownAuthority)と議会力(ParliamentPower)を**並列の連続2軸**として持ち、政体ラベルは導出表示に格下げ。絶対王政＝王権のみ／共和＝議会のみ／立憲＝両立／プロイセン型（議会はあるが軍・大臣は王権）や明治欽定憲法（王権を保ったまま議会を下賜）が**2次元空間の自然な点**になる。ワイマール後退も「議会力の合法的縮小」として連続的に表現可能。
**設計整合**：①「イデオロギーは創発化予定」「政策選好の脱ハードコード」方針の政体版＝遷移グラフの創発化 ②材料は実在（議会=Parliament/議席/FranchiseVoice・王権≈Legitimacy×圧政・NetSupportの議会項重み1.2・**今回実装のマンデートマージンは事実上「王権が議会/民意を押し切る力」**）。
**コスト警告**：Polity enumは遷移・テスト・UI・外交イデオロギー緊張・**較正のClassifyPath（Meiji/Tokugawa判定）**まで全域参照＝多国化以来の最大級リファクタ。目標④（政体多様性）の定義も要再設計。
**段階案**：(i) enum維持のまま2軸を内部状態として導入しゲート重みに接続 → (ii) ラベルを2軸から導出化 → (iii) 遷移グラフ廃止。**前提＝LegitimacyIsStock（#17）が先**（王権の経路依存が土台になる）。

### 3-b. 争議の梯子（ユーザー発案2026-07-10・Faction Phase1の具体化）
**スト合法性は新法でなく既存LaborUnion法**（非合法/統制/容認＝StrikeProductionHit 0.25・改革派動員は配線済み）。拡充＝**エスカレーション梯子**：不満→(識字×合法性の2×2で分岐)→①識字×合法＝**ストライキ**（要求付きミニ勢力・呑む/鎮圧/放置の選択イベント＝Faction Phase1第一号）②文盲or違法＝**暴動/一揆**（既存Desperation経路を選択イベント化）。合法ストは暴動の弁（実効閾値↑）＝「組合を許すか」が体制の安全弁選択になる。現状＝スト/暴動とも閾値0.5で梯子未形成・暴動は自動処理のみ（呑む/鎮圧の選択イベント未実装）。

### 3-c. 反乱の規模と統一内戦ロジック（ユーザー設計2026-07-10）
**規模＝兵員×資金**：反乱戦力＝参加popのSize（頭数）×軍資金充足。農民だけ＝頭数あれど**金がない**→装備/持続が尽き簡単に鎮圧（史実のジャクリー＝数週間で崩壊）。貴族/ブルジョアが支援＝**彼らのSavingsが軍資金**→大規模化（米独立戦争の仏資金・南京の富を得た太平天国）。**国家の軍と同じ経済**（Fund/装備充足/給与の流用）＝新物理なし。支援の成否は3-aの結合ルール（イデオロギー距離勾配）がそのまま決める＝規模機構と結合機構は同一物。
**同時多発＝存亡の危機（清型）**：既存 `ColonialHoldSharedArmy=0.5`（同時反乱で抑え分散）の内政版＝鎮圧力を戦線数で分割＋戦費の乗算。1〜2件は楽勝・5件で王朝崩壊が算術から創発。
**処理は戦争と同じでよい（判断＝可）**：押し合い(LandPower×投射)・軍資金(Fund)・厭戦・スコア→講和条件、の**式は全て流用**。反乱側は擬似Power（侵略標的の抽象Power＝Nation=nullの前例あり）として実体化・軍資金＝支援popのSavings移転（保存則は既存台帳パターン）。差分は講和条件のみ＝領土でなく**要求**（呑む水準＝反乱スコア比例）。地域基盤＝州の支配状態（分離機構が州反転の前例）。
**反乱＝内戦の統一（判断＝可能・中難度）**：**目的が違うだけの同一システム**に統一する——①要求貫徹（法/税）＝争議の武装版 ②王座（政体転覆）＝現行「内戦」 ③独立＝現行「分離」。内戦＝王座目的の最大規模反乱。現行の3separate機構（内戦/分離/絶望暴動）をFaction P3で畳み込む。難所は戦争機構がDiplomacy層（国家間）にある点＝式の流用は容易・オブジェクト共有は擬似Power方式で回避。**軍の帰属（4アクター）が鎮圧側戦力を決める**＝軍が離反した反乱＝ほぼ勝利（露1917）も同式から。

### 3-d. 反乱UIと軍の帰属（ユーザー確定2026-07-10）
**反乱イベント＝目的（法改正/減税等の要求top-k）と規模（兵員×資金）を表示し「受け入れる/鎮圧する」の2択**。国家転覆目的（内乱）のみ「鎮圧する」一択（受諾＝退位は選択肢でなく**鎮圧失敗の結果**として発生＝ルイ・フィリップ/ニコライ2世型）。AIも同じ2択を「要求コスト vs 鎮圧期待コスト」で判断。
**軍の帰属が両軍の規模を決める**：正規軍の実効鎮圧力＝軍×忠誠（協力度）・離反分は反乱側へ合流。忠誠＝給与充足（既存FiscalFundingRatio/即応度）×イデオロギー親和×親軍法。**給与を払えない独裁者はクーデター**＝忠誠崩壊時、軍自身が「王座目的の反乱勢力」として蜂起（統一内戦ロジックの一例＝既存の軍事独裁遷移をこの経路に置換）。露1917＝軍離反で鎮圧力ゼロ＝同式。
