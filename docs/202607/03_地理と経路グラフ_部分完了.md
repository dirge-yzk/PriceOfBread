# 0. 結論

**州をノード、k近傍を辺とする1本のグラフを作り、陸・海・国内・軍事投射をすべてその上の最短路で解く。**

置き換えられるもの：

| 現在 | 経路グラフ後 |
|---|---|
| `Geo.IsWestern` の二値判定 | **不要** |
| `Geo.SeaDistanceKm` の経由地1つ方式 | **不要**（グラフの最短路） |
| `ChokeBlockadePenalty = 0.8`（加法の当て木） | **不要**（封鎖＝辺のリスク） |
| `Geo.BasinOf` の矩形 | **不要**（海盆は港が持つデータ） |
| `StepDomestic`（国内交易の並行市場） | **不要**（同じグラフ内の最短路） |
| `NearestPortDistanceKm` / `InlandPortDistanceDecay` | **不要**（グラフ距離そのもの） |
| `Geo.ContinentOf` の陸続き判定 | **不要**（同じグラフ＝英軍がインドへ陸路、が構造的に起きない） |
| 陸の迂回率の係数 | **作らずに済む**（グラフが自動で出す） |

# 3. ★設計：1本の経路グラフ

## 3-1. ノード

| 種別 | 内容 | 数 |
|---|---|---|
| **州** | 158州（`Climate.CityCoord` に全数座標あり・欠落0） | 158 |
| **植民地** | `Geo.ColonyCoord` の46件 | 46 |
| **陸バリア** | 山脈・砂漠・無人内陸（★詳細 3-4） | 40〜60 |
| **海ノード** | 洋上の格子点（外洋は粗く・閉じた海は細かく） | 200〜400 |
| **通路** | 海峡・運河（★手置き・扼者と開通条件を持つ） | 9 |

## 3-2. 辺の張り方

```
陸の辺 ＝ 陸ノード同士の k近傍（k=5前後）を相互に張る
海の辺 ＝ 海ノード同士の k近傍。ただし「陸を横切る辺」は棄却（★3-3）
港の辺 ＝ 沿岸州 ↔ 最寄りの海ノード
通路の辺 ＝ 手置き（両端点の座標＋内部長＋開通条件＋扼者）
```

★ 同距離の決定性は既存作法（先頭優先＝`EconomyStep` の ArgMax と同規約）。

★ **k近傍は相互に張る**（A の近傍に B が入れば B→A も張る）＝非対称を作らない。

## 3-3. ★「陸を横切る辺」の判定

陸では偽の辺（狭い海を跨ぐ陸辺）は**陸単価が12倍なので勝手に使われず無害**。
**海では逆で、偽の海辺（イベリア半島を突っ切る）は安いので必ず勝つ**＝明示判定が要る。

```
規則：辺を9点でサンプリングし、いずれかの点から 420km 以内に陸ノードがあれば棄却。
      （通路＝海峡・運河は手置きなのでこの判定を通さない）
```

**実測 9/10 正答：**

| 辺 | 判定 | 引っかかった陸ノード |
|---|---|---|
| ビスケー湾→リヨン湾（仏を突っ切る） | **棄却** ✓ | ボルドー 337km |
| 大西洋中央→アゾレス沖 | 通す ✓ | — |
| ジブラルタル西→東 | 通す ✓ | —（通路） |
| ラゴス沖→ザンジバル沖（アフリカ横断） | **棄却** ✓ | ▲コンゴ 120km |
| 喜望峰の西→東 | 通す ✓ | — |
| 北海→バルト（ユトランド越え） | **棄却** ✓ | （ズンド通路を経由すべき） |
| ボンベイ沖→アデン湾（アラビア海） | 通す ✓ | — |
| ペルシャ湾→地中海（アラビア半島横断） | **棄却** ✓ | バスラ 389km |
| 南大西洋（ブラジル沖→アフリカ沖） | 通す ✓ | — |
| 紅海→地中海（スエズ地峡） | 棄却 ✗ | カイロ 368km ＝**通路を手置き辺にすれば解消** |

★ **閾値は固定値（420km）であること。** 辺の長さに比例させると、長い辺で遠い陸を見逃し（アフリカ横断が通る）、
逆に沿岸の点で過剰に棄却する（アラビア海が落ちる）。両方を実測で確認済み。

★ **アフリカ内陸に州ノードが無い**ので、バリアノード（▲コンゴ・▲サハラ等）が無いとアフリカ横断が通ってしまう。
**陸バリアは陸グラフと海グラフの両方で使う＝1つのデータが2つの役目を持つ。**

## 3-4. 陸バリアノード

```
アルプス／ピレネー／カルパチア／カフカス／ヒマラヤ／ヒンドゥークシュ
サハラ／コンゴ／カラハリ／アラビア内陸／シベリア／豪州内陸／アンデス／ロッキー
```

**山脈の長さに応じて点を並べる**（k近傍が跨がない密度が必要）。おおむね40〜60点。

★ **峠は「通行可能だが高い」ノード**にする＝二値ではなく費用。
ブレンナー峠・カイバル峠・キャフタ・モンスニが表現できる。

⚠ 作者裁定「陸地形は考慮しない」との整合：**地形係数は作らない。** バリアは通/不通（と峠の割増）だけ。
迂回距離はグラフが自動的に出す。

# 5. 単価とリスク

## 5-1. 陸単価（作者裁定：実効距離に吸収・新係数を作らない）

史実のトンkm比：**前鉄道期で海の約10²倍、鉄道後で約10¹倍**。逆転したことは一度も無い。
新しい係数を作らず、**陸の辺の重みに倍率を織り込む**（＝実効距離）。較正債務ゼロ。

★ これで **B2（地形を考慮しない）が破綻しない**：

```
デリー→ラサ  陸1,355km → 実効 13,550〜27,100km 相当（ロンドン→ボンベイ18,000kmより遠い）
アルジェ→カノ 陸2,806km → 実効 28,000〜56,000km 相当（＝隊商の経済）
```

**ヒマラヤをモデル化しなくても、陸単価だけでチベットは遠くなる。**

## 5-2. ★リスク（作者裁定：輸送財を消滅させない）

財を消すと `Invariants.cs:113` の収支恒等式が破れる。**マージンに乗せる。**

```
実効マージン ＝ 通常マージン ＋ リスク料
リスク料     ＝ 1 − exp( −Σ 敵支配度 × 区間距離 )
```

- 短距離・平時 → リスク料 ≈ 0
- 長距離・敵支配下 → リスク料 → 1 → **マージンが発散＝取引が成立しない**

**財は1つも消えない。** 割に合わない交易が起きないだけ。
拿捕の対価は既存の `PrizeCargoShare = 1.0`（点火済み）が**金銭の移転**として処理＝保存則も通る。

★ 副産物：`CommerceRaidFloor = 0.25`（「完全な制海権喪失でも中立船で25%残る」）が**不要**になる。
短距離のリスク料が自然にゼロなので、床を書く必要がない。

★ **経路に沿った線積分**になるので、区間ごとに敵支配度が違っても素直に足し上がる：

```
生存確率 = Π 各区間 exp(−λ_b × d) = exp( −Σ λ_b d )
```

# 6. ★地図への表示（作者裁定）

> 「k近傍を相互に張る、これはマップ上にも出したい。それなら、マップ上にピレネー山脈なども表示し、
> **そこに経路が引かれていないことを可視化**した方が良い」

| 表示するもの | 意味 |
|---|---|
| **陸の辺** | 州と州を結ぶ線＝陸路の骨格 |
| **山脈・砂漠のバリア** | 辺が張られていないことが見える |
| **海の辺** | 海路の骨格。大陸を横切っていないことが見える |
| **通路（海峡・運河）** | 扼者と開通状態 |

★ **これは思想⑦（UIに説明文を置かない）に反しない** — 説明文ではなく**データそのものの表示**。

★★ **そしてこれ自体が最強のデバッグ器になる。**
今日見つけた ×0.23（欧州域内）や ×0.38（アフリカ横断）は **grep では絶対に見つからない**が、
**地図に線を引けば一目で分かる**。型Fの検出器（`refprice`）と同じ役割を、地理に対して果たす。

★ バリアノードは当初「地図上には出さない」方針だったが、**表示する**に変更。
山脈が見えるから経路が曲がる理由が分かる。
