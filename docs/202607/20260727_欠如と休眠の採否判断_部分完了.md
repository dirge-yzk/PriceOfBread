# 欠如機能・休眠機能の採否判断 — **バランス後回し前提**（2026-07-27 改訂）

前版は設計思想④（帯を壊さない）をゲートとして判断していた。本版は**「較正は後でまとめてやる」という前提**で書き直したもの。判断軸が変わるので結論も大きく変わる。

> **★却下リストと「面白い順」はほぼ逆順である。** 劇的な歴史を生む機構ほど結果を動かし、結果を動かすほど帯が揺れる。帯は本質的に保守的な力として働いていた。前版で「実測で却下済み」とした11件のうち**7件は帯だけが理由**で、前提を外せば解禁できる。

# 0. 前提の変更と、その運用

## 0-1. ④は「ゲート」から「計器」へ降格する

**batch30 は回し続け、数字も記録する。それを理由に差し戻さない。** これだけを変える。

測るのをやめてはいけない理由がある。帯は「この機構は間違っている」と「機構は正しいが数値が要調整」を区別する**唯一の手段**である。記録をやめると、後で較正ラウンドを回すときにどこから狂ったのかを追えなくなる。**ゲートを外すのであって、計器を外すのではない。**

記録すべき最小セット（1バッチごと）：
```
exact / near / ◎ / 固着 / 逸脱過多 / 人口一致 / 破綻 / 清の勝率 / chronicle 総政変
```
差し戻さないぶん、**どの機構を何の値で入れたか**の台帳が前版より重要になる。`Coefficients.cs` の行内コメントを §0-4 の定型で書くこと。

## 0-2. 硬性ゲートは外さない

以下は帯とは別の種類の検査なので、バランス後回しとは無関係に維持する。
- `dotnet test` 169件緑
- `leakhunt` 清潔（貨幣・人口の保存則）
- 破綻 0/30（未完走がゼロ）
- 決定論（同一シードのビット一致）

**保存則を破る変更だけは、面白くても入れてはいけない。** これは較正で直せない種類の壊れ方だから。

## 0-3. 却下理由を2種類に選り分ける

| 型 | 前提を外すと | 該当 |
|---|---|---|
| **帯だけが理由** | **解禁できる** | 綿花ゲート・会議外交・矯正講和・坩堝鋼・連立歩み寄り・信認割引・第3群/第4群の各種 |
| **帯以外の理由がある** | **前提は変わらない** | 寡占（意味が逆）・単一国世界市場（台本禁止）・部隊ユニット（設計思想）・革命の波（二重計上）・電力費用構造（テストの前提） |

## 0-4. コメント規約（今回から必須）

差し戻さない運用では、行内コメントが唯一の履歴になる。
```
係数名 = 値;   // [状態:点火済み|休眠] [日付] 意味。点火時の帯＝exact__/near__/◎__。
```

# 2. 導入順（面白い順・依存を解いたもの）

**判断基準＝「名前のついた歴史的状況」がいくつ生まれるか。** このゲームの快楽は、書いていない歴史が機構から立ち上がることにある。

## 第1波：即入れられて効果が大きい

### ①綿花の栽培適地ゲート ★本命
`Climate.cs:31` の `CottonBeltLatMax` を **90.0 → 37.0** に変える。それだけ。

生まれるもの＝**ランカシャー綿花飢饉**。緯度で綿花の産地が限られ、南北戦争や封鎖で供給が断たれると英の綿工業が止まる。しかも**死んでいた機能が2つ生き返る**：

- `Simulation.cs:805-807` の**毛織衣料**と `:840` の**亜麻衣料**は、コメントに「綿花が断たれた時の代替（米南北戦争の綿花飢饉でランカシャーが羊毛へ）」と**まさにそのために書かれている**のに、本国が自前で綿花を産む限り出番がなかった
- 植民地の**海上リードタイム**（`ColonialImportLagMonths`）も存在理由を取り戻す（`EconomyStep.cs:82` が「本国の需要ギャップが当月中に植民地から即充足する＝綿花飢饉型の価格スパイクが減衰」と明記）

前例＝差し戻し2回。①4カ国テスト世界に綿花供給国（印・エジプト）がおらず綿布連鎖が詰まって米が死ぬ ②53カ国世界で exact33/near67・西人口×1.17。**②は純粋に帯なので解禁。①はテスト世界の問題なので、テスト側に供給国を足すかテストを除外する対処が別途要る。**

### ②対外戦争での民間人死亡
実装は `Diplomacy.cs:1272` のブロックに `CivilWarCivilianToll` と同型を足すだけ。**保存則の作法が既に2箇所で確立済み**なので小規模。

生まれるもの＝戦争が本当に恐ろしくなる。厭戦→革命の駆動が実体を持ち、封鎖の兵糧攻めが「厭戦」だけでなく餓死という帰結を得る。直近に強い採用前例（内戦ダメージ・戦場資本破壊はどちらも採用、後者は exact37/near70 で当時最良）。

### ③坩堝鋼／ベッセマー転炉の不連続
`CrucibleSteelEnabled` を 0 → 1。係数1本、配線完了済み。

生まれるもの＝1783年から安価な鋼が存在する現状が直り、製鋼法の転換が時代を刻む。鋼原価が+77%動いて機械部品〜工業財の連鎖に波及するので、**工業化のテンポそのものが変わる**。前例＝◎18→12（純粋に帯）。

### ④矯正講和（`ImposeRegimeEnabled`）
係数1本。生まれるもの＝**衛星共和国と反動介入が1本の一般則で両方出る**。「神聖同盟が革命を潰す」「フランスが姉妹共和国を作る」が国名も方向も書かずに起きる。

前例＝exact33/near65・逸脱過多17。1914政体分布に直撃するのが理由なので、まさに帯。

### ⑤会議外交（賠償抑制）
生まれるもの＝**ウィーン体制**。傍観する列強が多いほど勝者の取り分が削られる＝ヨーロッパ協調が機構として見える。

前例＝0.10 で exact41→38・清12→17。**ただし副作用の向きに注意**：賠償を削ると富の移転が減って清が entrench する。値を下げる（0.03〜0.05）か、会議度の定義を直すほうがよい（現在は `列強数(整数) × 勝者の脅威度` で飽和せず線形に伸び、覇権的な勝者ほど強く抑制されるという逆向きの形になっている）。

# 3. それでも導入できないもの（理由の型別）

## 3-1. 意味が逆になる — 寡占マークアップ

**バランスを後回しにしても解禁できない唯一の帯却下項目。** 却下理由が帯ではなく**機構の意味**だから。

> モデルでは独占が消費者→生産者の富移転で**伝統帝国を強くする**＝「独占は悪」の狙いと逆（`HANDOFF.md:243`）

つまり点火すると、独占が「儲かるだけのもの」になる。バランスの問題ではなく、**プレイヤーに与える選択肢の意味が反転する**。さらに偽独占の是正（`HhiIncludesRestOfWorld`）も exact39→36 で退行し、**偽独占が load-bearing** だったことも判明している。

**正しい順序＝#4（政治腐敗＋大衆 resentment ＝独占を純コスト化する）を先に作る。** それが入って初めて「独占は短期に儲かるが政治的に高くつく」というトレードオフになる。

なお**企業クラスの新設は不要**。代理抽象 `EffFirms`（`Model.cs:294`）が既にあり休眠しているだけ。

## 3-2. 設計思想に触れる

| 項目 | 抵触 |
|---|---|
| **単一国モードの世界市場ON** | 136財に固定世界価格を新規投入することになる＝**①台本禁止**。しかも現データでは全財 `WorldPrice=0` で空点火。永久に不可 |
| **部隊ユニットと前線移動** | **プレイヤーは政府であって将軍ではない**というゲームの本体と衝突。加えて州の隣接データがどこにも存在しない（`Geo.cs` は距離・海路・海盆の3機能のみ）＝新サブシステム＋新データ整備 |
| **自然災害を暦年で置く** | ①台本禁止。確率＋州別ハザードデータからの創発でなければならず、158州分のハザードデータ新規整備が要る |

## 3-3. 二重計上になる — 革命の波

既に別の因（時代ゲート＋共通緯度帯天候）から2年窓3カ国以上のクラスタが**23窓**創発している。足すと同じ効果が2回数えられる。闘争度target [PORT:P1] には既に7項が加算されており、うち MilCrowd（便乗＝国内版の同型機構）と二重化する。

**面白さの観点でも得がない**：波及は既に起きているので、プレイヤーから見た絵は変わらない。

## 3-4. 別の前提が要る

| 項目 | 前提 |
|---|---|
| **電力の費用構造（燃料主導化）** | 帯ではなく**米の技術アンカーテストを割った**（RefPrice電力の低下→電化前倒し→教育産出の労働が痩せる→Elite→Tech減速）。アンカーテストの再設計とセット |
| **綿花ゲートの4カ国テスト世界** | テスト世界に綿花供給国を足すか、当該テストを53カ国世界へ移す |

## 3-5. 決定を増やさない解像度（入れても面白くならない）

いずれも**死んでいる既存機能がゼロ**で、保存則の書き直しコストだけが残る。

- **州内空間構造** — 158州×136財の市場を都市/農村へ割ると Market 状態が倍。財収支恒等式と貨幣保存の検査を全経路書き換え＝決定論への露出が全項目中で最大
- **年齢別人口ピラミッド** — `OldShare` の読み手6件はすべて生きている。ビン化すると pop 併合/移動の加重平均7箇所すべての保存則を書き直す必要
- **疫病の病原体別区別** — 政策レバー（衛生・医薬）が病原体で変わらないので決定が増えない
- **世界市場の二国間化・航路グラフ** — 較正ラウンド級。帯を決める全機構が単一プールと `distF` 1本の上に載っている
- **最恵国待遇・関税同盟** — 二国間化が前提で単独実装不能（既に `#5関税同盟（匿名プールでMFN表現不能・SKIP）` と判断済み）
- **財の品質次元** — 136財すべてに品質値を国別特例なしで与える必要があり、データ整備が実装より重い

> **★品質次元には安い代替がある。** 「並存レシピ機構は原理的に『高品質・高コスト』型を選べない（常に安い方が勝つ）」のが本体なので、クロム鋼のような個別ケースは**別の財として立てて下流の生産性を上げる**ことで表現できる。次元追加は不要。

# 5. 事実の誤り・バグ — これも前提と無関係に直す

| 項目 | 何が間違っているか | 直し方 |
