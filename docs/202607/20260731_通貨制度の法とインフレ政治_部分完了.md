# 1. 問いと答え

## 1-1. 作者の問い

> **作者（2026-07-31）**：「現在は一般に、適切なインフレは年2%と言われています。**これは人類史において不変の値でしょうか？**

## 1-2. ★★★ 答え：2%は不変ではない。**1990年のニュージーランド発**

| | |
|---|---|
| **起源** | 1989年 NZ準備銀行法 → 世界初の明示的インフレ目標。★★**2%という数字は蔵相の口頭の発言が元で、理論的導出はない** |
| **普及** | 加1991・英1992・欧州中銀1998・★**FRBは2012年** |

★★ **2%の3つの根拠は、すべて20世紀の産物：**

```
① 名目金利のゼロ下限を避ける余地   ★ゼロ下限が問題として理解されたのは1930年代以降
② CPIの上方バイアス（約1%）        ★CPIという統計自体が20世紀
③ 名目賃金の下方硬直を潤滑する     ★ケインズ『一般理論』1936年
```

★★★ **1783〜1934年の為政者はどれも知らない。** ⚠ 2%目標を入れるのは**思想①に精神で抵触**する。

## 1-3. ★★ しかも当時は貨幣供給を制御できなかった

```
1848 カリフォルニア ／ 1851 オーストラリア ／ 1886 南アフリカ ／ 1896 クロンダイク
```

★ **物価は金鉱の発見で決まった。** 中央銀行が「今年は2%にしよう」と決められる世界ではない。

## 1-4. ★★★ 当時の目標は数字でなく**平価の防衛**、そして**目標そのものが政治的に割れた**

⚠ **2%目標の欠点は「正解が1つ」なこと。** ★★ 19世紀の金融政策には**正解がなかった**——**誰の側に立つかで正解が違った。**

```
★債務者（抵当を抱えた農民・投資家）  → インフレを望む（借金が軽くなる）
```

⚠ ただしこれは**デフレ側の粘着**（名目賃金は下がりにくい＝ケインズ的）で、★**インフレ側の遅れではない。**

### ⚠ そして賃金の帯が物価水準に連動している


★★ **賃金と財が同じ `pl` でスケールする** → ⚠ **一般物価の上昇では実質賃金は構造的に落ちない。**
★★★ **落ちるのは相対価格が動いたとき＝食料が特異的に高騰したとき。**

★ **そしてそれこそが史実の入口だった：**

## 3-4. ★★★ トリレンマのUIは「○3つから2つ」ではない（作者指摘 2026-07-31）

### ⚠ 「○3つから2つ」が嘘をつく理由

### ★★★ 採る形＝**2つの法＋1つの帰結**

★ トリレンマの論理は「3つから2つ選ぶ」ではなく——**2つ選ぶと3つ目が決まる**。
★★ 史実でも**誰も「金融政策の自律」を選ばなかった**——金本位と資本移動を選び、

```
────────────────────────────────
政策金利  ▓▓▓░░  32%           ← ★★選択肢ではなく【帰結】
```

★★★ **選べないものを選択肢に並べない。** ★ 並べること自体が嘘になる。

# 5. 却下すべき案

| 案 | 却下理由 |
|---|---|
| **年2%のインフレ目標を入れる** | ★★★**却下。** ①**1990年NZ発**で、根拠の3つ（ゼロ下限・CPIバイアス・賃金硬直）とも**20世紀の理論** ②当時は**金鉱の発見で物価が決まり**、供給を制御できなかった ③**思想①に精神で抵触**（存在しなかった政策目標を持ち込む） ④★**「正解が1つ」になり、19世紀の政治（誰の側に立つか）が消える** |

## 前提・ブロッカー

【着手前に潰す前提】

■作者の裁定が要るもの
 1) ★**軸の向き**。doc は明示していない。提案＝**軸の増＝兌換の維持（金本位）／減＝停止（管理通貨）**。
    根拠＝既存の `MilitaryExport`（増＝禁止）・`OpiumPossession`（増＝禁止）と同じ「増＝規律を強める」で揃う。Headroom/DemandJa/Pref の符号が全部この向きに従うので、後から反転すると3箇所を同時に直すことになる。

 2) ★**法の段数**（doc §6-3）。2段（維持/停止）か、3段（旧平価復帰／新平価／管理通貨）か。
    ⚠ **3段は現物に受け皿がない**：`Convertibility` は 0..1 の連続量だが「平価の水準」を持たず、`ExchangeRate` の平価は 1.0 固定（World.cs:623 `rateTarget = floatTarget + (1.0 − floatTarget) × Convertibility`）。「新平価で戻る」を表すには**平価そのものを状態にする**新設が要る＝別ラウンドのL案件。→ **本ラウンドは2段**を推す。

 3) ★★**pop 別の負債を作るか**（doc §6-2）。**F2 の形を左右する最大の分岐**。
    - 作らない（推奨）＝上記 F2 の `DebtorBloc(w) × LeverageShare(w)` 案。片翼（都市の債務者＝資本）しか立たず、doc §3-3 の「農村債務者」は出ない。
    - 作る＝`Pop.Debt` 新設＋`Simulation.BackstopNegativeSavings()`（Simulation.cs:1775-1821）の書き換え。⚠ **保存則の台帳（Bank.Loans / LossFinanced / CumulativeFiatIssued）に直接触る**＝別ラウンドの L 案件。本書の中でやってはいけない。

 4) ★**セーブ互換の断絶**を許容するか。World に bool を1本足すだけで既存セーブが読めなくなる（SaveGame.cs 冒頭の既知の制約）。

 5) ★**不可逆性**の扱い。`Government.BlockedByIrreversibility`（Government.cs:365-385）に MonetaryStandard を**入れない**（default: false のまま）＝可逆。史実が両方向に動いた（英1797停止→1821復帰／1925復帰→1931離脱）ので裁定不要と判断できるが、記録は残す。

■他doc・他作業への依存
 6) ★**資本移動の法**（doc §6-6b）は本書の範囲外。現行 `CapitalOpennessTariffWeight = 1.0`（Coefficients.cs:1459・Fiscal.cs:177-179）で openness が関税に完全連動＝国が資本規制を選べない。⚠ **doc §3-4 が主張する「4状態（兌換停止＋資本規制）」は F1 だけでは出ない**ことを、着手前に作者と合意しておく。
