## ★全タスク共通の規律（毎回必ず守ること）

### 1. 浮動小数の非結合（このコードベースで唯一、差分を見ても分からない形で壊れる罠）
- **既存式に項を足すときは掛け算順序を保存し、新項は独立加算にする。**
- **式を読みやすく整理してはいけない。** 括弧の付け替え・項の並べ替え・`Math.Clamp` での包み直しは、係数0（無効化したはず）のままでも軌道を発散させる。
- 実績：`Fiscal` の leak 式を `Math.Clamp` で包んだだけで chronicle 総政変が 148→158 に動いた（テストは全部通り、差分は正しく見える）。
- **恒等を主張する変更は、必ず「なぜビット単位で同じか」を1文で説明できること。**

### 2. コメントより実リテラル
- 「既定0＝休眠」「較正中立」というコメントは陳腐化が多い。**必ず `public double 名前 = 値;` の実値を grep で確認**してから判断する。

### 3. 休眠フラグ規律
- 挙動を変える変更は、**既定値で厳密恒等**になる係数の後ろに置く。恒等を証明してから点火する。

# バッチ1：恒等が自明な2件（既定値で厳密恒等）【✅完了・恒等確認済み】

## 修正1. B-高2 フロンティア出生ブーストの上限

**根拠**：`LandRoomFertilityWeight=0.3` は無上限で、米は西部解錠（≈1791年）後に landRoom≈3.7 → **出生率倍率が最大4.7倍**。実測 4.4M(1784)→19.6M(1808)＝**年6.4%成長**は、史実（3.93M(1790)→7.24M(1810)＝年3.09%）の2倍、**人類最大の観測値（フッター派1880-1950の年約4.0%）の1.6倍**で生物学的に不可能。機構自体は Easterlin の土地入手可能性仮説どおりで正しく、**誤っているのは上限がないことだけ**。

### 1-a. 係数の追加
`Successor.SimCore/Coefficients.cs`、`LandRoomFertilityWeight` の宣言行の**直後**に1行追加：
```csharp
    public double LandRoomFertilityCap = 1e9;      // B-高2（史実検証2026-07-22）：landRoom の上限＝フロンティア出生倍率−1。既定1e9＝実質無上限で厳密恒等。点火0.6＝倍率1.6（米CBR約55/1000÷基準35/1000が根拠）
```

### 1-b. 適用箇所
`Successor.SimCore/Simulation.cs`（現在の行番号 1364-1365）

**置換前（この2行を探すこと。行番号でなく文字列で照合）**：
```csharp
        double landRoom = c.LandRoomFertilityWeight > 0 && ruralSum > 1e-9
            ? c.LandRoomFertilityWeight * Math.Max(0, arableSum / ruralSum - 1.0) : 0;
```

**置換後（上記2行はそのまま残し、直後に2行を追加するだけ）**：
```csharp
        double landRoom = c.LandRoomFertilityWeight > 0 && ruralSum > 1e-9
            ? c.LandRoomFertilityWeight * Math.Max(0, arableSum / ruralSum - 1.0) : 0;
        // B-高2（2026-07-22）：フロンティア出生ブーストの上限。無上限だと米は landRoom≈3.7＝出生倍率4.7倍→年6.4%成長（史実3.09%・生物学的上限約4%）。
        landRoom = Math.Min(landRoom, c.LandRoomFertilityCap);
```

**⚠既存の2行の式は1文字も変えないこと**（掛け算順序の保存）。

**恒等の理由**：`Math.Min(x, 1e9)` は `x < 1e9` のとき `x` をそのまま返す（演算を行わない）ため、ビット単位で不変。landRoom の実測最大は約3.7 なので常に `x < 1e9`。

## 修正3. C-中9 制度疲労の破産ショックが生涯1回しか窓を開かない（**調査のみ**）

3. デフォルトは1ゲームに複数回起こりうるか（`HadSovereignDefault` 以外に回数を数えている変数があるか）。
→ **報告のみ。設計は Opus が決める。**
