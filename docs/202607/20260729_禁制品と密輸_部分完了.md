# 1. 何を作るか

**禁制品を財ごとの特例で書くのをやめ、「障壁があれば密輸される」という1つの機構にする。**

```
密輸率 ＝ f( 障壁の高さ ，  取り締まる力 ，  内外価格差 )

障壁     ＝ 関税 ／ 禁令 ／ 封鎖 ／ 専売       ← 全部同じ形
取締る力 ＝ 行政力                             ← 既存（消費税の徴収漏れと同じ）
価格差   ＝ 内外価格差                          ← 既存（InternationalMarket の閾値）
```

★★ **1つの機構で6つの史実が出る** —— 阿片・奴隷・大陸封鎖・茶・塩・武器。

## 1-1. 作者の判断（採否）

| | 判定 | 理由 |
|---|---|---|
| **阿片** | ★入れる | アヘン戦争の中核 |
| **奴隷** | ★入れる | 1783-1934 は労働制度が奴隷→年季→賃金へ移る期間そのもの |
| **武器** | ★入れる | 「戦時にどちらへ武器を供給するか」で勝敗を左右できる |
| **塩・禁酒** | **不要** | 「別にゲームが面白くならない」。★塩の専売は既に実装済み（`MonopolyRentPremium=0.15`・`Catalog.cs:323 SaltId` に gabelle の注記）で、密輸を一般機構にすれば**塩の密輸は無料で出る** |

★ **判断基準＝「ゲームが面白くなるか」。** 史実に在っても、決定を生まないものは入れない。

## 2-1. 阿片は「専用ルール」で書かれている（約35箇所・係数9本）

# 3. 設計

## 3-1. 法（4本＝2財 × 2種）

`ReformLevel { None, Limited, Full }` にそのまま乗る。**新しい enum が要らない。**

### 保有の法（3段）

| 段 | 阿片 | 奴隷 |
|---|---|---|
| **None** | 許可 | 許可 |
| **Limited** | **輸入禁止**（国内は合法） | **輸入禁止**（保有は合法） |
| **Full** | **禁止** | **禁止** |

★ **この順序は史実で例外なく守られている。**

| 国 | 貿易禁止 | 全面禁止 |
|---|---|---|
| 英 | 1807 | 1833 |
| 米 | 1808 | 1865 |
| ブラジル | 1850 | 1888 |
| デンマーク | 1803 | 1848 |

**「貿易を禁じる前に奴隷制を廃止した国」は存在しない。** 単調な梯子にすると、**その順序をルールとして書かずに保証できる**（思想①）。

### 輸出の法（2段）

`許可 / 禁止`。★ **ほとんどの国は初期 禁止**（売るものが無い）。

**初期 許可 になる勢力**（world.json 実測・★いずれも現在は植民地か抽象標的）：

| 勢力 | 現在の扱い | 資源 |
|---|---|---|
| **アシャンティ** | 抽象標的 | 金・カカオ・パーム油（人口2） |
| **ソコト** | 抽象標的 | 染料・畜産・象牙（人口3） |
| **コンゴ** | 抽象標的 | 生ゴム・象牙・銅鉱・パーム油（人口3） |
| **ザンジバル** | オマーンの植民地 | 香辛料・象牙 ★**東アフリカ奴隷貿易の中心** |
| **バルバリ** | 抽象標的 | ★地中海の奴隷狩り |
| 沿岸西アフリカ／セネガル | 英・仏の植民地 | |

★ アシャンティ・ソコト・コンゴが小国になれば、**輸出禁止が本物の決断になる**——ダホメやアシャンティは
奴隷貿易が国庫の主収入で、**やめると財政が崩れ、続けると英海軍が来る**。思想⑤で葛藤がそのまま出る。

## 3-2. 中間の強制形態は「4段目」でなく遷移期間

補足調査で確定した史実：

```

蘭  国家監督 staatstoezicht 1863-73（スリナム）
キューバ patronato 1880-86
```

「解放したが移動と労働の自由は与えない」段階。★ **4段目にする必要はない。**
`Government.StepEnum` が法を段階的に進め、`FarmRentCap` が上限として徐々に噛むので、
**「法を通してから経済が調整されるまでの遅れ」がそのまま4〜10年の移行期**になる。

**法は3段、実効は連続。**

## 3-4. 密輸（一般機構）

```
禁令が効く割合 ＝ 行政充足率
漏れる割合     ＝ (1 − 行政充足率) × 内外価格差の関数
```

★★ **アヘン戦争がそのまま出る**——清は1729・1796・1800と繰り返し禁じたが、**取り締まれずに流入し続けた**。
1839年に林則徐が本気で取り締まった瞬間に戦争になった。

```
禁令を出す → 行政力が足りない → 密輸で流入し続ける → 中毒度が上がる
          → 行政費を上げて取り締まる → 輸出国との緊張が跳ねる → 戦争
```

★ **「行政費」というレバーが初めて外交的な意味を持つ。**

### ⚠ 「輸入禁止」と「禁止」で密輸の形が違う

```
輸入禁止 → 密輸で入ってくる（★アヘン戦争前の清）
禁止     → 国内生産も違法。密輸 ＋ 闇栽培
```

★ 史実では**清は禁止後に国内栽培が激増**した（1860年代以降、国産が輸入を上回る）。
これを出すなら「禁止しても国内RGOが消えず、行政力次第で残る」形になる。

### ⚠ 奴隷と阿片で式を変えない

奴隷は人で、船1隻あたりの利幅が桁違いに大きく、発覚時の処罰も重かった。
★ ただし**財ごとに係数を持たせると外科的特例に近づく**ので、**同じ式**を使う。
差は「取り締まる側の行政力」と「密輸の利幅（価格差）」から出るはず。

> 加えて法律に**「軍需輸出 許可／禁止」**を作り、禁止の場合は**緊張の高い相手（60以上）には輸出しなくする**。
> **これ以上のマネジメントは不要に感じる。**」

★★ **管理の粒度と効果の粒度を分離する。** プレイヤーは1回決めるだけで、**閾値が相手を選ぶ**。

### ★ 禁輸ボタンの廃止は AI に何も失わせない（実測）

| **中間の強制形態を4段目にする** | ★不要。`StepEnum` の遷移期間がそのまま4〜10年の移行期になる |
| **`SerfEmancipation` と奴隷法を統合する** | ★制度・地理・廃止年が全部別。統合すると「露の農奴解放で西インドの奴隷が解放される」 |
