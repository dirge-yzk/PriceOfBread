# A. 戦争の荒廃と役畜

「戦争はあらゆるサプライチェーンを傷つけるべき」「大量の馬を消費するので畜産にもダメージ」というユーザー方針にもとづく設計。

## 1. 現状の荒廃＝3つ実装済み・劣勢側のみ

`Diplomacy.cs:1345-1349`

```csharp
double wear = c.WarZoneCapitalDamage(0.01) * losing * contactNorm;
rz.Industrialization *= 1-wear;   // 工業化度
```

## 2. 荒廃しないもの

| | 現状 | 備考 |
|---|---|---|
| **農業・主食RGO** | ❌ | `Industrialization` は工場の乗数で、**RGOは土地と労働で決まる**ので無傷 |
| **畜産** | ❌ | 同上 |
| 送電網 `GridCapacity` | ❌ | 別ストック |
| 輸送容量（鉄道・船舶） | ❌ | 別ストック |
| 生産者の操業規模 `Scale` | ❌ | 工業化度は乗数を削るが**建った設備は残る** |
| **在庫 `Market.Stock`** | ❌ | ★**保存則の恒等式に引っかかる**（下記） |

★ **工業化度を削れば工場の産出は比例して落ちる**（乗数なので）。「サプライチェーンを傷つける」の**半分は既に効いている**。欠けているのは**農業・畜産・インフラ**。

### 2-1. ⚠ 在庫破壊は恒等式を破る

```csharp
// Invariants.cs:113-116
expected = PrevStock + LastProduced + LastImport − LastSold − LastExport;
if (|Stock − expected| > 1e-6) → 違反
```

在庫を戦災で消すと**この恒等式が破れて `leakhunt` が落ちる**。消すなら「戦災損失」の項（`LastWarLoss` のようなフィールド1本）を式に足す必要がある。

→ **優先度は低い**（在庫は数ヶ月で回復するので効果も一時的）。**当面は在庫に触らない。**

## 3. ★馬は既に軍需財だが、役畜ではない

### 3-1. 現状

```csharp
// Catalog.cs:234
new(127, "馬", GoodTier.Intermediate, 0.0, 0.5, 1.6, [I(19,0.6), I(110,0.4)]);
//                                                    畜産0.6 ＋ 飼料0.4
// Catalog.cs:189
new(110, "飼料", GoodTier.Intermediate, 0.0, 0.4, 2.2, [I(15,0.6)]);   // 麦から

// Coefficients.cs:1101
MilitaryGoods = [82, 83, 81, 86, 85, 127];   // 小銃・弾薬・火砲・軍艦・汽船・**馬**
//   コメント：「B6：騎兵・輜重の馬匹＝畜産/飼料へ波及」
```

**軍が馬を買う経路は稼働中。** 戦時に馬の需要が跳ねて畜産と飼料を奪う連鎖は既に動いている。

### 3-1a. ★訂正（2026-07-28・断線走査）——農業への経路は既に在る

**当初ここに「馬の消費先は軍だけ（`I(127` の grep が0件）」と書いたのは誤り。** 取り消す。

```csharp
// Catalog.cs:267
RgoBoosterGoods(作物) = [109 肥料, 127 馬];   // ← 馬は作物RGOの効率化材
// EconomyStep.cs:639-653 が候補のうち最安1つを購入
```

馬は**レシピ投入ではないが、作物RGOのブースターとして農業に繋がっている**。
`I(127`（レシピ投入）だけを見て、ブースター配列という第2の消費経路を見落とした。

```
軍 → 馬 → 畜産＋飼料 → 麦        ← 稼働中
農業 ← 馬（RGO効率化材として）    ← ★稼働中
```

**「軍が馬を取ると農業が困る」は既に成立している。** 価格経由の土地の取り合い（下記 3-3）も成立済み。

### 3-2. ★真の問題＝肥料が馬を駆逐しない（型F）

`Catalog.cs:267` のコメントはこう宣言している——
「肥料は onset0.6=1842 までゲート＝**序盤は馬耕・晩期は安い化学肥料が駆逐（最安選択で創発）**」。

**駆逐が起きない。** 参照価格を手計算すると：

| 候補 | 参照価格 | 内訳 |
|---|---|---|
| **馬(127)** | **0.91** | 畜産0.6＋飼料0.4 |
| 合成肥料(109) | 1.07 | 化学薬品0.5＋硫黄0.3 |
| （グアノ肥料） | 0.77 | グアノ0.6＋化学0.1（賦存は世界で1州のみ） |

`EconomyStep.cs:646` は候補のうち**最安1つ**を選ぶので、1842年に肥料が解禁されても
**馬が最後まで勝ち続ける**。19世紀農業の中心的転換（馬耕→化学肥料）が発生していない。

→ 詳細と他4件の同型は `02_断線の全域走査.PARTIAL.md` §1（型F）。
   **馬を主食RGOの投入に足す必要はない**（経路は既に在る）。直すべきは**価格の相対関係**。

```
（旧案・不要）主食RGO の入力に 馬 を小さい係数で追加
```

**循環は起きない。** 麦も畜産も入力ゼロの採取財なので：

```
麦(入力なし) → 飼料 ─┐
                      ├→ 馬 → 主食RGO
畜産(入力なし) ───────┘
```

`麦 → 飼料 → 馬 → 主食RGO(=麦)` は形式上ループに見えるが、**麦の生産に麦が要るのではなく「馬」を経由する別の財**なので、参照価格の反復緩和（24回）は収束する。⚠ **ただし `Catalog.Complexity` の深さ計算がこの経路をどう扱うかは実装時に要確認。**

### 3-3. ★これで出るもの＝土地の取り合い

飼料は麦から作るので、**馬を増やすには麦を飼料に回す**ことになる。

> **役畜と食料が同じ土地を奪い合う。** 史実でも英国の農地の**2〜2.5割が馬の飼料**に充てられていた。

そして戦争の徴発が因果として成立する。

```
戦争 → 軍が馬を買う（既存）→ 馬価格↑
     → 農民が馬を買えない → 主食産出↓
     → 補充のため麦を飼料へ回す → さらに食料↓
     → 食料充足↓ → 飢饉・闘争度↑ → 政変（既存の連鎖）
```

★**徴発を明示的に書く必要がない。** 市場価格で自動的に奪い合いになる。

## 4. 実装

### 4-1. 戦災の対象を広げる（`Diplomacy.cs:1349` の同じ行）

```csharp
// 追加（ストックへの乗算＝1行ずつ）
rz.GridCapacity *= 1 - wear;        // 送電網
rz.RailCapacity *= 1 - wear;        // 輸送容量（名称は要確認）
// 農業・畜産＝産出側の乗数として（EconomyStep 側・別経路）
//   畜産の係数は主食より重く（k>1）＝「馬は真っ先に持っていかれる」
```

★ **産出への乗数として持つ**のが素直。ストックを削ると回復経路が要るが、産出の減衰なら**戦争が終われば自然に戻る**。ただし**畜産は繁殖に時間がかかる**ので回復を遅くする余地はある。

### 4-2. 畜産の下流への波及（自動）

| 下流 | 効果 |
|---|---|
| 肉・加工肉・チーズ | **食料が減る** → 食料充足↓ → 飢饉・闘争度 |
| **缶詰**（肉＋ブリキ＋塩） | ★**軍需の携行食**。**戦争が長引くほど自軍の補給が細る** |
| 革 | 軍靴・馬具 |
| 羊毛 | 衣料 |

★ **缶詰の連鎖が効くのが面白い**——戦争が畜産を潰し → 肉が減り → 缶詰が作れず → 軍需が細る。**戦争が自分の戦争遂行能力を蝕む**という自己制限が、新しい機構なしで出る。

# B. 期待（Expectations）の導入

現状の意思決定はほぼ全部が**水準**（現在の価格・現在の利益）で行われている。人間は将来を予想して動くので、そこに「期待」を入れると景気循環・バブル・暴落が現実的になる。

**結論＝賛成。ただし期待には2つの型があり、帯への効果が逆になる。片方だけを入れる。**

---

## 1. 既存の期待機構＝雛形は1本ある

| | |
|---|---|
| `World.ExpectedInflation`（`World.cs:534`） | **期待インフレ（年率・平滑）** |
| 更新（`World.cs:572`） | `ExpectedInflation += InflationExpectationSmoothing(0.34) × (実績 − 現在値)`＝**適応的期待のEMA** |
| 消費者 | `Fiscal.cs:352` フィッシャー効果（名目金利＝実質＋期待）／`Credit.cs:51` 債務デフレ |

**「傾向から予想する」という作法が既に確立している。** 他の期待も同じ形で書けば整合が取れる。

あわせて、期待に近い挙動が既にある：

| 機構 | 実体 |
|---|---|
| `SupplyAdjustSpeed = 0.15` | 産出が目標へ緩慢に追従＝**素朴期待のコブウェブ**（前期価格＝予想価格） |
| `InventoryAdjustGain = 0.0` | **メッツラー在庫循環＝在庫についての期待。配線済み・休眠** |
| `PreTightenHeatFrac = 0.75` | **予防的引き締め**＝唯一の予見的な行動（2026-07-25点火） |
| EMA各種 | `ExportSmoothed` / `FoodRatioProductionSmoothed` / `TradeValueSmoothed` / `AdminPowerSmoothed` |

---

## 2. ★2つの型と、帯への逆の効果

提示された5例を分類すると、**4つは増幅・1つは平準化**に分かれる。

| 例 | 型 | 帯への効果 |
|---|---|---|
| 来年の価格予想 | **外挿的**（傾向が続くと思い込む） | **増幅** |
| 戦争が近いから備蓄 | **自己成就** | **増幅**（買い占め→価格スパイク） |
| 不景気を予想して投資控え | **自己成就** | **増幅**（ケインズ） |
| 国債暴落を予想して資金逃避 | **自己成就** | **増幅** |
| **豊作予想で穀物価格が先に下がる** | **予見的**（外生の事実を先読み） | **平準化** |

### 2-1. 予見的な賢さは歴史を平坦にする（実測済み）

`HANDOFF.md` の記録：

> **帯（政治史の再現）が恐慌の多さに依存**＝1848/1917型政変の駆動因が経済危機そのもの＝**AIを賢くすると歴史がおとなしくなる**

そして実測——`PreTightenHeatFrac`（予防的引き締め）を入れると **信用過熱先行の恐慌が 41%→29%** に減り、**near が 71→67 に落ちた**。

**危機を予見して避ける能力は、危機が駆動していた政治史を止める。**

### 2-2. だから入れる型を選ぶ

```
✅ 外挿的     ＝ 傾向が続くと思い込む      → バブルを生む
✅ 自己成就   ＝ みんながそう思うからそうなる → 暴落を深くする
❌ 予見的     ＝ 外生の事実を正しく先読み   → 危機を消す
```

---

## 3. ★期待の価値は「当たること」ではなく「外れること」

全員が正しく予測したら何も起きない。

- **バブルは外挿が外れるから弾ける**
- **恐慌は悲観が自己成就するから深くなる**

必要なのは正確な予測ではなく**間違った確信**である。

---

## 4. 実装＝「水準」に「変化率」を足す

現状はほぼ全部が水準で判断している。**変化率の項を1つ足す**のが最小の変更。

```
現在: 投資 = f(現在の採算)
提案: 投資 = f(現在の採算 + w × 直近の採算の変化)
```

去年10%上がったから今年も上がると思って買う → 買うから上がる → 確信して更に買う。**バブルはこの1項から出る。**

★ 係数 `w` は既定0で厳密恒等に入れられる（設計思想③）。

---

## 5. 最も安い入口＝`InventoryAdjustGain` の点火

**係数1本。配線済み。** 「望ましい在庫との差を産出目標に乗せる」＝**在庫についての期待そのもの**。

メッツラー在庫循環は、期待が生む短期循環の教科書的な例で、**期待の効果を測る最初の一歩として最適**。

---

## 6. 決定論の注意

★**期待は状態から計算すること。**

「来年の収穫を知っている」形にすると、先読みではなく**カンニング**になる。しかも歴史を平坦にする側に働く。

**エージェントは傾向から予想し、外れるべき。** `ExpectedInflation` の EMA が既にその作法（実績の平滑＝過去からの外挿）なので、それに倣う。

乱数は不要——外挿は決定論的に計算でき、**外れるのは世界が非線形だから**であって乱数のせいではない。

---

## 7. 実施順

```
1. InventoryAdjustGain の点火（係数1本・既存の期待機構）
   → 在庫循環が出る。期待の効果を単独で測れる
2. 価格の外挿項を投資判断へ（既定0で恒等 → 段階点火）
   → バブル
3. 自己成就する期待（備蓄・資金逃避）
   → 既存のバンクラン機構が雛形（自己成就の前例）
4. 予見的な期待（豊作先読み）は入れない
```

**1と2のあいだで帯を測る。** 増幅側の期待は恐慌を増やすので、`near` が上がる可能性がある（賢いAIで失った乱流を、正しい因果で戻すことになる）。

---

## 8. 副次的な整理

- 5例のうち「豊作予想」だけが**外生の事実についての期待**で、他4つは**自分たちの集合行動についての期待**。**後者は必ず自己成就的になる**——これが増幅/平準化を分ける本質
- `PreTightenHeatFrac` は既に点火済み（ユーザー裁定「AIは十分に賢くあるべき」）なので、**予見的な賢さは既に1本入っている**。増幅側を足すことで釣り合いを取る、という位置づけになる

# 実装記録（2026-07-29）

**A（戦争の荒廃）＝実装**：
- Region.LastWarIntensity（劣勢度×接触・0..1・毎月リセット＝終戦で即回復）を新設し、主食RGO産出×(1−0.3×強度)・畜産(19)×(1−0.5×強度)＝WarFarmOutputDamage/WarLivestockOutputDamage
- 戦災ストックの対象拡大＝GridCapacity（州）＋RailCapacity/ShipCapacity（国）に既存wearを乗算
- 肥料の馬駆逐（実施順2）＝02の型F是正で実装済み（肥料0.84＜馬0.91）。在庫（実施順4）＝方針どおり触らない
- ⚠帯リスク＝人口一致への直撃は記録どおり（#17再較正の対象）

**B（期待）＝増幅側のみ実装（§2-2の型選択どおり）**：
- B1: InventoryAdjustGain 0→**0.1**点火（メッツラー在庫循環）。⚠実測：0.2は放任経済の中核テーゼ（無介入→労働者窮乏＝過少消費テスト）を消す＝在庫期待が小世界では安定化側に働く。bisectで0.1なら両立（B2勢い項は無関係と切り分け済み）
- B2: 投資の外挿項＝scaleTarget = 1 + margin + **0.3×(margin − SmoothedMargin)**（採算の勢い＝InvestExtrapolationWeight・0で厳密恒等）。「上がったから更に上がる」の確信が過剰能力＝バブルと深い崩壊を生む
- B3（自己成就＝備蓄・資金逃避）＝B1/B2の帯測定後の次段＝裁定待ちへ。B4（予見的）＝設計どおり入れない
