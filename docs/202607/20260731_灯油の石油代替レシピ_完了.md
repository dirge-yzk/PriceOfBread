# 2. 設計

## 2-1. ★★★ 極性が鋼と逆で、**鋼より簡単**である

| | 鋼 | ★灯油 |
|---|---|---|
| **既定レシピ** | ベッセマー（新・安い） | 鯨油（**古い**） |
| **既定をゲートするか** | ★する（0.55へ） | ★★**しない**（1789年から灯りは要る） |
| **追加するレシピ** | 坩堝鋼（古い・高い）を `TechOnset=0` で | ★**石油ケロシン（新・安い）を `TechOnset=0.6` で** |

★★★ **既定の生産者に一切触れないので、フラグ0での恒等性の証明が鋼より容易である**——⚠ **「追加しない」だけで完全に元の状態**になる。

## 2-2. 追加する生産者

```
GoodId      = 68（灯油）
RecipeName  = "石油ケロシン"
TechOnset   = 0.6            ★原油の DefaultRecipeOnset(10) と同値＝ドレーク油井1859
Inputs      = 原油(10) ＋ 労働力 ＋ 高度労働力
              （既定の鯨油レシピと同じ労働の付け方＝Catalog.LaborPerOutput / AdvLaborPerOutput(68)）
Productivity = 既定（鯨油）より高い   ← §2-3
LaborPopIndex / OwnerPopIndex = 既定レシピから複写（鋼と同じ作法）
RentShare = 1.0 / BuysLabor = true    （同上）
```

⚠ **新しい `Good` は1つも足さない。** ★ `灯油(68)` も `原油(10)` も既にある。**足すのは `Producer` 1件だけ**である。

## 2-3. ★ 較正 — なぜ「安い」のか、根拠のある数値にする

⚠ **「石油のほうが安い」を倍率で書いてはならない**（思想②）。★ 投入係数と生産性で表し、**史実の価格差に較正する**。

**史実のアンカー：**

| | |
|---|---|
| ★**鯨油の最高値** | 1856年 約 **1.45 ドル/ガロン**（捕鯨の枯渇で高騰） |
| ★**石油ケロシン** | 1865年 約 0.58 → 1885年 約 **0.08 ドル/ガロン** |
| ★★**最終的な価格差** | ⚠ **おおむね 10〜20倍** |
| ★**捕鯨船団** | 1846年 735隻 → **1876年 39隻**（米） |

★★ **したがって較正の目標は「onset後、石油ケロシンの限界費用が鯨油の 1/5〜1/10 になる」**である。

⚠ **具体値は測定で決めること。** ★ 出発点の考え方：

- ★ 鯨油ルート＝`漁獲 0.8 単位/灯油1単位`。⚠ **漁獲は RGO（採取）で、捕鯨は3〜4年の航海＝労働集約**
- ★ 石油ルート＝原油からの精製収率。⚠ 1870年代の精製で**原油1バレルからケロシン 45〜60%** が主産品（残りは廃棄・ナフサ・重油。★★**ガソリンは当時は廃棄物**）
- ★ したがって**投入係数は原油側が有利**（≈0.5前後）で、加えて**生産性の差**（連続精製 vs 捕鯨）が乗る

★★★ **1点だけ譲れない条件**：⚠ **onset 前（技術 < 0.6）に石油ケロシンが動いてはならない。** ★ `RecipeTechScale` がそれを担う（`EconomyStep.cs:270,273`）。

## 2-4. ★★★ 狙う創発（是正しない副作用）

| 帰結 | 史実 |
|---|---|
| ★**1859年以降、原油に買い手がつく** | ⚠ 現在は内燃機関(1.45＝1900年代)まで40年空白 |
| ★★**漁獲(20)の需要が半減し、漁業・捕鯨が衰退** | ★★★ **米捕鯨船 1846年735隻 → 1876年39隻。これは狙う効果である** |
| ★**灯油が安くなり、大衆の灯りが充足する** | ★ 夜間労働・読書・新聞の普及の前提 |
| ★**産油地が経済的に重くなる** | ★ バクー・ペンシルヴェニア・ペルシャ(1908) |

⚠ **漁獲の下落は「壊れた」ではない。** ★★ 是正しようとしないこと——**鯨を救ったのがケロシンだった**というのが史実である。

# 6. 却下した案（★ 記録として残す）

| 案 | 却下理由 |
|---|---|
| ⚠ **ガソリンを新しい財として足す** | ★★★**モデルに耐久財のストックが無い**（`EconomyStep.cs:802` `GoodNeed = effBaseNeed × Size` ＝フロー）。⚠ **「自動車を保有している」状態が無いので、燃料需要の出所が作れない**。★ 燃料需要はストック比例であってフロー比例ではない |
| ⚠ **「石油のほうが安い」を倍率で書く** | ★★思想②。⚠ 投入係数と生産性で表し、史実の価格差（1/5〜1/10）へ較正する |
| ⚠ **鯨油レシピを削除する／ゲートする** | ★1789年の灯りは鯨油である。⚠ **削ると序盤の灯火が消える**。★★ 駆逐は**価格から創発**させる（鋼の onset 後の挙動と同じ） |
| ⚠ **捕鯨の衰退を是正する** | ★★★**それが狙う効果である**（米捕鯨船 735隻→39隻）。⚠ 是正すると史実が消える |
| ⚠ **暦年で1859年にイベントを置く** | ★★思想①（台本禁止）。⚠ `TechOnset = 0.6` が技術水準で担う |
