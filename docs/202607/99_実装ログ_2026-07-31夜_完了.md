# 3. S2 潜在NaN — ★原因は「移民の argmax」だった

## 3-1. ★★★ 増幅機構（静的走査＋敵対的検証で確定）

```csharp
Territory.cs（旧）
  Region dest = active[0];
  double bestOpp = Opportunity(dest, c);                       // ★先頭州の機会で初期化
  foreach (var r in active) { double o = …; if (o > bestOpp) … } // ⚠ o > NaN は恒偽
  …
  double gap = bestOpp − Opportunity(src, c) − TransportFriction;
  if (gap <= 0) continue;                                       // ⚠ NaN <= 0 は false ＝**素通し**
  double fraction = Math.Clamp(RegionMobility * gap, 0, Max);   // ⚠ Math.Clamp は NaN を除去しない
  …
  if (moveSize <= 1e-9) continue;                               // ⚠ 同上＝素通し
  sp.Size -= moveSize;  dp.Size += moveSize;                    // ★★★ここで Size が NaN になる
```

★★★ **先頭州の機会が一度でも NaN になると、それが「最大値」として居座り、国内全州の Size/Savings が同月に一括で NaN 化する。**
⚠ そして `Invariants.NonNegativeBounds` が「規模 が NaN／∞」で止まる＝**観測された破綻の姿と一致する。**

⚠ **クランプは NaN を除去しない。** ★ `Math.Clamp` / `Math.Max` / `Math.Min` はいずれも NaN を伝播する＝**「フロアで守っている」は見かけだけ**だった。

## 3-2. ★ 直し方＝**否定形のガード**（有限値では厳密に同値）

```csharp
if (gap <= 0) continue;        →  if (!(gap > 0)) continue;
if (moveSize <= 1e-9) continue; →  if (!(moveSize > 1e-9)) continue;
if (pop < 1.0) …               →  if (!(pop >= 1.0)) …
argmax は double.IsFinite(o) の候補だけを採る（全州が評価不能なら移民しない）
```

★★ **有限値の世界では1ビットも変わらない**（`!(x > t)` ≡ `x <= t`）。⚠ **NaN のときだけ fail-closed 側に落ちる。**
★ 同じ流儀を越境移民（`MultiNationSim.MoveMigrants` の送出/受入 argmax と流量ガード）にも適用した。
