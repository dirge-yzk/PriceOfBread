## 1. 判定の優先順位（衝突時の裁定順）

```
ゲームが壊れない（破綻0・デッドロック0・クラッシュなし）
＞ ワンサイドゲームにならない
＞ その値が現実的・実在的であるか
＞ 70%計器
```

厳密な次元間優先順位は定めない。上の4段で裁く。

## 2. 70%計器（史実一致度の物差し）

### 2-1. 原理

- 次元＝**政体・法・経済規模・人口・領土・列強の顔ぶれ**の6本
- 各次元の目標＝**厳格一致50%**（国ごと・シード横断）
- 厳格50%＝体感7割の根拠：現行計器の実測で厳格(exact)≈緩(near)×0.5 が安定
  （exact 24〜35 / near 64〜78）。二値判定は惜しい外れを0に数え、次元は相関するため
- 新計器の初回実走時に緩い帯（許容幅2倍）を併記し「緩≈厳×1.4〜1.5」を一度確認する

### 2-2. 次元別の一致定義（実装初期値・調整可）

| 次元 | 一致の定義（1914年12月断面） | 参照データ |
|---|---|---|
| 政体 | 史実政体と厳格一致 | 既存 HistoricalReference |
| 法 | 主要法の一致（既存 near の法判定を流用） | 既存 |
| 経済規模 | GDP世界順位が史実±3位以内（順位ベース＝単位系に頑健） | Maddison 1913年推計 |
| 人口 | 史実1914年人口の ×0.7〜1.4 | センサス系 |
| 領土（本国） | 史実1914年保有州のうち70%以上を保有 | world.json 州帰属 |
| 領土（植民地） | **場所ではなく規模で測る（作者裁定）**＝植民地州数が史実の±50% | 同上 |
| 列強の顔ぶれ | シード上位8カ国と史実列強8の一致が5カ国以上（世界レベル判定） | — |

### 2-3. 断面

- **判定断面＝1914年12月**
- **1934年終局＝狂気チェックのみ**（破綻0・デッドロック0＋跳躍ダイジェスト目視。史実一致は問わない）

## 3. 跳躍ダイジェスト（報告専用・合否に使わない）

70%計器は逸脱3割の空間で起きる跳躍を原理的に見ない。「説明できない跳躍は非常に稀」
の確認用に、chronicle から以下をバッチ末尾へ列挙するだけの報告を置く：

- 国力順位が1年で10ランク以上跳ぶ
- 政体が10年内に3回以上反転する
- 人口・経済の成長率が物理上限を超える

**合否基準にはしない。目視で「稀か」を見るためだけの窓。**

## 4. AIの規律

- **数字をいじる前にAIを賢くする。バランスのためにAIを愚かにしない**（恒久）
- 賢さの上限3則：
  1. **プレイヤー以上の情報を見ない**（情報対称）
  2. **歴史上発見されていない解決法を取らない**
  3. **ゲームをメタ認知しない**（仕様ハック禁止）
  その内側で最適化する
- **AIが賢すぎて適切に問題を解決できる前提でなお、恐慌・戦災は国家を十分に傾ける
  実インパクトを持たせる。**ゲームとして難しくなりすぎても考慮しない
  （＝賢いAIが消す乱流は、実在の因果の強化で置き換える）

## 5. 戦争と滅亡

- 軍事覇権の殲滅ゲームにしない。戦争は国を十分に弱らせるが復帰不可能ではない
- **最も致命的なダメージを受けた国でも20年で戦前水準へ復帰できる**（原器＝普仏戦争後の仏）
- 征服消滅（統一・自発併合を除く）＝報告専用で集計し、**30シード平均2〜3カ国超で是正対象**
  （既定値。統一による消滅＝独伊諸邦は正しい消滅として除外）

## 6. 技術ペナルティ

- 現状の逸脱＝**アジアの小国が近代化しすぎている**。これを70%計器に収まる範囲へ調整する
  （原器＝洋務運動の失敗：武器は輸入できても識字・行政が伴わず実効近代化が頭打ち）
- 吸収能力の新機構（輸入技術×制度力ゲート）＝**既存係数の強化で不足する場合のみ追加**。
  まず既存経路（教育→技術・制度疲労・低技術軍の質割引）の増強で試す

## 7. 検証プロセス

- **機能追加の反復＝15シード／最終チェック＝50シード**
- 15シードは1シード＝6.7pt。固定シードリストの対応比較とし、**2シード未満の差は雑音として追わない**
- 50シード走は分割実行（既知の並列OOMフレーク対策・Monitor経由・DLL mtime確認）
- **機構発火監査**：全機構・全係数に「発火回数>0 or 実測差分あり」をバッチで確認する
  カウンタを常設（「休眠でなくとも事実上機能していない」の検出＝方針の実行に必須）
- #17の手順＝B5裁定どおり：全実装→値の史実妥当性レビュー→シミュレート→
  バランスを明らかに崩す変数のリストアップ→調整
