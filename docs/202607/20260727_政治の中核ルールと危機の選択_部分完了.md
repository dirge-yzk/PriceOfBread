# 政治の中核ルールと、危機の選択UI（2026-07-27）

`20260727_政治系の再設計.PARTIAL.md`（依存グラフ実測）の続き。**体制側と革命側の意思決定を全数採取した結果**と、そこから導かれる設計。

---

# 1. 実測でわかった3つのこと

## 1-1. ★体制AIは革命が見えていない

体制AIの唯一の「本物の選択」は `SelfPlay.cs:162-214` の `ChooseStance`（5スタンスの効用argmax）。その入力は：

```
uMod = 1.0×techGap + 0.5×indRoom + 0.3×unrest
uInd = 1.2×indRoom + 0.5×techGap
uWel = 1.5×unrest + 2.0×famine
uFis = 1.2×fiscalNeed
uMil = militaristBase + 2.0×clamp(tension/100) + 0.3×Colonies + survival
```

**`Militancy`・`Legitimacy`・革命接近度・内乱の有無・`GdpDrawdown` のいずれも入力に存在しない。** grep実測で `SelfPlay.cs` 全体に `Legitimacy` は**0ヒット**、`Militancy` は参政権譲歩2箇所と休眠ゲート1箇所のみ。

危機の代理変数は `unrest = max(0, 0.7 − MeanSatisfaction)` と `famine` だけ。しかも **「弾圧」というスタンスが選択肢に存在しない。**

さらに「危機が近づいたとき何をするか」を比較する統合分岐が**どこにも無い**（`SelfPlay.cs:268-495`）。金本位・借金・侵略・参政権・金融政策・財政規律・消費税・反腐敗・工業投資…すべてが独立の閾値で平列に動くだけ。

**つまり「革命を回避するAI」の実質全部が、この2行である：**
```csharp
if (AvgMassMilitancy(w) > SuffrageReformThreshold(0.5) && p.Suffrage < AdultMale)
    p.Suffrage = AdultMale;
```
譲歩の内容は**参政権1軸のみ**。福祉・食糧・減税・報道緩和は闘争度に一切応答しない。上限は AdultMale で打ち止め。選択肢も代替案もコスト比較もない。

## 1-2. ★革命側にエージェントが存在しない

`FactionState`（`Factions.cs:15-27`）の全フィールドは
`Region / Bloc / Ideo / Size / AvgMilitancy / Cohesion / QuartersActive / AbsentQuarters / Mutated / MutantName` の10個。

> 「目標」「戦略」「待機」「次に何をするか」に相当する状態変数は**1つも無い**。行動を選ぶための候補集合も、選好を比較する評価関数も存在しない。**勢力は観測結果を書き写した集計オブジェクトであり、エージェントではない。**

具体的に：

| 項目 | 実態 |
|---|---|
| **蜂起のタイミング** | 選ばない。`strength > coerce + militia` になった**最初の四半期に自動発火**（RNGすら引かない） |
| **要求の内容** | 選ばない。`ComputeDemands(w, bloc)` の**引数は bloc だけ**＝世界中で要求ベクトルは高々3種。千年王国運動も共和主義大衆運動も、blocが同じなら要求は1文字も変わらない。`Ideo` は要求に入らない |
| **結束の蓄積** | 投資ではない。同じクラスタが四半期をまたいで存在し続けた**事実の副産物**（`growth = 0.05 × (0.5+意識)`、0.8到達に約30四半期） |
| **力の構成** | `Size × AvgMilitancy × Cohesion × org × (1−voice)` の5因子すべてが他系の従属変数。**勢力が操作できる項は一つも無い** |

★そして構造的な制約：**`voice=1.0` の勢力は強度が恒等ゼロ**。旧支配層（bloc0）は voice が常に 1.0 なので、**どれだけ結束しても永久に蜂起できない**。蜂起できるのは男子普選未満の大衆と制限選挙未満の近代エリートだけ。

## 1-3. ★ただし「唯一の選択点」は既に存在し、しかもよくできている

`Politics.cs:786-829` の国内危機イベント。組織運動の強度が `coerce + LoyalistMilitia` を超えた瞬間に発火し、

- **プレイヤーは時間停止ポップアップで3択**（要求受諾／武力鎮圧／対決）
- **AIは同じ3択を即決**（完全対称・設計経緯は `HANDOFF.md:196`）

**つまりユーザーが提案したUIは、既に実装されている。** 問題は「無い」ことではなく、**ここが唯一で、しかもAIの選び方が効用比較ではなく固定優先順位のカスケード**であること：

```
① 政体が立憲君主/共和でない かつ ExpansionWill >= 2.0  → 武力鎮圧
② 勢力の主軸イデオロギーの最近政体 == 現政体          → 要求受諾
③ それ以外                                            → 蜂起させる
```

★**議会制政体は①を構造的に選べない＝弾圧できるのは専制系のみ。**

# 2. 「簡単になりすぎるか」への答え

## 2-1. 既に予算制約が存在している（重要）

`鎮圧` と `侵略` は**同じ資源プール `ExpansionWill` を奪い合う**。

| 行動 | コスト | 上限 |
|---|---|---|
| 武力鎮圧 | **2.0 / 回** | `ExpansionWillCap = 10.0` |
| 侵略 | **8.0 + 2.0×標的軍** | 同上 |

つまり**「内を締めるか、外へ出るか」のトレードオフが既に実装されている**。前回提案した予算モデルの種が、ここに既にある。これは大きい。

## 2-2. しかし「無料の手段」がある＝ここが最大の危険

**武力鎮圧は闘争度に一切触れない。** 勢力は残り、`RevoltCooldownQuarters = 4` で再燃する。つまり鎮圧は**純粋な遅延**であって、根を断たない。

これは設計としては半分正しい（「弾圧は借金である」に近い）が、**蓄積機構が無いので借金になっていない**。ただ4四半期先送りするだけ。

**この状態でポップアップを前面に出すと、「とりあえず鎮圧」が支配戦略になります。** コスト2.0は上限10.0に対して安く、しかも副作用がない。

## 2-3. 難しさを保つ条件

| 条件 | 理由 |
|---|---|
| **結果の数値を出さない** | 「不満−20／正統性−10」を書くと判断が算数になる。UI規律⑦（説明文を置かない・データだけ）がそのまま設計を守る |
| **蓄積を見せない** | 体制に見えるのは可視の不穏（犯罪・ストライキ・選挙結果）だけ。蓄積ストックは隠す。**乱数ゼロで誤算が出る**＝決定論のまま1848年 |
| **鎮圧に代償を持たせる** | 現状は無料。「相手の貯蓄率を上げる」形にする（亡命・投獄が組織を強くする） |
| **二択でなく四択に** | 下記 |

## 2-4. 三行目が本命＝別の軸で埋め合わせる

| 手 | 内容 | 現状 |
|---|---|---|
| 飲む | 要求どおり法を通す | ✅ `ConcedeToFaction`（top-1を2段・他1段） |
| **別の軸で埋め合わせる** | **参政権は拒み社会保険を与える（ビスマルク）** | ❌ **存在しない** |
| 拒む | 何もしない。圧力は溜まる | △ ③蜂起として実装 |
| 弾圧する | 組織のコストを上げる | ✅ ただし無料・遅延のみ |

**2行目が最も歴史的に豊かで、しかも現状で唯一欠けている手。** そしてこれは4主体＋予算モデルでしか書けない（「要求された軸とは別の軸に予算を投じて相手の効用を埋める」）。

分断（穏健派を買って急進派を孤立させる）も同じ枠に入る。

# 3. 中核ルールの実装＝4主体モデル

## 3-1. 目的関数は既に計算されている

`Politics.cs:157-173` が毎tick計算している：
```csharp
ideal = Ideologies.IdealPoint(p.IdeologyShares);   // 理想点（4軸）
pd2   = Σ(ideal[i] - regimeCoord[i])²;             // 現体制との距離
```

**これを「だから不満だ」ではなく「だからそっちへ押す」に使う。** 新規状態ゼロ。

POPの「賃金を最大化する」に対応するものが、政治では**「理想点との距離を最小化する」**になる。

## 3-2. 狙うのは政体ラベルでなく座標の向き

| 主体 | 押す向き | 目標の性質 |
|---|---|---|
| 王権 | 君主の権力軸 | 固定 |
| 軍 | 軍の自律性軸 | 固定 |
| 議会 | 議会統制力軸 | 固定 |
| **大衆** | **参加軸＋`IdealPoint` 由来** | **移動する**（工業化で自由主義→社会主義→共産主義） |

★「議会→共和制」にしてはいけない。イギリス議会は共和制を目指していない。1914年のヨーロッパはほぼ全部が君主国で、ラベルを目標にすると **exact が崩壊する**。政体ラベルは座標から創発させる（`PolityLabelFromAxes=1.0` で既にそうなっている）。

★**第4主体（大衆）の目標だけが動く。そこに19世紀の弧がある。** 導出量なので新規状態は不要。

⚠ 既知の制約：`Abs[0.00,0.50,1.00,0.30]` と `Sho[0.00,0.55,1.00,0.15]` は**ほぼ同座標**で、座標だけでは絶対王政と幕府を撃ち分けられない。

## 3-3. 革命側にエージェント性を与える＝3点

現状 `FactionState` は決定変数ゼロ。以下を足すと**エージェントになる**。

| # | 追加 | 効果 | 既存の受け皿 |
|---|---|---|---|
| ① | **結束を「使うと減る予算」にする** | 静かな蓄積→一斉投入。**ショックが大きくなることと賢くなることが同じ1つの変更になる** | `Cohesion`（既に蓄積している。減らないだけ） |
| ② | **狙う軸を選べる** | 体制の守りが薄い軸へ投じる。`OpposingPower` の argmax。新データ不要 | `ComputeDemands` を bloc 依存から状況依存へ |
| ③ | **譲歩を受けても資本が残る** | 1848年。自由派は憲法を得て、急進派は勢いを銀行に預けて次へ | `ConcedeToFaction` の後処理 |

## 3-4. 時間は挑戦者に味方する

- **体制は毎期払う**（譲歩も弾圧も継続コスト）
- **挑戦者は一度しか払わない**（待つのは無料）

この非対称があると、**最適に打っても体制は負ける——成長していない限り**。税基盤と繁栄由来の正統性が蓄積を上回り続ける必要がある。英が生き延びて露が倒れたのはこれ。

**賢いAIは歴史を平坦にするのではなく、遅らせて凝縮する。** 静かな数十年のあとに数週間で数十年が動く＝1848/1917 の形。

# 4. 実装順

```
0. コメントの嘘を直す
   ★FactionRevoltScale=1.0 なのにコメントは「既定0で無効」
   ★TraditionalistLawGate=0.0 で ModernizationLawsGated は完全休眠（20行超の設計コメントが一行も実行されていない）
1. 体制AIに目を与える＝ChooseStance の入力に Militancy / Legitimacy / GdpDrawdown を追加
   （現状ゼロなので、これだけで「回避するAI」が成立する。新スタンス「宥和」「弾圧」も要検討）
2. 鎮圧に代償を持たせる（現状無料＝支配戦略になる）
3. 危機ポップアップを二択→四択へ。三行目「別の軸で埋め合わせる」を新設
4. 結束を予算化（①）＝革命側がエージェントになる
5. 要求を状況依存へ（②）／譲歩後の資本残存（③）
6. 4主体モデルへ統合。座標の向きで押す
```

**1と2は独立に効く。** 体制AIが革命を見られるようになるだけで挙動が大きく変わるので、まず単独で測ること。

# 5. 付随して見つかった事実

- **外征で内憂をそらすのは「意思決定」ではない**。`WarFever` への連続加算項（`diversion = 0.6 × AvgMassMilitancy × outlet`）で、`outlet` は**旧支配層の力と軍国法にしか開かない**＝議会制の近代国家は構造的に逸らせない。史実的に鋭いが、AIが「そらそう」と判断しているわけではない
- **民主的後退**（`SelfPlay.cs:372`）は実装とコメントが一致している稀な例。Militarize中の立憲/共和が Census へ後退を目標化するが、直後の闘争度譲歩が必ず上書きする＝「高闘争時は後退できない」
- **恐慌時の緊縮緩和** `CrisisAusterityRelief=0.5` は `Coefficients` ではなく `UtilityAgent` クラス内の `private const`＝係数台帳から見えない

# 6. 法の不可逆性（史実の精査・2026-07-27）

## 6-1. 史実は「制度」と「水準」で答えが割れる

| 分野 | 制度 | 水準 |
|---|---|---|
| **社会保険** | **ほぼ完全なラチェット。** ビスマルクの保険（1883/84/89）は帝政崩壊もヴァイマルもナチスも生き延びた。英1911年国民保険も同様 | **戻る。** 1931年英メイ委員会で失業給付10%削減＋資力調査導入（挙国一致内閣が生まれた政治危機の原因） |
| **女性の権利** | 財産権（英1870/1882年既婚女性財産法ほか）に撤回例なし。参政権も撤回例なし | — |
| **農奴解放** | **完全なラチェット。** 再隷農化した国は存在しない | — |
| **労働時間** | **ここだけ本物の例外がある**（次項） | — |

★ゲームは既にこの区別を持っている＝`SocialSecurityLaw`（enum＝制度）と `SocialSecurity`／`WelfareFunding`（スライダー＝水準）。**enum を不可逆にし、スライダーは自由**が史実どおり。

★女性参政権について重要な区別：**撤回されたのではなく「選挙が無意味化」された**。ナチス期の女性は形式上投票権を保持したまま、司法・医療から追放され大学入学は10%に制限。**ゲームでは法の後退ではなく政体遷移として扱うべき。**

## 6-2. 労働時間だけは戦時に戻る

- 英**1915年軍需品法**＝工場法の制限を停止。女性と年少者の労働時間が延びた
- 独も両大戦で同様
- **1934年ナチス「国民労働秩序法」**＝労働組合と経営協議会を廃止（ゲーム期間の末端）

→ **不可逆、ただし戦時のみ緩和可**とするのが正しい。`WartimeRationing` と同型の戦時法として実装する。

★これは良い機構になる：**戦争の代償が「兵と金」だけでなく「社会立法の後退」として現れる**。しかも戦後に戻すかで揉める（史実そのもの）。

## 6-3. 一般則＝「支持層を作る法」は戻らない

| 戻らない（支持層を作る） | 戻る（金を動かすだけ） |
|---|---|
| 参政権（有権者を作る） | 税率 |
| 社会保険の制度（受給者と官僚機構を作る） | 給付水準 |
| 農奴解放（自作農を作る） | 関税 |
| 財産権（法主体を作る） | 支出配分 |
| 工場法（監督官と組合を作る） | |

**宣言ではなく導出できる規則**なので設計思想②に合う。しかも4主体＋予算モデルでは**自動的にこうなる**——法によって力を得たブロックが、その軸に予算を投じて撤回に抵抗する。不可逆フラグを立てなくても不可逆になる。当面はフラグ実装でよい（`IrreversibleEmancipation` の前例がある）。

## 6-4. 対象一覧

| 軸 | 扱い |
|---|---|
| 参政権・女性財産権・農奴解放 | **完全不可逆** |
| 社会保険の**制度**（enum） | **不可逆**（給付水準スライダーは自由） |
| 労働時間・児童労働 | **不可逆、戦時のみ緩和可** |
| 報道の自由 | 可逆（史実でも検閲は復活する） |
| 税率・関税・支出 | 可逆。ただし §6-5 |

⚠ **不可逆の仕組みが既に2箇所に別実装されている**（`Government.cs:263-264` の StepEnum 減少禁止と `Parliament.cs:312` の綱領 `Math.Max` 化）。統合してから拡張すること。

## 6-5. 減税は「上限」でなく「破れる約束」に

硬い禁止だと「レバーが動かない」だけになる。破れるほうが判断が生まれる。

```
減税を飲む → その軸に「約束した上限」が N年間つく
上限を超えて上げ直す → 通せるが、押し切り遺恨が発生する
```

機構は既にある（`Government.cs:152-164` の `PushGrievance`）。

**史実的な裏付け**＝ピーコック＝ワイズマンの転位効果。戦争で上がった税率は戦後も元の水準に戻らない。英の所得税は1799年に戦費として導入、1816年に廃止、**1842年に恒久復活**。「一時的措置」の恒久化は繰り返されたパターン。つまり税は「戻せる」のではなく**「戻すと約束したのに戻さない」**のが史実の姿。

# 7. 反動の圧力＝先進法に代償を与える（2026-07-27 ユーザー指摘）

## 7-1. 問題

**先進的な法ほど国家出力が出るなら、プレイヤーは常に先進法を目指す**（労働法を除く）。旧支配層の抵抗は速度制限にすぎず、戦略的な力にならない。

しかし §6 で法を不可逆にすると、反動が働く余地がさらに減る。**この2つは矛盾する。**

## 7-2. 史実の解決＝反動は「撤回」でなく3つの形で現れた

**史実の反動は、平時に法を撤回してはいない。** 次の3つで現れた。

### (a) 断裂の窓＝革命が失敗した直後だけ後退する

| 例 | 内容 |
|---|---|
| **仏 1850年5月31日法** | 居住要件で**約300万人（有権者の約1/3）を選挙人名簿から排除**。1848年革命の反動 |
| **露 1907年6月3日** | ストルイピンが第二ドゥーマを解散し**選挙法を地主優遇へ書き換え**（しばしばクーデタと呼ばれる） |
| **普 1848-49** | 欽定憲法と**三級選挙法**＝革命議会の目標からの後退 |
| **墺 1851年大晦日勅令** | 三月憲法を撤回＝バッハの新絶対主義 |

**規則：法は平時には戻らない。だが革命が失敗した直後・クーデタ直後には戻る。**

これはゲーム性として理想的で、**「進めすぎると反動で巻き戻される」という真の判断**が生まれる。

★受け皿は既にある＝`CrownRollbackRate = 0.02`（コメントに**「ストルイピン後退」**と明記・現在は `ParliamentControl` だけを動かす）と、鎮圧後の `RevoltCooldownQuarters = 4`。

★面白い逆転：ナポレオン3世は1851年のクーデタ後、**自らの正統化のために男子普通選挙を復活**させた。後退が常に反動的とは限らない。

### (b) 執行を飢えさせる＝法は残して監督官を切る

工場法は数十年にわたり**執行されなかった**（1802年徒弟法は事実上空文）。

**反動の実手は「法の撤回」ではなく「行政予算の削減」だった。** 安く、政治的コストも低い。

ゲームには既に `AdminSpending`（スライダー）と `AdminPowerSmoothed` / `AdminEfficiency` がある。**先進法の効果が行政力でゲートされる**ようにすれば、旧支配層は法に触れずに骨抜きにできる。

→ 不可逆性を破らずに反動が働く。**これが本命の経路。**

### (c) 衰える階級ほど激しく抵抗する

旧支配層の力は富シェア由来（`InterestGroups.cs:26-30`）で、工業化がそれを侵食する。**残る資本を投じて阻止するしかなく、失敗すれば終わり。** これが19世紀そのもの。

4主体＋予算モデルでは**自動的にこうなる**。予算が減るほど、残りを1軸に集中せざるをえない。

## 7-3. 先進法の代償は既にモデル内にある（が効いていない可能性）

| 法 | 既存の代償経路 |
|---|---|
| 公教育・報道の自由 | 識字↑ → **意識↑ → `politicalGap` → 闘争度↑**（`Politics.cs:157-173`） |
| 参政権 | 議会の構成が変わる＝自分の綱領が通らなくなる |
| 労働時間 | `WorkHoursValue` → 産出に直撃（唯一、明確に効いている） |
| 農奴解放 | 地主が労働力を失う |

**代償の経路は存在する。** 「先進法に代償がない」と感じるなら、それは経路の欠落ではなく**出力ゲインが数値的に上回っている**という較正の問題。バランス後回し方針なので、いまは記録に留めて #17 で扱う。

## 7-4. 実装の提案（優先順）

| # | 内容 | 規模 | 既存の受け皿 |
|---|---|---|---|
| 1 | **執行の飢餓**＝先進法の効果を行政力でゲートする | 中 | `AdminEfficiency` / `AdminSpending` |
| 2 | **断裂の窓**＝革命鎮圧・クーデタ直後の N四半期だけ不可逆を解除し、旧支配層が後退を押せる | 小 | `CrownRollbackRate`（名前が既に「ストルイピン後退」）・`RevoltCooldownQuarters` |

**2 が最も安く、最もゲーム性に効く。** 「進めすぎると反動で巻き戻される」という判断が生まれ、しかも平時の不可逆性（§6）と両立する。

# 8. 天命の再定義＝「未教育層の支持」（2026-07-27 ユーザー提案）

## 8-1. 提案

- **未教育POP** → 闘争度に影響せず、**天命に影響**（天命＝未教育層の支持）。不満を発散する方法を知らないため
- **教育POP** → 様々な要素に影響し、闘争度を高める

## 8-2. 評価＝抽象EMAが「支持層」に置き換わる

現状の `DynasticMandate` は `dmSat`（満足度）・`dmWar`（厭戦）・`dmGraft`（汚職）を混ぜたEMAで、**支持層を持たない抽象スカラー**。「王朝がうまくやっているか」という宣言的な量である。

提案はこれを**具体的な集団の支持**に変える。測る対象が実在するので、値の妥当性を検算できるようになる。

★**半分は既に実装されている。** `Politics.cs:157-173`：
```csharp
politicalGap = p.Consciousness * (1-effVoice) * sqrt(pd2) * 0.5;
```
**教育（意識）で闘争度がゲートされている。** つまり「教育POPが闘争度を高める」は既にある。欠けているのは補集合＝`(1 − Consciousness)` のぶんが政治的にどこへも行っていないこと。

## 8-3. ★二重計上が構造的に消える

依存グラフ実測で `MeanSatisfactionPol` は**4経路**に入っていた（天命 `dmSat` / 一党支配ゲート / 独裁引力ゲート / 実績ストック経由）。

提案を採ると：
- 満足度は**未教育POPを通じてのみ**天命へ
- 満足度は**教育POPを通じてのみ**闘争度へ

**同じ根が「式」ではなく「人口」で分割される。** 各POPは意識に応じてどちらか一方へ重みを流すので、和は保存され二重計上が起こりえない。これは規約3（同じ根を2ポートから叩かない）を**構造的に**満たす形であり、手で経路を整理するより強い。

## 8-4. 係数が1本消える

`ncFade = clamp(1 − 1.2 × NationalConsciousness)`（`Politics.cs:285`）は「国民意識が上がると天命の効果が消える」という**手で書いた減衰**。

提案では**識字が広がるほど未教育層の人口が減り、天命の母数が自動的に痩せる**。`ncFade` は不要になる。

## 8-5. ⚠ 修正が要る点＝未教育層は静かではない

「不満を発散する方法を知らない」は**綱領を持たない**という意味では正しいが、**暴動は起こす**。ジャックリー、ヴァンデー、パンの蜂起。

ゲームには既に両方の回路がある：

| 回路 | 主体 | 実装 |
|---|---|---|
| **綱領的政治**（意識でゲート） | 教育層 | `politicalGap` → 闘争度 → イデオロギー → 政体遷移 |
| **窮乏の回路**（意識と直交） | 未教育層 | `DesperationChallengeWeight`＋`DesperationConsciousnessGate=1.0`／州一揆 `RegionalRevoltThreshold`（州平均闘争度 × 主食欠乏） |

★HANDOFF に「**権威国の『出口』を創発で回復＝窮乏チャネル（パンの蜂起）**」として記録されている既存機構。

→ 正しい定式化は「未教育層は闘争度に影響しない」ではなく：

```
未教育層 → 天命（平時の支持）＋ 窮乏の回路（飢えたら暴れる。綱領はない）
教育層   → 綱領的政治（闘争度→イデオロギー→政体）
```

## 8-6. ⚠ 帯リスク＝伝統帝国が安定しすぎる恐れ

未教育人口が巨大な国（清・オスマン）ほど天命の母数が大きくなる。**清の勝率は既に37%で「近代化が簡単すぎる」が繰り返し問題になっている**ので、無条件だと逆方向へ押す。

**緩和＝天命は無条件の忠誠ではなく「食えている限りの忠誠」にする。** `dmSat`/`dmWar`/`dmGraft`（飢饉・厭戦・汚職）が既にその条件であり、不作が来れば天命は落ちる。**これが王朝循環そのもの。**

★さらに：**天命は「侵食」ではなく「撤回」されるべき**。滑らかなEMAで削れるのではなく、閾値で崩落する形が史実に近い。血の日曜日事件（1905）が典型で、農民は請願を持って皇帝のもとへ**行った**——素朴王政観（наивный монархизм）が壊れた瞬間である。

## 8-7. 4主体モデルとの統合

これは第5の主体を足すのではなく、**大衆ブロックを意識で2つに割る**ことになる。

| 大衆の状態 | 押す先 | 重み |
|---|---|---|
| 未政治化（低意識） | **現体制の維持**（君主個人への支持） | `(1 − Consciousness) × Size` |
| 政治化（高意識） | `IdealPoint` の方向 | `Consciousness × Size` |

**教育が広がると、重みが前者から後者へ移る。19世紀がこの1行に収まる。**

そして「未教育層は君主個人を支持し、国家や綱領を支持しているのではない」という区別が、政体遷移の意味を変える——王朝が倒れると天命の母数がまるごと宙に浮く。

## 8-8. 実装規模

| 作業 | 規模 |
|---|---|
| 天命の算出を `dmSat/dmWar/dmGraft` の混合EMAから、未教育POPの加重平均へ | 小 |
| `ncFade` の削除 | 係数1本 |
| 窮乏の回路を「未教育層のみ」に明示（現状は意識と直交＝全層） | 小 |

**先に上2つだけやると、天命が検算可能な量になり `MeanSatisfactionPol` の4経路が2経路に減る。** 帯は動くので単独バッチ。

## 13-5. 政体の性格が2軸で出る

```
絶対王政 = 速く動けるが、取れる金が少ない（身分制免税・同意なし）
議会制   = 遅いが、深く取れる（同意があるから）
```

**専制プレイ＝即断できるが常に金が無い／議会プレイ＝金はあるが何も通らない。** 機能1（政体ごとに別のマネジメント）が求めていたものが、導出式から出る。

## 13-6. 所得税の上限は既に実装済み（確認済み・追加不要）

`Government.cs:76`：
```csharp
double incomeTaxCeiling = Math.Clamp(w.AdminPowerSmoothed / Math.Max(1e-9, c.IncomeTaxAdminGate), 0, 1);
```

| 税 | 必要行政力 | 意図 |
|---|---|---|
| 土地税 | `LandTaxAdminGate = 0.1` | 粗い検地台帳＝近世国家の主財源（年貢/タイユ）。確立した国家は序盤から課税可 |
| 所得税 | `IncomeTaxAdminGate = 0.75` | 所得査定機構＝19世紀の発明 |

`AdminEfficiency` は**行政役務の充足率（人口加重平均）**＝行政サービス財を実際に買えている割合なので、**閾値が任意でなく経済的な裏付けを要求する**。

設計として良い点3つ：**暦年を使っていない**（設計思想①）／**衰退が効く**（上限は連続で `行政力/0.75`）／**史実の形が出る**（英の所得税は1799年に戦費で導入→1816年廃止→1842年恒久復活。早期導入自体は史実的で、ありえないのは「恒久的に高い所得税」のほう）。

⚠ 残る唯一の未確認＝行政力0.75で `ceiling=1.0` に達したとき、**スライダー1.0が実効何%を意味するか**。1913年時点で英の標準税率は約5.8%、プロイセンのミーケル改革（1891）でも最高4%。`PrivilegeTaxDiscount`・漏れ・`EffectiveCorruption` で実効は下がるので、**スライダー値と実効負担率の対応の実測が要る**（#17較正枠）。

## 13-7. 共産主義＝マルクス主義。ただし無神論は政体に付く

1848年以降ならほぼ一致する。**ただし無神論の帰属先が違う。**

マルクス主義以前の共産主義は無神論ではない——バブーフ、サン＝シモン（『新キリスト教』1825）、フーリエ、カベ（『イエス・キリストによる真のキリスト教』1846）。

そして**1848年以降もマルクス主義政党は無神論を国策にしていない**。世界最大のマルクス主義政党だったドイツ社会民主党は、エアフルト綱領（1891）で宗教を「**私事（Privatsache）**」と宣言した（カトリック労働者を失わないため）。

**国家無神論を実行したのはボリシェヴィキだけ**、しかも1917年以降（戦闘的無神論者同盟1925・教会攻撃1929）。

| | 無神論 |
|---|---|
| `Ideology.Communism`（popの信条シェア） | **含めない** |
| `Polity.ProletarianDictatorship`（体制） | **強制** |

§6の女性参政権と同じ形＝**法が戻るのではなく政体が無効化する**。

★ゲーム期間（〜1934）に実在した共産主義国家は**ソ連1つだけ**（ハンガリー・バイエルンのソヴィエト共和国は1919年の数ヶ月）。1事例のために分類学を作らない。

★**`ProletarianDictatorship [0.30, 0.85, 0.00, 0.20]` は共産主義イデオロギーの座標と完全に同一。** パリコミューンとソ連の同一視は、座標系が既にそう扱っている。

## 13-8. 座標から導けない例外は2つだけ

| # | 内容 | 対処 |
|---|---|---|
| ① | **国家無神論が表現できない** | `StateReligionLaw { StateChurch, InnerFreedom, ReligiousFreedom }` に4つ目 `StateAtheism` を追加。**§9（宗教＝未教育層の政治回路）と直結する重い穴**——これが無いと共産主義国家は農民の天命忠誠を破壊できない |
| ② | **国有化が6部門のみ** | `NationalizedSector { Railways, Mines, Military, Telecom, Oil, Electricity }`＝全てインフラ・採取業。**製造業・農業・小売を国有化する手段が無い**。機構自体は稼働中（`NationalizationGate=1.0`/`NationalizationStateShare=1.0` 点火済み）なので**対象を広げるだけ** |

## 13-9. 共産主義の固定位置（史実の税目に注意）

★**所得税ではなく消費税。** ソ連の歳入は圧倒的に**取引税（налог с оборота）**——消費財への売上税で1930年代には歳入の6割超。賃金への所得税は小さい。**国家が企業を所有しているので、余剰を賃金段階で取る必要がない。**

| 軸 | 位置 | 現状 |
|---|---|---|
| 国有化 | **最大・全部門** | ⚠ 6部門のみ（例外②） |
| 消費税 | **高**（＝取引税） | ✅ `ConsumptionTax` |
| 社会保障 | **最大** | ✅ |
| 所得税 | 主役でない | ✅ |
| 教育法 | **Compulsory 強制**（リクベス） | ✅ |
| 報道 | **StatePressOnly 強制** | ✅ §12と接続 |
| 組合 | **Controlled 強制** | ✅ **`LaborUnionLaw.Controlled` が既にある**（国家統制組合＝共産主義とファシズム両方の特徴） |
| 国教 | **StateAtheism 強制** | ⚠ 値が無い（例外①） |
| 参政権 | 名目 Universal・実質無意味 | §6と同型＝政体が無効化する |

## 13-10. 銀行法は不要

法の enum は12種（`Policy.cs`）あり、**金融の法は存在しない**。信用は `InterestRate`（スライダー）と `Bank` で扱う。

共産主義で変わるのは「誰が投資するか」＝資本家POPの貯蓄が投資を駆動する経路（`IndInvestmentFrac × 投資家Savings`）が止まり国家建設が代わる。`StateBuildUnitsPerMonth`（休眠・0=無制限）が既にあるので**可動域の指定で足りる**。新設不要。
