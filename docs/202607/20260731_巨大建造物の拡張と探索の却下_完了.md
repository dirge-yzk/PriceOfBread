## 1-2. ★★★★★ 金額は既に「暗記できない」

```csharp
EconomyStep.cs:453      monumentConstruction = region.MonumentBuildQueue / ★costPerUnit;
EconomyStep.cs:456-458  investDemand[鋼] += ConsSteel × monumentConstruction;
                        investDemand[機械] / investDemand[セメント] / investDemand[製材] も同様
EconomyStep.cs:445-448  ★労働も同経路（ConstructionLaborViaMarket）
```

★★★ **`costPerUnit` は建設束（鋼・機械・セメント・製材＋労働）の【市場価格】である。**

| | 性質 | 暗記されるか |
|---|---|---|
| **`BuildUnits`** | ★**物量**（何束ぶん必要か）＝データ | ⚠ される。★**されて構わない**（何トン鋼が要るかは技術書に載る類の情報） |
| ★★★**金額** | **物量 × 十数年ぶんの市場価格の経路積分** | ★★★ **できない** |

⚠ **価格が依存するもの**：自国の工業化度／他国の需要／戦争／不作／**景気循環**（★実測で恐慌が10/10のシードで発生・平均79.2回）／物価水準。

★★★ **すべてシミュレーションから創発し、決定論であり、⚠ 誰にも暗記できない。**

# 5. ⚠ 却下2 — 探索（南極・エジプト等の探検）

## 5-1. 却下理由

| # | 理由 |

| ★★★**1** | ⚠ **請求先が存在しない。** `Diplomacy.cs:1044-1048` の植民地化は「弱小の**勢力**を従える」ことで、**無人の土地に旗を立てる機構ではない**。★ 探検の報酬に領土を置くには**空白地**が要り、⚠ **それはヴィクトリア2の病そのもの**（別途 `20260812_アフリカ植民.DONE.md`） |

| ★★**3** | ⚠ **新しい状態を要求する。** ★ 「方面ごとの既知度」が要る。⚠ 巨大建造物が誇る「**新しい状態を1つも作らない**」（`Megaprojects.cs:8`）を満たせない |
| ★**4** | ⚠ **同じ目的が安く達成できる。** ★ `megaprojects.json` は7件で、候補が44件書いてある（§2） |

## 5-2. ★ 検討した設計（記録として残す・採らない）

⚠ **再提案されたときのために書き残す。** ★ 以下は「ガチャにしない探索」の設計として妥当だったが、§5-1 の理由で採らない。

- ★ 産出を**「到達距離」という連続量**にする（成功/失敗の二値にしない）
- ★★ 成否は RNG でなく**投じた実物 × 技術 × 距離 × 気候**で決まる
- ★★★ 威信は**一番乗りだけ**が取る／⚠ **二番手が得るのは「確実性」**（安く確実に着く）
- ★ 見積もりは**その方面の既知度**で誤差が決まり、⚠ **他国の探検でも既知度が上がる**＝**先駆者の代価**

★ 史実の裏付け：**最南到達点（Farthest South）は当時の実際の競争指標だった**——ボルクグレヴィンク78°50′(1900) → スコット82°17′(1902) → ⚠ **シャクルトン88°23′(1909・残り97マイルで引き返した)** → アムンセン90°(1911)。★★ **アムンセンが勝ったのは運ではなく、犬橇・スキー・極地経験・基地位置の準備差である。**

## 5-3. ⚠ 併せて却下した案

★ **「探しに行ったものと、見つけたものが違う」**（ナイル源流を探しにいってタンガニーカ湖に着く）。⚠ **却下**——世界に「未発見のもの」が存在しないため**発見物の表を書くことになり**、★★★ **`Formations.cs` の州名500と同じ外科的構造**になる。
