## 8-1. ① B4 利息の支払い方＝**案A＋案Bの合成**（`Credit.cs`）

裁定：最後の貸し手（`Credit.cs:93` LOLR）では解決しない＝**層が違う**。LOLR は銀行の準備を補強する機構で、
困っているのは借り手（投資家pop）。バジョットは「銀行に貸せ」であって借り手の救済ではない。

**実装側からの確認依頼への回答＝当期の利潤は単一フィールドの差で取れる。近似は不要。**
`Pop.Earned`（その月に得た総所得・`Model.cs:152`）と `Pop.Paid`（その月に支払った総額・`:151`）が実在する。

```
旧  paid = min(利息, borrower.Savings)                      ← ストックで頭打ち＋不足分を捨てる
新  profitDaily = max(0, Earned − Paid) / DaysPerMonth       ← 案A：フローから払う
    paid  = min(利息, min(profitDaily, Savings))            ← 現金も同時に上限（持っていない金は払えない）
    未払い = 利息 − paid → bank.Loans へ繰入（係数ゲート）    ← 案B
```

★**単位の注意（実装で判明）**：`Earned`/`Paid` は `EconomyStep.cs:86` で**月次**リセット、`Credit.Step` は
**日次**（`Simulation.cs:1008`）。月次の利潤で日次の利息を頭打ちにすると**1ヶ月で最大30回ぶん払える**ので日割りで揃えた。

**保存則**：`bank.Loans` は `MoneyConservation` の恒等式（`BaseMoney = baseline + TradeFlow + GoldMinted + FiatIssued`）に
入っていないので繰入は貨幣を作らない＝作者の指摘どおり。倒産の既存規律（「負債は帳消ししない・倒産は産出0のみで貨幣非接触」）と同性質。

**係数**：`InterestCapitalization`（既定 **0**＝案Aのみ／1で A+B）。破綻率は別バッチで測る。

## 8-2. ③ 阿片の輸出条件＝**外圧駆動**（`SelfPlay.cs`）

```
旧  p.OpiumExportBan = (自国の保有法 == 全面禁止)        ← 英が出ない
新  外圧 = Σ( 阿片を禁じていて、かつ緊張が高い相手の TradeWeight )
    輸出禁止 ⟸ 外圧 > 閾値
```
史実の英は**自国で禁じないまま輸出を続け**、外交的代価が耐えられなくなって止めた（1907英清阿片協定・1913インド阿片輸出終了）。
**新しいスカラーはゼロ**（緊張・`TradeWeight`・相手の保有法はすべて既存）。この規則の形は奴隷貿易（英海軍の圧力）・
児童労働（国際労働規制）へそのまま再利用でき、**道徳問題が増えても規則は増えない**。

## 8-5. 法軸を増やすかの一般原則（作者提案・採用）

> **新しい法軸が正当化されるのは、その賛否連合が既存のどの軸とも違うときだけ。同じなら既存軸に畳む。**

本作の「保有から創発」から自動的に出る基準＝連合が同じなら同じ決定を2回聞いているだけ。
児童労働に当てると賛成＝大衆／反対＝工場を持つ資本 ＝ `ShorterHours` とほぼ同じ連合＝畳める可能性が高い。
ただし児童労働は「世帯所得の減少」という別の代価があるので、大衆側が一枚岩でないなら別軸に値する。
