## 3-1. ★★★ 州の陣営選択 — **反復元を替えるだけ**

## 3-2. 陣営の戦力 — **既にある2つの量を陣営別に積むだけ**

現行の決着は `attack`（全国の challenge）と `coerce + militia` の比較である。新形は同じ量を**陣営別に集計**する：

```
govForce   = Σ_{lean(r) ≤ 0}  coerce に寄与する量（兵士pop・警察）
rebelForce = Σ_{lean(r) >  0}  challenge に寄与する量 ＋ w.CivilWarRebelStrength
```

⚠ **`w.CivilWarRebelStrength`（`Politics.cs:715`・`Coefficients.cs:1450` で点火済み）はすでに「反乱側の戦力」という概念そのもの**である。★ 新設ではなく**配属先を州に分けるだけ**。

## 3-3. ★★★ 決着 — **既存の定数を1本で2箇所に使う**

```csharp
Coefficients.cs:139  CivilWarLandslideRatio = 1.8   // ★現在は発火側にしか使われていない
```

★★ この定数はもともと「**拮抗か圧勝か**」を分けるために置かれている。⚠ **決着側にも同じ定数を使う**＝新しい係数を1つも増やさない。

| 条件 | 決着 |
|---|---|
| `rebelForce > govForce × 1.8` | ★反乱の圧勝＝**現行どおり全国が反転**（`ApplyRegime`） |
| `govForce > rebelForce × 1.8` | ★政府の圧勝＝**現行どおり鎮圧** |
| **それ以外（拮抗）** | ★★★**分裂**——反乱側の州が新国家として独立し、政府側は残る |

★★ **現行の挙動が両端に保存されている。** ⚠ 中央の帯だけが新しい。これは思想③（休眠フラグ規律）と相性がよい——**`CivilWarSplitEnabled = 0` のとき、拮抗帯も現行どおり `attack > coerce` の二値に落とせば厳密恒等**になる。

## 3-6. ⚠ スペイン内戦が逆になる件（**是正しない**）

★ 上の規則だと、マドリードを保持した共和国政府が「継続国」になる。⚠ 史実ではフランコ側が国際承認を得て継続国になった。

★★★ **これは是正しない。** 理由：

1. ⚠ 是正するには「国際承認」という**新しいスカラー**が要る。⚠ そして承認の判定には結局**列強の政治的立場**が要る＝機構が1段深くなる
2. ★ 首都規則は**169州すべてに同じく当たる**。スペインだけ違う結果になるのは**個別の是正が要る証拠ではなく、一般則が個別事例を外した普通の例**である
3. ★★ 思想②が禁じているのは「スペインだけ別の規則」であって、**一般則が特定の国で史実と食い違うことではない**

⚠ **記録として残す**：この食い違いは既知であり、**意図的に放置されている**。

# 5. ★★★ 思想⑤（プレイヤーとAIは完全対等）— これは違反ではない

⚠ 一見すると違反に見える：**プレイヤーは陣営を選べ、AIは選べない**。

★★★ **違反ではない。理由は、陣営選択が国家の挙動を1ミリも変えないからである。**

| | |
|---|---|
| ★**分裂の判定** | §3-3 の規則で決まる。**プレイヤーが何を選んでも同じ2国ができる** |
| ★**両国のその後** | どちらも通常の国として `MultiNationSim` が回す。**選ばれなかった側もAIとして生き続ける** |
