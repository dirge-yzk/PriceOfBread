[produced[gi] は Output の和か]
- はい。produced[s.GoodId] += s.Output（EconomyStep.cs:1141）が唯一の加算。同じ生産者の段（:1017 からの loop）で Output を書き終えた直後に足す。
- 足さない生産者：眠り（:1019・SleepState :786 は Output==0 のときだけ眠らせる＝0）・倒産（:1021 で Output=0 にしてから continue）＝どちらも Output は 0。
- Run に早い return は無い（:792〜:2213 の return は全て内側のラムダ）。:1141 と :2213 の間に Output の書き手は無い。
- ⇒ Run の末では、州 r・財 g について LastProduced ＝ Σ_{r の生産者で財 g} Output（同じ順の左からの和）。
