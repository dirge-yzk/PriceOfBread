== 2. 段 0 の予言（腕の前・ソースと keep_1096/base_ins から）
- 投資家 POP の無い州：0（州の組み立て Simulation.cs:971・:1629 が全て InvestorPopIndex＝3）。ただし投資家の貯蓄の乏しい州は買えず T_r が育たない＝陸の倍率が 12×馬に残る（旗 0 は国の容量を全ての州に配るので、貧しい州も発見の年から 3×鉄道）。この差が段 R の働きそのもの。
- 陸の倍率：発見の年に旗 0 は全州一斉に 12×馬→3×鉄道（紙 G1：10 種の上位の組の側で 467,528 側が 3×鉄道・358,369 側が 12×馬）。旗 1 は T_r の積み上がりに沿う。
  積み上がり：need 一定・買いが足りる州の不動点（減耗の後・買う前）＝T′*＝b÷(1/(1−d)−(1−b+d))×need＝0.9973×need（b＝0.15・d＝0.02）・買った後＝T′*÷(1−d)＝1.0176×need。半減期 約 4〜5 か月。
  ＝清算の φ（買った後の T で読む時）は十分に買える州で 1。発見から 1〜2 年で旗 0 の倍率に追いつく見込み。符号：発見後の数年は旗 1 の陸が高い（貿易が少ない）。
- 線路の容量：旗 0 の国の定常 C＝0.88×target（材料 §4-1）。旗 1 は州ごとに 1.018×need＝買えた州の和で約 +16%（線路の財の需要も約 +16%＝値段を通して工業へ波及・記録）。貧しい州の分だけ下がる。
- ㉗：G6（壊さない）は、清と日の貿易を下げる向きに破れうる（基礎の目標に対する容量が 2〜3 倍・材料 §4-1＝国の容量は小さく、州の投資家も乏しい見込み）。それでも回す理由＝発見の年の全州一斉の 12→3 は史実と合わず（材料 §2）、州ごとの積み上がりが段 R の目的そのもの。
