## [5] 列（単位は接尾辞・額はその国の通貨・どれも四半期の末の月の値）

### landbase_s（国×四半期・州が 1 つ以上ある全ての国＝cornint_s と同じ行の集合）
- quarter・year・nation
- privExemptDegreeShare：d′＝PrivilegeTaxDiscount≦0 なら 0／PrivilegeFromCrownShare＞0 なら nan／政体が絶対王政・専制・幕府なら PrivilegeTaxDiscount／他は 0（Privileges.cs:41〜:45 を計器が書く）。privBase′＝閉鎖かつ兵士でない POP は 1−d′・他は 1。
- landClaimPerMonth：Σ_POP（犯罪者を除く＝Fiscal.cs の `if (p.IsCriminal) continue;`）[LandTax＞1e-9 かつ LandRentPerMonth＞0] LandTax×LandRentPerMonth×privBase′（Fiscal.cs:803〜:804 の独立の写し・同意を掛けない）
- landClaimExemptPerMonth：同じ和の LandTax×LandRentPerMonth×(1−privBase′)
- landTaxPaidPerMonth：World.LastTaxLandPerMonth を読むだけ
- landPaidOverClaim：上の 2 列の比（請求が 0 以下なら nan）
- landClaimExtShareUpperPerMonth：LandTax＞1e-9 のとき Σ_州 LandTax×r_州×V_州（r と V が有限の州だけ）。r_州＝州の主食の RGO（IsRgo・Tier が Staple・倒産でない・Output＞0）の Output で重みを付けた min(RentShare, FarmRentCap)（主食の RGO が無い州は nan＝和に入れない）。V_州＝LastSubsistenceOutput×主食の値段（subst_s の式）。
- landClaimExtGrossUpperPerMonth：同じ和の r＝1（V が有限の州）
- baseRPerMonth：R（照合の列・cornint_s の rentDomTotalPerMonth と同じ集合）
- baseRCheckRelDiff：R を 2 通りに double で数えた相対差＝|R_素直−R_ブロック|÷max(R_素直, 1e-300)（R_素直＝州→POP の順の 1 本の和・R_ブロック＝cornint_s と同じく閉鎖／近代エリート／大衆の 3 本に分けて足してから 3 本を足す）
- baseRCheckBreakFlag：baseRCheckRelDiff が 1e-12 以下でなければ 1（否定形・NaN も 1）
- baseLag4Ratio：R の 4 四半期前（計器が同じ World を見た q−4 の値）÷今（履歴が無い・今の R が 0 以下なら nan）
- baseOverFirstSeenRatio：計器がその World を最初に見た四半期の R÷今の R（今の R が 0 以下なら nan・最初の四半期は R＞0 なら 1）
- fpCarrierPops：担い手（SubsistenceBasis＞0・Size＞1e-12・犯罪者でない）の POP の数
- fpShortPops：担い手のうち 請求′＞max(0, Savings) の数（本国格の州も含む）
- fpShortSizeK：同じ POP の Size の和
- fpShortfallGoodsPerMonth：同じ POP の Σ(請求′−max(0, Savings))÷州の主食の値段（値段が有限で正の州だけ）
- fpShortNoPricePops：同じ POP のうち州の主食の値段が有限で正でない数（不足の量に足していない数）
- fpShortPopsSizeK1・fpShortPopsSizeK10・fpShortPopsSizeK100・fpShortPopsSizeK1000・fpShortPopsSizeKOver：同じ POP を Size（千人）の桁で（≦1・(1,10]・(10,100]・(100,1000]・＞1000）＝記録（門の母集合にしない）
- 請求′（月）＝人頭税（PollTax＞1e-9 かつ IsCommoner：PollTaxRate×PollTax×Size）＋所得税の上界（TaxRate×max(0, LastEarnedPerMonth)×privBase′・同意を掛けない）＋十分の一税の上界（率′＝TitheRate×度合い＞1e-9 かつ国に聖職〔ClassId＝聖職かつ Size＞1e-9〕の Size の和＞1e-9 かつ大衆〔IsCommoner かつ近代エリートでない〕で LastEarnedPerMonth＞0：率′×LastEarnedPerMonth・度合いは国教法の分岐〔Privileges.cs:35〜:37〕を計器が書く）。当月の土地税・累進課税・仲介者の取り分は含めない。

### landbasereg_s（州×四半期・計器の国の名簿〔POB_INSTRUMENTS_NATIONS・IsPicked〕の国の全ての州）
- quarter・year・nation・region・tier
- regionBasePerMonth：州の Σ max(0, LandRentPerMonth)（Colonial の移しの後＝植民地格の州の不在地主の分は首都の州に載る）
- regionPayersWithRent：LandRentPerMonth＞0 の POP の数
- regionStapleRentShare：r_州（主食の RGO が無い州は nan）
- regionSubValuePerMonth：V_州（主食の重みが 0 の州は nan）

- regionBaseLag4Ratio：州の基数の 4 四半期前（計器が同じ Region を見た q−4）÷今（履歴が無い・今が 0 以下なら nan・Region を鍵にする＝割譲で持ち主が変わっても州に付いて行く）
