■ [3] 計器の定義（腕の前に固定・エンジンの関数を呼ばず、状態の欄は計器が自分で読む）

  subst_s（州×四半期・四半期の末の断面＝直近の月の値・行は担い手がいる州〔自給の担い手の人数＞0〕か農業労働の売り手がいる州だけ）
    列（単位の接尾辞：PerMonth＝その月の量・Share＝0〜1・Over＝比）：
    quarter／year／nation／region／tier／subPopK（Subsistence＞0 の POP の Size の和）／subRateWeighted（Size 加重の Subsistence）／
    farmCapPerMonth（農業労働力の人力の売り手〔財＝FarmLabor・RecipeName が空・Inputs が空・倒産でない・Capacity＞0〕の Capacity の和）／farmSoldPerMonth（農業労働力の市場の LastSold）／farmProducedPerMonth（同 LastProduced）／
    soldOverCap（売れた÷能力・能力＝0 なら nan）／
    unsoldD1Share＝D1（clamp01(1−売れた÷能力)・能力＝0 なら nan）／unsoldD2Share＝D2（産出＞1e-9 なら clamp01(1−売れた÷産出)・そうでなければ 0＝今の失業の式の Eps の枝と同じ）／producedZeroFlag（産出≦1e-9 なら 1）／
    stapleNeedPerCapita（Catalog の主食〔Tier＝Staple〕の BaseNeed の和＝名目 1.10）／engineSubOutputPerMonth（Region.LastSubsistenceOutput＝エンジンが月に積んだ自給の量・収穫係数と補正を含む）／nominalSubPerMonth（Σ Size×Subsistence×stapleNeedPerCapita＝収穫係数 1・補正なし）／
    productivityFromDataPerCapita（subRateWeighted×stapleNeedPerCapita÷SubstD1Ref＝国のデータから導いた開幕の生産性）／
    derivedD1PerMonth（D1×SubstCalibration×subPopK）／derivedD2PerMonth（D2×SubstCalibration×subPopK）／
    derivedD1OverNominal・derivedD2OverNominal・derivedD1OverEngine・derivedD2OverEngine（導いた÷今・分母＝0 なら nan）／
    Q2 の材料：pollClaimPerMonth（Subsistence＞0 の POP の人頭税の請求＝PollTaxRate×段×Size・段＞1e-9・閉鎖階級・兵士・犯罪者を除く）／incomeTaxUpperPerMonth（TaxRate×max(0, LastEarnedPerMonth)・Subsistence＞0 の POP の上界）／rentToOthersPerMonth（Subsistence≦0 の POP の LandRentPerMonth の和＝地代を受け取る他の層）／rentToFarmersPerMonth（Subsistence＞0 の POP の LandRentPerMonth の和）／
    stapleNeedWeightedPrice（主食の BaseNeed で重み付けた州の市場の値段）／stapleNeedValuePerMonth（Σ Size〔Subsistence＞0〕×stapleNeedPerCapita×stapleNeedWeightedPrice）／marketShareOfNeed（1−subRateWeighted）／
    obligationOverMarketNeed（(pollClaimPerMonth＋incomeTaxUpperPerMonth＋rentToOthersPerMonth)÷(marketShareOfNeed×stapleNeedValuePerMonth)・分母＝0 なら nan）。
  定数（計器の名乗り・係数ではない）：SubstD1Ref＝0.866（開幕 1783〜85 の売れた÷能力の補の物差し＝c66ds 材料 D-2 の〈0.866〉）・SubstCalibration＝0.89（c66ds が (825) の 1.1 を取り直した値＝0.7×1.10÷0.866 ≈ 0.889 を 2 桁に丸めた名乗り）。

  cornint_s（国×四半期・四半期の末の断面・全ての国）
    ブロックの添字 b：0＝旧支配層（Closed）・1＝近代エリート（IsModernElite）・2＝大衆（それ以外）＝PolicyPreferences.BlocOf と同じ三項式を計器が自分で書く。
    列：quarter／year／nation／cornLawsCode（World.CornLaws の序数）／
    rentDomPerMonth0..2（国の全 POP の max(0, LandRentPerMonth) のブロック別の和＝エンジンの Rent[b] の正規化の前）／rentDomTotalPerMonth／engineRentShare0..2（rentDom_b÷rentDomTotal・分母＜1e-9 なら 0＝Normalize と同じ）／
    rentExpPerMonth0..2（PaySales の地代：輸出された財ごとに、その財の RGO の売り手〔所有者と労働の POP の添字が有効・産出＞0〕の産出比で ExportsByGood を割り、慣習の取り分 min(RentShare, FarmRentCap) を掛けた額を所有者のブロックへ・国営持分と不在地主は引かない〔限界⑤〕）／
    rentGrainDomPerMonth0..2・rentGrainExpPerMonth0..2（穀物法の客体＝Tier が Staple か GrainChain の財の分）／
    tariffLandTermNow0..2（RentProtectionWeightCoef×engineRentShare_b＝今の関税の地主の項）／cornPrefNow0..2（今の穀物法の選好＝RentProtectionWeightCoef×engineRentShare_b−(b＝0 なら 0・他は 1)）／
    grainImportValue・grainExportValue・grainProducedValue（客体の財の World.ImportsByGood・ExportsByGood の和＝国境を越えた分だけ・産出の値＝Σ 州 LastProduced×値段）／allImportValue・allExportValue／
    sigmaGrain（客体の財の Σ(輸入−輸出)÷Σ(輸入＋輸出＋産出の値)）／sigmaGrainRentW（客体の財の地代で重み付けた財ごとの σ）／sigmaAllRentW（全ての財の地代で重み付けた財ごとの σ）／
    c1InterestGrain0..2（Σ_財∈客体 rent_bg×σ_g÷rentTotal）／c1InterestAll0..2（Σ_財 rent_bg×σ_g÷rentTotal）・rentTotal＝Σ_b（rentDom_b＋rentExp_b）＝国の地代の和（反証役の訂正 中〜低④）／
    c1CornPref0..2（RentProtectionWeightCoef×c1InterestGrain_b−(b＝0 なら 0・他は 1)）／c1TariffLand0..2（RentProtectionWeightCoef×c1InterestAll_b）／
    flipCorn0（今の穀物法の選好の正負と C1 の正負が違えば 1）。
    財ごとの σ_g＝(ImportsByGood[g]−ExportsByGood[g])÷(ImportsByGood[g]＋ExportsByGood[g]＋産出の値_g)・分母＝0 なら 0・ByGood の配列が無い国は σ＝nan。ByGood は国境を越えた分だけ（BilateralMarket.cs の crossA の中でだけ積む＝同じ国の州どうしは数えない・反証役の訂正 中②）。
    地代の財ごとの配分（国内）：POP の LandRentPerMonth を、その POP が所有する RGO の産出の値〔産出×州の値段〕で按分する。所有する RGO の産出の値が 0 の POP の地代は rentDomUnattrPerMonth0..2 に別に出す（和＝rentDom）。

  共通の限界（計器が自己申告する）：①四半期の末＝直近の月の値②限界の記録として、地代の財ごとの配分は産地ごとの地代がどこにも貯まっていないための近似③輸出の地代は国営持分・不在地主・州ごとの取引の分布を数えない近似（国の産出比）④ByGood は値（世界価格建て・輸入は運賃を含む）で産出は州の値段建て⑤国営持分と不在地主の分は引かない⑥Subsistence の担い手は農民以外も数える（エンジンと同じ読み方）。
