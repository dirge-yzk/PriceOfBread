## 3-8. 外交（85件）
### この分野は何をしているか

★★★ **外交の中心は「緊張」という1つの数字。** ⚠ 好感度・信頼度といった別のスカラーは持たない。国と国の組ごとに 0〜200 の緊張が持たれ、積もると戦争になる。⚠ 画面の%表示は**開戦閾値=100%**の目盛り（内部140が100%）。

**緊張が積もる原因**

| 原因 | 説明 |
|---|---|
| ★★**脅威** | ⚠ **大国であること自体が周囲の緊張を生む**（★経済規模・植民地・軍事力の平均超過分。訓練された軍ほど重い） |
| ★**思想の距離** | 政体が違うほど緊張する（同じ政体は冷める） |
| ★**文明の距離** | 民族・法体系・宗教の隔たり |
| ★**同じ宗教の住民の保護** | ⚠ 異教の国が自国と同じ宗教の州を支配していると、保護の利害が立つ |
| ★★**交易路の扼圧** | ⚠ **閉じた海の唯一の出口を他国が握っている**と、依存する側の緊張が積む |
| ★**挑発と侮辱** | ⚠ **国内のタカ派が喝采する**が、相手との緊張が上がる |
| ★**勢力圏の奪い合い** | ⚠ 侵略に手を出しただけで他の列強との緊張が上がる |
| ★**復讐心** | 失った土地の記憶（半減期20年） |
| ★**アヘンの禁令** | ⚠ 輸出国が怒る |
| ★**参戦要請の拒否・調停の拒否** | ⚠ 面子を潰された側との緊張 |

★★ **緊張は自然に冷めるが、⚠ 高い帯では冷めにくい。** ★ 冷めなさの正体は**遺恨**（領土を奪われた記憶）であって、固定の下限ではない。

★★★ **軍事力は両方向に効く。** ⚠ 大きな軍は緊張を高めるが、★★ **同時に相手を屈服させて戦争を防ぐ**（陣営戦力に3倍の差があれば弱い側が引く）。

★★ **緊張が積もった理由は台帳として残る。** ⚠ 21種のチャネルごとに寄与が積まれ、合計が現在の緊張に一致する＝画面のホバーとモーダルはこの台帳をそのまま出す。

⚠ **講和・独立の後の休戦は無い**（固定の年数は 2026-09-08 に廃止・規模で決める器も 2026-09-26 (52) に削除）。

### あなたが動かせるもの

- **挑発**（⚠ 緊張を上げる。★ 国内のタカ派が喜び、ハト派が怒る。★★ **禁輸も同時に発動する**）
- **緩和**（★ 緊張を下げる。⚠ 格下への宥和は「弱腰」として叩かれる）
- **最後通牒への応答**（受け入れる／開戦）
- **同盟からの参戦要請への応答**（受ける／断る）
- **侵略**（★ 弱小への唯一の動詞。⚠ 屈服なら併合／属国化、拒めば開戦）
- **統一戦争**（★ 同じ文化の必要州を持つ国への宣戦）
- **他国の戦争への調停**（★★ **AIの列強介入と同じ述語・同じ本体**）
- **軍需輸出の法**（⚠ 禁じると緊張の高い相手の比重ぶん、軍需の輸出が一律に絞られる）
- **アヘン輸出の法**（⚠ 禁じると相手国との緊張の源が断たれる）
- **他国植民地への「関心」**（★ 地図上の○をクリック。講和で勝ったとき優先して取る。⚠ 効くのは領土だけの勢力の植民地だけ＝州になった植民地には効かない）

### ⚠ できないこと

★★★ **宣戦布告のボタンは無い。** ⚠ 戦争は緊張から創発する（統一戦争と侵略の拒否だけが例外的な開戦経路）。
★★ **防衛同盟の締結・破棄のボタンも無い。** ⚠ 同盟は「共通の敵を恐れる二国が手を結ぶ」経路で**プレイヤーも含めて自動**に成立し、緊張が上がれば自動で壊れる。
★ **禁輸の単独ボタンも無い**（挑発に同梱・戦時は強制・終戦と属国化で自動解除）。
★ **通商条約の提案ボタンも無い**（2026-09-07 に廃止＝AIと同じ四半期の掃引で自動に結ぶ）。
